## What is Master UI? [sr-only]
### A universal UI library
Master UI is a universal UI library built on top of [Master CSS](https://rc.css.master.co/guide/introduction). It works seamlessly with any technology, including HTML, CSS, JavaScript, React, Vue, Svelte, Angular, and more. Additionally, you can adopt various development strategies such as semantic CSS, atomic CSS, or a combination of both.

There are different ways to create the primary button.

1. Write nostalgic **semantic CSS**.
```html
<button class="btn btn-md btn-primary">Submit</button>
```
That’s not all! You can even use advanced syntax like `mcss btn-sm@<=sm` 🚧.

2. For frameworks, such as **React**.
```tsx
import { Button } from '@master/ui.react'

export default () => <>
    <Button>Submit</Button>
</>
```
It is not a feature-rich component of a specific framework. We only componentize them in a [lightweight way](https://github.com/master-co/ui/blob/alpha/packages/react/src/Button.tsx), providing a simple interface and basic states such as [loading](/components/button#loading).

3. **Copy-paste** atomic CSS to take full control of internals.
```html
<button class="center-content inline-flex {cursor:wait;text:transparent}.loading {bg:transparent;fg:lightest;outline:0;cursor:not-allowed}:disabled:not(.loading) bg:primary bg:touch-primary:active fg:primary-contrast font:14 font:semibold h:10x outline-offset:-1 outline:1|ring-primary px:4x r:6:where(*) user-select:none">Submit</button>
```
When you need full customization, you can copy atomic classes or even the source code. When you need quick usage, you can add semantic classes or even import them from NPM.

This is where Master UI comes into play.

## Why Master UI?
Master UI opens up new ideas for component construction, which is more flexible, burden-free, and easier to use than you think, and covers the CSS development patterns you have seen.

You can think of Master UI as a combination of today's popular libraries such as Bootstrap, Tailwind UI, Shadcn UI, and Material UI. We address some of the discomforts you experienced with these frameworks and incorporated some of their advantages.

### Compared to Bootstrap
[Bootstrap](https://getbootstrap.com) provides a bundled set of default CSS and JavaScript, enabling developers to easily build modern, responsive websites. It includes numerous pre-designed styles and layout options, significantly streamlining the frontend development process and being widely used across global web development projects.

In Bootstrap, you can **copy-paste the impressive CDN** to instantly enable all of features:
```html name=Bootstrap
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width, initial-scale=1">
+        <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-QWTKZyjpPEjISv5WaRU9OFeRpok6YctnYmDr5pNlyT2bRjXh0JMhjY6hW+ALEwIH" crossorigin="anonymous">
+        <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" integrity="sha384-YvpcrYf0tY3lHB60NNkmXc5s9fDVZLESaAA55NDzOxhy9GkcIdslK1eN7N6jIeHz" crossorigin="anonymous"></script>
    </head>
    <body>
        <button class="btn btn-primary">Primary</button>
    </body>
</html>
```
Master UI also works out of the box in the browser:
```html name=Master UI
<!DOCTYPE html>
<html lang="en" style="display: none">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <link rel="preload" as="script" href="https://cdn.master.co/css-runtime@rc">
    <link rel="preload" as="script" href="https://cdn.master.co/ui@alpha">
    <link rel="preload" as="style" href="https://cdn.master.co/normal.css">
+    <link rel="stylesheet" href="https://cdn.master.co/normal.css">
+    <script src="https://cdn.master.co/css-runtime@rc"></script>
+    <script src="https://cdn.master.co/ui@alpha"></script>
</head>
<body>
    <button class="btn btn-md btn-primary">Primary</button>
</body>
</html>
```
The core strategy of Master UI is to use modern techniques of pure HTML and CSS to implement interactive components, thereby avoiding the global registration overhead and pitfalls of a dynamic DOM using JavaScript.

### Compared to Tailwind UI
[Tailwind UI](https://tailwindui.com) is a professional, paid product built on top of Tailwind CSS. It offers pre-designed components, including navigation, forms, and modals, allowing developers to quickly build modern web applications by copying and pasting.

Let's take the badge as an example:
<Demo>
    <span className={styles['tailwind-ui-purple-badge']}>Badge</span>
</Demo>
```html name=Tailwind UI
<span class="inline-flex items-center rounded-md bg-purple-50 px-2 py-1 text-xs font-medium text-purple-700 ring-1 ring-inset ring-purple-700/10">Badge</span>
```
While different design systems have distinct styles, often their basic components are similar. If you only need to make minor modifications or use them directly, semantic CSS remains relatively convenient and concise at this point.
<Demo>
    <Badge color="purple">Badge</Badge>
</Demo>
```html name=Master UI
<span class="badge badge-md badge-purple">Badge</span>
```
**Again, you can always switch to atomic CSS if you want!**

This maintains flexibility in modifications, mitigates the chaos of atomic CSS, and ensures consistency of these basic components through theme variables.

**In Master UI, all common components are open-source**, and each component is carefully built one-to-one.
