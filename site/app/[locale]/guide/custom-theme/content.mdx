This guide walks you through how to use Master CSS variables and styles to implement common specifications in design systems.

By presetting these variables and styles, the complexity of template markup is significantly reduced, making a single source of truth easier to maintain.

---

## Customize the primary color
You can choose a color from the [default palette](https://rc.css.master.co/reference/colors) as the primary color. On this site, we use classic the yellow.
<ColorPalette filterColors={['yellow']} />
```js name=master.css.js
import { variables } from '@master/css'

/** @type {import('@master/css').Config} */
export default {
    variables: {
         primary: variables.yellow,
         text: {
            primary: '$(text-yellow)'
         }
    }
}
```
