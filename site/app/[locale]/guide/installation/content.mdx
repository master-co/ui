The easiest way to use Master UI from scratch is to initialize with the Master CSS runtime in the entry file.

<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a project
            If you haven't a project yet, it's recommended to create a Master CSS & UI project locally using the official CLI.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create @master/css@rc __project__ --example ui
            cd __project__
            npm run dev --open
            ```
        </StepR>
        <StepEnd/>
    </Step>
</StepSection>

## Import into existing project
<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master UI
            Install Master UI into your Master CSS project via package managers.
        </StepL>
        <StepR>
            ```install
            **@master/ui@alpha**
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import Master UI
            Import `@master/ui` and add it to the `extends` section in your **master.css.js** file.

            <details>
                <summary>Or import a specific component</summary>
                <div>
                    ```js
                    + import { button } from '@master/ui'

                    /** @type {import('@master/css').Config} */
                    export default {
                    +    extends: [button]
                    }
                    ```
                </div>
            </details>
        </StepL>
        <StepR>
            ```js name=master.css.js
            + import ui from '@master/ui'

            /** @type {import('@master/css').Config} */
            export default {
            +    extends: [ui]
            }
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Start using Master UI
        Now style your first element using Master UI syntax!
        ```html
        <button class="**btn** **btn-md** **btn-primary**">Submit</button>
        ```
        It's just that easy to use.
        <Demo>
            <button className="btn btn-md btn-primary">Submit</button>
        </Demo>
    </Step>
</StepSection>
