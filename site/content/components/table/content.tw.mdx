## 儲存格 \{#cells\}

儲存格用來標示所在列時，使用 `<th class="table-cell" scope="row">`。用來標示一組資料列時，使用 `scope="rowgroup"`。這類儲存格會靠起始側對齊，字重採用 `--font-weight-control`。以 ARIA 角色組成的網格中，帶有 `role="rowheader"` 的 `table-cell` 也採用相同樣式。一般儲存格沿用周圍的字重，讓瀏覽器預設的 `<th>` 置中與粗體樣式不會打亂表格的排版。

用 ARIA 角色組成的表格也可用相同類別設定表格、列與儲存格的顯示方式，單獨使用 CSS 時也適用。

- `table-primary` 標示用來辨識資料列的儲存格，並加深文字顏色。其餘儲存格維持內文色，讓使用者先看到名稱。
- 在欄標題及該欄的儲存格加上 `table-numeric`，即可靠末端對齊，並使用等寬數字。各位數會上下對齊，便於依位數比較數值。

## 排序 \{#sorting\}

帶有 `aria-sort="ascending"` 或 `aria-sort="descending"` 的欄標題會加深文字顏色，並顯示指向排序方向的折角圖示。在欄標題內放一個按鈕來變更排序。樣式表會讀取這個屬性，由腳本或伺服器設定其值。

## 寬表格 \{#wide-tables\}

表格會保留欄位配置，不會改排成卡片，以便使用者逐欄比較資料。如果表格可能超出所在欄的寬度，請用沿行內軸捲動的[捲動區域](/components/scroll-area)包住它。有更多欄位的邊緣會淡出。`table-sticky` 會讓欄標題留在畫面上，資料列則從下方捲過。

## 無障礙 \{#accessibility\}

- 使用原生 `<table>`，搭配 `<thead>`、`<tbody>`，並在欄標題上加上 `scope="col"`，讓螢幕閱讀器在讀取每個儲存格時一併讀出所屬欄的標題。
- 捲動容器需要 `tabindex="0"`、`role="region"` 和標籤，讓使用者能用鍵盤捲動。
- 刻意在兩處表達選取狀態，分別透過列上的 `aria-selected` 與該列核取方塊的狀態。
