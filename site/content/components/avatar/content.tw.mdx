頭像代表個人或團隊。有相片時顯示相片，其餘情況顯示姓名縮寫，兩者都放在同樣大小的圓形中。邊緣有一道淡淡的內描邊，讓淺色相片在淺色底面上也能看清輪廓。

## 尺寸 \{#sizes\}

預設為 32px。姓名縮寫會隨圓形一起縮放，請使用一到兩個字母。

| 類別 | 尺寸 |
| --- | --- |
| `avatar-xs` | 20px |
| `avatar-sm` | 24px |
| `avatar` | 32px |
| `avatar-lg` | 40px |
| `avatar-xl` | 56px |

## 方形 \{#square\}

`avatar-square` 是圓角正方形，圓角半徑為邊長的四分之一。團隊、專案或組織可使用這個類別，讓使用者從形狀區分個人與群組。

<ComponentPreview name="square" height={96} title="方形" html={`<span class="avatar avatar-square" role="img" aria-label="Master">M</span>
<span class="avatar avatar-square avatar-lg" role="img" aria-label="Atlas">AT</span>`} />

## 狀態 \{#status\}

`avatar-status` 在圓形下緣加上狀態圓點，並用與後方底面同色的環形描邊勾出輪廓。圓點預設為綠色。若要表示其他狀態，可設定 `--avatar-status`，或加上 `bg-warning` 之類的背景 utility。請在無障礙名稱中用文字說明圓點代表的狀態。

## 重疊排列 \{#stack\}

`avatar-group` 讓相鄰頭像重疊自身尺寸的四分之一。每個頭像都會遮住前一個頭像的重疊部分，並以 2px 的環形描邊隔開，描邊顏色與後方底面相同。無論文字書寫方向為何，頭像都依標記順序排列。請在最後一個頭像顯示其餘人數，並為整組頭像提供一個名稱。

<ComponentPreview name="stack" height={96} title="重疊排列" html={`<div class="avatar-group" role="group" aria-label="Ada Lovelace, Alan Turing, Katherine Johnson and 4 others">
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-2.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-3.svg" alt=""></span>
  <span class="avatar" aria-hidden="true">+4</span>
</div>`} />

環形描邊的顏色須與頭像群組所在的底面一致。放在[面板、托盤、卡片](/components/surface)或對話框內時，各底面會透過 `--surface-color` 提供自身的顏色，描邊會自動配合。若使用自訂背景，請將 `--avatar-ring` 設為背景色。

## 無障礙 \{#accessibility\}

- 相片的 `alt` 須包含當事人的姓名。若頭像顯示姓名縮寫，請加上 `role="img"`，並用 `aria-label` 提供姓名。
- 如果頭像旁已有姓名，頭像便是裝飾，請使用 `alt=""` 或 `aria-hidden="true"`。
- 頭像重疊排列時，只在容器上為整組提供一個名稱，並將各圖片的替代文字留空，以免姓名被讀出兩次。
