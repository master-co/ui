An avatar stands for a person or a team: a photo when there is one, initials when there is not, in a circle that keeps the same size either way. A faint inward stroke finishes the edge, so a pale photo does not dissolve into a pale surface.

<ComponentPreview name="default" title="Avatar" html={`<span class="avatar"><img class="avatar-image" src="/demo/portrait-1.svg" alt="Ada Lovelace"></span>
<span class="avatar" role="img" aria-label="Grace Hopper">GH</span>`} />

## Sizes \{#sizes\}

The default is 32px. Initials scale with the circle. Use one or two letters.

<span class="avatar avatar-sm" role="img" aria-label="Ada Lovelace">AL</span>
<span class="avatar" role="img" aria-label="Ada Lovelace">AL</span>
<span class="avatar avatar-lg"><img class="avatar-image" src="/demo/portrait-2.svg" alt="Alan Turing"></span>
<span class="avatar avatar-xl"><img class="avatar-image" src="/demo/portrait-3.svg" alt="Katherine Johnson"></span>`} />

| Class | Size |
| --- | --- |
| `avatar-xs` | 20px |
| `avatar-sm` | 24px |
| `avatar` | 32px |
| `avatar-lg` | 40px |
| `avatar-xl` | 56px |

## Square \{#square\}

`avatar-square` is a rounded square with a corner a quarter of its size. Use it for a team, a project or an organization, so people and groups can be told apart by shape.

<ComponentPreview name="square" title="Square" html={`<span class="avatar avatar-square" role="img" aria-label="Master">M</span>
<span class="avatar avatar-square avatar-lg" role="img" aria-label="Atlas">AT</span>`} />

## Status \{#status\}

`avatar-status` puts a presence dot on the lower end of the circle, cut out by a ring of the surface behind it. It is green by default; set `--avatar-status`, or add a background utility such as `bg-warning`, for another status. A dot alone is not a message: say the status in the accessible name.

<ComponentPreview name="status" title="Status" html={`<span class="avatar avatar-lg">

  <span class="avatar-status"></span>
</span>
<span class="avatar avatar-lg" role="img" aria-label="Grace Hopper, away">
  GH
  <span class="avatar-status bg-warning"></span>
</span>`} />

## Stack \{#stack\}

`avatar-group` overlaps avatars by a quarter of their size. Each paints in front of the one before it and is separated from it by a 2px ring in the color of the surface behind the stack. The order follows the markup in both writing directions. Count the people who are not shown in a last avatar, and name the whole group once.

<ComponentPreview name="stack" title="Stack" html={`<div class="avatar-group" role="group" aria-label="Ada Lovelace, Alan Turing, Katherine Johnson and 4 others">
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-2.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-3.svg" alt=""></span>
  <span class="avatar" aria-hidden="true">+4</span>
</div>`} />

The ring must match the surface the stack sits on. Inside a [sheet, a tray, a card](/components/surface) or a dialog it does so by itself, because each surface publishes its color as `--surface-color`. On a custom background, set `--avatar-ring` to that background's color.

<ComponentPreview name="surface" title="On a surface" bodyClass="p-lg" html={`<div class="tray">
  <div class="sheet flex items-center justify-between gap-md p-lg">
    <span class="text-sm fg-text-strong">Reviewers</span>
    <div class="avatar-group" role="group" aria-label="Ada Lovelace and Alan Turing">
      <span class="avatar avatar-sm"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
      <span class="avatar avatar-sm"><img class="avatar-image" src="/demo/portrait-2.svg" alt=""></span>
    </div>
  </div>
</div>`} />

## Accessibility \{#accessibility\}

- A photo needs `alt` with the person's name. Initials are not a name: give the avatar `role="img"` and `aria-label`.
- When the name is written next to the avatar, the avatar is decoration: use `alt=""` or `aria-hidden="true"`.
- In a stack, name the group once on the container and leave the images empty, so a name is not read twice.
