## 정사각형 \{#square\}

`avatar-square`는 모서리 반경이 한 변 길이의 4분의 1인 둥근 정사각형입니다. 팀, 프로젝트, 조직에 이 모양을 사용하면 개인과 그룹을 모양으로 구분할 수 있습니다.

## 상태 \{#status\}

`avatar-status`는 원의 아래쪽 가장자리에 접속 상태를 나타내는 점을 배치합니다. 뒤쪽 표면과 같은 색의 테두리가 점을 둘러싸 점이 아바타에서 오려낸 것처럼 보입니다. 기본 색상은 녹색입니다. 다른 상태를 표시하려면 `--avatar-status`를 설정하거나 `bg-warning` 같은 배경 유틸리티를 추가하세요. 점만으로는 상태를 전달할 수 없으므로 접근 가능한 이름에 상태를 명시하세요.

## 배지 \{#badge\}

`avatar-badge`는 같은 모서리에 그림을 배치해 상대가 접속해 있는지가 아니라 어떤 사람인지를 나타냅니다. 인증 여부, 소속 회사, 프로젝트가 속한 팀 등을 표시할 수 있습니다. 크기는 아바타의 5분의 2이며, 중심이 원의 가장자리 45° 위치에 놓입니다. 상태 점과 마찬가지로 뒤쪽 표면과 같은 색의 테두리가 배지를 둘러싸 아바타에서 오려낸 것처럼 보입니다. 정사각형 아바타에서는 배지도 모서리가 둥근 정사각형이 됩니다. 배지 안에 아이콘을 넣거나 배지 자체를 이미지로 만들고, 그 의미를 아바타의 이름에 명시하세요.

## 사진을 불러오지 못할 때 \{#fallback\}

서버에서 가져오는 사진은 늦게 불러와지거나 없을 수 있습니다. 사진 아래의 `avatar-fallback`에 이니셜이나 아이콘을 넣으세요. 둘은 같은 셀을 공유하므로 상자 크기가 바뀌지 않습니다. [`avatar` 동작](/guide/behaviors)은 사진의 상태를 추적합니다. 사진을 불러오는 동안에는 폴백이 보이고, 사진을 불러오면 폴백이 숨겨집니다. 사진을 불러오지 못하거나 소스가 없으면 반대로 사진을 숨기므로, 깨진 이미지가 표시되지 않습니다. `src`가 바뀌면 처음부터 다시 시작하며, 아바타가 더 이상 표시하지 않는 사진에 대한 응답은 아무것도 바꾸지 않습니다.

아바타의 이름은 루트에 `role="img"`와 `aria-label`로 한 번만 지정하세요. 사진에는 빈 `alt`를, 폴백에는 `aria-hidden`을 지정해 이름이 두 번 읽히지 않도록 합니다. 스크립트가 없으면 사진이 그려져 폴백을 덮을 때까지 폴백이 보이며, 불러오지 못한 사진은 브라우저가 그리는 깨진 이미지로 표시됩니다.

```js name=app.js
import { avatar } from '@master/ui/behaviors/avatar.js'

for (const root of document.querySelectorAll('.avatar')) avatar(root)
```

## 접근성 \{#accessibility\}

- 사진에는 사람의 이름을 담은 `alt` 속성이 필요합니다. 이니셜만으로는 이름을 알 수 없으므로 아바타에 `role="img"`와 `aria-label`을 지정하세요.
- 아바타 옆에 이름이 표시되어 있으면 아바타는 장식 요소이므로 `alt=""` 또는 `aria-hidden="true"`를 사용하세요.
- 아바타를 겹쳐 배치할 때는 컨테이너에 그룹 이름을 한 번만 지정하고, 각 이미지의 대체 텍스트를 비워 이름이 두 번 읽히지 않도록 하세요.
- 배지나 상태 점은 그 자체로 읽히지 않습니다. 인증 여부, 자리 비움, 소속 회사는 아바타의 이름에 명시하세요.

## React, Svelte 및 Vue \{#frameworks\}

`avatar` 컴포넌트는 `src`, `alt`, `initials`를 받아 폴백 위에 사진을 배치하고 동작을 연결합니다. 모서리 표시는 자식 요소로 전달합니다. `npx master-ui add avatar`로 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte 및 Vue](/guide/frameworks)에서 확인할 수 있습니다. 불러오기에 실패할 일이 없는 사진이라면 컴포넌트가 필요 없으며 위의 마크업으로 충분합니다.
