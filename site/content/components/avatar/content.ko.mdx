아바타는 사람이나 팀을 나타냅니다. 사진이 있으면 사진을, 없으면 이니셜을 표시하며 원의 크기는 두 경우 모두 같습니다. 가장자리 안쪽에 옅은 선을 둘러 밝은 사진도 밝은 표면 위에서 경계가 드러나도록 합니다.

<span class="avatar" role="img" aria-label="Grace Hopper">GH</span>`} />

## 크기 \{#sizes\}

기본 크기는 32px입니다. 이니셜의 크기는 원의 크기에 비례합니다. 글자 한두 개를 사용하세요.

<span class="avatar avatar-sm" role="img" aria-label="Ada Lovelace">AL</span>
<span class="avatar" role="img" aria-label="Ada Lovelace">AL</span>
<span class="avatar avatar-lg"><img class="avatar-image" src="/demo/portrait-2.svg" alt="Alan Turing"></span>
<span class="avatar avatar-xl"><img class="avatar-image" src="/demo/portrait-3.svg" alt="Katherine Johnson"></span>`} />

| 클래스 | 크기 |
| --- | --- |
| `avatar-xs` | 20px |
| `avatar-sm` | 24px |
| `avatar` | 32px |
| `avatar-lg` | 40px |
| `avatar-xl` | 56px |

## 정사각형 \{#square\}

`avatar-square`는 모서리 반경이 한 변 길이의 4분의 1인 둥근 정사각형입니다. 팀, 프로젝트, 조직에 이 모양을 사용하면 개인과 그룹을 모양으로 구분할 수 있습니다.

<ComponentPreview name="square" height={96} title="정사각형" html={`<span class="avatar avatar-square" role="img" aria-label="Master">M</span>
<span class="avatar avatar-square avatar-lg" role="img" aria-label="Atlas">AT</span>`} />

## 상태 \{#status\}

`avatar-status`는 원의 아래쪽 가장자리에 접속 상태를 나타내는 점을 배치합니다. 뒤쪽 표면과 같은 색의 테두리가 점을 둘러싸 점이 아바타에서 오려낸 것처럼 보입니다. 기본 색상은 녹색입니다. 다른 상태를 표시하려면 `--avatar-status`를 설정하거나 `bg-warning` 같은 배경 유틸리티를 추가하세요. 점만으로는 상태를 전달할 수 없으므로 접근 가능한 이름에 상태를 명시하세요.

  <img class="avatar-image" src="/demo/portrait-1.svg" alt="Ada Lovelace, online">

</span>

## 아바타 겹치기 \{#stack\}

`avatar-group`은 아바타를 크기의 4분의 1만큼 겹쳐 배치합니다. 각 아바타는 앞선 아바타 위에 그려지며, 뒤쪽 표면과 같은 색의 2px 테두리로 구분됩니다. 어느 쓰기 방향에서든 순서는 마크업을 따릅니다. 표시하지 않은 인원 수는 마지막 아바타에 표시하고, 그룹 전체에 이름을 한 번만 지정하세요.

<ComponentPreview name="stack" height={96} title="겹친 아바타" html={`<div class="avatar-group" role="group" aria-label="Ada Lovelace, Alan Turing, Katherine Johnson and 4 others">
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-2.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-3.svg" alt=""></span>
  <span class="avatar" aria-hidden="true">+4</span>
</div>`} />

테두리 색은 겹친 아바타가 놓인 표면의 색과 같아야 합니다. [시트, 트레이, 카드](/components/surface) 또는 대화 상자 안에서는 각 표면이 자체 색상을 `--surface-color`로 제공하므로 자동으로 일치합니다. 사용자 지정 배경에서는 `--avatar-ring`을 해당 배경색으로 설정하세요.

## 접근성 \{#accessibility\}

- 사진에는 사람의 이름을 담은 `alt` 속성이 필요합니다. 이니셜만으로는 이름을 알 수 없으므로 아바타에 `role="img"`와 `aria-label`을 지정하세요.
- 아바타 옆에 이름이 표시되어 있으면 아바타는 장식 요소이므로 `alt=""` 또는 `aria-hidden="true"`를 사용하세요.
- 아바타를 겹쳐 배치할 때는 컨테이너에 그룹 이름을 한 번만 지정하고, 각 이미지의 대체 텍스트를 비워 이름이 두 번 읽히지 않도록 하세요.
