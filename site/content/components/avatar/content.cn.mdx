头像代表个人或团队。有照片时显示照片，否则显示姓名首字母，两种情况下圆形头像的尺寸相同。边缘内侧有一圈淡淡的细线，让浅色照片在浅色表面上也能看清轮廓。

## 尺寸 \{#sizes\}

默认尺寸为 32px。首字母随圆形头像等比例缩放。使用一个或两个字母。

<span class="avatar" role="img" aria-label="Ada Lovelace">AL</span>

| 类名 | 尺寸 |
| --- | --- |
| `avatar-xs` | 20px |
| `avatar-sm` | 24px |
| `avatar` | 32px |
| `avatar-lg` | 40px |
| `avatar-xl` | 56px |

## 方形 \{#square\}

`avatar-square` 是圆角方形，圆角半径为边长的四分之一。用于团队、项目或组织，可通过形状区分个人和群组。

<span class="avatar avatar-square avatar-lg" role="img" aria-label="Atlas">AT</span>`} />

## 状态 \{#status\}

`avatar-status` 在圆形头像下缘显示一个表示在线状态的圆点，并用一圈与底层表面同色的描边将圆点与头像隔开。圆点默认为绿色。要表示其他状态，请设置 `--avatar-status`，或添加 `bg-warning` 等背景工具类。在无障碍名称中写明状态，避免仅靠圆点传达信息。

  <span class="avatar-status"></span>
</span>

</span>`} />

## 堆叠 \{#stack\}

`avatar-group` 让相邻头像重叠各自尺寸的四分之一。每个头像盖在前一个头像上，并用一圈 2px 宽、与底层表面同色的描边将两者隔开。两种书写方向都遵循标记中的顺序。用最后一个头像显示未展示的人数，并为整个群组提供一个名称。

<ComponentPreview name="stack" height={96} title="堆叠" html={`<div class="avatar-group" role="group" aria-label="Ada Lovelace, Alan Turing, Katherine Johnson and 4 others">
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-2.svg" alt=""></span>
  <span class="avatar"><img class="avatar-image" src="/demo/portrait-3.svg" alt=""></span>
  <span class="avatar" aria-hidden="true">+4</span>
</div>`} />

描边必须与堆叠头像所在的表面同色。在[面板、托盘、卡片](/components/surface)或对话框内，描边会自动匹配，因为这些表面都通过 `--surface-color` 提供自身的颜色。使用自定义背景时，将 `--avatar-ring` 设为该背景的颜色。

## 无障碍 \{#accessibility\}

- 照片需要通过 `alt` 提供人物姓名。头像仅显示首字母时，请通过 `role="img"` 和 `aria-label` 提供姓名。
- 头像旁已写明姓名时，将头像作为装饰处理，使用 `alt=""` 或 `aria-hidden="true"`。
- 头像堆叠时，只在容器上为群组命名，并将各图片的替代文本留空，避免重复朗读姓名。
