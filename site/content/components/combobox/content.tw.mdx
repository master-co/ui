組合方塊是可輸入文字的選擇控制項，會開啟[清單方塊](/components/listbox)來顯示相符選項。它由現有的[輸入群組](/components/input#input-group)和浮動清單方塊組成，兩者以 `combobox` 包裝元素相連。樣式表負責定位和外觀。`combobox` [行為](/guide/behaviors)負責篩選選項、在選項間移動，以及將選取的值填入欄位。

## 樣式表的作用 \{#what-the-stylesheet-does\}

- **位置。** `combobox` 包裝元素將自身設為具名錨點，並將名稱的作用域限制在自身範圍內。清單方塊會在整個欄位下方 6px 處開啟，不以文字游標或按鈕為基準，並透過 `anchor-size()` 確保寬度至少與欄位相同。無須另外量測尺寸，同一頁上的多個組合方塊也能各自運作。
- **箭頭。** `combobox-toggle` 是欄位末端的小按鈕。當欄位為 `aria-expanded="true"` 時，按鈕上的箭頭會翻轉。
- **空白狀態。** 所有選項都設為 `hidden` 時，`listbox-empty` 會自動顯示。
- **欄位狀態。** 指標停留、焦點、無效及停用狀態均由輸入群組提供。

瀏覽器若不支援錨點定位，清單方塊仍可開啟，並依它在標記中的位置直接顯示在欄位下方，寬度為清單方塊本身的寬度。

## 行為 \{#behavior\}

`combobox` 接收根元素（也就是帶有 `combobox` 類別的元素）和選項物件，並傳回用來解除行為的函式。它會透過 `role="combobox"` 找到欄位，並透過 `role="listbox"` 找到清單。`filter` 選項預設為 true；`filter: false` 會把選項交由頁面處理，如[自動完成](#autocomplete)所示。`name`、`removeLabel` 和 `draw` 與[多個值](#several-values)有關。

```js name=app.js
import { combobox } from '@master/ui/behaviors/combobox.js'

const box = combobox(document.querySelector('.combobox'))
box.value // what the chosen option stands for, or null
box.query // the text in the field
```

它傳回的函式有兩個屬性，可從外部讀取和設定。設定任一屬性都不會派送事件。

- **`value`** 是所選選項代表的值，也就是它的 `data-value` 或文字；當欄位中的文字並未對應到任何已選選項時為 null。設定它會勾選該選項，並將其文字寫入欄位。
- **`query`** 是欄位中的文字，也就是讀者正在搜尋的內容。它不是值：每按一個鍵就會改變，選定選項後則是該選項的文字。設定它會寫入欄位，並像輸入文字時一樣篩選選項。

- **輸入文字**時，不包含輸入文字的選項會設為 `hidden`，比對不分大小寫。清單會開啟，第一個相符項目會成為作用中選項。
- **作用中選項**設為 `aria-selected="true"`，並由欄位上的 `aria-activedescendant` 指向。焦點會留在欄位內。
- **選取選項**時，可按 <kbd>Enter</kbd> 或用指標操作。選項文字會填入欄位，略過 `listbox-description` 和 `listbox-end` 的內容。選取的選項會設為 `aria-checked="true"`，其餘設為 `false`，清單隨即關閉。重新輸入並覆寫選取值時，會清除該選項的勾選狀態。
- **開啟與關閉。** 清單方塊使用 `popover="manual"`，因此在欄位內輸入或點擊時，清單會維持開啟。點擊欄位或切換按鈕，或按方向鍵，都會開啟清單。按 <kbd>Esc</kbd> 或焦點離開組合方塊時，會關閉清單。行為也會同步更新 `aria-expanded`。
- **事件。** 選取選項時，欄位會依序觸發 `input` 和 `change`，與輸入文字時相同。值取自欄位的 `value`。

停用或隱藏的選項會被略過。輸入法組字期間，<kbd>Enter</kbd> 和方向鍵會交由輸入法處理。

未掛上行為時，欄位會維持為文字輸入欄位。使用者仍可輸入值，清單則保持關閉。

## 多個值 \{#several-values\}

設有 `aria-multiselectable="true"` 的清單方塊可以容納多個值。這時欄位改用帶有 `input-group-wrap` 的輸入群組，與[標籤輸入](/components/tags)相同，每個選取的選項都會以[膠囊標籤](/components/chip)顯示在欄位前方。選取時會勾選或取消勾選該選項、清空欄位並讓清單維持開啟，只要再按幾個鍵就能加入下一個值。選項會保留勾選狀態，因此清單和膠囊標籤一樣能看出已選取哪些值。

- **欄位只負責搜尋。** 輸入文字只會篩選清單，不會取消任何勾選；已選取的值由膠囊標籤保留。
- **膠囊標籤。** 欄位是唯一的 Tab 停駐點。在空白欄位中按 <kbd class="kbd">Backspace</kbd>，或按往回方向的方向鍵，就能移到膠囊標籤上，此時的按鍵操作與[標籤輸入](/components/tags#keyboard)相同。用移除按鈕或 <kbd class="kbd">Backspace</kbd> 移除膠囊標籤時，會取消勾選對應的選項。
- **表單。** 若現有的膠囊標籤已帶有設定 `name` 的隱藏輸入元件，或有傳入 `name`，行為寫入的膠囊標籤就會帶有一個存放該值的隱藏輸入元件。`removeLabel` 用頁面的語言為移除按鈕命名。
- **值**是已選取值的清單，依選取的先後排列。

若值是自由輸入、而不是從清單中選取，請使用[標籤輸入](/components/tags)。

## 自動完成 \{#autocomplete\}

當相符項目來自伺服器，或來自頁面自己的搜尋時，請以 `filter: false` 掛載行為。它不會隱藏任何選項：在欄位每次觸發 `input` 時，讀取 `query`、搜尋它，再把相符項目寫成清單的選項。在觸發搜尋的輸入之後才送達的選項，仍會得到作用中選項，因此 <kbd>Enter</kbd> 和方向鍵都能操作它們。

<ComponentPreview name="autocomplete" height={360} title="自動完成" background="plain" bodyClass="content-start p-lg min-h(360)" behaviors html={`<div class="field max-w(320) mx-auto">
  <label for="city">City</label>
  <div class="combobox" id="city-combobox">
    <div class="input-group">
      <input class="input-group-field" id="city" role="combobox" aria-expanded="false" aria-controls="city-list" aria-autocomplete="list" autocomplete="off" placeholder="Start typing a city">
      <button type="button" class="combobox-toggle" tabindex="-1" aria-label="Show cities"></button>
    </div>
    <div id="city-list" popover="manual" class="listbox" role="listbox" aria-label="Cities">
      <div class="listbox-empty">No cities start with that.</div>
    </div>
  </div>
</div>
<script>
addEventListener('DOMContentLoaded', function () {
  var root = document.getElementById('city-combobox')
  var list = document.getElementById('city-list')
  var cities = ['Amsterdam', 'Athens', 'Auckland', 'Bangkok', 'Barcelona', 'Berlin', 'Bogotá', 'Boston', 'Brussels', 'Buenos Aires', 'Cairo', 'Cape Town', 'Chicago', 'Copenhagen', 'Dublin', 'Frankfurt', 'Helsinki', 'Hong Kong', 'Istanbul', 'Lisbon', 'London', 'Los Angeles', 'Madrid', 'Melbourne', 'Mexico City', 'Montreal', 'Mumbai', 'Nairobi', 'New York', 'Oslo', 'Paris', 'Prague', 'Rome', 'San Francisco', 'Santiago', 'São Paulo', 'Seoul', 'Singapore', 'Stockholm', 'Sydney', 'Taipei', 'Tokyo', 'Toronto', 'Vienna', 'Warsaw', 'Zurich']
  var box = MasterUI.combobox(root, { filter: false })
  var asked = 0

  // Stands for a request to a server: the cities that start with the query, a moment later.
  function search(query) {
    return new Promise(function (resolve) {
      setTimeout(function () {
        var text = query.trim().toLowerCase()
        resolve(cities.filter(function (city) { return city.toLowerCase().startsWith(text) }).slice(0, 6))
      }, 120)
    })
  }

  function write(matches) {
    list.querySelectorAll('.listbox-option').forEach(function (option) { option.remove() })
    matches.forEach(function (city) {
      var option = document.createElement('div')
      option.className = 'listbox-option'
      option.setAttribute('role', 'option')
      option.setAttribute('aria-checked', 'false')
      option.textContent = city
      list.insertBefore(option, list.querySelector('.listbox-empty'))
    })
  }

  root.addEventListener('input', function (event) {
    // A choice says input too; its text is the option's, with nothing more to look for.
    if (event.target.getAttribute('role') !== 'combobox' || box.value !== null) return
    var ticket = ++asked
    search(box.query).then(function (matches) {
      // An answer to an older query that arrives late is dropped.
      if (ticket === asked) write(matches)
    })
  })
  search('').then(write)
})
</script>`} caption="輸入幾個字母：頁面會搜尋查詢文字，稍後寫入選項。用方向鍵和 Enter 選取其中一個。" />

- **讀取 `query`，而不是事件。** 查詢文字就是欄位的文字；無論是讀者輸入的還是框架寫入的，`query` 都以相同方式讀取。
- **選取也會派送 `input`。** 此時文字是所選選項的文字，`value` 也不再是 null：沒有需要搜尋的內容，這時寫入新選項會把已選的選項移除。
- **回應的順序可能錯亂。** 只保留最新查詢的回應。
- **空白狀態由樣式表處理。** 清單中沒有任何選項時，`listbox-empty` 會自動顯示。

在 React、Svelte 和 Vue 中，元件的 `query` 和 `onQueryChange`（Svelte 中為可繫結的 `query`，Vue 中為 `v-model:query`）傳遞的是相同的文字：搜尋它，並把相符項目當作 `options` 傳入，同時將 `filter` 設為 false。

## 選擇控制項 \{#choosing-a-control\}

若純文字選項不超過 12 個，可用[下拉選單](/components/select)，無須腳本即可使用平台內建的鍵入定位功能。當清單很長而需要搜尋、選項會隨輸入載入，或每個選項需要呈現較豐富的內容時，請使用組合方塊。

## 鍵盤操作 \{#keyboard\}

按鍵由行為處理。清單關閉時，或按住 <kbd>Shift</kbd> 時，<kbd>Home</kbd> 和 <kbd>End</kbd> 會像在一般欄位中一樣移動文字游標。沒有作用中選項時，<kbd>Enter</kbd> 保留原本的行為，仍可送出表單。

## 無障礙 \{#accessibility\}

- 輸入欄位具有 `role="combobox"`、指向清單方塊的 `aria-controls`，以及 `aria-autocomplete="list"` 和 `aria-expanded`。
- 焦點留在輸入欄位內，輔助技術透過 `aria-activedescendant` 讀出作用中選項。
- 使用 `tabindex="-1"` 將切換按鈕移出 Tab 鍵的巡覽順序，因為在欄位中就能按方向鍵開啟清單。
- 設定 `autocomplete="off"`，避免瀏覽器內建的自動完成建議遮住清單方塊。

## React、Svelte 和 Vue \{#frameworks\}

`combobox` 元件會根據選項清單產生這套標記、掛上行為，並支援傳入及傳出選取值。設定 `multiple` 時，元件會根據值寫入膠囊標籤，此時值是一個清單。帶有 `group` 的選項會寫在該群組的標題下，放在帶有 `role="group"` 的 `listbox-group` 中，並以其 `listbox-label` 作為標籤；群組中的選項全部被篩選掉時，群組也會一併隱藏。除了值之外，元件也會傳遞查詢文字：React 中為 `query` 和 `onQueryChange`，Svelte 中為可繫結的 `query` 搭配 `onQueryChange`，Vue 中為 `v-model:query`。查詢文字會在讀者輸入時傳出，選定後也會在值之後傳出；由擁有者傳入的查詢文字會寫入欄位並篩選選項。用 `npx master-ui add combobox` 將元件複製到專案中。元件的建置與使用方式請參閱 [React、Svelte 和 Vue](/guide/frameworks)。
