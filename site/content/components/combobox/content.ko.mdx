## 스타일시트의 역할 \{#what-the-stylesheet-does\}

- **배치.** `combobox` 래퍼는 자신을 앵커로 지정하고 앵커 이름의 범위를 래퍼 자체로 제한합니다. 목록 상자는 캐럿이나 버튼이 아닌 필드 전체를 기준으로 그 아래 6px에 열리며, `anchor-size()`를 사용해 목록 상자의 너비를 최소한 필드 너비만큼 확보합니다. 별도의 측정이 필요 없으며 한 페이지에 콤보박스가 여러 개 있어도 서로 영향을 주지 않습니다.
- **꺾쇠 아이콘.** `combobox-toggle`은 필드 끝에 있는 작은 버튼으로, 꺾쇠 아이콘을 담습니다. 필드가 `aria-expanded="true"` 상태인 동안 꺾쇠 아이콘이 반대 방향을 향합니다.
- **빈 상태.** 모든 옵션이 `hidden` 상태가 되면 `listbox-empty`가 자동으로 표시됩니다.
- **필드 상태.** 호버, 포커스, 유효하지 않음, 비활성화 상태는 입력 그룹에서 처리합니다.

앵커 위치 지정을 지원하지 않는 브라우저에서도 목록 상자는 열리며, 마크업에 놓인 위치대로 필드 바로 아래에 목록 상자 자체의 너비로 표시됩니다.

## 동작 \{#behavior\}

`combobox` 동작은 `combobox` 클래스가 있는 루트 요소와 옵션 객체를 받아, 연결한 동작을 해제하는 함수를 반환합니다. `role="combobox"`로 필드를 찾고 `role="listbox"`로 목록을 찾습니다. `filter` 옵션의 기본값은 true입니다. `filter: false`를 지정하면 [자동 완성](#autocomplete)에서 보듯이 옵션을 페이지가 처리합니다. `name`, `removeLabel`, `draw`는 [여러 값 선택](#several-values)에 사용합니다.

```js name=app.js
import { combobox } from '@master/ui/behaviors/combobox.js'

const box = combobox(document.querySelector('.combobox'))
box.value // what the chosen option stands for, or null
box.query // the text in the field
```

반환된 함수에는 외부에서 읽고 설정할 수 있는 속성이 두 개 있습니다. 어느 속성을 설정해도 이벤트는 발행하지 않습니다.

- **`value`** 속성은 선택한 옵션이 나타내는 값으로, 옵션의 `data-value` 또는 텍스트입니다. 필드에 텍스트를 입력한 뒤 옵션을 선택하지 않은 상태에서는 null입니다. 값을 설정하면 해당 옵션에 체크 표시를 하고 그 텍스트를 필드에 입력합니다.
- **`query`** 속성은 필드의 텍스트, 즉 사용자가 찾고 있는 내용입니다. 선택 값과는 다릅니다. 키를 누를 때마다 바뀌며, 옵션을 선택하면 그 옵션의 텍스트가 됩니다. 값을 설정하면 필드에 입력하고, 직접 입력할 때와 마찬가지로 옵션을 필터링합니다.

- **텍스트를 입력하면** 대소문자를 구분하지 않고 입력한 문자열이 포함되어 있는지 확인합니다. 텍스트에 해당 문자열이 없는 옵션에 `hidden` 속성을 설정하고 목록을 연 뒤, 첫 번째 일치 항목을 활성 옵션으로 지정합니다.
- **활성 옵션**에는 `aria-selected="true"`가 설정되며, 필드의 `aria-activedescendant` 속성이 해당 옵션을 가리킵니다. 포커스는 필드에 유지됩니다.
- <kbd>Enter</kbd> 키나 포인터로 **옵션을 선택하면** 옵션에서 `listbox-description`과 `listbox-end`를 제외한 텍스트를 필드에 입력하고, 선택한 옵션은 `aria-checked="true"`로, 나머지 옵션은 `false`로 표시한 뒤 목록을 닫습니다. 선택한 값을 직접 수정하면 해당 옵션의 체크 표시가 사라집니다.
- **열기와 닫기.** 목록 상자는 `popover="manual"`이므로 필드에 입력하거나 필드를 클릭해도 닫히지 않습니다. 이 동작은 필드를 클릭하거나 토글 버튼을 조작하거나 방향키를 누르면 목록을 열고, <kbd>Esc</kbd> 키를 누르거나 포커스가 콤보박스를 벗어나면 목록을 닫습니다. `aria-expanded`는 목록의 열림 상태에 맞춰 갱신합니다.
- **이벤트.** 옵션을 선택하면 필드에 직접 입력할 때와 마찬가지로 필드에서 `input`, `change` 순서로 이벤트를 발생시킵니다. 값은 필드의 `value`입니다.

비활성화되거나 숨겨진 옵션은 건너뜁니다. 입력기로 문자를 조합하는 동안에는 입력기가 <kbd>Enter</kbd> 키와 방향키를 처리합니다.

동작을 연결하지 않으면 필드는 일반 텍스트 입력란으로 작동합니다. 값을 직접 입력할 수 있으며 목록은 열리지 않습니다.

## 여러 값 선택 \{#several-values\}

`aria-multiselectable="true"`가 설정된 목록 상자에는 여러 값을 담을 수 있습니다. 이때 필드는 [태그 입력](/components/tags)과 마찬가지로 `input-group-wrap`을 적용한 입력 그룹이 되며, 선택한 옵션은 각각 필드 앞에 [칩](/components/chip)으로 표시됩니다. 옵션을 선택하면 체크 표시가 켜지거나 꺼지고, 필드가 비워지며, 목록은 열린 상태로 유지됩니다. 따라서 다음 값도 키 몇 번으로 바로 고를 수 있습니다. 옵션의 체크 표시도 유지되므로, 칩과 마찬가지로 목록에서도 무엇을 선택했는지 알 수 있습니다.

## 자동 완성 \{#autocomplete\}

일치 항목을 서버에서 가져오거나 페이지 자체의 검색으로 찾는다면 `filter: false`로 동작을 연결하세요. 동작은 아무것도 숨기지 않습니다. 필드에서 `input`이 발생할 때마다 `query`를 읽어 검색하고, 일치 항목을 목록의 옵션으로 작성하세요. 입력에 대한 응답이 늦게 도착해도 도착한 옵션 중 하나가 활성 옵션으로 지정되므로, <kbd>Enter</kbd> 키와 방향키로 조작할 수 있습니다.

- **이벤트가 아니라 `query`를 읽으세요.** 검색어는 필드의 텍스트입니다. 사용자가 입력했든 프레임워크가 작성했든 `query`는 같은 방식으로 이 텍스트를 읽습니다.
- **옵션을 선택해도 `input`이 발생합니다.** 이때 텍스트는 선택한 옵션의 텍스트이며, `value`는 더 이상 null이 아닙니다. 검색할 내용이 없으며, 이때 새 옵션을 작성하면 선택한 옵션이 사라집니다.

React, Svelte, Vue에서는 컴포넌트의 `query`와 `onQueryChange`(Svelte에서는 바인딩 가능한 `query`, Vue에서는 `v-model:query`)가 같은 텍스트를 전달합니다. 이 텍스트로 검색하고, `filter`를 false로 설정한 뒤 일치 항목을 `options`로 전달하세요.

## 컨트롤 선택 기준 \{#choosing-a-control\}

단순한 옵션이 12개 이하라면 [셀렉트](/components/select)에서 스크립트 없이 플랫폼 기본 기능으로 글자를 입력해 옵션을 찾을 수 있습니다. 목록이 길어 검색이 필요하거나, 입력에 따라 옵션을 불러오거나, 각 행에 부가 설명 등 다양한 콘텐츠를 표시해야 할 때는 콤보박스를 사용하세요.

## 키보드 조작 \{#keyboard\}

키보드 입력은 연결한 동작에서 처리합니다. 목록이 닫혀 있거나 <kbd>Shift</kbd> 키를 누른 상태에서는 <kbd>Home</kbd>과 <kbd>End</kbd> 키가 일반 입력 필드에서처럼 캐럿을 이동합니다. 활성 옵션이 없으면 <kbd>Enter</kbd> 키의 기본 동작을 그대로 두므로 양식을 제출할 수 있습니다.

## 접근성 \{#accessibility\}

- 입력 요소에는 `role="combobox"`, 목록 상자를 가리키는 `aria-controls`, `aria-autocomplete="list"`, `aria-expanded` 속성이 설정됩니다.
- 포커스는 입력 요소에 유지되며, 스크린 리더는 `aria-activedescendant` 속성을 통해 활성 옵션을 읽어 줍니다.
- 필드에서 방향키로 목록을 열 수 있으므로 `tabindex="-1"`을 설정해 토글 버튼을 탭 순서에서 제외하세요.
- 브라우저의 자체 추천 항목이 목록을 가리지 않도록 `autocomplete="off"`로 설정하세요.

## React, Svelte, Vue \{#frameworks\}

`combobox` 컴포넌트는 옵션 목록을 바탕으로 이 마크업을 렌더링하고 동작을 연결하며, 선택한 값을 받아 외부로 전달할 수 있습니다. `multiple`을 지정하면 값이 목록이 되고, 컴포넌트가 그 값으로 칩을 작성합니다. `group`이 있는 옵션은 해당 캡션 아래, `listbox-label`로 레이블이 지정되고 `role="group"`이 있는 `listbox-group` 안에 작성됩니다. 그룹의 옵션이 모두 필터링되면 그룹도 함께 숨겨집니다. 컴포넌트는 값 외에 검색어도 전달합니다. React에서는 `query`와 `onQueryChange`, Svelte에서는 `onQueryChange`와 함께 쓰는 바인딩 가능한 `query`, Vue에서는 `v-model:query`를 사용합니다. 검색어는 사용자가 입력할 때마다 전달되며, 옵션을 선택하면 선택 값을 전달한 뒤 검색어를 전달합니다. 외부에서 지정한 검색어는 필드에 반영되며, 그 검색어로 옵션을 필터링합니다. `npx master-ui add combobox` 명령을 실행해 프로젝트에 복사하세요. 컴포넌트의 구성과 사용 방법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
