组合框是可输入文字的选择控件，输入时会打开一个显示匹配项的[列表框](/components/listbox)。外层的 `combobox` 将现有的[输入组](/components/input#input-group)和浮动列表框组合在一起。样式表负责定位和呈现，`combobox` [行为脚本](/guide/behaviors)负责筛选选项、在选项间移动，并将选中的选项写入输入框。

## 样式表的作用 \{#what-the-stylesheet-does\}

- **定位。** 外层的 `combobox` 为自身设置锚点名称，并将名称的作用域限定在自身。列表框在整个输入区域下方 6px 处打开，定位不受插入光标或按钮位置影响，并通过 `anchor-size()` 使其宽度至少与输入区域相同。整个过程无需测量尺寸，同一页面上的多个组合框可以独立定位。
- **箭头。** `combobox-toggle` 是输入区域末端的小按钮，内含一个箭头图标。输入框处于 `aria-expanded="true"` 状态时，箭头会翻转。
- **空状态。** 所有选项都处于 `hidden` 状态时，`listbox-empty` 会自动显示。
- **输入框状态。** 悬停、聚焦、无效和禁用状态由输入组提供。

浏览器不支持锚点定位时，列表框仍可打开，并按它在标记中的位置直接显示在输入区域下方，宽度为列表框自身的宽度。

## 行为脚本 \{#behavior\}

`combobox` 接收带有 `combobox` 类的根元素和一个选项对象，并返回一个用于解除绑定的函数。它通过 `role="combobox"` 查找输入框，通过 `role="listbox"` 查找列表。`filter` 选项默认为 true；`filter: false` 将选项交由页面处理，如[自动补全](#autocomplete)所示。`name`、`removeLabel` 和 `draw` 用于[多个值](#several-values)。

```js name=app.js
import { combobox } from '@master/ui/behaviors/combobox.js'

const box = combobox(document.querySelector('.combobox'))
box.value // what the chosen option stands for, or null
box.query // the text in the field
```

返回的函数有两个属性，可从外部读取和设置。设置其中任何一个都不会派发事件。

- **`value`** 是所选选项代表的值，即其 `data-value` 或文本；输入框中的文字没有对应的已选选项时为 null。设置它会勾选对应的选项，并将其文本写入输入框。
- **`query`** 是输入框中的文字，即读者要查找的内容。它不是值：每次按键都会变化，选定某个选项后则变为该选项的文本。设置它会写入输入框，并像输入文字时一样筛选选项。

- **输入文字**时，脚本会给文本中不含输入内容的选项设置 `hidden`，匹配时忽略大小写。随后打开列表，并将第一个匹配项设为活动选项。
- **活动选项**带有 `aria-selected="true"`，输入框通过 `aria-activedescendant` 指向该选项。焦点保留在输入框中。
- **选择选项**时，按 <kbd>Enter</kbd> 或使用指针都会将选项文本写入输入框，省去其中的 `listbox-description` 和 `listbox-end`，将该选项标记为 `aria-checked="true"`，将其余选项标记为 `false`，然后关闭列表。输入新内容覆盖已选值时，会清除该选项的勾选标记。
- **打开和关闭。** 列表框使用 `popover="manual"`，因此在输入框中打字或点击时会保持打开。点击输入框或切换按钮，或按方向键时，脚本会打开列表。按 <kbd>Esc</kbd> 或焦点离开组合框时，脚本会关闭列表，并使 `aria-expanded` 与开关状态保持同步。
- **事件。** 选中选项时，输入框会像输入文字时一样，先派发 `input`，再派发 `change`。当前值取自输入框的 `value`。

移动时会跳过禁用和隐藏的选项。输入法处于组字状态时，<kbd>Enter</kbd> 和方向键由输入法处理。

未绑定行为脚本时，输入框仍可接受文本输入，列表保持关闭。

## 多个值 \{#several-values\}

带有 `aria-multiselectable="true"` 的列表框可以容纳多个值。此时输入区域是带有 `input-group-wrap` 的输入组，与[标签输入](/components/tags)相同，每个已选选项都以[胶囊标签](/components/chip)显示在输入框之前。选择选项会勾选或取消勾选该选项，清空输入框并保持列表打开，因此只需再按几个键就能选择下一个值。选项会保留勾选标记，因此列表和胶囊标签一样能表明已选择了哪些值。

- **输入框只负责搜索。** 输入文字只会筛选列表，不会取消任何勾选；已选的值由胶囊标签保存。
- **胶囊标签。** 输入框是唯一的 Tab 停靠点。在空输入框中按 <kbd class="kbd">Backspace</kbd>，或按指向前一项的方向键，会定位到胶囊标签，在胶囊标签上的按键操作与[标签输入](/components/tags#keyboard)相同。用移除按钮或 <kbd class="kbd">Backspace</kbd> 删除胶囊标签时，会取消勾选对应的选项。
- **表单。** 如果现有胶囊标签已带有设置了 `name` 的隐藏输入框，或传入了 `name` 选项，行为脚本写入的胶囊标签也会带有一个保存该值的隐藏输入框。`removeLabel` 以页面的语言为移除按钮命名。
- **值**是已选值的列表，按选择的先后排序。

如果值由读者自由输入，而不是从列表中选择，请使用[标签输入](/components/tags)。

## 自动补全 \{#autocomplete\}

匹配项来自服务器或页面自己的搜索时，用 `filter: false` 绑定行为脚本。脚本不会隐藏任何选项：在输入框的每次 `input` 事件中读取 `query`，查找匹配项，并将结果写为列表的选项。即使选项在触发查找的输入之后才到达，仍会设置活动选项，因此 <kbd>Enter</kbd> 和方向键对它们同样有效。

  <div class="combobox" id="city-combobox">
    <div class="input-group">
      <input class="input-group-field" id="city" role="combobox" aria-expanded="false" aria-controls="city-list" aria-autocomplete="list" autocomplete="off" placeholder="Start typing a city">

  </div>

<script>
addEventListener('DOMContentLoaded', function () {
  var root = document.getElementById('city-combobox')
  var list = document.getElementById('city-list')
  var cities = ['Amsterdam', 'Athens', 'Auckland', 'Bangkok', 'Barcelona', 'Berlin', 'Bogotá', 'Boston', 'Brussels', 'Buenos Aires', 'Cairo', 'Cape Town', 'Chicago', 'Copenhagen', 'Dublin', 'Frankfurt', 'Helsinki', 'Hong Kong', 'Istanbul', 'Lisbon', 'London', 'Los Angeles', 'Madrid', 'Melbourne', 'Mexico City', 'Montreal', 'Mumbai', 'Nairobi', 'New York', 'Oslo', 'Paris', 'Prague', 'Rome', 'San Francisco', 'Santiago', 'São Paulo', 'Seoul', 'Singapore', 'Stockholm', 'Sydney', 'Taipei', 'Tokyo', 'Toronto', 'Vienna', 'Warsaw', 'Zurich']
  var box = MasterUI.combobox(root, { filter: false })
  var asked = 0

  // Stands for a request to a server: the cities that start with the query, a moment later.
  function search(query) {
    return new Promise(function (resolve) {
      setTimeout(function () {
        var text = query.trim().toLowerCase()
        resolve(cities.filter(function (city) { return city.toLowerCase().startsWith(text) }).slice(0, 6))
      }, 120)
    })
  }

  function write(matches) {
    list.querySelectorAll('.listbox-option').forEach(function (option) { option.remove() })
    matches.forEach(function (city) {
      var option = document.createElement('div')
      option.className = 'listbox-option'
      option.setAttribute('role', 'option')
      option.setAttribute('aria-checked', 'false')
      option.textContent = city
      list.insertBefore(option, list.querySelector('.listbox-empty'))
    })
  }

  root.addEventListener('input', function (event) {
    // A choice says input too; its text is the option's, with nothing more to look for.
    if (event.target.getAttribute('role') !== 'combobox' || box.value !== null) return
    var ticket = ++asked
    search(box.query).then(function (matches) {
      // An answer to an older query that arrives late is dropped.
      if (ticket === asked) write(matches)
    })
  })
  search('').then(write)
})
</script>`} caption="输入几个字母：页面会查找该内容，稍后写入选项。用方向键和 Enter 选择其中一个。" />

- **读取 `query`，而不是事件。** 查询内容就是输入框中的文字；无论是读者输入的还是框架写入的，`query` 都以相同方式读取。
- **选择选项同样会派发 `input`。** 此时文字是所选选项的文本，`value` 也不再为 null：已无需查找，这时写入新选项反而会移除已选的那个。
- **响应可能乱序到达。** 只保留对最新查询的响应。
- **空状态由样式表处理。** 列表中没有选项时，`listbox-empty` 会自动显示。

在 React、Svelte 和 Vue 中，组件的 `query` 和 `onQueryChange`（Svelte 中为可绑定的 `query`，Vue 中为 `v-model:query`）传递同样的文字：用它进行查找，再将匹配项作为 `options` 传入，并将 `filter` 设为 false。

## 选择控件 \{#choosing-a-control\}

对于最多十二个纯文本选项，[下拉选择框](/components/select)无需脚本即可利用平台原生的键入查找功能。如果选项多到需要搜索、需要随输入动态加载，或选项行包含丰富内容，请使用组合框。

## 键盘操作 \{#keyboard\}

这些按键由行为脚本处理。列表关闭时，或按住 <kbd>Shift</kbd> 时，<kbd>Home</kbd> 和 <kbd>End</kbd> 会像在普通输入框中一样移动光标。没有活动选项时，脚本保留 <kbd>Enter</kbd> 的默认行为，因此仍可用它提交表单。

## 无障碍 \{#accessibility\}

- 输入框带有 `role="combobox"`、指向列表框的 `aria-controls`、`aria-autocomplete="list"` 和 `aria-expanded`。
- 焦点保留在输入框中，辅助技术通过 `aria-activedescendant` 播报活动选项。
- 用 `tabindex="-1"` 将切换按钮移出 Tab 键导航顺序，因为在输入框中按方向键即可打开列表。
- 设置 `autocomplete="off"`，避免浏览器自带的建议遮住列表。

## React、Svelte 和 Vue \{#frameworks\}

`combobox` 组件根据选项列表渲染这段标记，绑定行为脚本，并接收和传出选中的值。设置 `multiple` 时，组件会根据值写入胶囊标签，此时值是一个列表。带有 `group` 的选项写在对应的分组标题下，位于带 `role="group"` 的 `listbox-group` 中，并以其中的 `listbox-label` 作为标签；某个分组的选项全部被筛掉时，该分组随之隐藏。除了值，组件还传递查询内容：React 中为 `query` 和 `onQueryChange`，Svelte 中为可绑定的 `query` 和 `onQueryChange`，Vue 中为 `v-model:query`。读者输入时以及做出选择后（在值之后）都会传出查询内容；调用方传入的查询内容会写入输入框，并用于筛选选项。使用 `npx master-ui add combobox` 将组件复制到项目中。有关这些组件的实现和用法，请参阅 [React、Svelte 和 Vue](/guide/frameworks)。
