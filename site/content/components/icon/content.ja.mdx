## Master Icons \{#master-icons\}

Master UI 自身のコンポーネントと例は [Master Icons](https://icons.master.co) を使います。各アイコンは 16、20、24px 用に 3 回描かれ、`currentColor` で描画されます。`icon` は任意の SVG、画像、アイコンコンポーネントを受け取るため、ほかのセットも同じように使えます。Master Icons は既定であり、必須ではありません。

```bash
npm install @master/icons-react --save-exact
```

フレームワークに合うパッケージをインストールします。`@master/icons-react`、`-vue`、`-svelte`、`-preact`、`-astro` のいずれか、SVG ファイルと素の JavaScript だけなら `@master/icons` です。

コンポーネントがアイコンに与えるサイズで図案を選び、その図案だけをインポートして `icon` を付けます。

| コンポーネントが設定するサイズ | 図案 | 図案の線幅 |
| --- | --- | --- |
| 17px 以下 | 16 | 1 |
| 18〜22px | 20 | 1.25 |
| 22px 超 | 24 | 1.5 |

```tsx
import SearchIcon from '@master/icons-react/native/16/soft/search'

<button type="button" className="btn btn-square" aria-label="Search">
  <SearchIcon className="icon" />
</button>
```

HTML では、[コレクション](https://icons.master.co/icons)から SVG をコピーして `icon` を付けます。名前はほかのセットと異なるため、書く前に検索します。

```bash
node node_modules/@master/icons/skills/master-icons/scripts/search.mjs "arrow left"
```

## 線幅 \{#stroke\}

アイコンは図案が持つ線幅を保ちます。Master Icons はどのサイズもグリッドの 16 分の 1 の線幅で描かれているため、16px では 1px になり、コンポーネントが設定するサイズに比例して太くなります。Master Icons の太さを変えるには、`@master/icons-react/16/soft` などの固定エントリーで `strokeWidth` を選びます。切り欠きと隙間はその線幅に合わせて描き直されます。

`--icon-stroke` は図案の線幅を、図案の viewBox の単位で置き換えます。塗りつぶしアイコンには影響しません。単純な線画アイコンのセットをインターフェースの太さに合わせるときに使います。コンテナーに設定すると、中のアイコンすべてに適用されます。

## アクセシビリティ \{#accessibility\}

- 装飾用のアイコンは、`aria-hidden="true"`で支援技術から隠します。
- アイコンだけのコントロールには、コントロール自体に名前を付けます。たとえば、[正方形ボタン](/components/button#with-icons)には`aria-label`を指定します。
- 上の例のダウンロードの矢印のように、文中で語の代わりになるアイコンは、その語そのものです。`role="img"`を指定し、見た目ではなく表している内容を`aria-label`で示します。
