## In text \{#in-text\}

Outside a component an icon is `1em`, set slightly below the baseline so it sits with lowercase text.

## Stroke \{#stroke\}

Stroke icons drawn on a 24px grid use a 1.5 stroke: about 1px at 16px. `--icon-stroke` adjusts it for a set; fill icons are unaffected.

<ComponentPreview name="stroke" height={96} title="Stroke" html={`<svg class="icon fg-text-strong" style="--icon-size: 1.5rem" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="12" r="8"/><path d="M12 8v4l2.5 2.5"/></svg>
<svg class="icon fg-text-strong" style="--icon-size: 1.5rem; --icon-stroke: 1.25" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="12" r="8"/><path d="M12 8v4l2.5 2.5"/></svg>
<svg class="icon fg-text-strong" style="--icon-size: 1.5rem; --icon-stroke: 2" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="12" r="8"/><path d="M12 8v4l2.5 2.5"/></svg>`} />

If artwork supplies its own stroke width, put `icon` on a holder and keep the stroke width on the SVG. The holder takes the component’s size while the SVG uses its own drawing. The example keeps a 16px optical drawing at its 16px viewBox and 1.25 stroke.

```html
<span class="icon" style="--icon-size: 16px" aria-hidden="true">
  <svg width="16" height="16" viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linecap="round">
    <path d="M8 3.5v9M3.5 8h9" />
  </svg>
</span>
```

## Accessibility \{#accessibility\}

- Hide a decorative icon with `aria-hidden="true"`.
- An icon-only control carries the name itself, such as `aria-label` on a [square button](/components/button#with-icons).
- An icon that stands for a word in a sentence, as the download arrow does above, is that word: give it `role="img"` and an `aria-label` that names what it stands for, not what it looks like.
