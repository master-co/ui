## In text \{#in-text\}

Outside a component an icon is `1em`, set slightly below the baseline so it sits with lowercase text.

<ComponentPreview name="text" title="In text" background="plain" html={`<p class="m(0) text-sm fg-text-body">

## Stroke \{#stroke\}

Stroke icons drawn on a 24px grid use a 1.5 stroke: about 1px at 16px. `--icon-stroke` adjusts it for a set; fill icons are unaffected.

## Accessibility \{#accessibility\}

- Hide a decorative icon with `aria-hidden="true"`.
- An icon-only control carries the name itself, such as `aria-label` on a [square button](/components/button#with-icons).
