## Before a paragraph \{#before-a-paragraph\}

An icon that leads a paragraph belongs to its first line. Centered on the whole paragraph, it drifts down as the text wraps and ends up beside no line at all. Stand it in a box one line tall, `block-size: 1lh`, and center it there: it keeps the middle of the first line at one line or four, and at any text size.

## Master Icons \{#master-icons\}

The icons in Master UI's own components and examples are [Master Icons](https://icons.master.co). Each one is drawn three times, for 16, 20 and 24px, in `currentColor`. `icon` takes any SVG, image or icon component, so another set works the same way: Master Icons is the default, not a requirement.

```bash
npm install @master/icons-react --save-exact
```

Install the package for your framework: `@master/icons-react`, `-vue`, `-svelte`, `-preact` or `-astro`, or `@master/icons` for SVG files and plain JavaScript.

Pick the drawing by the size the component gives the icon, import that one drawing and put `icon` on it:

| Size the component sets | Drawing | Its stroke |
| --- | --- | --- |
| Up to 17px | 16 | 1 |
| 18 to 22px | 20 | 1.25 |
| Above 22px | 24 | 1.5 |

```tsx
import SearchIcon from '@master/icons-react/native/16/soft/search'

<button type="button" className="btn btn-square" aria-label="Search">
  <SearchIcon className="icon" />
</button>
```

In HTML, copy the SVG from the [collection](https://icons.master.co/icons) and put `icon` on it. Look a name up before writing it, since names differ from other sets:

```bash
node node_modules/@master/icons/skills/master-icons/scripts/search.mjs "arrow left"
```

## Stroke \{#stroke\}

An icon keeps the stroke its drawing carries. Master Icons draws every size at a sixteenth of its grid, so an icon is 1px at 16px and grows with the size its component sets. To change the weight of a Master Icon, choose a `strokeWidth` on a fixed entry such as `@master/icons-react/16/soft`: its cutouts and gaps are redrawn for that width.

`--icon-stroke` replaces the width a drawing carries, in the units of its viewBox; fill icons are unaffected. Use it to bring a set of plain line icons to the interface's weight. Set on a container, every icon inside follows.

## Accessibility \{#accessibility\}

- Hide a decorative icon with `aria-hidden="true"`.
- An icon-only control carries the name itself, such as `aria-label` on a [square button](/components/button#with-icons).
- An icon that stands for a word in a sentence, as the download arrow does above, is that word: give it `role="img"` and an `aria-label` that names what it stands for, not what it looks like.
