## Master Icons \{#master-icons\}

Master UI 自己的元件與範例使用 [Master Icons](https://icons.master.co)。每個圖示都為 16、20、24px 各畫一次，並以 `currentColor` 繪製。`icon` 接受任何 SVG、圖片或圖示元件，所以其他圖示集的用法相同：Master Icons 是預設，不是必要條件。

```bash
npm install @master/icons-react --save-exact
```

請安裝對應框架的套件：`@master/icons-react`、`-vue`、`-svelte`、`-preact` 或 `-astro`；只需要 SVG 檔案與純 JavaScript 時安裝 `@master/icons`。

依元件給圖示的尺寸選擇圖稿，只匯入那一張圖稿，並加上 `icon`：

| 元件設定的尺寸 | 圖稿 | 圖稿線寬 |
| --- | --- | --- |
| 17px 以下 | 16 | 1 |
| 18 到 22px | 20 | 1.25 |
| 超過 22px | 24 | 1.5 |

```tsx
import SearchIcon from '@master/icons-react/native/16/soft/search'

<button type="button" className="btn btn-square" aria-label="Search">
  <SearchIcon className="icon" />
</button>
```

在 HTML 中，從[圖示集](https://icons.master.co/icons)複製 SVG 並加上 `icon`。名稱與其他圖示集不同，寫之前請先查詢：

```bash
node node_modules/@master/icons/skills/master-icons/scripts/search.mjs "arrow left"
```

## 描邊 \{#stroke\}

圖示會保留圖稿自己的線寬。Master Icons 每個尺寸的線寬都是網格的十六分之一，所以圖示的線寬在 16px 時是 1px，並隨元件設定的尺寸等比增加。要改變 Master Icons 的粗細，請在固定入口（例如 `@master/icons-react/16/soft`）選擇 `strokeWidth`：鏤空與間隙會依該線寬重新繪製。

`--icon-stroke` 會取代圖稿的線寬，以圖稿 viewBox 的單位計算；填色圖示不受影響。可用它把一組單純的線條圖示調整到介面的粗細。設定在容器上時，裡面的圖示都會跟著改變。

## 無障礙 \{#accessibility\}

- 使用 `aria-hidden="true"` 隱藏裝飾性圖示。
- 只有圖示的控制項應在本身設定無障礙名稱，例如將 `aria-label` 加在[方形按鈕](/components/button#with-icons)上。
- 在句子中代替一個詞的圖示，例如上方的下載箭頭，就是那個詞：請為它加上 `role="img"`，並以 `aria-label` 說明它代表什麼，而不是它長什麼樣子。
