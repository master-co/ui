## 段落前的图标 \{#before-a-paragraph\}

放在段落开头的图标属于段落的第一行。如果相对整个段落居中，文字一换行它就往下移，最后不对着任何一行。把它放进一个一行高的盒子里，即 `block-size: 1lh`，并在其中居中：无论段落是一行还是四行，无论字号多大，它都保持在第一行的正中。

## Master Icons \{#master-icons\}

Master UI 自己的组件和示例使用 [Master Icons](https://icons.master.co)。每个图标都为 16、20、24px 各绘制一次，颜色使用 `currentColor`。`icon` 接受任何 SVG、图片或图标组件，因此其他图标集的用法相同：Master Icons 是默认选择，而不是必要条件。

```bash
npm install @master/icons-react --save-exact
```

请安装对应框架的包：`@master/icons-react`、`-vue`、`-svelte`、`-preact` 或 `-astro`；只需要 SVG 文件和纯 JavaScript 时安装 `@master/icons`。

按组件给图标的尺寸选择图稿，只导入那一张图稿，并加上 `icon`：

| 组件设置的尺寸 | 图稿 | 图稿线宽 |
| --- | --- | --- |
| 17px 及以下 | 16 | 1 |
| 18 到 22px | 20 | 1.25 |
| 超过 22px | 24 | 1.5 |

```tsx
import SearchIcon from '@master/icons-react/native/16/soft/search'

<button type="button" className="btn btn-square" aria-label="Search">
  <SearchIcon className="icon" />
</button>
```

在 HTML 中，从[图标集](https://icons.master.co/icons)复制 SVG 并加上 `icon`。名称与其他图标集不同，书写前请先查询：

```bash
node node_modules/@master/icons/skills/master-icons/scripts/search.mjs "arrow left"
```

## 描边 \{#stroke\}

图标会保留图稿自身的线宽。Master Icons 每个尺寸的线宽都是网格的十六分之一，因此图标的线宽在 16px 时为 1px，并随组件设置的尺寸等比增加。要改变 Master Icons 的粗细，请在固定入口（例如 `@master/icons-react/16/soft`）选择 `strokeWidth`：镂空和间隙会按该线宽重新绘制。

`--icon-stroke` 会替换图稿的线宽，以图稿 viewBox 的单位计算；填充图标不受影响。可用它把一组单纯的线条图标调整到界面的粗细。设置在容器上时，里面的图标都会随之改变。

## 无障碍 \{#accessibility\}

- 用 `aria-hidden="true"` 将装饰性图标从无障碍树中隐藏。
- 仅含图标的控件应在自身上设置无障碍名称，例如在[方形按钮](/components/button#with-icons)上设置 `aria-label`。
- 在句子中代替一个词的图标（例如上面的下载箭头）就是那个词：为它设置 `role="img"`，并用 `aria-label` 说明它代表什么，而不是它的外观。
