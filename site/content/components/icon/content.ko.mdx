## 문단 앞의 아이콘 \{#before-a-paragraph\}

문단 앞에 놓인 아이콘은 문단의 첫 줄에 속합니다. 문단 전체의 세로 중앙에 맞추면 텍스트가 여러 줄로 이어질수록 아이콘이 아래로 내려가 결국 어느 줄 옆에도 놓이지 않게 됩니다. 아이콘을 한 줄 높이의 상자(`block-size: 1lh`)에 넣고 그 안에서 가운데에 맞추세요. 문단이 한 줄이든 네 줄이든, 글자 크기가 얼마든 아이콘은 첫 줄의 가운데를 유지합니다.

## Master Icons \{#master-icons\}

Master UI 자체의 컴포넌트와 예제는 [Master Icons](https://icons.master.co)를 사용합니다. 각 아이콘은 16, 20, 24px용으로 세 번 그려지며 색은 `currentColor`를 사용합니다. `icon`은 모든 SVG, 이미지, 아이콘 컴포넌트를 받으므로 다른 세트도 같은 방식으로 쓸 수 있습니다. Master Icons는 기본값이지 필수 조건이 아닙니다.

```bash
npm install @master/icons-react --save-exact
```

프레임워크에 맞는 패키지를 설치하세요. `@master/icons-react`, `-vue`, `-svelte`, `-preact`, `-astro` 중 하나이며, SVG 파일과 순수 JavaScript만 필요하면 `@master/icons`입니다.

컴포넌트가 아이콘에 주는 크기에 따라 그림을 고르고, 그 그림 하나만 가져와 `icon`을 적용합니다.

| 컴포넌트가 정한 크기 | 그림 | 그림의 선 두께 |
| --- | --- | --- |
| 17px 이하 | 16 | 1 |
| 18~22px | 20 | 1.25 |
| 22px 초과 | 24 | 1.5 |

```tsx
import SearchIcon from '@master/icons-react/native/16/soft/search'

<button type="button" className="btn btn-square" aria-label="Search">
  <SearchIcon className="icon" />
</button>
```

HTML에서는 [컬렉션](https://icons.master.co/icons)에서 SVG를 복사해 `icon`을 적용합니다. 이름이 다른 세트와 다르므로 쓰기 전에 검색하세요.

```bash
node node_modules/@master/icons/skills/master-icons/scripts/search.mjs "arrow left"
```

## 선 두께 \{#stroke\}

아이콘은 그림이 가진 선 두께를 유지합니다. Master Icons는 모든 크기를 격자의 16분의 1 두께로 그리므로, 아이콘의 선은 16px에서 1px이며 컴포넌트가 정한 크기에 비례해 굵어집니다. Master Icons의 굵기를 바꾸려면 `@master/icons-react/16/soft` 같은 고정 엔트리에서 `strokeWidth`를 고르세요. 뚫린 부분과 간격이 그 두께에 맞게 다시 그려집니다.

`--icon-stroke`는 그림의 선 두께를 그림의 viewBox 단위로 대체합니다. 채움형 아이콘에는 영향을 주지 않습니다. 단순한 선 아이콘 세트를 인터페이스의 굵기에 맞출 때 사용하세요. 컨테이너에 설정하면 안의 모든 아이콘이 따릅니다.

## 접근성 \{#accessibility\}

- 장식용 아이콘은 `aria-hidden="true"`로 보조 기술에서 숨기세요.
- 아이콘만 있는 컨트롤에는 접근 가능한 이름을 컨트롤 자체에 지정합니다. 예를 들어 [정사각형 버튼](/components/button#with-icons)에 `aria-label`을 지정합니다.
- 위의 다운로드 화살표처럼 문장 속에서 단어를 대신하는 아이콘은 그 단어 자체입니다. `role="img"`를 지정하고, 생김새가 아니라 무엇을 나타내는지를 `aria-label`로 알려 주세요.
