Use `.kbd` on a `<kbd>` element for keys in running text, menus and hints. The default keycap is drawn with one contour so it stays quiet inside a line.

<ComponentPreview name="default" height={96} title="Kbd" background="plain" html={`<p class="flex items-center gap-2xs m(0) text-sm fg-text-body">
  Search with <kbd class="kbd">⌘</kbd><kbd class="kbd">K</kbd>
</p>`} />

## Raised \{#raised\}

`kbd-raised` catches the light like a physical key. Use it when the shortcut itself is the lesson.

<ComponentPreview name="raised" height={96} title="Raised" background="plain" html={`<kbd class="kbd kbd-raised">⇧</kbd>
<kbd class="kbd kbd-raised">⌘</kbd>
<kbd class="kbd kbd-raised">P</kbd>`} />
