이전·다음 페이지 탐색은 글 하단에 링크 두 개를 나란히 배치합니다. 각 링크는 평평한 표면으로 표시되며, 이동할 페이지 제목 위에는 제목보다 눈에 덜 띄는 방향 레이블이 놓입니다. 링크는 `rel="prev"`와 `rel="next"`로 이전과 다음을 구분하고, 스타일시트가 이 값을 읽으므로 방향별 클래스는 필요하지 않습니다.

## 속성 하나로 정하는 링크 위치 \{#rel\}

`rel`은 링크와 현재 페이지의 관계를 나타내는 HTML 속성이며, `prev`와 `next`는 이 속성에 사용할 수 있는 값입니다. 이전·다음 페이지 탐색의 각 링크에 해당 값을 지정하면 페이지 순서를 마크업으로 올바르게 표현할 수 있습니다. 스타일시트는 이 값을 읽어 다음 세 가지를 처리합니다.

- 다음 페이지 링크는 행 끝에 배치되고, 링크의 텍스트도 끝에 맞춰 정렬됩니다.
- 다음 페이지 링크의 화살표는 레이블 뒤에서 진행 방향을 가리키고, 이전 페이지 링크의 화살표는 레이블 앞에서 반대 방향을 가리킵니다. 오른쪽에서 왼쪽으로 읽는 페이지에서는 두 화살표의 방향이 뒤집힙니다.
- 다음 페이지 링크만 있는 경우에도 사용자가 눈으로 찾거나 엄지로 누르기 쉬운 행 끝에 배치됩니다.

이동할 페이지가 없으면 해당 링크를 생략하세요. 가이드의 첫 페이지에는 다음 링크만, 마지막 페이지에는 이전 링크만 표시합니다.

## 표면과 움직임 \{#material\}

링크는 하나의 윤곽선으로 둘러싼 평평한 표면이며, 모서리에는 큰 컨트롤과 같은 둥글기를 적용합니다. 포인터를 올리면 표면이 한 단계 올라오고 화살표는 자신이 가리키는 방향으로 2px 이동합니다. 누르면 표면이 오목한 영역으로 들어갑니다. 동작 줄이기가 설정되어 있으면 화살표는 제자리에 머뭅니다.

이전·다음 페이지 탐색은 크기 컨테이너입니다. 컨테이너 자체의 너비가 26rem 미만이면 두 링크가 각각 컨테이너 전체 너비를 차지하며, 이전 페이지 링크가 위에 오도록 세로로 쌓입니다.

## 이전·다음 페이지 탐색과 페이지 매김 \{#pager-or-pagination\}

이전·다음 페이지 탐색은 순서대로 읽는 페이지 사이를 이동할 수 있게 하며 각 페이지의 제목을 표시합니다. [페이지 매김](/components/pagination)은 긴 목록 하나를 번호가 매겨진 여러 페이지로 나누고 그 사이를 이동할 수 있게 합니다. 사이트에서 현재 페이지가 어디에 있는지는 [탐색 경로](/components/breadcrumb)로 표시합니다.

## 접근성 \{#accessibility\}

- 페이지의 다른 탐색 영역과 구별할 수 있도록 링크를 `aria-label`이 지정된 `<nav>`에 넣으세요.
- 링크의 접근성 이름은 레이블과 제목을 합친 형태입니다. 예를 들어 "다음, 테마 설정"과 같이 읽힙니다. 제목만으로는 어느 방향으로 이동하는지 알 수 없으므로 레이블을 유지하세요.
- 화살표는 스타일시트로 그리며 스크린 리더에서 읽히지 않습니다.
