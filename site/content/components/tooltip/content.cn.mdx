工具提示是在墨色表面上显示的简短标签，用于标明控件的名称或快捷键。它属于提示型弹出层。在标签上设置 `popover="hint"` 和 `.tooltip`，在控件上设置 `interestfor`。鼠标悬停或通过键盘聚焦时，浏览器会短暂延迟后显示工具提示。在触摸屏上，长按即可显示。按 <kbd>Esc</kbd> 可隐藏工具提示，已打开的菜单会保持打开。CSS 锚点定位将工具提示水平居中放在控件上方。

## 位置 \{#placement\}

工具提示位于控件上方 6px 处，上方空间不足时会翻转到下方。对于顶部栏中的控件，可以用 `tooltip-bottom` 优先将工具提示放在下方。

<div id="tip-deploy" popover="hint" class="tooltip tooltip-bottom">Ships the main branch to production</div>`} />

## 内容 \{#content\}

工具提示用几个词即可。文本在 16rem 的宽度限制下自动换行，并尽量让各行长度均衡。工具提示会调整按键标记使用的令牌，因此其中的 [`kbd`](/components/kbd) 无需指定变体，就能在墨色表面上清晰显示。链接、表单等需要读者操作的内容应放在[弹出层](/components/popover)中。

## 无障碍 \{#accessibility\}

- 控件需要有自己的名称，工具提示用于补充说明。纯图标按钮应保留 `aria-label`，因为在触摸屏上只有长按才会显示工具提示。
- 浏览器会将工具提示与对应控件关联起来，辅助技术会将其作为控件的描述读出。
- Chrome 和 Edge 已支持通过 interestfor 触发提示。缺少这项支持时，浏览器会保留控件的无障碍名称，工具提示则不会显示。要在这些浏览器中也显示工具提示，请在指针和焦点事件处理函数中调用 `showPopover()` 和 `hidePopover()`，并沿用同一份样式表。

## React、Svelte 和 Vue \{#frameworks\}

`tooltip` 组件通过 id 将控件与工具提示关联起来。控件由页面自身的标记定义，工具提示由浏览器显示。使用 `npx master-ui add tooltip` 将组件复制到项目中。组件的实现和用法见 [React、Svelte 和 Vue](/guide/frameworks)。
