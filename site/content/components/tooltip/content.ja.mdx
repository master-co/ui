ツールチップは、コントロールの名前やショートカットを示す短いラベルで、背景に前景色を使います。ヒント用のポップオーバーとして、ラベルに `popover="hint"` と `.tooltip` を、コントロールに `interestfor` を指定します。ブラウザーは、ホバー時とキーボードフォーカス時には短い遅延の後、タッチスクリーンでは長押しで表示します。<kbd>Esc</kbd> で非表示になりますが、ツールチップの表示や非表示によって、すでに開いているメニューが閉じることはありません。CSS アンカー位置指定により、コントロールの上方中央に配置されます。

## 配置 \{#placement\}

ツールチップはコントロールの 6px 上に表示され、上に空きがなければ下に切り替わります。上部バーのコントロールなどでは、`tooltip-bottom` で下側を優先できます。

## 内容 \{#content\}

ツールチップの文言は数語に収めます。テキストは幅 16rem で折り返し、各行の長さのバランスが取れるように調整されます。中に置いた[`kbd`](/components/kbd)は、ツールチップがキーキャップ用のトークンを調整するため、バリアントを指定しなくても前景色の背景上で読み取れます。リンクやフォームなど、ユーザーが操作する内容には[ポップオーバー](/components/popover)を使います。

## アクセシビリティ \{#accessibility\}

- ツールチップはコントロールの名前を補足するもので、名前の代わりにはなりません。タッチスクリーンでは長押ししたときだけ表示されるため、アイコンだけのボタンには `aria-label` を指定して名前を付けます。
- ブラウザーがツールチップをコントロールに関連付けるため、支援技術はツールチップの内容をコントロールの説明として読み上げます。
- Chrome と Edge は Interest Invoker に対応しています。未対応のブラウザーではツールチップは表示されず、コントロールのアクセシブルネームは維持されます。未対応のブラウザーでも表示するには、ポインターとフォーカスのイベントハンドラーから `showPopover()` と `hidePopover()` を呼び出します。同じスタイルシートを使えます。

## React、Svelte、Vue \{#frameworks\}

`tooltip` コンポーネントは、コントロールとツールチップを ID で関連付けます。コントロールにはページ側のマークアップをそのまま使い、ブラウザーがツールチップを表示します。`npx master-ui add tooltip` でプロジェクトにコピーできます。コンポーネントの仕組みと使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
