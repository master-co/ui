工具提示是簡短的深色標籤，用來顯示控制項的名稱或快速鍵。它使用提示型彈出層。請在標籤上設定 `popover="hint"` 和 `.tooltip`，並在控制項上設定 `interestfor`。指標停留或控制項取得鍵盤焦點後，瀏覽器會稍作延遲再顯示提示，在觸控螢幕上則可長按顯示。按 <kbd>Esc</kbd> 可隱藏提示，已開啟的選單會保持開啟。CSS 錨點定位會將提示置中在控制項上方。

## 位置 \{#placement\}

工具提示位於控制項上方，間隔 6px。上方空間不足時，會改到下方。頂部工具列的控制項可用 `tooltip-bottom` 優先將提示放在下方。

## 內容 \{#content\}

工具提示用幾個字就好。文字到 16rem 寬時會換行，並平衡各行的長度。工具提示會調整按鍵標示使用的 token，因此內部的 [`kbd`](/components/kbd) 可直接在深色表面上清楚呈現，無須指定變體。連結、表單等需要使用者操作的內容，請用[彈出層](/components/popover)呈現。

## 無障礙 \{#accessibility\}

- 工具提示用來補充控制項的名稱。只有圖示的按鈕仍須保留 `aria-label`，因為觸控螢幕上只有長按才會顯示提示。
- 瀏覽器會將工具提示與控制項關聯起來，讓輔助技術將提示朗讀為控制項的說明。
- Chrome 和 Edge 支援 interestfor 觸發機制。瀏覽器缺少這項支援時，工具提示不會顯示，但控制項仍保有無障礙名稱。若也要在這些瀏覽器顯示提示，可在指標與焦點事件的處理函式中呼叫 `showPopover()` 和 `hidePopover()`，並沿用同一份樣式表。

## React、Svelte 和 Vue \{#frameworks\}

`tooltip` 元件透過 ID 將控制項與工具提示關聯起來。控制項沿用頁面本身的標記，工具提示由瀏覽器顯示。使用 `npx master-ui add tooltip` 將元件複製到專案中，並參閱 [React、Svelte 和 Vue](/guide/frameworks) 瞭解元件的建構方式和用法。
