선택 옵션은 요금제, 결제 수단, 아래에 한 문장 설명이 붙는 설정처럼 선택지에 관한 설명을 담을 만큼 넉넉한 컴포넌트입니다. 네이티브 [라디오 버튼](/components/radio)이나 [체크박스](/components/checkbox)를 감싸는 `<label>`이므로 표면 전체가 조작 영역이 되고, 입력 요소는 상태와 키보드 동작을 관리합니다. 기본 상태에서는 윤곽선 하나를 두른 평평한 표면으로 표시됩니다. 선택하면 표면이 한 단계 올라오고 윤곽선은 잉크 색으로 바뀝니다.

## 입력 상태 반영 \{#how-it-reads-its-state\}

선택 옵션은 자체 상태 없이 `:has()`를 사용해 내부 입력 요소의 상태를 확인합니다. `:has(:checked)`는 표면을 한 단계 올리고, `:has(:focus-visible)`은 작은 입력 요소 대신 선택지 전체에 포커스 윤곽선을 그리며, `:has(:disabled)`는 표면을 오목한 영역으로 바꿉니다. 스크립트로 상태를 전환하지 않으므로 표시 상태와 폼 상태가 어긋날 일이 없습니다.

## 접근성 \{#accessibility\}

- 선택 옵션은 legend 요소가 있는 [`fieldset`](/components/input#fieldset)으로 묶고, 라디오 버튼에는 같은 `name` 값을 지정하세요.
- 제목과 설명이 모두 레이블에 포함되므로 스크린 리더는 둘 다 선택지의 이름으로 읽습니다. 설명은 한 문장으로 쓰세요.
- 선택 상태는 잉크 색과 표면의 높이, 입력 요소 자체의 선택 표시로 나타내며 색상 차이에는 의존하지 않습니다.
