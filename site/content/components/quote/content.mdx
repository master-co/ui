A quote sets someone else's words apart from yours. In running text it hangs from a soft rail at its start, in the ink of a heading. The rail is drawn with round ends, not a border, so it never ends in a corner.

  <footer class="quote-source">

</blockquote>`} />

Put each paragraph of the quotation in a `quote-text`. The source is a `<footer>` with `quote-source`: an [avatar](/components/avatar) if there is one, a `quote-name` in ink, and a quiet line for a role or a place. Put the title of a work in `<cite>`.

## Pull quote \{#pull-quote\}

`quote-lg` is a pull quote: the words carry it. The rail gives way to an opening mark, and the lines are balanced. Use one on a page, and keep it to a sentence or two.

## Accessibility \{#accessibility\}

- Use `<blockquote>` for a quotation set apart and `<q>` for one inside a sentence. A `cite` attribute can carry the source's URL.
- The opening mark of a pull quote is decoration drawn by the stylesheet; it is not read. Do not type quotation marks into a pull quote as well.
- The source's avatar repeats the name beside it, so its `alt` is empty.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `quote` | The `<blockquote>`, on a rail |
| `quote-lg` | A pull quote under an opening mark |
| `quote-text` | A paragraph of the quotation |
| `quote-source` | Who said it: an avatar beside a name and a line |
| `quote-name` | The name, in ink on its own line |
