[自動グリッド](/components/auto-grid)と同様に、利用可能な幅から列数を決めます。各列の最小幅は`--masonry-min`で、クエリーは不要です。ブラウザーがグリッドレーンに対応していればグリッドで詰めて配置し、対応していなければ段組みで配置します。違いはタイルを読む順序で、[下記](#fallback)で説明します。

## レイアウトの仕組み \{#how-it-is-built\}

- **利用可能な幅から列数を決定。** `masonry`は、幅が`--masonry-min`以上の等幅列を、収まるだけ作ります。各列はコンテナーの幅を超えないため、スマートフォンでもはみ出しません。ギャラリーでは`--masonry-min`を10remに設定し、スマートフォンでも2列を保ちます。
- **ブラウザーによる配置。** `display: grid-lanes`に対応している場合、各列はグリッドの列になり、ブラウザーが各タイルを下端の最も高い列に置きます。フォールバックでは段組みを使い、1列ずつ埋めながら列の高さを均等にします。
- **タイルの分割防止。** `masonry-item`はタイルが2つの列に分割されるのを防ぎ、タイル上部の間隔も確保します。フォールバックではどちらにもタイルのクラスが必要なため、すべてのタイルに指定します。
- **元の縦横比を維持。** 各画像を[図版](/components/figure)にし、元の縦横比を`--figure-ratio`に設定します。読み込み前から列内に必要なスペースが確保されるため、画像が表示されてもレイアウトはずれません。

## 列 \{#lanes\}

`--masonry-min`は列の最小幅で、既定は14remです。最小幅を小さくすると、細い列を多く並べられます。画像なら9remまたは10remでスマートフォンでも2列を保てます。段落を含むカードには16rem以上を使います。`--masonry-gap`は列間と列内のタイル間の間隔で、1remです。

タイルは画像に限りません。メモ、引用、長めのキャプションが付いた図版など、内容に合わせて高さが決まる要素なら、同じレイアウトに混在させられます。

## グリッドレーンとフォールバック \{#fallback\}

メイソンリーは共通のマークアップで記述でき、ブラウザーの対応状況に応じてレイアウトが切り替わります。

| | グリッドレーン対応時 | フォールバック時 |
| --- | --- | --- |
| 列の構成 | `display: grid-lanes`の列 | `columns: var(--masonry-min)`による段組みの列 |
| タイルの配置先 | マークアップ順に、下端が最も高い列へ | 先頭の列を上から埋め、いっぱいになったら次の列へ |
| 見た目の順序 | 列を横にたどる順序。先頭のタイルが最上段に並ぶ | 各列を上から下へたどる順序。先頭のタイルが最初の列に並ぶ |
| タイル間の間隔 | グリッドのギャップ | マージン。列の先頭では省略 |

グリッドレーンは新しい機能で、対応状況はブラウザーエンジンによって異なります。使用しているレイアウトは[ブラウザー対応](/guide/browser-support#layout)に一覧があります。フォールバックでも、すべてのタイルが分割されずに元の形のまま詰めて配置されます。違いは並び順だけです。下の番号をたどると、お使いのブラウザーでどちらのレイアウトが使われているか確認できます。

ギャラリーやメモのボード、引用の一覧など、どの順序で読んでもよい場合にメイソンリーを選びます。新着順のフィードなど、順序が重要な場合は、各行を常に横にたどれる[自動グリッド](/components/auto-grid)を使います。

## 使い分け \{#when\}

| タイルの特徴 | 適したレイアウト |
| --- | --- |
| 内容に応じた高さで、読む順序は任意 | メイソンリー |
| サイズが同じ、または行を揃えて配置 | [自動グリッド](/components/auto-grid) |
| 数種類のサイズを固定配置し、重要度に差を付ける | [ベントーレイアウト](/components/bento) |
| 1行に並べてスクロール | [カルーセル](/components/carousel) |

## アクセシビリティ \{#accessibility\}

- どちらのレイアウトでも、読み取り順序とキーボードでの移動順序はマークアップ順です。見た目では、グリッドレーンは列を横に、フォールバックは各列を上から下へたどると、その順序になります。どちらのレイアウトでもタイルの順序は保たれます。
- 同種の項目を並べる場合は、項目数が読み上げられるよう、リスト`<ul class="masonry">`を使います。各タイルをリスト項目にします。
- 情報を伝える画像には、キャプションがあっても`alt`テキストが必要です。キャプションは画像を補足するものです。
