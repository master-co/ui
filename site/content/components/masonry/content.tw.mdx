瀑布流會將高低不一的區塊緊密排入等寬的欄。每個區塊都放進底端目前最高的欄，因此較矮的圖片旁即使有較高的圖片，也不會留下一整排空白，每張圖片也能維持原始比例。瀑布流只負責版面配置，區塊本身可用[圖文](/components/figure)、[卡片](/components/card)或[面板](/components/surface)呈現。

瀑布流和[自動網格](/components/auto-grid)一樣，會依可用空間決定欄數，每欄至少為 `--masonry-min`，無須查詢。瀏覽器支援 grid lanes 時，由格線安排區塊的位置，否則由多欄容器排列。兩者的差異在於區塊的閱讀順序，詳見[下方說明](#fallback)。

## 實作方式 \{#how-it-is-built\}

- **依空間決定欄數。** `masonry` 會排入盡可能多的等寬欄，每欄至少為 `--masonry-min`，且不會寬於容器本身，因此在手機上也不會溢出。圖庫將 `--masonry-min` 設為 10rem，讓手機上也能維持兩欄。
- **由瀏覽器排列。** 支援 `display: grid-lanes` 時，每欄都是格線的一欄，瀏覽器會將每個區塊放入底端目前最高的欄。其他情況下則使用多欄容器，依序填滿各欄，並平衡欄高。
- **保持區塊完整。** `masonry-item` 防止區塊被拆到兩欄，並保留其上方的間距。備援版面需要在區塊上加這個類別才能做到這兩點，因此每個區塊都要加上。
- **保留區塊原有的比例。** 每張圖片都使用[圖文元件](/components/figure)，並將 `--figure-ratio` 設為圖片的比例。這樣在圖片載入前就能預留空間，載入後版面也不會位移。

## 欄寬與間距 \{#lanes\}

`--masonry-min` 設定最小欄寬，預設為 14rem。最小值越小，欄數就越多，每欄也越窄。圖片可設為 9 或 10rem，讓手機上維持兩欄。含段落的卡片可設為 16rem 以上。`--masonry-gap` 設定欄與欄之間及同欄區塊之間的距離，預設為 1rem。

只要高度由內容決定，就能放進瀑布流，例如便條、引文，或帶有較長圖說的圖文。

## Grid lanes 與備援版面 \{#fallback\}

瀑布流只需寫一份標記，瀏覽器會依支援情況決定版面配置。

| | 支援 grid lanes | 使用備援版面 |
| --- | --- | --- |
| 欄的來源 | `display: grid-lanes` 的格線欄 | 多欄容器的欄，`columns: var(--masonry-min)` |
| 區塊放置位置 | 依標記順序放入底端目前最高的欄 | 由上往下填滿第一欄，再填下一欄 |
| 視覺順序 | 橫向跨欄，最前面的區塊構成第一列 | 沿各欄由上往下，最前面的區塊構成第一欄 |
| 區塊間距 | 格線的間距 | 使用外距，欄頂的外距會裁掉 |

Grid lanes 是較新的功能，目前部分瀏覽器引擎尚未支援。[瀏覽器支援](/guide/browser-support#layout)列出了使用這項功能的版面配置。備援版面只會改變視覺上的閱讀順序，每個區塊仍會緊密排列、完整保留原有比例。順著下方的編號看，就能知道瀏覽器採用哪一種排列方式。

內容可按任意順序閱讀時，例如圖庫、便條看板或引文牆，可使用瀑布流。如果順序很重要，例如需要把最新內容放在最前面的動態消息，請使用[自動網格](/components/auto-grid)，讓每一列都依橫向順序閱讀。

## 何時使用 \{#when\}

| 區塊特性 | 適用元件 |
| --- | --- |
| 高度由內容決定，可按任意順序閱讀 | 瀑布流 |
| 尺寸相同，或需要在各列對齊 | [自動網格](/components/auto-grid) |
| 有幾種尺寸，位置固定，部分區塊需要更突出 | [Bento 版面](/components/bento) |
| 排成一列，以捲動瀏覽 | [輪播](/components/carousel) |

## 無障礙 \{#accessibility\}

- 兩種版面都以標記順序作為閱讀順序和鍵盤導覽順序。使用 grid lanes 時，視覺順序會橫向跨欄。使用備援版面時，則會沿各欄由上往下。兩種方式都保留區塊在標記中的先後順序。
- 同類型的內容請用清單 `<ul class="masonry">`，並將每個區塊做成清單項目，讓螢幕閱讀器能讀出項目數量。
- 傳達資訊的圖片即使已有圖說，仍需要 `alt` 文字。圖說用來補充圖片資訊，無法取代替代文字。
