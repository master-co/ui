浮動通知是在頁面上方短暫顯示的訊息，用來告知使用者剛發生的事，例如已儲存、已部署或已複製。每則通知都是固定定位的 `toast-region` 內的非模態 `<dialog>`，可透過對話框的原生機制關閉，無須腳本，進出場動畫則由 CSS 樣式表處理。

## 顯示與關閉 \{#showing-and-dismissing\}

- 帶有 `open` 屬性的通知會在頁面載入時顯示，適合在表單以 POST 送出後，由伺服器直接算繪訊息。
- 在腳本中，對通知區域內的通知呼叫 `toast.show()`，或在區域內附加新的 `<dialog open class="toast">`。兩種做法都會透過 `@starting-style` 設定通知進場時的起始樣式。
- 將按鈕放在 `<form method="dialog">` 裡，或在按鈕上設定 `commandfor` 和 `command="close"`，都能關閉通知。`display` 透過 `allow-discrete` 進行轉場，讓退場動畫播完後，通知才停止占用空間。

## 限時 \{#timed\}

`toast-timed` 會讓通知在六秒後自動消失。計時由 CSS 動畫控制，動畫結束時套用 `display: none`。指標停在通知上或鍵盤焦點位於通知內時，計時會暫停，讓使用者有足夠時間閱讀。通知底部的細線會隨剩餘時間縮短，並與計時同步暫停。用 `--toast-duration` 調整顯示時間。請勿在限時通知中放入使用者可能仍需執行的操作。重要內容應放在會持續顯示的[提示訊息](/components/alert)中。

## 通知區域 \{#the-region\}

`toast-region` 固定在底部靠末端的一角，將通知堆疊起來，最新一則排在最下方。區域本身不接收指標事件，透過區域的空白處仍可操作被覆蓋的頁面。在窄螢幕上，通知區域會橫跨整個寬度。

| 類別 | 位置 |
| --- | --- |
| `toast-region` | 底部，靠末端邊緣 |
| `toast-region-top` | 頂部，通知向下進場，最新一則排在最上方 |
| `toast-region-center` | 水平置中 |

通知區域是設有 `z-index` 的一般固定定位元素。要讓通知顯示在已開啟的模態[對話框](/components/dialog)上方，請為區域設定 `popover="manual"`，再對它呼叫一次 `showPopover()`，即可將它放入頂層。

## 無障礙 \{#accessibility\}

- 用 `aria-live="polite"` 將通知區域設為即時區域，讓通知出現時能由輔助技術朗讀，並以 `aria-label` 為區域命名。
- 每則通知都應設定名稱，可用 `aria-labelledby` 指向標題，或直接設定 `aria-label`。
- 浮動通知用來確認結果。使用者即使錯過通知，也應能取得所需資訊或完成操作，因此請在通知之外保留操作入口。
- 啟用減少動態效果時，通知會在原地淡入淡出。

## React、Svelte 和 Vue \{#frameworks\}

`toast` 元件以佇列管理通知。你可以從任何地方呼叫 `toast()` 函式，只需算繪一次通知區域，即可顯示佇列中的通知。使用 `npx master-ui add toast` 將元件複製到專案中，並參閱 [React、Svelte 和 Vue](/guide/frameworks) 瞭解元件的建構方式和用法。
