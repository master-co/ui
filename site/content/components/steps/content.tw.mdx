步驟元件顯示讀者目前在結帳或設定等簡短流程中的哪一步。它以有序清單呈現，並由 CSS 計數器為標記編號。只要在目前的步驟加上 `aria-current="step"`，其餘狀態會由樣式表判定。

<ComponentPreview name="default" height={96} title="步驟" background="plain" bodyClass="p-lg" html={`<ol class="steps">
  <li class="steps-item"><span class="steps-title">Account</span></li>
  <li class="steps-item" aria-current="step"><span class="steps-title">Billing</span></li>
  <li class="steps-item"><span class="steps-title">Confirm</span></li>
</ol>`} />

## 單一屬性 \{#one-attribute\}

一個屬性就能決定三種狀態：

- **目前**的步驟帶有 `aria-current="step"`。它的標記像一張浮起的小面板，帶有墨色外框。
- 排在目前步驟之前的步驟皆為**已完成**：`.steps-item:has(~ .steps-item[aria-current="step"])`。標記是鏤空勾號的墨色圓形，勾號透出底下的表面色，在兩種主題下都清楚可見。從該步驟延伸出去的線也會變成墨色。
- 其餘步驟皆為**等待中**，編號顯示在凹槽裡。

將屬性移到下一個項目，三種狀態就會一併更新。整個流程結束時，已沒有目前步驟。在清單上加上 `steps-complete`，即可將所有步驟標為完成。

<ComponentPreview name="complete" height={96} title="全部完成" background="plain" bodyClass="p-lg" html={`<ol class="steps steps-complete">
  <li class="steps-item"><span class="steps-title">Account</span></li>
  <li class="steps-item"><span class="steps-title">Billing</span></li>
  <li class="steps-item"><span class="steps-title">Confirm</span></li>
</ol>`} />

## 垂直排列 \{#vertical\}

`steps-vertical` 將步驟由上到下排列，適合窄欄，或每個步驟都需要一句說明的情況。用 `steps-body` 包住文字，再加入 `steps-description`。

## 無障礙 \{#accessibility\}

- 使用 `<ol>`，因為步驟順序本身具有意義，而且清單會讓輔助科技報讀步驟總數。
- `aria-current="step"` 會告知輔助科技目前是哪一步。勾號和墨色只提供視覺提示，螢幕閱讀器使用者可從清單順序判斷哪些步驟已完成。
- 水平排列時，以四到五個簡短標題為限。步驟更多時，使用 `steps-vertical`。
