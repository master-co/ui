步骤条显示用户在结账、设置等简短流程中所处的位置。它采用有序列表，由 CSS 计数器为列表标记编号。只需用 `aria-current="step"` 标记当前步骤，其余状态由样式表推断。

<ComponentPreview name="default" height={96} title="步骤条" background="plain" bodyClass="p-lg" html={`<ol class="steps">
  <li class="steps-item"><span class="steps-title">Account</span></li>
  <li class="steps-item" aria-current="step"><span class="steps-title">Billing</span></li>
  <li class="steps-item"><span class="steps-title">Confirm</span></li>
</ol>`} />

## 一个属性 \{#one-attribute\}

一个属性决定三种状态：

- **当前**步骤带有 `aria-current="step"`。它的标记呈现为带墨色轮廓的小型凸起面板。
- 位于当前步骤之前的步骤为**已完成**：`.steps-item:has(~ .steps-item[aria-current="step"])`。它的标记是一个镂空出对勾的墨色圆盘，底下的表面透过镂空显出对勾，在两种主题中都清晰可见。从该标记通往下一步的线条也变为墨色。
- 其余步骤均为**待完成**，在凹槽内显示编号。

将属性移到下一项，三种状态会随之更新。整个流程结束后，没有当前步骤，此时给列表添加 `steps-complete`，所有步骤都会显示为已完成。

<ComponentPreview name="complete" height={96} title="全部完成" background="plain" bodyClass="p-lg" html={`<ol class="steps steps-complete">
  <li class="steps-item"><span class="steps-title">Account</span></li>
  <li class="steps-item"><span class="steps-title">Billing</span></li>
  <li class="steps-item"><span class="steps-title">Confirm</span></li>
</ol>`} />

## 纵向排列 \{#vertical\}

`steps-vertical` 将步骤逐项纵向排列，适合窄栏或每个步骤各有一句说明的情况。用 `steps-body` 包住文字，再添加一个 `steps-description`。

## 将步骤标题设为链接 \{#as-links\}

如果用户可以返回先前的步骤，将已完成步骤的标题设为[链接](/components/link)。待完成的步骤仍显示为纯文本。

<ComponentPreview name="links" height={96} title="步骤标题链接" background="plain" bodyClass="p-lg" html={`<nav aria-label="Checkout">

    <li class="steps-item"><a class="steps-title link link-quiet" href="#shipping">Shipping</a></li>
    <li class="steps-item" aria-current="step"><span class="steps-title">Payment</span></li>
    <li class="steps-item"><span class="steps-title">Review</span></li>
  </ol>
</nav>`} />

## 无障碍 \{#accessibility\}

- 使用 `<ol>`，因为顺序本身表达了步骤之间的关系，列表还会播报步骤总数。
- `aria-current="step"` 告知辅助技术哪个步骤是当前步骤。对勾和墨色只提供视觉提示，屏幕阅读器用户通过列表顺序判断哪些步骤已完成。
- 横向排列适合四五个标题简短的步骤。步骤更多时，使用 `steps-vertical`。
