단계 컴포넌트는 결제나 설정처럼 짧은 절차에서 사용자가 어디까지 진행했는지 보여 줍니다. 순서가 있는 목록을 사용하며, 각 단계의 표식에는 CSS 카운터로 번호를 매깁니다. 현재 단계에만 `aria-current="step"`을 지정하면 스타일시트가 나머지 단계의 상태를 결정합니다.

  <li class="steps-item" aria-current="step"><span class="steps-title">Billing</span></li>
  <li class="steps-item"><span class="steps-title">Confirm</span></li>
</ol>`} />

## 속성 하나로 표현하는 상태 \{#one-attribute\}

속성 하나로 세 가지 상태를 표현합니다.

- **현재** 단계에는 `aria-current="step"`을 지정합니다. 표식은 잉크색 윤곽선이 있는 작은 볼록한 표면으로 표시됩니다.
- 현재 단계보다 앞에 있는 단계는 **완료** 상태가 됩니다(`.steps-item:has(~ .steps-item[aria-current="step"])`). 표식은 체크 모양으로 뚫린 잉크색 원입니다. 뚫린 부분으로 아래 표면이 드러나 두 테마 모두에서 체크 표시를 알아볼 수 있고, 다음 단계로 이어지는 선은 잉크색으로 바뀝니다.
- 나머지 단계는 모두 **대기** 상태이며, 오목한 영역에 번호가 표시됩니다.

속성을 다음 항목으로 옮기면 세 상태가 모두 갱신됩니다. 절차가 끝나면 현재 단계가 없어집니다. 목록에 `steps-complete`를 추가하면 모든 단계가 완료 상태로 표시됩니다.

  <li class="steps-item"><span class="steps-title">Account</span></li>
  <li class="steps-item"><span class="steps-title">Billing</span></li>
  <li class="steps-item"><span class="steps-title">Confirm</span></li>
</ol>`} />

## 세로 배치 \{#vertical\}

`steps-vertical` 클래스는 단계를 세로로 배치합니다. 열이 좁거나 단계마다 문장 하나가 들어갈 때 사용하세요. 텍스트를 `steps-body`로 감싸고 `steps-description`를 추가하세요.

## 단계 제목 링크 \{#as-links\}

사용자가 이전 단계로 돌아갈 수 있다면 완료된 단계의 제목을 [링크](/components/link)로 만드세요. 대기 중인 단계는 일반 텍스트로 표시하세요.

## 접근성 \{#accessibility\}

- `<ol>` 요소를 사용하세요. 항목의 순서 자체에 의미가 있으며, 목록을 통해 전체 단계 수를 알 수 있습니다.
- `aria-current="step"`은 보조 기술에 어느 단계가 현재 단계인지 알려 줍니다. 체크 표시와 잉크색은 시각적으로만 전달되므로, 스크린 리더 사용자는 목록 순서로 어느 단계까지 완료되었는지 파악합니다.
- 가로 배치에서는 짧은 제목을 붙인 단계 4~5개까지만 표시하세요. 단계가 더 많다면 `steps-vertical` 클래스를 사용하세요.
