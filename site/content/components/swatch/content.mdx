A swatch is a color as a thing to look at or to pick. Set the color with `--swatch`. It is a small disc with a hairline just inside its edge and a line of light on its top, so white reads on white and black on black. As a `<label>` around a native radio it is a choice: the chosen one stands in a ring of ink, a gap away.

The gap between a chosen swatch and its ring is cut in the color of the surface it sits on. [Surfaces](/components/surface) publish that color as `--surface-color`, so the same markup is right on the page, on a sheet and in a popover.

## Sizes and shape \{#sizes-and-shape\}

A swatch is 24px; `swatch-sm` is 16px, for a row in a [list](/components/list) or a [menu](/components/menu), and `swatch-lg` 32px. `swatch-square` is a tile with a chip's corner, for a palette or a token table. Without an input a swatch is a plain mark: put it beside the color's name.

## Accessibility \{#accessibility\}

- A color has no text, so every input needs a name: `aria-label="Indigo"` on the input, or visible text beside the swatch tied with `aria-labelledby`. Name the color, not its use, unless the use is the point ("Danger").
- Group the choices in a `role="radiogroup"` or a `<fieldset>` with a label. Radios that share a `name` move with the arrow keys.
- The chosen state is a ring of ink, not a change of color, and keyboard focus draws its own outline outside that ring.
- On touch screens the target grows to 44px around the disc without moving it; leave at least 12px between swatches.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `swatch` | The disc; a `label` around a `swatch-input`, or a plain mark |
| `swatch-input` | The radio or checkbox inside a swatch |
| `swatch-sm`, `swatch-lg` | 16px and 32px; the default is 24px |
| `swatch-square` | A tile with a chip's corner |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--swatch` | `currentColor` | The color, or any background image |
| `--swatch-size` | `1.5rem` | The diameter |
