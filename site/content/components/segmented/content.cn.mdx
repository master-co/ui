分段控件在一个凹槽中容纳少量互斥选项，当前选项以凸起面板呈现。轨道的圆角半径等于选项的圆角半径加上 4px 的内缩距离，使两者的圆角保持同心。各尺寸的高度与对应尺寸的按钮完全一致。

每个选项都是一个 `segmented-item`。如果选择结果表示一个值，用标签包裹带有 `segmented-input` 的原生单选按钮，使这组选项保留方向键导航并可在表单中使用：

<ComponentPreview name="default" height={96} title="分段控件" html={`<div class="segmented" role="radiogroup" aria-label="View">
  <label class="segmented-item"><input type="radio" class="segmented-input" name="view" value="list" checked>List</label>
  <label class="segmented-item"><input type="radio" class="segmented-input" name="view" value="board">Board</label>
  <label class="segmented-item"><input type="radio" class="segmented-input" name="view" value="timeline">Timeline</label>
</div>`} />

## 滑块的滑动效果 \{#the-gliding-thumb\}

浏览器支持 CSS 锚点定位时，凸起面板由同一个滑块呈现，选项切换时会平滑移到当前选项。当前选项为自身设置锚点名称，轨道用 `anchor-scope` 将该名称限定在自身范围内，并用一个伪元素贴合锚点的各条边缘。选择变化时，伪元素的边缘位置随之过渡。整个过程无需脚本测量尺寸或位置，同一页面上的多个分段控件也互不干扰。浏览器不支持 CSS 锚点定位或启用减少动态效果时，凸起面板由当前选项自身呈现，切换立即生效。

## 用作切换按钮 \{#as-toggle-buttons\}

每个选项都会触发操作时，使用带有 `aria-pressed` 的按钮，并通过脚本更新该属性。链接到同级页面时使用 `aria-current="page"`。

<ComponentPreview name="pressed" height={96} title="切换按钮" html={`<div class="segmented" role="group" aria-label="Text alignment">
  <button type="button" class="segmented-item" aria-pressed="true">Left</button>
  <button type="button" class="segmented-item" aria-pressed="false">Center</button>
  <button type="button" class="segmented-item" aria-pressed="false">Right</button>
</div>`} />
