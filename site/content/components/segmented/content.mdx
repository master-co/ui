A segmented control is a well holding a few mutually exclusive options; the current one rises as a sheet. The track's radius is the thumb's plus its padding, so the corners stay concentric.

Options are direct children of `.segmented`. Wrap native radios in labels when the choice is a value, so the group has arrow-key navigation and works in forms:

<ComponentPreview name="default" title="Segmented control" html={`<div class="segmented" role="radiogroup" aria-label="View">
  <label><input type="radio" name="view" value="list" checked>List</label>
  <label><input type="radio" name="view" value="board">Board</label>
  <label><input type="radio" name="view" value="timeline">Timeline</label>
</div>`} />

## As toggle buttons \{#as-toggle-buttons\}

When each option triggers an action, use buttons with `aria-pressed` and update it from your script. Links to sibling pages use `aria-current="page"`.

<ComponentPreview name="pressed" title="Toggle buttons" html={`<div class="segmented" role="group" aria-label="Text alignment">
  <button type="button" aria-pressed="true">Left</button>
  <button type="button" aria-pressed="false">Center</button>
  <button type="button" aria-pressed="false">Right</button>
</div>`} />

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `segmented` | The well; its direct `button`, `a` and `label` children are options |
| `segmented-sm`, `segmented-lg` | Compact and prominent tracks |

The current option is the one with `aria-pressed`, `aria-selected`, `aria-checked` or `aria-current="page"`, or a label whose radio is checked.
