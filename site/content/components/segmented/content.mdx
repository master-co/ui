A segmented control is a compact group of mutually exclusive options. Build it from native radio inputs so the group has arrow-key navigation and works in forms.

<ComponentPreview name="default" title="Segmented control" html={`<div class="segmented" role="radiogroup" aria-label="View">
  <label class="segment"><input type="radio" name="view" value="list" checked>List</label>
  <label class="segment"><input type="radio" name="view" value="board">Board</label>
  <label class="segment"><input type="radio" name="view" value="timeline">Timeline</label>
</div>`} />

## As toggle buttons \{#as-toggle-buttons\}

When each option triggers an action instead of a form value, use buttons with `aria-pressed` and update it with your own script.

<ComponentPreview name="pressed" title="Toggle buttons" html={`<div class="segmented" role="group" aria-label="Text alignment">
  <button type="button" class="segment" aria-pressed="true">Left</button>
  <button type="button" class="segment" aria-pressed="false">Center</button>
  <button type="button" class="segment" aria-pressed="false">Right</button>
</div>`} />

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--segment-height` | `1.75rem` | Height of each option |
| `--segment-padding-x` | `var(--spacing-sm)` | Inline padding of each option |
| `--segment-font-size` | `var(--font-size-sm)` | Label size |
