A segmented control is a well holding a few mutually exclusive options; the current one rises as a sheet. The track's radius is the option's radius plus its 4px inset, so the corners stay concentric, and each size is exactly as tall as the matching button.

Each option is a `segmented-item`. When the choice is a value, make it a label around a native radio with `segmented-input`, so the group keeps arrow-key navigation and works in forms:

<ComponentPreview name="default" title="Segmented control" html={`<div class="segmented" role="radiogroup" aria-label="View">
  <label class="segmented-item"><input type="radio" class="segmented-input" name="view" value="list" checked>List</label>
  <label class="segmented-item"><input type="radio" class="segmented-input" name="view" value="board">Board</label>
  <label class="segmented-item"><input type="radio" class="segmented-input" name="view" value="timeline">Timeline</label>
</div>`} />

## The gliding thumb \{#the-gliding-thumb\}

Where the browser supports CSS anchor positioning, the raised sheet is one thumb that travels to the current option instead of blinking from one to the next. The current option names itself as an anchor, the track scopes that name to itself with `anchor-scope`, and a single pseudo-element is drawn on the anchor's edges; when the choice changes, those edges transition. No script measures anything, and several segmented controls on a page do not interfere. Elsewhere, and with reduced motion, the current option carries the sheet itself and changes at once.

## As toggle buttons \{#as-toggle-buttons\}

When each option triggers an action, use buttons with `aria-pressed` and update it from your script. Links to sibling pages use `aria-current="page"`.

<ComponentPreview name="pressed" title="Toggle buttons" html={`<div class="segmented" role="group" aria-label="Text alignment">
  <button type="button" class="segmented-item" aria-pressed="true">Left</button>
  <button type="button" class="segmented-item" aria-pressed="false">Center</button>
  <button type="button" class="segmented-item" aria-pressed="false">Right</button>
</div>`} />

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `segmented` | The well around the options |
| `segmented-item` | An option: a `button`, an `a`, or a `label` around a radio |
| `segmented-input` | The radio inside a label option, covering it invisibly |
| `segmented-sm`, `segmented-lg` | 32px and 44px tracks; the default is 38px, matching buttons |

The current option has `aria-pressed="true"`, `aria-selected="true"` or `aria-current="page"`, or holds a checked `segmented-input`.
