세그먼트 컨트롤은 여러 옵션 중 하나만 선택할 수 있도록 오목한 영역에 옵션을 모아 놓은 컴포넌트입니다. 현재 옵션은 솟아오른 표면으로 표시됩니다. 트랙의 모서리 반경은 옵션의 모서리 반경에 안쪽 여백인 4px을 더한 값이므로 두 모서리의 중심이 일치합니다. 각 크기의 높이는 같은 크기의 버튼과 정확히 일치합니다.

각 옵션은 `segmented-item`입니다. 값을 선택하는 경우에는 각 옵션을 레이블 요소로 만들고, 그 안에 `segmented-input`을 지정한 네이티브 라디오 버튼을 넣으세요. 이렇게 하면 그룹에서 방향키로 옵션을 탐색할 수 있고 폼에서도 사용할 수 있습니다.

## 손잡이 이동 \{#the-gliding-thumb\}

브라우저가 CSS 앵커 위치 지정을 지원하면 솟아오른 표면은 하나의 손잡이로 표시됩니다. 선택이 바뀔 때 표면이 한 옵션에서 사라졌다가 다른 옵션에 나타나는 대신 손잡이가 현재 옵션으로 부드럽게 이동합니다. 현재 옵션은 자신을 이름이 있는 앵커로 지정하고, 트랙은 `anchor-scope`를 사용해 그 이름의 범위를 트랙 내부로 한정합니다. 가상 요소 하나를 앵커의 가장자리에 맞춰 그리며, 선택이 바뀌면 각 가장자리의 위치가 부드럽게 바뀝니다. 스크립트로 위치나 크기를 측정할 필요가 없고, 한 페이지에 세그먼트 컨트롤이 여러 개 있어도 서로 영향을 주지 않습니다. 브라우저가 이 기능을 지원하지 않거나 동작 줄이기가 켜져 있으면 현재 옵션 자체에 솟아오른 표면을 표시하며 선택이 바뀌는 즉시 반영합니다.

## 토글 버튼 \{#as-toggle-buttons\}

각 옵션이 동작을 실행한다면 버튼에 `aria-pressed`를 지정하고 스크립트에서 그 값을 갱신하세요. 같은 계층의 다른 페이지로 연결하는 링크에는 `aria-current="page"`을 사용하세요.

  <button type="button" class="segmented-item" aria-pressed="true">Left</button>
  <button type="button" class="segmented-item" aria-pressed="false">Center</button>
  <button type="button" class="segmented-item" aria-pressed="false">Right</button>
</div>`} />
