A skeleton stands in for content that is on its way, in the shape it will have, so the page does not jump when it arrives. It is a chip-toned block that a soft band of light crosses. Skeletons in one block start one after another, so the light runs down the block as a single pass where the browser supports `sibling-index()`. Size each like the content it replaces.

## Shapes \{#shapes\}

- `skeleton` alone is a block. Give it the height of an image, a chart or a card.
- `skeleton-text` is one line of text: as tall as the letters and centered in the line it stands for, so the real text lands on the same baseline grid. It follows the font size and line height around it.
- `skeleton-circle` is an avatar or an icon. Give it a width; the height follows.

## Accessibility \{#accessibility\}

- Hide skeletons with `aria-hidden="true"` and mark the region they fill with `aria-busy="true"` and a label that says what is loading.
- With reduced motion the band of light does not move; the shape alone says the content is pending.
- Show a skeleton only when a wait is likely to be noticed. For a short wait, show nothing; for a button, use `aria-busy` and a [spinner](/components/spinner).
