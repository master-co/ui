Checkboxes and radios are small wells that fill with ink when checked. Put `.checkbox` or `.radio` on the native input, and wrap it with its text in a `<label class="check">` so the whole row is a target.

<ComponentPreview name="default" title="Checkbox" bodyClass="flex flex-col items-start gap-sm p-lg" html={`<label class="check"><input type="checkbox" class="checkbox" checked> Email me about releases</label>
<label class="check"><input type="checkbox" class="checkbox"> Weekly digest</label>`} />

## Radio \{#radio\}

Group radios in a `<fieldset>` with a `<legend>`, and give them one `name`.

<ComponentPreview name="radio" title="Radio" bodyClass="p-lg" html={`<fieldset class="flex flex-col gap-sm m(0) p(0) b(0)">
  <legend class="mb-xs text-sm fg-text-strong">Visibility</legend>
  <label class="check"><input type="radio" class="radio" name="visibility" checked> Public</label>
  <label class="check"><input type="radio" class="radio" name="visibility"> Private</label>
</fieldset>`} />

## Indeterminate \{#indeterminate\}

A parent checkbox whose children are partly selected shows a dash. Set `indeterminate` from script; HTML has no attribute for it.

<ComponentPreview name="indeterminate" title="Indeterminate" bodyClass="p-lg" html={`<label class="check"><input type="checkbox" class="checkbox" id="select-all"> Select all</label>
<script>document.getElementById('select-all').indeterminate = true</script>`} />

## Disabled \{#disabled\}

<ComponentPreview name="disabled" title="Disabled" bodyClass="flex flex-col items-start gap-sm p-lg" html={`<label class="check"><input type="checkbox" class="checkbox" checked disabled> Required by your plan</label>
<label class="check"><input type="radio" class="radio" disabled> Unavailable</label>`} />

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `checkbox` | A native `type="checkbox"` input |
| `radio` | A native `type="radio"` input |
| `check` | A label row around a checkbox, radio or switch |
