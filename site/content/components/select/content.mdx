Use `.select` directly on a native `<select>`. The browser keeps its option list, keyboard handling and mobile pickers; the class draws the well and a quiet chevron that reads in both themes.

<ComponentPreview name="default" title="Select" bodyClass="p-lg" html={`<label class="field">
  Framework
  <select class="select">
    <option>Astro</option>
    <option>Next.js</option>
    <option>SvelteKit</option>
    <option>Nuxt</option>
  </select>
</label>`} />

## Raised \{#raised\}

In a toolbar or a filter row, `select-raised` makes the select a raised control beside buttons.

<ComponentPreview name="raised" title="Raised" html={`<select class="select select-raised select-sm" aria-label="Sort">
  <option>Newest first</option>
  <option>Oldest first</option>
</select>
<button type="button" class="btn btn-sm">Export</button>`} />

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `select` | A native select drawn as a well |
| `select-raised` | A raised select for toolbars |
| `select-sm`, `select-lg` | 32px and 44px heights; the default is 40px |
