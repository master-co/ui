Use `.select` directly on a native `<select>`. The browser keeps the keys, type-ahead and the form value; the class draws the well and a quiet chevron that reads in both themes. Where the browser supports the customizable select, the option list is drawn in the same material as the rest of the interface.

## The option list \{#the-option-list\}

With `appearance: base-select` the list is no longer drawn by the operating system. It becomes `::picker(select)`, a popover that the browser anchors to the control and flips at the viewport edge, and the stylesheet gives it the floating sheet, whose corner is a row's corner plus the 4px between them. Put `select-option` on each `<option>`:

- The row under the pointer or the arrow keys takes a chip tone.
- The current option carries a check at its end, drawn on `::checkmark`.
- The control's chevron is `::picker-icon`; it turns over while the list is open.

A browser without the customizable select ignores all of this and shows the platform's own list, as it always has. Nothing in the markup changes, and `select-option` does no harm there.

## Options with icons \{#options-with-icons\}

Give each option a text label and a value. A decorative icon can sit beside the text. In a customizable select, `<selectedcontent>` mirrors the chosen option in the closed control. The native picker in other browsers still shows the labels and submits the same values.

      <button type="button"><selectedcontent></selectedcontent></button>
      <option class="select-option" value="email"><svg class="icon" viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linejoin="round" aria-hidden="true"><path d="M2 4h12v8H2z M2 4l6 4 6-4"/></svg> Email</option>
      <option class="select-option" value="sms"><svg class="icon" viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linejoin="round" aria-hidden="true"><path d="M3 3h10v7H7l-4 3z"/></svg> Text message</option>
    </select>
  </label>
  <button type="submit" class="btn btn-sm">Save</button>

## Raised \{#raised\}

In a toolbar or a filter row, `select-raised` makes the select a raised control beside buttons.

  <option class="select-option">Oldest first</option>
  <option class="select-option">Name</option>
</select>
<button type="button" class="btn btn-sm">Export</button>`} />

## Sizes \{#sizes\}

A select is 32, 38 or 44px tall, as a [button](/components/button) and an [input](/components/input) are, whether it is a well or raised.
