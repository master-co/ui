Wrap a native `<select>` in `.select`. The browser keeps its option list, keyboard handling and mobile pickers; the wrapper draws a consistent field and indicator.

<ComponentPreview name="default" title="Select" html={`<label class="flex flex-col gap-2xs text-sm fg-text-strong">
  Framework
  <span class="select">
    <select>
      <option>Astro</option>
      <option>Next.js</option>
      <option>SvelteKit</option>
      <option>Nuxt</option>
    </select>
  </span>
</label>`} />

## Full width \{#full-width\}

The wrapper is inline by default. Add `w-full` to fill a form column.

<ComponentPreview name="full-width" title="Full width" bodyClass="p-lg" html={`<span class="select w-full">
  <select aria-label="Plan">
    <option>Hobby</option>
    <option>Team</option>
    <option>Enterprise</option>
  </select>
</span>`} />

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--select-height` | `2.25rem` | Field height |
| `--select-padding-x` | `var(--spacing-sm)` | Inline padding; the indicator side adds its width |
| `--select-font-size` | `var(--font-size-sm)` | Text size |
| `--select-radius` | `var(--radius-md)` | Corner radius |
| `--select-indicator` | `1rem` | Indicator size |
