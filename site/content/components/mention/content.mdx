A mention names a person, a team or a thing inside a sentence: `@Ada`, `#design`, an issue's number. It keeps the sentence's own type and ink, at the control weight, on a faint tint of that ink. It has no contour, which tells it apart from inline [code](/components/code).

## Link or text \{#link-or-text\}

On an `<a>` a mention goes somewhere, a profile or an issue, and its tint deepens under the pointer. On a `<span>` it is only a name set apart, such as a date a parser recognized. The stylesheet tells the two apart by `:any-link`, so nothing that cannot be followed looks as if it could.

## The reader's own name \{#self\}

`mention-self` marks the reader: a firmer tint and a hairline, so their own name is found at a glance in a long thread. It stays in ink like every other mention; say "you" or the name in the text, since the difference in tone is slight on purpose.

## In text \{#in-text\}

A mention does not break across lines. Its tint and its hairline are mixed from the current color, so it reads wherever the sentence does: inside a sent [message](/components/message), which is ink, the name is the bubble's own light text on a light tint.

## Accessibility \{#accessibility\}

- The sign is part of the text. Write `@` or `#` in the element, so the mention reads the same when copied or spoken.
- A mention that opens a profile is a link and needs no extra role.
