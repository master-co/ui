## 레이블과 개수 \{#labels-and-counts\}

`nav-label`은 행 묶음에 제목을 붙이며, 제목은 그 아래 행에 속합니다. 제목 위 여백은 행 사이 간격의 몇 배라서 앞 묶음과 나뉘고, 아래 여백은 작아서 제목이 이끄는 행과 함께 읽힙니다. 목록 맨 앞에 오면 위 여백을 조금만 둡니다. `nav-end` 클래스는 행 끝에 개수, 단축키 또는 [배지](/components/badge)를 배치하며, 0부터 9까지의 숫자 글자는 모두 같은 너비로 표시합니다.

## 그룹 \{#groups\}

그룹에는 `nav-group` 클래스를 지정한 네이티브 `<details>` 요소를 사용합니다. `<summary>`는 `nav-item`과 `nav-toggle` 클래스를 적용한 행으로, 끝에 `nav-chevron` 아이콘을 담습니다. 아래 행은 `nav-sub` 안에 배치하고 가는 안내선을 따라 들여씁니다. 브라우저에서 펼치기와 접기, 키보드 조작을 처리합니다. 페이지 내 검색에서 접힌 그룹 안에 검색어와 일치하는 내용이 있으면 해당 그룹이 펼쳐집니다. 브라우저가 `interpolate-size` 속성을 지원하면 그룹이 콘텐츠 높이까지 부드럽게 열리며, 그 외 브라우저에서는 즉시 열립니다.

## 접근성 \{#accessibility\}

- 레이블을 지정한 `<nav>` 요소로 목록을 감싸고, `aria-current="page"`로 현재 페이지를 표시합니다.
- 사용할 수 없는 링크에는 `aria-disabled="true"`를 지정하고 `href` 속성을 제거합니다.
- 페이지 안에서 같은 계층의 페이지 사이를 이동할 때는 [탭](/components/tabs)을, 페이지 위에 현재 위치의 경로를 표시할 때는 [브레드크럼](/components/breadcrumb)을 사용합니다.
