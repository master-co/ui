## Labels and counts \{#labels-and-counts\}

`nav-label` captions a set of rows and belongs to them: the room above it is several times the gap between rows, which parts one set from the set before, and the room below is small, so the caption reads with the rows it leads. First in the list, it keeps only a little room above. `nav-end` sets a count, a shortcut or a [badge](/components/badge) at the end of a row, in tabular figures.

## Groups \{#groups\}

A group is a native `<details>` with `nav-group`. Its `<summary>` is a row with `nav-item` and `nav-toggle`, and holds a `nav-chevron` icon at its end; the rows under it go in a `nav-sub`, set in on a hairline guide. The browser keeps the toggle and the keys, and find-in-page opens a folded group that holds a match. The group opens to its own height where `interpolate-size` is supported, and at once elsewhere.

## Accessibility \{#accessibility\}

- Wrap the list in a `<nav>` with a label, and mark the current page with `aria-current="page"`.
- For a link that is not available, use `aria-disabled="true"` and remove the `href`.
- A nav of sibling pages inside a page is [tabs](/components/tabs); the path above a page is a [breadcrumb](/components/breadcrumb).
