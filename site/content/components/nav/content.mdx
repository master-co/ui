## Labels and counts \{#labels-and-counts\}

`nav-label` captions a set of rows. `nav-end` sets a count, a shortcut or a [badge](/components/badge) at the end of a row, in tabular figures.

## Groups \{#groups\}

A group is a native `<details>` with `nav-group`. Its `<summary>` is a row with `nav-item` and `nav-toggle`, which adds a chevron; the rows under it go in a `nav-sub`, set in on a hairline guide. The browser keeps the toggle and the keys, and find-in-page opens a folded group that holds a match. The group opens to its own height where `interpolate-size` is supported, and at once elsewhere.

## Accessibility \{#accessibility\}

- Wrap the list in a `<nav>` with a label, and mark the current page with `aria-current="page"`.
- For a link that is not available, use `aria-disabled="true"` and remove the `href`.
- A nav of sibling pages inside a page is [tabs](/components/tabs); the path above a page is a [breadcrumb](/components/breadcrumb).

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `nav` | The list |
| `nav-item` | A destination: a link, a button, or the `<summary>` of a group |
| `nav-end` | A count or a badge at the end of a row |
| `nav-label` | A caption over a set of rows |
| `nav-group`, `nav-toggle`, `nav-sub` | A folding `<details>`, its summary and the rows under it |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--nav-item-height` | `2rem` | Row height |
| `--nav-item-radius` | `var(--radius-control-sm)` | Row corner |
