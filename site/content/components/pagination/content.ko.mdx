페이지네이션은 긴 목록의 각 페이지를 `<nav>` 안에 링크 한 줄로 표시합니다. 각 링크는 눈에 띄지 않는 정사각형 [버튼](/components/button)입니다. 현재 페이지에는 `aria-current="page"`가 지정되며, 눌린 토글처럼 오목한 영역에 들어간 상태로 유지됩니다. 이 스타일시트는 링크 행과 건너뛴 페이지를 나타내는 간격을 제공합니다. 가이드의 장처럼 이름이 있고 순서대로 읽는 페이지에는 [이전·다음 페이지 탐색](/components/pager)을 사용합니다.

## 이전·다음 버튼만 사용 \{#previous-and-next-only\}

페이지 수를 모르거나 페이지 수가 중요하지 않다면 레이블이 있는 버튼 두 개면 충분합니다. 링크 자체는 비활성화할 수 없으므로 첫 페이지에서는 "이전"에 `aria-disabled="true"`를 지정하고 `href`를 제거하세요.

<ComponentPreview name="simple" height={96} title="이전·다음 버튼만 사용" background="plain" html={`<nav class="flex items-center gap-xs" aria-label="Pagination">

  <span class="px-xs text-center fg-text-muted (min-width:12ch) (font-size:.78125rem) (font-variant-numeric:tabular-nums)">Page 1 of 24</span>
  <a class="btn btn-sm" href="#page-2">Next</a>
</nav>`} />

## 긴 페이지 번호 \{#long-page-numbers\}

`btn-square`는 정사각형에 들어가는 레이블, 즉 한 자리에서 세 자리까지의 페이지 번호에 사용합니다. 자릿수가 그보다 많으면 번호 링크에서 이 클래스를 빼세요. 그러면 각 링크가 번호만큼 넓어지고 작은 버튼의 안쪽 여백을 유지합니다. 화살표는 정사각형으로 유지합니다.

## 접근성 \{#accessibility\}

- 목록을 `<nav aria-label="Pagination">`로 감싸고 현재 페이지를 `aria-current="page"`로 표시하세요.
- 숫자만으로는 링크의 이름이 명확하지 않습니다. 각 페이지 링크에 "3페이지"와 같은 `aria-label`을 지정하세요.
- 건너뛴 페이지를 나타내는 간격은 조작할 수 있는 요소가 아니므로 `aria-hidden="true"`로 숨기세요.
