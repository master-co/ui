간트 차트는 프로젝트 단계, 당직 교대 근무, 정기 릴리스 일정처럼 일정 기간 이어지는 항목을 공통 시간축에 막대로 표시합니다. 마크업은 목록으로 구성합니다. 각 행에는 막대의 시작과 끝, 항목 이름, 막대가 나타내는 내용을 담은 텍스트가 들어갑니다. 스타일시트가 한 열에는 이름을, 다른 열에는 막대를 배치하고 각 눈금 단위마다 가는 선을 그립니다. 차트를 표시하는 데는 스크립트나 SVG가 필요하지 않습니다. 사용자가 일정을 계획하는 화면에서는 `gantt` [동작](/guide/behaviors)으로 [막대를 옮기고 크기를 조절](#moving-the-bars)할 수 있습니다.

## 막대 배치 방식 \{#how-a-bar-gets-its-place\}

눈금의 시작값 `--gantt-from`과 끝값 `--gantt-to`는 목록에 지정합니다. 일, 주, 시간, 스프린트 등 원하는 단위를 사용하세요. 각 `gantt-row`에는 같은 단위로 `--from`과 `--to`를 지정합니다. 해당 `gantt-bar`의 양 끝은 전체 눈금 범위에서 두 값이 차지하는 비율에 맞춰 배치됩니다. 소수 값도 사용할 수 있어 막대가 한 눈금 단위의 중간에서 끝날 수 있습니다.

이름 열의 너비는 가장 긴 이름에 맞춰지고, 막대 영역은 남은 너비를 모두 차지합니다. 모든 행이 두 열을 공유하므로 너비를 따로 지정하지 않아도 막대가 정렬됩니다. 막대 뒤에는 눈금 단위마다 가는 선이 표시됩니다.

막대 텍스트에는 날짜, 기간, 담당자 등 막대가 나타내는 정보를 적습니다. 막대가 짧아 텍스트를 표시할 공간이 부족해도 스크린 리더가 읽을 수 있도록 작성하세요. 공간에 맞지 않는 텍스트는 끝에 줄임표가 표시됩니다.

## 진행률, 현재 행, 현재 시점 \{#progress\}

행에 `--progress`를 0부터 100까지의 값으로 지정하면 그 비율만큼 막대가 한층 진한 색조로 채워집니다. `aria-current="true"`로 표시한 행의 막대에는 전경색이 적용됩니다. 독자가 현재 진행 중인 단계나 화면에서 중점적으로 보여 주는 단계를 표시할 때 사용합니다.

목록에 `gantt-now`를 지정하면 오늘을 나타내는 `--gantt-now` 위치에 모든 행을 가로지르는 세로선이 전경색으로 표시됩니다. 행에 포인터를 올리면 막대가 한 단계 진해지고 이름에 강조 전경색이 적용되어, 넓은 차트에서도 해당 행을 가로로 따라가기 쉽습니다.

## 마일스톤 \{#milestones\}

마일스톤은 한 시점을 나타냅니다. `--from`만 지정한 행의 막대에 `gantt-milestone`을 붙이면 해당 지점에 전경색으로 채운 작은 마름모가 표시됩니다. 막대 텍스트는 보조 기술을 위해 목록에 남아 있지만 화면에 표시되지 않으므로, 그 시점에 일어나는 일을 행 이름에 담으세요.

## 시간 눈금 \{#the-scale\}

`gantt-scale`이 지정된 행은 각 눈금 단위에 이름을 붙입니다. 이 행에는 단위별 항목을 하나씩 담은 `gantt-ticks` 목록 하나를 넣습니다. 각 이름은 해당 단위가 시작되는 가는 선 위에 표시됩니다. 막대 텍스트가 이미 전달하는 정보를 시각적으로 보여 주므로 `aria-hidden`으로 보조 기술에서 숨기세요.

## 좁은 컨테이너 \{#narrow\}

간트 차트는 크기 컨테이너입니다. 차트 자체의 너비가 26rem 미만이면 각 이름이 막대 위로 이동해 막대 영역이 전체 너비를 확보합니다. 휴대전화에서는 눈금 범위를 짧게 유지하세요. 8단위는 읽을 수 있지만 30단위는 읽을 수 없습니다.

## 막대 옮기기 \{#moving-the-bars\}

막대에 `role="slider"`를 지정하고 `gantt` 동작을 연결하면 사용자가 막대를 옮길 수 있습니다. 막대 본체를 드래그하면 눈금을 따라 이동하고, 한쪽 끝을 드래그하면 시작이나 종료 시점이 바뀝니다. 막대는 눈금의 정수 단위(이 예시에서는 일)에 맞춰 스냅되며, 잡고 있는 동안 막대의 텍스트는 지금 놓으면 적용될 시작과 종료 시점을 표시합니다. <kbd class="kbd">Escape</kbd> 키를 누르면 원래 위치로 돌아갑니다. 포인터로 할 수 있는 조작은 모두 키보드로도 할 수 있습니다.

움직이는 막대는 스타일시트가 다음과 같이 그립니다.

- **기본 상태**에서는 다른 막대와 같은 모양이며, 커서는 잡기 모양입니다. 포인터를 올리거나 포커스가 있으면 양 끝에 짧은 세로 손잡이가 나타나고, 그 위에서 커서가 크기 조절 화살표로 바뀝니다. 호버가 없는 터치 화면에서는 손잡이가 항상 표시되면서 더 넓어지고, 막대는 28px 높이를 유지합니다.
- **포커스가 있으면** 포커스 윤곽선이 표시되며, 주변 행 위에 그려집니다.
- **잡고 있는 동안**에는 `aria-busy="true"`가 지정됩니다. 막대는 한층 진한 색조를 띠고 그림자가 생겨 위로 떠 보이며, 이징 없이 포인터를 따라가며, 포인터가 어디로 가든 커서는 쥔 손 모양을 유지합니다. 끝을 잡고 있는 동안(`gantt-resize-start`, `gantt-resize-end`)에는 크기 조절 화살표를 유지합니다. 키 입력이나 외부에서 설정한 값으로 이동할 때는 막대가 제자리로 부드럽게 이동하며, 동작 줄이기가 활성화되어 있으면 바로 이동합니다.
- **읽기 전용**(`aria-readonly="true"`)인 막대는 포커스를 받고 읽히지만 움직이지 않습니다. **비활성화**(`aria-disabled="true"`)된 막대는 움직이지 않고, 키 조작에서 건너뛰며, 텍스트에는 비활성 상태의 전경색이 적용됩니다.

마일스톤은 한 지점으로 움직이며, 크기를 조절할 끝이 없습니다.

## 동작 \{#behavior\}

`gantt`는 `gantt` 클래스가 있는 루트 요소를 받아, 연결한 동작을 해제하는 함수를 반환합니다. `role="slider"`가 지정된 막대만 움직이며, 나머지는 그림으로 남습니다. 동작은 각 막대에 슬라이더에 필요하지만 페이지가 지정하지 않은 속성을 기록합니다. 이름은 행의 `gantt-label`에서, 가장 이른 시작과 가장 늦은 끝을 나타내는 `aria-valuemin`과 `aria-valuemax`는 눈금에서 가져옵니다. `aria-valuenow`에는 시작 값을, `aria-valuetext`에는 `format`이 기간을 표현한 텍스트를 기록합니다. 막대를 더 좁은 구간 안에 두려면 막대에 `aria-valuemin`과 `aria-valuemax`를 직접 지정하세요.

```js name=app.js
import { gantt } from '@master/ui/behaviors/gantt.js'

const plan = gantt(document.querySelector('.gantt'), {
  // What a bar says for a range, as its text and to assistive technology.
  format: (start, end) => `Days ${start + 1} to ${end}`,
})

plan.value // { research: [0, 3], design: [2, 6], … }
plan.value = { design: [3, 7] }
```

- **값**은 각 막대의 기간으로, 눈금 단위의 `[start, end]`이며 행의 `data-value` 또는 레이블 텍스트를 키로 사용합니다. 마일스톤의 기간은 같은 지점에서 시작하고 끝납니다. 외부에서 막대를 옮기려면 이 값을 설정하세요. 이때 이벤트는 발행하지 않습니다.
- **이벤트.** 루트는 드래그하는 동안을 포함해 막대의 기간이 바뀔 때마다 `input`을 발생시키고, 놓거나 키 입력으로 기간이 바뀌면 `change`를 한 번 발생시킵니다.
- **포인터.** 누른 뒤 4px를 초과해 움직이면 드래그로 처리합니다. 이동 거리가 4px 미만이면 막대에 포커스만 둡니다. 스타일시트가 양 끝에 그리는 손잡이 너비 안을 누르면 해당 끝이 움직이고, 그 밖의 위치를 누르면 막대 전체가 움직입니다. 눈금 한 단위의 크기는 막대가 그려진 너비에서 읽으므로, 어떤 레이아웃에서든 드래그는 `step` 단위(기본값 1)로 스냅됩니다. 손가락을 페이지 아래로 움직이면 여전히 페이지가 스크롤됩니다(`touch-action: pan-y`).
- **제한.** 막대는 `aria-valuemin`과 `aria-valuemax` 사이에 머무르며, 한 단계보다 짧아지지 않으며, 이미 그보다 짧다면 현재 길이보다 짧아지지 않습니다.
- **안내하는 내용.** 막대는 놓거나 키 입력으로 기간이 적용되면 슬라이더가 값을 알리듯 `aria-valuetext`로 새 기간을 알립니다. 변경이 거부되었거나 드래그가 취소된 것처럼 값으로 전할 수 없는 내용은 루트 바로 뒤에 있는 `role="status"` 영역인 `gantt-status`에서 알립니다. 페이지의 언어로 안내하려면 `messages`를 전달하세요.
- **오른쪽에서 왼쪽으로 쓰는 페이지**에서는 눈금도 오른쪽에서 왼쪽으로 진행하며, 포인터와 방향키도 같은 방향을 따릅니다. <kbd class="kbd">ArrowLeft</kbd> 키가 더 늦은 시점입니다.

동작이 없어도 차트는 항목과 날짜를 읽을 수 있는 목록으로 남습니다.

## 페이지의 규칙 \{#rules\}

의존 관계, 리소스, 근무일은 페이지가 판단합니다. 막대가 기간을 적용하기 전에 동작은 취소할 수 있는 `beforechange` 이벤트를 발행하며, 이벤트에는 막대의 `id`, 적용할 `range`, 이전 기간인 `previous`가 들어 있습니다. 변경을 거부하려면 `preventDefault()`를 호출하세요. 키 입력은 아무 효과가 없고, 놓은 막대는 드래그를 시작한 위치로 돌아가며, 상태 영역이 막대가 그대로 있다고 알립니다. 이 예시에서 Build는 Design이 끝나기 전에 시작할 수 없으며, Freeze는 릴리스 팀이 관리하므로 읽기 전용입니다.

## 접근성 \{#accessibility\}

- `<ol>` 요소로 작성하고 `aria-label`이나 제목으로 이름을 지정하세요. 각 행은 목록 항목 하나이며, "디자인, 3~6주 차"처럼 이름과 막대 텍스트가 순서대로 읽힙니다.
- 막대, 가는 눈금선, 현재 시점을 나타내는 선은 스타일시트가 그립니다. 이런 요소가 전달하는 정보는 텍스트에도 적으세요. 막대가 나타내는 날짜를 적고, 필요한 경우 해당 행이 현재 행임을 명시하세요.
- 현재 행은 색상에 의존하지 않고 구분합니다. 기본 표시에서는 옅은 색조의 막대 사이에서 전경색으로 채운 막대로 구분하고, 강제 색상 모드에서는 윤곽선만 있는 막대 사이에서 채워진 막대로 구분합니다.
- 움직이는 막대는 행의 이름으로 레이블이 지정된 슬라이더이며, 값은 페이지의 언어로 표현한 시작부터 종료까지의 범위입니다. 예를 들어 "디자인, 슬라이더, 11월 4~7일 · 4일간"으로 읽힙니다. `format`에는 막대 텍스트와 같은 표현을 지정해 두 내용이 일치하게 하세요.
- `gantt-status` 영역은 처음부터 빈 상태로 페이지에 두세요. 안내하는 순간에 추가한 영역은 읽히지 않는 경우가 많습니다. 이 영역은 슬라이더의 값으로 전할 수 없는 내용만 안내하므로 같은 내용을 두 번 읽지 않습니다.
- 포인터로 할 수 있는 조작은 모두 키보드로 할 수 있습니다. 포인터를 사용하지만 드래그할 수 없는 사용자를 위해, 행에서 여는 [대화 상자](/components/dialog)의 입력 필드처럼 드래그 없이 날짜를 설정하는 방법도 제공하세요.
- 위의 캡션처럼 키로 막대를 옮기는 방법을 차트 가까이에 적으세요. Shift와 Alt 키로 끝을 옮기는 슬라이더는 사용자가 짐작할 수 없습니다.

## React, Svelte, Vue \{#frameworks\}

`gantt` 컴포넌트는 데이터로 행을 작성합니다. 각 행에는 `id`, `label`, `start`, `end`가 있으며, `end`가 없는 행은 마일스톤입니다. 각 막대의 위치와 텍스트는 `{ [id]: [start, end] }` 형식의 값으로 작성합니다. 눈금은 `from`과 `to`로, 현재 시점은 `now`로, 눈금 단위의 이름은 `ticks`로 받습니다. 막대가 움직이는 동안 `onValueChange`를, 막대를 놓으면 `onValueCommit`을 호출하며, 막대가 기간을 적용하기 전에 `onBeforeChange`(Vue에서는 `beforeChange` 이벤트 발행)로 확인을 요청합니다. `npx master-ui add gantt`로 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
