甘特圖在同一條時間刻度上以長條呈現有持續時間的事項，例如專案階段、值班時段或定期發行排程。它以清單呈現，每列包含長條的起訖位置、項目名稱和長條上的文字。樣式表負責版面配置，將名稱與長條分成兩欄，並在每個刻度單位的起點畫一條細線。圖表本身不需要腳本或 SVG；在讀者需要規劃的地方，`gantt` [行為](/guide/behaviors)讓他們可以[移動長條並調整長度](#moving-the-bars)。

## 長條定位 \{#how-a-bar-gets-its-place\}

在清單上設定 `--gantt-from` 和 `--gantt-to`，指定刻度的起訖範圍。單位可自行選擇，例如天、週、小時或衝刺週期。每個 `gantt-row` 使用相同單位設定 `--from` 和 `--to`，其 `gantt-bar` 會依這兩個值在刻度範圍內的比例決定起訖位置。也可使用小數，讓長條在一個刻度單位中途結束。

名稱欄以最長的名稱為準，軌道占用其餘寬度。每列共用這兩欄，無須指定欄寬，長條就能對齊。長條後方的細線標出每個刻度單位。

用文字寫出長條所代表的資訊，例如日期、持續時間或負責人。即使長條太短，也請保留文字，讓螢幕閱讀器能讀出內容。放不下的文字會以省略號截斷。

## 進度、目前列與現在時間 \{#progress\}

在列上設定 0 到 100 的 `--progress`，長條就會依該百分比填入較深的色調。以 `aria-current="true"` 標記的列會使用深色實心長條，表示讀者目前所處的階段，或這個畫面所聚焦的階段。

在清單上加上 `gantt-now`，就會在 `--gantt-now` 指定的位置畫出一條貫穿各列的深色線，標示今天。當指標停在某一列上時，該列的長條會加深一階，名稱也會改用高對比文字色，方便讀者在較寬的圖上沿著同一列閱讀。

## 里程碑 \{#milestones\}

里程碑代表單一時間點。讓該列只設定 `--from`，再將 `gantt-milestone` 加到長條上，就會在該位置畫出深色的小菱形。長條文字會保留在清單中供輔助科技讀取，但畫面上不會顯示，因此請在列名稱中寫明該時間點發生的事。

## 刻度 \{#the-scale\}

使用 `gantt-scale` 的列用來標示各刻度單位。列內放一份 `gantt-ticks` 清單，每個刻度單位對應一個項目，各標籤會對齊該單位起點的細線。刻度將長條文字已有的資訊以視覺方式呈現，因此請加上 `aria-hidden`。

## 窄容器中的甘特圖 \{#narrow\}

甘特圖本身是尺寸容器。當自身寬度低於 26rem 時，各列名稱會移到長條上方，讓軌道使用整個寬度。在手機上請縮短刻度範圍，八個單位容易閱讀，三十個就太擠。

## 移動長條 \{#moving-the-bars\}

將長條標記為 `role="slider"` 並掛載 `gantt` 行為，讀者就能移動它：拖曳長條本體可沿著刻度移動，拖曳任一端則可改變開始或結束的時間。長條會貼齊刻度的整數單位（這裡是天），按住期間，長條文字會顯示它將取得的範圍。<kbd class="kbd">Escape</kbd> 會讓它回到原位。指標能做的事，按鍵都能做到。

樣式表為可移動的長條繪製的內容：

- **靜止時**外觀與一般長條相同，游標為抓取手勢。指標停在上方或取得焦點時，兩端會出現短短的直立握把，游標移到握把上會變成調整大小的箭頭；觸控螢幕沒有懸停狀態，因此握把會一直顯示並加寬，長條則維持 28px 高。
- **取得焦點時**會顯示焦點外框，畫在周圍列的上方。
- **按住時**會帶有 `aria-busy="true"`：長條以抬起的陰影和較深的色調浮起，無緩動地跟隨指標，無論指標移到哪裡，游標都維持握緊的手，按住一端時則維持調整大小的箭頭（`gantt-resize-start`、`gantt-resize-end`）。按鍵或從外部設定的值會讓它滑到定位；啟用減少動態效果時則直接跳到定位。
- **唯讀**（`aria-readonly="true"`）時，可以取得焦點並被讀出，但不會移動。**停用**（`aria-disabled="true"`）時不會移動，按鍵操作會略過它，文字也會套用停用狀態的文字色。

里程碑以單一點的方式移動，沒有可調整的兩端。

## 行為 \{#behavior\}

`gantt` 接收根元素（帶有 `gantt` 類別的元素），並回傳可卸載行為的函式。只有標記為 `role="slider"` 的長條可以移動，其他長條仍只是圖像。行為會在每個可移動的長條上寫入滑桿所需、而頁面未提供的資訊：取自該列 `gantt-label` 的名稱；取自刻度的 `aria-valuemin` 和 `aria-valuemax`，也就是最早的開始與最晚的結束；長條開始處的 `aria-valuenow`；以及 `aria-valuetext`，也就是 `format` 對其範圍的描述。若要讓長條限制在較窄的區間內，請自行在長條上寫入 `aria-valuemin` 和 `aria-valuemax`。

```js name=app.js
import { gantt } from '@master/ui/behaviors/gantt.js'

const plan = gantt(document.querySelector('.gantt'), {
  // What a bar says for a range, as its text and to assistive technology.
  format: (start, end) => `Days ${start + 1} to ${end}`,
})

plan.value // { research: [0, 3], design: [2, 6], … }
plan.value = { design: [3, 7] }
```

- **值**是每個長條的範圍，以刻度單位表示為 `[start, end]`，以該列的 `data-value` 為鍵，沒有時則以標籤文字為鍵。里程碑的範圍起訖都在它所在的點。設定它可從外部移動長條，不會派送事件。
- **事件。** 每當長條的範圍改變（包括拖曳期間），根元素都會派送 `input`；放開或按鍵改變範圍後，則派送一次 `change`。
- **指標。** 按下後移動超過 4px 就是拖曳；未超過則只會讓長條取得焦點。按在握把上（樣式表在兩端繪製的寬度）會移動該端，按在其他位置則移動整個長條。刻度單位是從長條繪製的寬度讀出的，因此無論版面如何，拖曳都會貼齊 `step` 個單位，預設為 1。手指往頁面下方移動時仍會捲動頁面（`touch-action: pan-y`）。
- **限制。** 長條會維持在它的 `aria-valuemin` 和 `aria-valuemax` 之間，長度也絕不會短於一個步進，或短於它目前的長度。
- **播報內容。** 放開或按鍵套用新範圍後，長條會像滑桿播報其值一樣，透過 `aria-valuetext` 播報新範圍。值無法表達的內容，例如變更遭拒或拖曳已取消，會由 `gantt-status` 區域播報，它是緊接在根元素之後的 `role="status"`。傳入 `messages` 即可用頁面的語言播報。
- **頁面由右至左排列時**，刻度、指標和方向鍵也都由右至左：<kbd class="kbd">ArrowLeft</kbd> 代表較晚。

沒有行為時，圖表仍是一份可閱讀的事項及其日期清單。

## 頁面的規則 \{#rules\}

相依關係、資源和工作日都由頁面掌握。長條取得某個範圍之前，會派送可取消的 `beforechange` 事件，其中包含長條的 `id`、將取得的 `range`，以及原本的 `previous`。呼叫 `preventDefault()` 即可拒絕：按鍵不會有任何作用，放開的長條會回到拖曳開始的位置，狀態區域也會播報長條維持原狀。這個範例中，Build 不能在 Design 完成前開始，而 Freeze 屬於發行團隊，因此設為唯讀。

## 鍵盤操作 \{#keyboard\}

和[工具列](/components/toolbar)或[樹狀檢視](/components/tree)一樣，整個圖表在 Tab 順序中只占一個停駐點，因此冗長的計畫也不會有幾十個停駐點。<kbd class="kbd">ArrowUp</kbd> 和 <kbd class="kbd">ArrowDown</kbd> 在長條之間移動，因為各列是上下堆疊的；<kbd class="kbd">ArrowLeft</kbd> 和 <kbd class="kbd">ArrowRight</kbd> 移動長條，因為時間是左右延伸的：方向鍵與畫面一致。圖表維持為清單而非格線，因為每列只有一個可操作的對象，也就是長條；否則長條的方向鍵就得等切換模式後才能使用。

## 無障礙 \{#accessibility\}

- 使用 `<ol>`，並以 `aria-label` 或標題為清單命名。每列都是一個清單項目，會依序讀出名稱和長條文字，例如「設計，第 3 到第 6 週」。
- 長條、刻度細線和現在時間線由樣式表繪製。請在文字中寫出它們傳達的資訊，例如長條的起訖日期，並在需要時說明哪一列是目前的階段。
- 辨識目前列無須依賴色相。它以深色長條和其餘列的淺色長條形成明暗對比。在強制色彩模式下，目前列為實心長條，其餘列只有外框。
- 可移動的長條是以所在列命名的滑桿，其值是以頁面用語描述的範圍，例如「設計，滑桿，11 月 4 日至 7 日」。請讓 `format` 使用與長條文字相同的措辭，讓兩者說法一致。
- 從一開始就在頁面中保留空白的 `gantt-status` 區域：在要播報時才加入的區域常常不會被讀出。它只播報滑桿本身的值無法表達的內容，因此不會重複播報。
- 指標能做的事，按鍵都能做到。對於使用指標但無法拖曳的讀者，也請為該列提供不需拖曳就能設定日期的方式，例如從該列開啟的[對話框](/components/dialog)中的欄位。
- 在圖表附近說明如何用按鍵移動長條，就像上方的說明文字一樣：以 Shift 和 Alt 移動兩端的滑桿，不是讀者猜得到的操作。

## React、Svelte 和 Vue \{#frameworks\}

`gantt` 元件會根據資料寫出各列，每列包含 `id`、`label`、`start` 和 `end`（沒有 `end` 的列是里程碑），並依值 `{ [id]: [start, end] }` 寫出每個長條的位置與文字。它以 `from` 和 `to` 接收刻度的起訖值，以 `now` 接收目前時間的位置，並以 `ticks` 接收刻度單位的名稱。長條移動時回報 `onValueChange`，放開後回報 `onValueCommit`，並在長條取得範圍前詢問 `onBeforeChange`（Vue 中為發出的 `beforeChange` 事件）。使用 `npx master-ui add gantt` 將元件複製到專案中；元件的實作方式與用法請見 [React、Svelte 和 Vue](/guide/frameworks)。
