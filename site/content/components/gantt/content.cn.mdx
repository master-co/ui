甘特图在同一时间标尺上用条形表示持续一段时间的事项，例如项目阶段、待命值班时段和按固定节奏协调发布的计划。甘特图采用列表结构。每行包含条形的起止位置、事项名称和条形显示的文本。样式表负责排布：名称和条形各占一列，标尺的每个单位都用细线标记。图表本身无需脚本或 SVG；需要读者做计划时，`gantt` [行为](/guide/behaviors)让读者可以[移动条形并调整其长度](#moving-the-bars)。

## 条形如何定位 \{#how-a-bar-gets-its-place\}

在列表上用 `--gantt-from` 和 `--gantt-to` 设置标尺的起止值。单位可自行选择，例如天、周、小时或迭代周期。每个 `gantt-row` 都用同一单位设置 `--from` 和 `--to`，其 `gantt-bar` 按对应比例在轨道上起止。支持小数值，因此条形可以在一个单位的中途结束。

名称列的宽度由最长的名称决定，轨道占据剩余宽度。所有行共用这两列，无需显式指定宽度即可对齐条形。条形后方的细线标出标尺的每个单位。

用条形文本写明条形表达的信息，例如起止日期、时长和负责人。即使条形太短也要写这段文本，屏幕阅读器会朗读它。超出可用空间的文本会以省略号结尾。

## 进度、当前行和当前时间 \{#progress\}

在行上将 `--progress` 设为 0 到 100 之间的值，条形就会按相应比例填入更深的色调。用 `aria-current="true"` 标记的行采用墨色条形，表示读者当前所处的阶段，或当前视图所关注的阶段。

在列表上设置 `gantt-now`，会在 `--gantt-now` 处画一条贯穿所有行的墨色竖线，标出今天。指针悬停在某行时，该行的条形会加深一级，名称也会使用更深的墨色，方便读者在宽图中沿着同一行查看。

## 里程碑 \{#milestones\}

里程碑表示单个时间点。在仅设置了 `--from` 的行中，将 `gantt-milestone` 加到条形上，该时间点就会显示一个墨色小菱形。条形文本保留在列表中供辅助技术读取，视觉上隐藏，因此请用该时间点发生的事件为这一行命名。

## 时间标尺 \{#the-scale\}

带有 `gantt-scale` 的行用来标注各个单位。该行包含一个 `gantt-ticks` 列表，每个单位对应一个列表项，名称位于该单位起始细线的上方。条形文本已经传达了这些信息，因此用 `aria-hidden` 将标尺对辅助技术隐藏。

## 窄容器中的布局 \{#narrow\}

甘特图本身是一个尺寸容器。自身宽度小于 26rem 时，名称移到对应条形的上方，轨道占满整行。在手机上应减少标尺单位数：8 个单位仍清晰可读，30 个就难以辨认。

## 移动条形 \{#moving-the-bars\}

将条形标记为 `role="slider"` 并挂载 `gantt` 行为，读者就可以移动它：拖动条形主体可沿标尺移动，拖动其一端可改变开始或结束时间。条形会吸附到标尺的整数单位（此处为天），按住期间，其文本显示它将占用的范围。按 <kbd class="kbd">Escape</kbd> 会让它回到原处。指针能做的一切，按键都能做到。

样式表为可移动的条形绘制的状态：

- **静止时**，它与普通条形外观相同，光标为抓取手形。指针悬停或获得焦点时，两端各显示一个短的竖向握柄，光标移到握柄上会变为调整大小的箭头；触摸屏没有悬停，握柄会一直显示并变宽，条形保持 28px 高。
- **获得焦点时**，显示焦点环，并绘制在周围各行之上。
- **按住时**，它带有 `aria-busy="true"`：以更深的色调和浮起阴影抬起，无缓动地跟随指针；无论指针移到哪里，光标都保持为握紧的手形，按住一端时则为调整大小的箭头（`gantt-resize-start`、`gantt-resize-end`）。通过按键或从外部设置值时，条形会平滑滑到新位置；启用减少动态效果时则直接跳过去。
- **只读**（`aria-readonly="true"`）时，它可以获得焦点并被朗读，但不能移动。**禁用**（`aria-disabled="true"`）时，它不能移动，按键会跳过它，其文本使用禁用状态的墨色。

里程碑作为一个点移动，没有可调整的两端。

## 行为 \{#behavior\}

`gantt` 接收带有 `gantt` 类的根元素，并返回一个用于解除绑定的函数。只有标记为 `role="slider"` 的条形可以移动，其余条形仍是静态图形。对于每个可移动的条形，脚本会写入滑块需要而页面未提供的内容：取自该行 `gantt-label` 的名称；取自标尺的 `aria-valuemin` 和 `aria-valuemax`，即最早的开始和最晚的结束；表示开始位置的 `aria-valuenow`；以及 `aria-valuetext`，即 `format` 对其范围的描述。在条形上自行写入 `aria-valuemin` 和 `aria-valuemax`，可以把它限制在更窄的范围内。

```js name=app.js
import { gantt } from '@master/ui/behaviors/gantt.js'

const plan = gantt(document.querySelector('.gantt'), {
  // What a bar says for a range, as its text and to assistive technology.
  format: (start, end) => `Days ${start + 1} to ${end}`,
})

plan.value // { research: [0, 3], design: [2, 6], … }
plan.value = { design: [3, 7] }
```

- **值**是每个条形的范围，即以标尺单位表示的 `[start, end]`，以所在行的 `data-value` 或其标签文本为键。里程碑的范围起止于同一个点。设置它可从外部移动条形，且不会派发事件。
- **事件。** 每当条形的范围发生变化（包括拖动过程中），根元素都会派发 `input`；放下条形或按键改变范围后，派发一次 `change`。
- **指针。** 按下后移动超过 4px 才算拖动；移动距离更短时只会让条形获得焦点。按在握柄上（即样式表在两端绘制握柄的宽度内）会移动对应的一端；按在其他位置会移动整个条形。标尺的一个单位根据条形的绘制宽度计算，因此在任何布局中，拖动都会按 `step` 指定的步长吸附，默认步长为 1 个标尺单位。手指沿页面向下移动时仍会滚动页面（`touch-action: pan-y`）。
- **限制。** 条形始终位于其 `aria-valuemin` 和 `aria-valuemax` 之间，长度不会短于一个步长，也不会短于其当前长度。
- **播报内容。** 放下条形或按键使其采用新范围后，条形会像滑块播报值一样，通过 `aria-valuetext` 播报新范围。值无法表达的内容，例如某次更改被拒绝或拖动被取消，由 `gantt-status` 区域播报，它是紧跟在根元素之后的 `role="status"`。传入 `messages` 可用页面的语言播报这些内容。
- **页面从右到左排列时**，标尺、指针和方向键也从右到左：<kbd class="kbd">ArrowLeft</kbd> 表示更晚。

未挂载行为时，图表仍是一份可读的事项及其日期列表。

## 页面的规则 \{#rules\}

依赖关系、资源和工作日由页面掌握。条形采用新范围之前，会派发可取消的 `beforechange` 事件，携带条形的 `id`、它将采用的 `range` 以及原来的 `previous`。调用 `preventDefault()` 即可拒绝：按键不起作用，放下的条形回到拖动开始的位置，状态区域会说明条形保持未变。此处 Build 的开始时间不得早于 Design 的结束时间，冻结期归发布团队管理，因此是只读的。

## 键盘操作 \{#keyboard\}

用甘特图呈现有起止时间的事项。按发生顺序呈现各个时间点的事件时，用[时间线](/components/timeline)。比较与时间位置无关的数值时，用[图表](/components/chart)。

## 无障碍 \{#accessibility\}

- 使用 `<ol>` 编写列表，并用 `aria-label` 或标题为其命名。每行是一个列表项，先朗读名称，再朗读条形文本，例如“Design，第 3 周至第 6 周”。
- 条形、细线和当前时间线均由样式表绘制。用文本写明图形表达的信息，包括条形的起止日期，并在有必要时注明哪一行是当前行。
- 区分当前行无需辨认色相。常规模式下，当前行用墨色条形，其他行用浅色条形。强制颜色模式下，当前行用实心条形，其他行只显示轮廓。
- 可移动的条形是以所在行命名的滑块，其值是用页面语言表达的范围，例如“Design，滑块，11 月 4 日至 7 日 · 共 4 天”。为 `format` 提供与条形文本相同的措辞，让两者表达一致。
- 从一开始就在页面中保留空的 `gantt-status` 区域：在需要播报时才添加的区域，往往不会被读出。它只播报滑块自身的值无法表达的内容，因此不会重复播报。
- 指针能做的一切，按键都能做到。对于使用指针但无法拖动的读者，还要为该行提供一种无需拖动即可设置日期的方式，例如从该行打开的[对话框](/components/dialog)中的输入框。
- 像上方说明文字那样，在图表附近说明如何用按键移动条形：通过 Shift 和 Alt 移动两端的滑块，读者不可能猜到。

## React、Svelte 和 Vue \{#frameworks\}

`gantt` 组件根据数据写出各行，每行包含 `id`、`label`、`start` 和 `end`（没有 `end` 的行是里程碑），并根据值 `{ [id]: [start, end] }` 写出每个条形的位置和文本。它通过 `from` 和 `to` 接收标尺，通过 `now` 接收当前时间，通过 `ticks` 接收各单位的名称；条形移动时调用 `onValueChange`，放下后调用 `onValueCommit`，条形采用新范围之前先询问 `onBeforeChange`（Vue 中为派发的 `beforeChange` 事件）。使用 `npx master-ui add gantt` 将组件复制到项目中。[React、Svelte 和 Vue](/guide/frameworks) 介绍这些组件的实现和用法。
