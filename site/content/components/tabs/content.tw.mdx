分頁沿著一條細線排列文字標籤，並以深色底線標示目前的分頁。分頁用於切換同層的頁面或面板。如果要在有限空間內選擇數值或選項，請使用[分段控制項](/components/segmented)。

瀏覽器支援 CSS 錨點定位時，所有分頁共用一條底線。`aria-selected` 變更時，底線會滑到目前的分頁，頂部的圓角讓線條收尾更柔和。其他瀏覽器則由各分頁各自繪製底線。

## 分頁面板 \{#tab-panels\}

頁面內的面板請依循 WAI-ARIA 分頁模式，使用帶有 `role="tablist"` 的容器、帶有 `role="tab"`、`aria-selected` 和 `aria-controls` 的按鈕，以及帶有 `role="tabpanel"` 的區域。樣式表負責呈現各種狀態，`tabs` [行為](/guide/behaviors)負責切換面板，並讓分頁清單支援鍵盤操作。

`tabs` 接收具有 `tabs` 類別與 `role="tablist"` 的分頁清單元素，不接受選項，並回傳一個用來解除綁定的函式。

```js name=app.js
import { tabs } from '@master/ui/behaviors/tabs.js'

const detach = tabs(document.querySelector('.tabs[role="tablist"]'))
```

- **單一 Tab 停駐點。** 只有選取的分頁會進入 Tab 巡覽順序。方向鍵會移到上一個或下一個分頁並選取它，略過停用的分頁，到了兩端則循環切換。<kbd>Home</kbd> 和 <kbd>End</kbd> 分別移到第一個與最後一個分頁。帶有 `aria-orientation="vertical"` 的分頁清單改用上下方向鍵。
- **面板。** 每個分頁以 `aria-controls` 指向自己的面板。選取的分頁會顯示對應面板，其餘面板則加上 `hidden`。
- **值。** 選取分頁時，分頁清單會發出可冒泡的 `change` 事件。`detail.value` 是分頁的 `data-value`，若未設定則取分頁文字。行為回傳的函式也有相同的 `value`，可從外部設定它來選取分頁。
- **沒有腳本時**，只有已選取分頁的面板未加上 `hidden`，也無法切換面板。如果每個分頁都能做成獨立頁面，請在 `nav` 中使用連結。

## React、Svelte 和 Vue \{#frameworks\}

`tabs` 元件根據資料呈現分頁清單及面板，以 ID 將各分頁連到對應面板，並掛載行為，讓外部可傳入選取值並取得變更。若分頁是 `nav` 內的連結，直接使用標記即可。執行 `npx master-ui add tabs` 將元件複製到專案中。[React、Svelte 和 Vue](/guide/frameworks)說明元件的實作與用法。
