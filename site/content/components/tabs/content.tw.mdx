預設橫排的分頁標籤沿著細線排列，用來切換同層的頁面或面板。目前選取的標籤會加上深色底線。如果要在有限空間內選擇數值或選項，請使用[分段控制項](/components/segmented)。

橫排時，若瀏覽器支援 CSS 錨點定位，所有分頁標籤共用一條底線。`aria-selected` 變更時，底線會滑到目前的分頁標籤，頂部的圓角讓線條收尾更柔和。其他瀏覽器則由各分頁標籤各自繪製底線。

## 分頁面板 \{#tab-panels\}

頁面內的面板請依循 WAI-ARIA 分頁標籤模式，使用帶有 `role="tablist"` 的容器、帶有 `role="tab"`、`aria-selected` 和 `aria-controls` 的按鈕，以及帶有 `role="tabpanel"` 的區域。樣式表負責呈現各種狀態，`tabs` [行為](/guide/behaviors)負責切換面板，並讓分頁標籤清單支援鍵盤操作。

`tabs` 接收分頁標籤列，並回傳卸載行為的函式。

```js name=app.js
import { tabs } from '@master/ui/behaviors/tabs.js'

const detach = tabs(document.querySelector('.tabs[role="tablist"]'))
```

- **單一 Tab 停駐點。** 只有選取的分頁標籤會進入 Tab 巡覽順序。方向鍵會移到上一個或下一個分頁標籤並選取它，略過停用的分頁標籤，到了兩端則循環切換。<kbd>Home</kbd> 和 <kbd>End</kbd> 分別移到第一個與最後一個分頁標籤。帶有 `aria-orientation="vertical"` 的分頁標籤清單改用上下方向鍵。
- **面板。** 每個分頁標籤以 `aria-controls` 指向自己的面板。選取的分頁標籤會顯示對應面板，其餘面板則加上 `hidden`。
- **值。** 選取另一個分頁標籤時，分頁標籤清單會依序發出可冒泡的 `input` 和 `change` 事件，兩者的 `detail.value` 都是分頁標籤的 `data-value`，若未設定則取分頁標籤文字。行為回傳的函式也有相同的 `value`，可從外部設定它來選取分頁標籤，這不會發出任何事件。
- **沒有腳本時**，只有已選取分頁標籤的面板未加上 `hidden`，也無法切換面板。如果每個分頁標籤都能做成獨立頁面，請在 `nav` 中使用連結。

將 `aria-orientation="vertical"` 加到分頁標籤清單，可在面板旁垂直排列標籤。按上下方向鍵可在標籤之間移動，選取標記位於行內起始邊。標籤與 `aria-controls` 指向的面板必須在同一份文件或同一個 shadow root 裡。移除已選標籤後，會選取下一個可用標籤；若已到末端，則選取前一個。只有焦點原本位於被移除的標籤時，才會跟著移動。

## 可搜尋的面板 \{#searchable-panels\}

在 `tabs()` 的第二個引數傳入 `{ searchable: true }`，或設定框架元件的 `searchable` 屬性，可透過頁內搜尋與片段連結找到文字較多的未選取面板。原生 `beforematch` 會選取該面板對應的分頁標籤，並派送與點擊相同的事件。請把裝飾和間距放在內層元素，讓隱藏的面板不占空間。不支援 `beforematch` 的瀏覽器沿用一般的隱藏行為。

## React、Svelte 和 Vue \{#frameworks\}

`tabs` 元件根據資料呈現分頁標籤清單及面板，以 ID 將各分頁標籤連到對應面板，並掛載行為，讓外部可傳入選取值並取得變更。若分頁標籤是 `nav` 內的連結，直接使用標記即可。執行 `npx master-ui add tabs` 將元件複製到專案中。[React、Svelte 和 Vue](/guide/frameworks)說明元件的實作與用法。
