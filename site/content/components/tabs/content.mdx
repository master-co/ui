Tabs are words on one hairline, the current one underlined in ink. They switch between sibling pages or panels; for a compact choice of values, use a [segmented control](/components/segmented).

Where the browser supports CSS anchor positioning, the underline is one mark that glides to the current tab when `aria-selected` changes, with a softened top so the ink does not end in a hard corner. Elsewhere each tab draws its own underline.

## Tab panels \{#tab-panels\}

For in-page panels, follow the WAI-ARIA tabs pattern: a `role="tablist"` container, `role="tab"` buttons with `aria-selected` and `aria-controls`, and `role="tabpanel"` regions. The stylesheet draws every state; the `tabs` [behavior](/guide/behaviors) switches the panels and gives the tablist its keys.

`tabs` takes the tablist, the element with the `tabs` class and `role="tablist"`, has no options, and returns the function that detaches it.

```js name=app.js
import { tabs } from '@master/ui/behaviors/tabs.js'

const detach = tabs(document.querySelector('.tabs[role="tablist"]'))
```

- **One tab stop.** The selected tab is the one in the tab order. The arrow keys move to the tab before or after and select it, skipping disabled tabs and wrapping at the ends; <kbd>Home</kbd> and <kbd>End</kbd> go to the first and the last. A tablist with `aria-orientation="vertical"` takes the up and down arrows instead.
- **Panels.** A tab names its panel in `aria-controls`. The panel of the selected tab is shown and the others get `hidden`.
- **The value.** Selecting a tab dispatches a bubbling `change` from the tablist with `detail.value`: the tab's `data-value`, or its text. The function the behavior returns has the same `value`; set it to select a tab from outside.
- **Without the script** the selected tab's panel is the only one without `hidden`, and nothing switches. Use links in a `nav` when each tab can be a page.

## React, Svelte and Vue \{#frameworks\}

The `tabs` component renders a tablist and its panels from data, joins each tab to its panel by id, attaches the behavior and passes the selected tab in and out. Tabs that are links in a `nav` stay markup. Copy it into the project with `npx master-ui add tabs`; [React, Svelte and Vue](/guide/frameworks) says how the components are built and used.
