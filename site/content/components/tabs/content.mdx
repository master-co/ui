Tabs are words on one hairline, the current one underlined in ink. They switch between sibling pages or panels; for a compact choice of values, use a [segmented control](/components/segmented).

Where the browser supports CSS anchor positioning, the underline is one mark that glides to the current tab when `aria-selected` changes, with a softened top so the ink does not end in a hard corner. Elsewhere each tab draws its own underline.

## Tab panels \{#tab-panels\}

For in-page panels, follow the WAI-ARIA tabs pattern: a `role="tablist"` container, `role="tab"` buttons with `aria-selected` and `aria-controls`, and `role="tabpanel"` regions. The stylesheet draws every state; switching panels and arrow-key focus need a small script, which the framework bindings will provide.
