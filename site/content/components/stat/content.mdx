A stat is one figure and what it measures: a quiet label, the value in large tabular figures, and an optional change beside it. It has no surface of its own. Put it in a [card](/components/card), or set several in a row. A figure that is a cost is a [price](/components/price).

## The change \{#the-change\}

`stat-delta` sits on the value's baseline. `stat-delta-up` and `stat-delta-down` add a status ink, and take an arrow icon before the figure; without either it is a neutral note.

For a rate that changes from 40% to 45%, see [percentage points and relative change](/guide/reporting-values#percentage-points).

The modifiers describe the direction, and the color follows the direction: up is the success ink, down the danger ink. When a fall is good news, as with an error rate or a cost, say so in words, or leave the delta neutral. The arrow and the number carry the meaning; the hue only agrees with them.

## Accessibility \{#accessibility\}

- The arrow is an icon with `aria-hidden="true"` and is not announced. Write the direction into the text a screen reader gets, for example with a visually hidden "up" before the number.
- Figures use tabular numerals, so a value that updates does not shift the text around it.
- Several stats that describe one thing read well as a `<dl>`, with `stat-label` on the `<dt>` and the row inside the `<dd>`.
