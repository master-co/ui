내비게이션 바는 페이지나 앱 상단에서 브랜드, 주요 링크, 몇 가지 동작 버튼을 제공하는 컴포넌트입니다. 페이지 맨 위에서는 막대에 별도의 표면 효과가 없어 페이지 전체가 하나의 표면처럼 보입니다. 스크롤하는 콘텐츠가 막대 아래를 지나가면 막대가 가는 테두리와 짧은 그림자가 있는 서리 낀 유리 패널처럼 바뀝니다. 스크롤 상태 컨테이너 쿼리가 막대가 상단에 붙었는지 감지하므로 스크립트로 스크롤을 감시할 필요가 없습니다.

막대는 `position: sticky` 방식으로 스크롤 컨테이너 상단에 붙습니다. 대부분의 레이아웃에서는 페이지가 스크롤 컨테이너입니다. 브라우저가 스크롤 상태 쿼리를 지원하지 않으면 패널이 항상 표시됩니다.

내비게이션 바는 자체 표면 효과와 상단에 붙었을 때의 상태, 링크가 숨겨지는 너비를 담당합니다. 주변 요소의 구성은 레이아웃에서 정합니다. 메뉴, 두 번째 동작 버튼, 드로어가 포함된 전체 사이트 헤더가 필요하면 [헤더](/blocks/header) 블록을 복사합니다. 사이드바가 있는 페이지에 막대를 배치하는 방법은 [앱 셸](/pages/app-shell) 레이아웃을 참고합니다.

## 좁은 내비게이션 바 \{#narrow\}

막대는 크기 컨테이너이기도 합니다. 막대 너비가 36rem 미만이면 `navbar-nav`가 숨겨지고 `navbar-toggle`이 표시됩니다. 36rem 이상에서는 반대로 표시됩니다. 토글 버튼을 같은 링크가 들어 있는 [드로어](/components/dialog#drawer)나 [메뉴](/components/menu)에 연결합니다.

## 읽기 진행률 \{#progress\}

막대 안에 `navbar-progress` 요소를 넣으면 페이지를 스크롤할 때 막대 하단의 가는 선이 전경색으로 채워집니다. 루트 스크롤러의 스크롤 타임라인을 따라 페이지의 진행률을 표시하며, 브라우저가 스크롤 기반 애니메이션을 지원할 때만 나타납니다.

```html
<header class="navbar">
  …
  <div class="navbar-progress" role="presentation"></div>
</header>
```

## 접근성 \{#accessibility\}

- 막대에는 `<header>` 요소를 사용하고, 링크 목록에는 레이블을 지정한 `<nav>` 요소를 사용합니다. 현재 페이지의 링크에는 `aria-current="page"`를 지정합니다. 이 표시가 있는 링크만 전경색으로 표시됩니다.
- 토글에는 일반 버튼을 사용합니다. `popovertarget` 또는 `command`로 메뉴나 드로어를 열면 스크립트가 필요 없습니다.
- 패널은 장식 요소입니다. `prefers-reduced-transparency`에서는 불투명하게 표시되며, 강제 색상 모드에서는 캔버스 색으로 표시되고 아래에 선이 생깁니다.
- 상단에 붙는 막대는 페이지 윗부분을 가립니다. 제목으로 이동하는 링크를 따라갔을 때 제목이 막대에 가려지지 않도록 스크롤러의 `scroll-padding-top`을 막대 높이로 설정합니다.
