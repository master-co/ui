导航栏位于页面或应用顶部，包含品牌标识、主要链接和少量操作。页面处于顶部时，导航栏完全透明，整个页面呈现为一块连续的表面。内容滚到导航栏下方后，导航栏呈现磨砂玻璃质感，并带有细边线和短阴影。滚动状态容器查询负责判断导航栏何时吸附，无需脚本监听滚动。

导航栏通过 `position: sticky` 吸附在滚动容器顶部。在大多数布局中，滚动容器就是页面。浏览器不支持滚动状态查询时，导航栏始终显示磨砂玻璃背景。

导航栏组件只负责栏本身的材质、吸附状态和隐藏链接的宽度阈值。需要带菜单、第二个操作和抽屉的完整网站页头时，复制[页头](/blocks/header)区块。要将导航栏放在带侧栏的页面中，请参阅[应用框架](/pages/app-shell)布局。

## 窄导航栏 \{#narrow\}

导航栏也是一个尺寸容器。栏宽小于 36rem 时，`navbar-nav` 隐藏，`navbar-toggle` 显示。栏宽达到或超过 36rem 时，两者的显示状态互换。将切换按钮指向包含相同链接的[抽屉](/components/dialog#drawer)或[菜单](/components/menu)。

## 悬浮 \{#floating\}

## 阅读进度 \{#progress\}

在导航栏内放置一个 `navbar-progress`，栏底的墨色细线便会随页面滚动逐渐填满。细线由根滚动容器上的滚动时间线驱动，反映整个页面的滚动进度，仅在浏览器支持滚动驱动动画时显示。

```html
<header class="navbar">
  …
  <div class="navbar-progress" role="presentation"></div>
</header>
```

## 无障碍 \{#accessibility\}

- 导航栏使用 `<header>`，链接组使用带标签的 `<nav>`。用 `aria-current="page"` 标记当前页面，只有当前页链接会以墨色显示。
- 切换控件使用普通按钮。通过 `popovertarget` 或 `command` 打开菜单或抽屉，无需脚本。
- 导航栏背景仅用于装饰。启用 `prefers-reduced-transparency` 时，背景完全不透明。在强制颜色模式下，背景使用画布色，底部加一条线。
- 吸附的导航栏会覆盖页面顶部。将滚动容器的 `scroll-padding-top` 设为导航栏高度，确保通过链接跳转时目标标题不会被遮住。
