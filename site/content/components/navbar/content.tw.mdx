導覽列位於網頁或應用程式頂端，放置品牌標誌、主要連結和幾個操作按鈕。頁面停在頂端時，導覽列的背景完全透明，與頁面背景融為一體。內容捲動到導覽列下方後，導覽列就會呈現霧面玻璃效果，帶有一條細線和短陰影。捲動狀態容器查詢會判斷導覽列是否已吸附，無須用腳本監聽捲動。

導覽列透過 `position: sticky` 吸附在捲動容器頂端。在多數版面配置中，這個容器就是頁面。瀏覽器若不支援捲動狀態容器查詢，面板會一律顯示。

導覽列元件只處理自身的背景效果、吸附狀態，以及隱藏連結的寬度門檻。若需要含選單、第二個操作和抽屜的完整網站頁首，請複製[頁首](/blocks/header)區塊。若要在有側邊欄的頁面放置導覽列，請參考[應用程式框架](/pages/app-shell)的版面配置。

## 窄版導覽列 \{#narrow\}

導覽列也是尺寸容器。列寬小於 36rem 時，`navbar-nav` 會隱藏，`navbar-toggle` 會顯示。列寬為 36rem 以上時，兩者的顯示狀態互換。請將切換按鈕指向包含相同連結的[抽屜](/components/dialog#drawer)或[選單](/components/menu)。

## 閱讀進度 \{#progress\}

在導覽列內放入 `navbar-progress`，底緣就會出現一條採用主題文字色的細線，並隨頁面捲動逐漸延伸。它由根捲動容器的捲動時間軸驅動，顯示整個頁面的捲動進度，且只會在支援捲動驅動動畫的瀏覽器中顯示。

```html
<header class="navbar">
  …
  <div class="navbar-progress" role="presentation"></div>
</header>
```

## 無障礙 \{#accessibility\}

- 導覽列使用 `<header>`，連結則放在有標籤的 `<nav>` 內。用 `aria-current="page"` 標記目前頁面，只有加上這個標記的連結才會使用主題文字色。
- 切換控制項是一般按鈕。透過 `popovertarget` 或 `command` 開啟選單或抽屜，無須使用腳本。
- 面板僅供裝飾。使用者偏好減少透明效果（`prefers-reduced-transparency`）時，面板會變成不透明。在強制色彩模式下，面板使用畫布色，底部加上一條線。
- 吸附的導覽列會蓋住頁面頂端。將捲動容器的 `scroll-padding-top` 設為導覽列高度，避免點擊標題連結後，目標標題被導覽列遮住。
