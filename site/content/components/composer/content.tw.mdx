訊息編輯器用來撰寫訊息或提示詞。略微浮起的面板上有一個無框欄位，會隨文字增高。下方是一排低調的工具，最末端是傳送按鈕。欄位取得焦點時，面板會像[輸入欄位](/components/input)一樣，以一道深色輪廓和柔和的光暈顯示焦點。

欄位是套用 `field-sizing: content` 的 `<textarea>`，從一行開始，最多增高到十行，之後便在欄位內捲動。用 `--composer-rows` 和 `--composer-max-rows` 分別調整起始與最大行數。如果瀏覽器無法依內容調整欄位大小，欄位會固定顯示三行，超出的內容可捲動查看。

按鈕距離面板邊緣 8px，並採用同心圓角，因此傳送按鈕的弧度會貼合面板的圓角。

## 停用 \{#disabled\}

欄位停用時，面板會呈現內嵌的外觀，也不再浮起。請一併停用傳送按鈕，並在預留文字或編輯器旁說明原因。

## 按 Enter 傳送 \{#enter\}

在多行文字欄位中，按 Enter 預設會換行。若要讓 Enter 傳送、Shift+Enter 換行，只需加上一個事件監聽器，並在輸入法組字期間略過這項處理。

```js
field.addEventListener('keydown', event => {
  if (event.key === 'Enter' && !event.shiftKey && !event.isComposing) {
    event.preventDefault()
    field.form.requestSubmit()
  }
})
```

各產品的按鍵慣例不同，請在工具列旁用 `composer-hint` 說明操作方式。

## 無障礙 \{#accessibility\}

- 請用 `aria-label` 或編輯器上方可見的 `<label for>` 為欄位提供可存取名稱。預留文字無法提供這個名稱。
- 編輯器是 `<form>`，因此傳送按鈕可以送出表單，密碼管理工具或擴充功能也能辨識它。
- 圖示按鈕應提供 `aria-label`。按 Tab 會先到欄位，再依閱讀順序移到各項工具。
- 點擊面板的內距區域時，欄位不會自動取得焦點。若要讓使用者點擊面板任一處時，欄位都能取得焦點，請用 `<label>` 包住欄位。
- 在觸控螢幕上，欄位的文字大小為 16px，因此 iOS 不會在欄位取得焦點時放大頁面。
