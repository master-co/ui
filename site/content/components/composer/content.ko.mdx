메시지 입력창은 메시지나 프롬프트를 입력하는 곳입니다. 살짝 떠 있는 표면에는 별도의 테두리 없이 텍스트에 따라 높이가 늘어나는 입력란이 있고, 그 아래에는 눈에 덜 띄는 도구들이 한 줄로 배치되며 맨 끝에 전송 버튼이 놓입니다. [입력 컴포넌트](/components/input)와 마찬가지로 입력란에 포커스가 오면 표면에 잉크색 윤곽선 하나와 은은한 빛 테두리가 나타납니다.

입력란은 `field-sizing: content`가 적용된 `<textarea>`입니다. 한 줄에서 시작해 최대 10줄까지 늘어나며, 그 이후에는 스크롤됩니다. 최소 줄 수는 `--composer-rows`로, 최대 줄 수는 `--composer-max-rows`로 바꾸세요. 브라우저가 내용에 맞춰 입력란의 크기를 조절할 수 없으면 높이가 3줄로 유지되며, 그 이상은 스크롤됩니다.

버튼은 표면 가장자리에서 8px 안쪽에 배치되며, 모서리 곡선은 표면의 모서리와 같은 중심을 기준으로 그려집니다. 그래서 전송 버튼의 모서리 곡선이 표면의 모서리 곡선을 따라갑니다.

## 첨부 항목 \{#attachments\}

## 비활성 상태 \{#disabled\}

입력란을 비활성화하면 표면이 오목하게 들어가고 더 이상 떠오르지 않습니다. 전송 버튼도 함께 비활성화하고, 그 이유를 플레이스홀더나 메시지 입력창 옆에 표시하세요.

## Enter 키로 전송 \{#enter\}

textarea에서 Enter를 누르면 줄바꿈이 입력됩니다. Enter로 전송하고 Shift+Enter로 줄바꿈하려면 이벤트 리스너 하나면 충분합니다. 입력기가 문자를 조합 중일 때는 이 처리를 건너뛰세요.

```js
field.addEventListener('keydown', event => {
  if (event.key === 'Enter' && !event.shiftKey && !event.isComposing) {
    event.preventDefault()
    field.form.requestSubmit()
  }
})
```

제품마다 키 동작이 다르므로 도구 옆에 `composer-hint`를 넣어 Enter로 전송하고 Shift+Enter로 줄을 바꾼다고 안내하세요.

## 접근성 \{#accessibility\}

- 입력란에는 접근 가능한 이름이 필요합니다. `aria-label`을 사용하거나 메시지 입력창 위에 `<label for>` 요소를 배치해 레이블이 보이도록 하세요. 플레이스홀더는 접근 가능한 이름으로 인정되지 않습니다.
- 메시지 입력창은 `<form>`이므로 전송 버튼을 누르면 폼이 제출되며, 비밀번호 관리자나 브라우저 확장 프로그램도 이 폼을 찾을 수 있습니다.
- 아이콘 버튼에는 `aria-label`이 지정됩니다. Tab 키로 이동하면 입력란 다음에 도구가 읽는 순서대로 포커스를 받습니다.
- 표면의 패딩 영역을 클릭하는 것만으로는 입력란에 포커스가 가지 않습니다. 표면 전체를 클릭해 입력란에 포커스를 주려면 입력란을 `<label>` 요소로 감싸세요.
- 터치 화면에서는 입력란의 글자 크기가 16px이므로, 포커스를 받을 때 iOS가 페이지를 확대하지 않습니다.
