A composer is where a message or a prompt is written. A raised sheet holds a bare field that grows with its text, and under it a row of quiet tools with the send button at the end. The sheet draws the field's focus, one ink contour and a soft halo, the way an [input](/components/input) does.

The field is a `<textarea>` with `field-sizing: content`: it starts at one line and grows to ten, then scrolls. Set `--composer-rows` and `--composer-max-rows` to change either end. Where the browser cannot size a field by its content, it keeps three lines and scrolls from there.

Buttons sit 8px in from the sheet's edge and take the concentric corner, so the send button's curve follows the sheet's.

## Attachments \{#attachments\}

`composer-attachments` is a wrapping row above the field for what goes with the message: [chips](/components/chip) for files, or thumbnails.

## Disabled \{#disabled\}

When the field is disabled the sheet settles into a well and stops lifting. Disable the send button with it, and say why in the placeholder or beside the composer.

## Sending with Enter \{#enter\}

A textarea takes Enter as a new line. To send on Enter and keep Shift+Enter for a line, one listener is enough; skip it while an input method is composing.

```js
field.addEventListener('keydown', event => {
  if (event.key === 'Enter' && !event.shiftKey && !event.isComposing) {
    event.preventDefault()
    field.form.requestSubmit()
  }
})
```

Say so beside the tools with a `composer-hint`, since the convention differs between products.

## Accessibility \{#accessibility\}

- The field needs a name: `aria-label`, or a visible `<label for>` above the composer. A placeholder is not a name.
- The composer is a `<form>`, so the send button submits it and a password manager or an extension can find it.
- Icon buttons carry `aria-label`. The tools are in the tab order after the field, in reading order.
- Clicking the sheet's padding does not focus the field by itself; if you want the whole sheet to be the target, wrap the field in a `<label>`.
- On touch screens the field's text is 16px, so iOS does not zoom the page on focus.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `composer` | The sheet around the field and its tools |
| `composer-field` | The `<textarea>`, growing with its content |
| `composer-attachments` | A wrapping row above the field |
| `composer-toolbar` | The row of tools under the field |
| `composer-end` | The group pushed to the end of the toolbar |
| `composer-hint` | A quiet note beside the tools |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--composer-rows` | `1` | Lines the field starts with |
| `--composer-max-rows` | `10` | Lines after which the field scrolls |
| `--composer-radius` | `var(--radius-surface)` | The sheet's corner |
| `--composer-inset` | `.5rem` | The sheet's padding, and the inset its buttons' corners follow |
