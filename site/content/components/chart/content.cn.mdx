图表把数值画成折线、面积、条形、饼图、环形图、同心圆环、雷达图或散点图。整个图表是一个 SVG，会适应所给的宽度：刻度上的内容按百分比定位，无论绘图区拉伸多宽，线条都保持原有粗细，文字也不会被缩放。只有一个数据系列的图表使用墨色，和[进度条](/components/progress)的填充一样；有多个数据系列时，各系列使用[类别](/components/category)的颜色。每个数据点都是一个列表项，用文字说明自己的数值。

## 绘制方式 \{#how-it-is-drawn\}

绘图区是一个没有 `viewBox` 的 `<svg>`：宽度与可用空间相同，高度为 `--chart-height`，未另行指定时为 14rem。细线、刻度标签、条形和圆点都以绘图区的百分比写入，因此位于 `x="42%"` 的条形在任何宽度下都保持在 42% 处，同时圆角半径和文字大小保持不变。

只有必须用路径绘制的图形，即折线、面积和扇区，才画在 `chart-canvas` 中。它是一个嵌套的 SVG，坐标框为 100 × 100，并拉伸到与绘图区同样大小。其中的描边不随之缩放，因此无论卡片宽窄，折线的粗细都是 `--chart-stroke`。

宽度变化时无需测量，也无需重绘，因此服务器、[框架组件](#frameworks)和行为脚本生成的标记完全相同。图表会占满所给的宽度：与其他内容排成一行时，请为它设置宽度，或让它伸展。

## 绘制图表 \{#draw\}

行为脚本把图表写入带有 `chart` 类的元素。`label` 说明图表展示的内容及其单位；`labels` 为刻度上的各个位置命名，每个数据系列在每个位置上各有一个数值。

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

在服务器上，`chartMarkup()` 以字符串形式返回同一个图表，其中的所有文字都已转义；把它放进元素中，页面在任何脚本运行之前就能阅读。`chartLayout()` 以数据形式返回图中的全部内容：刻度及其刻度值、每个数据系列的路径，以及每个数据点及其图形和描述它的句子。

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

在该元素上调用 `chart()` 且不传入数据系列时，行为脚本会按现有标记让图表运作；`@master/ui/behaviors` 中的 `attach()` 会对页面上的每个图表这样做。

## 图表类型 \{#forms\}

每种图表类型都有自己的页面，包含示例和与之相关的选项。

| 类型 | `type` | 用途 |
| --- | --- | --- |
| [折线图](/charts/line) | `line` | 用折线连接各点，呈现前后相连的数值变化。 |
| [面积图](/charts/area) | `area` | 在折线下方淡染同色，可单独呈现，也可堆叠成总量。 |
| [条形图](/charts/bar) | `bar` | 以立在基线上的条形比较数量，可并排、堆叠或横向排列。 |
| [雷达图](/charts/radar) | `radar` | 在相同的指标上比较少数几个对象，每个对象是一圈围绕中心的轮廓。 |
| [饼图](/charts/pie) | `pie` | 用圆的扇区呈现一个整体由哪些部分组成。 |
| [环形图](/charts/donut) | `donut` | 整体的各个部分围成一圈，中央放一个数字。 |
| [同心圆环](/charts/rings) | `rings` | 少数几个读数，各自在自己的圆环上朝目标填满。 |
| [散点图](/charts/scatter) | `scatter` | 两个指标相互对照，每个对象是一个点。 |

## 数值提示与键盘操作 \{#readout\}

`chart-tip` 是数值提示：先是数据点的名称，然后每个数据系列占一行，包含一道该系列颜色的短线、系列名称和数值。它位于数据点旁空间更大的一侧，并沿自身高度滑动，因此不会离开绘图区，也无需由脚本定位。行为脚本根据数据点的图形所携带的信息填充它，并将数据点的位置以 `--chart-x`、`--chart-y` 和 `--chart-reach` 传递给它。

无论有多少个数据点，绘图区在 Tab 顺序中只占一个停靠点。方向键在数据点之间移动，并显示每个数据点的数值提示；手指沿图表滑动也有同样的效果。

## 图例 \{#legend\}

有两个或更多数据系列的图表带有图例：颜色绝不是区分数据系列的唯一方式。每个图例项是一个包裹复选框的 label，因此可以按 Tab 键到达，按空格键切换；取消勾选后，对应的数据系列从图表中移除，刻度按剩余内容调整，其他系列保持原有颜色。只有一个数据系列的图表没有图例，因为标题已经说明了所画的内容。

`toggle: false` 把图例写成普通列表；`legend: false` 则不生成图例，适用于周围文字已说明各数据系列名称的图表。图表的值是隐藏的数据系列的名称：可从 `chart()` 的返回值读取，也可设置它，从外部隐藏数据系列。

## 颜色 \{#color\}

只有一个数据系列的图表用 `--chart-color` 绘制，即墨色。图表有多个数据系列时，各系列以及整体的各个部分按固定顺序各取一种类别：蓝色、橙色、蓝绿色、紫罗兰色、琥珀色、粉色、绿色和天蓝色。在浅色和深色两种配色方案下，这一顺序中相邻的颜色对常见类型的色觉障碍者而言都能区分开。超过八个后，顺序从头开始，因此请把其余部分归入“其他”，或另画一个图表。

颜色跟随对象本身时，为数据系列指定自己的 `category`：无论 Tokyo 在列表中排在第几位，它在图表、[徽标](/components/badge)和表格行中都是蓝色。状态颜色绝不用来代表数据系列；出现故障的数据系列用文字说明。

## 刻度与数字 \{#scale\}

刻度从零开始，有小于零的数值时从零以下开始，到高于最大值的一个整数为止，大约分四段标出。`min` 和 `max` 可固定任一端，`ticks` 可要求分成其他段数。条形图的刻度应从零开始：条形的长度就是它的数值。

`format` 决定数值提示中和条形末端的数值如何书写，`tickFormat` 决定刻度数字如何书写；刻度数字在 10,000 以下完整写出，超过后采用紧凑写法。两者都接收数字并返回字符串。`locale` 是用于数字的 BCP 47 标签，默认为 `en-US`；由服务器生成图表时请给出它，使两端保持一致。

| 选项 | 默认值 | |
| --- | --- | --- |
| `type` | `'bar'` | `line`、`area`、`bar`、`pie`、`donut`、`rings`、`radar` 或 `scatter` |
| `label` | 无 | 图表展示的内容及其单位，即绘图区的无障碍名称 |
| `labels` | `[]` | 沿刻度排列的名称，或雷达图四周的名称 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，扇区或圆环使用 `value`，散点图使用 `points`；还可选填 `category`、`type` 和圆环的 `max` |
| `stacked` | `false` | 条形或面积上下堆叠 |
| `horizontal` | `false` | 条形横向排列 |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 自动适配，`4` | 刻度的两端，以及大约分几段标出；散点图的横向刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否写出刻度数字；`false` 只保留细线，适用于磁贴中的小图表 |
| `format`, `tickFormat` | 按 locale 的格式 | 数值和刻度数字的书写方式；散点图的横向刻度使用 `xFormat` |
| `dots`, `values` | `false` | 标出折线上的每个数据点；写出每根条形的数值 |
| `current` | 无 | 标有 `aria-current` 的数据点的索引 |
| `legend`, `toggle` | 有两个数据系列时生成，`true` | 是否生成图例，以及图例项是否为复选框 |
| `hole`, `center` | `.7`，无 | 环形图的中空部分，以及环形图或同心圆环中央显示的内容 |
| `hidden` | `[]` | 不显示的数据系列的名称 |
| `locale` | `'en-US'` | 用于数字的 BCP 47 标签 |
| `draw` | 无 | 接管图表的生成：调用时传入隐藏的名称，供自行生成图表的渲染器使用 |

## 不使用脚本 \{#without-a-script\}

## 动态效果 \{#motion\}

图形首次出现时会自行画出：条形依次从基线升起，折线从起点画入，扇区和雷达图的形状从中心展开，圆环逐渐填充。数值提示在数据点之间平滑滑动，而标示数据点的细线、圆点和退为浅色的条形则立即响应，因为高亮必须跟得上手的移动。启用减少动态效果时，没有任何位移动画：图形直接以画好的状态出现，数值提示立即变换位置。

## 平台提供的能力 \{#platform\}

- **条形的圆角和升起效果**由 SVG 形状上的 `clip-path` 实现。不支持用 CSS 形状裁剪 SVG 形状的浏览器会以完整长度绘制方角条形。
- **面积的渐隐**由路径上的 `mask-image` 实现。不支持时，面积为均匀的浅色。
- **圆点的半径**是 CSS 的 `r` 属性，由 `--chart-dot` 设置。不支持时，圆点保持标记中写明的半径。
- **标签的精简**由绘图区主体上的容器查询实现。不支持时，所有标签都保留。
- **画入效果**由 `@starting-style` 实现。不支持时，图形直接以画好的状态出现。

## 图表不够用时 \{#limits\}

图表为几百个图形而设计，每个图形都是读者可以到达的元素。成千上万个数据点、持续流入的数值、缩放、刷选、地图或 K 线图，应交给在 canvas 上绘图的图表引擎。用不着整个图表时，有更小的组件可选：句子中的趋势用[迷你趋势线](/components/sparkline)，单个数字用[统计指标](/components/stat)，单个读数用[计量条](/components/meter)或[仪表盘](/components/gauge)，沿一根条形展示总量的各个部分用[占比分布](/components/breakdown)，呈现大量较小数值的整体规律用[热力图](/components/heatmap)。[图表](/guide/charts)指南说明该选哪一种。

## 无障碍 \{#accessibility\}

- 为 `label` 写一句话，说明测量的内容及其单位：它是绘图区的名称，而绘图区是一个列表。
- 每个数据点都是一个以其数值命名的列表项，例如“Thu: Tokyo 71, Osaka 49”，因此屏幕阅读器像读列表一样读出图表，无需脚本，也无需表格。细线、刻度标签和数值提示对屏幕阅读器隐藏，因为它们只是重复数据点已说明的内容。
- 数值提示是为视觉阅读提供的便利。它在指针悬停、获得焦点和手指触碰时出现，按 <kbd class="kbd">Esc</kbd> 可将其隐藏。
- 颜色从不单独承担含义：数据系列在图例中有名称，数值提示也在数值旁写出系列名称。类别不是状态。
- 获得焦点的数据点，其轮廓画在所属区间、圆点、扇区或圆环上，而不是围绕一个方框。
- 在强制颜色模式下，墨色和细线使用系统颜色，焦点以高亮色绘制。数据系列保持所指定的颜色，因此请在图例中写出它们的名称。
- 在任何语言中，刻度都从左侧开始。名称、数值和图例跟随页面的文字方向。

## React、Svelte 和 Vue \{#frameworks\}

`chart` 组件根据 `chartLayout()` 生成图表，因此服务器发送的初始 HTML 中就包含图表；组件还会绑定行为脚本，由它填充数值提示并响应键盘操作。组件以 prop 的形式接收上文的选项，它的值是隐藏的数据系列的名称。使用 `npx master-ui add chart` 将组件复制到项目中，参见 [React、Svelte 和 Vue](/guide/frameworks) 了解这些组件的实现和用法。
