图表用适合读者所问问题的形式呈现数据，包括折线图、柱状图、环形图、直方图、漏斗图，[总计二十多种](#forms)。各种形式都使用一个适应可用宽度的 SVG：按刻度定位的元素使用百分比，绘图区无论拉伸多宽，线条粗细和文字大小都保持不变。单个数据系列使用墨色绘制，就像[进度条](/components/progress)用墨色填充一样。多个数据系列则使用[类别](/components/category)配色。每个数据点都是一个列表项，用文字说明其数值。

## 绘制原理 \{#how-it-is-drawn\}

绘图区是一个没有 `viewBox` 的 `<svg>`，宽度等于可用宽度，高度由 `--chart-height` 设置，默认是 14rem。细线、刻度、柱子和圆点都以绘图区的百分比定位，因此设为 `x="42%"` 的柱子在任何宽度下都位于 42% 处，圆角半径和文字大小也保持不变。

只有折线、面积和扇区这类必须用路径表示的图形才绘制在 `chart-canvas` 中。它是一个坐标范围为 100 × 100 的嵌套 SVG，会拉伸以填满绘图区。描边不会随其缩放，因此无论卡片宽窄，线条宽度都是 `--chart-stroke`。

宽度变化时无需测量或重绘，因此服务器、[框架组件](#frameworks)和行为生成的标记相同。图表会占满分配给它的宽度。如果图表与其他元素并排排列，请为它设置宽度，或允许它伸展。

## 绘制图表 \{#draw\}

图表行为会把图表写入类名为 `chart` 的元素。`label` 说明图表展示的内容及其单位，`labels` 为刻度上的各个位置命名，每个数据系列在每个位置上各有一个数值。

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

在服务器上，`chartMarkup()` 将同一个图表作为字符串返回，其中的所有文本都经过转义。将它写入元素后，页面在脚本运行前就可以阅读。`chartLayout()` 以数据形式返回绘图所需的信息，包括标尺及其刻度、每个数据系列的路径，以及每个数据点的图形标记和描述语句。

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

在该元素上调用 `chart()` 时，如果不传入数据系列，行为会直接接管已有标记。使用 `@master/ui/behaviors` 中的 `attach()` 可为页面上的所有图表附加行为。

### 只加载页面用到的图表形式 \{#forms-only\}

`chart.js` 包含所有图表形式，压缩并经 gzip 打包后约为 16 kB。如果页面只绘制一两种图表，可以只加载所需形式。`chart-core.js` 是不含任何图表形式的核心模块，约为 6 kB。每种图表形式都是可传给 `chartForms()` 的模块。折线图、面积图和柱状图共用标尺，合计增加约 2 kB，其余图表形式各不到 1 kB。

```js name=app.js
import { chartCore, chartForms } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
chartCore(document.querySelector('.chart'), { type: 'line', label, labels, series })
```

| `chart-scatter.js` | `scatter` |

## 图表形式 \{#forms\}

每种图表形式都有独立页面，列出示例和相关选项。

| 图表形式 | `type` | 适用场景 |
| --- | --- | --- |
| [折线图](/charts/line) | `line` | 逐点连线，展示数值随顺序变化的趋势。 |
| [面积图](/charts/area) | `area` | 用与折线同色的浅色填充线下区域，可单独展示，也可堆叠展示总量。 |
| [斜率图](/charts/slope) | `slope` | 通过连线的斜率和交叉，展示两个时点之间哪些数值上升、下降或相互超越。 |
| [排名变化图](/charts/bump) | `bump` | 展示若干对象的排名变化，一个对象超越另一个对象时，连线会交叉。 |
| [柱状图](/charts/bar) | `bar` | 用共用基线的柱子比较数值，可并排、堆叠，也可横向绘制为条形图。 |
| [雷达图](/charts/radar) | `radar` | 按相同指标比较若干对象，每个对象在同一中心周围形成一条轮廓线。 |
| [瀑布图](/charts/waterfall) | `waterfall` | 用逐步增减的柱子，展示起始值如何变为最终值。 |
| [区间图](/charts/range) | `range` | 展示每个区间的跨度及其起止值。 |
| [哑铃图](/charts/dumbbell) | `dumbbell` | 用一条线连接每个对象的两个数值，突出两者的差距。 |
| [饼图](/charts/pie) | `pie` | 用圆形中的各个扇区展示整体的构成。 |
| [环形图](/charts/donut) | `donut` | 围绕中心的一个数值展示整体的各个组成部分。 |
| [多环进度图](/charts/rings) | `rings` | 用独立的圆环展示每项读数占其总量的比例。 |
| [马赛克图](/charts/marimekko) | `marimekko` | 用柱宽表示各组总量，再将每根柱子划分为各个组成部分。 |
| [漏斗图](/charts/funnel) | `funnel` | 展示同一流程中依次收窄的各个阶段。 |
| [华夫格图](/charts/waffle) | `waffle` | 用 100 个方格展示整体，每格代表 1%。 |
| [矩形树图](/charts/treemap) | `treemap` | 用多个矩形展示整体的各个部分，每个矩形的面积与其占比成正比。 |
| [旭日图](/charts/sunburst) | `sunburst` | 用两层圆环展示整体、各组成部分及其下一级构成。 |
| [直方图](/charts/histogram) | `histogram` | 按易读的整值划分区间，用柱高表示每个区间内的观测数量，展示数据分布。 |
| [箱线图](/charts/box) | `box` | 每组用五个统计量概括分布，通过箱体、中位线和须呈现。 |
| [热力图](/charts/heatmap) | `heatmap` | 展示两个维度上的数据规律，用单元格颜色深浅表示数值大小。 |
| [散点图](/charts/scatter) | `scatter` | 用两个指标分别确定点的位置，每个点代表一个对象。 |

折线、面积和柱子共用同一个标尺，可以绘制在同一张图表中。为数据系列单独设置 `type`，即可按该类型绘制，例如在柱子上叠加折线。

## 数据提示与键盘操作 \{#readout\}

`chart-tip` 是数据提示，先显示数据点名称，再为每个数据系列各显示一行，列出对应颜色的短线、系列名称和数值。提示框放在数据点旁空间较大的一侧，并可在自身高度范围内上下移动，因此始终位于绘图区内，无需脚本计算提示框的位置。行为从数据点的图形标记中读取内容，并通过 `--chart-x`、`--chart-y` 和 `--chart-reach` 传递数据点的位置。

无论有多少数据点，整个绘图区在 Tab 顺序中只占一个焦点位置。按方向键可在数据点之间移动并查看各点的数据提示，沿图表滑动手指也可以逐点查看。

## 图例 \{#legend\}

包含两个或更多数据系列的图表带有图例，读者可以根据名称区分各个系列。每个图例项都是包裹复选框的标签，可用 Tab 键聚焦，用空格键切换。取消选中后，对应的数据系列会从图表中隐藏，标尺会适配剩余数据，其他系列的颜色保持不变。只有一个数据系列时无需图例，标题已经说明了绘制内容。

`toggle: false` 将图例呈现为普通列表。若图表周围的文字已列出各数据系列的名称，可以用 `legend: false` 省略图例。图表的值是隐藏的数据系列名称列表，可以从 `chart()` 的返回值中读取，也可以从外部设置它来隐藏数据系列。

## 颜色 \{#color\}

只有一个数据系列时，图表使用 `--chart-color` 指定的墨色绘制。多个数据系列或整体的各组成部分依次使用固定的类别配色：蓝色、橙色、蓝绿色、紫色、琥珀色、粉色、绿色和天蓝色。在两种配色方案下，常见色觉障碍的用户都能区分该顺序中相邻的颜色。超过八种后，配色会从头循环，可将剩余项目归入“其他”，或另绘一张图表。

如果某个对象需要始终使用同一种颜色，请为对应的数据系列指定 `category`。例如，不论东京在列表中排第几，它在图表、[徽章](/components/badge)和表格对应行中都使用蓝色。状态色不能用来标识数据系列。数据系列出现异常时，用文字注明状态。

## 标尺与数值 \{#scale\}

标尺从零开始，有负值时则从零以下开始，终点是高于最大值的易读整值，通常划分为约四个间隔。`min` 和 `max` 可固定两端，`ticks` 可指定其他间隔数量。柱状图的标尺应从零开始，因为柱长代表数值大小。

`format` 用于设置数据提示和柱子末端的数值格式，`tickFormat` 用于设置刻度数字的格式。刻度数字小于 10,000 时完整显示，超过 10,000 时使用紧凑格式。两者都接收数值并返回字符串。`locale` 是用于数字格式化的 BCP 47 语言标签，默认值为 `en-US`。由服务器生成图表时请指定它，以确保两端格式一致。

## 动效 \{#motion\}

图形标记首次出现时会逐步绘出：柱子依次从基线升起，折线从起点向前绘制，扇区和雷达图轮廓从中心展开，圆环逐渐填满。数据提示会在数据点之间滑动，细线、圆点和柱子的淡化则立即更新，让高亮跟上操作。启用减少动态效果的偏好后，图形标记直接以完整状态呈现，数据提示也会立即切换位置。

## 浏览器原生功能 \{#platform\}

- **柱子的圆角和上升动效**通过 SVG 图形上的 `clip-path` 实现。如果浏览器不支持用 CSS 形状裁剪 SVG 图形，柱子会以直角和完整长度显示。
- **面积的渐隐效果**通过路径上的 `mask-image` 实现。缺少这项支持时，面积会以均匀的浅色填充。
- **圆点半径**由 CSS `r` 属性控制，并通过 `--chart-dot` 设置。浏览器不支持该属性时，圆点会保留标记中指定的半径。
- **减少标签数量**通过绘图区主体上的容器查询实现。浏览器不支持容器查询时，会保留所有标签。
- **入场绘制动效**通过 `@starting-style` 实现。浏览器不支持时，图形标记会直接以完整状态呈现。

## 何时需要其他图表方案 \{#limits\}

图表组件适合绘制几百个图形标记，每个标记都是读者可以访问的元素。如果要展示数千个点或实时流入的数据，或者需要缩放、刷选、地图或蜡烛图，请使用基于画布绘制的图表引擎。更简单的场景可以用更小的组件：用[迷你折线图](/components/sparkline)在句子中展示趋势，用[统计值](/components/stat)展示单个数字，用[计量条](/components/meter)或[仪表盘](/components/gauge)展示单项读数，用[构成条](/components/breakdown)在一根条中展示总量构成，或用[热力图](/components/heatmap)呈现大量小数值之间的变化规律。[图表指南](/guide/charts)介绍了如何选择。

## 无障碍 \{#accessibility\}

- 用一句话为 `label` 说明测量的内容及其单位。这句话是绘图区的无障碍名称，绘图区以列表的形式呈现。
- 每个数据点都是一个列表项，名称包含该点的数值，例如 "Thu: Tokyo 71, Osaka 49"。屏幕阅读器可以像读取普通列表一样读取图表，无需脚本或表格。细线、刻度和数据提示会对屏幕阅读器隐藏，因为这些信息已由数据点提供。
- 数据提示便于直接查看数值。在悬停、聚焦或手指触碰时显示，按 <kbd class="kbd">Esc</kbd> 隐藏。
- 除颜色外，图例还会标明数据系列的名称，数据提示也会在数值旁列出系列名称。类别与状态各有独立含义。
- 数据点获得焦点时，焦点轮廓沿对应的带状区域、圆点、扇区或圆环绘制，不包围外接矩形。
- 在强制颜色模式下，墨色和细线采用系统颜色，焦点轮廓使用系统高亮色。各数据系列会保留指定的颜色，因此请在图例中标明系列名称。
- 在所有语言下，标尺都从左侧开始。名称、数值和图例遵循页面的文字方向。

## React、Svelte 和 Vue \{#frameworks\}

`chart` 组件根据 `chartLayout()` 生成图表，因此服务器首次发送的 HTML 就包含图表。组件还会附加行为，用于填充数据提示和响应键盘操作。它将上面的选项作为 props 接收，其值为隐藏的数据系列名称列表。使用 `npx master-ui add chart` 将组件复制到项目中。[React、Svelte 和 Vue](/guide/frameworks)介绍了这些组件的实现和用法。

<FrameworkSource name="chart" />

如果复制的组件只绘制折线图、面积图或条形图，可以将原本从 `chart.js` 的导入改成图表核心与 Cartesian 图形。所需类型也从 `chart-core.js` 导入，并在模块层级注册图形。

```js
import { chartCore as chart, chartForms, chartLayout } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
```

导入别名让复制的组件沿用原有的行为绑定。服务器使用 `chartLayout()` 绘制，绑定后可用方向键在数据点之间移动，并用 Escape 关闭读数提示。
