차트는 독자가 확인하려는 내용에 맞춰 수치를 그립니다. 꺾은선 차트, 막대 차트, 도넛 차트, 히스토그램, 퍼널 차트 등 [20가지가 넘는 형태](#forms)를 지원합니다. 모든 형태는 주어진 너비에 맞는 하나의 SVG로 그립니다. 눈금을 따르는 요소는 백분율로 배치하고, 플롯이 아무리 늘어나도 선 두께와 텍스트 크기는 그대로 유지합니다. 계열이 하나면 [진행률 표시줄](/components/progress)의 채움과 같은 잉크 색상을 쓰고, 여러 계열에는 [카테고리](/components/category) 색상을 씁니다. 각 데이터 점은 그 값을 문장으로 설명하는 목록 항목입니다.

## 렌더링 방식 \{#how-it-is-drawn\}

플롯은 `viewBox`가 없는 `<svg>`입니다. 너비는 주어진 공간에 맞추고 높이는 `--chart-height`로 정합니다. 기본값은 14rem입니다. 가는 안내선, 눈금, 막대, 점은 플롯에 대한 백분율로 배치합니다. 따라서 `x="42%"`에 놓인 막대는 너비와 상관없이 42% 위치에 있고, 모서리 반지름과 텍스트 크기도 그대로 유지됩니다.

선, 영역, 조각처럼 경로가 필요한 요소만 `chart-canvas`에 그립니다. 이 중첩 SVG는 100×100 좌표 영역을 플롯 크기에 맞춰 늘립니다. 선 두께는 함께 늘어나지 않으므로 좁은 카드와 넓은 카드에서 모두 `--chart-stroke`로 지정한 두께를 유지합니다.

너비가 바뀌어도 크기를 다시 측정하거나 차트를 다시 그릴 필요가 없으므로 서버, [프레임워크 컴포넌트](#frameworks), 동작 코드가 모두 같은 마크업을 생성합니다. 차트는 주어진 너비를 채웁니다. 여러 요소를 가로로 배치할 때는 차트에 너비를 지정하거나 남은 공간을 채우도록 설정합니다.

## 차트 그리기 \{#draw\}

동작 코드는 `chart` 클래스가 있는 요소에 차트를 생성합니다. `label`에는 차트가 보여 주는 내용과 단위를 적습니다. `labels`에는 눈금의 각 위치에 붙일 이름을 지정하고, 각 계열에는 위치마다 값 하나를 넣습니다.

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

서버에서는 `chartMarkup()`이 텍스트를 모두 이스케이프해 동일한 차트를 문자열로 반환합니다. 이 문자열을 요소에 넣으면 스크립트가 실행되기 전에도 차트를 읽을 수 있습니다. `chartLayout()`은 눈금 범위와 눈금값, 계열별 경로, 그리고 각 데이터 점과 그 표시 요소 및 설명 문장을 데이터로 반환합니다.

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

계열을 전달하지 않고 해당 요소에 `chart()`를 호출하면 기존 차트 마크업에 동작을 연결합니다. `@master/ui/behaviors`의 `attach()`는 페이지의 모든 차트에 같은 동작을 연결합니다.

### 필요한 차트 형태만 불러오기 \{#forms-only\}

`chart.js`에는 모든 형태가 들어 있으며, 축소 후 gzip으로 압축하면 약 16 kB입니다. 한두 가지 형태만 그리는 페이지에서는 필요한 형태만 불러올 수 있습니다. `chart-core.js`에는 차트의 기본 기능만 들어 있으며 크기는 약 6 kB입니다. 각 형태는 `chartForms()`에 전달하는 모듈입니다. 꺾은선, 영역, 막대 차트는 같은 눈금 체계를 공유하므로 한 모듈에서 함께 제공하며, 이 모듈을 추가하면 약 2 kB가 늘어납니다. 나머지 형태는 각각 1 kB 미만입니다.

```js name=app.js
import { chartCore, chartForms } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
chartCore(document.querySelector('.chart'), { type: 'line', label, labels, series })
```

| 모듈 | 지원 형태 |
| --- | --- |
| `chart-cartesian.js` | `line`, `area`, `bar` |
| `chart-scatter.js` | `scatter` |
| `chart-pie.js` | `pie`, `donut` |
| `chart-rings.js`, `chart-radar.js`, `chart-sunburst.js` | `rings`, `radar`, `sunburst` |
| `chart-waterfall.js`, `chart-range.js` | `waterfall`; `range`, `dumbbell` |
| `chart-slope.js`, `chart-bump.js` | `slope`, `bump` |
| `chart-marimekko.js`, `chart-funnel.js`, `chart-waffle.js`, `chart-treemap.js` | `marimekko`, `funnel`, `waffle`, `treemap` |
| `chart-histogram.js`, `chart-box.js`, `chart-heatmap.js` | `histogram`, `box`, `heatmap` |

등록된 모듈에서 지원하지 않는 유형을 지정하면 가져와야 할 모듈을 알려 주는 오류가 발생해 누락을 바로 확인할 수 있습니다.

## 차트 형태 \{#forms\}

| --- | --- | --- |
| [꺾은선 차트](/charts/line) | `line` | 이어지는 값을 점과 점 사이의 선으로 표시합니다. |
| [영역 차트](/charts/area) | `area` | 선 아래를 같은 색으로 옅게 채웁니다. 계열 하나를 표시하거나 여러 계열을 쌓아 합계를 나타냅니다. |

| [폭포 차트](/charts/waterfall) | `waterfall` | 시작값이 최종값에 이르기까지의 증감을 계단식으로 보여 줍니다. |

| [원형 차트](/charts/pie) | `pie` | 전체를 구성하는 각 부분을 원의 조각으로 표시합니다. |
| [도넛 차트](/charts/donut) | `donut` | 가운데 수치 하나를 두고, 그 둘레에 전체를 구성하는 각 부분을 표시합니다. |
| [링 차트](/charts/rings) | `rings` | 각 측정값이 해당 전체에서 차지하는 비율만큼 별도의 링을 채웁니다. |
| [마리메코 차트](/charts/marimekko) | `marimekko` | 각 열의 너비를 합계에 비례하게 정하고 열을 구성 항목별로 나눕니다. |

| [선버스트 차트](/charts/sunburst) | `sunburst` | 전체의 구성 항목과 각 항목의 하위 항목을 두 겹의 링으로 표시합니다. |
| [히스토그램](/charts/histogram) | `histogram` | 떨어지는 수를 경계로 측정값을 여러 구간에 나누고, 구간마다 측정값 개수를 높이로 표시해 분포를 보여 줍니다. |
| [상자 수염 그림](/charts/box) | `box` | 그룹마다 요약값 다섯 개를 상자, 중앙값 선, 수염으로 표시해 분포를 비교합니다. |
| [히트맵](/charts/heatmap) | `heatmap` | 두 축에 걸친 패턴을 각 셀의 값에 따른 색 농도로 보여 줍니다. |
| [산점도](/charts/scatter) | `scatter` | 항목 하나를 점 하나로 표시해 두 측정값의 관계를 보여 줍니다. |

꺾은선, 영역, 막대는 같은 눈금 체계를 사용하므로 한 차트에 함께 그릴 수 있습니다. 계열에 별도의 `type`을 지정하면 그 형태로 그립니다. 예를 들어 막대 위에 꺾은선을 겹칠 수 있습니다.

## 값 표시와 키보드 조작 \{#readout\}

`chart-tip`은 값 표시 팝오버입니다. 데이터 점의 이름을 먼저 표시하고, 그 아래에 계열마다 해당 색상의 선, 계열 이름, 값을 한 줄에 표시합니다. 공간이 더 넓은 쪽에 데이터 점을 기준으로 배치하고, 팝오버 자체 높이를 기준으로 세로 위치를 조정합니다. 이렇게 하면 플롯을 벗어나지 않고 스크립트로 위치를 계산할 필요도 없습니다. 동작 코드는 데이터 점을 나타내는 요소에서 내용을 가져와 팝오버를 채우고, 그 점의 위치를 `--chart-x`, `--chart-y`, `--chart-reach`로 전달합니다.

데이터 점의 개수와 관계없이 플롯은 Tab으로 한 번만 포커스를 받습니다. 방향키로 데이터 점 사이를 이동하며 각 점의 값을 확인할 수 있습니다. 터치 화면에서는 차트를 따라 손가락을 움직이면 같은 방식으로 값을 확인할 수 있습니다.

## 범례 \{#legend\}

계열이 두 개 이상이면 범례를 표시해 색상 외에도 이름으로 계열을 구분할 수 있게 합니다. 각 항목은 체크박스를 감싸는 라벨이므로 Tab으로 이동하고 스페이스바로 선택을 전환할 수 있습니다. 선택을 해제하면 해당 계열이 숨겨지고 나머지 계열에 맞춰 눈금 범위가 조정됩니다. 다른 계열의 색상은 그대로 유지됩니다. 계열이 하나인 차트는 제목에서 내용을 알 수 있으므로 범례를 표시하지 않습니다.

`toggle: false`를 지정하면 범례를 일반 목록으로 표시합니다. 차트 주변 텍스트에서 각 계열의 이름을 설명하는 경우 `legend: false`로 범례를 생략할 수 있습니다. 차트의 값은 숨긴 계열의 이름 목록입니다. `chart()`의 반환값에서 이 목록을 읽거나 외부에서 설정해 계열을 숨길 수 있습니다.

## 색상 \{#color\}

계열이 하나인 차트는 잉크 색상인 `--chart-color`로 그립니다. 계열이 여러 개인 차트와 전체를 부분으로 나누는 차트에는 파랑, 주황, 청록, 보라, 호박색, 분홍, 초록, 하늘색 순으로 카테고리 색상을 적용합니다. 두 색상 모드에서 모두 주요 유형의 색각 이상이 있는 사용자도 이 순서에서 이웃한 색을 구분할 수 있습니다. 8개를 넘으면 처음 색상부터 반복되므로, 나머지 항목은 “기타”로 묶거나 차트를 하나 더 그립니다.

같은 항목에 항상 같은 색을 쓰려면 계열에 `category`를 직접 지정합니다. 예를 들어 도쿄는 목록의 순서와 관계없이 차트, [배지](/components/badge), 표의 행에서 모두 파란색으로 표시할 수 있습니다. 상태 색상은 계열에 사용하지 않습니다. 실패 상태인 계열은 그 상태를 텍스트로 표시합니다.

## 눈금과 숫자 표기 \{#scale\}

눈금 범위는 0에서 시작하되 음수가 있으면 0 아래에서 시작합니다. 끝값은 최댓값보다 크면서 눈금 단위로 딱 떨어지는 수로 정하고, 눈금은 약 네 단계로 나눕니다. `min`과 `max`로 범위의 양 끝을 지정하고 `ticks`로 눈금 단계 수를 조정합니다. 막대의 길이 자체가 값을 나타내므로 막대 차트의 눈금은 0에서 시작해야 합니다.

`format`은 팝오버와 막대 끝에 표시되는 값의 형식을 정하고, `tickFormat`은 눈금값의 형식을 정합니다. 기본적으로 눈금값은 10,000 미만이면 전체 숫자로, 10,000 이상이면 축약형으로 표시합니다. 두 함수 모두 숫자를 받아 문자열을 반환합니다. `locale`은 숫자 형식에 사용할 BCP 47 태그이며 기본값은 `en-US`입니다. 서버에서 차트를 생성할 때 이 옵션을 지정하면 서버와 클라이언트의 표기가 일치합니다.

| 옵션 | 기본값 | |
| --- | --- | --- |
| `type` | `'bar'` | [차트 형태](#forms)에 나열된 유형 중 하나 |
| `label` | 없음 | 차트의 내용과 단위를 설명하는 플롯의 접근 가능한 이름 |
| `labels` | `[]` | 눈금을 따라, 레이더 차트 둘레에, 또는 히트맵의 각 열 위에 표시할 이름 |
| `series` | `[]` | 각 계열에는 `name`과 해당 형태에 필요한 `values`, `value`, `points`, `ranges`, `children` 중 하나를 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`를 추가로 지정할 수 있습니다. |

## 모션 \{#motion\}

차트의 표시 요소는 처음 나타날 때 그려지는 애니메이션을 재생합니다. 막대는 기준선에서 차례로 올라오고, 선은 시작점부터 뻗어 나갑니다. 원형 조각과 레이더 차트의 도형은 중심에서 펼쳐지고, 링은 둘레를 따라 채워집니다. 팝오버는 데이터 점 사이를 부드럽게 이동합니다. 강조 표시가 손의 움직임을 따라갈 수 있도록 가는 안내선, 점, 흐려지는 막대는 즉시 반응합니다. 모션 감소 설정에서는 표시 요소가 완성된 상태로 나타나며 팝오버도 즉시 새 위치로 이동합니다.

## 브라우저 기능 \{#platform\}

- **막대의 둥근 모서리와 올라오는 효과**는 SVG 도형에 적용한 `clip-path`로 구현합니다. CSS 도형으로 SVG 도형을 자를 수 없는 브라우저에서는 각진 막대가 처음부터 전체 길이로 표시됩니다.
- **영역의 페이드 효과**는 경로에 적용한 `mask-image`로 구현합니다. 이를 지원하지 않으면 영역 전체가 균일한 색으로 표시됩니다.
- **점의 반지름**은 `--chart-dot`으로 설정하는 CSS `r` 속성으로 지정합니다. 이 속성을 지원하지 않으면 마크업에 지정된 반지름을 사용합니다.
- **라벨 수 줄이기**는 플롯 본문에 적용한 컨테이너 쿼리로 구현합니다. 컨테이너 쿼리를 지원하지 않으면 모든 라벨을 표시합니다.
- **처음 그려지는 효과**는 `@starting-style`로 구현합니다. 이를 지원하지 않으면 표시 요소가 완성된 상태로 나타납니다.

## 차트의 사용 범위 \{#limits\}

차트는 사용자가 개별적으로 탐색할 수 있는 표시 요소 수백 개를 그리도록 설계되었습니다. 데이터 점이 수천 개이거나 실시간으로 값이 들어오는 경우, 또는 확대, 브러시 선택, 지도, 캔들스틱이 필요한 경우에는 캔버스에 그리는 차트 엔진을 사용합니다. 더 간단한 표시에는 문장 안에 추세를 보여 주는 [스파크라인](/components/sparkline), 수치 하나를 보여 주는 [통계](/components/stat), 측정값 하나를 보여 주는 [미터](/components/meter)와 [게이지](/components/gauge), 전체의 구성을 막대 하나로 보여 주는 [구성 내역](/components/breakdown), 여러 작은 값에 걸친 패턴을 보여 주는 [히트맵](/components/heatmap)이 있습니다. [차트 가이드](/guide/charts)에서 용도에 맞는 컴포넌트를 고를 수 있습니다.

## 접근성 \{#accessibility\}

- `label`에는 측정 대상과 단위를 설명하는 문장을 지정합니다. 이 문장은 목록으로 제공되는 플롯의 이름이 됩니다.
- 각 데이터 점은 “목: 도쿄 71, 오사카 49”처럼 값을 포함한 이름을 가진 목록 항목입니다. 스크린 리더는 스크립트나 표 없이도 차트를 목록으로 읽습니다. 가는 안내선, 눈금, 팝오버는 데이터 점과 같은 정보를 반복하므로 스크린 리더에서 숨깁니다.
- 값 표시 팝오버는 값을 눈으로 쉽게 확인할 수 있게 합니다. 포인터를 올리거나 포커스를 옮기거나 손가락으로 터치하면 나타나며 <kbd class="kbd">Esc</kbd>를 누르면 닫힙니다.
- 색상과 함께 계열 이름을 표시합니다. 범례에 계열 이름을 적고 팝오버에서 값 옆에 같은 이름을 표시합니다. 카테고리 색상으로 상태를 나타내지 않습니다.
- 포커스를 받은 데이터 점은 해당 띠, 점, 조각 또는 링의 모양을 따라 윤곽선으로 표시합니다.
- 강제 색상 모드에서는 잉크 색상과 가는 안내선에 시스템 색상을 적용하고 포커스에는 강조 색상을 씁니다. 계열에는 지정된 색상이 유지되므로 범례에 계열 이름을 표시합니다.
- 눈금은 언어에 관계없이 왼쪽에서 시작합니다. 이름, 값, 범례는 페이지의 쓰기 방향을 따릅니다.
