차트는 숫자를 선, 영역, 막대, 파이, 도넛, 링, 레이더 또는 산점도로 그립니다. 차트는 주어진 너비에 맞춰지는 SVG 하나입니다. 눈금 위에 놓이는 요소는 백분율로 배치하고, 선은 그래프 영역이 아무리 늘어나도 두께를 유지하며, 텍스트는 크기가 조정되지 않습니다. 계열이 하나인 차트는 [진행률 표시줄](/components/progress)이 잉크색으로 채워지듯 잉크색으로 그립니다. 계열이 여러 개이면 각 계열에 [카테고리](/components/category)의 색상을 사용합니다. 각 지점은 자신의 값을 글로 알려 주는 목록 항목입니다.

## 그리는 방식 \{#how-it-is-drawn\}

그래프 영역은 `viewBox`가 없는 `<svg>`입니다. 너비는 주어진 공간을 채우고 높이는 `--chart-height`이며, 따로 지정하지 않으면 14rem입니다. 가는 선, 눈금 레이블, 막대, 점은 그래프 영역에 대한 백분율로 작성합니다. 따라서 `x="42%"`에 놓인 막대는 너비가 얼마이든 42% 위치에 머물고, 모서리는 반경을, 텍스트는 크기를 그대로 유지합니다.

선, 영역, 조각처럼 반드시 경로여야 하는 요소만 `chart-canvas`에 그립니다. `chart-canvas`는 중첩된 SVG로, 100×100 크기의 좌표 영역이 그래프 영역에 맞춰 늘어납니다. 획의 두께는 함께 늘어나지 않으므로 선은 좁은 카드에서도 넓은 카드에서도 `--chart-stroke` 두께로 그려집니다.

너비가 바뀌어도 아무것도 측정하지 않고 아무것도 다시 그리지 않으므로, 서버에서든 [프레임워크 컴포넌트](#frameworks)에서든 동작에서든 같은 마크업이 나옵니다. 차트는 주어진 너비를 채웁니다. 여러 요소가 나란히 놓인 행에서는 차트에 너비를 지정하거나 차트가 늘어나도록 하세요.

## 차트 그리기 \{#draw\}

동작은 `chart` 클래스가 있는 요소 안에 차트를 작성합니다. `label`은 차트가 무엇을 어떤 단위로 보여 주는지 알려 줍니다. `labels`는 눈금의 각 단계에 이름을 붙이고, 각 계열은 단계마다 값을 하나씩 가집니다.

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

서버에서는 `chartMarkup()`이 같은 차트를 문자열로 반환하며, 그 안의 모든 텍스트는 이스케이프됩니다. 이 문자열을 요소 안에 넣으면 스크립트가 실행되기 전에도 페이지를 읽을 수 있습니다. `chartLayout()`은 그림에 담기는 내용을 데이터로 반환합니다. 눈금과 눈금 레이블, 각 계열의 경로, 그리고 모든 지점과 그 지점의 표시 요소 및 지점을 알려 주는 문장이 포함됩니다.

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

계열을 전달하지 않고 해당 요소에 `chart()`를 호출하면 이미 작성된 차트를 그대로 작동시킵니다. `@master/ui/behaviors`의 `attach()`는 페이지의 모든 차트에 같은 작업을 수행합니다.

## 차트 형식 \{#forms\}

차트 형식마다 전용 페이지가 있으며, 예제와 해당 형식에 관련된 옵션을 담고 있습니다.

| 형식 | `type` | 용도 |
| --- | --- | --- |
| [선 차트](/charts/line) | `line` | 이어지는 값을 점과 점을 잇는 선으로 나타냅니다. |
| [영역 차트](/charts/area) | `area` | 선 아래를 같은 색으로 옅게 채웁니다. 단독으로, 또는 합계가 되도록 쌓아서 씁니다. |
| [막대 차트](/charts/bar) | `bar` | 기준선 위의 막대로 양을 비교합니다. 나란히, 누적, 가로 방향으로 그릴 수 있습니다. |
| [레이더 차트](/charts/radar) | `radar` | 몇 가지 대상을 같은 지표로 비교합니다. 각 대상은 중심을 둘러싼 윤곽선이 됩니다. |
| [파이 차트](/charts/pie) | `pie` | 하나의 전체가 무엇으로 이루어지는지를 원의 조각으로 나타냅니다. |
| [도넛 차트](/charts/donut) | `donut` | 전체를 이루는 부분들이 가운데에 놓인 수치 하나를 둘러쌉니다. |
| [링](/charts/rings) | `rings` | 몇 개의 측정값이 각자의 링을 전체를 향해 채웁니다. |
| [산점도](/charts/scatter) | `scatter` | 두 지표를 서로 대비시키고, 대상마다 점 하나를 찍습니다. |

## 값 표시창과 키 \{#readout\}

`chart-tip`은 값 표시창입니다. 지점의 이름이 먼저 나오고, 이어서 계열마다 계열 색의 짧은 획, 이름, 값을 담은 행이 하나씩 나옵니다. 값 표시창은 지점 옆에서 공간이 더 넓은 쪽에 놓이고 자신의 높이만큼 미끄러져 움직이므로, 그래프 영역을 벗어나지 않으며 스크립트로 위치를 잡을 필요도 없습니다. 동작은 지점의 표시 요소에 담긴 내용으로 값 표시창을 채우고, 지점의 위치를 `--chart-x`, `--chart-y`, `--chart-reach`로 전달합니다.

그래프 영역은 지점이 몇 개이든 탭 순서에서 정지 위치 하나를 차지합니다. 방향키는 지점에서 지점으로 이동하며 각 지점의 값 표시창을 표시합니다. 손가락으로 차트를 따라 움직여도 같은 동작이 일어납니다.

## 범례 \{#legend\}

계열이 둘 이상인 차트에는 범례가 있습니다. 계열을 색상만으로 구분하는 일은 없기 때문입니다. 각 항목은 체크박스를 감싼 레이블이므로 Tab으로 이동하고 Space로 전환합니다. 체크를 해제하면 해당 계열이 차트에서 빠지고, 눈금은 남은 계열에 맞춰지며, 나머지 계열은 색상을 그대로 유지합니다. 계열이 하나인 차트에는 범례가 없습니다. 차트의 제목이 무엇을 그렸는지 이미 알려 주기 때문입니다.

`toggle: false`는 범례를 일반 목록으로 작성하고, `legend: false`는 주변 글에서 계열의 이름을 밝히는 차트를 위해 범례를 생략합니다. 차트의 값은 숨긴 계열의 이름입니다. `chart()`가 반환하는 값에서 읽거나, 값을 설정해 바깥에서 계열을 숨길 수 있습니다.

## 색상 \{#color\}

계열이 하나인 차트는 잉크색인 `--chart-color`로 그립니다. 계열이 여러 개인 차트의 계열과 전체를 이루는 부분에는 정해진 순서대로 카테고리가 하나씩 배정됩니다. 순서는 파랑, 주황, 청록, 보라, 호박색, 분홍, 초록, 하늘색입니다. 이 순서에서 이웃한 색은 두 색 구성표 모두에서 흔한 유형의 색각 이상이 있어도 서로 구분됩니다. 여덟 개를 넘으면 순서가 처음부터 다시 시작되므로, 나머지는 "기타"로 묶거나 두 번째 차트를 그리세요.

색상이 대상을 따라다녀야 할 때는 계열에 고유한 `category`를 지정하세요. Tokyo는 목록에서 어느 자리에 있든 차트에서도, [배지](/components/badge)에서도, 표의 해당 행에서도 파란색입니다. 상태 색상은 절대 계열을 나타내지 않습니다. 실패하고 있는 계열은 그 사실을 글로 알립니다.

## 눈금과 숫자 \{#scale\}

눈금은 0에서 시작하고, 0보다 작은 값이 있으면 0 아래에서 시작합니다. 끝은 가장 큰 값보다 큰 딱 떨어지는 수이며, 약 네 단계로 나누어 표시됩니다. `min`과 `max`는 양 끝을 각각 고정하고, `ticks`는 다른 단계 수를 요청합니다. 막대의 길이가 곧 값이므로 막대의 눈금은 0에서 시작해야 합니다.

`format`은 값 표시창과 막대 끝에 값을 적는 방식을 정하고, `tickFormat`은 눈금 숫자를 적는 방식을 정합니다. 눈금 숫자는 10,000 미만이면 전체를 적고 그보다 크면 축약해서 적습니다. 두 옵션 모두 숫자를 받아 문자열을 반환합니다. `locale`은 숫자에 적용하는 BCP 47 태그이며 기본값은 `en-US`입니다. 서버가 차트를 작성할 때는 양쪽 결과가 일치하도록 `locale`을 지정하세요.

| 옵션 | 기본값 | |
| --- | --- | --- |
| `type` | `'bar'` | `line`, `area`, `bar`, `pie`, `donut`, `rings`, `radar` 또는 `scatter` |
| `label` | 없음 | 차트가 무엇을 어떤 단위로 보여 주는지 알려 주는, 그래프 영역의 접근 가능한 이름 |
| `labels` | `[]` | 눈금을 따라 놓이는 이름 또는 레이더 둘레에 놓이는 이름 |
| `series` | `[]` | 각 계열에는 `name`과 `values`를 지정합니다. 조각이나 링에는 `value`를, 산점도에는 `points`를 지정합니다. 선택적으로 `category`, `type`, 링의 `max`를 지정할 수 있습니다 |
| `stacked` | `false` | 막대 또는 영역이 서로 위에 쌓입니다 |
| `horizontal` | `false` | 막대가 가로로 놓입니다 |
| `curve` | `'smooth'` | `smooth`, `linear` 또는 `step` |
| `min`, `max`, `ticks` | 데이터에 맞춤, `4` | 눈금의 양 끝과 눈금을 표시하는 대략적인 단계 수. 산점도의 가로 눈금에는 `xMin`, `xMax`, `xTicks`를 사용합니다 |
| `axis` | `true` | 눈금 숫자를 적을지 여부. `false`이면 가는 선만 남으며, 타일 안의 작은 차트에 사용합니다 |
| `format`, `tickFormat` | 로캘의 형식 | 값과 눈금 숫자를 적는 방식. 산점도의 가로 눈금에는 `xFormat`을 사용합니다 |
| `dots`, `values` | `false` | 선의 모든 지점을 점으로 표시합니다. 모든 막대의 값을 적습니다 |
| `current` | 없음 | `aria-current`로 표시하는 지점의 인덱스 |
| `legend`, `toggle` | 계열이 둘이면 작성, `true` | 범례를 작성할지 여부와 범례 항목을 체크박스로 만들지 여부 |
| `hole`, `center` | `.7`, 없음 | 도넛의 구멍, 그리고 도넛이나 링의 가운데에 놓이는 내용 |
| `hidden` | `[]` | 제외할 계열의 이름 |
| `locale` | `'en-US'` | 숫자에 적용하는 BCP 47 태그 |
| `draw` | 없음 | 차트 작성을 넘겨받습니다. 숨긴 계열의 이름과 함께 호출되며, 차트를 직접 작성하는 렌더러에 사용합니다 |

## 모션 \{#motion\}

표시 요소는 처음 나타날 때 스스로 그려집니다. 막대는 기준선에서 하나씩 차례로 솟아오르고, 선은 시작점에서부터 그어지며, 조각과 레이더의 도형은 중심에서 펼쳐지고, 링은 채워집니다. 값 표시창은 지점에서 지점으로 미끄러지듯 이동합니다. 반면 지점을 표시하는 요소인 가는 선과 점, 물러나는 막대는 즉시 반응합니다. 강조 표시는 손의 움직임을 따라잡아야 하기 때문입니다. 동작 줄이기가 설정되어 있으면 아무것도 이동하지 않습니다. 표시 요소는 다 그려진 상태로 나타나고 값 표시창은 즉시 위치를 바꿉니다.

## 플랫폼이 담당하는 부분 \{#platform\}

- **막대의 모서리와 솟아오르는 움직임**은 SVG 도형에 적용한 `clip-path`입니다. SVG 도형을 CSS 도형으로 잘라 내지 않는 브라우저는 모서리가 각진 막대를 처음부터 전체 길이로 그립니다.
- **영역이 흐려지는 효과**는 경로에 적용한 `mask-image`입니다. 지원되지 않으면 영역은 고른 옅은 색으로 채워집니다.
- **점의 반지름**은 `--chart-dot`으로 설정하는 CSS `r` 속성입니다. 지원되지 않으면 점은 마크업에 적힌 반지름을 유지합니다.
- **레이블 솎아 내기**는 그래프 영역의 본체에 적용한 컨테이너 쿼리입니다. 지원되지 않으면 모든 레이블이 그대로 남습니다.
- **그려지며 나타나는 효과**는 `@starting-style`입니다. 지원되지 않으면 표시 요소가 다 그려진 상태로 나타납니다.

## 차트로 충분하지 않을 때 \{#limits\}

차트는 표시 요소 수백 개를 그리도록 만들어졌으며, 각 표시 요소는 독자가 접근할 수 있는 요소입니다. 수천 개의 지점, 실시간으로 들어오는 값, 확대·축소, 브러시, 지도, 캔들스틱은 캔버스에 그리는 차트 엔진의 몫입니다. 차트보다 작은 것이 필요할 때를 위한 더 작은 컴포넌트도 있습니다. 문장 안의 추세에는 [스파크라인](/components/sparkline), 수치 하나에는 [지표](/components/stat), 측정값 하나에는 [미터](/components/meter)나 [게이지](/components/gauge), 막대 하나에 나타내는 합계의 구성 부분에는 [구성 내역](/components/breakdown), 작은 값 여러 개에 걸친 패턴에는 [히트맵](/components/heatmap)을 사용합니다. 어떤 것을 선택할지는 [차트](/guide/charts) 가이드에서 설명합니다.

## 접근성 \{#accessibility\}

- `label`에는 무엇을 어떤 단위로 측정했는지 알려 주는 문장을 지정하세요. 이 문장이 그래프 영역의 이름이며, 그래프 영역은 목록입니다.
- 각 지점은 "Thu: Tokyo 71, Osaka 49"처럼 자신의 값을 이름으로 가진 목록 항목입니다. 따라서 스크린 리더는 스크립트나 표 없이도 목록을 읽듯 차트를 읽습니다. 가는 선, 눈금 레이블, 값 표시창은 지점이 알려 주는 내용을 반복하므로 스크린 리더에 노출되지 않습니다.
- 값 표시창은 눈으로 보는 독자를 위한 편의 기능입니다. 포인터를 올리거나 포커스를 받거나 손가락을 댈 때 나타나며, <kbd class="kbd">Esc</kbd>를 누르면 숨겨집니다.
- 색상은 절대 단독으로 쓰이지 않습니다. 계열의 이름은 범례에 표시되고, 값 표시창도 값 옆에 계열의 이름을 표시합니다. 카테고리는 상태가 아닙니다.
- 포커스를 받은 지점의 윤곽선은 상자 둘레가 아니라 해당 지점의 구간, 점, 조각 또는 링에 그려집니다.
- 강제 색상 모드에서는 잉크색과 가는 선에 시스템 색상이 적용되고, 포커스는 강조 색상으로 그려집니다. 계열은 지정된 색상을 유지하므로 범례에서 계열의 이름을 밝히세요.
- 눈금은 모든 언어에서 왼쪽부터 시작합니다. 이름, 값, 범례는 페이지의 방향을 따릅니다.
