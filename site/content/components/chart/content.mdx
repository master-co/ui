A chart shows a few numbers as bars. It is a list: every item carries its number once for the drawing and once as text, and the stylesheet draws the bar, the scale behind it and the value under the pointer. Bars are ink, the way a [progress bar](/components/progress) fills with ink. There is no script and no SVG.

## How a bar gets its height \{#how-a-bar-gets-its-height\}

Each `chart-item` sets `--value` in its `style`. The chart sets the top of the scale with `--chart-max`, 100 unless you say otherwise, and the plot's height with `--chart-height`. A bar is its share of the maximum; a value above the maximum fills the plot, and a value of nothing leaves a one-pixel tick on the baseline, so an empty day is still a day.

The number is written twice on purpose. `--value` is for the drawing. `chart-value` is the same number as text, formatted the way a person reads it: the tip under the pointer shows it, and so does a screen reader, a search and a copy.

Four hairlines mark even steps of the scale. Set `--chart-lines` to match your maximum: five lines for a scale of 100 put one at every 20.

## One bar that matters \{#quiet\}

`chart-quiet` turns the bars into a tint and keeps the ink for the item marked `aria-current`: today in a week, the plan a reader is on, the release being discussed.

## Many bars \{#many-bars\}

Columns share the width equally, so a month fits where a week did. Narrow the space between bars with `--chart-gap`. A name is centered on its bar and may be wider than its column: name every seventh item and leave the others empty. An item with an empty name takes an `aria-label` instead, so its value still has something to belong to.

## Motion \{#motion\}

A bar rises from the baseline when it first appears, with `@starting-style`, and eases to a new height when `--value` changes. With reduced motion it does neither. A bar under the pointer answers at once, with no fade, because the highlight has to keep up with a hand moving along the columns.

## When a list of bars is not enough \{#limits\}

This is a chart for a handful of numbers on one scale. A line, an area, two series side by side, a zoom or a time axis with gaps need a charting library, and a single reading within a range is a [meter](/components/meter).

## Accessibility \{#accessibility\}

- Use `<ol>` when the order means something, such as days, and `<ul>` for a ranking you have already sorted. Give the list an `aria-label` that says what is measured and in what unit.
- Each item reads as its name and its value. Do not rely on the tip: it appears only under a pointer.
- Bars are told apart by position and length, never by hue. If you set `--chart-color` to a status color, say the status in words nearby.
- In forced colors the bars take the system text color.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `chart` | The list and its plot |
| `chart-quiet` | Tinted bars; the item with `aria-current` is ink |
| `chart-values` | Every value written over its bar |
| `chart-horizontal` | Rows: a name on a tint, the figure at the end |
| `chart-spark` | Bars alone, 32px tall |
| `chart-item` | One bar; set `--value` in its `style` |
| `chart-label` | The item's name |
| `chart-value` | The item's number as text |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--value` | `0` | On an item: its number |
| `--chart-max` | `100` | The top of the scale |
| `--chart-height` | `10rem` | Height of the plot |
| `--chart-gap` | `.375rem` | Space between bars |
| `--chart-lines` | `4` | Steps of the scale marked by a hairline |
| `--chart-bar-width` | `2.5rem` | The widest a bar gets |
| `--chart-color` | `var(--color-surface-inverse)` | The ink of the bars |
