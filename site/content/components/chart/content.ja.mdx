チャートは数値を、折れ線、面、棒、円グラフ、ドーナツグラフ、リング、レーダーチャート、散布図として描画します。与えられた幅に収まる1つのSVGで、スケール上に置くものはパーセンテージで配置し、線はプロットがどれだけ引き伸ばされても太さを保ち、テキストは拡大も縮小もされません。系列が1つのチャートは、[プログレスバー](/components/progress)の塗りと同じインク色で描画します。系列が複数ある場合は、各系列に[カテゴリ](/components/category)の色を使います。各ポイントはリスト項目で、その値を言葉で伝えます。

## 描画の仕組み \{#how-it-is-drawn\}

プロットは`viewBox`のない`<svg>`です。幅は配置先の幅いっぱいで、高さは`--chart-height`になり、指定しなければ14remです。細線、目盛り、棒、ドットはプロットに対するパーセンテージで記述します。そのため、`x="42%"`の棒はどの幅でも42%の位置にとどまり、角の半径もテキストのサイズも変わりません。

パスでなければ描けない折れ線、面、スライスだけを`chart-canvas`に描画します。これは入れ子のSVGで、100×100のボックスがプロットに合わせて引き伸ばされます。ストロークは一緒に拡大・縮小されないため、折れ線の太さは狭いカードでも広いカードでも`--chart-stroke`のままです。

幅が変わっても、何も計測せず、何も描き直しません。そのため、サーバー、[フレームワークコンポーネント](#frameworks)、ビヘイビアのどれからも同じマークアップが得られます。チャートは与えられた幅いっぱいに広がります。ほかの要素と横に並べる場合は、幅を指定するか、伸長できるようにします。

## チャートを描画する \{#draw\}

ビヘイビアは、クラス`chart`を持つ要素にチャートを書き込みます。`label`には、チャートが何をどの単位で示すかを記述します。`labels`にはスケールの各区分の名前を指定し、各系列は区分ごとに値を1つ持ちます。

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

サーバーでは、`chartMarkup()`が同じチャートを文字列として返し、その中の文言はすべてエスケープされます。この文字列を要素に入れておけば、スクリプトが実行される前からページを読めます。`chartLayout()`は、描画の内容をデータとして返します。スケールとその目盛り、各系列のパス、そして各ポイントのマークとそのポイントを伝える文です。

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

系列を渡さずにその要素に対して`chart()`を呼び出すと、記述済みのチャートがそのまま動作するようになります。`@master/ui/behaviors`の`attach()`は、ページ上のすべてのチャートに対して同じ処理を行います。

## チャートの種類 \{#forms\}

チャートの種類ごとに専用のページがあり、例とその種類に関係するオプションを載せています。

| 種類 | `type` | 用途 |
| --- | --- | --- |
| [折れ線グラフ](/charts/line) | `line` | 連続して変化する値を、点から点へ結ぶ線で表します。 |
| [面グラフ](/charts/area) | `area` | 線の下を同じ色で淡く塗ります。単独でも、積み上げて合計を示すこともできます。 |
| [棒グラフ](/charts/bar) | `bar` | 基線に立つ棒で量を比べます。横並び、積み上げ、横向きにできます。 |
| [レーダーチャート](/charts/radar) | `radar` | 少数の対象を同じ指標で比べます。それぞれが中心を囲む輪郭になります。 |
| [円グラフ](/charts/pie) | `pie` | ひとつの全体が何で構成されているかを、円の扇形で表します。 |
| [ドーナツグラフ](/charts/donut) | `donut` | 全体を構成する部分が、中央に置いた1つの数値を囲みます。 |
| [リング](/charts/rings) | `rings` | 少数の測定値が、それぞれ自分のリングを全体に向かって満たします。 |
| [散布図](/charts/scatter) | `scatter` | 2つの指標を対比させ、対象ごとに1つの点を置きます。 |

## 値表示とキー操作 \{#readout\}

`chart-tip`が値表示です。ポイントの名前に続いて、系列ごとに1行ずつ、その色の短い線、名前、値を並べます。値表示はポイントの横の、余地が広い側に置かれ、自身の高さの範囲で上下にずれます。そのため、プロットからはみ出すことがなく、スクリプトで位置を決める必要もありません。ビヘイビアは、ポイントのマークが持つ情報から値表示の内容を書き込み、ポイントの位置を`--chart-x`、`--chart-y`、`--chart-reach`として渡します。

プロットは、ポイントがいくつあっても、タブ順序の中で1つのタブストップです。矢印キーでポイントからポイントへ移動し、それぞれの値表示を表示します。指でチャートをなぞっても同じように動作します。

## 凡例 \{#legend\}

系列が2つ以上あるチャートには凡例があります。系列を見分ける手段が色だけになることはありません。各項目はチェックボックスを囲むラベルなので、Tabキーで移動し、Spaceキーで切り替えられます。チェックを外すと、その系列はチャートから消え、スケールは残った系列に合わせて決まり、ほかの系列の色は変わりません。系列が1つのチャートには凡例がありません。何が描かれているかは、すでにタイトルが伝えているためです。

`toggle: false`は凡例を単純なリストとして書き出します。`legend: false`は凡例を省略し、周囲の文章で系列の名前を示しているチャートに使います。チャートの値は、非表示の系列の名前です。`chart()`の戻り値から読み取るか、値を設定して外部から系列を非表示にします。

## 色 \{#color\}

系列が1つのチャートは、インク色である`--chart-color`で描画します。複数の系列を持つチャートの各系列と、全体を構成する各部分には、決まった順序でカテゴリを1つずつ割り当てます。順序はblue、orange、teal、violet、amber、pink、green、skyです。この順序で隣り合う色は、どちらの配色でも、一般的な色覚特性で見分けられるように離してあります。8つを超えると順序が最初に戻るため、残りは「その他」にまとめるか、2つ目のチャートを描きます。

色が対象そのものに結び付く場合は、系列に固有の`category`を指定します。たとえばTokyoは、リスト内のどの位置にあっても、チャートでも、その[バッジ](/components/badge)でも、テーブルの行でも青になります。ステータス色で系列を表すことはありません。失敗している系列は、そのことを言葉で伝えます。

## スケールと数値 \{#scale\}

スケールはゼロから始まり、ゼロ未満の値がある場合はゼロより下から始まります。終わりは最大値より上の切りのよい数値で、約4段階の目盛りが付きます。`min`と`max`はそれぞれの端を固定し、`ticks`は別の段階数を指定します。棒のスケールはゼロから始めてください。棒の長さがその値を表すためです。

`format`は値表示と棒の端に書き出す値の書式を決め、`tickFormat`はスケールの数値の書式を決めます。スケールの数値は、10,000未満では省略せずに、それ以上では短縮表記で書き出されます。どちらも数値を受け取り、文字列を返します。`locale`は数値に使うBCP 47タグで、既定値は`en-US`です。サーバーがチャートを書き出す場合は、サーバーとブラウザーの結果が一致するように指定します。

| オプション | 既定値 | |
| --- | --- | --- |
| `type` | `'bar'` | `line`、`area`、`bar`、`pie`、`donut`、`rings`、`radar`、`scatter`のいずれか |
| `label` | なし | チャートが何をどの単位で示すか。プロットのアクセシブルな名前になります |
| `labels` | `[]` | スケールに沿って、またはレーダーチャートの周囲に並ぶ名前 |
| `series` | `[]` | それぞれが`name`と`values`を持ちます。スライスやリングでは`value`、散布図では`points`を指定します。任意で`category`、`type`、リングの`max`を指定できます |
| `stacked` | `false` | 棒または面を積み重ねます |
| `horizontal` | `false` | 棒を横向きにします |
| `curve` | `'smooth'` | `smooth`、`linear`、`step`のいずれか |
| `min`、`max`、`ticks` | 自動調整、`4` | スケールの両端と、目盛りのおおよその段階数。散布図の横方向のスケールには`xMin`、`xMax`、`xTicks`を使います |
| `axis` | `true` | スケールの数値を書き出すかどうか。`false`にすると細線だけが残ります。タイル内の小さなチャートに使います |
| `format`、`tickFormat` | ロケールの書式 | 値と目盛りの書式。散布図の横方向のスケールには`xFormat`を使います |
| `dots`、`values` | `false` | 折れ線のすべてのポイントにドットを付けます。すべての棒の値を書き出します |
| `current` | なし | `aria-current`を付けるポイントのインデックス |
| `legend`、`toggle` | 系列が2つ以上あれば表示、`true` | 凡例を書き出すかどうかと、その項目をチェックボックスにするかどうか |
| `hole`、`center` | `.7`、なし | ドーナツグラフの穴と、ドーナツグラフまたはリングの中央に置く内容 |
| `hidden` | `[]` | 非表示にする系列の名前 |
| `locale` | `'en-US'` | 数値に使うBCP 47タグ |
| `draw` | なし | 書き出しを引き受けます。非表示の系列名を引数に呼び出され、チャートを自前で書き出すレンダラーに使います |

## アニメーション \{#motion\}

マークは、最初に表示されるときに描き込まれます。棒は基準線から1本ずつ順に伸び、折れ線は始点から走り、スライスとレーダーチャートの図形は中心から開き、リングは塗られていきます。値表示はポイントからポイントへ滑らかに移動します。一方、ポイントを示す細線、ドット、淡い色へ退く棒は即座に応答します。強調表示は手の動きに遅れてはならないためです。動きを抑える設定では、何も移動しません。マークは描画済みの状態で表示され、値表示は即座に位置を変えます。

## プラットフォームが担う部分 \{#platform\}

- **棒の角丸と伸びる動き**は、SVG図形に対する`clip-path`です。SVG図形をCSSのシェイプで切り抜かないブラウザーでは、棒は角が四角いまま、最初から全長で描画されます。
- **面の薄れていく塗り**は、パスに対する`mask-image`です。未対応の場合、面は均一な淡い色になります。
- **ドットの半径**は、`--chart-dot`で設定するCSSの`r`プロパティです。未対応の場合、ドットはマークアップに記述された半径のままになります。
- **ラベルの間引き**は、プロットの本体に対するコンテナークエリーです。未対応の場合、すべてのラベルが残ります。
- **描き込みの動き**は`@starting-style`です。未対応の場合、マークは描画済みの状態で表示されます。

## チャートでは足りない場合 \{#limits\}

チャートは数百個のマークを想定して描画され、各マークは読者が到達できる要素です。数千個のポイント、流れ込み続ける値、ズーム、ブラシ選択、地図、ローソク足には、canvasに描画するチャートエンジンを使います。チャートほどの規模が必要ない場合は、より小さなコンポーネントがあります。文中の推移には[スパークライン](/components/sparkline)、1つの数値には[統計指標](/components/stat)、1つの測定値には[メーター](/components/meter)または[ゲージ](/components/gauge)、1本のバーに沿った合計の内訳には[内訳](/components/breakdown)、多数の小さな値にまたがるパターンには[ヒートマップ](/components/heatmap)を使います。どれを選ぶかは、ガイドの[チャート](/guide/charts)で説明しています。

## アクセシビリティ \{#accessibility\}

- `label`には、何をどの単位で測定しているかを伝える文を指定します。これがプロットの名前になり、プロットはリストです。
- 各ポイントは、「Thu: Tokyo 71, Osaka 49」のように、値を含む名前を持つリスト項目です。そのため、スクリプトもテーブルもなしで、スクリーンリーダーはリストを読むのと同じようにチャートを読み上げます。細線、目盛り、値表示はスクリーンリーダーから隠されます。ポイントが伝える内容の繰り返しだからです。
- 値表示は、目で見るための補助です。ホバーしたとき、フォーカスしたとき、指で触れたときに表示され、<kbd class="kbd">Esc</kbd>で非表示になります。
- 色だけに頼ることはありません。系列の名前は凡例に示され、値表示でも値の横に示されます。カテゴリはステータスではありません。
- フォーカスのあるポイントでは、ボックスの周囲ではなく、その帯、ドット、スライス、リングに輪郭線が描かれます。
- 強制カラーモードでは、インク色と細線にシステムの色が使われ、フォーカスはハイライト色で描かれます。系列は指定された色を保つため、凡例で系列の名前を示してください。
- スケールは、どの言語でも左から始まります。名前、値、凡例はページの書字方向に従います。
