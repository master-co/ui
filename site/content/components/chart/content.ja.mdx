チャートは、読み手が知りたいことに合わせて数値を可視化します。折れ線グラフ、棒グラフ、ドーナツグラフ、ヒストグラム、ファネルチャートなど、[全部で20種類以上](#forms)あります。どの形式も、与えられた幅に収まる1つのSVGです。スケール上の要素はパーセントで配置されるため、プロットが横に伸びても線の太さと文字の大きさは変わりません。系列が1つなら、[プログレスバー](/components/progress)の塗りと同じインク色を使います。複数の系列には[カテゴリ](/components/category)の色を使います。各データ点は、値を文章で伝えるリスト項目です。

## 描画の仕組み \{#how-it-is-drawn\}

プロットは `viewBox` のない `<svg>` です。幅は利用可能な領域いっぱいに広がり、高さは `--chart-height` で、既定は14remです。細い補助線、目盛り、棒、点はプロットに対するパーセントで指定します。たとえば `x="42%"` の棒は、幅が変わっても42%の位置にあり、角の丸みと文字の大きさも変わりません。

折れ線、面、扇形など、パスとして描く必要があるものだけを `chart-canvas` に描画します。これは100×100の座標領域を持ち、プロット全体に伸びる入れ子のSVGです。線幅はSVGの拡大縮小に追従しないため、細いカードでも幅の広いカードでも `--chart-stroke` のままです。

幅が変わっても計測や再描画は行いません。そのため、サーバー、[フレームワークコンポーネント](#frameworks)、ビヘイビアは同じマークアップを生成します。チャートは与えられた幅を埋めます。ほかの要素と横に並べる場合は、幅を指定するか、伸びるようにしてください。

## チャートを描く \{#draw\}

ビヘイビアは、CSSクラス `chart` を持つ要素にチャートを書き込みます。`label` には表示内容と単位を指定し、`labels` にはスケール上の各位置の名前を指定します。各系列はそれぞれの位置に対応する値を1つずつ持ちます。

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

サーバーでは、`chartMarkup()` がテキストをすべてエスケープし、同じチャートを文字列として返します。その文字列を要素に入れると、スクリプトが実行される前からチャートを読めます。`chartLayout()` は描画内容をデータとして返します。これにはスケールと目盛り、各系列のパス、各データ点のマークと値を伝える文が含まれます。

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

系列を渡さずにその要素で `chart()` を呼び出すと、既存のマークアップにビヘイビアが付きます。`@master/ui/behaviors` の `attach()` は、ページ内のすべてのチャートに同じ処理を行います。

### ページで使う形式だけを読み込む \{#forms-only\}

`chart.js` はすべての形式を含み、ミニファイとgzip圧縮後で約16 kBです。使う形式が1つか2つなら、その形式だけを読み込めます。`chart-core.js` は描画形式を含まない約6 kBの本体です。各形式はモジュールとして `chartForms()` に渡します。折れ線グラフ、面グラフ、棒グラフはスケールを共有するため、合わせて約2 kBです。ほかの形式はそれぞれ1 kB未満です。

```js name=app.js
import { chartCore, chartForms } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
chartCore(document.querySelector('.chart'), { type: 'line', label, labels, series })
```

## 形式 \{#forms\}

形式ごとのページで、使用例とその形式に関係するオプションを確認できます。

| 形式 | `type` | 用途 |
| --- | --- | --- |
| [折れ線グラフ](/charts/line) | `line` | 点を順につなぎ、値の推移を示します。 |
| [面グラフ](/charts/area) | `area` | 線の下を同系色で塗りつぶし、単独の系列や積み上げた合計を示します。 |
| [スロープグラフ](/charts/slope) | `slope` | 2つの時点の間で何が上昇し、下降し、順位が入れ替わったかを線の傾きや交差で示します。 |
| [順位推移グラフ](/charts/bump) | `bump` | 複数の項目の順位の推移を示します。順位が入れ替わる箇所で線が交差します。 |
| [棒グラフ](/charts/bar) | `bar` | 基準線から伸びる棒で量を比較します。棒は並列、積み上げ、横向きで表示できます。 |
| [レーダーチャート](/charts/radar) | `radar` | 共通の指標で複数の項目を比較します。各項目を、同じ中心を囲む輪郭で示します。 |
| [ウォーターフォールグラフ](/charts/waterfall) | `waterfall` | 初期値から最終値に至るまでの増減を段階ごとに示します。 |
| [範囲グラフ](/charts/range) | `range` | 2つの値の間の範囲を示し、それぞれの始点と終点を比較できます。 |
| [ダンベルチャート](/charts/dumbbell) | `dumbbell` | 各項目の2つの値を線で結び、その差を示します。 |
| [円グラフ](/charts/pie) | `pie` | 全体の内訳を円の扇形で示します。 |
| [ドーナツグラフ](/charts/donut) | `donut` | 全体の内訳を、中央に置いた1つの数値の周りに示します。 |
| [リンググラフ](/charts/rings) | `rings` | 複数の測定値を個別のリングで示し、それぞれの全体に対する割合を塗りで表します。 |
| [マリメッコチャート](/charts/marimekko) | `marimekko` | 列の幅で合計を示し、列を分割して内訳を表します。 |
| [ファネルチャート](/charts/funnel) | `funnel` | 1つのプロセスの各段階を、先に進むほど細くなる形で示します。 |
| [ワッフルチャート](/charts/waffle) | `waffle` | 100個のセルで全体を示します。1セルは全体の1%です。 |
| [ツリーマップ](/charts/treemap) | `treemap` | 全体の内訳を、構成比に応じた面積のタイルで示します。 |
| [サンバーストチャート](/charts/sunburst) | `sunburst` | 全体とその内訳、さらに各部分の内訳を2つのリングで示します。 |
| [ヒストグラム](/charts/histogram) | `histogram` | 測定値の分布を示します。区切りのよい数値で階級を分け、その度数を棒の高さで表します。 |
| [箱ひげ図](/charts/box) | `box` | 複数のグループの分布を、それぞれ5つの統計量に基づく箱、中央値、ひげで示します。 |
| [ヒートマップ](/charts/heatmap) | `heatmap` | 2つのスケールにまたがるパターンを、値に応じたセルの濃淡で示します。 |
| [散布図](/charts/scatter) | `scatter` | 各項目を1つの点として、2つの指標の関係を示します。 |

折れ線、面、棒は共通のスケールを使うため、1つのチャートに混在させられます。たとえば系列に個別の `type` を指定すると、棒グラフに折れ線を重ねられます。

## 値の表示とキー操作 \{#readout\}

`chart-tip` は値を表示する領域です。データ点の名前に続き、系列ごとに色見本の線、系列名、値を1行で表示します。データ点の横で余裕のある側に置かれ、表示領域自体の高さに応じて上下にずれるため、スクリプトで配置を計算しなくてもプロットからはみ出しません。ビヘイビアはデータ点のマークが持つ情報を使って内容を埋め、点の位置を `--chart-x`、`--chart-y`、`--chart-reach` で渡します。

データ点の数にかかわらず、Tabキーでフォーカスする位置はプロット全体で1か所です。矢印キーでデータ点間を移動し、それぞれの値を表示できます。タッチ操作でも、チャートに沿って指を動かすと同じように確認できます。

## 凡例 \{#legend\}

系列が2つ以上あるチャートには凡例があり、色に加えて名前でも系列を区別できます。各項目はチェックボックスを包むラベルです。Tabキーで移動し、Spaceキーで切り替えられます。チェックを外すと該当する系列が非表示になり、スケールは表示中の系列に合わせて調整されます。残った系列の色は維持されます。系列が1つのチャートは、タイトルで内容が分かるため凡例を表示しません。

`toggle: false` は凡例を通常のリストとして出力します。周囲の文章に系列名が書かれている場合などは、`legend: false` で凡例を省略できます。チャートの値は非表示の系列名です。`chart()` の戻り値から読み取ったり、外部から設定して系列を非表示にしたりできます。

## 色 \{#color\}

系列が1つのチャートは、インク色の `--chart-color` で描画します。複数の系列や全体の内訳には、青、オレンジ、ティール、紫、アンバー、ピンク、緑、空色の順でカテゴリ色を割り当てます。どちらの配色モードでも、一般的な色覚特性で隣り合う色を見分けられます。9つ目からは同じ順序を繰り返すため、残りを「その他」にまとめるか、別のチャートに分けてください。

対象に合わせて色を固定する場合は、系列に `category` を指定します。たとえば東京を青にすると、リスト内での位置にかかわらず、チャート、[バッジ](/components/badge)、表の行で色をそろえられます。系列の色にステータス色は使いません。系列が異常な状態にある場合は、テキストで伝えます。

## スケールと数値 \{#scale\}

スケールの下限は0で、負の値がある場合は0未満になります。上限は最大値を超える区切りのよい数値で、およそ4段階の目盛りに分けます。`min` と `max` で両端を固定でき、`ticks` で段階数の目安を変更できます。棒の長さが値を表すため、棒グラフのスケールは0から始めてください。

`format` は値の表示欄や棒の端の数値を整形し、`tickFormat` はスケールの目盛り値を整形します。既定では、目盛り値が10,000未満なら全桁を表示し、それを超える値は短縮表記にします。どちらも数値を受け取って文字列を返します。`locale` は数値の書式に使うBCP 47タグで、既定は `en-US` です。サーバーでチャートを生成する場合は、クライアント側と同じ書式になるように指定してください。

| オプション | 既定 | |
| --- | --- | --- |
| `type` | `'bar'` | 描画形式。[形式](#forms)にあるタイプのいずれか |
| `label` | なし | チャートの内容と単位を示す、プロットのアクセシブルな名前 |
| `labels` | `[]` | スケールに沿った名前、レーダーチャートの周囲の名前、またはヒートマップの列見出し |
| `series` | `[]` | 各系列は `name` と、形式に応じた `values`、`value`、`points`、`ranges`、`children` のいずれかを持ちます。必要に応じて `category`、`type`、`low` と `high`、リングの `max` を指定できます |
| `stacked` | `false` | 棒や面を積み上げます。`'percent'` は各積み上げの合計を100%にし、`'stream'` は積み上げた面全体の中心を中央線にそろえます |
| `horizontal` | `false` | 棒、レンジ、ダンベル、箱ひげを横向きにします |
| `mark` | `'bar'` | `'lollipop'` は棒を先端に点が付いた線として描きます |
| `curve` | `'smooth'` | `smooth`、`linear`、`step` のいずれか |
| `min`, `max`, `ticks` | 自動調整、`4` | スケールの下限、上限、段階数の目安。散布図の横方向には `xMin`、`xMax`、`xTicks` を使います |
| `axis` | `true` | 目盛り値を表示するかどうか。タイル内の小さなチャートでは、`false` で細い補助線だけを残せます |
| `format`, `tickFormat` | ロケールに従う | 値と目盛り値の表示形式。散布図の横方向には `xFormat` を使います |
| `dots`, `values` | `false` | 折れ線の各データ点に点を描くか、各棒に値を表示するかを指定します |
| `current` | なし | `aria-current` を付けるデータ点のインデックス |
| `legend`, `toggle` | 系列が2つ以上の場合、`true` | 凡例を出力するか、凡例の項目をチェックボックスにするかを指定します |
| `hole`, `center` | `.7`、なし | ドーナツグラフの穴の大きさと、ドーナツグラフまたはリングチャートの中央に表示する内容 |
| `total` | なし | ウォーターフォールグラフの最後に表示する棒の名前 |
| `bins` | データ件数から算出 | ヒストグラムで測定値を分ける階級数の目安 |
| `ascending` | `false` | 順位推移グラフで最小値を1位にします |
| `words` | 英語 | 箱ひげ図の5つの統計量の名前。`min`、`q1`、`median`、`q3`、`max` |
| `hidden` | `[]` | 非表示にする系列の名前 |
| `locale` | `'en-US'` | 数値の書式に使うBCP 47タグ |
| `draw` | なし | 独自のレンダラーにチャートの出力を任せるためのコールバック。非表示の系列名が渡されます |

## アニメーション \{#motion\}

マークは初めて表示されるときにアニメーションで描かれます。棒は基準線から順に伸び、折れ線は始点から描かれ、扇形やレーダーチャートの輪郭は中心から開き、リングは徐々に塗りつぶされます。値の表示欄は点から点へ滑らかに移動します。細い補助線、点、ほかの棒の強調の変化は、操作に追従するよう即座に反映されます。動きを抑える設定では、マークは描画済みの状態で現れ、値の表示欄もすぐに移動します。

## ブラウザーの機能 \{#platform\}

- **棒の角の丸みと伸びるアニメーション**には、SVG図形の `clip-path` を使います。SVG図形をCSSの基本図形でクリップできないブラウザーでは、角が直角の棒が初めから全長で表示されます。
- **面グラフのフェード**には、パスの `mask-image` を使います。未対応の場合、面は均一な色で表示されます。
- **点の半径**には、CSSの `r` プロパティを使い、`--chart-dot` で設定します。未対応の場合、マークアップで指定した半径が使われます。
- **ラベルの間引き**には、プロット本体のコンテナークエリーを使います。未対応の場合はすべてのラベルが表示されます。
- **初回描画のアニメーション**には `@starting-style` を使います。未対応の場合、マークは描画済みの状態で表示されます。

## チャートの適用範囲 \{#limits\}

チャートは数百個程度のマークを想定しており、読み手はそれぞれの要素にアクセスできます。数千のデータ点、ストリーミングデータ、ズーム、ブラシ選択、地図、ローソク足には、Canvasに描画するチャートエンジンが適しています。簡潔な表示には、小さなコンポーネントもあります。文章中の推移には[スパークライン](/components/sparkline)、単独の数値には[統計値](/components/stat)、1つの測定値には[メーター](/components/meter)や[ゲージ](/components/gauge)、1本の棒で合計の内訳を示すには[内訳バー](/components/breakdown)、多数の小さな値にまたがるパターンには[ヒートマップ](/components/heatmap)を使えます。選び方は[チャートガイド](/guide/charts)を参照してください。

## アクセシビリティ \{#accessibility\}

- `label` には、測定対象と単位が分かる文を指定してください。プロットはリストとして扱われ、この文がその名前になります。
- 各データ点は「木曜：東京 71、大阪 49」のように値を名前に含むリスト項目です。そのため、スクリプトや表がなくても、スクリーンリーダーは通常のリストと同じようにチャートを読み上げます。細い補助線、目盛り、値の表示欄は、データ点と情報が重複するため読み上げの対象外です。
- 値の表示欄は目で確認するための補助です。ホバー時、フォーカス時、タッチ操作時に表示され、<kbd class="kbd">Esc</kbd> で閉じられます。
- 色に加えて、凡例には系列名を、値の表示欄には系列名と値を示します。カテゴリ色はステータスの表示とは別です。
- フォーカスされたデータ点は、外接する四角形を使わず、帯、点、扇形、リングのいずれかの形に沿って輪郭を描きます。
- 強制カラーモードでは、インク色と細い補助線にシステムカラーを使い、フォーカスをハイライト色で示します。系列には割り当てられた色が残るため、凡例に系列名を示してください。
- スケールは言語にかかわらず左から進みます。名前、値、凡例はページの書字方向に従います。

## React、Svelte、Vue \{#frameworks\}

`chart` コンポーネントは `chartLayout()` からチャートを生成するため、サーバーが最初に送るHTMLにチャートが含まれます。さらにビヘイビアを適用して、値の表示欄とキー操作を有効にします。上記のオプションをpropsとして受け取り、値として非表示の系列名を保持します。`npx master-ui add chart` でプロジェクトにコピーできます。コンポーネントの構成と使い方は[React、Svelte、Vue](/guide/frameworks)を参照してください。

<FrameworkSource name="chart" />

コピーしたコンポーネントが折れ線、面、棒だけを描くなら、`chart.js` のインポートをチャートコアと Cartesian 形式に置き換えます。必要な型も `chart-core.js` から読み込み、形式をモジュールのスコープで登録します。

```js
import { chartCore as chart, chartForms, chartLayout } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
```

別名により、コピーしたコンポーネントの既存のビヘイビアの接続を保てます。サーバーは `chartLayout()` で描画し、接続後は矢印キーでデータ点を移動し、Escape で値の表示を閉じられます。
