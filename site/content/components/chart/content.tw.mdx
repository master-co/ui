圖表可將數值畫成折線圖、面積圖、長條圖、圓餅圖、環圈圖、圓環圖、雷達圖或散佈圖。它是一個 SVG，會配合所給的寬度：位於刻度上的內容以百分比定位，無論繪圖區伸展多寬，線條都維持原本的粗細，文字也絕不會被縮放。只有一組資料序列的圖表使用墨色，就像[進度條](/components/progress)以墨色填滿一樣；有多組序列時，各序列採用[分類色](/components/category)的顏色。每個資料點都是一個清單項目，用文字說出自己的數值。

## 繪製方式 \{#how-it-is-drawn\}

繪圖區是一個沒有 `viewBox` 的 `<svg>`：寬度與所在空間相同，高度為 `--chart-height`，未另行指定時為 14rem。細線、刻度標記、長條和圓點都以繪圖區的百分比寫成，因此位於 `x="42%"` 的長條在任何寬度下都維持在 42% 的位置，圓角維持原本的半徑，文字也維持原本的大小。

只有必須以路徑繪製的圖形，也就是折線、面積或扇形，才畫在 `chart-canvas` 中：這是一個巢狀 SVG，方框為 100 乘 100，並伸展至整個繪圖區。筆畫不會隨它縮放，因此不論卡片是窄是寬，折線的寬度都是 `--chart-stroke`。

寬度改變時無須測量任何東西，也無須重新繪製，因此伺服器、[框架元件](#frameworks)和行為產生的都是同一份標記。圖表會填滿所給的寬度：與其他內容排成一列時，請為它指定寬度，或讓它伸展。

## 繪製圖表 \{#draw\}

行為會把圖表寫入帶有 `chart` 類別的元素。`label` 說明圖表呈現的內容及單位；`labels` 為刻度上的每一格命名，每組序列則為每一格各提供一個數值。

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

在伺服器上，`chartMarkup()` 會以字串傳回相同的圖表，其中的所有文字都已跳脫；把它放進元素，頁面在任何腳本執行前就能閱讀。`chartLayout()` 則以資料傳回圖形的內容：刻度及其刻度標記、每組序列的路徑，以及每個資料點，連同它的圖形和描述該點的句子。

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

對該元素呼叫 `chart()` 且不傳入序列時，行為會直接操作已寫好的圖表；`@master/ui/behaviors` 的 `attach()` 則會對頁面上的每個圖表這麼做。

## 圖表類型 \{#forms\}

每種圖表類型都有自己的頁面，包含範例和與它相關的選項。

| 類型 | `type` | 用途 |
| --- | --- | --- |
| [折線圖](/charts/line) | `line` | 用折線連接各點，呈現前後相連的數值變化。 |
| [面積圖](/charts/area) | `area` | 在折線下方淡染同色，可單獨呈現，也可堆疊成總量。 |
| [長條圖](/charts/bar) | `bar` | 以立在基線上的長條比較數量，可並排、堆疊或橫向排列。 |
| [雷達圖](/charts/radar) | `radar` | 在相同的指標上比較少數幾個對象，每個對象是一圈繞著中心的輪廓。 |
| [圓餅圖](/charts/pie) | `pie` | 用圓的扇形呈現一個整體由哪些部分組成。 |
| [環圈圖](/charts/donut) | `donut` | 整體的各個部分圍成一圈，中央放一個數字。 |
| [圓環圖](/charts/rings) | `rings` | 少數幾個讀數，各自在自己的圓環上朝目標填滿。 |
| [散佈圖](/charts/scatter) | `scatter` | 兩個指標互相對照，每個對象是一個點。 |

## 數值提示與按鍵 \{#readout\}

`chart-tip` 是數值提示：先是資料點的名稱，接著每組序列各占一列，列出一道該序列顏色的短線、序列名稱及數值。它立在資料點旁空間較大的那一側，並沿著自身的高度滑動，因此絕不會離開繪圖區，也無須由腳本定位。行為會用資料點的圖形所帶的資料填入內容，並把資料點的位置以 `--chart-x`、`--chart-y` 和 `--chart-reach` 傳給它。

無論有多少個資料點，繪圖區在 Tab 順序中都只占一個停駐點。方向鍵可在資料點之間移動，並顯示各點的數值提示；手指沿著圖表滑動也有相同效果。

## 圖例 \{#legend\}

有兩組以上序列的圖表會有圖例：顏色絕不是辨別序列的唯一方式。每個項目都是包住核取方塊的 label，因此可用 Tab 移到項目上，再按 Space 切換；取消勾選後，對應的序列會從圖表中移除，刻度會配合剩下的內容調整，其他序列則保留原本的顏色。只有一組序列的圖表沒有圖例，因為標題已說明畫的是什麼。

`toggle: false` 會把圖例寫成一般清單，`legend: false` 則省略圖例，適用於周圍文字已說明各序列名稱的圖表。圖表的值是已隱藏序列的名稱：可從 `chart()` 的傳回值讀取，也可以設定它，從外部隱藏序列。

## 顏色 \{#color\}

只有一組序列的圖表以 `--chart-color` 繪製，也就是墨色。有多組序列的圖表，以及整體的各個組成部分，會依固定順序各取一個分類色：藍色、橘色、藍綠色、紫羅蘭色、琥珀色、粉紅色、綠色和天藍色。在兩種色彩配置下，順序相鄰的顏色對常見的色覺辨認障礙類型而言都仍可區分。超過八個時，順序會從頭開始，因此請把其餘部分併入「其他」，或另外畫一個圖表。

顏色跟著對象走時，請為序列指定自己的 `category`：不論 Tokyo 排在清單的哪個位置，它在圖表、[徽章](/components/badge)和表格的對應列中都是藍色。狀態色絕不用來代表序列；出現問題的序列要用文字說明。

## 刻度與數字 \{#scale\}

刻度從零開始，有小於零的數值時則從零以下開始，並結束於高於最大值的整齊數字，大約分成四格標示。`min` 和 `max` 可固定任一端，`ticks` 可要求不同的格數。長條的刻度應從零開始：長條的長度就是它的數值。

`format` 決定數值在數值提示和長條末端的寫法，`tickFormat` 決定刻度數字的寫法；刻度數字小於 10,000 時會完整寫出，超過時則採精簡寫法。兩者都接收數字並傳回字串。`locale` 是數字所用的 BCP 47 標籤，預設為 `en-US`；由伺服器寫出圖表時請提供它，讓兩端的結果一致。

| 選項 | 預設值 | |
| --- | --- | --- |
| `type` | `'bar'` | `line`、`area`、`bar`、`pie`、`donut`、`rings`、`radar` 或 `scatter` |
| `label` | 無 | 圖表呈現的內容及單位，也就是繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿著刻度排列的名稱，或環繞雷達圖的名稱 |
| `series` | `[]` | 每組序列都有 `name` 和 `values`；扇形或圓環改用 `value`，散佈圖改用 `points`；另可選擇性提供 `category`、`type`，以及圓環的 `max` |
| `stacked` | `false` | 長條或面積彼此堆疊 |
| `horizontal` | `false` | 長條橫向延伸 |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 自動配合、`4` | 刻度的兩端，以及大約用幾格標示；散佈圖的橫向刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否寫出刻度數字；`false` 只保留細線，適用於資訊小卡中的小型圖表 |
| `format`, `tickFormat` | 依語系 | 數值和刻度標記的寫法；散佈圖的橫向刻度使用 `xFormat` |
| `dots`, `values` | `false` | 標出折線上的每個點；寫出每根長條的數值 |
| `current` | 無 | 標有 `aria-current` 的資料點的索引 |
| `legend`, `toggle` | 有兩組序列時寫出、`true` | 是否寫出圖例，以及圖例項目是否為核取方塊 |
| `hole`, `center` | `.7`、無 | 環圈圖的中空大小，以及環圈圖或圓環圖中央顯示的內容 |
| `hidden` | `[]` | 排除在外的序列名稱 |
| `locale` | `'en-US'` | 數字所用的 BCP 47 標籤 |
| `draw` | 無 | 接手寫出圖表的工作：呼叫時會傳入隱藏序列的名稱，供自行寫出圖表的算繪器使用 |

## 動態效果 \{#motion\}

圖形首次出現時會自行繪入：長條從基線依序升起，折線從起點延伸進來，扇形和雷達圖的形狀從中心展開，圓環則逐漸填滿。數值提示會在資料點之間平順滑動，而標示資料點的細線、圓點和退為淡色的長條則會立即回應，因為凸顯效果必須跟得上手的動作。啟用減少動態效果時，沒有任何東西會移動：圖形出現時就已畫好，數值提示也會立即換位置。

## 由平台完成的部分 \{#platform\}

- **長條的圓角和升起效果**是套用在 SVG 形狀上的 `clip-path`。瀏覽器若無法用 CSS 形狀裁切 SVG 形狀，就會以完整長度畫出方角的長條。
- **面積的漸淡效果**是套用在路徑上的 `mask-image`。不支援時，面積會是均勻的淡色。
- **圓點的半徑**是 CSS 的 `r` 屬性，由 `--chart-dot` 設定。不支援時，圓點會維持標記中所寫的半徑。
- **精簡標籤**是套用在繪圖區主體上的容器查詢。不支援時，所有標籤都會保留。
- **繪入效果**使用 `@starting-style`。不支援時，圖形出現時就已畫好。

## 圖表不敷使用時 \{#limits\}

圖表是為數百個圖形而繪製的，每個圖形都是讀者可以到達的元素。數千個資料點、串流進來的數值、縮放、範圍刷選、地圖或 K 線圖，則屬於在 canvas 上繪圖的圖表引擎。若需求比圖表更小，還有更小的元件可用：[迷你趨勢線](/components/sparkline)呈現句子中的趨勢，[統計數值](/components/stat)呈現一個數字，[量表](/components/meter)或[儀表](/components/gauge)呈現一個讀值，[占比分布](/components/breakdown)沿著一條長條呈現總和的組成，[熱圖](/components/heatmap)則呈現大量較小數值之間的規律。[圖表](/guide/charts)指南說明該選哪一個。

## 無障礙 \{#accessibility\}

- 請為 `label` 提供一句話，說明測量的項目及單位：它是繪圖區的名稱，而繪圖區是一份清單。
- 每個資料點都是以其數值命名的清單項目，例如「Thu: Tokyo 71, Osaka 49」，因此螢幕閱讀器會像讀清單一樣讀出圖表，無須腳本，也無須表格。細線、刻度標記和數值提示都會對螢幕閱讀器隱藏，因為它們只是重複資料點已說出的內容。
- 數值提示是給眼睛的便利功能。它會在指標懸停、取得焦點和手指觸碰時出現，按 <kbd class="kbd">Esc</kbd> 可將它隱藏。
- 顏色絕不單獨傳達資訊：序列的名稱會列在圖例中，數值提示也會在數值旁標出序列名稱。分類色不代表狀態。
- 取得焦點的資料點，外框會畫在它所屬的那一格、圓點、扇形或圓環上，而不是圍著一個方框。
- 在強制色彩模式下，墨色和細線會採用系統顏色，焦點則以醒目提示色繪製。序列會保留所指定的顏色，因此請在圖例中標出序列名稱。
- 在所有語言中，刻度都從左側開始。名稱、數值和圖例則依循頁面的書寫方向。

## React、Svelte 和 Vue \{#frameworks\}

`chart` 元件會依 `chartLayout()` 寫出圖表，因此伺服器送出的初始 HTML 就包含圖表；元件也會掛載行為，由行為填入數值提示並回應按鍵。它以 props 接收上述選項，其值則是已隱藏序列的名稱。用 `npx master-ui add chart` 將它複製到專案中，並參閱 [React、Svelte 和 Vue](/guide/frameworks) 了解元件的實作及用法。
