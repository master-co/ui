## 繪製方式 \{#how-it-is-drawn\}

繪圖區使用沒有 `viewBox` 的 `<svg>`，寬度填滿可用空間，高度由 `--chart-height` 設定，預設為 14rem。極細線、刻度線、長條和圓點都以繪圖區的百分比定位，所以 `x="42%"` 的長條在任何寬度下都位於 42% 的位置，圓角半徑和文字大小也維持原樣。

只有必須用路徑表示的圖形，也就是線條、區域或扇形，才會繪製在 `chart-canvas` 裡。這是一個座標範圍為 100 × 100 的巢狀 SVG，會拉伸至填滿繪圖區。筆畫粗細不隨之縮放，所以無論卡片寬窄，線寬都是 `--chart-stroke`。

寬度改變時，圖表無須測量尺寸或重新繪製，因此伺服器、[框架元件](#frameworks)和行為都會產生相同的標記。圖表會填滿可用寬度。若將它和其他項目並排，請指定寬度或讓它伸展以填滿剩餘空間。

## 繪製圖表 \{#draw\}

圖表行為會將圖表寫入帶有 `chart` 類別的元素。`label` 說明圖表呈現的內容與單位，`labels` 為刻度上的各個位置命名，而每個資料序列在每個位置各有一個數值。

```js name=app.js
import { chart } from '@master/ui/behaviors/chart.js'

chart(document.querySelector('.chart'), {
  type: 'line',
  label: 'Latency by region, in milliseconds',
  labels: ['Jan', 'Feb', 'Mar', 'Apr'],
  series: [
    { name: 'Tokyo', values: [42, 44, 41, 47] },
    { name: 'Frankfurt', values: [61, 58, 63, 66] },
  ],
})
```

在伺服器端，`chartMarkup()` 會以字串傳回相同的圖表，其中的文字均已跳脫。將字串放入元素後，讀者在任何腳本執行前就能閱讀頁面上的圖表。`chartLayout()` 會傳回繪圖所用的資料，包括刻度範圍與刻度、各資料序列的路徑，以及每個資料點的圖形標記與描述文字。

```js name=server.js
import { chartMarkup } from '@master/ui/behaviors/chart.js'

const html = `<figure class="chart">${chartMarkup({ type: 'bar', label, labels, series })}</figure>`
```

對該元素呼叫 `chart()` 且不傳入資料序列，即可讓既有的圖表標記具備互動行為。`@master/ui/behaviors` 的 `attach()` 則會為頁面上的所有圖表加上互動行為。

### 只載入頁面使用的圖表形式 \{#forms-only\}

`chart.js` 包含所有形式，壓縮程式碼並以 gzip 壓縮後約為 16 kB。若頁面只繪製一兩種圖表，可以只載入需要的形式。`chart-core.js` 約為 6 kB，本身未包含任何圖表形式。各形式各有模組，可傳給 `chartForms()`。折線圖、區域圖和長條圖共用刻度，三者合計增加約 2 kB，其餘形式各增加不到 1 kB。

```js name=app.js
import { chartCore, chartForms } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
chartCore(document.querySelector('.chart'), { type: 'line', label, labels, series })
```

| 模組 | 繪製內容 |
| --- | --- |
| `chart-cartesian.js` | `line`, `area`, `bar` |
| `chart-scatter.js` | `scatter` |
| `chart-pie.js` | `pie`, `donut` |
| `chart-rings.js`, `chart-radar.js`, `chart-sunburst.js` | `rings`, `radar`, `sunburst` |
| `chart-waterfall.js`, `chart-range.js` | `waterfall`; `range`, `dumbbell` |
| `chart-slope.js`, `chart-bump.js` | `slope`, `bump` |
| `chart-marimekko.js`, `chart-funnel.js`, `chart-waffle.js`, `chart-treemap.js` | `marimekko`, `funnel`, `waffle`, `treemap` |
| `chart-histogram.js`, `chart-box.js`, `chart-heatmap.js` | `histogram`, `box`, `heatmap` |

若指定了尚未載入的圖表類型，就會立即擲出錯誤，指出應匯入的模組。

## 圖表形式 \{#forms\}

每種圖表都有專屬頁面，提供範例與相關選項。

| 形式 | `type` | 用途 |
| --- | --- | --- |
| [折線圖](/charts/line) | `line` | 以線段依序連接資料點，呈現數值變化。 |
| [面積圖](/charts/area) | `area` | 在折線下方填上同色的淡色，可單獨呈現，也可堆疊以顯示總量。 |
| [斜率圖](/charts/slope) | `slope` | 從線條的斜率與交會看出兩個時間點之間的上升、下降與相對位置變化。 |
| [排名變化圖](/charts/bump) | `bump` | 以線條呈現各項目的排名變化，線條交會處表示排名互換。 |
| [長條圖](/charts/bar) | `bar` | 用共用基準線的長條比較數量，可並排、堆疊或橫向排列。 |
| [雷達圖](/charts/radar) | `radar` | 沿共用指標比較多個項目，每個項目各以環繞同一個中心的輪廓表示。 |
| [瀑布圖](/charts/waterfall) | `waterfall` | 用逐步增加與減少的數值，呈現起始值如何變成最終值。 |
| [區間圖](/charts/range) | `range` | 呈現各區間的起點與終點。 |
| [啞鈴圖](/charts/dumbbell) | `dumbbell` | 以線段連接各項目的兩個數值，凸顯兩者之間的差距。 |
| [圓餅圖](/charts/pie) | `pie` | 用扇形呈現整體的組成。 |
| [圓環圖](/charts/donut) | `donut` | 在中央數值周圍呈現整體的各個部分。 |
| [多環圖](/charts/rings) | `rings` | 每個讀值各用一個環，以填滿的比例表示讀值占總量的多少。 |
| [馬賽克圖](/charts/marimekko) | `marimekko` | 各長條的寬度反映總量，條內再依組成比例分割。 |
| [漏斗圖](/charts/funnel) | `funnel` | 呈現流程的各個階段，寬度逐階縮小。 |
| [華夫格圖](/charts/waffle) | `waffle` | 以一百個方格呈現整體，每格代表 1%。 |
| [樹狀矩形圖](/charts/treemap) | `treemap` | 用矩形區塊呈現整體的各個部分，區塊面積反映各自的占比。 |
| [旭日圖](/charts/sunburst) | `sunburst` | 用兩層圓環呈現整體、各個部分，以及各部分的細項。 |
| [直方圖](/charts/histogram) | `histogram` | 用易讀的數值作為組界，將讀值分入各組距，並以柱高表示各組的筆數，以呈現分布。 |
| [盒鬚圖](/charts/box) | `box` | 每組以五個統計量呈現分布，畫出盒體、中位數與兩端的鬚線。 |
| [熱圖](/charts/heatmap) | `heatmap` | 在兩個維度上呈現資料模式，以格子的色深表示數值。 |
| [散佈圖](/charts/scatter) | `scatter` | 比較兩項指標之間的關係，每個項目以一個點表示。 |

折線圖、區域圖和長條圖可以共用刻度並放在同一張圖表中。為資料序列指定自己的 `type`，就會按指定形式繪製，例如在長條上疊加折線。

## 數值提示與鍵盤操作 \{#readout\}

`chart-tip` 是數值提示。它先顯示資料點名稱，再逐列顯示各資料序列的色線、名稱與數值。提示會出現在資料點旁空間較多的一側，並依自身高度調整垂直位置，因此能留在繪圖區內，無須由腳本定位。互動行為會從資料點的圖形標記取得內容，並透過 `--chart-x`、`--chart-y` 和 `--chart-reach` 傳遞資料點的位置。

無論有多少資料點，整個繪圖區在 Tab 鍵巡覽順序中都只占一站。按方向鍵可逐點移動並查看數值提示，也可以用手指沿著圖表滑動。

## 圖例 \{#legend\}

有兩個以上資料序列的圖表會顯示圖例，讓使用者也能透過名稱辨識資料序列。每個圖例項目都是包住核取方塊的標籤，可按 Tab 移入焦點，再按空白鍵切換。取消勾選後，對應的資料序列會從圖表隱藏，刻度會配合剩餘資料調整，其他序列則保留原有色彩。單一資料序列的圖表由標題說明繪製內容，因此省略圖例。

`toggle: false` 會將圖例顯示為一般清單。若圖表周圍的文字已說明各資料序列的名稱，可用 `legend: false` 省略圖例。圖表的值是隱藏的資料序列名稱。可從 `chart()` 的回傳結果讀取這個值，也可從外部設定它來隱藏資料序列。

## 色彩 \{#color\}

單一資料序列使用前景色 `--chart-color`。多個資料序列或整體的各個部分，依固定順序使用類別色：藍、橘、藍綠、紫、琥珀、粉紅、綠和天藍。無論淺色或深色配置，常見色覺辨識障礙的使用者仍能區分相鄰的色彩。超過八個就會循環使用配色，可將其餘項目合併為「其他」，或另畫一張圖表。

若同一項目在各處都要使用同一色彩，請為資料序列指定 `category`。例如東京無論排在清單的哪個位置，在圖表、[徽章](/components/badge)和表格列中都使用藍色。資料序列不使用狀態色。若某個序列的表現不佳，請用文字說明。

## 刻度與數值 \{#scale\}

刻度從零起算，有負值時則從零以下起算，並以高於最大值的易讀數值作為上限。預設約分成四個間距。可用 `min` 和 `max` 固定兩端，再用 `ticks` 指定其他間距數。長條圖的刻度應從零開始，因為長條的長度代表數值。

`format` 設定數值提示與長條末端的數值格式，`tickFormat` 設定刻度的數字格式。刻度在 10,000 以下顯示完整數字，超過時採用精簡格式。兩者均接收數字並傳回字串。`locale` 是用於數字格式的 BCP 47 語言標籤，預設為 `en-US`。由伺服器產生圖表時，請指定此選項，讓伺服器與用戶端使用相同的格式。

| 選項 | 預設 | |
| --- | --- | --- |
| `type` | `'bar'` | [圖表形式](#forms)中列出的其中一種類型 |
| `label` | 無 | 繪圖區的無障礙名稱，說明圖表呈現的內容與單位 |
| `labels` | `[]` | 刻度各處、雷達圖周圍或熱圖各欄上方的名稱 |
| `series` | `[]` | 每個資料序列都有 `name`，並依圖表形式提供 `values`、`value`、`points`、`ranges` 或 `children`。也可選填 `category`、`type`、`low`、`high`，以及環形量表的 `max` |
| `stacked` | `false` | 堆疊長條或區域。`'percent'` 將各組堆疊調整為 100%，`'stream'` 使堆疊區域沿中線置中 |
| `horizontal` | `false` | 橫向繪製長條、範圍、啞鈴與盒鬚 |
| `mark` | `'bar'` | `'lollipop'` 用末端帶圓點的線段表示長條 |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 自動配合資料、`4` | 刻度的兩端與約略的間距數。散佈圖的橫軸刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否顯示刻度數字。用於區塊內的小圖表時，可設為 `false` 以只保留極細線 |
| `format`, `tickFormat` | 依語言標籤 | 數值與刻度的顯示格式。散佈圖的橫軸刻度使用 `xFormat` |
| `dots`, `values` | `false` | 標示折線上的每個資料點，以及顯示各長條的數值 |
| `current` | 無 | 標有 `aria-current` 的資料點索引 |
| `legend`, `toggle` | 兩個以上資料序列時顯示、`true` | 是否顯示圖例，以及圖例項目是否使用核取方塊 |
| `hole`, `center` | `.7`、無 | 圓環圖的中空比例，以及圓環圖或環形量表的中央內容 |
| `total` | 無 | 瀑布圖最後一個長條的名稱 |
| `bins` | 依資料筆數 | 直方圖將讀值分成的約略組數 |
| `ascending` | `false` | 在排名變化圖中，數值最低者排第一 |

| `draw` | 無 | 由自行繪製圖表的渲染器接手，呼叫時會傳入隱藏的資料序列名稱 |

## 動態效果 \{#motion\}

圖形標記初次顯示時會逐步繪出。長條依序從基準線升起，折線從起點延伸，扇形與雷達圖的圖形從中心展開，環形量表則逐步填滿。數值提示會在資料點之間滑動，極細線、圓點和長條淡化等醒目效果則會立即跟上使用者的操作。啟用減少動態效果時，圖形會直接以完成狀態顯示，數值提示也會立即換位。

## 瀏覽器功能 \{#platform\}

- **長條的圓角與升起效果**以 SVG 圖形上的 `clip-path` 實作。若瀏覽器不支援以 CSS 形狀裁切 SVG 圖形，長條會以直角和完整長度顯示。
- **區域的漸淡效果**由路徑上的 `mask-image` 實作。缺少此功能時，整塊區域會以均勻的淡色顯示。
- **圓點半徑**使用 CSS 的 `r` 屬性，由 `--chart-dot` 設定。缺少此功能時，圓點會保留標記中指定的半徑。
- **減少標籤數量**由繪圖區主體的容器查詢控制。缺少容器查詢時，會保留所有標籤。
- **初次繪出的效果**使用 `@starting-style`。缺少此功能時，圖形標記會直接以完成狀態顯示。

## 圖表的適用範圍 \{#limits\}

圖表適合呈現數百個圖形標記，每個標記都是讀者可存取的元素。若要處理數千個資料點、串流數值、縮放、框選、地圖或 K 線圖，請使用在 Canvas 上繪製的圖表引擎。若只需要呈現少量資訊，也有更精簡的元件可用。用[走勢圖](/components/sparkline)在句子中呈現趨勢，用[統計數值](/components/stat)呈現單一數字，用[量表](/components/meter)或[儀表](/components/gauge)呈現單一讀值，用[組成長條](/components/breakdown)在一根長條上呈現總量的組成，或用[熱圖](/components/heatmap)呈現許多小數值形成的模式。請參閱[圖表指南](/guide/charts)選擇合適的元件。

## 無障礙 \{#accessibility\}

- 為 `label` 撰寫一句話，說明測量的內容和單位。這句話是繪圖區的名稱，而繪圖區會以清單呈現。
- 每個資料點都是以其數值命名的清單項目，例如「週四：東京 71、大阪 49」。無須腳本或表格，螢幕閱讀器就能像讀取清單一樣讀取圖表。極細線、刻度線和數值提示會對螢幕閱讀器隱藏，因為資料點已提供相同資訊。
- 數值提示方便讀者直接查看數值。將指標停在資料點上、讓資料點取得焦點或用手指觸碰時都會顯示，按 <kbd class="kbd">Esc</kbd> 即可隱藏。
- 除了色彩，圖例也會標示資料序列的名稱，數值提示則會並列顯示名稱與數值。類別色不代表狀態。
- 資料點取得焦點時，焦點外框會沿著其帶狀區域、圓點、扇形或圓環的輪廓繪製。
- 在強制色彩模式下，前景色與極細線會採用系統色，焦點則使用系統的醒目提示色。各資料序列會保留指定色彩，請在圖例中標示其名稱。
- 無論使用哪種語言，刻度都從左側開始。名稱、數值與圖例遵循頁面的書寫方向。

## React、Svelte 與 Vue \{#frameworks\}

`chart` 元件依 `chartLayout()` 產生圖表，因此伺服器首次送出的 HTML 就包含圖表。元件也會加上互動行為，以填入數值提示並回應按鍵。元件以上述選項作為 props，其值為隱藏的資料序列名稱。使用 `npx master-ui add chart` 將元件複製到專案。請參閱 [React、Svelte 與 Vue](/guide/frameworks) 了解如何建置與使用元件。

<FrameworkSource name="chart" />

若複製的元件只繪製折線圖、面積圖或長條圖，可將原本從 `chart.js` 的匯入改成圖表核心與 Cartesian 圖形。所需型別同樣從 `chart-core.js` 匯入，並在模組層級註冊圖形。

```js
import { chartCore as chart, chartForms, chartLayout } from '@master/ui/behaviors/chart-core.js'
import { chartCartesian } from '@master/ui/behaviors/chart-cartesian.js'

chartForms(chartCartesian)
```

匯入別名讓複製的元件沿用原本的行為掛載。伺服器用 `chartLayout()` 繪製，掛載後可用方向鍵在資料點間移動，並用 Escape 關閉讀值提示。
