標題使用頁面的高對比文字色。所有尺寸都採略偏輕的中字重，靠字級和文字色呈現層級，無須加粗。換行時會平衡各行長度，避免最後一行只剩一個字詞，字級越大，字距也越緊。在任一標題元素上使用 `.heading`，由類別決定外觀，由元素決定層級。

<ComponentPreview name="default" height={272} mediumHeight={264} narrowHeight={384} title="標題" background="plain" bodyClass="flex justify-center p-lg" html={`<header class="flex flex-col gap-sm max-w(520)">
  <p class="eyebrow">Changelog</p>
  <h1 class="heading heading-2xl">Faster cold builds, and comments on previews</h1>
  <p class="lead">Dependency caches are restored before the install step, and anyone can leave a note on a preview, pinned to the element they clicked.</p>
</header>`} />

標題有兩個搭配項目。`eyebrow` 是標題上方的簡短標籤，用來交代接下來的內容類型。`lead` 是標題下方的引言，字級比內文大一階。

## 尺寸 \{#sizes\}

七種尺寸沿用全站的尺寸命名。依標題在頁面上的位置選擇字級，再依文件大綱選擇元素。同樣是 `<h2>`，在卡片中可以用 `heading-sm`，在區段開頭則可以用 `heading-2xl`。

<ComponentPreview name="sizes" height={392} mediumHeight={376} narrowHeight={368} title="尺寸" background="plain" bodyClass="p-lg" html={`<div class="flex flex-col gap-md w-full">
  <p class="heading heading-display">Display</p>
  <p class="heading heading-2xl">Two extra large</p>
  <p class="heading heading-xl">Extra large</p>
  <p class="heading heading-lg">Large</p>
  <p class="heading">Medium, the default</p>
  <p class="heading heading-sm">Small</p>
  <p class="heading heading-xs">Extra small</p>
</div>`} />

| 類別 | 尺寸 | 用途 |
| --- | --- | --- |
| `heading-display` | 2.5 至 4.25rem | 到達頁唯一的主標題 |
| `heading-2xl` | 2 至 2.5rem | 頁面標題、到達頁的區段標題 |
| `heading-xl` | 1.625 至 2rem | 應用程式中的頁面標題 |
| `heading-lg` | 1.5rem | 區段標題 |
| `heading` | 1.25rem | 子區段、對話框大小的面板標題 |
| `heading-sm` | 1.0625rem | 卡片、橫列標題 |
| `heading-xs` | 0.9375rem | 連結群組、資訊密集的面板標題 |

## 隨可用寬度調整的尺寸 \{#fluid\}

最大的三種尺寸使用容器查詢單位，以最近的尺寸容器為基準，找不到尺寸容器時則以檢視區為基準。主標題在手機的窄欄中為 2.5rem，在寬欄中可達 4.25rem，中間會隨欄寬連續縮放，無須斷點。

<PagePreview name="fluid" title="隨可用寬度調整的尺寸" height={240} tabletHeight={232} phoneHeight={280} html={`<section class="container-inline p-xl bg-surface-base">
  <h1 class="heading heading-display">Every push gets an address.</h1>
  <p class="lead mt-md max-w(480)">Choose Tablet, then Phone: the title is set smaller as its container narrows, and its lines are balanced again at each size.</p>
</section>`} />

若要讓標題隨面板寬度調整，請在面板上加上 `container-inline`，將它設為尺寸容器。

## 平衡換行 \{#balance\}

標題使用 `text-wrap: balance` 換行，瀏覽器會讓各行長度接近，所以兩行標題會排得較均勻。引言使用 `text-wrap: pretty`，避免最後一行只剩一個字詞。如果瀏覽器兩者都不支援，文字會照常換行。

標題放在寬欄中時，可用 `max-w(560)` 等方式限制行寬。平衡換行只會調整各行的長度，行數仍由可用寬度和文字內容決定。

## 無障礙 \{#accessibility\}

- 類別只設定外觀。請依序使用 `<h1>` 到 `<h6>`，避免跳級，並依各標題所在的位置選擇合適的尺寸。
- 每個頁面使用一個 `<h1>`。
- 前導標籤使用 `<p>`。螢幕閱讀器會先讀出前導標籤，再讀出標題。請勿將前導標籤設為標題，讓標題清單從標題本身開始。
- 無論背景為何，標題都使用高對比文字色。在反色面板上，請加上 `fg-text-inverse`。
