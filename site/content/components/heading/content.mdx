A heading is a title set in the ink of the page. Its weight is a light medium at every size: size and ink carry the hierarchy, not boldness. Its lines are balanced, so a title never leaves one word alone on its last line, and its tracking tightens as it grows. Use `.heading` on any heading element; the class sets the look, the element sets the level.

<ComponentPreview name="default" title="Heading" background="plain" bodyClass="flex justify-center p-lg" html={`<header class="flex flex-col gap-sm max-w(520)">
  <p class="eyebrow">Changelog</p>
  <h1 class="heading heading-2xl">Faster cold builds, and comments on previews</h1>
  <p class="lead">Dependency caches are restored before the install step, and anyone can leave a note on a preview, pinned to the element they clicked.</p>
</header>`} />

Two companions come with it. An `eyebrow` is the few words over a heading that say what kind of thing follows. A `lead` is the paragraph under it, a step larger than body text.

## Sizes \{#sizes\}

Seven sizes, named like the rest of the scale. Pick the size by the heading's place on the page, and the element by its place in the outline: an `<h2>` can be `heading-sm` in a card and `heading-2xl` at the top of a section.

  <p class="heading heading-display">Display</p>
  <p class="heading heading-2xl">Two extra large</p>
  <p class="heading heading-xl">Extra large</p>
  <p class="heading heading-lg">Large</p>

| Class | Size | Use |
| --- | --- | --- |
| `heading-display` | 2.5 to 4.25rem | The one title of a landing page |
| `heading-2xl` | 2 to 2.5rem | A page's title, a section of a landing page |
| `heading-xl` | 1.625 to 2rem | A page's title in an application |
| `heading-lg` | 1.5rem | A section |
| `heading` | 1.25rem | A subsection, a dialog-sized panel |
| `heading-sm` | 1.0625rem | A card, a bar |
| `heading-xs` | 0.9375rem | A group of links, a dense panel |

## Sizes that follow the room \{#fluid\}

The three largest sizes are written in container units. They measure the nearest size container, and where there is none, the viewport. A display heading is 2.5rem in a phone's column and 4.25rem in a wide one, with every width between; no breakpoint is involved.

<PagePreview name="fluid" title="Sizes that follow the room" fit height={360} html={`<section class="container-inline p-xl bg-surface-base">
  <h1 class="heading heading-display">Every push gets an address.</h1>
  <p class="lead mt-md max-w(480)">Choose Tablet, then Phone: the title is set smaller as its container narrows, and its lines are balanced again at each size.</p>
</section>`} />

To make a heading follow a panel instead of the page, make the panel a size container: `container-inline` on it.

## Balance \{#balance\}

A heading wraps with `text-wrap: balance`: the browser evens out the lines instead of filling each one, so a title of two lines is two lines of similar length. A lead wraps with `text-wrap: pretty`, which avoids a last line of one word. Where a browser supports neither, the text wraps as usual.

Give a heading a measure, such as `max-w(560)`, when it sits in a wide column. Balance evens the lines; it does not decide how many there are.

## Accessibility \{#accessibility\}

- The class does not make a heading. Use `<h1>` to `<h6>` in order, without skipping a level, and style each with the size its place calls for.
- A page has one `<h1>`.
- An eyebrow is a `<p>`. It is read before the heading, which is right, but it must not be a heading itself: a list of headings should start with the title.
- A heading is in strong ink on every surface. On an inverse sheet, add `fg-text-inverse`.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `heading` | A title: strong ink, a light medium weight, balanced lines |
| `heading-xs`, `heading-sm`, `heading-lg`, `heading-xl`, `heading-2xl`, `heading-display` | Sizes; the default is 1.25rem |
| `eyebrow` | A small uppercase line over a heading |
| `lead`, `lead-sm`, `lead-lg` | The paragraph under a heading |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--heading-size` | `1.25rem` | Font size |
| `--heading-leading` | `1.3` | Line height |
| `--heading-tracking` | `-.012em` | Letter spacing |
