分隔条由两个窗格和中间的手柄组成。手柄决定两个窗格如何分配空间，例如文件列表与编辑器左右并排，或编辑器与终端上下排列。两个窗格以一条细线相接。指针悬停在线上或细线获得焦点时，细线呈现墨色，并显示一个小握柄。

分隔条是组件而不是布局，尽管布局会用到它：它的手柄有自己的材质、状态和键盘交互契约。如果两个窗格的尺寸无需调整，请参阅[主从布局](/pages/master-detail)。

样式表负责绘制分隔条并完成布局，`splitter` [行为脚本](/guide/behaviors)负责移动手柄。该行为把第一个窗格的尺寸以百分比写入容器的 `--splitter-size`，并把同一数值四舍五入后写入手柄的 `aria-valuenow`。除此之外，两者之间不传递任何信息。对于左右并排的窗格，如果中间的手柄没有声明方向，该行为会在挂载时为它设置 `aria-orientation="vertical"`。

## 行为 \{#behavior\}

`splitter` 接收带有 `splitter` 类的根元素，并返回用于解绑行为的函数。它移动的手柄是根元素的直接子元素 `splitter-handle`，因此窗格内可以嵌套自己的分隔条。

```js name=app.js
import { splitter } from '@master/ui/behaviors/splitter.js'

const root = document.querySelector('.splitter')
splitter(root, { step: 10 })

root.addEventListener('change', (event) => {
  localStorage.setItem('files-width', event.target.getAttribute('aria-valuenow'))
})
```

- **拖动。** 发生 `pointerdown` 时，手柄捕获指针。指针移动期间，该行为将指针在容器内的位置写为百分比。
- **按键。** 按与手柄移动轴对应的方向键，手柄移动一个步长。<kbd class="kbd">Home</kbd> 和 <kbd class="kbd">End</kbd> 分别将窗格尺寸调至最小值和最大值。
- **每次变化**都会设置根元素的 `--splitter-size` 和手柄的 `aria-valuenow`。尺寸限制在手柄的 `aria-valuemin` 与 `aria-valuemax` 之间，未设置时分别默认为 0 和 100。
- **事件。** 每次尺寸变化时，手柄都会触发 `input`。拖动结束或按键使手柄移动后，手柄会触发 `change`。两个事件都会冒泡。从手柄读取 `aria-valuenow`。
- **禁用。** 带有 `aria-disabled="true"` 的手柄无法移动。

| 选项 | 设置内容 |
| --- | --- |
| `step` | 按一次方向键时手柄移动的幅度，以百分比计，默认为 5 |

无论指定什么尺寸，样式表都会将第一个窗格的尺寸限制在一定范围内，使分隔线与容器两端各相距至少 `--splitter-min`。按住手柄时，样式表会阻止文本选中，并根据手柄的方向切换布局。未绑定该行为时，两个窗格保持 `--splitter-size` 指定的比例，手柄固定不动。

## 上下排列的窗格 \{#stacked\}

`aria-orientation` 说明分隔线的走向，而且必须明确写出：没有声明方向的分隔线，无论布局看起来如何，辅助技术都会视为水平。窗格左右并排时，手柄在标记中就带有 `aria-orientation="vertical"`，因此在任何脚本运行之前，方向就已正确。设置 `aria-orientation="horizontal"` 后，窗格上下排列，手柄变为一条水平线。容器和方向键都读取这个属性，因此不需要另设一个修饰类并让它与属性保持同步。

窗格中也可以再放一个分隔条，每个分隔条都由自己的手柄调整布局：本例中，外层分隔条的两个窗格左右并排，编辑器和终端则上下排列在它的第二个窗格中。

## 无障碍 \{#accessibility\}

- 手柄是可聚焦的 `role="separator"`，其无障碍名称指明它调整的对象，`aria-valuenow`、`aria-valuemin` 和 `aria-valuemax` 均以第一个窗格所占的百分比表示。辅助技术据此将手柄识别为窗口分隔条。
- 键盘必须能完成指针能完成的所有操作：用方向键移动手柄，用 Home 键和 End 键移到两端。该行为已涵盖这些操作。
- 分隔线在布局中占 1px，垂直于线的交互区域宽 9px。触摸屏上该区域宽 25px，握柄始终可见。
- 窗格可独立滚动。如果可滚动的窗格内没有可聚焦的内容，请为窗格设置无障碍名称和 `tabindex="0"`，使其可以通过键盘获得焦点。
