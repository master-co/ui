분할 조절기는 두 패널과 그 사이에서 공간 배분을 조절하는 손잡이로 이루어집니다. 파일 목록과 편집기를 나란히 배치하거나 편집기 아래에 터미널을 배치할 때 사용합니다. 두 패널은 가느다란 경계선에서 맞닿습니다. 경계선에 호버하거나 포커스하면 선의 색이 진해지고 작은 손잡이 표시가 나타납니다.

분할 조절기는 레이아웃 자체가 아니라 레이아웃에 쓰이는 컴포넌트입니다. 손잡이에는 고유한 재질과 상태, 키보드 조작 계약이 있습니다. 크기를 조절할 필요가 없는 두 패널에는 [마스터-디테일](/pages/master-detail)을 참고하세요.

스타일시트는 분할 조절기의 모양과 배치를 정하고, `splitter` [동작](/guide/behaviors)은 손잡이를 움직입니다. 이 동작이 갱신하는 값은 컨테이너의 `--splitter-size`와 손잡이의 `aria-valuenow`뿐이며, 두 곳에 첫 번째 패널의 크기를 같은 숫자로 기록합니다.

## 동작 \{#behavior\}

`splitter`는 `splitter` 클래스가 있는 루트 요소를 받아 동작을 해제하는 함수를 반환합니다. 루트의 직접 자식인 `splitter-handle`만 움직이므로 패널 안에 별도의 분할 조절기를 둘 수 있습니다.

```js name=app.js
import { splitter } from '@master/ui/behaviors/splitter.js'

const root = document.querySelector('.splitter')
splitter(root, { step: 10 })

root.addEventListener('change', (event) => {
  localStorage.setItem('files-width', event.target.getAttribute('aria-valuenow'))
})
```

- **드래그.** `pointerdown` 이벤트가 발생하면 손잡이에서 포인터를 캡처하고, 포인터가 움직이는 동안 컨테이너 안에서의 위치를 백분율로 기록합니다.
- **키보드 조작.** 손잡이가 움직이는 축에 해당하는 방향키를 누르면 한 단계씩 이동합니다. <kbd class="kbd">Home</kbd> 키는 크기를 최솟값으로, <kbd class="kbd">End</kbd> 키는 최댓값으로 설정합니다.
- **크기가 바뀔 때마다** 루트의 `--splitter-size`와 손잡이의 `aria-valuenow` 값을 설정합니다. 크기는 손잡이의 `aria-valuemin` 값과 `aria-valuemax` 값 사이로 제한되며, 해당 값이 없으면 각각 0과 100을 사용합니다.
- **이벤트.** 손잡이는 크기가 바뀔 때마다 `input` 이벤트를 발생시키고, 드래그가 끝나거나 키 조작으로 손잡이가 움직이면 `change` 이벤트를 발생시킵니다. 두 이벤트 모두 버블링됩니다. 값은 손잡이의 `aria-valuenow`에서 읽으세요.
- **비활성 상태.** `aria-disabled="true"`가 설정된 손잡이는 움직이지 않습니다.

| 옵션 | 설정 항목 |
| --- | --- |
| `step` | 방향키를 한 번 누를 때 손잡이가 이동하는 비율(%). 기본값은 5 |

스타일시트는 어떤 크기를 지정하든 첫 번째 패널의 경계가 컨테이너 양 끝에서 최소 `--splitter-min` 떨어지도록 합니다. 손잡이를 잡고 있는 동안에는 텍스트 선택을 막고, 손잡이 방향에 맞춰 레이아웃을 전환합니다. 동작을 연결하지 않으면 패널은 `--splitter-size`에서 정한 비율을 유지하며 손잡이는 움직이지 않습니다.

## 위아래로 배치한 패널 \{#stacked\}

`aria-orientation` 속성은 경계선의 방향을 지정합니다. 기본값은 수직이며 두 패널은 좌우로 나란히 배치됩니다. `aria-orientation="horizontal"`로 지정하면 패널이 위아래로 배치되고 손잡이는 수평선이 됩니다. 컨테이너가 속성을 직접 읽으므로 별도의 수정자 클래스를 맞춰 줄 필요가 없습니다.

## 접근성 \{#accessibility\}

- 손잡이는 포커스할 수 있는 `role="separator"`입니다. 레이블은 크기가 조절되는 대상을 명시하고, `aria-valuenow`, `aria-valuemin`, `aria-valuemax` 값은 첫 번째 패널의 현재 크기, 최소 크기, 최대 크기를 각각 백분율로 나타냅니다. 이 정보로 보조 기술은 손잡이를 창 분할 조절기로 인식합니다.
- 포인터로 할 수 있는 모든 조작은 키보드로도 할 수 있어야 합니다. 분할 조절기 동작은 방향키로 손잡이를 이동하고 Home과 End 키로 양 끝에 도달하는 조작을 지원합니다.
- 레이아웃에서 경계선의 두께는 1픽셀이며, 조작 영역은 경계선을 가로질러 9px입니다. 터치 화면에서는 조작 영역이 25px이고 손잡이 표시가 항상 나타납니다.
- 각 패널은 독립적으로 스크롤됩니다. 스크롤 가능한 패널에 포커스할 수 있는 콘텐츠가 없다면, 키보드로 패널에 접근할 수 있도록 레이블과 `tabindex="0"`을 지정하세요.

## React, Svelte, Vue \{#frameworks\}

`splitter` 컴포넌트는 동작을 연결하고 크기 값을 입력받아 변경된 값을 외부로 전달합니다. 두 패널의 마크업은 페이지에서 직접 작성합니다. `npx master-ui add splitter`로 컴포넌트를 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte, Vue](/guide/frameworks)에서 확인하세요.
