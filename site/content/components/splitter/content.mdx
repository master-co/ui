A splitter is two panes and the handle between them that sets how they share the space: a file list beside an editor, an editor over a terminal. The panes meet at a hairline. Under the pointer, or with focus, the line takes ink and a small grip appears on it.

A splitter is a component, not a layout, though layouts use it: its handle has a material, states and a keyboard contract. For two panes that need no resizing, see [master-detail](/layouts/master-detail).

The stylesheet draws the splitter and lays it out; a script moves it. The script writes the first pane's size to `--splitter-size` on the container and the same number to the handle's `aria-valuenow`. Nothing else changes hands.

    <p class="m(0)">master.css</p>

  </div>
  <div class="splitter-handle" role="separator" tabindex="0" aria-label="Resize the file list" aria-valuenow="36" aria-valuemin="15" aria-valuemax="85"></div>

    <p class="m(0) fg-text-strong">Editor</p>

<script>
(function () {
  document.querySelectorAll('.splitter-handle').forEach(function (handle) {
    var root = handle.parentElement
    var rows = handle.getAttribute('aria-orientation') === 'horizontal'
    function set(value) {
      value = Math.max(15, Math.min(85, value))
      root.style.setProperty('--splitter-size', value + '%')
      handle.setAttribute('aria-valuenow', Math.round(value))
    }
    handle.addEventListener('pointerdown', function (event) {
      handle.setPointerCapture(event.pointerId)
      function move(e) {
        var box = root.getBoundingClientRect()
        set(rows ? (e.clientY - box.top) / box.height * 100 : (e.clientX - box.left) / box.width * 100)
      }
      handle.addEventListener('pointermove', move)
      handle.addEventListener('pointerup', function () { handle.removeEventListener('pointermove', move) }, { once: true })
    })
    handle.addEventListener('keydown', function (event) {
      var now = Number(handle.getAttribute('aria-valuenow'))
      var step = { ArrowLeft: -5, ArrowUp: -5, ArrowRight: 5, ArrowDown: 5, Home: -100, End: 100 }[event.key]
      if (step) { event.preventDefault(); set(now + step) }
    })
  })
})()
</script>`} caption="Drag the line, or focus it and use the arrow keys, Home and End." />

## What the script does \{#script\}

The script in the example is the whole behavior, about twenty lines:

- On `pointerdown` it captures the pointer on the handle and, while the pointer moves, writes its position inside the container as a percentage.
- On the arrow keys it moves by a step; <kbd class="kbd">Home</kbd> and <kbd class="kbd">End</kbd> go to the ends.
- Each change sets `--splitter-size` on the container and `aria-valuenow` on the handle.

The stylesheet keeps the first pane `--splitter-min` away from both ends whatever size is asked for, stops text selection while the handle is held, and switches the layout by the handle's orientation.

## Stacked panes \{#stacked\}

`aria-orientation` says which way the line runs. A separator is vertical by default, between panes side by side. With `aria-orientation="horizontal"` the panes stack, and the handle becomes a horizontal line; the container reads the attribute, so there is no modifier class to keep in step.

## Accessibility \{#accessibility\}

- The handle is a focusable `role="separator"` with a label that names what it resizes, and `aria-valuenow`, `aria-valuemin` and `aria-valuemax` as percentages of the first pane. That makes it a window splitter to assistive technology.
- The keyboard must do everything the pointer does: arrows to move, Home and End for the ends. The example script covers these.
- The line is one pixel in the layout with a 9px target across it, and 25px on touch screens, where the grip is always shown.
- A pane scrolls by itself. Give a pane that scrolls a label and `tabindex="0"` when it holds no focusable content, so the keyboard can reach it.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `splitter` | The container: first pane, handle, second pane |
| `splitter-pane` | A pane; scrolls by itself |
| `splitter-handle` | The `role="separator"` between the panes; horizontal with `aria-orientation="horizontal"` |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--splitter-size` | `50%` | The first pane's size; the script writes it |
| `--splitter-min` | `4rem` | The least either pane keeps |
