ダイヤルは、つまみを円周に沿って回して値を設定します。ノブのように設定するレベル、角度、方向などに使います。[ゲージ](/components/gauge)に対応する入力用のコンポーネントです。円形のトラックは塗りと同じ色で淡く描かれ、始点から現在値の位置まではその色で塗られます。[スライダー](/components/slider)と同じ真珠調のつまみが値の角度に置かれます。中央には等幅数字で数値が表示されます。これに相当するネイティブ要素はないため、ダイヤルは `role="slider"` を指定した要素で作り、`dial` の[ビヘイビア](/guide/behaviors)が回転を処理します。

  <span class="dial-value">40%</span>
  <span class="dial-thumb"></span>

既定では、ダイヤルはノブとして動作します。下部が開いた 270 度の範囲で、左下が最小値、右下が最大値です。トラックを押すと、値がその位置に移動します。つまみを押すと現在の位置のままつかむため、値が飛ばずに回せます。端を越えてドラッグすると、ポインターが戻ってくるまで、値は下部の切れ目を挟んでその端に留まります。

## 角度 \{#angle\}

`dial-full` は上端から始まる円周全体を使います。`aria-valuemin` 0 から `aria-valuemax` 360 までの角度や方向に使います。キー操作でも、上端を越えるドラッグでも、最大値を越えると最小値に戻ります。360 は同じ位置である 0 として書き出されます。<kbd class="kbd">End</kbd> は 360 の 1 ステップ手前で止まります。

  <span class="dial-thumb"></span>

ラベルと `aria-valuetext` は、数値の前後に記述された文字をそのまま保持します。そのため、ページ側のスクリプトがなくても「135°」は「136°」になります。別の種類の文言にするには、[ビヘイビア](#behavior)のセクションに示すように、ビヘイビアに `text` 関数を渡します。

## 目盛りと目印 \{#ticks-and-marks\}

`dial-ticks` 要素は、つまみの軌道のすぐ外側に、回転範囲を `--dial-ticks` 個の等しいステップに分ける細い線を描きます。ノブではステップ数より 1 本多く、両端に 1 本ずつ描かれ、円周全体ではステップ数と同じ本数になります。`dial-mark` は外周に置く短い語や数字で、スタイルシートが `--dial-at` が示す値の位置に配置します。どちらもダイヤルのボックス内側に外周の領域を取るため、その分トラックは小さくなります。目印を付けるダイヤルには大きいサイズを指定します。

## サイズ \{#sizes\}

ダイヤルの直径は 120px です。`dial-sm` は 88px で、コントロールを並べる行に使います。`dial-lg` は 160px で、パネルの主題となる 1 つの値や、目印付きのダイヤルに使います。トラックの太さは幅の 20 分の 1 で、数値の大きさはトラックに合わせて変わります。つまみはどのポインターでもスライダーと同じ 18px です。

## フォームでの使用 \{#form\}

`role="slider"` はフォームコントロールではないため、ダイヤルは hidden input を内包します。ビヘイビアは変更のたびに、ダイヤル内の最初の `<input type="hidden">` に値を書き込み、フォームはその値を input の `name` で送信します。ダイヤルの `input` と `change` イベントは、ネイティブのコントロールと同様にフォームまでバブリングします。フォームのリセットは hidden input に影響しないため、ダイヤルはリセット直前の位置に留まります。リセットで値を戻す必要がある場合は、ページ側で値を設定し直します。

表示するラベルは独立した要素にし、`aria-labelledby` で参照します。`<label>` が名前を付けられるのはフォームコントロールだけだからです。数値だけでは範囲がわかりにくい場合は、ダイヤルの横に範囲を文字で示します。

## 無効 \{#disabled\}

`aria-disabled="true"` を指定すると、ダイヤルが薄く表示され、キー、ポインター、ホイールのいずれの操作も受け付けなくなります。`tabindex="-1"` でタブ移動の順序から外し、フォームが値を送信しないように hidden input にも `disabled` を指定します。

## 回転の向き \{#direction\}

どの書字方向でも、時計回りが増加方向です。ダイヤルは時計や機器のノブのように回り、それらは右から左に書く言語でも反転しません。そのため、ダイヤルも反転せず、矢印キーの向きも入れ替わりません。<kbd class="kbd">→</kbd> と <kbd class="kbd">↑</kbd> は常に値を増やします。視線が最初に向かうダイヤルの上端では、時計回りは右方向であり、その位置で値を増やすのは右矢印キーです。

## ビヘイビア \{#behavior\}

`dial` は、`dial` クラスを持つ要素であるルートを受け取り、ビヘイビアを解除する関数を返します。この関数は数値の `value` を持ちます。外部からダイヤルを回すには `value` を設定します。この場合、イベントは発行されません。

```js name=app.js
import { dial } from '@master/ui/behaviors/dial.js'

const root = document.querySelector('.dial')
const turn = dial(root, { step: 15, text: (value) => `${value}°` })

root.addEventListener('change', () => save(turn.value))
```

- **変更のたび**に、値をルートの `aria-valuenow` と `--dial-value`、`dial-value` のテキスト、`aria-valuetext`（存在する場合、または `text` が渡された場合）、hidden input に書き込みます。適用時には最初の値を同じ方法で書き込み、属性を読み取れないブラウザーのために、`aria-valuemin` と `aria-valuemax` を `--dial-min` と `--dial-max` にコピーします。
- **値**は、`aria-valuemin` を起点とするステップの位置に揃い、`aria-valuemin` と `aria-valuemax` の間に収まります。省略時の既定値は、最小値が 0、最大値が 100 です。円周全体の場合は、範囲を越えると反対側に戻ります。
- **ドラッグ**　`pointerdown` でポインターをキャプチャし、ダイヤルの中心から見たポインターの角度を読み取ります。その角度を、スタイルシートの描画と同じ `--dial-start` と `--dial-sweep` を使って値に変換します。回転範囲が 360 度のダイヤルは、`dial-full` の有無にかかわらず、範囲を越えると反対側に戻ります。中心付近の数値の上を押しても値は動きません。
- **キー操作**　矢印キーで 1 ステップ、<kbd class="kbd">Page Up</kbd> と <kbd class="kbd">Page Down</kbd> でより大きな単位だけ回し、<kbd class="kbd">Home</kbd> と <kbd class="kbd">End</kbd> で両端に移動します。
- **ホイール**は、有効にした場合、1 ノッチごとにダイヤルを 1 ステップ回します。ただし、<kbd class="kbd">Alt</kbd>（<kbd class="kbd">Option</kbd>）キーを押している間に限ります。ページをスクロールしてダイヤルの上を通過しても、ダイヤルが回ることはありません。
- **イベント**　ルートは、値が変わるたびに `input` を、ドラッグが終わったときやキー・ホイールで回したときに `change` を発行します。どちらもバブリングします。
- **無効**　`aria-disabled="true"` を指定したダイヤルは、キー、ポインター、ホイールのいずれの操作も受け付けません。

| オプション | 設定する内容 |
| --- | --- |
| `step` | 矢印キーで値が動く量と、ドラッグ時に値を丸める単位。既定値は 1 です |
| `page` | Page Up と Page Down で値が動く量。既定値は範囲の 10 分の 1 で、ステップの位置に揃えます |
| `text` | 値を受け取り、その文言を返す関数。`dial-value` と `aria-valuetext` に書き込まれます |
| `wheel` | `true` にすると、Alt キーを押している間ホイールでダイヤルを回せます。既定値は `false` です |

`attach()` はオプションを渡しません。オプションが必要なダイヤルには、`attach()` の実行後に個別にビヘイビアを適用します。このプレビューのスクリプトのように、1 つのルートに対する 2 回目の呼び出しは最初の呼び出しを置き換えます。`MasterUI` はプレビューが読み込むバンドルです。プロジェクトでは、上の例のように `dial` をインポートします。

  <span class="dial-ticks" style="--dial-ticks: 24"></span>
  <span class="dial-value">210°</span>
  <span class="dial-thumb"></span>
</div>
<script>
addEventListener('DOMContentLoaded', function () {
  MasterUI.dial(document.getElementById('hue'), {
    step: 15,

  })

## アクセシビリティ \{#accessibility\}

- ルートは、フォーカス可能な `role="slider"` です。`aria-label` または `aria-labelledby` でアクセシブルな名前を付け、`aria-valuemin` と `aria-valuemax` の間の値を `aria-valuenow` に示します。円周上ではスライダーの向きに意味がないため、`aria-orientation` は指定しません。
- 数値を理解するのに単位や文言が必要な場合は、「135°」「21 degrees」「Loud」のように `aria-valuetext` を記述します。ビヘイビアはこれを値と同期させます。
- スライダー内の数値、目盛り、目印はすべて視覚的な表示で、支援技術には個別の要素として公開されません。ドラッグでできることはすべてキー操作でもでき、トラックを 1 回押すだけでも値を設定できるため、ドラッグして回すことが唯一の手段になることはありません。
- フォーカスリングは、スライダーと同様につまみの周囲に表示されます。タッチスクリーンではダイヤル全体が指の操作を受け取り、ページをスクロールせずに回るため、つまみのサイズは変わりません。
- 動きを抑える設定では、つかんだつまみが大きくなりません。強制カラーモードでは、塗りはシステムのハイライト色、トラックと目盛りはシステムのグレー、つまみはボタンのテキスト色になります。

## React、Svelte、Vue \{#frameworks\}

`dial` コンポーネントはビヘイビアを適用し、値の受け渡しを行います。目盛りと目印はデータから描画し、`name` が渡された場合は hidden input も描画します。`npx master-ui add dial` でプロジェクトにコピーできます。コンポーネントの構成と使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
