## 值 \{#the-value\}

渐变是一个由四部分组成的值：

| 部分 | 含义 |
| --- | --- |
| `type` | `linear`、`radial` 或 `conic` |
| `angle` | 角度（度），用于线性渐变和锥形渐变 |
| `center` | 两个百分比，用于径向渐变和锥形渐变 |
| `stops` | 每个色标都有一个始终跟随它的 `id`、取值 0 到 100 的 `offset`，以及一个 `color` |

颜色的写法与颜色选择器一致：以十六进制表示的 sRGB，并带有不透明度。`gradientCss(value)` 将渐变输出为 CSS，预览和复制的文本都来自它：在能够指定插值空间的浏览器中使用 OKLab 插值，并在此之前先提供一行回退声明，供不支持的浏览器使用。

```css name=copied.css
background-image: linear-gradient(90deg, #ff6a00 0%, #ee0979 100%);
background-image: linear-gradient(in oklab 90deg, #ff6a00 0%, #ee0979 100%);
```

编辑器不会回读 CSS：编辑器持有的是值，应用程序保存的也是值，而不是文本。

## 色标 \{#the-stops\}

- **色标的手柄是一个滑块**，控制色标的位置，在色条上显示为一个带有该色标颜色的圆片。按下手柄即选中该色标，拖动即可移动；方向键每次移动 1，按住 <kbd class="kbd">Shift</kbd> 再按方向键，每次移动 10，<kbd class="kbd">Home</kbd> 和 <kbd class="kbd">End</kbd> 将它移到两端。当前选中的色标带有 `aria-current="true"`，会稍稍向前突出并显示一道墨色圆环。
- **色标可以交叉。** 一个色标移过另一个色标时，仍保留自己的 id，其手柄也保持焦点；渐变按各色标位置的先后顺序绘制。两个色标位于同一位置时会形成硬边，并保持原有顺序。
- **添加**会在当前色标之后 10 个单位处放置一个与其同色的新色标，最远到 100。**删除**（使用按钮或 <kbd class="kbd">Delete</kbd> 键）会把焦点交给色条上的下一个色标，没有下一个时交给前一个。色标至少要有两个：只剩两个时，无法再删除色标。
- **反转**会把色标颠倒过来：每个位置变为 100 减去原值。

拖动绝不是唯一的操作方式：位置旁边另有滑块和数字输入框，每个色标也都能用 <kbd class="kbd">Tab</kbd> 键到达。

## 状态 \{#states\}

在根元素上设置 `aria-readonly="true"` 表示渐变不可更改，设置 `aria-disabled="true"` 表示渐变未启用：两种情况下手柄都保持原位，控件都被禁用。

## 行为脚本 \{#behavior\}

```js name=app.js
import { gradient, gradientCss } from '@master/ui/behaviors/gradient.js'

const editor = gradient(document.querySelector('.gradient'), {
  value: { type: 'linear', angle: 90, center: [50, 50], stops: [
    { id: 'from', offset: 0, color: '#ff6a00' },
    { id: 'to', offset: 100, color: '#ee0979' },
  ] },
})
editor.value                     // the value as above
gradientCss(editor.value).text   // the two lines to copy
```

读者操作过程中会持续派发 `input` 事件，操作结束时派发 `change` 事件；通过代码设置 `value` 会显示另一个渐变，但不派发任何事件。行为脚本根据值生成手柄标记，因此自行生成手柄标记的框架应传入 `draw`。它在根元素上以 `--gradient` 和 `--gradient-fallback` 发布整个渐变，并在每个色标的手柄上以 `--gradient-offset` 和 `--gradient-color` 发布该色标：编辑器所绘制的是它的内容，而由样式表负责摆放。

## 无障碍 \{#accessibility\}

- 每个手柄都以它在色标中的序位命名，并通过 `aria-valuetext` 说明其位置和颜色。
- 预览只是值的图像：请对辅助技术隐藏它，因为色标和 CSS 已经表达了相同的信息。
- 在强制颜色模式下，渐变保留自身的颜色，因为这些颜色就是它的内容；手柄和色条则用系统颜色描边。
