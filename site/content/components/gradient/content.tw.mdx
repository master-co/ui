漸層編輯器用來製作漸層：色標排在一條橫條上，目前選取的色標以[取色器](/components/color-picker)調整，並可設定漸層的類型、角度與中心點。其中每個控制項都是元件庫本身的元件：取色器、用來設定色標位置的[滑桿](/components/slider)和數字欄位、用來選擇類型的[分段控制項](/components/segmented)、用來設定角度的[旋鈕](/components/dial)，以及用來設定中心點的數字欄位。漸層本身加上的是色標橫條、預覽，以及讓這一切保持同步的 [`gradient` 行為](/guide/behaviors)。

## 值 \{#the-value\}

漸層是由四個部分組成的值：

| 部分 | 內容 |
| --- | --- |
| `type` | `linear`、`radial` 或 `conic` |
| `angle` | 角度（度），用於線性與圓錐漸層 |
| `center` | 兩個百分比，用於放射與圓錐漸層 |
| `stops` | 每個色標都有一個固定跟著它的 `id`、從 0 到 100 的 `offset`，以及一個 `color` |

色彩的寫法與取色器相同，以十六進位的 sRGB 表示，並包含不透明度。`gradientCss(value)` 會將漸層寫成 CSS，預覽和複製的文字都來自它：在能指定插值色彩空間的瀏覽器中以 OKLab 插值，並在前面先寫一行供不支援的瀏覽器使用的備援。

```css name=copied.css
background-image: linear-gradient(90deg, #ff6a00 0%, #ee0979 100%);
background-image: linear-gradient(in oklab 90deg, #ff6a00 0%, #ee0979 100%);
```

編輯器不會讀回 CSS：值由編輯器保存，應用程式也應儲存值，而不是文字。

## 色標 \{#the-stops\}

- **色標的控點是一個滑桿**，代表它的位置，在橫條上以該色標顏色的圓盤呈現。按下即可選取色標，拖曳可移動它；方向鍵每次移動 1，按住 <kbd class="kbd">Shift</kbd> 時每次移動 10，<kbd class="kbd">Home</kbd> 和 <kbd class="kbd">End</kbd> 則移到兩端。目前選取的色標帶有 `aria-current="true"`，會略微突出，並加上以文字色繪製的外環。
- **色標可以越過彼此。** 將色標移過另一個色標時，移動的色標會保留原有的 id，控點也會保留焦點；漸層會依位置的順序繪製色標。兩個色標位於同一位置時會形成銳利的邊界，並維持原本的順序。
- **新增**會在目前色標之後 10 個單位處（最多到 100）加入一個與目前色標同色的色標。以按鈕或 <kbd class="kbd">Delete</kbd> **移除**色標時，焦點會交給橫條上的下一個色標，若沒有則交給前一個。至少需要兩個色標：只剩兩個時，無法再移除。
- **反轉**會將色標的順序顛倒：每個位置都變成 100 減去原本的值。

拖曳從來不是唯一的操作方式：位置有滑桿和旁邊的數字欄位，每個色標也都能以 <kbd class="kbd">Tab</kbd> 抵達。

## 狀態 \{#states\}

在根元素上設定 `aria-readonly="true"` 表示漸層無法變更，設定 `aria-disabled="true"` 則表示漸層目前未使用：控點停留在原位，控制項則會停用。

## 行為 \{#behavior\}

```js name=app.js
import { gradient, gradientCss } from '@master/ui/behaviors/gradient.js'

const editor = gradient(document.querySelector('.gradient'), {
  value: { type: 'linear', angle: 90, center: [50, 50], stops: [
    { id: 'from', offset: 0, color: '#ff6a00' },
    { id: 'to', offset: 100, color: '#ee0979' },
  ] },
})
editor.value                     // the value as above
gradientCss(editor.value).text   // the two lines to copy
```

使用者操作期間會持續觸發 `input`，操作結束時觸發 `change`；設定 `value` 會顯示另一個漸層，但不會觸發任何事件。行為會依值寫出控點，因此自行寫出控點的框架應提供 `draw`。它會在根元素上以 `--gradient` 和 `--gradient-fallback` 公開漸層，並在每個色標的控點上以 `--gradient-offset` 和 `--gradient-color` 公開該色標：編輯器繪製的是它的內容，樣式表則負責定位。

## 無障礙 \{#accessibility\}

- 每個控點都以它在色標中的順序命名，並在 `aria-valuetext` 中說明它的位置與色彩。
- 預覽只是值的圖像：請將它從輔助技術中隱藏，因為色標和 CSS 已傳達相同的資訊。
- 在強制色彩模式下，漸層會保留自己的色彩，因為這些色彩就是它的內容；控點和橫條則以系統色彩繪製輪廓。
