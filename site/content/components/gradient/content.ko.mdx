그라데이션 편집기는 그라데이션을 만듭니다. 막대 위에 색상 정지점을 배치하고, 선택한 정지점을 [색상 선택기](/components/color-picker)에 표시하며, 유형, 각도, 중심을 설정합니다. 편집기 안의 모든 컨트롤은 라이브러리의 컴포넌트입니다. 색상 선택기, 정지점 위치를 정하는 [슬라이더](/components/slider)와 숫자 입력, 유형을 고르는 [세그먼트 컨트롤](/components/segmented), 각도를 정하는 [다이얼](/components/dial), 중심을 정하는 숫자 입력으로 구성됩니다. 그라데이션이 추가하는 것은 정지점 막대, 미리보기, 그리고 이 모두를 동기화하는 [`gradient` 동작](/guide/behaviors)입니다.

## 값 \{#the-value\}

그라데이션은 네 부분으로 이루어진 값입니다.

| 부분 | 내용 |
| --- | --- |
| `type` | `linear`, `radial`, `conic` 중 하나 |
| `angle` | 선형 및 원뿔형 그라데이션의 각도(도) |
| `center` | 방사형 및 원뿔형 그라데이션의 중심을 나타내는 두 백분율 |
| `stops` | 각 정지점에 고정된 `id`, 0부터 100까지의 `offset`, `color`가 있습니다. |

색상은 색상 선택기가 작성하는 방식대로 불투명도를 포함한 sRGB 16진수로 작성합니다. `gradientCss(value)`는 그라데이션을 CSS로 작성하며, 미리보기와 복사되는 텍스트 모두 이 함수에서 나옵니다. 브라우저에 보간 색 공간을 지정할 수 있으면 OKLab에서 보간하고, 지정할 수 없는 브라우저를 위해 그 앞에 폴백을 둡니다.

```css name=copied.css
background-image: linear-gradient(90deg, #ff6a00 0%, #ee0979 100%);
background-image: linear-gradient(in oklab 90deg, #ff6a00 0%, #ee0979 100%);
```

CSS를 다시 읽어 들이지는 않습니다. 편집기는 값을 보유하며, 애플리케이션도 텍스트가 아니라 값을 저장합니다.

## 색상 정지점 \{#the-stops\}

- **정지점의 손잡이는 슬라이더입니다.** 정지점의 위치를 값으로 갖고, 막대 위에 정지점 색상의 원으로 표시됩니다. 누르면 정지점이 선택되고, 드래그하면 이동합니다. 방향키로 1씩, <kbd class="kbd">Shift</kbd>와 함께 누르면 10씩 이동하며, <kbd class="kbd">Home</kbd>과 <kbd class="kbd">End</kbd>로 양 끝으로 이동합니다. 선택한 정지점에는 `aria-current="true"`가 지정되며, 살짝 앞으로 나와 잉크 색 테두리가 표시됩니다.
- **정지점은 서로 교차할 수 있습니다.** 다른 정지점을 지나쳐 이동한 정지점은 id를 유지하고 손잡이도 포커스를 유지합니다. 그라데이션은 위치 순서대로 정지점을 칠합니다. 두 정지점이 같은 위치에 있으면 경계가 선명하게 나뉘며, 순서는 유지됩니다.
- **추가**하면 선택한 정지점의 색상으로 새 정지점을 선택한 정지점보다 10만큼 뒤에, 최대 100 위치에 놓습니다. 버튼이나 <kbd class="kbd">Delete</kbd>로 **삭제**하면 포커스가 막대의 다음 정지점으로, 없으면 이전 정지점으로 이동합니다. 정지점은 최소 두 개이며, 두 개일 때는 삭제가 비활성화됩니다.
- **반전**하면 정지점의 순서가 뒤집혀, 각 위치가 100에서 자신의 값을 뺀 값이 됩니다.

드래그가 유일한 조작 방법은 아닙니다. 위치에는 범위 입력과 그 옆의 숫자 입력이 있으며, 모든 정지점은 <kbd class="kbd">Tab</kbd>으로 이동할 수 있습니다.

## 상태 \{#states\}

루트에 `aria-readonly="true"`를 지정하면 변경할 수 없는 그라데이션을, `aria-disabled="true"`를 지정하면 사용하지 않는 그라데이션을 표시합니다. 손잡이는 제자리에 머물고 컨트롤은 비활성화됩니다.

## 동작 \{#behavior\}

```js name=app.js
import { gradient, gradientCss } from '@master/ui/behaviors/gradient.js'

const editor = gradient(document.querySelector('.gradient'), {
  value: { type: 'linear', angle: 90, center: [50, 50], stops: [
    { id: 'from', offset: 0, color: '#ff6a00' },
    { id: 'to', offset: 100, color: '#ee0979' },
  ] },
})
editor.value                     // the value as above
gradientCss(editor.value).text   // the two lines to copy
```

독자가 조작하는 동안에는 `input` 이벤트가, 조작이 끝나면 `change` 이벤트가 발행됩니다. `value`를 설정하면 다른 그라데이션을 표시하며 이벤트는 발행되지 않습니다. 동작은 값으로 손잡이를 작성하므로, 손잡이를 직접 작성하는 프레임워크는 `draw`를 지정합니다. 동작은 루트에 그라데이션을 `--gradient`와 `--gradient-fallback`으로, 각 손잡이에 정지점을 `--gradient-offset`과 `--gradient-color`로 출력합니다. 편집기가 칠하는 색은 콘텐츠이며, 스타일시트는 그 위치만 정합니다.

## 접근성 \{#accessibility\}

- 각 손잡이의 이름에는 정지점 중 몇 번째인지가 포함되며, `aria-valuetext`로 위치와 색상을 알려 줍니다.
- 미리보기는 값을 그림으로 보여 줄 뿐입니다. 정지점과 CSS가 같은 내용을 전달하므로 보조 기술에서 숨기세요.
- 강제 색상 모드에서도 그라데이션은 콘텐츠이므로 고유한 색상을 유지하며, 손잡이와 막대에는 시스템 색상의 윤곽선이 표시됩니다.

## React, Svelte 및 Vue \{#frameworks\}

`gradient` 컴포넌트는 값으로 손잡이와 컨트롤을 작성하고 동작을 연결합니다. `npx master-ui add gradient`로 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte 및 Vue](/guide/frameworks)에서 확인할 수 있습니다.
