グラデーションエディターでは、グラデーションを作成します。バー上にカラーストップを並べ、編集中のストップの色を[カラーピッカー](/components/color-picker)で選び、種類、角度、中心を設定します。中のコントロールはすべてこのライブラリーのものです。カラーピッカー、ストップの位置を指定する[スライダー](/components/slider)と数値入力、種類を選ぶ[セグメントコントロール](/components/segmented)、角度を指定する[ダイヤル](/components/dial)、中心を指定する数値入力です。グラデーションが加えるのは、ストップを並べたバー、プレビュー、そしてこれらすべてを同期させる [`gradient` ビヘイビア](/guide/behaviors)です。

## 値 \{#the-value\}

グラデーションは 4 つの部分からなる値です。

| 部分 | 内容 |
| --- | --- |
| `type` | `linear`、`radial`、`conic` のいずれか |
| `angle` | 角度（度）。線形と円錐形のグラデーションで使います |
| `center` | 2 つのパーセント値。放射状と円錐形のグラデーションで使います |
| `stops` | 各ストップは、そのストップに固定された `id`、0 から 100 までの `offset`、`color` を持ちます |

色はカラーピッカーと同じ形式で、不透明度を含む sRGB の 16 進数で書きます。`gradientCss(value)` はグラデーションを CSS として書き出し、プレビューもコピーされるテキストもここから生成されます。ブラウザーに指定できる場合は OKLab で補間し、指定できないブラウザー向けのフォールバックをその前に置きます。

```css name=copied.css
background-image: linear-gradient(90deg, #ff6a00 0%, #ee0979 100%);
background-image: linear-gradient(in oklab 90deg, #ff6a00 0%, #ee0979 100%);
```

CSS を読み戻すことはありません。値を保持するのはエディターで、アプリケーションが保存するのもテキストではなく値です。

## ストップ \{#the-stops\}

- **ストップのハンドルは、位置を表すスライダーです。** バー上では、ストップの色の円として表示されます。押すとそのストップが編集対象になり、ドラッグで移動します。矢印キーで 1 ずつ、<kbd class="kbd">Shift</kbd> を押しながらだと 10 ずつ移動し、<kbd class="kbd">Home</kbd> と <kbd class="kbd">End</kbd> で両端に移動します。編集中のストップには `aria-current="true"` が付き、インク色のリングとともに少し手前に表示されます。
- **ストップは交差できます。** ほかのストップを越えて移動したストップは id を保ち、そのハンドルはフォーカスを保ちます。グラデーションは位置の順に描画されます。同じ位置にある 2 つのストップは境界のはっきりした色の切り替わりになり、順序は保たれます。
- **追加**すると、編集中のストップの 10 ポイント後ろ（最大 100）に、同じ色のストップが加わります。ボタンまたは <kbd class="kbd">Delete</kbd> で**削除**すると、バー上の次のストップに、なければ前のストップにフォーカスが移ります。ストップは最低 2 つ必要で、2 つのときは削除が無効になります。
- **反転**すると、ストップの並びが逆になります。各位置は 100 からその位置を引いた値になります。

ドラッグだけが操作手段になることはありません。位置にはスライダーとその横の数値入力があり、どのストップにも <kbd class="kbd">Tab</kbd> で移動できます。

## 状態 \{#states\}

ルートに `aria-readonly="true"` を付けるとグラデーションは読み取り専用になり、`aria-disabled="true"` を付けると無効になります。ハンドルはその場にとどまり、コントロールは無効になります。

## ビヘイビア \{#behavior\}

```js name=app.js
import { gradient, gradientCss } from '@master/ui/behaviors/gradient.js'

const editor = gradient(document.querySelector('.gradient'), {
  value: { type: 'linear', angle: 90, center: [50, 50], stops: [
    { id: 'from', offset: 0, color: '#ff6a00' },
    { id: 'to', offset: 100, color: '#ee0979' },
  ] },
})
editor.value                     // the value as above
gradientCss(editor.value).text   // the two lines to copy
```

ユーザーの操作中は `input` が発行され、操作が終わると `change` が発行されます。`value` を設定すると別のグラデーションが表示され、イベントは発行されません。ビヘイビアは値からハンドルを書き出すため、ハンドルを自分で書き出すフレームワークは `draw` を指定します。ビヘイビアは、グラデーションをルートの `--gradient` と `--gradient-fallback` として、各ストップをハンドルの `--gradient-offset` と `--gradient-color` として公開します。エディターが描画するのはそのコンテンツで、配置はスタイルシートが行います。

## アクセシビリティ \{#accessibility\}

- 各ハンドルには、ストップの中での順番を含む名前を付け、`aria-valuetext` で位置と色を伝えます。
- プレビューは値を絵にしたものです。ストップと CSS が同じ内容を伝えるため、支援技術からは隠します。
- 強制カラーモードでは、グラデーションの色はコンテンツなので、そのまま保たれます。ハンドルとバーの輪郭はシステムカラーで描画されます。
