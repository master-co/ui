대화 상자는 표면 계층에서 가장 높은 표면입니다. 페이지를 어둡고 흐릿하게 만드는 배경막 위에 오버레이 시트가 놓입니다. 네이티브 `<dialog>`에 `.dialog` 클래스를 적용하세요. `commandfor`와 `command="show-modal"`이 지정된 버튼으로 열면 브라우저가 대화 상자를 최상위 레이어에 표시하고, 포커스를 대화 상자 안에 유지하며, <kbd>Esc</kbd> 키로 닫을 수 있게 하므로 스크립트가 필요 없습니다.

## 열기와 닫기 \{#opening-and-closing\}

속성 세 개로 모달에 필요했던 스크립트를 대체할 수 있습니다.

- 버튼에 `commandfor="id"`와 `command="show-modal"`을 함께 지정하면 대화 상자가 모달로 열립니다. `command="close"`는 대화 상자를 닫고 처음 열었던 버튼으로 포커스를 돌려보냅니다.
- 대화 상자에 `closedby="any"`를 지정하면 배경막을 클릭해 닫을 수 있습니다. <kbd>Esc</kbd> 키로는 이 속성과 관계없이 항상 닫을 수 있습니다. 실수로 클릭했을 때 작업 내용이 사라지면 안 되는 경우에는 이 속성을 생략하세요. 이 속성을 지원하지 않는 브라우저에서도 <kbd>Esc</kbd> 키와 닫기 버튼은 동작합니다.
- 대화 상자 안의 `<form method="dialog">` 폼을 제출하면 대화 상자가 닫힙니다. 어느 버튼으로 제출했는지는 대화 상자의 `returnValue`로 확인할 수 있습니다.

모달 대화 상자가 열려 있는 동안에는 뒤쪽 페이지와 상호작용하거나 페이지를 스크롤할 수 없습니다.

## 크기 \{#sizes\}

대화 상자의 기본 너비는 28rem입니다. 한 문장으로 확인을 요청할 때 쓰는 `dialog-sm`의 너비는 22rem이며, `dialog-lg`의 너비는 40rem입니다. 좁은 화면에서는 모든 크기가 뷰포트 가장자리에서 1rem의 여백을 유지합니다. 푸터는 컨테이너 쿼리를 통해 대화 상자 자체의 너비에 맞춰 배치를 바꿉니다. 너비가 22rem 미만이면 주 동작 버튼을 맨 위에 두고, 각 버튼이 전체 너비를 차지하도록 세로로 배치합니다.

## 모션 \{#motion\}

대화 상자는 원래 크기의 97%로, 제자리보다 0.5rem 아래에서 시작해 280ms 동안 서서히 나타납니다. 사라지는 데는 160ms가 걸립니다. 스타일시트는 열기와 닫기 전환을 모두 CSS로 정의합니다. `@starting-style`은 처음 렌더링되는 프레임의 상태를 지정하고, `display`와 `overlay`는 `allow-discrete`로 전환되므로 대화 상자가 최상위 레이어를 벗어나기 전에 닫기 애니메이션이 재생됩니다. 동작 줄이기가 활성화되면 페이드 효과만 남습니다.

## 접근성 \{#accessibility\}

- `aria-labelledby` 속성이 대화 상자의 `dialog-title`을 가리키도록 지정해 대화 상자에 접근 가능한 이름을 부여하세요.
- `show-modal`로 열면 포커스가 대화 상자 안으로 이동하고, 닫으면 대화 상자를 열었던 버튼으로 돌아갑니다. 사용자가 처음 사용할 필드에 `autofocus` 속성을 지정하세요. 데이터를 삭제하는 등 되돌리기 어려운 동작을 확인하는 대화 상자에서는 안전한 동작에 지정하세요.
- `command`와 `commandfor`는 최신 Chrome, Edge, Firefox, Safari에서 지원됩니다. 이전 브라우저에서는 클릭 핸들러에서 `dialog.showModal()` 메서드를 호출하세요. 스타일시트는 그대로 사용합니다.

## React, Svelte, Vue \{#frameworks\}

`dialog` 컴포넌트는 애플리케이션 상태에 따라 대화 상자를 열고 닫으며, 브라우저에서 대화 상자가 열리거나 닫히면 이를 알립니다. 대화 상자를 여는 요소와 내부 요소는 페이지의 마크업에서 직접 정의합니다. `npx master-ui add dialog`로 컴포넌트를 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
