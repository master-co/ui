对话框是层次最高的表面。浮层面板位于遮罩上方，遮罩压暗页面并弱化背景细节。在原生 `<dialog>` 上使用 `.dialog`。带有 `commandfor` 和 `command="show-modal"` 的按钮可以打开对话框，浏览器会将对话框置于顶层，将焦点限制在框内，并支持按 <kbd>Esc</kbd> 关闭，全程无需脚本。

## 打开和关闭 \{#opening-and-closing\}

三个属性即可实现过去需要脚本处理的模态对话框行为：

- 在按钮上将 `commandfor="id"` 与 `command="show-modal"` 搭配使用，即可将对话框以模态方式打开。`command="close"` 关闭对话框，并将焦点还给打开它的按钮。
- 在对话框上添加 `closedby="any"` 后，点击遮罩也能关闭对话框。按 <kbd>Esc</kbd> 始终可以关闭。如果误点可能导致工作成果丢失，请省略此属性。在不支持此属性的浏览器中，<kbd>Esc</kbd> 和关闭按钮仍然有效。
- 对话框内的 `<form method="dialog">` 会在提交时关闭对话框，并通过对话框的 `returnValue` 报告使用了哪个按钮。

模态对话框打开时，后方页面无法交互，也不会滚动。

## 尺寸 \{#sizes\}

对话框默认宽 28rem。`dialog-sm` 宽 22rem，适合一句话的确认提示。`dialog-lg` 宽 40rem。在窄屏上，各尺寸的对话框与视口左右边缘各留出 1rem。底部通过容器查询响应对话框自身的宽度。宽度小于 22rem 时，按钮纵向排列并占满可用宽度，主要操作排在最上方。

## 动效 \{#motion\}

对话框从正常尺寸的 97%、向下偏移 0.5rem 的位置淡入，入场耗时 280ms，退场耗时 160ms。样式表用 CSS 实现入场和退场。`@starting-style` 定义首个渲染帧，`display` 和 `overlay` 使用 `allow-discrete` 进行过渡，使退场动画在对话框离开顶层前播完。启用减少动态效果时，仅保留淡入淡出。

## 无障碍 \{#accessibility\}

- 让 `aria-labelledby` 指向对话框的 `dialog-title`，为对话框提供无障碍名称。
- 通过 `show-modal` 打开对话框时，焦点会移入对话框，关闭后则返回触发按钮。将 `autofocus` 加到应首先获得焦点的字段上。确认破坏性操作时，将它加到安全的操作上。
- 当前版本的 Chrome、Edge、Firefox 和 Safari 均支持 `command` 和 `commandfor`。在旧版浏览器中，从点击事件处理函数调用 `dialog.showModal()`，继续使用同一份样式表。

## React、Svelte 和 Vue \{#frameworks\}

`dialog` 组件根据应用状态打开和关闭对话框，并在浏览器打开或关闭对话框时发出通知。触发控件和对话框内部各部分的标记由页面自行编写。使用 `npx master-ui add dialog` 将组件复制到项目中。参见 [React、Svelte 和 Vue](/guide/frameworks) 了解组件的实现和用法。
