对话框是层次最高的表面。浮层面板位于遮罩上方，遮罩压暗页面并弱化背景细节。在原生 `<dialog>` 上使用 `.dialog`。带有 `commandfor` 和 `command="show-modal"` 的按钮可以打开对话框，浏览器会将对话框置于顶层，将焦点限制在框内，并支持按 <kbd>Esc</kbd> 关闭，全程无需脚本。

## 打开和关闭 \{#opening-and-closing\}

三个属性即可实现过去需要脚本处理的模态对话框行为：

- 在按钮上将 `commandfor="id"` 与 `command="show-modal"` 搭配使用，即可将对话框以模态方式打开。`command="close"` 关闭对话框，并将焦点还给打开它的按钮。
- 在对话框上添加 `closedby="any"` 后，点击遮罩也能关闭对话框。按 <kbd>Esc</kbd> 始终可以关闭。如果误点可能导致工作成果丢失，请省略此属性。在不支持此属性的浏览器中，<kbd>Esc</kbd> 和关闭按钮仍然有效。
- 对话框内的 `<form method="dialog">` 会在提交时关闭对话框，并通过对话框的 `returnValue` 报告使用了哪个按钮。

模态对话框打开时，后方页面无法交互，也不会滚动。

## 尺寸 \{#sizes\}

对话框默认宽 28rem。`dialog-sm` 宽 22rem，适合一句话的确认提示。`dialog-lg` 宽 40rem。在窄屏上，各尺寸的对话框与视口左右边缘各留出 1rem。底部通过容器查询响应对话框自身的宽度。宽度小于 22rem 时，按钮纵向排列并占满可用宽度，主要操作排在最上方。

## 滑动关闭 \{#swipe\}

滑动关闭的实现方式：

- **由浏览器移动面板。** 轨道是一个带有吸附点的滚动容器：一个是打开时的停靠位置，另一个是越过边缘、与视口一样长的区域，面板松手后会滑到那里。手指、触控板和滚轮都能滚动它，因此跟手移动、轻扫的惯性以及最终停在哪里，都由浏览器自行处理。轨道采用反向排列的 Flex 布局，面板位于其末端，因此无需脚本即可从打开时的停靠位置开始。
- **行为脚本处理滚动做不到的事。** 无论面板以何种方式离开轨道，脚本都会在其离开后关闭对话框。它恢复 `closedby="any"` 的效果：轨道覆盖了浏览器监听点击的遮罩，因此由行为脚本在点击面板旁边时关闭对话框。鼠标无法通过拖动来滚动，脚本让鼠标可以按住手柄或面板上任何不是控件或正文的部分来拖动面板，并在松手时让面板停到被甩向的那个停靠位置，或较近的那个；精确指针按住面板时，轨道停止吸附。脚本将遮罩剩余的比例写入 `--dialog-scrim`，因此遮罩会随面板离开而逐渐变淡。
- **对话框仍是对话框。** <kbd>Esc</kbd>、关闭按钮、焦点限制、焦点返回触发按钮以及滑入滑出动画，都与其他抽屉或底部面板相同。
- **可滚动的正文保留自己的滚动。** 使用鼠标或滚轮时，在 `dialog-body` 中拖动会滚动正文或选中文字。在触摸屏上，拖动到正文顶部后继续拖动会移动底部面板。

滑动只是一种快捷方式：保留关闭按钮或能关闭对话框的操作，并保留 <kbd>Esc</kbd>。

### 停靠高度 \{#detents\}

为可滑动的底部面板添加 `dialog-detents` 后，它会停在两个高度：打开时的半个视口高度，以及全高。拖动或轻扫可在两者之间切换；从全高向下轻扫会停在半高，只有从半高向下轻扫才会关闭。将手柄设为带有无障碍名称的 `<button>`：点击、按 <kbd>Enter</kbd> 或 <kbd>Space</kbd> 会将底部面板切换到另一个高度，按 <kbd>↑</kbd> 展开到全高，按 <kbd>↓</kbd> 收起到半高。其 `aria-expanded` 表示底部面板是否处于全高。

处于半高时，底部面板的下半部分（包括页脚）位于屏幕边缘之下：停靠高度适用于供浏览的底部面板，例如列表、评论或地图，其操作应放在顶部。低于半个视口高度的底部面板只有一个停靠位置，即全高，其手柄也会如实表明这一点。

### 不支持某项特性时 \{#swipe-fallbacks\}

- 脚本不可用时，越过边缘的区域不是停靠位置（`@media (scripting: enabled)`）：松手后面板会弹回，<kbd>Esc</kbd> 和关闭按钮仍可关闭对话框。只要脚本能运行，就要挂载行为脚本，否则松手后面板会停在屏幕外，而页面仍处于惰性状态。
- 没有行为脚本时，遮罩会保持完整，直到对话框关闭。遮罩的变淡没有使用滚动驱动动画：在反向滚动容器中，Chromium 和 WebKit 运行滚动时间轴和视图时间轴的方向相反。
- 在支持 `scroll-initial-target` 的浏览器（Chromium）中，带停靠高度的底部面板在任何脚本运行之前就以半高打开；在其他浏览器中，它以全高打开，直到行为脚本将其移到半高。

滑动关闭已在 Chromium 和 WebKit 中验证，覆盖鼠标、滚轮，以及 Chromium 中的触摸操作。滚动吸附、反向弹性布局滚动和 `scrollend` 已在所有当前浏览器中可用。

## 动效 \{#motion\}

对话框从正常尺寸的 97%、向下偏移 0.5rem 的位置淡入，入场耗时 280ms，退场耗时 160ms。样式表用 CSS 实现入场和退场。`@starting-style` 定义首个渲染帧，`display` 和 `overlay` 使用 `allow-discrete` 进行过渡，使退场动画在对话框离开顶层前播完。启用减少动态效果时，仅保留淡入淡出。

## 无障碍 \{#accessibility\}

- 让 `aria-labelledby` 指向对话框的 `dialog-title`，为对话框提供无障碍名称。
- 通过 `show-modal` 打开对话框时，焦点会移入对话框，关闭后则返回触发按钮。将 `autofocus` 加到应首先获得焦点的字段上。确认破坏性操作时，将它加到安全的操作上。
- 当前版本的 Chrome、Edge、Firefox 和 Safari 均支持 `command` 和 `commandfor`。在旧版浏览器中，从点击事件处理函数调用 `dialog.showModal()`，继续使用同一份样式表。
- 滑动绝不能是唯一的关闭方式：保留关闭按钮或能关闭对话框的操作，<kbd>Esc</kbd> 仍然有效。在带停靠高度的底部面板中，手柄是带有无障碍名称（例如“底部面板高度”）的按钮，按键和点击都能像拖动一样改变高度；没有停靠高度时，手柄是对辅助技术隐藏的凹槽。手柄的命中区域宽 64px、高 24px，在触摸屏上高度增至 44px。

## React、Svelte 和 Vue \{#frameworks\}

`dialog` 组件根据应用状态打开和关闭对话框，并在浏览器打开或关闭对话框时发出通知。触发控件和对话框内部各部分的标记由页面自行编写。组件为每个对话框挂载 `drawer` 行为脚本，因此带有 `dialog-swipe` 和 `dialog-panel` 的抽屉或底部面板松手即可关闭，并像其他关闭方式一样发出通知；对没有 `dialog-swipe` 的对话框，该行为脚本不做任何事。使用 `npx master-ui add dialog` 将组件复制到项目中。参见 [React、Svelte 和 Vue](/guide/frameworks) 了解组件的实现和用法。
