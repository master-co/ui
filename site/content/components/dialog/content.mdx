A dialog is the highest surface on the ladder: an overlay sheet over a scrim that dims and softens the page. Use `.dialog` on a native `<dialog>`. A button with `commandfor` and `command="show-modal"` opens it, so the browser supplies the top layer, the focus trap and <kbd>Esc</kbd>, and no script is involved.

## Opening and closing \{#opening-and-closing\}

Three attributes replace the script a modal used to need:

- `commandfor="id"` with `command="show-modal"` on a button opens the dialog as a modal. `command="close"` closes it and returns focus to the button that opened it.
- `closedby="any"` on the dialog adds light dismiss: a click on the scrim closes it, as <kbd>Esc</kbd> always does. Leave it out when a stray click must not discard work. A browser that does not know the attribute keeps <kbd>Esc</kbd> and the close buttons.
- A `<form method="dialog">` inside the dialog closes it on submit and reports which button was used through the dialog's `returnValue`.

While a modal dialog is open, the page behind it is inert and does not scroll.

## With a form \{#with-a-form\}

`dialog-body` holds the content between the header and the footer. It takes the remaining height and scrolls inside the sheet when the content is longer than the viewport allows. `dialog-close` puts a quiet square button in the corner: give it an accessible name.

## Sizes \{#sizes\}

A dialog is 28rem wide. `dialog-sm` is 22rem, for a confirmation of one sentence, and `dialog-lg` is 40rem. Each keeps 1rem clear of the viewport on a narrow screen. The footer answers to the dialog's own width through a container query: under 22rem its buttons stack at full width, the main action first.

## Drawer \{#drawer\}

## Sheet \{#sheet\}

`dialog-sheet` rises from the bottom edge, for a short task or a list of choices on a small screen, where the thumb is. It spans the width up to its `--dialog-width`, squares its lower corners against the edge and clears the home indicator with `env(safe-area-inset-bottom)`.

## Motion \{#motion\}

The dialog fades in from 97% of its size and half a rem below, over 280ms; it leaves in 160ms. The stylesheet writes both directions in CSS: `@starting-style` gives the first rendered frame, and `display` and `overlay` transition with `allow-discrete`, so the exit plays before the dialog leaves the top layer. With reduced motion only the fade remains.

## Accessibility \{#accessibility\}

- Name the dialog with `aria-labelledby` pointing at its `dialog-title`.
- Opened with `show-modal`, focus moves into the dialog and returns to the invoking button on close. Put `autofocus` on the field a reader should start in. For a destructive confirmation, put it on the safe action.
- `command` and `commandfor` are supported in current Chrome, Edge, Firefox and Safari. In an older browser, call `dialog.showModal()` from a click handler; the stylesheet is the same.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `dialog` | The overlay sheet, on a `<dialog>` |
| `dialog-header`, `dialog-title`, `dialog-description` | The title and what it means |
| `dialog-body` | Content between header and footer; scrolls when it is long |
| `dialog-footer` | Actions, the main one last |
| `dialog-close` | Places a square button in the top corner |
| `dialog-sm`, `dialog-lg` | 22rem and 40rem wide; the default is 28rem |
| `dialog-drawer` | A panel on the inline-end edge |
| `dialog-drawer-start` | With `dialog-drawer`: the panel on the inline-start edge, 18rem wide |
| `dialog-sheet` | A panel that rises from the bottom edge |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--dialog-width` | `28rem` | Preferred width |
| `--dialog-padding` | `1.5rem` | Padding around the parts |
| `--dialog-radius` | `1.25rem` | Corner radius |
