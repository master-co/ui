對話框位於表面層級的最上層。面板下方的遮罩會讓頁面變暗、變模糊。請在原生 `<dialog>` 上使用 `.dialog`。帶有 `commandfor` 和 `command="show-modal"` 的按鈕可開啟對話框，由瀏覽器提供頂層、限制焦點在對話框內，並處理 <kbd>Esc</kbd>，全程無須腳本。

## 開啟與關閉 \{#opening-and-closing\}

以下三個屬性可取代以往操作模態對話框所需的腳本。

- 在按鈕上同時設定 `commandfor="id"` 和 `command="show-modal"`，即可用模態方式開啟對話框。`command="close"` 會關閉對話框，並將焦點移回原先開啟它的按鈕。
- 在對話框上設定 `closedby="any"` 後，點擊遮罩也能關閉對話框，<kbd>Esc</kbd> 則照常可用。如果要避免誤點就捨棄工作，請省略這個屬性。瀏覽器即使不支援這個屬性，仍可用 <kbd>Esc</kbd> 或關閉按鈕關閉對話框。
- 對話框內的 `<form method="dialog">` 會在送出時關閉對話框，並透過對話框的 `returnValue` 回報使用了哪個按鈕。

模態對話框開啟期間，後方的頁面無法互動或捲動。

## 尺寸 \{#sizes\}

對話框預設寬 28rem。`dialog-sm` 寬 22rem，適合只需一句話的確認訊息，`dialog-lg` 則寬 40rem。在窄螢幕上，各尺寸都會與檢視區左右邊緣各保留 1rem。頁尾透過容器查詢依對話框本身的寬度調整版面配置。寬度小於 22rem 時，按鈕會改為垂直排列，每個按鈕都占滿寬度，主要動作排在最上方。

## 動態效果 \{#motion\}

對話框從原尺寸的 97%、下移半個 rem 的位置開始淡入，進場耗時 280ms，退場耗時 160ms。進場與退場都由樣式表中的 CSS 控制。`@starting-style` 定義首次繪製時的樣式，`display` 和 `overlay` 則透過 `allow-discrete` 套用轉場，讓退場動畫播完後，對話框才離開頂層。啟用減少動態效果時，只保留淡入淡出。

## 無障礙 \{#accessibility\}

- 將 `aria-labelledby` 指向對話框的 `dialog-title`，為對話框提供可存取名稱。
- 用 `show-modal` 開啟時，焦點會移入對話框，關閉時則移回開啟它的按鈕。請在使用者應先操作的欄位上設定 `autofocus`。如果是確認破壞性操作，請將該屬性設在安全的選項上。
- 目前版本的 Chrome、Edge、Firefox 和 Safari 支援 `command` 和 `commandfor`。在較舊的瀏覽器中，可從點擊事件處理函式呼叫 `dialog.showModal()`，並沿用同一份樣式表。

## React、Svelte 和 Vue \{#frameworks\}

`dialog` 元件會依應用程式的狀態開啟或關閉對話框，也會回報瀏覽器何時開啟或關閉它。觸發元件和對話框內的各個部分仍由頁面自己的標記定義。執行 `npx master-ui add dialog` 將元件複製到專案中。[React、Svelte 和 Vue](/guide/frameworks) 說明元件的建置與使用方式。
