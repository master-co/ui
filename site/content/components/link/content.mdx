A link is text that goes somewhere, written in the ink of its sentence. The interface is monochrome, so a link is marked by its underline instead of a hue: a quiet line at rest that takes the full ink under the pointer. Use `.link` on an `<a>`.

## Quiet \{#quiet\}

`link-quiet` takes the color around it and shows no line until touched. Use it where a row of links would otherwise rule the page: footers, metadata and navigation lists. It must still be recognizable as a link by its place or its wording.

<ComponentPreview name="quiet" height={96} title="Quiet" background="plain" html={`<nav class="flex gap-md text-sm fg-text-muted" aria-label="Footer">
  <a class="link link-quiet" href="#docs">Docs</a>
  <a class="link link-quiet" href="#changelog">Changelog</a>
  <a class="link link-quiet" href="#license">License</a>
</nav>`} />

## New tab \{#new-tab\}

A link with `target="_blank"` draws a small arrow that points out of its line, so leaving the page is not a surprise. The arrow is decoration: say "opens in a new tab" in the link's name or its text for those who cannot see it.

## Link or button \{#link-or-button\}

A link navigates and a button acts. For navigation that should look like a control, put [`btn`](/components/button) on the `<a>`. For an action inside a sentence, such as "undo", put `link` on a `<button type="button">` so it keeps a button's keys and semantics.
