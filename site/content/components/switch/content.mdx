A switch is a well whose pearl thumb slides onto ink. Use `.switch` on a native checkbox with `role="switch"` for settings that take effect immediately; for choices submitted with a form, a [checkbox](/components/checkbox) is clearer.

## Accessibility \{#accessibility\}

- Keep `role="switch"` so assistive technology announces on and off rather than checked.
- Every switch needs a label: a wrapping `<label>`, a `<label for>` or `aria-label`.
- The input stays focusable and toggles with Space, as a native control does.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `switch` | A native checkbox with `role="switch"` |
| `switch-sm`, `switch-lg` | 18px and 26px tracks; the default is 22px |
