## Accessibility \{#accessibility\}

- Keep `role="switch"` so assistive technology announces on and off rather than checked.
- Every switch needs a label: a wrapping `<label>`, a `<label for>` or `aria-label`.
- The checkbox remains focusable and toggles with Space, as a native control does.

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--switch-height` | `1.25rem` | Track height; the width and thumb follow |
| `--switch-width` | `height × 1.75` | Track width |
| `--switch-track` | `var(--color-control-track)` | Track color when off |
| `--switch-track-on` | `var(--color-accent)` | Track color when on |
