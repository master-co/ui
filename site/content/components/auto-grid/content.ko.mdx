자동 그리드는 최소 너비를 지키면서 같은 너비의 열을 공간에 들어가는 만큼 배치합니다. 그리드가 주어진 공간에 맞춰 열 수를 직접 정하므로 쿼리가 필요 없습니다. 같은 마크업으로 대시보드에서는 타일이 네 열, 사이드바에서는 두 열, 휴대전화에서는 한 열로 배치됩니다.

이 기능을 레이아웃 클래스로 제공하는 이유는 그 바탕이 되는 규칙인 `repeat(auto-fill, minmax(min(100%, 16rem), 1fr))`을 유틸리티로 표현할 수 없고, 직접 작성할 때도 미묘한 실수가 생기기 쉽기 때문입니다. `min(100%, …)`은 화면이 좁을 때 열 하나가 화면 너비를 넘지 않도록 합니다.

## 최소 열 너비 \{#minimum\}

`--auto-grid-min`은 열의 최소 너비이며 기본값은 16rem입니다. 최소 너비를 줄이면 더 좁은 열을 더 많이 배치할 수 있습니다. 그림에는 11rem, 문단이 들어 있는 카드에는 20rem이 적합합니다.

## 빈 열 유지 또는 접기 \{#fill-or-fit\}

기본적으로 빈 열도 자리를 유지하므로 넓은 그리드에 타일이 두 개뿐이어도 각 타일은 원래 너비를 유지합니다. `auto-grid-fit`은 빈 열을 접어 타일이 있는 열들이 행 전체의 너비를 나눠 쓰게 합니다. 항목이 늘어나는 목록에는 기본 동작을 사용하고, 항목 수가 고정되어 항상 한 행을 가득 채워야 한다면 fit을 사용하세요.

## 자동 그리드가 적합하지 않은 경우 \{#when-not\}

열 수가 디자인의 일부라면 `grid grid-cols(3)`과 `grid-cols(3)@container(--4xl)` 같은 컨테이너 변형으로 열 수를 명시하세요. 자동 그리드는 열 수를 직접 결정하므로 항목을 나열할 때는 적합하지만, 세 번째 열에 별도의 의미가 있는 레이아웃에는 적합하지 않습니다.

## 접근성 \{#accessibility\}

- 그리드는 열 수만 바꿉니다. 항목은 소스 순서에 따라 왼쪽에서 오른쪽으로, 위에서 아래로 읽힙니다.
- 타일이 같은 종류의 항목으로 이루어져 있다면 `<ul class="auto-grid">` 목록을 사용해 스크린 리더가 항목 수를 안내하도록 하세요.
