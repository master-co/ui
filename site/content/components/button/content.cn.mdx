按钮是一块带有半像素轮廓的小型凸起面板。指针悬停时抬高半像素，按下时沉入凹槽，状态变化靠光影和凹凸来区分，无需改变颜色。执行操作时，将 `.btn` 用在 `<button>` 上。需要让导航链接呈现按钮外观时，将同一个类用在 `<a>` 上。

<ComponentPreview name="default" height={96} title="按钮" html={`<button type="button" class="btn">Cancel</button>
<button type="button" class="btn btn-primary">Save changes</button>`} />

## 变体 \{#variants\}

默认按钮采用 Moonstone 材质。根据操作的重要程度选择变体：

- `btn-primary` 在 Moonstone 上呈墨色，在 Obsidian 上呈珍珠色。每个视图只用一个，用于该视图的核心操作。
- `btn-quiet` 在交互时才显现材质，适合工具栏、页头和紧凑的行。
- `btn-danger` 保留凸起材质，标签使用危险状态的前景色。
- `btn-brand` 是唯一带色相的控件，采用品牌靛蓝，适合首页的主操作或升级等需要突出显示的操作。每个视图最多使用一个。按钮的表面、边缘和光晕都由 `--color-brand` 混合生成，随品牌色变化。

<button type="button" class="btn btn-primary">Primary</button>
<button type="button" class="btn btn-quiet">Quiet</button>
<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-brand">Get started</button>`} />

## 破坏性操作 \{#destructive\}

单独使用 `btn-danger` 时，按钮保持凸起，仅标签采用危险状态的前景色，适合与其他操作并列的删除按钮。与 `btn-primary` 搭配时，按钮用危险色填充，用于确认破坏性操作，填充方式与品牌按钮使用品牌色相同。只在最后一步使用填充样式，例如在[对话框](/components/dialog)内提供确认按钮，并在标签中写明具体操作。

<ComponentPreview name="destructive" height={96} narrowHeight={152} title="破坏性操作" html={`<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-primary btn-danger">Delete project</button>
<button type="button" class="btn btn-primary btn-danger" disabled>Delete project</button>`} />

## 尺寸 \{#sizes\}

默认高度为 38px，紧凑界面用 32px，需要突出显示的操作用 44px。内边距、标签字号、图标尺寸和圆角半径随尺寸一同变化。在触摸屏上，各尺寸的高度均至少为 44px。

<ComponentPreview name="sizes" height={96} title="尺寸" html={`<button type="button" class="btn btn-sm">Small</button>
<button type="button" class="btn">Medium</button>
<button type="button" class="btn btn-lg">Large</button>`} />

## 搭配图标 \{#with-icons\}

将 [`icon`](/components/icon) 加到图标本身。图标尺寸由按钮设定，默认 16px，小按钮 14px，大按钮 18px，描边宽度为 1.5。`btn-square` 将按钮设为正方形，用 `aria-label` 为它提供无障碍名称。

## 胶囊形 \{#pill\}

`btn-pill` 将两端变成半圆，并略微增加行内方向的留白，因为圆弧端部比平直端部看起来更紧凑。

<ComponentPreview name="pill" height={96} title="胶囊形" html={`<button type="button" class="btn btn-pill">Follow</button>
<button type="button" class="btn btn-primary btn-pill">Subscribe</button>`} />

## 切换按钮 \{#toggle\}

低调样式的按钮带有 `aria-pressed="true"` 时会保持下沉，呈现凹槽效果。用自己的脚本更新该属性。紧跟在这类按钮之后的[菜单](/components/menu#menubar)或[弹出层](/components/popover)打开时，按钮也会自动保持下沉。

  <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M7 5h6a3.5 3.5 0 0 1 0 7H7zM7 12h7a3.5 3.5 0 0 1 0 7H7z"/></svg>
</button>
<button type="button" class="btn btn-quiet btn-square" aria-label="Italic" aria-pressed="false">
  <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M11 5h6M7 19h6M14 5l-4 14"/></svg>
</button>`} />

## 按钮组 \{#group\}

`btn-group` 将相关操作合成一个整体轮廓。每个按钮保留各自的材质，组内相接处的圆角改为直角，相邻轮廓重叠成一道接缝。组内按钮不会单独抬升，以维持整体形状。为按钮组设置 `role="group"` 和标签。

<ComponentPreview name="group" height={96} narrowHeight={152} title="按钮组" html={`<div class="btn-group" role="group" aria-label="History">
  <button type="button" class="btn">Undo</button>
  <button type="button" class="btn">Redo</button>
</div>
<div class="btn-group" role="group" aria-label="Deploy">
  <button type="button" class="btn btn-primary">Deploy</button>
  <button type="button" class="btn btn-primary btn-square" aria-label="Deploy options">
    <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg>
  </button>
</div>`} />

分体按钮中的第二个按钮通常用于打开[菜单](/components/menu)。添加 `popovertarget` 后，菜单会自动贴着该按钮定位。

## 分页 \{#pagination\}

用一排低调样式的方形按钮作为页码链接。当前页的按钮带有 `aria-current="page"`，像按下的切换按钮一样保持下沉，呈现凹槽效果。

  </a>
  <a class="btn btn-quiet btn-square btn-sm" href="#page-1">1</a>

</nav>`} />

## 忙碌状态 \{#busy\}

操作执行期间设置 `aria-busy="true"`。按钮保留原有标签和材质，不再抬升，并在行内显示一个与按钮图标同尺寸的[加载指示器](/components/spinner)。更新标签以说明正在执行的操作，并在事件处理函数中忽略后续触发。

<ComponentPreview name="busy" height={96} narrowHeight={152} title="忙碌状态" html={`<button type="button" class="btn" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Saving…
</button>
<button type="button" class="btn btn-primary" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Publishing…
</button>`} />

## 禁用状态 \{#disabled\}

禁用的按钮沉入表面，呈现平坦的凹槽，标签使用禁用状态的前景色。链接本身不支持禁用，需使用 `aria-disabled="true"` 并移除 `href`。

<ComponentPreview name="disabled" height={96} title="禁用状态" html={`<button type="button" class="btn" disabled>Default</button>
<button type="button" class="btn btn-primary" disabled>Primary</button>`} />
