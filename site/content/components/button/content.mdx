## Variants \{#variants\}

The default button sits on a raised surface. Choose a variant by the weight of the action: one primary action per view, accent for emphasis, danger for destructive actions and ghost for quiet toolbar actions.

<ComponentPreview name="variants" title="Variants" html={`<button type="button" class="btn">Default</button>
<button type="button" class="btn btn-primary">Primary</button>
<button type="button" class="btn btn-accent">Accent</button>
<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-ghost">Ghost</button>`} />

## Sizes \{#sizes\}

`.btn-md` is the default size. Sizes change the height, padding, gap, font size and radius together.

<ComponentPreview name="sizes" title="Sizes" html={`<button type="button" class="btn btn-primary btn-xs">Extra small</button>
<button type="button" class="btn btn-primary btn-sm">Small</button>
<button type="button" class="btn btn-primary btn-md">Medium</button>
<button type="button" class="btn btn-primary btn-lg">Large</button>
<button type="button" class="btn btn-primary btn-xl">Extra large</button>`} />

## With icons \{#with-icons\}

An inline `<svg>` scales with the button text. Add `.btn-icon` for a square, icon-only button and give it an accessible name with `aria-label`.

<ComponentPreview name="icons" title="With icons" html={`<button type="button" class="btn btn-primary">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M12 5v14M5 12h14"/></svg>
  New project
</button>
<button type="button" class="btn btn-icon" aria-label="Settings">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M4 6h16M4 12h16M4 18h16"/></svg>
</button>`} />

## Busy \{#busy\}

Set `aria-busy="true"` while an action runs. The label stays in the layout to keep the width, and a nested [spinner](/components/spinner) takes its place.

<ComponentPreview name="busy" title="Busy" html={`<button type="button" class="btn btn-primary" aria-busy="true">
  <span class="spinner" aria-hidden="true"></span>
  Saving
</button>`} />

## Disabled \{#disabled\}

Use the `disabled` attribute on buttons. Links cannot be disabled; use `aria-disabled="true"` and remove the `href`.

<ComponentPreview name="disabled" title="Disabled" html={`<button type="button" class="btn" disabled>Default</button>
<button type="button" class="btn btn-primary" disabled>Primary</button>`} />

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--btn-height` | `2.25rem` | Block size of the button |
| `--btn-padding-x` | `var(--spacing-md)` | Inline padding |
| `--btn-gap` | `var(--spacing-xs)` | Space between icon and label |
| `--btn-font-size` | `var(--font-size-sm)` | Label size |
| `--btn-radius` | `var(--radius-md)` | Corner radius |
| `--btn-bg`, `--btn-bg-hover` | Raised and inset surfaces | Background at rest and on hover |
| `--btn-fg` | `var(--color-text-strong)` | Label and icon color |
| `--btn-border` | `var(--color-line-divider)` | Border color |
