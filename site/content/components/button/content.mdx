A button is a small raised sheet with a half-pixel contour. It lifts by half a pixel under the pointer and sinks into a well when pressed, so its state reads through light and depth rather than color. Use `.btn` on a `<button>` for actions and on an `<a>` for navigation that should look like one.

<ComponentPreview name="default" title="Button" html={`<button type="button" class="btn">Cancel</button>
<button type="button" class="btn btn-primary">Save changes</button>`} />

## Variants \{#variants\}

The default button is moonstone. Choose the variant by the weight of the action:

- `btn-primary` is ink on moonstone and pearl on obsidian. Use one per view, for the action the view exists for.
- `btn-quiet` has no material until touched; use it in toolbars, headers and dense rows.
- `btn-danger` keeps the raised material and gives its label the danger ink.
- `btn-brand` is the one hued control, in the brand indigo: a moment such as a homepage call to action or an upgrade. Use at most one per view. Its face, edge and glow are mixed from `--color-brand`, so it follows your brand color.

<ComponentPreview name="variants" title="Variants" html={`<button type="button" class="btn">Default</button>
<button type="button" class="btn btn-primary">Primary</button>
<button type="button" class="btn btn-quiet">Quiet</button>
<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-brand">Get started</button>`} />

## Destructive actions \{#destructive\}

`btn-danger` alone is the quiet form: a raised button whose label is in the danger ink, for a delete among other actions. Together with `btn-primary` it becomes the confirming button of a destructive act, filled with the danger color the way a brand button is filled with the brand. Keep the filled form for the last step, such as the button that confirms inside a [dialog](/components/dialog), and let its label name the act.

<ComponentPreview name="destructive" title="Destructive actions" html={`<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-primary btn-danger">Delete project</button>
<button type="button" class="btn btn-primary btn-danger" disabled>Delete project</button>`} />

## Sizes \{#sizes\}

The default height is 38px, with 32px for dense UI and 44px for prominent actions. Padding, label size, icon size and radius change together. On touch screens every size grows to at least 44px.

<ComponentPreview name="sizes" title="Sizes" html={`<button type="button" class="btn btn-sm">Small</button>
<button type="button" class="btn">Medium</button>
<button type="button" class="btn btn-lg">Large</button>`} />

## With icons \{#with-icons\}

Put [`icon`](/components/icon) on the icon itself. The button sets its size, 16px by default, 14px in small and 18px in large buttons, at a 1.5 stroke. `btn-square` makes a square button: give it an accessible name with `aria-label`.

## Pill \{#pill\}

`btn-pill` rounds the ends fully and adds a little inline space, since a round end feels tighter than a flat one.

## Toggle \{#toggle\}

A quiet button with `aria-pressed="true"` stays sunk into a well. Update the attribute with your own script. A quiet button also stays sunk, without script, while the [menu](/components/menu#menubar) or [popover](/components/popover) placed right after it is open.

</button>`} />

## Group \{#group\}

`btn-group` joins related actions into one outer shape. Each button keeps its own material; the group squares the corners that meet and lets neighboring contours overlap into a single seam. A button in a group does not lift on its own, so the shape stays whole. Give the group `role="group"` and a label.

<ComponentPreview name="group" title="Group" html={`<div class="btn-group" role="group" aria-label="History">
  <button type="button" class="btn">Undo</button>
  <button type="button" class="btn">Redo</button>
</div>
<div class="btn-group" role="group" aria-label="Deploy">
  <button type="button" class="btn btn-primary">Deploy</button>
  <button type="button" class="btn btn-primary btn-square" aria-label="Deploy options">
    <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg>
  </button>
</div>`} />

The second button of a split action usually opens a [menu](/components/menu): add `popovertarget` and the menu places itself against it.

## Busy \{#busy\}

Set `aria-busy="true"` while an action runs. The button keeps its label and material, stops lifting and shows an inline [spinner](/components/spinner) sized like its icons. Change the label to say what is happening, and ignore further activation in your handler.

<ComponentPreview name="busy" title="Busy" html={`<button type="button" class="btn" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Saving…
</button>
<button type="button" class="btn btn-primary" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Publishing…
</button>`} />

## Disabled \{#disabled\}

A disabled button drops back into the surface: a flat well with disabled ink. Links cannot be disabled; use `aria-disabled="true"` and remove the `href`.

<ComponentPreview name="disabled" title="Disabled" html={`<button type="button" class="btn" disabled>Default</button>
<button type="button" class="btn btn-primary" disabled>Primary</button>`} />

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `btn` | The raised base button |
| `btn-primary`, `btn-quiet`, `btn-danger`, `btn-brand` | Variants; `btn-primary btn-danger` fills a destructive confirmation |
| `btn-sm`, `btn-lg` | 32px and 44px heights; the default is 38px |
| `btn-square`, `btn-pill` | A square icon-only button, fully rounded ends |
| `btn-group` | A container that joins its buttons into one shape |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--btn-height` | `2.375rem` | Minimum block size |
| `--btn-padding-x` | `var(--spacing-md)` | Inline padding |
| `--btn-font-size` | `.84375rem` | Label size |
| `--btn-radius` | `var(--radius-control)` | Corner radius: 10px, with 8px for small and 12px for large buttons |
| `--btn-gap` | `.5rem` | Space between icon and label |
| `--icon-size` | `1rem` | Size of an `icon` inside the button |
