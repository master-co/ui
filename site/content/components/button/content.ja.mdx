ボタンは、0.5px の輪郭を持ち、背景面からわずかに浮いた小さなシートです。ポインターを重ねると 0.5px 浮き上がり、押すとくぼみに沈みます。明暗と奥行きの変化で状態がわかるため、色の違いに頼りません。操作には `<button>`、ボタンの見た目にしたいナビゲーションには `<a>` を使い、それぞれにクラス `.btn` を指定します。

<button type="button" class="btn btn-primary">Save changes</button>`} />

## バリエーション \{#variants\}

既定のボタンは moonstone です。操作の重要度に合わせてバリエーションを選びます。

- `btn-primary` は、moonstone の面にインク色、obsidian の面にパール色を使います。そのビューの主目的となる操作に、ビューごとに 1 つ使います。
- `btn-quiet` は、操作するまでボタン面の質感が現れません。ツールバー、ヘッダー、項目が密に並ぶ行に使います。
- `btn-danger` は浮き上がった面の質感を保ち、ラベルに危険を示す文字色を使います。
- `btn-brand` は、ブランドのインディゴを使う唯一の有彩色のボタンです。ホームページで行動を促すボタンや、アップグレードなど、特に目立たせたい操作に使います。1 つのビューにつき最大 1 つです。ボタン面、縁、光彩の色は `--color-brand` から合成するため、ブランドカラーに連動します。

<ComponentPreview name="variants" height={96} mediumHeight={152} narrowHeight={216} title="バリエーション" html={`<button type="button" class="btn">Default</button>
<button type="button" class="btn btn-primary">Primary</button>
<button type="button" class="btn btn-quiet">Quiet</button>
<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-brand">Get started</button>`} />

## 破壊的な操作 \{#destructive\}

`btn-danger` 単体では、浮き上がったボタンのラベルに危険を示す文字色を使う、控えめな表示になります。ほかの操作に交じって削除ボタンを置く場合などに使います。`btn-primary` と組み合わせると、ブランドボタンをブランドカラーで塗りつぶすのと同じように、危険を示す色で塗りつぶした確認ボタンになります。塗りつぶしは [ダイアログ](/components/dialog) 内の確定ボタンなど、最終段階に限って使い、ラベルには実行する操作を明記します。

<ComponentPreview name="destructive" height={96} narrowHeight={152} title="破壊的な操作" html={`<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-primary btn-danger">Delete project</button>
<button type="button" class="btn btn-primary btn-danger" disabled>Delete project</button>`} />

## サイズ \{#sizes\}

高さは既定で 38px です。要素が密に並ぶ UI では 32px、目立たせたい操作では 44px を使います。パディング、ラベルの文字サイズ、アイコンのサイズ、角丸の半径も連動して変わります。タッチスクリーンでは、どのサイズも高さが最低 44px になります。

<ComponentPreview name="sizes" height={96} title="サイズ" html={`<button type="button" class="btn btn-sm">Small</button>
<button type="button" class="btn">Medium</button>
<button type="button" class="btn btn-lg">Large</button>`} />

## アイコン付き \{#with-icons\}

アイコン自体に [`icon`](/components/icon) を指定します。アイコンのサイズはボタン側で決まり、既定は 16px、小サイズは 14px、大サイズは 18px で、線幅は 1.5 です。`btn-square` を指定すると正方形のボタンになります。`aria-label` でアクセシブルな名前を付けます。

  New project
</button>
<button type="button" class="btn btn-square" aria-label="Search">

</button>
<button type="button" class="btn btn-quiet btn-square" aria-label="More">

</button>`} />

## ピル型 \{#pill\}

`btn-pill` はボタンの両端を完全に丸めます。直線の端に比べて窮屈に見えやすいため、インライン方向の余白を少し増やします。

<ComponentPreview name="pill" height={96} title="ピル型" html={`<button type="button" class="btn btn-pill">Follow</button>
<button type="button" class="btn btn-primary btn-pill">Subscribe</button>`} />

## トグル \{#toggle\}

控えめなボタンに `aria-pressed="true"` を指定すると、くぼみに沈んだ状態を保ちます。この属性は独自のスクリプトで更新します。直後に置いた [メニュー](/components/menu#menubar) や [ポップオーバー](/components/popover) が開いている間も、スクリプトなしで沈んだ状態を保ちます。

  <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M7 5h6a3.5 3.5 0 0 1 0 7H7zM7 12h7a3.5 3.5 0 0 1 0 7H7z"/></svg>
</button>
<button type="button" class="btn btn-quiet btn-square" aria-label="Italic" aria-pressed="false">
  <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M11 5h6M7 19h6M14 5l-4 14"/></svg>
</button>`} />

## ボタングループ \{#group\}

`btn-group` は関連する操作を一つの外形にまとめます。各ボタンは固有の質感を保ち、隣り合う角は直角になり、輪郭が重なって一本の境界線になります。グループ内ではボタンが個別に浮き上がらないため、全体の形が保たれます。グループには `role="group"` とラベルを指定します。

<ComponentPreview name="group" height={96} narrowHeight={152} title="ボタングループ" html={`<div class="btn-group" role="group" aria-label="History">
  <button type="button" class="btn">Undo</button>
  <button type="button" class="btn">Redo</button>
</div>
<div class="btn-group" role="group" aria-label="Deploy">
  <button type="button" class="btn btn-primary">Deploy</button>
  <button type="button" class="btn btn-primary btn-square" aria-label="Deploy options">
    <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg>
  </button>
</div>`} />

分割ボタンの 2 つ目のボタンは、通常 [メニュー](/components/menu) を開きます。`popovertarget` を追加すると、メニューがそのボタンに接する位置に自動で配置されます。

## ページネーション \{#pagination\}

控えめな正方形のボタンを横に並べて、各ページへのリンクを作ります。現在のページには `aria-current="page"` を指定し、オンのトグルと同じように、くぼみに沈んだ状態を保ちます。

## 処理中 \{#busy\}

処理中は `aria-busy="true"` を設定します。ボタンはラベルと質感を保ち、ポインターを重ねても浮き上がらず、アイコンと同じサイズのインライン [スピナー](/components/spinner) を表示します。ラベルは進行中の処理を伝える文言に変え、ハンドラーでは処理中の再操作を無視します。

<ComponentPreview name="busy" height={96} narrowHeight={152} title="処理中" html={`<button type="button" class="btn" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Saving…
</button>
<button type="button" class="btn btn-primary" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Publishing…
</button>`} />

## 無効 \{#disabled\}

無効なボタンは背景面に沈み、平らなくぼみと無効状態の文字色で表示されます。リンク自体には無効化の機能がないため、`aria-disabled="true"` を指定し、`href` を削除します。

<ComponentPreview name="disabled" height={96} title="無効" html={`<button type="button" class="btn" disabled>Default</button>
<button type="button" class="btn btn-primary" disabled>Primary</button>`} />
