버튼은 반 픽셀 두께의 윤곽선을 두른 작고 살짝 돌출된 표면입니다. 포인터를 올리면 반 픽셀만큼 떠오르고 누르면 오목한 영역으로 들어갑니다. 색상 변화 없이도 빛과 깊이로 상태를 구분할 수 있습니다. 동작을 실행하는 `<button>`과 버튼처럼 보여야 하는 탐색 링크 `<a>`에 `.btn`을 적용합니다.

<button type="button" class="btn btn-primary">Save changes</button>`} />

## 변형 \{#variants\}

기본 버튼은 moonstone 표면을 사용합니다. 동작의 중요도에 따라 변형을 선택합니다.

- `btn-primary`는 moonstone 표면에 잉크색 레이블을, obsidian 표면에 진주색 레이블을 표시합니다. 화면마다 핵심 동작 하나에 사용합니다.
- `btn-quiet`는 상호작용하기 전까지 표면이 드러나지 않습니다. 도구 모음, 헤더, 요소가 빽빽한 행에 사용합니다.
- `btn-danger`는 돌출된 표면을 유지하고 레이블에는 위험을 나타내는 글자색을 적용합니다.
- `btn-brand`는 브랜드 인디고로 표면을 채우는 유일한 버튼 변형입니다. 홈페이지의 주요 행동 유도나 업그레이드처럼 강조할 동작에 화면당 최대 하나만 사용합니다. 버튼의 표면, 테두리, 빛 번짐 효과에는 `--color-brand`를 바탕으로 혼합한 색을 사용하므로 브랜드 색상을 따릅니다.

<button type="button" class="btn btn-primary">Primary</button>
<button type="button" class="btn btn-quiet">Quiet</button>
<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-brand">Get started</button>`} />

## 파괴적 작업 \{#destructive\}

`btn-danger`만 적용하면 돌출된 표면을 유지하면서 레이블에만 위험 색상을 써서 강조를 낮춥니다. 여러 동작 중 하나로 삭제를 제공할 때 사용합니다. `btn-primary`를 함께 적용하면 파괴적 작업을 확정하는 버튼이 됩니다. 브랜드 버튼이 브랜드 색상으로 채워지듯 이 버튼은 위험 색상으로 채워집니다. 색상을 채운 형태는 [대화상자](/components/dialog)에서 작업을 확정하는 버튼처럼 마지막 단계에만 사용합니다. 레이블에는 실행할 동작을 명시합니다.

<ComponentPreview name="destructive" height={96} narrowHeight={152} title="파괴적 작업" html={`<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-primary btn-danger">Delete project</button>
<button type="button" class="btn btn-primary btn-danger" disabled>Delete project</button>`} />

## 크기 \{#sizes\}

기본 높이는 38px입니다. 요소가 빽빽한 UI에는 32px, 강조할 동작에는 44px 높이를 사용합니다. 안쪽 여백, 레이블 크기, 아이콘 크기, 모서리 반경은 함께 달라집니다. 터치 화면에서는 모든 크기의 버튼이 최소 44px 높이로 표시됩니다.

<ComponentPreview name="sizes" height={96} title="크기" html={`<button type="button" class="btn btn-sm">Small</button>
<button type="button" class="btn">Medium</button>
<button type="button" class="btn btn-lg">Large</button>`} />

## 아이콘이 있는 버튼 \{#with-icons\}

## 캡슐형 \{#pill\}

`btn-pill`은 양 끝을 완전히 둥글게 만듭니다. 둥근 끝은 평평한 끝보다 좁아 보이므로 인라인 방향의 여백도 조금 늘어납니다.

<ComponentPreview name="pill" height={96} title="캡슐형" html={`<button type="button" class="btn btn-pill">Follow</button>
<button type="button" class="btn btn-primary btn-pill">Subscribe</button>`} />

## 토글 \{#toggle\}

`aria-pressed="true"`를 지정한 btn-quiet 버튼은 오목한 영역에 들어간 상태를 유지합니다. 이 속성은 직접 작성한 스크립트로 갱신하세요. btn-quiet 버튼 바로 뒤에 배치한 [메뉴](/components/menu#menubar)나 [팝오버](/components/popover)가 열려 있는 동안에는 스크립트 없이도 버튼이 눌린 상태를 유지합니다.

## 그룹 \{#group\}

`btn-group`은 관련 동작을 하나의 외곽 형태로 묶습니다. 각 버튼은 고유한 표면을 유지합니다. 그룹은 맞닿는 모서리를 직각으로 만들고, 이웃한 버튼의 윤곽선을 겹쳐 경계가 한 줄로 보이게 합니다. 그룹 안의 버튼은 개별적으로 떠오르지 않아 전체 형태가 유지됩니다. 그룹에 `role="group"`과 레이블을 지정합니다.

<ComponentPreview name="group" height={96} narrowHeight={152} title="그룹" html={`<div class="btn-group" role="group" aria-label="History">
  <button type="button" class="btn">Undo</button>
  <button type="button" class="btn">Redo</button>
</div>
<div class="btn-group" role="group" aria-label="Deploy">
  <button type="button" class="btn btn-primary">Deploy</button>
  <button type="button" class="btn btn-primary btn-square" aria-label="Deploy options">
    <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg>
  </button>
</div>`} />

분할 버튼에서 두 번째 버튼은 보통 [메뉴](/components/menu)를 엽니다. 두 번째 버튼에 `popovertarget`을 추가하면 메뉴가 해당 버튼에 맞춰 배치됩니다.

## 처리 중 \{#busy\}

동작을 실행하는 동안 `aria-busy="true"`를 설정합니다. 버튼은 레이블과 표면을 유지한 채 떠오르는 동작을 멈추고, 아이콘과 같은 크기의 인라인 [스피너](/components/spinner)를 표시합니다. 현재 처리 중인 작업을 알 수 있도록 레이블을 바꾸고, 핸들러에서 추가 실행 요청을 무시합니다.

<ComponentPreview name="busy" height={96} narrowHeight={152} title="처리 중" html={`<button type="button" class="btn" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Saving…
</button>
<button type="button" class="btn btn-primary" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Publishing…
</button>`} />

## 비활성화 \{#disabled\}

비활성화된 버튼은 주변 표면으로 가라앉아 바닥이 평평한 홈처럼 보이며, 레이블에는 비활성 상태를 나타내는 글자색을 사용합니다. 링크는 비활성화할 수 없으므로 `aria-disabled="true"`를 적용하고 `href` 속성을 제거합니다.

<ComponentPreview name="disabled" height={96} title="비활성화" html={`<button type="button" class="btn" disabled>Default</button>
<button type="button" class="btn btn-primary" disabled>Primary</button>`} />
