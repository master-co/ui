多數版面配置都會反覆用到幾種做法：把項目直向堆疊、讓橫列換行、把兩組項目推到兩端，或將單一項目置中。每種做法只需兩三個 utility。Master UI 刻意省去這些做法的專用類別，因為類別只會為原本的 utility 組合另取名稱，每多一種變化又得加一個類別。

本頁介紹版面配置的基本做法。其他版面配置、[區塊](/blocks)和[頁面](/pages)都會組合運用這些做法。

## 直向堆疊 \{#stack\}

用 `flex flex-col` 搭配間距，將項目排成間隔一致的單欄。間距由堆疊容器統一設定，因此增減子項目時，不會留下多餘的外距。

<ComponentPreview name="stack" height={240} title="直向堆疊" html={`<div class="flex flex-col gap-md w-full max-w(320)">
  <div class="well p-md">One</div>
  <div class="well p-md">Two</div>
  <div class="well p-md">Three</div>
</div>`} />

依間距級距選擇合適的間隔：標籤和值之間用 `gap-xs`（8px），欄位之間用 `gap-md`（16px），區段之間用 `gap-xl`（32px）。

## 橫向群組 \{#cluster\}

用 `flex flex-wrap` 搭配間距，排出可換行的橫列。適合把寬度各異、但應放在一起的項目排成一組，例如標籤、篩選條件或一組按鈕。換行後，各列之間也會保留間距。

  <span class="chip">Design</span>
  <span class="chip">Engineering</span>
  <span class="chip">Research</span>
  <span class="chip">Operations</span>
  <span class="chip">Support</span>
  <span class="chip">Legal</span>
  <span class="chip">Finance</span>
</div>`} />

## 分列兩端 \{#split\}

用 `flex items-center justify-between` 將兩組項目推到橫列的兩端。加上 `flex-wrap` 和間距後，同一列放不下時，第二組會移到第一組下方，避免互相擠壓。

<ComponentPreview name="split" height={128} narrowHeight={184} title="分列兩端" bodyClass="flex justify-center p-lg" html={`<header class="sheet flex flex-wrap items-center justify-between gap-sm w-full max-w(520) p-md">
  <div class="flex flex-col gap-3xs">
    <h3 class="heading heading-sm">Members</h3>
    <p class="m(0) text-sm fg-text-muted">Four people have access.</p>
  </div>
  <div class="flex gap-xs">
    <button type="button" class="btn btn-sm">Export</button>
    <button type="button" class="btn btn-sm btn-primary">Invite</button>
  </div>
</header>`} />

如果只想把最後一個項目推到列尾，在該項目上加上 `ml-auto`，其餘項目維持原位。

## 置中 \{#center\}

要讓單一項目在容器內水平和垂直置中，請在容器上套用 `flex items-center justify-center`。要讓整欄在頁面中置中並限制欄寬，請在該欄設定最大寬度和 `mx-auto`。

</div>`} />

## 等寬欄 \{#columns\}

`grid grid-cols(3)` 會將可用寬度平分為三欄，`grid-col-span(2)` 則讓單一項目跨兩欄。欄數要隨寬度自動調整時，請使用[自動網格](/components/auto-grid)。方塊有幾種固定規格時，使用[Bento 版面](/components/bento)。方塊各有不同高度時，使用[瀑布流版面配置](/components/masonry)。

<ComponentPreview name="columns" height={176} title="等寬欄" bodyClass="p-lg" html={`<div class="grid grid-cols(3) gap-md w-full">
  <div class="well p-md">One</div>
  <div class="well p-md">Two</div>
  <div class="well p-md">Three</div>
  <div class="well p-md grid-col-span(2)">Four, across two</div>
  <div class="well p-md">Five</div>
</div>`} />

## 並排 \{#beside\}

要讓兩個項目並排，一個用固定寬度，另一個填滿剩餘空間，剩餘空間太窄時再改為上下排列，也無須撰寫查詢。在兩者的容器上套用 `flex flex-wrap` 和間距。較窄的項目套用 `grow(1) basis(…)`，將其中的 basis 值設為該項目並排時的基準寬度。較寬的項目套用 `grow(999) basis(0)` 和 `min-w(…)`。較寬的項目會占用幾乎所有剩餘空間。當空間小於它的最小寬度時，它會換到下一列，較窄的項目則會撐滿上方整列。

  <aside class="sheet flex flex-col gap-xs grow(1) basis(240) p-md" aria-label="Filters">

  </aside>
  <div class="sheet flex flex-col gap-xs grow(999) basis(0) min-w(320) p-md">
    <h3 class="heading heading-sm">Issues</h3>
    <p class="m(0) leading-md">The list takes everything the filters leave. Under 320px of its own it would be too narrow to read, so the row wraps instead.</p>
  </div>
</section>`} />

## 依可用寬度調整 \{#responsive\}

變體可依寬度改變 utility 的效果。`@md` 這類變體以檢視區寬度為準，適合用在頁面的外框。`@container(--2xl)` 這類變體以最近的尺寸容器為準，也就是最近套用 `container-inline` 的祖先元素。將它們用於頁面外框內的配置，同一個區段在寬大的頁面、側邊欄或對話框裡，都會依相同規則調整。

<PagePreview name="responsive" title="響應式排列" height={152} tabletHeight={200} phoneHeight={456} caption="選擇「手機」後，橫列會改為直向堆疊。" html={`<section class="container-inline p-lg bg-surface-base fg-text-body text-sm">
  <div class="flex flex-col flex-row@container(--2xl) gap-md">
    <div class="sheet p-lg grow(1) basis(0)">
      <h3 class="heading heading-sm">Stacked when narrow</h3>
      <p class="m(0) mt-xs leading-md">This is a stack until its container is 42rem wide.</p>
    </div>
    <div class="sheet p-lg grow(1) basis(0)">
      <h3 class="heading heading-sm">Side by side when wide</h3>
      <p class="m(0) mt-xs leading-md">Then the same markup is a row of equal columns.</p>
    </div>
    <div class="sheet p-lg grow(1) basis(0)">
      <h3 class="heading heading-sm">By its own width</h3>
      <p class="m(0) mt-xs leading-md">The query measures the section, not the screen.</p>
    </div>
  </div>
</section>`} />

| 變體 | 測量對象 | 適用情境 |
| --- | --- | --- |
| `@xs` `@sm` `@md` `@lg` | 檢視區：48、52.125、64、80rem | 頁面外框 |
| `@container(--md)` … `@container(--5xl)` | 最近的容器：28 … 64rem | 頁面內的區域 |
| `@container(--max-3xl)` | 同樣測量最近的容器，在寬度低於門檻時生效 | 空間較窄時 |

## 何時使用類別 \{#when-a-class\}

有些配置無法用 utility 表達，或每次重寫都容易出錯，例如以 `dvh` 設定高度、為手機的主畫面指示器保留安全區域、讓黏附欄可獨立捲動、讓網格自行計算欄數、只在格子夠多時讓方塊跨格、將項目緊密排進軌道、讓圖超出文字欄，以及讓面板依序黏附在彼此下方。這些情況適合使用版面配置類別：

| 類別 | utility 無法表達的配置 |
| --- | --- |
| [`auto-grid`](/components/auto-grid) | 可自行計算欄數的網格軌道清單 |
| [`bento`](/components/bento) | 依空間調整欄數、依欄數調整跨欄範圍，並設定列高下限 |
| [`masonry`](/components/masonry) | 網格軌道配置，並在瀏覽器不支援時改用多欄容器 |
| [`breakout`](/components/breakout) | 限制欄寬，並依欄外可用空間計算外距 |
| [`sticky-stack`](/components/sticky-stack) | 依每個面板在同層元素中的位置計算位移 |
| [`form`](/components/form) | 容器寬度門檻，以及會反轉順序的操作項目 |
| [`page`](/pages/page), [`shell`](/pages/app-shell) | 整頁的外框：`dvh`、安全區域、黏附欄 |

其餘配置都可以用本頁的做法組合而成。

## 無障礙 \{#accessibility\}

- 原始碼順序決定鍵盤操作和螢幕閱讀器的朗讀順序。`flex-row-reverse` 和 `order(…)` 只改變視覺順序，請在兩種順序都合理時才使用。
- 版面配置 utility 本身不會賦予語意。請選用能表達內容用途的元素，例如 `<nav>`、`<header>`、`<ul>`，再把 utility 套用到該元素上。
