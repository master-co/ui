多くのレイアウトは、要素を縦に積む、折り返す、2 つのグループを両端に寄せる、1 つの要素を中央に置く、といった操作の繰り返しで作れます。どれも 2〜3 個のユーティリティで表現できます。Master UI では、これらの配置にあえて専用クラスを設けていません。クラスを作ってもユーティリティの組み合わせに別名が付くだけで、少し違う配置のたびにクラスが増えるためです。

ここで紹介する基本の配置を組み合わせると、ほかのレイアウトや[ブロック](/blocks)、[ページ](/pages)を作れます。

## 縦積み \{#stack\}

縦積みでは、`flex flex-col` とギャップで要素を一定の間隔で縦に並べます。間隔は親要素のギャップで管理するため、子要素を追加・削除しても余分なマージンが残りません。

<ComponentPreview name="stack" height={240} title="縦積み" html={`<div class="flex flex-col gap-md w-full max-w(320)">
  <div class="well p-md">One</div>
  <div class="well p-md">Two</div>
  <div class="well p-md">Three</div>
</div>`} />

ギャップにはスペーシングスケールを使います。ラベルと値の間には `gap-xs`（8px）、フィールド間には `gap-md`（16px）、セクション間には `gap-xl`（32px）を使います。

## 折り返し \{#cluster\}

`flex flex-wrap` とギャップで、収まりきらない要素を次の行に折り返します。タグ、フィルター、ボタン群など、幅の異なる関連要素をまとめるときに使います。ギャップは行間にも適用されます。

<ComponentPreview name="cluster" height={112} title="折り返し" html={`<div class="flex flex-wrap gap-xs max-w(360)">
  <span class="chip">Design</span>
  <span class="chip">Engineering</span>
  <span class="chip">Research</span>
  <span class="chip">Operations</span>
  <span class="chip">Support</span>
  <span class="chip">Legal</span>
  <span class="chip">Finance</span>
</div>`} />

## 両端揃え \{#split\}

`flex items-center justify-between` で 2 つのグループを行の両端に配置します。`flex-wrap` とギャップを加えると、1 行に収まらないときに、先頭のグループの幅を詰めずに 2 番目のグループを次の行へ送れます。

<ComponentPreview name="split" height={128} narrowHeight={184} title="両端揃え" bodyClass="flex justify-center p-lg" html={`<header class="sheet flex flex-wrap items-center justify-between gap-sm w-full max-w(520) p-md">
  <div class="flex flex-col gap-3xs">
    <h3 class="heading heading-sm">Members</h3>
    <p class="m(0) text-sm fg-text-muted">Four people have access.</p>
  </div>
  <div class="flex gap-xs">
    <button type="button" class="btn btn-sm">Export</button>
    <button type="button" class="btn btn-sm btn-primary">Invite</button>
  </div>
</header>`} />

最後の要素だけを行末に寄せるには、その要素に `ml-auto` を指定します。ほかの要素は元の位置に留まります。

<ComponentPreview name="push" height={120} title="最後の要素を行末に配置" bodyClass="flex justify-center p-lg" html={`<div class="sheet flex items-center gap-sm w-full max-w(520) p-sm">

  <button type="button" class="btn btn-sm btn-primary ml-auto">Publish</button>
</div>`} />

## 中央揃え \{#center\}

ボックス内の 1 要素を縦横ともに中央に配置するには、ボックスに `flex items-center justify-center` を指定します。カラムの幅に上限を設けてページの中央に配置するには、カラムに最大幅と `mx-auto` を指定します。

  <button type="button" class="btn">In the middle</button>
</div>`} />

## カラム \{#columns\}

`grid grid-cols(3)` は利用可能な幅を均等な 3 カラムに分け、`grid-col-span(2)` は 1 つの要素を 2 カラムにまたがらせます。幅に応じてカラム数を自動で変えるなら[自動グリッド](/components/auto-grid)、数種類のサイズのタイルを組み合わせるなら[ベントーレイアウト](/components/bento)、タイルごとに高さが異なるなら[メイソンリー](/components/masonry)を使います。

<ComponentPreview name="columns" height={176} title="カラム" bodyClass="p-lg" html={`<div class="grid grid-cols(3) gap-md w-full">
  <div class="well p-md">One</div>
  <div class="well p-md">Two</div>
  <div class="well p-md">Three</div>
  <div class="well p-md grid-col-span(2)">Four, across two</div>
  <div class="well p-md">Five</div>
</div>`} />

## 横並び \{#beside\}

一方を固定幅、もう一方を残りの幅で横に並べ、残りの幅が足りないときに縦に積む配置も、クエリーなしで実現できます。親要素に `flex flex-wrap` とギャップを指定します。幅の狭い要素には、同じ行に並ぶときの幅として `grow(1) basis(…)` を指定し、幅の広い要素には `grow(999) basis(0)` と `min-w(…)` を指定します。幅の広い要素は空き幅のほぼすべてを使います。空き幅がその要素の最小幅を下回ると次の行へ折り返し、幅の狭い要素は上の行いっぱいに広がります。

  <aside class="sheet flex flex-col gap-xs grow(1) basis(240) p-md" aria-label="Filters">
    <h3 class="heading heading-sm">Filters</h3>
    <label class="flex items-center gap-xs"><input type="checkbox" class="checkbox" checked> Open</label>
    <label class="flex items-center gap-xs"><input type="checkbox" class="checkbox"> Assigned to me</label>
  </aside>
  <div class="sheet flex flex-col gap-xs grow(999) basis(0) min-w(320) p-md">
    <h3 class="heading heading-sm">Issues</h3>
    <p class="m(0) leading-md">The list takes everything the filters leave. Under 320px of its own it would be too narrow to read, so the row wraps instead.</p>
  </div>
</section>`} />

## 利用可能な幅に応じた配置 \{#responsive\}

バリアントを使うと、幅に応じて適用するユーティリティを切り替えられます。`@md` と同系統のバリアントはビューポートの幅を基準にするので、ページ全体のレイアウトに使います。`@container(--2xl)` と同系統のバリアントは、`container-inline` が指定された最も近い祖先要素をサイズコンテナーとして、その幅を基準にします。ページ内の要素に使えば、幅の広いページ、サイドバー、ダイアログのいずれでも、配置先の幅に応じて同じように振る舞います。

<PagePreview name="responsive" title="レスポンシブ" height={152} tabletHeight={200} phoneHeight={456} caption="「スマートフォン」を選ぶと、横並びが縦積みに変わります。" html={`<section class="container-inline p-lg bg-surface-base fg-text-body text-sm">
  <div class="flex flex-col flex-row@container(--2xl) gap-md">
    <div class="sheet p-lg grow(1) basis(0)">
      <h3 class="heading heading-sm">Stacked when narrow</h3>
      <p class="m(0) mt-xs leading-md">This is a stack until its container is 42rem wide.</p>
    </div>
    <div class="sheet p-lg grow(1) basis(0)">
      <h3 class="heading heading-sm">Side by side when wide</h3>
      <p class="m(0) mt-xs leading-md">Then the same markup is a row of equal columns.</p>
    </div>
    <div class="sheet p-lg grow(1) basis(0)">
      <h3 class="heading heading-sm">By its own width</h3>
      <p class="m(0) mt-xs leading-md">The query measures the section, not the screen.</p>
    </div>
  </div>
</section>`} />

| バリアント | 幅の基準 | 用途 |
| --- | --- | --- |
| `@xs` `@sm` `@md` `@lg` | ビューポート（48、52.125、64、80rem） | ページ全体のレイアウト |
| `@container(--md)` … `@container(--5xl)` | 最も近いコンテナー（28〜64rem） | ページ内の領域 |
| `@container(--max-3xl)` | 同じコンテナー（指定幅未満） | 幅が狭いときの配置 |

## クラスを使う場面 \{#when-a-class\}

ユーティリティだけでは表現できないものや、その都度組むと誤りやすいものもあります。たとえば、`dvh` で指定する高さ、スマートフォンのホームインジケーターを避ける余白、独立してスクロールする追従カラム、カラム数を自動で決めるグリッド、存在するカラム数を上限にセルをまたぐタイル、隙間を詰めて並べるレーン、図版がはみ出すカラム、直前のパネルの下に順に重なって追従するパネルです。こうした配置には、次のレイアウトクラスを使います。

| クラス | ユーティリティでは表現できないこと |
| --- | --- |
| [`auto-grid`](/components/auto-grid) | カラム数を自動で決めるトラックリスト |
| [`bento`](/components/bento) | 幅に応じたカラム数、カラム数に応じたスパン、行の最小高 |
| [`masonry`](/components/masonry) | グリッドレーンと、利用できない場合のマルチカラムによるフォールバック |
| [`breakout`](/components/breakout) | 所定の幅のカラムと、周囲の空き幅に応じたマージン |
| [`sticky-stack`](/components/sticky-stack) | 兄弟要素の中での各パネルの位置に応じたオフセット |
| [`form`](/components/form) | コンテナー幅のしきい値と、順序が反転するアクション |
| [`page`](/pages/page), [`shell`](/pages/app-shell) | ページ全体の枠組み（`dvh`、セーフエリア、追従カラム） |

それ以外の配置は、このページのユーティリティで組み立てられます。

## アクセシビリティ \{#accessibility\}

- キーボードでの移動順とスクリーンリーダーの読み上げ順は、ソースの順序に従います。`flex-row-reverse` と `order(…)` が変えるのは見た目の順序だけです。どちらの順序でも意味が通る場合に限って使います。
- レイアウト用ユーティリティは、要素の意味を付け加えません。`<nav>`、`<header>`、`<ul>` など、内容に合った要素を選び、その要素にユーティリティを指定します。
