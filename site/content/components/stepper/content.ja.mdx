ステッパーは、席数、数量、文字サイズなど、直接入力するより少しずつ増減することの多い数値に使います。ネイティブの`<input type="number">`を囲む[入力グループ](/components/input#input-group)で、入力欄の両端に[ボタン](/components/button)を配置します。グループには`stepper`、入力フィールドには`stepper-field`を追加します。

## 入力欄の標準機能 \{#what-the-field-already-does\}

数値入力フィールドを使うため、ステッパーの基本機能の多くは、スクリプトを実行する前からプラットフォームが提供します。

- <kbd>↑</kbd>と<kbd>↓</kbd>で値を`step`ずつ増減でき、`min`と`max`で止まります。
- 入力欄はスピンボタンとして、現在の値と上下限とともに読み上げられます。
- スマートフォンでは数字キーボードが表示されます。
- 入力した値が範囲外の場合は`:user-invalid`が適用され、ウェルにエラーを示す輪郭が付きます。

両端のボタンで増減を操作するため、スタイルシートでブラウザー標準のスピンボタンを非表示にします。

## ビヘイビア \{#behavior\}

`stepper` [ビヘイビア](/guide/behaviors)を使うと、2つのボタンでその間の数値を増減できます。`stepper` クラスを持つルート要素と、[書式付きの数値](#formatted)および[スクラブ](#scrub)のオプションを受け取り、ビヘイビアを解除する関数を返します。

```js name=app.js
import { stepper } from '@master/ui/behaviors/stepper.js'

const root = document.querySelector('.stepper')
stepper(root)

root.addEventListener('change', (event) => console.log(event.target.value))
```

- **増減。** ボタンは入力欄の `stepDown()` または `stepUp()` を呼び出します。矢印キーも同じメソッドを使うため、`min`、`max`、`step` は入力欄に一度指定するだけで済みます。
- **上限と下限。** 値がボタンの増減方向の限界に達すると、そのボタンは `disabled` になります。無効になったボタンはウェル内でフラットに表示されます。入力欄が空の場合は、どちらの限界にも達していないものとして扱います。ビヘイビアを解除すると、各ボタンの `disabled` は適用前の状態に戻ります。
- **長押し。** ボタンを押し続けると、短い待ち時間のあとに増減を繰り返します。押下を解除するか、ポインターがボタンの外に出るか、ポインター操作がキャンセルされるか、値が限界に達すると停止します。
- **増減方向。** 各ボタンの `value` で増減方向を指定します。負の値を指定すると減少します。指定がなければ、入力欄の前のボタンは減少、後ろのボタンは増加に割り当てられます。
- **イベント。** ボタンで数値が変わると、直接入力した場合と同じように、入力欄は `input`、続いて `change` を発火します。値は入力欄の `value` です。

ボタンには `tabindex="-1"` を指定します。タブ移動でフォーカスが止まるのは入力欄だけで、キー操作でもボタンと同じように増減できます。ビヘイビアを適用しなくても入力欄は[標準の機能](#what-the-field-already-does)を保ちますが、ボタンは動作しません。

## 幅 \{#width\}

ウェルの幅は数値の桁数に合わせて決まります。ブラウザーが `field-sizing: content` に対応している場合、入力欄は入力された桁数に応じて 3 桁分から 9 桁分まで広がります。それ以外では 3 桁分の幅になります。別の桁数に合わせるには `--stepper-min` と `--stepper-max` を設定します。ステッパー自体に幅を指定すると、ボタンは両端に寄り、数値はその間の中央に表示されます。

単位は入力欄の後ろに `input-group-addon` で表示します。`step` を大きくすると、一度に増減する量が増えます。

## 書式付きの数値 \{#formatted\}

価格、割合、大きな数は、`$1,250`、`12%`、`1,250,000` のように書式を整えたほうが読みやすくなります。入力欄と `stepper-display` を `stepper-value` に入れ、ビヘイビアに `format`（[`Intl.NumberFormat`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat) のオプション）を渡します。ページとは異なるロケールで数値を書式設定する場合は、`locale` も渡します。

```js name=app.js
stepper(root, { format: { style: 'currency', currency: 'USD', maximumFractionDigits: 0 }, locale: 'en-US' })
```

`attach()` はオプションを渡さないため、このプレビューでは `attach()` の実行後に `stepper` を明示的に呼び出します。同じルートに対して 2 回呼び出すと、2 回目が 1 回目を置き換えます。`MasterUI` はプレビューが読み込むバンドルです。プロジェクトでは、[ビヘイビア](#behavior)セクションの例に従って `stepper` をインポートします。

- **数値は入力欄が保持します。** 入力欄にフォーカスがない間は表示部が入力欄の位置に表示され、入力欄自体の数字は透明になります。入力欄にフォーカスすると表示部は退き、読者は `$1,250` ではなく `1250` を編集します。矢印キー、`min`、`max`、`step`、入力検証、フォームが送信する値は、これまでどおり数値入力欄のものです。
- **読み上げる言葉。** ボタン、キー操作、入力、外部からの値の設定など、値が変わるたびに、ビヘイビアは書式付きの数値を表示部と入力欄の `aria-valuetext` に書き込みます。そのため、スクリーンリーダーも「$1,250」と読み上げます。表示部には `aria-hidden="true"` を指定します。
- **書式を指定しない場合。** `stepper-display` があり `format` がないステッパーは、ロケールに従って桁区切りだけを行います。`Intl.NumberFormat` では書けない表記には、`format` に数値を受け取る関数を指定することもできます。
- **幅。** 数値部分の幅は、入力欄と表示部のうち広いほうに合わせ、`--stepper-min` から `--stepper-max` の範囲に収まります。そのため、入力欄にフォーカスしてもボタンの位置は変わりません。
- **スクリプトがない場合**、表示部は空のままで、入力欄が通常どおり数値を表示します。

## スクラブ \{#scrub\}

デザインツールでは、ラベルをドラッグして数値を変更することがよくあります。入力欄に対応する `<label>`、またはウェル内のハンドルに `stepper-scrub` クラスを付けます。ラベルはページ内のどこに置いてもかまいません。横にドラッグすると 4px ごとに 1 ステップずつ数値が変わり、行の終端方向で値が増えます。<kbd>Shift</kbd> を押している間は、10 ステップずつ変わります。

- **押すのではなくドラッグ。** ドラッグはポインターが 3px 動いた時点で始まるため、ラベルを押すだけなら入力欄にフォーカスが移ります。ドラッグを終えたときのクリックは無視されます。
- **ポインターロック。** マウスでは、ブラウザーが対応していればドラッグ中にポインターをロックするため、長くドラッグしても画面の端にぶつかりません。ポインターは元の位置に戻ります。ペンや指の場合は代わりにハンドルがポインターをキャプチャーし、タッチ画面での縦方向のスワイプでは引き続きページがスクロールします。
- **イベント。** 入力欄はステップごとに `input` を発行し、ドラッグが終わったときに `change` を一度発行します。
- **方向。** 右から左に書くページでは、行の先頭方向、つまり左へのドラッグで値が増えます。
- スクラブはポインター向けの便利な機能です。キー操作、ボタン、入力でスクラブと同じことがすべてできるため、専用のキー操作は不要で、ハンドルはタブ順序に含めません。

## 無効 \{#disabled\}

入力欄と両方のボタンを無効にします。ウェルの配置はそのままで、数値は無効状態の文字色になります。入力欄が無効または読み取り専用の場合、ビヘイビアは値を増減しません。このプレビューはマークアップのみで、スクリプトは適用していません。

## ほかのコンポーネントを使う場面 \{#when-to-use-something-else\}

- ポート番号や価格のように、一度入力したあとで調整することが少ない数値には、`type="number"` を指定した通常の[入力欄](/components/input)を使います。
- 広い範囲の中で、正確な数値よりも感覚的な調整を重視する場合は、[スライダー](/components/slider)を使います。
- ラベル付きの少数の数量から選ぶ場合は、[セグメントコントロール](/components/segmented)を使います。

## キーボード操作 \{#keyboard\}

数値入力欄の標準のキー操作を使います。ビヘイビアによるキー操作の追加はありません。Shift はスクラブでのみ意味を持ちます。

## アクセシビリティ \{#accessibility\}

- `<label>`、[フィールド](/components/input#field)、または `aria-label` で入力欄にラベルを付けます。各ボタンには、何を変更するかがわかる名前を付けます。たとえば「プラス」ではなく「座席数を増やす」とします。
- `min`、`max`、`step` は入力欄に指定します。キー操作、ボタン、支援技術はいずれもこの設定を参照します。
- ボタンはタブ順序から外します。キーボードでは入力欄の矢印キーで値を増減できます。ポインター操作では 30px の操作領域を、タッチ操作では同じ 30px のボタンの周囲に 44px の操作領域を確保します。
- 書式付きの数値は入力欄の `aria-valuetext` で伝え、それを表示する表示部は支援技術から隠します。ウェル内のスクラブ用ハンドルも、キー操作と同じことを繰り返すだけなので隠します。

## React、Svelte、Vue \{#frameworks\}

`stepper` コンポーネントはビヘイビアを適用し、数値の受け渡しを行います。[書式付きの数値](#formatted)には `format` と、必要に応じて `locale` を渡します。コンポーネントは `stepper-value` と表示部を描画し、最初の数値を書き込んだ状態にするため、サーバーが送る HTML にも数値が表示されます。`stepper-scrub` クラスを付けた入力欄のラベルは、フレームワークを使わない場合と同じようにスクラブで値を変更します。`npx master-ui add stepper` でプロジェクトにコピーできます。コンポーネントの仕組みと使い方は、[React、Svelte、Vue](/guide/frameworks)を参照してください。
