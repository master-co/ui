數字步進器適合座位數、數量、字級等較常逐步調整、較少直接輸入的數值。它以[輸入群組](/components/input#input-group)包住原生的 `<input type="number">`，並在輸入槽兩端各放一個[按鈕](/components/button)。請在群組加上 `stepper`，並在欄位加上 `stepper-field`。

## 欄位的原生功能 \{#what-the-field-already-does\}

欄位採用數字輸入，因此在腳本執行前，平台就已提供步進器的大部分功能：

- <kbd>↑</kbd> 和 <kbd>↓</kbd> 會依 `step` 增減數值，並在 `min` 和 `max` 停下。
- 輔助科技會將欄位讀為數值調整按鈕，並讀出目前數值與上下限。
- 手機會顯示數字鍵盤。
- 手動輸入的數值超出範圍時，欄位會符合 `:user-invalid`，輸入槽的外框也會切換為危險色。

樣式表會隱藏瀏覽器內建的增減按鈕，改由兩側的按鈕提供相同操作。

## 行為 \{#behavior\}

`stepper` [行為](/guide/behaviors)讓兩側的按鈕能逐步增減中間的數值。它接受帶有 `stepper` 類別的根元素，沒有可設定的選項，並回傳用來解除綁定的函式。

```js name=app.js
import { stepper } from '@master/ui/behaviors/stepper.js'

const root = document.querySelector('.stepper')
stepper(root)

root.addEventListener('change', (event) => console.log(event.target.value))
```

- **逐步調整。** 按鈕會呼叫欄位的 `stepDown()` 或 `stepUp()`，與方向鍵使用相同的方法，因此 `min`、`max` 和 `step` 只需在欄位上設定一次。
- **上下限。** 數值到達某個按鈕所對應的上限或下限時，該按鈕會進入 `disabled` 狀態，並在輸入槽中以平面樣式顯示。欄位留空時，視為尚未達到上限或下限。解除綁定時，會還原各按鈕原本的 `disabled` 狀態。
- **按住。** 按住按鈕後，經過短暫延遲便會連續調整數值，直到放開、指標移出按鈕、指標操作取消，或數值到達上限或下限。
- **方向。** 每個按鈕以 `value` 指定調整方向，負值代表減少。未設定時，欄位前方的按鈕會減少數值，後方的按鈕會增加數值。
- **事件。** 按鈕改變數值時，欄位會依序派送 `input` 和 `change`，與手動輸入時相同。請從欄位的 `value` 讀取數值。

按鈕設有 `tabindex="-1"`，因此用 Tab 鍵瀏覽時只會停在欄位上。在欄位中按方向鍵，就能完成按鈕的操作。若未掛載行為，欄位仍保有[平台原生功能](#what-the-field-already-does)，按鈕則不會改變數值。

## 尺寸 \{#sizes\}

## 寬度 \{#width\}

輸入槽的寬度會配合數值。若瀏覽器支援 `field-sizing: content`，欄位會隨輸入的位數調整寬度，最窄可容納三位數，最寬可容納九位數。其餘瀏覽器會維持三位數的寬度。若要容納其他位數，請設定 `--stepper-min` 和 `--stepper-max`，也可以直接指定步進器的寬度，讓欄位填滿扣除按鈕後的剩餘空間。

若要顯示單位，請在欄位後方加上 `input-group-addon`。將 `step` 設大，可增加每次調整的幅度。

## 停用 \{#disabled\}

請同時停用欄位與兩個按鈕。輸入槽會保留原本占用的空間，數值則會以停用色顯示。若欄位已停用或為唯讀，行為不會調整數值。這個預覽只有標記，未掛載腳本。

## 何時使用其他元件 \{#when-to-use-something-else\}

- 若數字通常只輸入一次，很少調整，例如連接埠號或價格，請使用設有 `type="number"` 的一般[輸入欄位](/components/input)。
- 若要在較大的範圍內選擇位置，且操作手感比精確數值更重要，請使用[滑桿](/components/slider)。
- 若要從少數有名稱的數量選項中擇一，請使用[分段控制項](/components/segmented)。

## 無障礙 \{#accessibility\}

- 請使用 `<label>`、[表單欄位](/components/input#field)或 `aria-label` 為欄位加上標籤。每個按鈕都需要有自己的名稱，清楚說明會調整什麼，例如「增加座位數」，避免只寫「加號」。
- 請將 `min`、`max` 和 `step` 設在欄位上。鍵盤操作、按鈕和輔助科技都會讀取這些設定。
- 按鈕不列入 Tab 鍵的焦點順序。鍵盤使用者可在欄位中按方向鍵調整數值。指標操作區為 30px，44px 高的輸入槽內則有 36px 的手指觸控區。
