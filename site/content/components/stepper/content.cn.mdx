## 输入框的原生功能 \{#what-the-field-already-does\}

步进器使用数字输入框，无需运行脚本即可获得大部分功能：

- <kbd>↑</kbd> 和 <kbd>↓</kbd> 按 `step` 设定的步长增减数值，并在达到 `min` 或 `max` 时停止。
- 辅助技术会将输入框读作微调按钮，并播报当前值和上下限。
- 手机会显示数字键盘。
- 手动输入的数值超出范围时，输入框会匹配 `:user-invalid`，凹槽会显示危险状态的轮廓。

凹槽两端的按钮接管增减操作，因此样式表会隐藏浏览器自带的微调按钮。

## 行为脚本 \{#behavior\}

`stepper` [行为脚本](/guide/behaviors)让两端的按钮按步长调整中间输入框的数值。它接收带有 `stepper` 类的根元素，无需选项，并返回一个用于解除绑定的函数。

```js name=app.js
import { stepper } from '@master/ui/behaviors/stepper.js'

const root = document.querySelector('.stepper')
stepper(root)

root.addEventListener('change', (event) => console.log(event.target.value))
```

- **步进。** 按钮调用输入框的 `stepDown()` 或 `stepUp()` 方法，与方向键使用的方法相同，因此只需在输入框上设置一次 `min`、`max` 和 `step`。
- **上下限。** 数值达到按钮所对应的上限或下限时，该按钮会处于 `disabled` 状态，并在凹槽内呈平坦状态。输入框为空时，视为尚未达到任何一端的限制。解除绑定时，按钮会恢复原有的 `disabled`。
- **按住。** 按住按钮片刻后，数值会连续增减，直到松开、指针移出、指针操作被取消，或数值达到上下限。
- **方向。** 每个按钮通过自己的 `value` 指定步进方向，负值表示减小。省略该属性时，输入框前的按钮减小数值，输入框后的按钮增大数值。
- **事件。** 按钮改变数值时，输入框会像手动输入时一样，先触发 `input`，再触发 `change`。数值取自输入框的 `value`。

按钮带有 `tabindex="-1"`，因此在步进器内，只有输入框会通过 Tab 键获得焦点，方向键已能完成按钮的操作。未绑定行为脚本时，输入框仍保留[浏览器提供的原生功能](#what-the-field-already-does)，两个按钮则没有作用。

## 尺寸 \{#sizes\}

步进器沿用输入组的尺寸。`input-group-sm` 为 32px，`input-group-lg` 为 44px，与同尺寸按钮等高。两端按钮的高度均比凹槽小 8px，圆角与凹槽同心。

## 宽度 \{#width\}

凹槽宽度随数值变化。浏览器支持 `field-sizing: content` 时，输入框会随输入的位数调整宽度，最窄容纳三位数字，最宽容纳九位数字。其他浏览器中，输入框保持三位数字的宽度。可设置 `--stepper-min` 和 `--stepper-max` 以适应其他位数，也可直接设置步进器的宽度，让输入框占用按钮之外的可用空间。

在输入框后放置一个 `input-group-addon` 来显示单位，并用更大的 `step` 增大每次调整的幅度。

## 何时选用其他组件 \{#when-to-use-something-else\}

- 如果数值通常只输入一次，很少调整，例如端口号或价格，请使用带有 `type="number"` 的普通[输入框](/components/input)。
- 如果要在较宽的范围内选取位置，主要凭感觉调整，对精确数值的要求较低，请使用[滑块](/components/slider)。
- 如果要从少量带名称的数值选项中选择，请使用[分段控件](/components/segmented)。

## 无障碍 \{#accessibility\}

- 使用 `<label>`、[字段](/components/input#field)或 `aria-label` 为输入框提供无障碍名称。每个按钮都需要有自己的名称，明确说明它会调整什么，例如用“增加座位数”代替“加号”。
- 将 `min`、`max` 和 `step` 保留在输入框上。键盘操作、按钮和辅助技术都从输入框读取这些属性。
- 按钮不进入 Tab 键的焦点顺序。键盘用户在输入框内用方向键增减数值。指针操作的目标尺寸为 30px，手指触控的目标尺寸为 36px，位于 44px 的凹槽内。
