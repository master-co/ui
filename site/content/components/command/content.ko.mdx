## 구성 요소 \{#parts\}

- `command-search`는 `<label>`이므로 행 어디를 눌러도 입력란에 포커스가 갑니다. 행에는 [`icon`](/components/icon)과 `command-input`이 들어가며, 필요하면 힌트도 넣을 수 있습니다.
- `command-input`에는 자체 표면 스타일이 없습니다. 대화상자가 표면을 제공하고, 가는 구분선이 이 부분과 검색 결과를 나눕니다.
- 목록 상자에 `command-list`를 적용하세요. 목록 상자가 남은 높이를 채우고 대화상자 안에서 스크롤됩니다.
- `command-footer`에는 `command-hint` 그룹이 들어갑니다. 키는 [`kbd`](/components/kbd)에 넣고, 그 뒤에 각 키의 기능을 설명합니다.

팔레트는 뷰포트 상단 가까이에서 열리고 아래로 늘어납니다. 따라서 아래 목록의 길이가 바뀌어도 검색 필드의 위치는 그대로입니다.

## 동작 \{#behavior\}

대화상자는 스크립트 없이 열고 닫을 수 있습니다. `command` [동작](/guide/behaviors)은 명령 팔레트에 필요한 추가 기능을 제공합니다. 대화상자를 인수로 받아 동작을 해제하는 함수를 반환합니다.

```js name=app.js
import { command } from '@master/ui/behaviors/command.js'

command(document.querySelector('.command'))

document.getElementById('cmd-new').addEventListener('click', () => {
  // Create the project.
})
```

- **단축키.** <kbd>⌘K</kbd> 또는 <kbd>Ctrl</kbd> <kbd>K</kbd>를 누르면 문서 어디서든 팔레트를 열 수 있으며, 같은 단축키를 다시 누르면 닫힙니다.
- **필터링.** `command-input`에 입력하면 일치하지 않는 옵션에 `hidden`을 설정하고, 첫 번째로 일치하는 옵션을 활성화합니다. [목록 상자](/components/listbox#filtering)는 결과가 없을 때 자체 빈 상태를 표시하며, 그룹의 명령이 모두 검색 조건에 맞지 않으면 해당 그룹을 자동으로 숨깁니다.
- **활성 옵션**에는 `aria-selected="true"`가 설정되며, 검색 필드의 `aria-activedescendant`가 이 옵션을 가리킵니다. 방향키로 활성 옵션을 바꿀 수 있습니다. 팔레트를 열 때부터 활성 옵션이 있으므로 <kbd>Enter</kbd>를 누르면 바로 명령을 실행할 수 있습니다.
- **명령 실행.** <kbd>Enter</kbd>를 누르면 활성 옵션에 클릭이 발생합니다. 포인터로 클릭할 때와 마찬가지로, 옵션이 링크라면 해당 위치로 이동하고 옵션에 `click` 리스너가 있으면 실행됩니다. <kbd>Enter</kbd>나 포인터로 옵션을 클릭하면 팔레트가 닫힙니다. 이 동작은 별도의 이벤트를 디스패치하지 않습니다. 명령 실행을 알리는 이벤트는 `click`입니다.

| 옵션 | 설정 항목 |
| --- | --- |
| `shortcut` | Command 또는 Control과 함께 눌러 팔레트를 열고 닫는 키입니다. 기본값은 `'k'`이며, 단축키를 사용하지 않으려면 `false`를 지정합니다. |

동작을 연결하지 않아도 버튼으로 대화상자를 열고, 검색 필드에 텍스트를 입력하고, <kbd>Esc</kbd>로 닫을 수 있습니다. 필터링과 방향키를 통한 목록 이동은 동작을 연결해야 사용할 수 있습니다.

## 접근성 \{#accessibility\}

- `aria-label`로 대화상자에 접근 가능한 이름을 지정하세요. 열자마자 입력할 수 있도록 입력란에 `autofocus`를 지정하세요.
- 입력란은 [콤보 상자](/components/combobox#accessibility)와 마찬가지로 목록 상자를 제어하는 콤보 상자입니다. 명령 팔레트의 목록은 항상 펼쳐져 있습니다.
- 팔레트는 명령을 빠르게 실행하는 수단입니다. 팔레트의 모든 명령은 다른 경로로도 실행할 수 있어야 합니다.

## React, Svelte 및 Vue \{#frameworks\}

`command` 컴포넌트는 명령 목록을 받아 팔레트를 렌더링하고 동작을 연결하며, 팔레트가 열리거나 닫힐 때 애플리케이션에 알립니다. `npx master-ui add command`로 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte 및 Vue](/guide/frameworks)에서 확인할 수 있습니다.
