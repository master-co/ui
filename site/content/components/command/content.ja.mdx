## 構成要素 \{#parts\}

- `command-search` は `<label>` なので、行のどこをクリックしても入力欄にフォーカスが移ります。[`icon`](/components/icon)、`command-input`、必要に応じてヒントを配置します。
- `command-input` はダイアログの背景をそのまま使い、細い罫線で検索結果と区切ります。
- `command-list` はリストボックスに指定します。ダイアログの残りの高さを使い、その内側でスクロールします。
- `command-footer` には `command-hint` のグループを配置します。各グループでは、キーを [`kbd`](/components/kbd) で示し、その後に操作内容を記載します。

パレットはビューポートの上部付近に開き、下方向に伸びます。リストの長さが変わっても、検索欄の位置は変わりません。

## ビヘイビア \{#behavior\}

ダイアログはスクリプトなしで開閉できます。`command` [ビヘイビア](/guide/behaviors)は、パレット固有の操作を追加します。ダイアログを受け取り、ビヘイビアを解除する関数を返します。

```js name=app.js
import { command } from '@master/ui/behaviors/command.js'

command(document.querySelector('.command'))

document.getElementById('cmd-new').addEventListener('click', () => {
  // Create the project.
})
```

- **ショートカット**　ドキュメント内のどこからでも、<kbd>⌘K</kbd> または <kbd>Ctrl</kbd> <kbd>K</kbd> でパレットを開閉できます。
- **絞り込み**　`command-input` に入力すると、一致しない選択肢に `hidden` を設定し、最初に一致した選択肢をアクティブにします。[リストボックス](/components/listbox#filtering)は、一致するコマンドがなければ自動で空状態用の表示に切り替え、一致するコマンドが一つもないグループを非表示にします。
- **アクティブな選択肢**　アクティブな選択肢には `aria-selected="true"` が付き、検索欄の `aria-activedescendant` がその選択肢を参照します。矢印キーで切り替えられます。パレットを開いた時点で選択肢が一つアクティブになるため、すぐに <kbd>Enter</kbd> で実行できます。
- **コマンドの実行**　<kbd>Enter</kbd> を押すと、アクティブな選択肢がクリックされます。ポインターでクリックしたときと同様に、リンクなら遷移し、選択肢に `click` リスナーがあれば実行されます。ポインターまたは <kbd>Enter</kbd> で選択肢をクリックすると、パレットが閉じます。ビヘイビアは独自のイベントを発行せず、`click` が実行時のイベントになります。

| オプション | 設定内容 |
| --- | --- |
| `shortcut` | Command または Control と組み合わせてパレットを開閉するキー。既定は `'k'`、無効にする場合は `false` |

ビヘイビアを適用しなくても、ボタンでダイアログを開き、検索欄に文字を入力し、<kbd>Esc</kbd> で閉じることができます。絞り込みと矢印キーによるリスト内の移動には、ビヘイビアが必要です。

## アクセシビリティ \{#accessibility\}

- `aria-label` でダイアログの名前を指定します。開いた直後に入力できるように、入力欄に `autofocus` を付けます。
- 入力欄は、[コンボボックス](/components/combobox#accessibility)と同じようにリストボックスを制御するコンボボックスです。パレット内では、リストは常に展開されています。
- パレットはショートカットなので、すべてのコマンドを別の操作経路からも実行できるようにしてください。

## React、Svelte、Vue \{#frameworks\}

`command` コンポーネントは、コマンドのリストからパレットを生成し、ビヘイビアを適用して、開閉をアプリケーションに通知します。`npx master-ui add command` でプロジェクトにコピーできます。コンポーネントの構成と使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
