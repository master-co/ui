드롭 영역은 파일을 선택하거나 끌어다 놓을 수 있는 넓은 영역입니다. `<label>` 안에 네이티브 파일 입력을 배치해, 보이지 않는 상태로 영역 전체를 덮도록 합니다. 영역을 클릭하면 파일 선택 창이 열리고, 어디에 파일을 놓아도 입력에 전달되며, 폼을 제출하면 파일도 함께 전송됩니다. 이 모든 동작에 스크립트가 필요하지 않습니다. 점선 윤곽선은 파일을 놓을 위치를 알려 줍니다.

## 비활성화 \{#disabled\}

입력을 비활성화하면 영역에 비활성화 상태의 잉크 색상이 적용되고 포인터 조작에 반응하지 않습니다.

<ComponentPreview name="disabled" height={168} narrowHeight={184} title="비활성화" bodyClass="p-lg" html={`<label class="dropzone">
  <input type="file" class="dropzone-input" disabled>
  <span class="dropzone-title">Uploads are paused</span>
  <span class="dropzone-description">The project has reached its storage limit.</span>
</label>`} />

## 지원 범위 \{#what-it-does-not-do\}

입력이 보이지 않으므로 브라우저는 선택한 파일을 영역 안에 표시하지 않습니다. CSS에는 파일을 요소 위로 드래그하는 중임을 나타내는 상태도 없습니다. 폼에 이런 동작이 필요하다면 짧은 스크립트로 선택한 파일을 나열하고 드래그하는 동안 영역을 강조하세요. 여러 필드 사이에서 파일 하나만 받는 경우에는 기본 [파일 입력](/components/input#file)이 파일 이름을 자체적으로 표시하므로 추가 구현이 필요하지 않습니다.

## 접근성 \{#accessibility\}

- 실제 컨트롤인 입력이 포커스를 받으면 드롭 영역은 `:has(.dropzone-input:focus-visible)` 선택자를 사용해 둘레에 포커스 윤곽선을 표시합니다.
- 제목과 설명이 입력의 레이블을 이룹니다. 허용되는 파일 형식과 크기 등 사용자가 지켜야 할 제한은 설명에 명시하세요.
