A dropzone is a wide target for choosing or dropping files. It is a `<label>` around a native file input that covers it invisibly. A click opens the picker, a file dropped anywhere on it lands in the input, and the form submits it, all without script. A dashed contour says "put it here".

## Invalid \{#invalid\}

A file input that is wrong gives the dashed edge the danger color: `aria-invalid="true"` from the script that checks the files, or `:user-invalid` on a required input left empty once the reader has tried to submit. Put the zone in a [field](/components/input#hint-and-error) and say what is wrong in a `field-error` after it, tied with `aria-describedby`: outside the label, it is read as the input's description, not as part of its name.

<ComponentPreview name="invalid" height={192} title="Invalid" background="plain" bodyClass="p-lg" html={`<div class="field">
  <label class="dropzone">
    <input type="file" class="dropzone-input" name="logo" accept="image/png,image/svg+xml" aria-invalid="true" aria-describedby="logo-error">
    <span class="dropzone-title">Drop a logo here or choose one</span>
    <span class="dropzone-description">PNG or SVG, up to 2 MB</span>
  </label>
  <span class="field-error" id="logo-error">logo.gif is not a PNG or an SVG.</span>
</div>`} />

## Disabled \{#disabled\}

A disabled input drops the zone to disabled ink and stops it answering the pointer.

<ComponentPreview name="disabled" height={168} narrowHeight={184} title="Disabled" bodyClass="p-lg" html={`<label class="dropzone">
  <input type="file" class="dropzone-input" disabled>
  <span class="dropzone-title">Uploads are paused</span>
  <span class="dropzone-description">The project has reached its storage limit.</span>
</label>`} />

## What it does not do \{#what-it-does-not-do\}

The browser shows the chosen files nowhere in the zone, because the input is invisible, and CSS has no state for a file being dragged over an element. List the chosen files and highlight the zone during a drag from a small script when the form needs them. Such a script draws the drag over the zone by setting `--dropzone-contour` and `--dropzone-background` on it, listed under [custom properties](#custom-properties). For one file in a row of fields, a plain [file input](/components/input#file) shows its own file name and needs nothing more.

## Accessibility \{#accessibility\}

- The input is the control: it takes focus, and the zone draws the ring around itself with `:has(.dropzone-input:focus-visible)`.
- The title and description are the input's label. Say the limits a reader must meet, such as types and sizes, in the description.
