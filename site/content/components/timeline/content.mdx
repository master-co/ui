A timeline sets events in the order they happened, on one line: an activity feed, a deployment's history, a changelog. It is an ordered list. Each event has a marker on a column and its words beside it, and a hairline joins the markers.

## Markers \{#markers\}

An empty `timeline-marker` is a small dot. The event marked `aria-current` takes ink and a faint halo: the newest, or the one a reader is at. A marker that holds an [`icon`](/components/icon) becomes a small well around it, which `:has()` decides, so a feed can mix both.

## Timeline or steps \{#timeline-or-steps\}

A timeline records what happened; its length is open and every event is done. [Steps](/components/steps) show a fixed sequence a reader is moving through, with one step current and the rest ahead.

## Accessibility \{#accessibility\}

- Use an `<ol>` when the order matters, which it nearly always does, and a `<time>` with `datetime` for each moment.
- The markers and the line are drawn by the stylesheet and are not announced. An icon in a marker is decoration: say what happened in the title.
- A feed that updates while it is on screen should be a live region with `aria-live="polite"`.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `timeline` | The list |
| `timeline-item` | An event |
| `timeline-marker` | A dot, or a well around an `icon` |
| `timeline-body`, `timeline-title`, `timeline-description` | The words |
| `timeline-time` | When it happened |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--timeline-marker` | `1.5rem` | Width of the marker column |
