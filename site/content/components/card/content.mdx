A card is a raised [sheet](/components/surface#sheet) with a small structure: media, a header, a body and a footer of actions. Use `.card` on an `<article>`, a `<section>` or a list item. The card is a size container, so its parts follow the room the card is given rather than the viewport: the same markup works in a sidebar, a grid and a full-width column.

## Parts \{#parts\}

Every part is optional, and the card spaces whichever are present by 1rem.

- `card-media` is an image or a video at the top. It sits 4px inside the card, with a corner 4px smaller than the card's so the two stay concentric, and takes a faint inward outline so a pale image keeps its edge.
- `card-header` holds a `card-title`, a `card-description` and, at its end, a `card-action`: a status, a menu button or a switch.
- `card-body` is free content.
- `card-footer` lines up actions at the end, the main one last.

## It follows its container \{#it-follows-its-container\}

The card declares `container: card / inline-size` and its parts query it. Queries measure the card's content box, inside its padding:

- Under 15rem, the `card-action` moves below the title and description, and the footer's buttons stack at full width with the main one first.
- `card-split` sets the media beside the content from 28rem, 4px inside the card on three sides, and stacks it on top below that.

Drag the handle to narrow the preview: the layout changes with the card, not with the window.

Because the card is a size container, its width must come from its context: a grid track, a flex item with a basis, or a block. In a shrink-to-fit context such as `inline-flex`, give it a width.

## Flat \{#flat\}

`card-flat` keeps one contour and no lift, for cards in a dense list or on a [tray](/components/surface#tray).

## Interactive \{#interactive\}

When the whole card is one link or one button, put `card` and `card-interactive` on the `<a>` or `<button>` itself. It lifts under the pointer and settles when pressed, as a button does. Do not nest other controls inside it.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `card` | The raised sheet and size container |
| `card-media` | An image or video, 4px inside the card |
| `card-header`, `card-title`, `card-description` | The heading group |
| `card-action` | A control or status at the end of the header |
| `card-body`, `card-footer` | Free content, and actions at the foot |
| `card-split` | Media beside the content from 28rem |
| `card-flat` | One contour, no shadow |
| `card-interactive` | A card that is one link or button |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--card-padding` | `1.25rem` | Padding around the parts |
| `--card-radius` | `var(--radius-surface)` | Corner radius |
| `--card-media-inset` | `4px` | Space between the media and the card's edge |
| `--card-split` | `.4` | Share of the width the media takes in a split card |
