A file is one document shown as a thing: a small page with its extension, the name over a quiet line of facts, and one control at the end. It is a flat sheet, so a column of files under a [dropzone](/components/dropzone) or inside a [dialog](/components/dialog) reads as a stack of separate objects.

## The page \{#the-page\}

`file-page` is a small raised sheet, 28 by 36, with the extension written at its foot in whatever case you type; it is set in capitals. Keep it to four characters. The name beside it already says the same thing, so hide the page from assistive technology with `aria-hidden`.

Its folded corner is drawn by the browser: with `corner-shape`, the top corner at the end is a bevel, and the flap is what that bevel leaves of a small square. A browser without `corner-shape` shows the page with four round corners and no fold.

When the file is a picture, `file-thumb` on an `<img>` takes the page's place.

## Uploading \{#uploading\}

Put a native `<progress>` with `progress file-progress` inside the file. The bar is then the sheet itself: it lies under the words from edge to edge and tints the sheet as far as the upload has come, and the sheet's corner finishes the fill. Without a `value` the amount is unknown and a band of the same tone travels across.

Write the amount in `file-meta` as well, and mark the file `aria-busy="true"` while it is on its way.

## Failed \{#failed\}

`file-failed` gives the file the danger contour and turns `file-meta` to the danger ink. Say what went wrong there, and put the way out at the end. The state is a class because ARIA has no attribute for a failed item in a list: the words carry it, and `role="alert"` on them announces a failure that happens while the reader is on the page.

## Compact \{#compact\}

`file-sm` is one line, 36px tall and as wide as its name: an attachment above a [composer](/components/composer), or a file mentioned in a row. Its page is too small to carry the extension, so the name and the facts beside it do. The control at its end is 24px.

## A file that opens \{#a-file-that-opens\}

When the whole file is a link or a button, add `file-interactive`: it stands raised, lifts under the pointer and sinks when pressed, as a [button](/components/button) does. Use `<span>` for the parts inside a link.

## Accessibility \{#accessibility\}

- Several files are a list: use `<ul>` and put `file` on each `<li>`.
- A control's name says which file it acts on: "Remove report.pdf", not "Remove".
- Label the `<progress>`, and keep the percentage in the text too: the tint is a drawing of it.
- A long name is cut at the end. Put the full name in `title` when the ending matters, as with an extension.
