A data list sets out the facts about one thing as terms and their values: a deployment's region, commit and duration; an order's address and total. Use it on a `<dl>`, with a `<div>` around each term and value. Rows sit on hairlines, and every value starts on the same edge.

## One edge for every value \{#one-edge\}

The list is a two-column grid, and each row is a subgrid of it. The term column is as wide as the longest term, so the values line up on one edge however the terms differ in length, with no width to set by hand.

## It follows its container \{#it-follows-its-container\}

The list is a size container. Under 20rem each term moves above its value, so a long value has the full width. Drag the handle to narrow the preview.

## Data list or table \{#data-list-or-table\}

A data list describes one thing with many properties. A [table](/components/table) compares many things by the same properties. When the terms would repeat for every row, it is a table.

## Accessibility \{#accessibility\}

- A `<dl>` with `<dt>` and `<dd>` announces each term with its value. The `<div>` around a pair is allowed in a `<dl>` and is what the rows are styled on.
- Long values wrap anywhere, so an identifier or a URL does not push the list wider than its column.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `data-list` | The list, on a `<dl>` |
| `data-list-item` | A row, on a `<div>` around one term and its value |
| `data-list-term` | The term, on a `<dt>` |
| `data-list-value` | The value, on a `<dd>` |
