Dock 是一排放在霧面玻璃托盤上的啟動項目。每個方塊都放有圖片或圖示，本身是連結或按鈕。指標移過時，整排呈現透鏡般的放大效果。指標下方的方塊放大一半，左右相鄰的方塊各放大略多於四分之一，再外側的方塊各放大十分之一，讓整排平滑地朝指標所在處隆起。標籤會浮現在方塊上方，方塊下方的圓點則標示目前的項目。整個效果都由 CSS 實作，透過 `:hover`、相鄰兄弟組合器和 `:has()` 找出鄰近的方塊，無須用腳本量測指標位置。

## 透鏡效果 \{#lens\}

方塊平時是 40px。指標停在方塊上時，該方塊變成 60px，左右相鄰的方塊是 51px，再外側的方塊是 44px。`--dock-magnify` 設定最大的尺寸，其餘尺寸依此推算。放大效果透過改變方塊的實際尺寸達成，未使用 CSS 變形。整排方塊因此會在指標周圍拉開，避免彼此重疊，托盤也會隨之加寬。方塊從托盤底部向上放大，越過托盤上緣，並依主題的緩動設定平滑過渡。每個方塊的感應範圍都向外延伸至相鄰間距的一半，讓指標跨過方塊之間的空隙時，放大效果仍能持續。

透鏡效果適用於支援懸停的指標。在觸控螢幕上，Dock 會顯示一排 44px 的方塊。啟用減少動態效果時，方塊會維持原本的尺寸，標籤仍會顯示。空間不足時，所有方塊會一起縮小，並維持正方形。

## 方塊 \{#tiles\}

每個方塊都呈現微微抬高的效果，可放置尺寸為方塊邊長一半的圖示，或以 `dock-image` 填滿方塊。圖片的 `alt` 留空，啟動項目的名稱由標籤提供。方塊的圓角半徑是邊長的四分之一，40px 的控制項便是 10px。托盤的圓角半徑等於方塊的圓角半徑加上 8px 的內距，讓兩道弧線之間的間距一致。

若啟動項目是連結，請在目前頁面的連結加上 `aria-current="page"`。若是用來切換面板等內容的按鈕，則使用 `aria-pressed`。兩者都會在方塊下方顯示圓點。若 Dock 由按鈕組成，請加上 `role="toolbar"` 並提供名稱。

`dock-divider` 用一小段細線隔開不同群組。透鏡效果會直接跨過分隔線。

## 放置位置 \{#placing\}

Dock 本身不負責定位，位置由頁面決定。通常會放在畫面底部中央，可放入專屬區域，或用 `fixed` 或 `sticky` utility 固定在該處。請在 Dock 上方預留約 48px，供方塊放大及顯示標籤。

## 無障礙 \{#accessibility\}

- 若啟動項目用於導覽，請以帶有 `aria-label` 的 `nav` 包住它們。若 Dock 由按鈕組成，請加上 `role="toolbar"` 並提供標籤。
- 每個啟動項目的標籤就是它的無障礙名稱。標籤在指標移入或鍵盤焦點移到方塊時才會顯示，但始終留在頁面中，供螢幕閱讀器讀取。
- 每個啟動項目都能透過 Tab 取得焦點，聚焦時會顯示標籤與焦點外框。
- 請將啟動項目的名稱寫在標籤裡。標籤是該項目唯一的文字。
