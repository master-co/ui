範囲スライダーは、最低価格と最高価格、クリップの開始位置と終了位置など、同じ尺度上の二つの値を選ぶためのコントロールです。二つのネイティブ[スライダー](/components/slider)を一つのグループにまとめます。グループは一本のトラックを描画し、つまみの間を色で塗ります。各入力要素は、個別のキー操作、ラベル、フォームの値を保持します。

## スクリプトを使わない塗りの描画 \{#no-script-for-the-fill\}

単一のスライダーが塗りの範囲を求める場合と同じように、それぞれのつまみは自身の入力要素内でビュータイムラインの基準になります。グループは`timeline-scope`で二つのタイムラインを参照し、それぞれでアニメーションを実行して二つの割合を求めます。小さい方から大きい方までを塗るため、つまみが交差しても塗りはつまみの間に収まり、小さい方の値が引き続き範囲の下限になります。

フォームの処理でも同じように、小さい方の値を下限として扱います。二つの値を交差させたくない場合や、間隔を確保する必要がある場合は、[ビヘイビア](#keeping-a-distance)を適用します。描画はこれに依存しません。

スクロール駆動アニメーションに対応していないブラウザーでは、二つのつまみの下に塗りのないトラックが表示され、各入力要素は通常どおり操作できます。ChromiumとSafari 26では、つまみの間の塗りが描画されます。

## つまみがトラックを共有する仕組み \{#how-the-thumbs-share-a-track\}

二つの入力要素を同じグリッドセルに重ねます。それぞれ固有のトラックは表示せず、つまみだけがポインター操作を受け付けます。そのため、つまみの間を押しても入力要素には届かず、片方のつまみがもう片方の透明なトラックに覆われることもありません。操作中のつまみは前面に表示されます。つまみのない部分のトラックを押しても、どちらを動かすか特定できないため反応しません。

## 間隔の確保 \{#keeping-a-distance\}

`range`[ビヘイビア](/guide/behaviors)は、つまみ同士が離れた状態を保ちます。`range-start`が`range-end`を越えることはなく、`distance`を指定すると、二つのつまみはその間隔で止まります。止まるのは動かしているつまみで、静止しているつまみが押されて動くことはありません。ビヘイビアは、つまみを動かした`input`イベントの中で、その入力要素や範囲スライダーの周囲の要素がイベントを受け取る前に値を補正します。そのため、どのリスナーも間隔が保たれた値の組を読み取り、つまみが拒否された値を表示することもありません。キー操作、ドラッグ、フォームの値は、入力要素本来の動作のままです。

  MasterUI.range(range, { distance: 2 })
  range.addEventListener('input', function () {

    document.getElementById('hours-output').textContent = start + ':00 to ' + end + ':00'
  })
})
</script>`} caption="どちらかのつまみをもう一方に向かってドラッグすると、2時間の間隔で止まります。" />

`attach()`は範囲スライダーをプラットフォームの動作のままにするため、つまみは交差できます。つまみを離しておくには、このプレビューのように範囲スライダーに対して`range`を呼び出し、間隔を保つ場合は`distance`を指定します。同じルートに対して2回呼び出すと、2回目が1回目を置き換えます。`MasterUI`はプレビューが読み込むバンドルです。プロジェクトでは`range`をインポートします。

```js name=app.js
import { range } from '@master/ui/behaviors/range.js'

const detach = range(document.querySelector('.range'), { distance: 2 })
```

間隔は入力要素自身の単位で指定します。`step`の倍数を指定してください。入力要素は書き込まれた値をステップに丸めるため、ビヘイビアは間隔を保てる最も近いステップを選びます。

## 無効状態 \{#disabled\}

両方の入力要素を無効にします。つまみと塗りがともに薄く表示されます。

## アクセシビリティ \{#accessibility\}

- グループに`role="group"`と名前を指定し、各入力要素にも個別の`aria-label`を設定します。「開始」「終了」ではなく、「最低価格」「最高価格」のように、何の値かが伝わる名前を使います。
- つまみ自体には数値が表示されないため、二つの値をトラックの近くに表示してください。
- 各つまみにはTabキーで個別にフォーカスでき、ネイティブスライダーと同じキーで操作できます。タッチ画面でのつまみのサイズは24pxです。つまみはそれ自体が唯一の操作領域で、端の外まで操作領域を広げられないため、ライブラリの中で唯一大きくなる部分です。
- スライダーで値の位置を直感的に把握することよりも、正確な数値が重要な場合は、[ステッパー](/components/stepper)または数値入力欄を二つ用意してください。
