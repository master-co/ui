트리는 폴더, 문서 개요, 카테고리처럼 하위 항목을 포함하는 구조를 여러 단계의 행으로 표시합니다. 스크립트가 없으면 가지는 브라우저의 기본 `<details>` 요소로 구성되고, 그 안의 `<summary>`가 행이 됩니다. 따라서 브라우저가 기본으로 지원하는 키로 가지를 접고 펼칠 수 있으며, 페이지 내 검색에서 일치하는 항목이 접힌 가지 안에 있으면 해당 가지가 펼쳐집니다.

## 행 \{#rows\}

- `tree-item`은 행을 나타냅니다. 링크, 버튼 또는 가지의 `<summary>`가 행이 될 수 있습니다. 행의 높이는 28px이며, 촘촘하고 차분하게 배치됩니다. 포인터가 올라간 행과 현재 행에는 칩과 같은 색조가 적용됩니다.
- 가지의 행에 `tree-toggle` 클래스를 적용하면 맨 앞 열에 꺾쇠가 표시됩니다. 가지가 펼쳐져 있는 동안 꺾쇠는 아래를 향합니다. 모든 행에 이 열의 공간이 확보되므로 하위 항목이 없는 행도 같은 단계의 가지 행과 정렬됩니다.
- `tree-sub`는 가지 아래의 행을 한 단계 들여쓰고, 꺾쇠에서 아래로 이어지는 가는 선을 따라 배치합니다.

## 동작 \{#behavior\}

WAI-ARIA 트리 패턴에서 트리 전체는 하나의 Tab 정지점이 되며, 방향키로 행 사이를 이동하고 가지를 접을 수 있습니다. 이를 구현하려면 `tree` [동작](/guide/behaviors) 스크립트가 필요하며, 클래스는 그대로 사용합니다. 목록에는 `role="tree"`를, 각 가지의 행에는 `role="treeitem"`과 `aria-expanded`를, 해당 가지의 `tree-sub`에는 `role="group"`을 지정하세요. 그러면 꺾쇠는 `aria-expanded`의 상태에 따라 방향이 바뀌고, `aria-expanded="false"`가 지정된 행은 바로 뒤의 `tree-sub`를 숨기며, `aria-selected="true"`는 선택된 행을 나타냅니다.

`tree`는 `tree` 클래스가 지정된 루트 요소를 인수로 받습니다. 옵션은 없으며, 동작 연결을 해제하는 함수를 반환합니다.

```js name=app.js
import { tree } from '@master/ui/behaviors/tree.js'

const root = document.querySelector('.tree')
tree(root)

root.addEventListener('change', (event) => console.log(event.detail.item))
```

- **하나의 Tab 정지점.** 이 동작은 `tabindex`를 사용해 Tab 이동 순서에 행 하나만 유지합니다. 마크업에 `tabindex="0"`이 지정된 행, 선택된 행 또는 현재 행, 첫 번째 행 순으로 정지점을 정합니다. 포커스를 받은 행이 새 Tab 정지점이 됩니다. 동작 연결을 해제하면 각 행의 `tabindex`가 원래 상태로 복원됩니다.
- **행 사이 이동.** 키로 이동할 때는 접힌 가지 안의 행, `hidden` 속성이 지정된 행, 비활성화된 행을 건너뜁니다.
- **활성화.** summary 요소, 링크, 버튼은 브라우저의 기본 활성화 동작을 유지합니다. 기본 활성화 동작이 없는 행, 즉 `div`에 `role="treeitem"`을 지정한 행은 <kbd>Enter</kbd>, <kbd>Space</kbd> 또는 클릭으로 활성화됩니다. 가지는 펼쳐지거나 접히고, 하위 항목이 없는 행은 선택됩니다. 이전 행에 있던 `aria-selected="true"`는 새로 선택된 행으로 옮겨갑니다.
- **이벤트.** 행을 선택하면 루트에서 버블링되는 `change` 이벤트가 발생하며, `detail.item`에 선택된 행이 담깁니다.
- **비활성화.** `disabled` 또는 `aria-disabled="true"`가 지정된 행은 반응하지 않습니다. 링크로 이동하지 않으며 가지의 펼침 상태도 그대로 유지됩니다.

이 동작은 `<details>` 기반 트리에도 적용할 수 있습니다. 처음 두 미리보기는 이 동작을 연결하지 않고 실행됩니다. `open`으로 `tree-group`을 펼치거나 접으며, 트리 전체가 하나의 Tab 정지점이 되어 같은 키로 행 사이를 이동할 수 있습니다. `attach()`는 모든 트리에 이 동작을 연결합니다. `<details>` 기반 트리에서 플랫폼 기본 동작을 유지하려면 필요한 동작만 이름으로 가져오세요.

[내비게이션 목록](/components/nav)은 이동할 위치를 한 단계로 묶어 보여 주는 짧은 목록이며, 현재 행은 한 층 올라온 표면으로 표시됩니다. 트리는 여러 단계의 계층을 표시하며, 행을 촘촘하게 배치하고 각 가지 앞에 꺾쇠를 표시합니다.

## 접근성 \{#accessibility\}

- `<details>`를 사용할 때는 트리 역할을 추가하지 마세요. 보조 기술은 브라우저 기본 펼침 요소를 그대로 올바르게 안내하며, 동작 스크립트가 없으면 모든 행이 Tab 정지점이 됩니다.
- 현재 행은 `aria-current="page"`로 표시하세요. 트리 패턴에서는 `aria-selected="true"`로 표시하세요.
- 터치 화면에서는 행의 높이가 44px입니다.
