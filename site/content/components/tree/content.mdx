## Rows \{#rows\}

- `tree-item` is a row: a link, a button, or the `<summary>` of a branch. Rows are 28px, dense and quiet; the one under the pointer and the current one take a chip tone.
- `tree-toggle` on a branch's row draws a chevron in the leading column, which turns down while the branch is open. Every row keeps that column, so a leaf lines up with the branches beside it.
- `tree-sub` holds the rows under a branch, one level in, on a hairline that runs down from the chevron.

## With the tree pattern \{#with-the-tree-pattern\}

The WAI-ARIA tree pattern gives one tab stop and arrow keys that walk and fold the tree. That needs a script, and the same classes serve it: put `role="tree"` on the list, `role="treeitem"` and `aria-expanded` on each branch's row, and `role="group"` on its `tree-sub`. The chevron then follows `aria-expanded`, a row that says `aria-expanded="false"` hides the `tree-sub` that follows it, and `aria-selected="true"` marks the selected row.

## Tree or nav \{#tree-or-nav\}

A [nav](/components/nav) is a short list of destinations with one level of grouping, and its current row rises as a sheet. A tree is for depth: many levels, dense rows, and a chevron that leads each branch.

## Accessibility \{#accessibility\}

- With `<details>`, do not add tree roles: the native disclosure is announced correctly as it is, and every row is a tab stop.
- Mark the current row with `aria-current="page"`, or `aria-selected="true"` inside the tree pattern.
- On touch screens a row is 40px.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `tree` | The list |
| `tree-item` | A row |
| `tree-toggle` | On a branch's row: adds the chevron |
| `tree-group` | A `<details>` that holds a branch |
| `tree-sub` | The rows under a branch |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--tree-item-height` | `1.75rem` | Row height |
| `--tree-indent` | `1rem` | How far each level is set in |
