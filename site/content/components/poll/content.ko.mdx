투표는 질문과 몇 가지 응답 항목, 그리고 득표 결과로 구성됩니다. 각 응답 항목은 기본 라디오 버튼을 `<label>`로 감싸므로 그룹에서 방향키를 사용할 수 있고 폼에서도 선택값이 유지됩니다. 투표 전에는 모든 응답 항목이 하나의 윤곽선 안에 평평하게 배치됩니다. 하나를 선택하면 각 응답 항목의 시작 지점부터 득표율만큼 색이 차오르고 끝에 수치가 나타납니다. 이 동작은 스크립트 없이 입력 요소의 선택 상태만으로 이루어집니다.

## 결과 표시 방식 \{#how-the-result-shows\}

각 `poll-option`에는 0부터 100까지의 득표율을 `--value`로 지정하고, 같은 수치를 `poll-value`에 텍스트로 표시합니다. 선택된 입력 요소가 없으면 득표율을 나타내는 영역의 너비는 0이고, 수치도 숨겨져 보조 기술에 노출되지 않습니다. 응답을 선택하면 `:has()`가 그룹에서 선택 상태를 감지합니다. 각 영역은 득표율에 해당하는 너비까지 늘어나고 수치는 서서히 나타납니다.

선택한 응답 항목에는 짙은 윤곽선과 더 진한 배경색이 적용되고, 텍스트 뒤에 체크 표시가 나타납니다. 다른 응답을 선택하면 세 가지 표시가 새로 선택한 항목으로 옮겨가며 득표율은 그대로 유지됩니다.

수치는 페이지에서 제공합니다. 방금 제출한 표를 결과에 반영하려면 표를 기록할 때 `--value`와 텍스트를 갱신하세요. 득표율을 나타내는 영역의 너비가 새 값으로 부드럽게 바뀝니다.

## 종료된 투표 \{#closed\}

투표가 끝나면 입력 요소를 비활성화하세요. 결과는 처음부터 표시되고 응답을 선택할 수 없습니다. 결과를 읽을 수 있도록 응답 항목의 가독성은 그대로 유지됩니다. 사용자가 선택했던 응답에는 `checked`를 유지하세요.

## 복수 응답 \{#several-answers\}

사용자가 여러 응답을 선택할 수 있다면 체크박스를 사용하세요. 하나라도 선택하면 결과가 표시되고, 선택한 모든 응답에 윤곽선과 체크 표시가 적용됩니다. 이때 득표율의 합계는 더 이상 항상 100이 되지는 않습니다.

## 투표와 선택 항목 \{#poll-or-choice\}

투표는 여러 사람의 응답을 모으는 질문이며 응답을 선택하면 결과가 표시됩니다. [선택 항목](/components/choice)은 폼에서 문장 하나로 설명하는 옵션이며 선택 후 추가로 표시되는 내용이 없습니다. 투표를 거치지 않은 결과를 표시하려면 `chart-horizontal`을 적용한 [차트](/components/chart)를 사용하세요.

## 접근성 \{#accessibility\}

- `<fieldset>`을 사용하고 그 안의 `<legend>`에 질문을 넣어 각 응답을 읽을 때 질문도 함께 안내되도록 하세요. 그 안의 라디오 버튼에는 같은 `name` 값을 지정하세요.
- 각 응답 항목의 입력 요소를 `<label>`로 감싸면 항목 전체가 조작 영역이 됩니다. 이 영역의 높이는 38px이고 터치스크린에서는 44px입니다. 포커스 윤곽선은 응답 항목 둘레에 표시됩니다.
- 득표율 수치는 텍스트로 제공됩니다. 결과가 표시되기 전에는 `visibility`로 숨겨 스크린 리더가 미리 읽지 않게 합니다. 수치는 문서에 포함되어 있어 배경색을 볼 수 없는 사용자도 확인할 수 있습니다.
- 윤곽선을 볼 수 없는 사용자는 체크 표시로 선택한 응답을 구분할 수 있습니다. 강제 색상 모드에서는 선택한 응답에 시스템 강조 색상이 적용됩니다.
