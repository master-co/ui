## 캐러셀 컨트롤 \{#the-controls\}

버튼과 점에 해당하는 요소는 마크업에 없으며, 다음과 같은 의사 요소로 생성됩니다.

- `::scroll-button(inline-start)`과 `::scroll-button(inline-end)`은 트랙을 한 페이지씩 스크롤합니다. 다른 버튼처럼 볼록한 표면으로 표시되며, 호버하면 떠오르고 누르면 내려갑니다. 브라우저는 트랙의 양 끝에서 해당 방향의 버튼을 비활성화합니다. 스타일시트는 비활성화된 버튼을 서서히 흐리게 한 뒤 숨겨, 버튼 아래에 있는 슬라이드를 가리지 않게 합니다.
- 각 슬라이드의 `::scroll-marker`는 점으로 표시되며, `::scroll-marker-group`은 이 점들을 트랙 아래에 모읍니다. 현재 표시 중인 슬라이드의 점은 `:target-current`와 일치하며, 길어지고 전경색으로 표시됩니다. 각 점에 안쪽 여백을 넣어 조작 영역을 넓힙니다. 터치 화면에서는 이 영역이 더 넓어져 손가락으로 6픽셀 크기의 점을 정확히 누를 필요가 없습니다.

컨트롤은 앵커 위치 지정을 통해 자신이 속한 캐러셀을 기준으로 배치됩니다. 앵커 이름의 범위가 캐러셀별로 제한되므로 한 페이지에 캐러셀이 여러 개 있어도 컨트롤을 공유하지 않습니다. 이 의사 요소를 지원하지 않는 브라우저에서는 컨트롤만 빠지며, 슬라이드는 그대로 스와이프하고 스크롤할 수 있습니다. 이때는 얇은 스크롤 막대가 표시되어, 스와이프할 수 없는 마우스로도 옆으로 이동할 수 있습니다. 버튼과 점이 그려지는 브라우저와 `carousel-view` 안에서는 스크롤 막대가 표시되지 않습니다.

## 표시 중인 슬라이드 읽기와 설정 \{#view\}

어떤 슬라이드가 표시되어 있는지 알아야 하거나 특정 슬라이드를 보여 주어야 하는 페이지에서는 트랙을 `carousel-view`에 넣고 이전·다음 버튼과 점 행을 직접 작성합니다. 뷰 안에서는 생성된 컨트롤이 물러나므로 버튼은 한 세트만 남습니다. 이 컨트롤은 [`carousel` 동작](/guide/behaviors)이 제어합니다.

- `IntersectionObserver`로 각 슬라이드가 얼마나 보이는지 추적합니다. 스크롤이 `scrollend`로 끝나면 가장 많이 보이는 슬라이드가 현재 항목이 됩니다. 이 이벤트를 지원하지 않는 브라우저에서는 스크롤이 잠시 멈춘 뒤에 판단합니다. 표시 비율이 같으면 그중 현재 슬라이드를 유지하고, 현재 슬라이드가 없으면 문서 순서상 첫 항목을 선택합니다. 여러 슬라이드가 뷰 안에 동시에 들어갈 때 브라우저의 스냅 대상은 다른 슬라이드일 수 있습니다.
- 이전, 다음 버튼과 점은 플랫폼에 해당 슬라이드를 자체 스냅 정렬 위치로 스크롤해 달라고 요청하며, 동작 줄이기 설정에서는 즉시 이동합니다. 동작이 위치를 직접 설정하지는 않습니다.
- 현재 슬라이드의 점에는 `aria-current="true"`가 지정되고, 처음에는 이전 버튼이, 끝에서는 다음 버튼이 비활성화됩니다. 여러 슬라이드가 함께 보일 수 있지만 현재 슬라이드는 하나이며, 다른 슬라이드는 숨겨지지 않습니다.
- 각 슬라이드는 `data-value` 또는 `id`로 식별하므로, 앞에 슬라이드가 추가되어도 현재 슬라이드는 그대로 유지됩니다. 독자가 변경하면 `input`과 `change` 이벤트가 발행됩니다. 이 동작이 반환하는 함수의 `value`는 읽고 설정할 수 있으며, 값을 설정할 때는 이벤트가 발행되지 않습니다.

## 접근성 \{#accessibility\}

- 방향키로 트랙을 스크롤할 수 있도록 트랙에 `role="region"`과 레이블, `tabindex="0"`을 지정하세요.
- 스타일시트는 생성된 버튼에 각각 "Previous slide"와 "Next slide"라는 이름을 지정합니다. 페이지 언어로 이름을 지정하려면 `--carousel-previous-label`과 `--carousel-next-label`에 따옴표로 묶은 문자열을 설정하세요. 캐러셀 자체나 루트 같은 상위 요소에 설정합니다. 각 점의 이름은 해당 슬라이드 콘텐츠의 이름을 따릅니다.
- 캐러셀은 자동으로 이동하지 않습니다. 타이머에 따라 콘텐츠가 넘어가도록 구현하려면 스크립트로 일시정지 컨트롤을 제공해야 합니다.
- 동작 줄이기 설정이 켜져 있으면 트랙은 부드럽게 스크롤하는 대신 슬라이드 사이를 즉시 이동합니다.
- 강제 색상 모드에서는 버튼에 버튼 색상의 윤곽선이 표시되고, 점에는 시스템 색상이 유지됩니다. 현재 표시 중인 슬라이드의 점에는 시스템 강조 색상이 적용됩니다.
- `carousel-view`에서는 버튼과 점의 이름을 페이지 언어로 지정하세요. 점의 이름은 전체 슬라이드 중 몇 번째 슬라이드로 이동하는지 알려 주어야 합니다.

## React, Svelte 및 Vue \{#frameworks\}

`carousel` 컴포넌트는 항목 목록으로 슬라이드를 작성하고 그 옆에 뷰의 버튼과 점을 작성합니다. 각 항목의 `value`는 항목 목록이 바뀌어도 그대로 유지되어야 합니다. 컴포넌트의 값은 현재 슬라이드입니다. `npx master-ui add carousel`로 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte 및 Vue](/guide/frameworks)에서 확인할 수 있습니다. 현재 슬라이드를 읽을 필요가 없는 캐러셀이라면 컴포넌트가 필요 없으며 위의 마크업으로 충분합니다.
