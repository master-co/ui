波形沿用所在位置的文字墨色。收到的[消息](/components/message)在凸起面板上使用强墨色，发出的消息则在墨色背景上使用反相墨色，同一组竖条无需变体即可清晰显示。播放按钮采用与气泡相反的材质：凸起面板上用墨色按钮，墨色背景上用凸起面板按钮。

## 竖条 \{#bars\}

每个录音片段写一个 `waveform-bar`，用 `--level` 表示音量，取值为 0 到 1。竖条的高度为整行高度乘以该比例，沿水平中线居中，且至少与自身宽度相等，因此静音段显示为一排圆点。`round()` 将高度舍入到 2px 的整数倍，使两端的圆弧对齐像素网格。浏览器不支持 `round()` 时会使用精确高度，端部的圆弧可能显示不完整。

竖条宽 3px，间距为 2px。与其他元素同排时，例如在带有按钮和时间的气泡里，波形的宽度由竖条所需的空间决定：30 根竖条需要 148px。空间更宽时，波形会填满可用宽度，竖条之间的间距均匀拉开；空间不足时，所有竖条会一起变细。波形在尺寸计算中要求的宽度至少等于竖条所需的宽度。因此，如果外层容器按内容确定尺寸，就像为消息气泡设定尺寸那样，为容器设置宽度或最大宽度。无论录音多长，绘制的竖条数量都大致等于可容纳的数量。录制或上传时，将音频分成相应数量的片段，取出各段的峰值并随录音一起保存。

## 播放进度 \{#progress\}

波形行上的 `--waveform-progress` 表示播放进度，取值为 0 到 1。墨色填充以整行宽度为基准，因此能精确停在播放位置，即使该位置落在一根竖条中间，也会随数值平滑移动。每根竖条用 `clip-path` 裁剪成胶囊形，同时裁剪内部内容。内部的墨色相对于整行定位，从行首延伸到播放位置。所有浏览器引擎都能绘制这一效果，无需计算竖条数量或复制一组竖条。

要支持跳转播放位置，把 `waveform-seek` 范围输入控件放在波形行的末尾。控件不可见，覆盖在竖条上，滑块宽 1 像素，因此指针处的取值与下方的竖条位置对应。按方向键可逐步调整播放位置，波形行会绘制焦点环。指针悬停在波形上时，尚未播放的竖条颜色会略微加深，提示可以操作。

播放录音的脚本负责维护进度值。使用 `<audio>` 元素时，脚本在 `timeupdate` 时更新该属性和输入控件的值，并在控件的值变化时设置音频的当前播放位置：

```js
audio.addEventListener('timeupdate', () => {
  seek.value = audio.currentTime
  waveform.style.setProperty('--waveform-progress', audio.currentTime / audio.duration)
})
seek.addEventListener('input', () => { audio.currentTime = seek.value })
```

`timeupdate` 大约每秒触发四次。要让播放位置平滑移动，可在播放期间通过 `requestAnimationFrame` 循环读取 `audio.currentTime`，预览中的计时器就采用这种方式。

## 无障碍 \{#accessibility\}

- 竖条是空元素，不向辅助技术传达信息。播放按钮、用于跳转的输入控件和时间共同传达波形的含义。
- 为播放按钮设置 `aria-label`，根据当前状态使用“播放”或“暂停”。为用于跳转的输入控件设置 `aria-label` 和文字形式的 `aria-valuetext`，例如“共 14 秒，已播放 5 秒”，并随控件的值更新这段文字。
- 如果没有用于跳转的输入控件，就用文字标明录音时长，可以使用 `waveform-time`，也可以直接写在消息里。
- 在强制颜色模式下，竖条中已播放的部分使用系统文本颜色，尚未播放的部分使用系统灰色文本颜色。
