波形は配置先の文字色を引き継ぎます。受信した[メッセージ](/components/message)では浮き上がった面に濃い文字色を、送信したメッセージでは濃い面に反転した文字色を使います。同じバーが、バリアントを切り替えなくてもどちらの面でも見分けられます。再生ボタンは吹き出しと対になる質感で、浮き上がった面には濃いボタン、濃い面には浮き上がったボタンを置きます。

## バー \{#bars\}

録音を区切った各区間に `waveform-bar` を1つ記述し、音の大きさを 0 から 1 の値で `--level` に指定します。バーは列の中央線を中心に、列の高さにその値を掛けた高さで表示します。高さは少なくともバーの幅と同じなので、無音区間は点の列になります。`round()` で高さを 2px 刻みに丸め、両端の丸みをピクセルグリッドに揃えます。`round()` に対応していないブラウザーでは計算どおりの高さになり、端の丸みが一部欠けることがあります。

バーの幅は 3px、間隔は 2px です。再生ボタンや時刻表示とともに吹き出しに入れる場合など、ほかの要素と横に並べると、波形の幅はバーと間隔に必要な分だけになります。30本なら 148px です。余裕があれば、その幅いっぱいにバーを等間隔で広げます。使える幅が狭ければ、各バーが一律に細くなります。波形が要求する幅はバーの配置に必要な幅を下回らないため、内容に合わせて幅が決まるボックスには、吹き出しと同様に幅または最大幅を指定します。録音の長さにかかわらず、表示領域に収まる本数を目安に描画します。録音時またはアップロード時に、音声をバーの本数と同じ数の区間に分け、各区間のピーク値を音声と一緒に保存します。

## 再生位置の表示 \{#progress\}

バーの列に指定する `--waveform-progress` は、録音の再生位置を 0 から 1 の値で表します。再生済みの色は列全体の幅を基準に描画するため、バーの途中でも再生ヘッドの位置で正確に止まり、値に合わせて滑らかに動きます。各バーには `clip-path` を使い、内側の塗りをカプセル形の輪郭で切り抜きます。塗りの位置は列を基準とし、列の先頭から再生ヘッドまで伸びます。バーの本数を数えたり複製したりする必要はなく、どのブラウザーエンジンでも描画できます。

シークできるようにするには、バーの列の最後に `waveform-seek` クラスを付けた範囲入力を置きます。入力はバーの上に透明な状態で重なり、つまみの幅は 1px です。ポインターの位置で選ばれる値は、真下のバーに対応します。矢印キーで値を刻み単位で変更でき、フォーカスリングはバーの列に表示されます。ホバーできるポインターを重ねると、未再生のバーが少しせり上がり、操作できることを示します。

再生位置の値は、録音を再生するスクリプトが管理します。`<audio>` 要素を使う場合は、`timeupdate` の発生時にプロパティと入力の値を更新し、入力値が変わったら音声の再生位置を設定します。

```js
audio.addEventListener('timeupdate', () => {
  seek.value = audio.currentTime
  waveform.style.setProperty('--waveform-progress', audio.currentTime / audio.duration)
})
seek.addEventListener('input', () => { audio.currentTime = seek.value })
```

`timeupdate` は 1 秒に約 4 回発生します。再生ヘッドを滑らかに動かすには、プレビューのタイマーと同様に、再生中は `requestAnimationFrame` のループで `audio.currentTime` を読み取ります。

## アクセシビリティ \{#accessibility\}

- バーは空の要素なので、支援技術に情報を伝えません。再生ボタン、シーク入力、時刻表示が必要な情報を伝えます。
- 再生ボタンには、状態に応じて「再生」または「一時停止」を `aria-label` に設定します。シーク入力には `aria-label` と、「0:14 のうち 0:05」のように読み上げられる `aria-valuetext` を設定し、後者を入力値に合わせて更新します。
- シーク入力がない場合は、`waveform-time` またはメッセージ本文で、録音の長さをテキストで示します。
- 強制カラーモードでは、再生済み部分をシステムのテキスト色で、未再生部分をシステムのグレーのテキスト色で描画します。
