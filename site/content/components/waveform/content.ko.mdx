파형은 주변 텍스트의 잉크색을 따릅니다. 받은 [메시지](/components/message)에서는 한 층 높은 표면 위에 진한 잉크색으로, 보낸 메시지에서는 잉크색 배경 위에 반전된 잉크색으로 표시됩니다. 별도의 변형 없이 같은 막대를 두 곳에서 사용할 수 있습니다. 재생 버튼에는 말풍선과 반대되는 재질을 적용합니다. 한 층 높은 표면 위에는 잉크색 버튼을, 잉크색 배경 위에는 한 층 높은 표면의 버튼을 배치합니다.

## 막대 \{#bars\}

녹음을 나눈 구간마다 `waveform-bar`를 하나씩 작성하고 소리 크기를 0에서 1 사이의 `--level` 값으로 지정하세요. 각 막대의 높이는 전체 줄 높이에 이 값의 비율을 적용한 크기이며, 막대는 가로 중심선에 맞춰 배치됩니다. 막대 높이는 너비보다 작아지지 않으므로 소리가 없는 구간은 점으로 표시됩니다. `round()`로 높이를 2px 단위로 반올림해 양 끝의 둥근 부분을 픽셀 격자에 맞춥니다. `round()`를 지원하지 않는 브라우저에서는 계산된 높이를 그대로 사용하므로 끝부분이 덜 둥글게 보일 수 있습니다.

막대 너비는 3px이고 간격은 2px입니다. 버튼과 시간이 함께 놓인 말풍선처럼 다른 요소와 한 줄에 배치하면, 파형은 막대를 표시하는 데 필요한 너비를 차지합니다. 막대 30개에는 148px이 필요합니다. 공간이 더 넓으면 가용 너비를 채우도록 막대 간격을 균등하게 벌리고, 공간이 더 좁으면 막대 너비를 함께 줄입니다. 파형 자체가 요구하는 너비는 막대에 필요한 너비보다 작아지지 않으므로, 콘텐츠에 맞춰 크기가 정해지는 상자에는 말풍선처럼 너비나 최대 너비를 지정하세요. 녹음 길이에 관계없이 표시 공간에 들어가는 개수를 기준으로 막대 수를 대략 정합니다. 녹음하거나 업로드할 때 오디오를 막대 수만큼 나누고, 각 구간에서 가장 큰 소리의 크기를 오디오와 함께 저장하세요.

## 재생 진행도 \{#progress\}

막대가 놓인 줄의 `--waveform-progress` 값은 재생 진행도를 0에서 1 사이의 값으로 나타냅니다. 잉크색이 채워지는 범위는 줄 전체 너비를 기준으로 계산합니다. 재생 위치가 막대 한가운데에 있더라도 정확히 그 지점에서 채우기가 끝나며, 값이 부드럽게 바뀌면 채워진 범위도 그에 맞춰 움직입니다. 각 막대는 `clip-path`로 내부 콘텐츠를 잘라 양 끝이 둥근 모양을 만듭니다. 내부를 채우는 잉크색 영역은 줄 전체를 기준으로 배치되어 줄의 시작점부터 현재 재생 위치까지 이어집니다. 막대 수를 세거나 막대를 복제할 필요 없이 모든 브라우저 엔진에서 렌더링됩니다.

재생 위치를 이동하려면 줄의 맨 끝에 `waveform-seek` 범위 입력을 넣으세요. 이 입력은 막대 위에 보이지 않게 겹쳐 있고, 손잡이 너비가 1픽셀이므로 포인터 위치의 값이 그 아래 막대와 일치합니다. 방향키로 값을 한 단계씩 조절할 수 있으며, 포커스 링은 줄 전체에 표시됩니다. 호버를 지원하는 포인터를 올리면 아직 재생되지 않은 막대가 살짝 강조되어 조작할 수 있음을 보여 줍니다.

녹음을 재생하는 스크립트에서 진행도 값을 관리합니다. `<audio>` 요소를 사용하는 경우 `timeupdate` 이벤트가 발생할 때 사용자 지정 속성과 입력값을 갱신하고, 입력값이 바뀌면 오디오의 재생 위치를 설정합니다.

```js
audio.addEventListener('timeupdate', () => {
  seek.value = audio.currentTime
  waveform.style.setProperty('--waveform-progress', audio.currentTime / audio.duration)
})
seek.addEventListener('input', () => { audio.currentTime = seek.value })
```

`timeupdate` 이벤트는 초당 약 4회 발생합니다. 재생 위치를 부드럽게 움직이려면 미리보기의 타이머처럼 재생 중에 `requestAnimationFrame` 루프에서 `audio.currentTime` 값을 읽으세요.

## 접근성 \{#accessibility\}

- 막대는 빈 요소이므로 보조 기술에 전달하는 정보가 없습니다. 재생 버튼, 재생 위치 입력, 시간 표시가 파형의 의미를 전달합니다.
- 재생 버튼의 `aria-label`에는 상태에 따라 ‘재생’ 또는 ‘일시 정지’를 지정하세요. 재생 위치 입력에는 `aria-label`을 지정하고, `aria-valuetext`에는 ‘전체 0:14 중 0:05’처럼 읽을 수 있는 문구를 넣어 입력값이 바뀔 때마다 갱신하세요.
- 재생 위치 입력이 없다면 `waveform-time`을 사용하거나 메시지 본문에 텍스트로 녹음의 전체 길이를 표시하세요.
- 강제 색상 모드에서는 재생된 구간의 막대에 시스템 텍스트 색상을, 남은 구간의 막대에 시스템 회색 텍스트 색상을 사용합니다.
