波形沿用所在區域的文字色。收到的[訊息](/components/message)在抬升層級的背景上使用高對比文字色，送出的訊息則以文字色為底，搭配反相文字色。同一組直條無須切換變體就能清楚呈現。播放按鈕與訊息泡泡的底色互換，抬升層級的泡泡搭配以文字色為底的按鈕，以文字色為底的泡泡則搭配抬升層級的背景色作為按鈕底色。

## 直條 \{#bars\}

為錄音的每個切片放入一個 `waveform-bar`，並用 `--level` 設定 0 到 1 的音量值。直條高度是整列高度乘上這個值，並以水平中線置中。直條的高度至少等於寬度，因此停頓會顯示成一排圓點。高度使用 `round()` 取整為 2px 的倍數，讓兩端的圓角對齊像素格線。瀏覽器若不支援 `round()`，就會使用原始高度，端部可能無法保持完整的圓弧。

直條寬 3px，彼此相隔 2px。與其他元素排在同一列時，例如泡泡內的播放按鈕和時間，波形會採用直條所需的寬度，30 根直條需要 148px。空間較多時，波形會填滿可用寬度，並均勻拉開間距。空間較少時，直條會一起變窄。波形本身要求的寬度至少等於直條所需的寬度，因此如果外層容器會依內容決定大小，請像訊息泡泡一樣為容器設定寬度或最大寬度。不論錄音多長，都用大約能排得下的直條數來呈現。錄製或上傳時，將音訊切成對應數量的片段，取出各片段的音量峰值，並與錄音一併儲存。

## 播放進度 \{#progress\}

整列的 `--waveform-progress` 以 0 到 1 表示錄音的播放進度。填色以整列寬度為基準，無須按直條計數，因此即使播放位置落在某根直條的中間，填色也會精準停在該處，並隨進度值平順移動。每根直條用 `clip-path` 裁成膠囊形，並裁切其中的內容。直條內的填色以整列為定位基準，從列的起點延伸到播放位置。各瀏覽器引擎都能繪製這個效果，無須計算直條數量或複製一組直條。

若要支援跳轉播放位置，請在列的最後放入帶有 `waveform-seek` 的範圍輸入控制項。它會隱形覆蓋在直條上，滑塊只有 1 像素寬，因此指標所在位置的值會對應下方的直條。可用方向鍵逐步調整，焦點外框會繪在整列上。指標懸停時，尚未播放的直條會稍微加深同色填色，提示使用者可以操作。

播放錄音的腳本負責管理進度值。使用 `<audio>` 元素時，在 `timeupdate` 事件中更新自訂屬性與輸入控制項的值，並在輸入值改變時設定音訊的目前播放位置：

```js
audio.addEventListener('timeupdate', () => {
  seek.value = audio.currentTime
  waveform.style.setProperty('--waveform-progress', audio.currentTime / audio.duration)
})
seek.addEventListener('input', () => { audio.currentTime = seek.value })
```

`timeupdate` 約每秒觸發四次。若要讓播放位置平順移動，可像預覽的計時器一樣，在播放期間透過 `requestAnimationFrame` 迴圈讀取 `audio.currentTime`。

整列高 32px，與旁邊的小按鈕等高。`waveform-sm` 高 20px，直條寬 2px，適合清單或檔案列。`waveform-lg` 高 48px，直條寬 4px，適合以播放器為主的卡片。

## 無障礙 \{#accessibility\}

- 直條是空元素，輔助技術不會讀出內容。播放按鈕、跳轉控制項和時間文字負責傳達操作與播放資訊。
- 依狀態將播放按鈕的 `aria-label` 設為「播放」或「暫停」。也為跳轉控制項設定 `aria-label`，並用 `aria-valuetext` 提供可讀的文字，例如「總長 0:14，目前 0:05」，並隨控制項的值更新。
- 如果沒有跳轉控制項，請用 `waveform-time` 或直接在訊息中以文字標明錄音長度。
- 在強制色彩模式下，已播放的部分使用系統文字色，尚未播放的部分則使用系統灰色文字色。
