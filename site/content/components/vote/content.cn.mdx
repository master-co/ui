投票让每位读者可以为回答、帖子或评论加一分或减一分。两个箭头是同一组中的原生单选按钮，外观是低调的方形按钮。中间的分数由 CSS 计数器显示，按下箭头即可更新分数，无需脚本。

## 分数 \{#score\}

将组上的 `--votes` 设为不计当前读者投票的分数。选中向上箭头加一分，选中向下箭头减一分。如果页面知道读者投了哪一票，就选中对应的箭头，并将其他读者投出的分数作为基准。将 `vote-score` 留空，由计数器显示分数，负数使用真正的减号。如果分数太大，不适合逐一计数，可在其中填写 `1.4k` 之类的文本。

## 横向排列 \{#horizontal\}

`vote-horizontal` 将两个箭头放在分数两侧，适合评论下方的操作栏。分数预留三位数字的宽度，数值变化时箭头位置保持固定。

## 状态 \{#states\}

未悬停、按下或选中时，箭头仅显示柔和的墨色轮廓，按钮没有背景。指针悬停时，按钮呈现为小型凸起面板，按下时沉入凹槽，选中后箭头以墨色填实。两个箭头通过朝向区分，无需依赖颜色。对于无法投票的分数，例如读者自己帖子的分数，请禁用 fieldset。此时箭头变淡，分数仍然可见。

## 撤回投票 \{#taking-back\}

再次按下已选中的单选按钮无法取消选中，因此没有脚本时，读者只能改投。这几行代码让读者可以再次按下已选中的箭头，或在该箭头获得焦点时按空格键，撤回投票并将分数恢复为 `--votes`。

<ComponentPreview name="taking-back" height={136} title="撤回投票" background="plain" html={`<fieldset class="vote" id="vote-clear" aria-label="Vote on this answer" style="--votes: 7">
  <input type="radio" class="vote-up" name="vote-clear" value="up" aria-label="Upvote" checked>
  <output class="vote-score"></output>
  <input type="radio" class="vote-down" name="vote-clear" value="down" aria-label="Downvote">
</fieldset>
<script>
  const vote = document.getElementById('vote-clear')
  let chosen = vote.querySelector(':checked')

  vote.addEventListener('click', function (event) {
    const arrow = event.target.closest('.vote-up, .vote-down')
    if (!arrow) return
    if (arrow === chosen) {
      arrow.checked = false
      arrow.dispatchEvent(new Event('change', { bubbles: true }))
      chosen = null
    } else {
      chosen = arrow
    }
  })

  vote.addEventListener('keydown', function (event) {
    if (event.key === ' ' && event.target === chosen) {
      event.preventDefault()
      chosen.click()
    }
  })
</script>`} caption="再次按下实心箭头即可撤回投票。" />

## 无障碍 \{#accessibility\}

- 用 `aria-label` 或 `<legend>` 为单选按钮组提供无障碍名称，并分别将两个单选按钮命名为“赞成”和“反对”。
- 将分数放在 `<output>` 中。辅助技术按内容顺序读取，在读完第一个箭头后、读取第二个箭头前读出分数。投票改变分数时，还会将新分数作为状态更新播报。
- 箭头图形绘制在伪元素上，避免遮罩裁掉焦点环。与其他单选按钮组一样，方向键可在两个单选按钮之间切换投票。
- 每个箭头按钮的尺寸为 32px，在触摸屏上为 44px。在强制颜色模式下，箭头图形使用按钮文字颜色，选中的箭头使用高亮颜色。
