A vote is a score that each reader may move up or down by one: the score of an answer, a post or a comment. The two arrows are native radios of one group, drawn as quiet square buttons, and the score between them is a CSS counter, so a press moves the number with no script.

## The score \{#score\}

Set `--votes` on the group to the score without the reader's vote. The checked up arrow adds one and the checked down arrow takes one away, so a page that knows the reader's vote checks that arrow and gives the score of everyone else. Leave `vote-score` empty and the counter writes the score, with a true minus sign when it is below zero; write text inside it, such as `1.4k`, for a score too large to count by one.

## In a row \{#horizontal\}

`vote-horizontal` puts the arrows on either side of the score, for a row of actions under a comment. The score keeps the width of three figures, so the arrows do not move when it changes.

## States \{#states\}

At rest an arrow is an outline in muted ink with no face of its own. Under the pointer it rises as a small sheet, under a press it sinks into a well, and chosen it fills with ink. Up and down are told apart by direction, not by hue. Disable the fieldset to show a score that cannot be voted on, such as one on the reader's own post: the arrows fade and the score stays.

## Taking a vote back \{#taking-back\}

A radio cannot be cleared by pressing it again, so without a script a reader can change a vote but not withdraw it. These lines let a second press on the chosen arrow, or Space on it, clear the vote, and the score returns to `--votes`.

<ComponentPreview name="taking-back" height={136} title="Taking a vote back" background="plain" html={`<fieldset class="vote" id="vote-clear" aria-label="Vote on this answer" style="--votes: 7">
  <input type="radio" class="vote-up" name="vote-clear" value="up" aria-label="Upvote" checked>
  <output class="vote-score"></output>
  <input type="radio" class="vote-down" name="vote-clear" value="down" aria-label="Downvote">
</fieldset>
<script>
  const vote = document.getElementById('vote-clear')
  let chosen = vote.querySelector(':checked')

  vote.addEventListener('click', function (event) {
    const arrow = event.target.closest('.vote-up, .vote-down')
    if (!arrow) return
    if (arrow === chosen) {
      arrow.checked = false
      arrow.dispatchEvent(new Event('change', { bubbles: true }))
      chosen = null
    } else {
      chosen = arrow
    }
  })

  vote.addEventListener('keydown', function (event) {
    if (event.key === ' ' && event.target === chosen) {
      event.preventDefault()
      chosen.click()
    }
  })
</script>`} caption="Press the filled arrow again to take the vote back." />

## Accessibility \{#accessibility\}

- Name the group with `aria-label` or a `<legend>`, and each radio: "Upvote" and "Downvote".
- Put the score in an `<output>`. It is read where it stands, between the two arrows, and as a status it is announced when a vote changes it.
- The arrows keep their focus ring: the glyph is drawn on a pseudo-element, so no mask cuts the ring. Arrow keys move the vote between the two radios, as in any radio group.
- Each arrow is 32px, and 44px on a touch screen. In forced colors the glyphs take the button text color, and the chosen one the highlight color.
