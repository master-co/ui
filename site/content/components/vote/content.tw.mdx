## 分數 \{#score\}

在群組上將 `--votes` 設為扣除該讀者投票後的分數。選取向上箭頭會加一，選取向下箭頭會減一。若頁面已知道讀者投了哪一票，請選取對應的箭頭，並將其他人的投票總分設為基準。將 `vote-score` 留空，計數器就會自動顯示分數，負分會使用真正的負號。若分數太大，不適合以一分為單位顯示，可直接填入 `1.4k` 之類的文字。

## 橫向排列 \{#horizontal\}

`vote-horizontal` 將兩個箭頭分別放在分數兩側，適合放在留言下方的一排操作按鈕中。分數會保留三個數字的寬度，因此分數變動時箭頭不會位移。

## 狀態 \{#states\}

平時箭頭以柔和的文字色描出輪廓，按鈕本身沒有底色。指標移上時，按鈕會像小面板般浮起，按下時會凹下，選取後則以文字色填滿箭頭。向上與向下的票只靠箭頭方向區分。若分數不開放投票，例如讀者自己的貼文，請停用欄位群組，箭頭會淡出，分數仍會顯示。

## 撤回投票 \{#taking-back\}

再次按下已選取的單選按鈕無法清除選取，因此沒有腳本時，讀者只能改投另一邊。下方的程式碼讓讀者可以再次按下已選取的箭頭，或在該箭頭上按空白鍵來撤回投票，分數也會回到 `--votes`。

<ComponentPreview name="taking-back" height={136} title="撤回投票" background="plain" html={`<fieldset class="vote" id="vote-clear" aria-label="Vote on this answer" style="--votes: 7">
  <input type="radio" class="vote-up" name="vote-clear" value="up" aria-label="Upvote" checked>
  <output class="vote-score"></output>
  <input type="radio" class="vote-down" name="vote-clear" value="down" aria-label="Downvote">
</fieldset>
<script>
  const vote = document.getElementById('vote-clear')
  let chosen = vote.querySelector(':checked')

  vote.addEventListener('click', function (event) {
    const arrow = event.target.closest('.vote-up, .vote-down')
    if (!arrow) return
    if (arrow === chosen) {
      arrow.checked = false
      arrow.dispatchEvent(new Event('change', { bubbles: true }))
      chosen = null
    } else {
      chosen = arrow
    }
  })

  vote.addEventListener('keydown', function (event) {
    if (event.key === ' ' && event.target === chosen) {
      event.preventDefault()
      chosen.click()
    }
  })
</script>`} caption="再按一次實心箭頭即可撤回投票。" />

## 無障礙 \{#accessibility\}

- 使用 `aria-label` 或 `<legend>` 為群組命名，並為兩個單選按鈕分別命名為「投贊成票」和「投反對票」。
- 將分數放在 `<output>` 中。螢幕閱讀器會依版面順序在兩個箭頭之間讀出分數，投票改變分數時也會將新分數當作狀態訊息播報。
- 箭頭會保留焦點外框。箭頭圖形繪製在偽元素上，因此遮罩不會裁掉外框。方向鍵可在兩個單選按鈕之間切換投票，操作方式與一般單選群組相同。
- 每個箭頭按鈕為 32px，在觸控螢幕上為 44px。在強制色彩模式下，箭頭使用按鈕文字色，已選取的箭頭則使用醒目提示色。
