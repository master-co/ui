共同編集カーソルは、同じものを編集しているほかの人がどこにいるかを示します。キャンバスやボード上のポインター、テキスト内のキャレットや選択範囲などです。各人は 1 つの識別色で描かれ、その横に名前が表示されるため、誰がどこにいるかが一目でわかります。ポインターが動く範囲となる、CSS で位置指定された要素の中で、`presence-name` を含む要素に `presence` と、その人の[識別色](#identity)を表す `presence-1` から `presence-8` のいずれかを追加し、`--presence-x` と `--presence-y` で位置を指定します。

## ポインターの位置 \{#where-a-pointer-stands\}

ポインターの先端が位置を示す点です。`--presence-x` と `--presence-y` は、CSS で位置指定された最も近い祖先要素の左上隅からの距離をピクセルで表します。その要素は通常キャンバスやボードで、`relative` と `overflow-hidden` を指定し、端の近くにあるポインターがその端で切り取られるようにします。各人がどこにいて、いつ離れるかを知っているのはアプリケーションです。アプリケーションは、誰かが参加したときに `presence` を追加し、ポインターの移動に合わせて 2 つのプロパティを設定し、その人が離れたときに削除します。描画と動きはスタイルシートが担い、独自のスクリプトはありません。

```js name=app.js
function move(person, x, y) {
  const pointer = board.querySelector(`[data-person="${person.id}"]`)
  pointer.style.setProperty('--presence-x', `${x}px`)
  pointer.style.setProperty('--presence-y', `${y}px`)
}
```

- **動き**　ポインターは新しい点ごとに、160ms かけて直線的に滑らかに移動します。これにより、通信で 1 秒あたり数回しか届かない位置が、途切れない動きになります。`prefers-reduced-motion: reduce` では瞬時に移動します。
- **操作の妨げにならない**　ポインターはポインターイベントを受け取らないため、読者自身のポインターとその下にある要素の間に割り込むことはありません。
- **座標**　座標はキャンバス自体の単位で送信し、プロパティを設定する前に読者の表示に合わせて変換します。そうすることで、ウィンドウのサイズや拡大率が異なる 2 人でも、同じものを指し示せます。

## メッセージ \{#message\}

名前の下に置く `presence-message` は、カーソルチャットのように、その人が入力している短い言葉を表示します。たとえば、指し示しているものについての質問です。15rem で折り返します。その人が入力をやめてから数秒後に削除します。

## 識別色 \{#identity\}

Master UI では、色相は状態を表し、ここでは人を表します。テーマには `--color-identity-1` から `--color-identity-8` までの 8 つの識別色があり、すべて同じ明度です。各人はセッションの間 1 つの色を使い続け、その横には常に名前が表示されるため、色だけが人を見分ける手段になることはありません。`--color-identity-ink` はどの識別色の上でも使うテキストの色で、コントラスト比はライトスキームで 4.8:1 以上、ダークスキームで 9:1 以上です。

ポインター、キャレット、選択範囲、単独で表示する名前に、修飾クラス `presence-1` から `presence-8` のいずれかを指定して色を選びます。人を表す独自の色を持つプロダクトでは、代わりに `--presence-color` を設定します。その場合は、`--color-identity-ink` が読める明度の色を指定するか、そのトークンも設定します。

## テキスト内 \{#in-text\}

共同編集するドキュメントでは、ほかの人のキャレットは 2 つの文字の間に置く `presence-caret` です。その人の色の 2px のバーで、高さは行と同じです。バーの上に立つフラッグに名前が表示されます。場所を取らないため、キャレットが動いても周囲の文字は動きません。その人の選択範囲は、選択した語句を囲む `presence-selection` です。語句の背後にその人の色を薄く敷き、複数行にまたがっても続きます。

エディターは、共同編集レイヤーがほかの人の位置として示す場所にこれらの表示を置きます。これらはエディターが描画して削除する装飾であり、ドキュメントの一部ではありません。最初の行の上には名前のフラッグのための余白を確保するか、最初の行にあるキャレットのフラッグが、テキストを収める要素のパディングにはみ出すようにします。

## ほかのコンポーネントを使う場面 \{#when-to-use-something-else\}

- どこにいるかではなく、誰がいるかを示すには、ヘッダーに[アバター](/components/avatar)を重ねて並べます。
- アプリケーションがまだ書き込んでいるテキストの末尾に付ける表示は、[キャレット](/components/caret)です。
- 検索語に一致した箇所など、読者のために強調した語句は[マーク](/components/mark)です。

## アクセシビリティ \{#accessibility\}

- ポインターとキャレットは装飾です。キャンバスや文の途中で名前が読み上げられないように、それぞれに `aria-hidden="true"` を指定します。誰がいるかは、ヘッダーに名前付きのアバターを置くなど、別の場所で文字で伝えます。参加と退出がタスクにとって重要な場合は、aria-live の値を polite に設定したライブリージョンで通知します。
- 選択範囲は隠しません。中の語句はドキュメントのものだからです。色を敷いても語句の色は変わらないため、コントラストは保たれます。
- 色が唯一の手がかりになることはありません。すべてのポインターとキャレットの横に名前が表示されます。
- 強制カラーモードでは、矢印とキャレットはシステムカラーで描画され、フラッグと吹き出しには輪郭線が付きます。
