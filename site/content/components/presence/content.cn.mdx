协作者光标显示在同一内容上协作的其他人所在的位置：画布或白板上的指针，文本中的插入光标和选区。每个人都以一种身份色绘制，旁边附上名字，读者一眼就能看出谁在哪里。在指针移动所在的已定位元素中，给一个包含 `presence-name` 的元素加上 `presence` 和此人的[身份色](#identity)（`presence-1` 到 `presence-8`），再用 `--presence-x` 和 `--presence-y` 设置其位置。

## 指针的位置 \{#where-a-pointer-stands\}

指针的尖端就是它所指的点。`--presence-x` 和 `--presence-y` 是它距最近的已定位元素左上角的距离，以像素计。该元素通常是画布或白板，带有 `relative` 和 `overflow-hidden`，因此靠近边缘的指针会在边缘处被裁切。应用知道每个人在哪里、何时离开：有人到来时添加一个 `presence`，其指针移动时设置这两个属性，离开时将其移除。绘制和动画由样式表负责；它没有自己的脚本。

```js name=app.js
function move(person, x, y) {
  const pointer = board.querySelector(`[data-person="${person.id}"]`)
  pointer.style.setProperty('--presence-x', `${x}px`)
  pointer.style.setProperty('--presence-y', `${y}px`)
}
```

- **动画。** 指针以 160ms 沿直线滑向每个新位置，把连接每秒传来的少数几个位置变成连贯的移动。在 `prefers-reduced-motion: reduce` 下，指针会直接跳转。
- **不碍事。** 指针不接收任何指针事件，因此绝不会挡在读者自己的指针与其下方的内容之间。
- **坐标。** 请以画布自身的单位发送坐标，并在设置属性前换算到读者的视图，这样窗口大小和缩放比例不同的两个人指向的也是同一个对象。

## 消息 \{#message\}

名字下方的 `presence-message` 显示此人正在输入的几个字，就像光标聊天那样：例如针对其所指内容的一个问题。消息宽度上限为 15rem，超出时自动换行。请在对方停止输入几秒后将其移除。

## 身份色 \{#identity\}

在 Master UI 中，色相用来表示状态，在这里则表示一个人。主题有八种身份色，`--color-identity-1` 到 `--color-identity-8`，明度全部相同：一个人在整个会话中保持其中一种颜色，名字也始终显示在颜色旁边，因此颜色从来不是区分人的唯一方式。`--color-identity-ink` 是所有身份色上的文字颜色，在浅色配色中对比度至少为 4.8:1，在深色配色中至少为 9:1。

在指针、插入光标、选区或单独显示的名字上，用修饰类 `presence-1` 到 `presence-8` 选择一种颜色。如果产品有自己为人分配的颜色，请改为设置 `--presence-color`；请选择明度合适的颜色，使其与 `--color-identity-ink` 指定的文字颜色有足够的对比度，或者同时设置该自定义属性。

## 在文本中 \{#in-text\}

在共同编辑的文档中，另一个人的插入光标是位于两个字符之间的 `presence-caret`：一条与行同高、2px 宽的竖条，使用此人的颜色，名字显示在立于其上的小旗中。它不占空间，因此它移动时周围的文字不会移动。此人的选区是包裹所选文字的 `presence-selection`：在文字后方衬上此人颜色的浅色调，可以跨行延续。

编辑器根据协作层报告的其他人位置放置这些标记，它们是编辑器渲染和移除的装饰，不属于文档内容。请在第一行上方为名字小旗留出空间，或者让第一行插入光标的小旗延伸到容纳文本的元素的内边距中。

## 何时改用其他组件 \{#when-to-use-something-else\}

- 要显示谁在这里，而不是在哪里，请在标题栏中使用一叠[头像](/components/avatar)。
- 应用仍在写入的文本末尾的标记，请使用[光标](/components/caret)。
- 为读者突出显示的文字（例如搜索匹配项），请使用[文本高亮](/components/mark)。

## 无障碍 \{#accessibility\}

- 指针和插入光标属于装饰：给每一个都加上 `aria-hidden="true"`，以免在画布或句子中间读出它们的名字。请在其他地方用文字说明谁在这里，例如标题栏中带名字的头像；如果到来和离开对任务很重要，请在礼貌型实时区域中播报。
- 选区不隐藏：其中的文字属于文档。浅色调不会改变文字颜色，因此文字保持原有的对比度。
- 颜色从来不是唯一的线索：每个指针和插入光标旁边都有名字。
- 在强制颜色模式下，箭头和插入光标使用系统颜色绘制，小旗和气泡带有轮廓线。
