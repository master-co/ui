協作者游標會顯示正在處理同一份內容的其他人位於何處：他們在畫布或白板上的指標，以及在文字中的文字游標和選取範圍。每個人都以一種識別色繪製，旁邊附上名字，讓讀者一眼就能看出誰在哪裡。請在指標移動範圍所在的定位元素內，為包含 `presence-name` 的元素加上 `presence` 和該人的[識別色](#identity)（`presence-1` 到 `presence-8`），並以 `--presence-x` 和 `--presence-y` 設定它的位置。

## 指標的位置 \{#where-a-pointer-stands\}

指標的尖端就是它所指的點。`--presence-x` 和 `--presence-y` 是它與最近的定位元素左上角之間的距離，以像素計；這個定位元素通常是畫布或白板，會加上 `relative` 和 `overflow-hidden`，讓靠近邊緣的指標在邊緣處被裁切。應用程式知道每個人在哪裡、何時離開：有人加入時加上一個 `presence`，對方指標移動時設定這兩個屬性，對方離開時再將它移除。繪製和動態由樣式表負責；它本身沒有腳本。

```js name=app.js
function move(person, x, y) {
  const pointer = board.querySelector(`[data-person="${person.id}"]`)
  pointer.style.setProperty('--presence-x', `${x}px`)
  pointer.style.setProperty('--presence-y', `${y}px`)
}
```

- **動態。** 指標會以 160ms 沿直線滑到每個新位置，將連線每秒傳來的少數幾個位置轉為平穩的移動。在 `prefers-reduced-motion: reduce` 下則直接跳到定點。
- **不擋路。** 指標不接收任何指標事件，因此絕不會擋在讀者自己的指標和下方內容之間。
- **座標。** 請以畫布本身的單位傳送座標，並在設定屬性前轉換為讀者的檢視座標，這樣視窗大小和縮放比例不同的兩個人，才會指向同一個東西。

## 訊息 \{#message\}

名字下方的 `presence-message` 會顯示對方正在輸入的簡短文字，就像游標聊天（cursor chat）一樣，例如針對所指內容提出的問題。訊息寬度最多為 15rem，超出時會換行。請在對方停止輸入幾秒後將它移除。

## 識別色 \{#identity\}

在 Master UI 中，色相用來表示狀態，在這裡則用來代表一個人。主題提供八種識別色，從 `--color-identity-1` 到 `--color-identity-8`，明度全都相同：每個人在整個工作階段中保有其中一種，名字也一定顯示在旁邊，因此顏色絕不是區分不同人的唯一方式。`--color-identity-ink` 是所有識別色上的文字顏色，對比度在淺色配色中至少為 4.8:1，在深色配色中至少為 9:1。

在指標、文字游標、選取範圍或單獨顯示的名字上，用修飾類別 `presence-1` 到 `presence-8` 選擇其中一種。若產品有自己用來代表人員的顏色，請改為設定 `--presence-color`；請選擇明度足以讓 `--color-identity-ink` 清楚顯示的顏色，或同時設定該 token。

## 在文字中 \{#in-text\}

在共同編輯的文件中，其他人的文字游標是位於兩個字母之間的 `presence-caret`：一條與行高等高、以對方顏色繪製的 2px 直線，上方立著一面寫著對方名字的旗標。它不占空間，因此它移動時周圍的文字不會跟著移動。對方的選取範圍是包住所選文字的 `presence-selection`：在文字後方以對方顏色的淡色調鋪底，並延續到跨行的部分。

編輯器會依協作層回報的其他人位置放置這些標記，作為它自行算繪和移除的裝飾；它們不屬於文件內容。請在第一行上方保留放置名字旗標的空間，或讓第一行文字游標的旗標延伸到文字容器的內距中。

## 何時改用其他元件 \{#when-to-use-something-else\}

- 若要顯示誰在場，而不是在哪裡，請在標題列使用一疊[頭像](/components/avatar)。
- 應用程式仍在寫入的文字結尾標記，請使用[文字游標](/components/caret)。
- 為讀者醒目標示的文字，例如符合搜尋條件的文字，請使用[醒目標記](/components/mark)。

## 無障礙 \{#accessibility\}

- 指標和文字游標屬於裝飾：請為每一個加上 `aria-hidden="true"`，避免在畫布或句子中間讀出它們的名字。請在其他地方以文字說明誰在場，例如在標題列放上附有名字的頭像；若協作者的加入或離開會影響目前的工作，請在設為 polite 的即時區域中宣告這項變動。
- 選取範圍不會隱藏：其中的文字屬於文件內容。淡色調不會改變文字顏色，因此文字仍保有原本的對比度。
- 顏色絕不是唯一的線索：每個指標和文字游標旁都有名字。
- 強制色彩模式下，箭頭和文字游標以系統色繪製，旗標和對話泡泡則會加上外框線。
