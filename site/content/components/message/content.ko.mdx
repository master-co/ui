메시지는 대화의 한 차례에 해당합니다. 받은 메시지는 행의 시작에 살짝 떠 있는 표면으로 표시하고, 보낸 메시지는 기본 [버튼](/components/button)과 같은 잉크 색으로 행의 끝에 표시합니다. 말풍선의 모서리는 표면과 같은 모양이며, 작성자를 가리키는 모서리만 둥글기가 작습니다. 어느 댓글에나 답글을 달 수 있는 토론에는 [스레드](/components/thread)를 사용합니다.

대화에는 일반 목록 요소를 사용할 수 있습니다. 메시지 순서 자체가 내용의 일부이므로 `<ol>`을 사용하고, `m(0) p(0)`으로 목록의 마진과 패딩을 제거합니다. 메시지 간격은 각 메시지에 지정되어 있습니다. 앞 메시지와는 12px 간격을 두되, 두 메시지가 같은 쪽에 있으면 4px로 줄여 작성자가 바뀌는 지점이 드러나게 합니다. 좁은 대화 목록에서는 말풍선이 너비의 대부분을 차지하고, 넓은 목록에서는 읽기 편한 너비를 넘지 않습니다.

## 아바타 없는 메시지 \{#without-avatars\}

두 사람의 대화에서는 말풍선이 놓인 쪽만으로도 누가 말하는지 알 수 있습니다. 아바타를 생략하면 말풍선이 행의 시작에 놓입니다.

## 입력 중 표시 \{#typing\}

`message-typing`은 말풍선 안에서 점 세 개가 차례로 위로 움직이는 표시입니다. 보조 기술은 점만으로 의미를 알 수 없으므로, 말풍선에 `role="status"`를 지정하고 “Ada 님이 입력 중입니다”와 같은 레이블을 붙입니다.

## 접근성 \{#accessibility\}

- 대화 목록에는 `<ol>`을 사용합니다. 새 메시지를 `aria-live="polite"` 영역에 넣거나 목록 자체에 `role="log"`를 지정합니다. 그러면 포커스를 옮기지 않고도 새 메시지를 알릴 수 있습니다.
- 색상과 배치 방향 외에도 스크린 리더가 작성자를 식별할 수 있도록 각 메시지에 작성자 이름을 넣습니다. `message-meta`에 이름을 표시하거나 메시지 앞에 화면에서만 숨긴 텍스트로 추가합니다.
- 메시지에 작성자 이름이 없으면 아바타의 `alt`에 작성자 이름을 넣습니다. 메시지에 이름이 있으면 해당 값은 비워 둡니다.
- 동작 줄이기가 활성화되면 입력 중 표시의 점이 움직이지 않습니다. 보낸 말풍선에는 moonstone에서 잉크 색을, obsidian에서 진주색을 사용합니다. 두 테마 모두 텍스트 대비를 온전히 유지합니다.
