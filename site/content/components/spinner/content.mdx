A spinner is a fine ring for work of unknown duration. Its arc fades along its length, so it has a leading end and no hard tail. It takes the current text color, so it reads as ink on moonstone and pearl on obsidian.

## With text \{#with-text\}

When a visible label describes the work, hide the spinner from assistive technology and announce the label instead.

<ComponentPreview name="text" title="With text" html={`<p role="status" class="flex items-center gap-xs m(0) text-sm fg-text-muted">
  <span class="spinner" aria-hidden="true"></span>
  Uploading 3 files…
</p>`} />

## Accessibility \{#accessibility\}

- Give a standalone spinner `role="status"` and an `aria-label`.
- Use `aria-hidden="true"` when nearby text already describes the progress, as in a [busy button](/components/button#busy).
- With reduced motion preferred, the ring turns more slowly.
