A spinner is a fine ring for work of unknown duration. Its arc fades along its length, so it has a leading end and no hard tail. It takes the current text color, so it reads as ink on moonstone and pearl on obsidian.

## With text \{#with-text\}

When a visible label describes the work, hide the spinner from assistive technology and announce the label instead.

<ComponentPreview name="text" height={96} title="With text" background="plain" html={`<p role="status" class="flex items-center gap-xs m(0) text-sm fg-text-muted">
  <span class="spinner" aria-hidden="true"></span>
  Uploading 3 files…
</p>`} />

## Inline \{#inline\}

`spinner-inline` takes the icon size of the control around it, so the spinner of a [busy button](/components/button#busy) is as large as the icons beside it. Where no control sets an icon size it is 1em, as large as the text it stands in.

<ComponentPreview name="inline" height={96} narrowHeight={136} title="Inline" html={`<button type="button" class="btn btn-sm" aria-busy="true">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Saving…
</button>
<p role="status" class="m(0) text-lg fg-text-strong">
  <span class="spinner spinner-inline" aria-hidden="true"></span>
  Checking the domain…
</p>`} />

## Accessibility \{#accessibility\}

- Give a standalone spinner `role="status"` and an `aria-label`.
- Use `aria-hidden="true"` when nearby text already describes the progress, as in a [busy button](/components/button#busy).
- With reduced motion preferred, the ring turns more slowly.
