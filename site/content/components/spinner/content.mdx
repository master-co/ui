## Color \{#color\}

The spinner follows `currentColor`, so a color utility or the surrounding text decides its color.

## With text \{#with-text\}

When a visible label describes the work, hide the spinner from assistive technology and announce the label instead.

<ComponentPreview name="text" title="With text" html={`<p role="status" class="flex items-center gap-xs text-sm fg-text-body">
  <span class="spinner" aria-hidden="true"></span>
  Uploading 3 files…
</p>`} />

## Accessibility \{#accessibility\}

- Give a standalone spinner `role="status"` and an `aria-label`.
- Use `aria-hidden="true"` when nearby text already describes the progress, as in a [busy button](/components/button#busy).
- With reduced motion preferred, the ring turns more slowly.

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--spinner-size` | `1rem` | Diameter |
| `--spinner-width` | `max(1.5px, size / 8)` | Ring thickness |
