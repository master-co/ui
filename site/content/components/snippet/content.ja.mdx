スニペットは、ターミナルで実行する1行のコマンドを、プロンプトとコピーボタン付きで表示します。[コードブロック](/components/code#block)と同じように等幅フォントで表示する[くぼんだ面](/components/surface#well)で、ボタンと同じ高さなので横に並べられます。プロンプトは選択できず、コマンドは折り返しません。コピーボタンは終端から4px内側にあり、ポインターを重ねるまでは控えめに表示されます。

  var status = snippet.querySelector('.snippet-status')
  var timer = 0
  snippet.querySelector('.btn').addEventListener('click', function () {

## コマンド行 \{#line\}

`snippet`は、プロンプト、コマンド、コピーボタンを3列に並べます。`snippet-prompt`は、端末でコマンドの前に表示される`$`や`>`などの記号で、控えめな色で表示します。選択できないため、行を手動で選択してもコマンドだけが選択されます。読み上げの対象から外すため、`aria-hidden`を指定します。`snippet-command`は`<code>`に記述したコマンドです。最後に、控えめな正方形の[ボタン](/components/button)を置きます。ボタンの高さと角丸はスニペットが設定し、上下に4pxずつ余白を取ります。

行に収まらないコマンドは折り返さず、スクロールバーを表示せずに横スクロールできます。続きがある端には、スクロール位置に応じてフェードがかかります。スクロールするまでは先頭側にフェードはかかりません。コマンドに`tabindex="0"`を指定すると、矢印キーでスクロールでき、フォーカスリングは行全体を囲みます。

## コピー \{#copying\}

コピーにはスクリプトが必要です。コマンドのテキストを`navigator.clipboard`に渡します。コピー済みの状態は、クラスではなくボタンの隣にある空の`<output>`（`snippet-status`）で表します。この要素は画面には表示されません。スクリプトが「コピーしました」と書き込むとスクリーンリーダーが読み上げ、2秒後にスクリプトが内容を消去します。内容がある間は、スタイルシートがコピーアイコンをチェックマークに切り替え、画面上でもコピーの完了を伝えます。

プレビューのスクリプトは、表示中のコマンドを取得してクリップボードに書き込み、ステータスにメッセージを入れてから消去します。クリップボードを利用できるのは、HTTPSまたはlocalhostで配信されるページに限られます。スクリプトが無効な場合はボタンが表示されず、コマンドを手動で選択してコピーできます。

## パッケージマネージャー \{#package-managers\}

## スニペットとコードの使い分け \{#snippet-or-code\}

スニペットは、実行する1行のコマンドに使います。複数行のコード、ファイルの内容、出力結果を読ませる場合は[コードブロック](/components/code#block)、文中でコマンドに言及する場合はインラインの[コード](/components/code)を使います。押すキーには[キーボード入力](/components/kbd)を使います。

## アクセシビリティ \{#accessibility\}

- 装飾用のプロンプトには`aria-hidden="true"`を指定し、コマンドだけが読み上げられるようにします。
- コピーボタンには「コマンドをコピー」などの`aria-label`を指定します。アイコンには`aria-hidden`を指定します。
- マークアップでは`snippet-status`を空にし、空白文字も入れないでください。スクリプトが書き込んだ「コピーしました」がここから読み上げられます。`<output>`はそれ自体が優先度 polite のライブリージョンです。
- コマンドに`tabindex="0"`を指定し、行に収まらない場合にキーボードでスクロールできるようにします。
- 強制カラーモードでは、フェードがなくなり、コマンド欄に輪郭が付き、プロンプトにはシステムのグレーのテキスト色が適用されます。
