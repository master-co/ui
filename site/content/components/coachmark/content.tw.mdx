導覽提示是操作導覽中的一個步驟，用一張小卡片指向控制項並說明其用途。它是彈出視窗，因此瀏覽器會將它放在頂層，並把焦點移入其中。CSS 錨點定位會將卡片放在開啟它的元素旁，並以箭頭指向該元素。提示點是個不時向外擴散圓環的小圓點，用來標示頁面上的位置，也是開啟卡片的按鈕。

卡片採用 [sheet-inverse](/components/surface) 的反相配色，在月長石色底上用墨色，在黑曜石色底上用珍珠色，因此能與一般彈出視窗的表面及下方頁面區隔，箭頭也與卡片無縫相接。卡片上的預設[按鈕](/components/button)清楚標示可執行的動作。低調樣式的按鈕沿用卡片的前景色，指標停留時則以該色的淡色調作為底色。

## 結構 \{#anatomy\}

只有標題是必填項目。

| 類別 | 內容 |
| --- | --- |
| `coachmark-count` | 以較低調的前景色顯示導覽進度，例如「第 2 步，共 4 步」，也可顯示「新功能」之類的字樣 |
| `coachmark-title` | 步驟標題。為它設定 id，並用它標示導覽提示 |
| `coachmark-text` | 用一兩句話說明控制項的用途 |
| `coachmark-actions` | 卡片底部的小按鈕。有多個按鈕時，第一個（例如「略過」）靠起始端，其餘（例如「上一步」和「下一步」）靠結束端排列 |

操作按鈕與卡片邊緣相距 12px，讓小按鈕的圓角與卡片圓角相襯。卡片的圓角半徑等於按鈕的圓角半徑加上這段內距。

## 位置 \{#placement\}

導覽提示預設在觸發元素正下方置中開啟，箭頭尖端距離該元素 6px。下方空間不足時，卡片會翻到上方。`coachmark-top` 優先使用上方空間，適合靠近畫面底部的控制項，或像第一個範例那樣把提示點放在控制項的上角。

箭頭會指向標記中緊接在導覽提示前面的元素，因此請把導覽提示放在提示點或所要說明的控制項之後。導覽提示開啟時，該元素會成為具名錨點，箭頭會對準其中央。即使檢視區邊緣把卡片推向一旁，箭頭也會維持對準，同時避開卡片的圓角。卡片翻轉時，箭頭會移到另一側。和操作導覽一樣，一次只會開啟一則導覽提示。

## 提示點 \{#beacon\}

`coachmark-beacon` 是按鈕上直徑 10px 的圓點，外框沿用所在表面的顏色，操作目標尺寸為 24px，在觸控螢幕上為 44px。它透過 `popovertarget` 開啟對應的導覽提示，並需要用 `aria-label` 說明會開啟什麼。提示點的位置由頁面決定。可在 `relative` 包裝元素內使用 `absolute` utility，將提示點放在控制項的上角，也可將兩者並排。

提示點以向外擴散的圓環吸引注意。指標停在提示點上、提示點取得焦點、對應的導覽提示開啟，或使用者偏好減少動態效果時，圓環會維持為靜止的光暈。使用者看過該步驟後，請移除提示點。

## 操作導覽 \{#tour\}

操作導覽會依序開啟數則導覽提示。為每個步驟設定 `popover="manual"`，讓使用者點擊頁面（例如試用箭頭指向的控制項）時仍能繼續導覽。用一小段腳本切換步驟。`showPopover({ source })` 會以步驟前方的元素為錨點開啟該步驟，各步驟的操作按鈕則呼叫它開啟下一步或上一步。手動彈出視窗需要由腳本處理 <kbd>Esc</kbd>，關閉視窗後再將焦點移回導覽的起點。

## 無障礙 \{#accessibility\}

- 為導覽提示設定 `role="dialog"`，並透過 `aria-labelledby` 以其標題作為名稱。這是非模態對話框，使用者仍可操作周圍的頁面。
- 在主要操作按鈕上加上 `autofocus`，讓卡片開啟時焦點移入其中，使用者便可按 <kbd>Enter</kbd> 繼續。
- 每個步驟都應能退出，可透過「略過」或「完成」按鈕，也可按 <kbd>Esc</kbd>。單則導覽提示還可透過點擊外部關閉。
- 導覽中的所有資訊都應能從其他地方取得，讓略過導覽的使用者也能找到完整資訊。
- 在標記中將導覽提示緊接在提示點之後，這樣無論卡片顯示在哪裡，Tab 鍵都會在提示點之後進入導覽提示。

## 瀏覽器支援 \{#browser-support\}

導覽提示使用 CSS 錨點定位。卡片的位置由 `position-area` 和 `position-try-fallbacks` 決定，箭頭則使用 `anchor()` 相對於卡片與所指向的元素定位。瀏覽器若不支援錨點定位，導覽提示仍可開關，會依瀏覽器的彈出視窗預設位置在檢視區置中顯示，並省略箭頭。`showPopover()` 的 `source` 選項為導覽步驟指定錨點。未提供此選項時，步驟會在沒有錨點的情況下開啟。淡入與短距離滑動使用 `@starting-style`，缺少支援時卡片會立即出現或消失。

卡片進場時會淡入並朝錨點滑動 4px，退場時則以較短的時間淡出。卡片維持原尺寸，因為套用其他彈出視窗的縮放效果會把箭頭縮進卡片範圍內，使箭頭無法伸向所指的元素。
