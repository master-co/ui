ツールバーは、控えめなスタイルのコントロールを横一列に並べる、小さな浮き上がった面です。内側の余白は 4px で、ツールバーの角丸半径は小型コントロールの角丸半径にこの余白を足した値です。小型で控えめなスタイルの[ボタン](/components/button)、[セレクト](/components/select)、[セグメントコントロール](/components/segmented)を置くと、角丸の中心が揃います。高さ 32px のコントロールを収めたツールバーの高さは 40px です。

## ツールバー内の状態 \{#state-in-a-toolbar\}

控えめなスタイルのボタンは、通常時は背景が透明で、ツールバーの面がそのまま見えます。ポインターを重ねるとボタン自体の面が浮き上がり、押下中や `aria-pressed="true"` を指定した状態ではくぼんで見えます。ツールバーでは、くぼみ、平らな面、浮き上がった面という[状態の順序](/guide/theme#principles)を見比べやすくなります。

## Tab キーの移動先は 1 か所 \{#keys\}

ツールバーは、Tab キーの移動順序の中で 1 か所として扱われます。<kbd class="kbd">Tab</kbd> キーを押すと、最後にフォーカスしていたコントロールからツールバーに入り、もう一度押すとツールバーから出ます。コントロール間は矢印キーで移動します。`focusgroup="toolbar wrap"` を指定すると、[focusgroup](https://open-ui.org/components/scoped-focusgroup.explainer/) に対応したブラウザーでは、ブラウザー自身がこの動作を行います。それ以外のブラウザーでは、`toolbar` の[ビヘイビア](/guide/behaviors)が 1 つのコントロールだけを `tabindex="0"` に保って同じ動作を行います。ブラウザーが対応している場合、ビヘイビアは何もしません。

```js name=app.js
import { toolbar } from '@master/ui/behaviors/toolbar.js'

const detach = toolbar(document.querySelector('.toolbar'))
```

- **移動**　<kbd class="kbd">ArrowRight</kbd> と <kbd class="kbd">ArrowLeft</kbd> で、読む方向に従ってツールバー内を移動します。端では反対側に回ります。<kbd class="kbd">Home</kbd> と <kbd class="kbd">End</kbd> で最初と最後のコントロールに移動します。無効なコントロールはスキップされます。`aria-disabled="true"` を指定したコントロールは、ツールバーのコントロールに求められるとおり移動先に残り、クリックは止められます。
- **トグル**　`aria-pressed` を持つボタンは、クリックすると押した状態が切り替わり、`false` が `true` に、`true` が `false` になります。`aria-pressed` を持たないボタンはアクションで、状態を保持しません。
- **独自のキー操作を持つコントロール**　[セグメントコントロール](/components/segmented)やその他のネイティブのラジオグループは、チェックされているラジオボタンを代表とする 1 つのコントロールとして数えます。矢印キーでグループの外に移動し、<kbd class="kbd">Space</kbd> でフォーカスしているラジオボタンを選びます。セレクトとテキストフィールドは、それ自身の矢印キー操作を保ちます。

focusgroup とビヘイビアのどちらもない場合は、すべてのコントロールが Tab キーの移動先になります。操作はできますが、移動に手間がかかります。

## 縦配置 \{#vertical\}

`aria-orientation="vertical"` を指定すると、コントロールがキャンバスの横に縦一列に並び、区切り線は水平になります。コントロール間は <kbd class="kbd">ArrowDown</kbd> と <kbd class="kbd">ArrowUp</kbd> で移動します。`focusgroup="toolbar wrap block"` を指定します。

## フローティング \{#floating\}

`toolbar-floating` を指定すると、ツールバーがフローティングサーフェスに切り替わります。選択時のツールバーやエディターのコントロールなど、コンテンツに重ねるツールに使います。

## アクセシビリティ \{#accessibility\}

- コンテナーに `role="toolbar"` とラベルを指定します。エディターやキャンバスなど、ほかの対象を操作するコントロールにだけ使います。ナビゲーションには[ナビゲーションバー](/components/navbar)を使います。
- アイコンだけのボタンには `aria-label` で名前を付け、トグルボタンの状態は `aria-pressed` で伝えます。押した状態に応じてラベルを変えないでください。
- コントロールを無効にするときは、`disabled` ではなく `aria-disabled="true"` を使います。矢印キーで移動でき、利用できない理由を伝えられます。
