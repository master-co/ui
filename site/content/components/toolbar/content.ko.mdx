## 도구 모음의 상태 \{#state-in-a-toolbar\}

기본 상태에서 눈에 띄지 않는 버튼은 자체 표면이 없어 도구 모음의 표면이 그대로 보입니다. 포인터를 올리면 버튼 자체의 표면이 솟아오르고, 버튼을 누르거나 `aria-pressed="true"`를 지정하면 버튼이 오목한 영역으로 들어갑니다. 도구 모음에서는 오목한 영역, 기본 표면, 솟은 표면으로 이어지는 [상태 순서](/guide/theme#principles)를 가장 쉽게 볼 수 있습니다.

## 탭 포커스 \{#keys\}

도구 모음 전체가 탭 순서에서 한 항목을 차지합니다. <kbd class="kbd">Tab</kbd> 키를 누르면 마지막으로 포커스를 받은 컨트롤로 도구 모음에 들어가고, 다시 누르면 도구 모음을 벗어납니다. 도구 모음 안의 컨트롤 사이는 방향키로 이동합니다. `focusgroup="toolbar wrap"`을 지정하면 [focusgroup](https://open-ui.org/components/scoped-focusgroup.explainer/)을 지원하는 브라우저에서는 브라우저가 직접 이 동작을 처리합니다. 그 밖의 브라우저에서는 `toolbar` [동작](/guide/behaviors)이 컨트롤 하나만 `tabindex="0"`으로 유지하며 같은 동작을 구현하고, 브라우저가 focusgroup을 지원하면 관여하지 않습니다.

```js name=app.js
import { toolbar } from '@master/ui/behaviors/toolbar.js'

const detach = toolbar(document.querySelector('.toolbar'))
```

- **이동.** <kbd class="kbd">ArrowRight</kbd>와 <kbd class="kbd">ArrowLeft</kbd> 키는 읽기 방향을 따라 도구 모음 안을 이동하며, 양 끝에서는 반대쪽 끝으로 돌아갑니다. <kbd class="kbd">Home</kbd>과 <kbd class="kbd">End</kbd> 키는 첫 번째와 마지막 컨트롤로 이동합니다. 비활성화된 컨트롤은 건너뜁니다. `aria-disabled="true"`를 지정한 컨트롤은 도구 모음의 컨트롤답게 포커스를 받을 수 있지만, 클릭은 차단됩니다.
- **토글.** `aria-pressed`가 있는 버튼은 클릭하면 눌림 상태가 바뀝니다. `false`는 `true`로, `true`는 다시 `false`로 바뀝니다. `aria-pressed`가 없는 버튼은 작업 버튼이며 상태를 유지하지 않습니다.
- **자체 키 조작이 있는 컨트롤.** [세그먼트 컨트롤](/components/segmented)이나 그 밖의 네이티브 라디오 그룹은 선택된 라디오 버튼을 대표로 하는 컨트롤 하나로 취급합니다. 방향키를 누르면 그룹을 벗어나고, <kbd class="kbd">Space</kbd> 키는 포커스를 받은 라디오 버튼을 선택합니다. 셀렉트와 텍스트 필드는 방향키를 자체적으로 처리합니다.

두 방법 모두 사용하지 않으면 각 컨트롤이 탭 순서에 개별적으로 포함됩니다. 사용은 가능하지만 이동에 시간이 더 걸립니다.

## 접근성 \{#accessibility\}

- 컨테이너에 `role="toolbar"`와 레이블을 지정하세요. 편집기나 캔버스처럼 다른 대상에 작용하는 컨트롤에만 사용하고, 내비게이션에는 [내비게이션 바](/components/navbar)를 사용하세요.
- 아이콘만 있는 버튼에는 `aria-label`로 접근 가능한 이름을 지정하고, 토글 버튼의 상태는 `aria-pressed`로 전달하세요. 버튼을 누를 때 레이블은 바꾸지 마세요.
- 컨트롤을 비활성화할 때는 `disabled` 대신 `aria-disabled="true"`를 사용하세요. 그러면 방향키로 계속 컨트롤에 도달할 수 있고, 사용할 수 없는 이유도 알려 줄 수 있습니다.

## React, Svelte, Vue \{#frameworks\}

`toolbar` 컴포넌트는 역할, 레이블, `focusgroup`을 지정한 루트 요소를 렌더링하고, 페이지에 있는 동안 동작을 연결합니다. 그 안에 넣는 컨트롤은 직접 작성합니다. `npx master-ui add toolbar` 명령을 실행해 프로젝트에 복사하세요. 컴포넌트의 구성과 사용 방법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
