工具栏是一块小型凸起面板，容纳一排低调的控件。工具栏留出 4px 内边距，其圆角半径等于小号控件的圆角半径加上这段内边距，使小号低调样式的[按钮](/components/button)、[下拉选择框](/components/select)和[分段控件](/components/segmented)的圆角与工具栏圆角同心。工具栏高 40px，内部控件高 32px。

## 工具栏中的控件状态 \{#state-in-a-toolbar\}

低调样式的按钮默认没有自己的表面材质，因此会透出工具栏的面板。指针悬停时，按钮自身凸起成一块面板；按下或带有 `aria-pressed="true"` 时，按钮沉入凹槽。在工具栏中最容易看清[状态的层次顺序](/guide/theme#principles)：凹槽、面板、凸起。

## 在 Tab 顺序中只占一处 \{#keys\}

工具栏在 Tab 顺序中只占一处：按 <kbd class="kbd">Tab</kbd> 键进入工具栏时，焦点落在上次聚焦的控件上，再按一次即离开工具栏；在工具栏内部用方向键在控件之间移动。为工具栏设置 `focusgroup="toolbar wrap"`，浏览器支持 [focusgroup](https://open-ui.org/components/scoped-focusgroup.explainer/) 时会自行实现这些操作。在其他浏览器中，由 `toolbar` [行为脚本](/guide/behaviors)实现：它让一个控件保持 `tabindex="0"`；浏览器支持 focusgroup 时，行为脚本则不介入。

```js name=app.js
import { toolbar } from '@master/ui/behaviors/toolbar.js'

const detach = toolbar(document.querySelector('.toolbar'))
```

- **移动。** <kbd class="kbd">ArrowRight</kbd> 和 <kbd class="kbd">ArrowLeft</kbd> 沿工具栏移动，到达首尾时循环，并遵循文字的阅读方向；<kbd class="kbd">Home</kbd> 和 <kbd class="kbd">End</kbd> 移到第一个和最后一个控件。禁用的控件会被跳过。带有 `aria-disabled="true"` 的控件仍可通过方向键到达（工具栏中的控件理应如此），但其点击会被阻止。
- **切换按钮。** 带有 `aria-pressed` 的按钮在点击时切换按下状态：`false` 变为 `true`，再点击则变回。不带该属性的按钮是操作按钮，不保留状态。
- **自带按键操作的控件。** [分段控件](/components/segmented)或其他原生单选按钮组算作一个控件，即其中已选中的单选按钮：方向键会离开该控件，按 <kbd class="kbd">空格键</kbd> 选中当前聚焦的单选按钮。下拉选择框和文本输入框保留各自的方向键操作。

浏览器既不支持 focusgroup、页面也未启用工具栏行为脚本时，按 Tab 键会逐个聚焦控件，仍然可用，只是操作更慢。

## 无障碍 \{#accessibility\}

- 为容器设置 `role="toolbar"`，并提供标签。只将它用于作用于其他对象的控件，例如编辑器或画布中的工具；导航请使用[导航栏](/components/navbar)。
- 用 `aria-label` 为仅含图标的按钮提供无障碍名称，用 `aria-pressed` 表明切换按钮的状态，按下时不要更改按钮的标签。
- 使用 `aria-disabled="true"` 而不是 `disabled` 来禁用控件，这样方向键仍能到达该控件，控件也能说明为什么不可用。
