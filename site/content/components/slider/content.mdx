A slider picks a value from a range where the position matters more than the exact number: volume, opacity, zoom. Use `.slider` on a native `<input type="range">`. The browser keeps the keys, the form value and touch dragging; the class draws a thin well and the same pearl thumb a [switch](/components/switch) has.

  Volume
  <input type="range" class="slider" value="60">
</label>`} />

## The fill \{#the-fill\}

The part of the track before the thumb fills with ink, without script. Firefox draws it natively. Elsewhere the stylesheet reads the thumb's position with a scroll-driven animation: the input is the scroll container the thumb is measured in, a view timeline on the thumb reports how far along it is, and the track paints up to that point. Where neither exists the track stays an empty well and the thumb still shows the value.

## Accessibility \{#accessibility\}

- Label the slider with a `field` label or `aria-label`.
- A slider does not show its number. When the exact value matters, show it beside the slider or use an [input](/components/input) with `type="number"`.
- On touch screens the thumb grows to 24px.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `slider` | A range input: a well with a pearl thumb |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--slider-track` | `.375rem` | Track thickness |
| `--slider-thumb` | `1.125rem` | Thumb diameter |
| `--slider-color` | `var(--color-surface-inverse)` | Fill color |
