강조 표시는 검색어와 일치하는 결과의 일부나 검토자가 짚은 구절처럼 눈여겨볼 말에 형광펜을 칠한 듯한 효과를 줍니다. 특정 색조 대신 잉크 색을 옅게 깔아 어느 표면에서든 글자가 잘 읽히고 상태 색상도 묻히지 않습니다. 기본 HTML 요소인 `<mark>`에 `.mark` 클래스를 적용합니다.

[리스트박스](/components/listbox), [콤보박스](/components/combobox) 또는 [명령 팔레트](/components/command)에서는 사용자가 입력할 때 각 옵션에서 입력 내용과 일치하는 부분을 강조 표시로 감싸세요.

## 현재 일치 항목 \{#current\}

페이지 내 찾기처럼 사용자가 일치 항목을 하나씩 이동하며 확인할 때는 현재 항목에 `aria-current="true"`를 설정합니다. 해당 항목의 배경이 잉크 색으로 채워집니다.

<ComponentPreview name="current" height={144} narrowHeight={184} title="현재 일치 항목" background="plain" bodyClass="p-lg" html={`<p class="m(0) max-w(420) text-sm leading-md fg-text-body">Corners nest by their <mark class="mark">inset</mark>: a container's radius is its content's radius plus the <mark class="mark" aria-current="true">inset</mark> between them, so the gap keeps one width around the bend. A button 4px inside a well takes the well's radius minus that <mark class="mark">inset</mark>.</p>`} />

## 브랜드 색상과 밑줄 \{#brand-and-underline\}

`mark-brand`는 페이지의 주제를 담은 한 구절에 [브랜드 색상](/guide/theme#status-and-brand)을 옅게 입힙니다. `mark-underline`은 글자 위를 덮는 대신 글자 아래를 따라 굵은 밑줄을 긋습니다. 브라우저는 이 선을 글자 뒤에 그리고 줄이 바뀌어도 이어서 표시합니다.

## 접근성 \{#accessibility\}

- `<mark>` 요소는 ‘이 맥락과 관련 있음’을 뜻합니다. 중요성을 나타내려면 `<strong>`을 사용하세요. 대부분의 스크린 리더는 강조 표시 여부를 알려 주지 않으므로, 강조 표시 없이도 결과의 의미를 알 수 있어야 합니다.
- 강조 표시는 기존 텍스트 색상을 유지하고 배경에 약 10% 농도로 잉크 색을 깔기 때문에 대비가 달라지지 않습니다. 강제 색상 모드에서는 시스템 색상인 `Mark`와 `MarkText`를 사용합니다.
- 강조 표시가 여러 줄에 걸쳐도 각 줄의 패딩과 모서리 모양이 유지됩니다.
