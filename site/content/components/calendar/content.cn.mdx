日历按月显示可供选择的日期：可以选择一天、一个[日期范围](#range)或[多个日期](#several-days)，可以显示一个月，也可以[并排显示两个月](#several-months)。它是由按钮组成的 ARIA 网格，样式表负责呈现所有状态，`calendar` [行为脚本](/guide/behaviors)负责生成日期、处理月份切换按钮和方向键。日历本身没有表面，可以放在[卡片](/components/card)中，也可以放在[弹出层](/components/popover)中组成日期选择器。

标记由标题区和空网格组成。行为脚本将月份名称写入 `calendar-title`，将星期名称和各周的日期写入 `calendar-grid`，初始显示今天所在的月份。没有脚本时，网格会保留标记中的内容。如果日历需要在脚本运行前就可读，可参照下方[日期范围](#range)示例，在服务端渲染各周的日期，行为脚本挂载时会替换这些内容。

## 月份和年份 \{#months-and-years\}

上方日历的标题是一个按钮，即 `calendar-title` 中的 `calendar-title-button`。点击它，网格会变为当年的十二个月；再次点击，网格会变为该十年中的各个年份，前一年和后一年以弱化的墨色显示。选择某一年会显示它的各个月份，选择某个月会显示它的日期，焦点落在同一天上。按 <kbd>Escape</kbd> 会回到原来的日期视图。

月份和年份都是同一网格中的 `calendar-period` 按钮，每行三个，与日期按钮使用相同的材质。网格保持六周月份的高度，因此日历不会跳动。标题始终表明网格所处的位置：`November 2026`、`2026`、`2020 – 2029`。在月份视图中，月份切换按钮按年翻页；在年份视图中，按十年翻页；按钮在这两种视图中的名称取自 `labels` 选项。在年份视图中，标题按钮处于禁用状态，因为十年已是最上一级。

没有按钮的标题仍是普通标题，日历始终停留在日期视图。这种跳转适用于只显示一个月的日历。

另一种做法是在标题区放置原生的月份和年份下拉选择框，但未被采用：在部分语言中，两个下拉选择框加上两个月份切换按钮无法放进七个 36px 的列宽；一百年的列表在下拉选择框中需要长时间滚动；而可自定义样式的下拉选择框列表尚未得到所有浏览器的支持。月份和年份网格使用日历自身的材质，并沿用读者正在使用的按键。

## 状态 \{#states\}

每种状态都由日期按钮上的属性或类名表示。行为脚本会设置这些属性和类名，手写标记或服务端渲染时也使用同一套属性和类名。

| 状态 | 标记方式 | 显示效果 |
| --- | --- | --- |
| 今天 | `aria-current="date"` | 数字下方显示圆点 |
| 已选中 | `aria-selected="true"` | 用墨色填充，与选中的[复选框](/components/checkbox)相同 |
| 非本月日期 | `calendar-day-outside` | 数字使用弱化的墨色 |
| 不可选 | `disabled` | 数字使用禁用状态的墨色 |

跳转视图中的月份或年份带有同样的标记：今天所在的月份或年份带有 `aria-current="date"`，包含已选日期的月份或年份带有 `aria-selected="true"`，在 `min` 和 `max` 之间没有任何日期的带有 `disabled`。`calendar-period-outside` 标记十年前后的那一年。

日期按钮会像[菜单](/components/menu)中的条目一样立即响应指针操作。今天被选中时仍保留圆点，圆点与日期数字使用相同的墨色。

## 日期范围 \{#range\}

日期范围的起止日期用墨色填充，中间以胶囊标签色调的色带相连。起始日期使用 `calendar-day-range-start`，结束日期使用 `calendar-day-range-end`，中间的日期使用 `calendar-day-range`。范围内的所有日期都使用 `aria-selected="true"`。

- 列之间没有间距，色带可以跨单元格连续延伸。行之间保留 2px 间距，每周各有一条独立的色带。

## 多个日期 \{#several-days\}

## 行为脚本 \{#behavior\}

`calendar` 接收根元素和选项对象，并返回用于解除挂载的函数。

```js name=app.js
import { calendar } from '@master/ui/behaviors/calendar.js'

const root = document.querySelector('.calendar')
const picker = calendar(root, { value: '2026-11-04', min: '2026-11-01', max: '2026-12-31' })

root.addEventListener('change', (event) => console.log(event.detail.value))
```

| 选项 | 设置内容 |
| --- | --- |
| `value` | `YYYY-MM-DD` 格式的选中日期、日期范围的起止日期，或通过 `multiple` 选中的各个日期 |
| `month` | 初始显示的月份，格式为 `YYYY-MM`。默认显示所选值所在的月份，未设置值时显示今天所在的月份 |
| `min`, `max` | 可选的最早和最晚日期，格式为 `YYYY-MM-DD`。某个方向没有可切换的月份时，对应的月份切换按钮会禁用 |
| `range` | 用 `true` 选择两个日期及其间的所有日期 |
| `multiple` | 用 `true` 选择任意数量的不连续日期；与 `range` 同时启用时以 `range` 为准 |
| `labels` | 月份视图和年份视图中月份切换按钮的名称：`previousYear`、`nextYear`、`previousDecade`、`nextDecade`。默认为英文 |
| `weekStart` | 第一列对应的星期几，0 表示星期日，6 表示星期六。默认遵循区域设置，浏览器无法确定时使用星期一 |
| `locale` | 用于显示月份和星期名称的 BCP 47 标签。默认取日历所在范围的 `lang` |
| `disabled` | 接收 `Date` 并判断该日期是否不可选的函数 |
| `draw` | 代替脚本生成各网格的函数。调用时传入以 `YYYY-MM` 表示的要显示的月份，以及视图：`days`、`months` 或 `years`。在日期视图中，它写入该月份，并在后续网格中写入之后的各月，每个月份由 `calendarMonth(month, { offset })` 提供。在月份或年份视图中，它写入 `calendarPeriods(month, { view })` 提供的单元格。参见[自定义网格](/guide/behaviors#a-grid-of-your-own) |

- **脚本写入的内容。** 脚本写入星期名称、所显示的每个月的各周以及各月名称；在跳转视图中，写入月份或年份以及对应的标题。对日期按钮，脚本将日期写入 `value`，给今天加上 `aria-current="date"`，给选中的日期加上 `aria-selected="true"` 和范围类名，给不可选的日期加上 `disabled`，用 `aria-label` 提供完整日期，并通过 `tabindex` 让一个日期进入 Tab 键导航顺序。使用 `draw` 时，由模板或框架生成日期，脚本只为这些日期添加标记。
- **事件。** 选择日期时，根元素会派发可冒泡的 `change` 事件，并通过 `detail.value` 携带所选值。单个日期以 `YYYY-MM-DD` 表示，选定范围的两端后以 `[start, end]` 表示，启用 `multiple` 时则为排序后的日期列表。跳转到月份或年份视图时不会派发事件。
- **值。** 值保存在脚本中，不写入标记。通过返回函数的 `value` 读取，例如 `picker.value`。选择范围时，终点选定前为 `null`；启用 `multiple` 时，未选任何日期则为 `[]`。也可以从外部设置这个值来选择日期。`picker.value = '2026-11-20'` 会显示新日期所在的月份，且不会派发事件。
- **日期。** 日期采用本地时区和公历。

## 结构 \{#structure\}

- `calendar-grid` 统一声明七列。每个 `calendar-week` 占一行，并使用这七列的子网格，因此无需表格即可让星期名称和日期按列对齐。
- `calendar-weekday` 是列标题，其 `aria-label` 为完整的星期名称。
- `calendar-day` 是带有 `role="gridcell"` 的 `<button>`。
- `calendar-title-button` 在标题带有按钮时出现，是 `calendar-title` 中的 `<button>`，行为脚本将标题写入其中。
- `calendar-period` 是跳转视图中的月份或年份：带有 `role="gridcell"` 的 `<button>`，值为 `YYYY-MM` 或 `YYYY`，每个 `calendar-week` 中放三个。
- `calendar-month` 在显示多个月时容纳其中一个月的标题区和网格。

## 键盘操作 \{#keyboard\}

行为脚本为网格提供日期网格的键盘操作。焦点移出当前月份时，日历会显示相邻月份，并将焦点保持在移到的日期上。移动时会跳过不可选的日期，并在 `min` 和 `max` 处停止。在月份和年份视图中，方向键每次移动一格或一行（三格），按 <kbd>Enter</kbd> 选择后回到下一级视图。

## 无障碍 \{#accessibility\}

- 网格为 `role="grid"`，以月份标题作为无障碍名称。每周为 `role="row"`。
- Tab 键导航顺序中只有一个日期，优先使用选中的日期（选中多个时取第一个），其次使用今天。如果所显示的月份两者都没有，则使用这些月份的第一天。其余日期均带有 `tabindex="-1"`。并排显示的多个月份共用一个 Tab 键停靠点，每个网格以各自的标题作为无障碍名称。
- 可以选择日期范围或多个日期的网格带有 `aria-multiselectable="true"`。
- 标题按钮以其显示的标题命名，该标题同时也是网格的无障碍名称。请用 `aria-description` 说明按钮的作用，例如“Choose a month or a year”，而不要用 `aria-label`，否则网格的名称也会随之改变。
- 为标题添加 `aria-live="polite"`，以便在切换月份时播报。
- 在触摸屏上，日期按钮的尺寸为 44px。

## React、Svelte 和 Vue \{#frameworks\}

`calendar` 组件使用与行为脚本相同的数据渲染月份，使月份内容出现在初始 HTML 中，并支持传入和传出所选日期。它接受 `range` 和 `multiple`，用 `months` 并排显示多个月，只显示一个月时带有标题按钮；`jumpLabel` 是该按钮的描述，`labels` 是月份视图和年份视图中月份切换按钮的名称。使用 `npx master-ui add calendar` 将组件复制到项目中，参见 [React、Svelte 和 Vue](/guide/frameworks) 了解这些组件的实现和用法。
