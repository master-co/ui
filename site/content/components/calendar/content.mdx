A calendar is a month of days to pick from. It is an ARIA grid of buttons: the stylesheet draws every state, and the script that fills it supplies the dates, the month buttons and the arrow keys. It has no surface of its own, so it sits in a [card](/components/card), or in a [popover](/components/popover) to make a date picker.

## States \{#states\}

Every state is an attribute or a class on the day's button.

| State | Mark it with | Drawn as |
| --- | --- | --- |
| Today | `aria-current="date"` | A dot under the number |
| Chosen | `aria-selected="true"` | Ink, the way a checked [checkbox](/components/checkbox) fills |
| Outside the month | `calendar-day-outside` | Muted ink |
| Unavailable | `disabled` | Disabled ink |

A day answers the pointer at once, like a row in a [menu](/components/menu). Today keeps its dot when it is chosen, in the ink of the day.

A range is two ink days joined by a chip-toned band. Mark the first day `calendar-day-range-start`, the last `calendar-day-range-end` and the days between `calendar-day-range`. All of them are `aria-selected="true"`.

The band is drawn so it reads as one shape:

- Columns have no gap, so the band runs from cell to cell. Rows keep 2px apart, so each week is its own band.
- The band rounds where a week ends and the range goes on.
- At each end the band covers the half of the cell that faces the range, and the ink day sits on it as a layer of its own. The band therefore meets the day's middle, not its rounded edge.

## Structure \{#structure\}

- `calendar-grid` declares seven columns once. Each `calendar-week` is a row on a subgrid of them, so the weekday names and the days share the same columns without a table.
- `calendar-weekday` is a column heading. Give it the full name as `aria-label`.
- `calendar-day` is a `<button>` with `role="gridcell"`.

## Accessibility \{#accessibility\}

- The grid is `role="grid"`, labelled by the month's title; each week is `role="row"`.
- One day is in the tab order, the chosen one or today; the rest have `tabindex="-1"`, and the script moves focus with the arrow keys, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>Page Up</kbd> and <kbd>Page Down</kbd>.
- Give the title `aria-live="polite"`, so a change of month is announced.
- On touch screens a day is 44px.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `calendar` | The month |
| `calendar-header`, `calendar-title` | Previous, the month's name, next |
| `calendar-grid` | The seven-column grid |
| `calendar-week` | A row: the weekday names, or a week |
| `calendar-weekday` | A column heading |
| `calendar-day` | A day, on a `<button>` |
| `calendar-day-outside` | A day of the month before or after |
| `calendar-day-range-start`, `calendar-day-range`, `calendar-day-range-end` | The ends of a range and the days between |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--calendar-cell` | `2.25rem` | Width and height of a day |
| `--calendar-day-radius` | `var(--radius-control-sm)` | Corner of a day |
