カレンダーは、1 か月分の日付から選択するためのコンポーネントです。ボタンを並べた ARIA グリッドで、各状態の見た目はスタイルシートが担い、日付の生成、月の切り替えボタン、矢印キーの操作は `calendar` の [ビヘイビア](/guide/behaviors) が担います。カレンダー自体に背景面はありません。[カード](/components/card) に配置したり、[ポップオーバー](/components/popover) に配置して日付ピッカーにしたりできます。

マークアップはヘッダーと空のグリッドで構成します。ビヘイビアは月名を `calendar-title` に、曜日名と週ごとの日付を `calendar-grid` に書き込み、初期表示には今月を使います。スクリプトが動作するまではグリッドのマークアップがそのまま表示されます。実行前から日付を表示する必要がある場合は、下の [期間](#range) の例のように、週ごとの日付を含めてサーバーでレンダリングします。ビヘイビアが適用されると、グリッドの内容が置き換わります。

## 状態 \{#states\}

各状態は、日付ボタンの属性またはクラスで表します。ビヘイビアがこれらを設定します。手書きやサーバー生成のマークアップでも同じ属性とクラスを指定します。

| 状態 | 属性・クラス | 表示 |
| --- | --- | --- |
| 今日 | `aria-current="date"` | 数字の下にドット |
| 選択済み | `aria-selected="true"` | 選択済みの [チェックボックス](/components/checkbox) と同じインク色の塗りつぶし |
| 表示月の範囲外 | `calendar-day-outside` | 控えめな文字色 |
| 選択不可 | `disabled` | 無効状態の文字色 |

日付ボタンは、[メニュー](/components/menu) の項目と同じように、ポインターを重ねるとすぐに反応します。今日の日付を選択したときもドットは残り、その日付の文字色に揃います。

## 期間 \{#range\}

期間の始点と終点をインク色で塗りつぶし、チップと同系色の帯でつなぎます。開始日には `calendar-day-range-start`、終了日には `calendar-day-range-end`、その間の日付には `calendar-day-range` を指定します。期間内のすべての日付に `aria-selected="true"` を指定します。

このプレビューはマークアップだけで構成し、スクリプトは適用していません。「コード」ビューでは、ビヘイビアが生成する形式の 1 か月分のマークアップと、期間、今日、選択できない 2 つの日付の指定を確認できます。

## 日付ピッカー \{#date-picker\}

日付ピッカーは、入力フィールド、ボタン、[ポップオーバー](/components/popover) 内のカレンダーで構成します。ポップオーバーはスクリプトなしで開閉し、ボタンに接する位置に自動で配置されます。ビヘイビアはカレンダーを描画し、選択された日付を通知します。ページ側のスクリプトはその日付をフィールドに書き込み、ポップオーバーを閉じます。

カレンダーの `change` イベントはバブリングするため、リスナーはポップオーバーに登録します。イベントの `detail.value` には `YYYY-MM-DD` 形式の日付が入ります。これはフォームが日付の値として受け取る形式と同じです。

スマートフォンで使う場合や、フォームで日付を入力できれば十分な場合は、ネイティブの [`<input type="date">`](/components/input#date-time-and-color) を使うと、端末標準の日付ピッカーを利用できます。

## ビヘイビア \{#behavior\}

`calendar` はルート要素とオプションオブジェクトを受け取り、ビヘイビアの適用を解除する関数を返します。

```js name=app.js
import { calendar } from '@master/ui/behaviors/calendar.js'

const root = document.querySelector('.calendar')
const picker = calendar(root, { value: '2026-11-04', min: '2026-11-01', max: '2026-12-31' })

root.addEventListener('change', (event) => console.log(event.detail.value))
```

| オプション | 設定内容 |
| --- | --- |
| `value` | `YYYY-MM-DD` 形式の選択日、または期間の開始日と終了日 |
| `month` | 最初に表示する月を `YYYY-MM` 形式で指定。既定は値が属する月、値がなければ今月 |
| `min`, `max` | 選択可能な最初と最後の日付を `YYYY-MM-DD` 形式で指定。移動先の月がなければ、対応する月切り替えボタンは無効 |
| `range` | `true` を指定すると、2 つの日付を選んで、その間のすべての日付を含む期間を選択できます。 |
| `weekStart` | 最初の列の曜日。日曜の 0 から土曜の 6 まで。既定はロケールの週の開始曜日で、ブラウザーから取得できない場合は月曜 |
| `locale` | 月名と曜日名に使う BCP 47 言語タグ。既定はカレンダーに適用される `lang` 属性の値 |
| `disabled` | `Date` を受け取り、その日付が選択不可かどうかを返す関数 |
| `draw` | スクリプトに代わってグリッドを生成する関数。表示する月が `YYYY-MM` 形式で渡されます。[独自のグリッド](/guide/behaviors#a-grid-of-your-own) を参照してください。 |

- **生成する内容。** 曜日名、表示月の週ごとの日付、月名を書き込みます。日付ボタンでは、`value` に日付を設定し、今日には `aria-current="date"`、選択された日付には `aria-selected="true"` と期間用のクラス、選択できない日付には `disabled` を設定します。さらに、`aria-label` に完全な日付を指定し、`tabindex` でタブ順に含まれる日付を 1 つに絞ります。`draw` を指定した場合は、テンプレートやフレームワークが日付ボタンを生成し、スクリプトは状態などの属性やクラスだけを設定します。
- **イベント。** 日付を選択すると、ルートからバブリングする `change` が発行されます。イベントの `detail.value` には、選んだ日付が `YYYY-MM-DD` 形式で入ります。期間の両端を選択すると `[start, end]` が入ります。
- **値。** 値の保持先はスクリプト内です。返された関数の `value` から、`picker.value` のように読み取ります。期間の終了日は、選択されるまで `null` です。外部から選択を変更するには値を設定します。`picker.value = '2026-11-20'` は新しく選んだ日付が属する月を表示し、イベントは発行しません。
- **日付。** ローカルのタイムゾーンとグレゴリオ暦に従います。

## 構造 \{#structure\}

- `calendar-grid` で 7 列を一度だけ定義します。各 `calendar-week` はその列を引き継ぐサブグリッド上の行なので、テーブルを使わずに曜日名と日付の列を揃えられます。
- `calendar-weekday` は列見出しです。`aria-label` には省略していない曜日名を指定します。
- `calendar-day` は、`role="gridcell"` を持つ `<button>` です。

## キーボード操作 \{#keyboard\}

ビヘイビアは、日付グリッドのキーボード操作を提供します。月の境界を越えて移動すると、隣の月が表示され、移動先の日付にフォーカスが移ります。選択できない日付は飛ばし、`min` と `max` の境界で移動が止まります。

## アクセシビリティ \{#accessibility\}

- グリッドには `role="grid"` を指定し、月のタイトルをラベルにします。各週には `role="row"` を指定します。
- タブ順に含まれる日付は 1 つです。表示中の月に選択済みの日付があればその日、なければ今日を使い、どちらも含まれない月では 1 日を使います。ほかの日付には `tabindex="-1"` を指定します。
- 月の切り替えが読み上げられるよう、タイトルに `aria-live="polite"` を指定します。
- タッチスクリーンでは、日付ボタンのサイズは 44px です。

## React、Svelte、Vue \{#frameworks\}

`calendar` コンポーネントは、ビヘイビアと同じデータから月の表示を生成するため、最初の HTML にカレンダーが含まれます。選択日は外部から受け取り、選択の変更を外部に通知します。`npx master-ui add calendar` でプロジェクトにコピーできます。構成と使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
