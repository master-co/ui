달력에서는 한 달의 날짜 중 하나를 선택할 수 있습니다. 달력은 버튼으로 이루어진 ARIA 그리드입니다. 스타일시트가 각 상태의 모양을 정의하고, `calendar` [동작](/guide/behaviors)이 날짜를 채우고 월 이동 버튼과 방향키를 처리합니다. 달력 자체에는 표면이 없으므로 [카드](/components/card) 안에 배치하거나 [팝오버](/components/popover) 안에 넣어 날짜 선택기로 사용합니다.

마크업은 헤더와 빈 그리드로 구성됩니다. 동작은 `calendar-title`에 월 이름을, `calendar-grid`에 요일 이름과 주별 날짜를 채웁니다. 처음에는 오늘이 속한 달을 표시합니다. 스크립트가 없으면 그리드에는 마크업에 있는 내용만 표시됩니다. 스크립트가 실행되기 전에도 날짜를 읽을 수 있어야 한다면 아래 [날짜 범위](#range) 예시처럼 서버에서 주별 날짜까지 렌더링합니다. 동작이 연결되면 이 내용을 교체합니다.

## 상태 \{#states\}

각 상태는 날짜 버튼의 속성이나 클래스로 표시합니다. 동작이 이를 설정하며, 직접 작성하거나 서버에서 생성하는 마크업에도 같은 속성과 클래스를 사용합니다.

| 상태 | 지정 방법 | 표시 방식 |
| --- | --- | --- |
| 오늘 | `aria-current="date"` | 숫자 아래의 점 |
| 선택됨 | `aria-selected="true"` | 체크된 [체크박스](/components/checkbox)와 같은 잉크 색 채움 |
| 표시 중인 달에 속하지 않음 | `calendar-day-outside` | 톤을 낮춘 잉크 색 |
| 선택 불가 | `disabled` | 비활성 상태의 잉크 색 |

날짜는 [메뉴](/components/menu) 항목처럼 포인터에 즉시 반응합니다. 오늘을 선택해도 점은 그대로 표시되며, 점의 색은 날짜 숫자의 색을 따릅니다.

## 날짜 범위 \{#range\}

날짜 범위는 잉크 색으로 채운 두 날짜를 칩과 같은 색조의 띠로 연결해 표시합니다. 시작일에는 `calendar-day-range-start`, 종료일에는 `calendar-day-range-end`, 그 사이 날짜에는 `calendar-day-range`를 지정합니다. 이 날짜는 모두 `aria-selected="true"`입니다.

## 날짜 선택기 \{#date-picker\}

## 동작 \{#behavior\}

`calendar`는 루트와 옵션 객체를 받아 동작을 해제하는 함수를 반환합니다.

```js name=app.js
import { calendar } from '@master/ui/behaviors/calendar.js'

const root = document.querySelector('.calendar')
const picker = calendar(root, { value: '2026-11-04', min: '2026-11-01', max: '2026-12-31' })

root.addEventListener('change', (event) => console.log(event.detail.value))
```

| 옵션 | 설정 내용 |
| --- | --- |
| `value` | 선택한 날짜를 나타내는 `YYYY-MM-DD` 값 또는 범위의 시작일과 종료일 |
| `month` | 처음 표시할 월을 나타내는 `YYYY-MM` 값. 기본값은 선택 값이 속한 달이며, 선택 값이 없으면 오늘이 속한 달입니다. |
| `min`, `max` | 선택할 수 있는 첫날과 마지막 날을 나타내는 `YYYY-MM-DD` 값. 해당 방향으로 이동할 수 있는 달이 없으면 월 이동 버튼이 비활성화됩니다. |
| `range` | 두 날짜와 그 사이의 모든 날짜를 선택하려면 `true`로 설정합니다. |
| `weekStart` | 첫 열에 표시할 요일. 일요일은 0, 토요일은 6입니다. 기본값은 로캘의 주 시작 요일이며, 브라우저에서 이 값을 확인할 수 없으면 월요일을 사용합니다. |
| `locale` | 월과 요일 이름에 사용할 BCP 47 태그. 기본값은 달력에 적용되는 `lang`입니다. |
| `disabled` | `Date` 객체를 받아 해당 날짜가 선택 불가인지 반환하는 함수 |
| `draw` | 스크립트 대신 그리드를 생성하는 함수. 표시할 월을 `YYYY-MM` 형식으로 전달받습니다. [사용자 지정 그리드](/guide/behaviors#a-grid-of-your-own)를 참고하세요. |

- **생성하는 내용.** 표시 중인 달의 요일 이름, 주별 날짜, 월 이름을 채웁니다. 날짜 버튼에는 날짜를 `value`로 설정합니다. 오늘에는 `aria-current="date"`를, 선택된 날짜에는 `aria-selected="true"`와 범위 클래스를, 선택할 수 없는 날짜에는 `disabled`를 지정합니다. 전체 날짜는 `aria-label`에 지정하며, `tabindex`로 날짜 하나만 탭 순서에 포함되도록 합니다. `draw` 옵션을 사용하면 템플릿이나 프레임워크가 날짜를 생성하고 스크립트는 상태만 표시합니다.
- **이벤트.** 날짜를 선택하면 루트에서 버블링되는 `change` 이벤트를 발행합니다. 이벤트의 `detail.value`에는 날짜가 `YYYY-MM-DD` 형식으로 들어가며, 범위의 양 끝을 모두 선택하면 `[start, end]`가 들어갑니다.
- **선택 값.** 선택 값은 스크립트에만 저장됩니다. 반환된 함수의 `value` 속성으로 읽을 수 있습니다. 예를 들어 `picker.value`로 읽습니다. 범위의 종료일은 선택하기 전까지 `null`입니다. 외부에서 날짜를 선택하려면 이 값을 설정하세요. `picker.value = '2026-11-20'`는 새 날짜가 속한 달을 표시하며 이벤트를 발행하지 않습니다.
- **날짜 기준.** 날짜는 현지 시간대와 그레고리력을 기준으로 합니다.

## 구조 \{#structure\}

- `calendar-grid`에서 열 7개를 한 번 선언합니다. 각 `calendar-week` 행은 이 열을 서브그리드로 사용하므로, 테이블 없이도 요일 이름과 날짜가 같은 열에 정렬됩니다.
- `calendar-weekday`는 열 머리글입니다. `aria-label`에는 전체 요일 이름을 지정합니다.
- `calendar-day`는 `role="gridcell"`을 지정한 `<button>`입니다.

## 접근성 \{#accessibility\}

- 그리드는 `role="grid"`이며 월 제목을 접근 가능한 이름으로 사용합니다. 각 주는 `role="row"`입니다.
- 탭 순서에는 날짜 하나만 포함됩니다. 선택한 날짜가 우선이며, 표시 중인 달에 선택한 날짜가 없으면 오늘을 사용합니다. 둘 다 그 달에 없으면 그 달의 첫날을 사용합니다. 나머지 날짜에는 `tabindex="-1"`을 지정합니다.
- 월이 바뀔 때 변경 내용이 안내되도록 제목에 `aria-live="polite"`를 지정하세요.
- 터치 화면에서 날짜 칸의 크기는 44px입니다.
