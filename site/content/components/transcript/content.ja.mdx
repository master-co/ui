トランスクリプトは、録音で話されている内容を、それぞれ開始時刻を持つキューのリストとして示します。再生に合わせて追従し、現在のキューは浮き上がった面に強調表示し、再生済みのキューは控えめに、これから再生されるキューは通常の本文色で表示します。キューを選ぶと、録音がそこから再生されます。`transcript` の[ビヘイビア](/guide/behaviors)が、`aria-controls` で ID を指定した[メディアプレーヤー](/components/player)、または通常の `<audio>` や `<video>` とトランスクリプトを結び付けます。

## 追従とスクロール \{#following\}

録音の再生中、ビヘイビアは現在のキューに `aria-current="true"` を付けます。現在のキューは、`data-start` を過ぎた最後のキューです。そのため、2 つのキューの間に間があっても位置が保たれます。それより前のキューは、スタイルシートだけで再生済みとして描画されます。

リストは現在のキューを中央に保ちます。スクロールするのはリスト自身だけで、周囲の要素はスクロールしないため、トランスクリプトを置いたページが読者の操作中に動くことはありません。スクロールは滑らかに行われ、動きを抑える設定をしている読者には瞬時に移動します。読者がホイール、指、キー、スクロールバーでリストをスクロールし、現在のキューが表示範囲から外れると、リストは追従を止めます。リストの下端に表示される小さなピル形の `transcript-return` で、元に戻せます。キューを選ぶか、現在のキューが再び表示範囲に入るまでスクロールすると、追従が再開します。

リストは `--transcript-height` の範囲内でスクロールします。指定しない場合は 20rem です。リストに [`scroll-area`](/components/scroll-area) を追加すると、細いスクロールバーと、続きがある端のフェードが付きます。

## WebVTT トラックから生成する \{#from-a-track\}

リストが空の場合、ビヘイビアは TextTrack API を通じてメディアの最初の captions または subtitles のトラックを読み取り、キューを書き込みます。書き込むのは、時刻、タグを除いたテキスト、そして話者タグ（`<v Ana>`）で指定された話者です。トラックは disabled でなくなって初めてキューを読み込むため、ビヘイビアは disabled のトラックを `hidden` にします。`hidden` のトラックは映像の上に何も表示しません。この例では、トランスクリプトはブラウザー標準のコントロールを持つ通常の `<audio>` に追従しています。

## ビヘイビア \{#behavior\}

`transcript` は、`transcript` クラスを持つ要素であるルートを受け取り、ビヘイビアを解除する関数を返します。

```js name=app.js
import { transcript } from '@master/ui/behaviors/transcript.js'

const detach = transcript(document.querySelector('.transcript'))
```

- **メディア**は、`aria-controls` が指定する要素です。メディアプレーヤーの場合はその `player-media` を使い、`<audio>` や `<video>` の場合はそれ自体を使います。ビヘイビアはメディアがイベントを発行するたびに参照し直すため、トランスクリプトより後に書き込まれたメディアや、後から別のメディアを指定した場合にも追従します。`media` オプションを使うと、代わりに要素を直接指定できます。
- **キュー**は、開始時刻の秒数を表す `data-start` を持つ `li` で、`transcript-time` ボタンと `transcript-text` を含みます。キューのどこを押しても、その開始位置から再生します。ただし、読者がキューの文言を選択している場合は除きます。時刻の上で <kbd class="kbd">Enter</kbd> を押しても同じです。
- **ほかの場所で書き込まれた行**　ビヘイビアはリストを毎回読み取り、内容を保持しません。そのため、レンダラーがキューを書き込んだり変更したりできます。`draw: false` を指定すると、空のリストをレンダラーに任せます。`track` は、キューを書き込む元のトラックを選びます。ビヘイビアが書き込んだ行は、解除時に削除されます。

| オプション | 既定値 | |
| --- | --- | --- |
| `media` | `aria-controls` から取得 | 追従するメディア要素 |
| `track` | 最初の captions または subtitles のトラック | 空のリストを書き込む元のトラック |
| `draw` | `true` | 空のリストをトラックから書き込むかどうか |

ビヘイビアを適用しない場合、キューは読者が読むためのリストになります。何も強調されず、追従もせず、キューを選んでもシークしません。

## キーボード操作 \{#keyboard\}

Tab キーでフォーカスできる時刻ボタンは、現在のキューのボタンだけです。ボタン間は矢印キーで移動するため、トランスクリプトが長くても Tab キーの停止位置は増えません。

## アクセシビリティ \{#accessibility\}

- トランスクリプトには、`aria-label` または `aria-labelledby` で参照する見出しで名前を付け、`aria-controls` でメディアを指定します。
- 現在のキューは `aria-current="true"` です。スタイルシートは色相を変えず、文字色の濃さと面の浮き上がりで現在のキューを示します。強制カラーモードでは、システムカラーのアウトラインで示します。
- 録音の再生中に、トランスクリプトが自らフォーカスを取ることはありません。フォーカスは読者が動かしたときにだけ移動し、元に戻るボタンを選んだときには現在のキューに戻ります。
- 映像のない録音を音声なしで理解するには、トランスクリプトが必要です。スクリプトなしでページを読める必要がある場合は、トランスクリプトをページに記述します。

## React、Svelte、Vue \{#frameworks\}

`transcript` コンポーネントは、`cues` からキューを書き込みます。各キューは `start`、`text`、省略可能な `speaker` を持ちます。`media` として渡したメディアを指定し、キューの強調と追従を行うビヘイビアを適用します。`npx master-ui add transcript` でプロジェクトにコピーできます。コンポーネントの構成と使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
