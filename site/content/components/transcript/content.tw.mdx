逐字稿以字幕片段（cue）清單呈現錄音的內容，每個片段都標有開始時間。播放錄音時，逐字稿會跟著進度移動：目前播放的片段以醒目的文字和有層次感的底色突顯，已播放的片段會淡化，尚未播放的片段則維持一般內文色。選擇某個片段，錄音就會從該處開始播放。`transcript` [行為](/guide/behaviors)會將它連接到[媒體播放器](/components/player)或一般的 `<audio>`、`<video>`，連接對象由 `aria-controls` 中的 id 指定。

## 跟隨與捲離 \{#following\}

錄音播放時，行為會以 `aria-current="true"` 標示目前的片段：也就是播放進度已到達其 `data-start` 的片段中，最後一個片段，因此在兩個片段之間的停頓期間，位置仍會保留。在它之前的每個片段都會以已播放的樣式繪製，這完全由樣式表負責。

清單會讓目前的片段保持在中央。自動跟隨時，只有逐字稿清單會捲動，頁面會維持原位。清單會平滑捲動，使用者啟用減少動態效果時則直接跳到定位。當讀者用滾輪、手指、按鍵或捲軸捲動清單，使目前的片段離開視野時，清單會停止跟隨，並在下緣顯示一顆小型膠囊按鈕 `transcript-return`，可將清單帶回目前位置。選擇某個片段，或將目前的片段捲回視野內，都會恢復跟隨。

清單在 `--transcript-height` 的高度內捲動，未設定時為 20rem。為清單加上 [`scroll-area`](/components/scroll-area)，即可使用纖細的捲軸，並在內容延續的邊緣顯示淡出效果。

## 從 WebVTT 軌道產生 \{#from-a-track\}

清單為空時，行為會透過 TextTrack API 讀取媒體的第一條 captions 或 subtitles 軌道，寫入字幕片段：包括時間、去除標籤後的文字，以及語音標籤所指名的說話者（`<v Ana>`）。軌道只有在未停用時才會載入字幕片段，因此行為會將停用的軌道設為 `hidden`，這樣不會在畫面上顯示任何內容。下面的逐字稿跟隨的是一個使用瀏覽器控制項的一般 `<audio>`。

## 行為 \{#behavior\}

`transcript` 接收根元素，也就是帶有 `transcript` 類別的元素，並傳回用來解除行為的函式。

```js name=app.js
import { transcript } from '@master/ui/behaviors/transcript.js'

const detach = transcript(document.querySelector('.transcript'))
```

- **媒體**是 `aria-controls` 所指的元素：若是媒體播放器，會取用其中的 `player-media`；也可以是 `<audio>` 或 `<video>`。每次媒體發出事件時，行為都會重新查找，因此在逐字稿之後才寫入的媒體，或之後改指定的其他媒體，都能被跟隨。`media` 選項則可改為直接指定元素。
- **字幕片段**是帶有 `data-start`（開始的秒數）的 `li`，內含一個 `transcript-time` 按鈕和一個 `transcript-text`。在片段上任一處按下都會從它的開頭播放，除非讀者正在選取其中的文字；在它的時間上按 <kbd class="kbd">Enter</kbd> 也有相同效果。
- **由其他程式寫入的列。** 行為每次都會重新讀取清單，不保存任何內容，因此算繪程式可以寫入並變更字幕片段。`draw: false` 會將空清單留給算繪程式處理；`track` 用來選擇寫入字幕片段的來源軌道。行為解除時，會移除它所寫入的列。

| 選項 | 預設值 | |
| --- | --- | --- |
| `media` | 取自 `aria-controls` | 要跟隨的媒體元素 |
| `track` | 第一條 captions 或 subtitles 軌道 | 清單為空時，用來產生字幕片段的來源軌道 |
| `draw` | `true` | 清單為空時，是否從軌道讀取並填入字幕片段 |

未掛上行為時，字幕片段就是供讀者閱讀的清單；不會標示任何片段，不會跟隨，選擇片段也不會跳轉。

## 鍵盤操作 \{#keyboard\}

所有時間按鈕共用一個 Tab 停駐點，也就是目前片段的時間按鈕，並以方向鍵在它們之間移動，因此很長的逐字稿也不會讓 Tab 鍵的巡覽順序變得冗長。

## 無障礙 \{#accessibility\}

- 請以 `aria-label`，或以 `aria-labelledby` 指向的標題為逐字稿命名，並在 `aria-controls` 中指定它的媒體。
- 目前的片段設有 `aria-current="true"`；樣式表透過文字明暗和視覺層次突顯目前片段，無須依賴色相。強制色彩模式下則使用系統外框線。
- 錄音播放時，逐字稿絕不會自行取得焦點。只有讀者移動焦點時焦點才會移動，啟用返回按鈕時，焦點會回到目前的片段。
- 沒有畫面的錄音需要逐字稿，才能在沒有聲音的情況下被理解。若頁面必須能在沒有腳本的情況下閱讀，請將逐字稿寫在頁面中。

## React、Svelte 和 Vue \{#frameworks\}

`transcript` 元件會根據 `cues` 寫入字幕片段，每個片段包含 `start`、它的 `text`，以及選用的 `speaker`；它會指定以 `media` 傳入的媒體，並掛上行為，由行為負責標示和跟隨。用 `npx master-ui add transcript` 將元件複製到專案中。元件的建置與使用方式請參閱 [React、Svelte 和 Vue](/guide/frameworks)。
