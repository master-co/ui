A table of contents lists the headings of a page as a quiet column of links on a hairline rail. The link of the section in view is in ink, with a mark on the rail that glides from one link to the next. Where the browser supports `scroll-target-group`, the page marks it by itself: the list watches the scroll, and the link whose target is in view matches `:target-current`. No observer, no script.

## Levels \{#levels\}

A `toc-list` inside a list item is a deeper level. It shares the rail and indents its links by one step. Two levels are enough for a page; a third is a sign the page wants splitting.

## Marking the section yourself \{#marking\}

`aria-current="true"` on a link draws the same state as `:target-current`. Set it from the server for a static list, or from an `IntersectionObserver` where the scroll-target group is not supported. When both are present they agree, since both follow the section in view.

## Accessibility \{#accessibility\}

- The list is a `<nav>` with a label such as "On this page", so it can be found among the page's landmarks and told apart from the main navigation.
- Links go to headings by `id`. Give the scroller `scroll-padding-top` when a [navbar](/components/navbar) is stuck above it, so a heading does not land under the bar.
- The current link changes ink, and the mark is one and a half pixels of ink beside it; neither depends on hue. With reduced motion the mark moves without gliding.
