紋理是在表面上反覆鋪排的圖樣。當一塊區域沒有內容，仍需要讓人看出用途時，可以在元素上加上 `.texture`。紋理以低調的單色背景圖片呈現，疊在元素原有的底色上。例如，內凹區域加上圓點後，仍保有原本內凹的外觀。

## 圖樣 \{#drawings\}

五種圖樣各自傳達所在區域的用途。選擇圖樣時，應以它傳達的意義為準，不能只看外觀。這樣使用者在兩處看到斜紋時，就能知道兩處都表示預留空間。

| 類別 | 代表意義 | 用途 |
| --- | --- | --- |
| `texture` | 開放的展示區 | 範例、畫布或圖解的背景 |
| `texture texture-grid` | 有定位基準的區域 | 編輯器、平面圖或版面配置教學等重視位置的畫布 |
| `texture texture-stripes` | 預留的空間 | 欄間距、留白、空槽或圖片預留位置 |
| `texture texture-crosshatch` | 不可使用的區域 | 封鎖的時段、不開放的日期或超出界限的範圍 |
| `texture texture-checker` | 沒有底色 | 透明圖片或帶有 Alpha 值的色彩下方的背景 |

請勿把文字直接放在紋理上。圖樣會穿過字形，降低可讀性。請將說明文字放在紋理區域旁，或放在覆蓋紋理的面板上。

## 預留與不可用 \{#kept-and-unavailable\}

斜紋與交叉斜紋用來區分兩種空白區域。斜紋表示預留的空位，之後可能填入內容。交叉斜紋則表示無法選取。也請用文字說明狀態，讓無法辨識圖樣的使用者也能理解。這裡不開放的時段同時設為停用，並標明狀態。

## 尺寸、粗細與顏色 \{#size-weight-and-ink\}

可用三個自訂屬性調整個別圖樣。`--texture-size` 是單一圖塊的邊長，`--texture-weight` 是圓點半徑或線條寬度，`--texture-ink` 是圖樣的顏色。主題可透過 `--color-texture` 一次設定所有紋理的顏色。

讓紋理比上方的內容更低調。展示範例時，細而稀疏的圖樣就足以襯出範例的邊緣，太密則會分散注意力。

斜紋在正方形圖塊中以 45° 傾斜，因此線條間距為圖塊邊長除以 √2。預設圖塊邊長為 8px，間距為 5.7px。請將圖塊邊長設為整數像素，以免線條在相鄰圖塊之間錯位。

圖塊從區域中央開始排列，因此無論區域大小，圖樣在相對兩側邊緣的裁切方式都相同。若要改從角落開始排列，請設定 `background-position`。

## 淡出 \{#fade\}

`texture-fade` 讓圖樣往邊緣逐漸淡出，適合用在標題後方。這個遮罩也會讓元素內的內容淡出，因此請在內容後方放置獨立元素來套用遮罩，並讓輔助技術略過該元素。

## 疊層 \{#layering\}

紋理會取代表面原有的背景圖片，並保留元素的底色。若要同時保留另一張圖片，或用圖樣裁出形狀，請在套用紋理類別的元素上讀取 `--texture-image`，圖樣可透過這個屬性取得。

```css
.texture.stage {
  background-image: var(--texture-image), linear-gradient(var(--color-surface-raised), var(--color-surface-raised-low));
  background-size: var(--texture-size) var(--texture-size), auto;
}
```

交叉斜紋由兩層組成，因此請為兩層分別指定尺寸。

## 無障礙 \{#accessibility\}

強制色彩模式會移除紋理圖樣，因此每種有意義的紋理都需要其他方式傳達其意義。

- 純裝飾的區域無須額外說明。若元素只用來承載紋理，請加上 `aria-hidden="true"`。
- 如果紋理用來表示預留、不開放或透明等狀態，請在區域旁加上文字，或直接在區域本身加上 `role="img"` 和 `aria-label`。
- 無法使用的控制項應先設為 `disabled`。交叉斜紋只是補充呈現該屬性已表達的狀態。
