폼 레이아웃은 [필드](/components/input)를 세로로 일정한 간격을 두고 배치하고, 짧은 필드는 한 줄에 나란히 놓으며, 폼을 마무리하는 버튼은 맨 끝에 둡니다. 레이아웃이므로 컴포넌트처럼 표면을 그리거나 상태를 유지하지 않습니다. 가로로 배치한 항목을 언제 세로로 쌓을지 결정합니다.

폼은 크기 컨테이너이므로 행과 섹션의 배치는 뷰포트 너비가 아닌 폼에 주어진 열의 너비에 따라 달라집니다. 같은 마크업이 설정 페이지에서는 두 열로, 좁은 대화 상자에서는 한 열로 표시됩니다. 이처럼 너비 기준에 따라 배치가 바뀌므로 여러 유틸리티를 조합하는 대신 클래스 하나로 제공합니다.

## 행 \{#rows\}

`form-row`에는 이름과 성, 도시와 우편번호처럼 한 줄로 읽는 필드를 넣습니다. 폼 너비가 28rem 이상이면 같은 너비의 열에 나란히 배치되고, 그보다 좁으면 세로로 쌓입니다. 한 행에는 짧은 필드를 두세 개만 넣으세요.

## 섹션 \{#sections\}

`form-section`은 제목을 해당 필드 옆에 배치합니다. 폼 너비가 40rem 이상이면 설정 페이지처럼 제목이 너비의 3분의 1을, 필드가 나머지를 차지합니다. 그보다 좁으면 제목이 필드 위에 놓입니다. 섹션 사이는 가는 선으로 구분합니다.

## 동작 버튼 \{#actions\}

`form-actions`는 폼을 마무리하는 버튼을 줄 끝에 배치하고, 확인 버튼을 맨 마지막에 둡니다. 폼 너비가 24rem 미만이면 버튼이 각각 전체 너비를 차지하며 세로로 쌓이고, 확인 버튼이 엄지손가락이 닿기 쉬운 맨 위에 놓입니다. 마크업에는 읽는 순서대로 취소 버튼을 먼저, 확인 버튼을 나중에 작성하세요. 스타일시트가 세로로 쌓인 버튼의 표시 순서를 뒤집습니다.

## 접근성 \{#accessibility\}

- 폼 클래스는 레이아웃만 담당합니다. 레이블, 힌트, 오류 메시지는 [`field`](/components/input#hint-and-error)에서 제공하고, 관련 컨트롤은 `fieldset`으로 묶습니다.
- 각 섹션에 제목을 붙이고, `<section>`에서 `aria-labelledby`로 해당 제목을 참조해 그룹에 이름을 지정하세요.
- 동작 버튼을 세로로 쌓으면 화면에 보이는 순서만 바뀝니다. 문서 순서는 그대로이므로 Tab 키로 이동할 때는 취소, 확인 순으로 포커스가 이동합니다.
- 컨테이너의 너비는 주변 레이아웃에서 결정되어야 합니다. 콘텐츠에 맞춰 너비가 줄어드는 상자(예: inline-flex 부모 요소, 너비가 지정되지 않은 팝오버) 안에서는 폼에 너비를 지정하세요.
