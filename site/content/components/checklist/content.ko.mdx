체크리스트는 설정 단계나 검토 항목처럼 해야 할 일을 간단히 정리한 목록입니다. 각 항목의 레이블에는 네이티브 [체크박스](/components/checkbox)와 제목, 한 줄짜리 안내 문구가 들어갑니다. 완료한 항목은 덜 강조되며 제목에 가는 취소선이 표시됩니다. 목록은 완료한 항목 수를 자동으로 집계합니다.

## 완료 항목 자동 집계 \{#the-list-counts-itself\}

CSS 카운터 두 개로 항목 수를 집계합니다. `checklist-item`마다 전체 항목 수가 1씩 늘어납니다. 각 항목은 `:has()`로 체크박스의 선택 여부를 확인하고, 선택된 경우 완료 항목 수를 1 늘립니다. `checklist-count`는 두 수를 모두 표시합니다.

카운터는 문서 순서대로 집계하므로, 마크업에서는 두 수가 확정되는 항목 목록 뒤에 집계를 배치하세요. 집계 문구는 숫자 뒤에 오므로 원하는 언어로 번역할 수 있습니다. 두 숫자 사이에 들어가는 구분자는 `--checklist-of` 속성으로 지정하며 기본값은 `' / '`입니다. “2 of 4”로 표시하려면 값을 `' of '`로 설정하세요.

집계는 CSS에서 생성하는 콘텐츠입니다. 집계 값은 항상 현재 상태를 반영하지만, 값이 바뀌어도 스크린 리더가 알리지 않습니다. 목록 완료 여부를 알려야 한다면 별도의 상태 메시지를 제공하세요.

## 체크리스트 항목 \{#a-step\}

레이블이 행 전체를 차지하므로 텍스트 어디를 눌러도 체크박스를 선택할 수 있습니다. `checklist-title`에는 인라인 요소를 사용합니다. 완료된 제목의 취소선은 텍스트를 따라 길어지는 배경으로 구현되며, 제목이 여러 줄로 줄바꿈되어도 취소선은 한 줄로 유지됩니다. `checklist-end`에는 소요 시간처럼 항목 끝에 표시할 정보를 넣습니다.

[목록](/components/list)과 마찬가지로 텍스트가 시작하는 위치부터 가는 구분선을 그어 행을 나눕니다. 체크리스트 자체에는 표면이 없으므로 [카드](/components/card) 안에 배치하세요.

## 접근성 \{#accessibility\}

- `<ul>` 요소를 사용하세요. 정해진 순서대로 완료해야 하는 단계에는 `<ol>` 요소를 사용하세요.
- 체크리스트의 체크박스는 사용자가 직접 상태를 설정하는 컨트롤입니다. 시스템이 완료하는 단계는 [단계 표시기](/components/steps)로 표시하세요. 사용자가 상태를 바꿀 수 없는 체크박스는 비활성화된 컨트롤입니다. 완료 기록을 표시할 때는 단계 표시기를 사용하세요.
- 취소선이 있는 제목에는 강조를 낮춘 잉크 색을 적용하되 읽을 수 있는 대비를 유지합니다. 완료 여부는 체크박스의 상태로 전달합니다.
