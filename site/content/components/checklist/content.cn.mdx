核对清单是简短的待办列表，可用于列出设置步骤或审核要点。每一步都使用原生[复选框](/components/checkbox)，放在带有标题和一行提示的标签内。完成后，该步骤的视觉权重降低，标题上会出现一条细线，清单会自动统计完成数量。

## 自动计数 \{#the-list-counts-itself\}

两个 CSS 计数器分别统计总数和完成数。每个 `checklist-item` 都让总数加一，通过 `:has()` 匹配到复选框已选中的条目让完成数加一。`checklist-count` 显示这两个数字。

计数器按文档顺序计数，因此要把计数放在标记中的所有步骤之后，此时两个数字都已统计完毕。说明文字放在数字之后，可自行翻译。`--checklist-of` 指定两个数字之间的内容，默认值为 `' / '`。要显示“2 of 4”，请将它设为 `' of '`。

计数属于 CSS 生成内容，数值始终准确，但变化不会自动播报。如果清单是否全部完成很重要，请自行提供状态消息。

## 单个步骤 \{#a-step\}

标签覆盖整行，点击文字的任意位置都能勾选复选框。`checklist-title` 特意采用行内元素，已完成标题上的删除线由沿文字延伸的背景绘制，标题无论如何换行，线条都保持为一条。`checklist-end` 用于在步骤末尾放置附加信息，例如所需时间。

与[列表](/components/list)一样，各行之间用从文字处起始的细线分隔。核对清单本身没有独立的背景，可将它放入[卡片](/components/card)中。

## 无障碍 \{#accessibility\}

- 使用 `<ul>`，如果步骤必须按顺序完成，则使用 `<ol>`。
- 这里的复选框表示读者自行设置的状态。系统完成的步骤请用[步骤组件](/components/steps)展示，因为读者无法更改的复选框是禁用控件，不是完成记录。
- 带删除线的标题仍使用较淡的文字颜色，并保持足够的对比度以便阅读。完成状态由复选框表达，而非删除线。
