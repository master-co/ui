미디어 플레이어는 네이티브 `<audio>`나 `<video>` 위에 페이지 자체의 컨트롤을 둡니다. 재생하는 요소는 여전히 미디어 요소이므로, 그 의미, 브라우저 미디어 컨트롤에서의 위치, 그리고 폴백 역할을 하는 `controls` 속성이 모두 유지됩니다. `player` [동작](/guide/behaviors)은 연결할 때 이 속성을 제거하고, 그 뒤로는 미디어의 상태를 컨트롤 행에 그대로 반영합니다. 재생 버튼은 재생 중에 눌린 상태가 되고, 탐색 트랙은 [슬라이더](/components/slider)와 같은 range 입력 요소로 재생된 부분 아래에 불러온 부분을 그리며, 시간은 숫자가 바뀌어도 너비가 유지되는 작은 고정폭 숫자로 표시됩니다.

## 동영상 \{#video\}

`player-video`를 적용하면 미디어 플레이어가 동영상의 프레임이 됩니다. 영상은 표면과 같은 모서리 반경을 가진 어두운 영역을 채우고, 같은 컨트롤 행이 아래 가장자리에서 올라오는 그림자 위로 영상 아래쪽에 놓입니다. 화면은 어둡기 마련이므로 컨트롤 행은 어느 테마에서든 어두운 색 구성으로 그려집니다. 동영상에는 세 가지 컨트롤이 추가되며, 각각 작동할 수 있는 경우에만 표시됩니다. 자막 버튼은 동영상에 captions 또는 subtitles 트랙이 있을 때, 화면 속 화면 버튼은 브라우저가 지원할 때, 전체 화면 버튼은 브라우저가 허용할 때 표시됩니다. 영상을 클릭하면 재생과 일시 정지가 전환되고, 더블클릭하면 전체 화면이 됩니다.

동영상이 재생 중이고 포인터가 2.5초 동안 움직이지 않거나 프레임을 벗어나면, 컨트롤 행이 영상에서 사라지고 포인터도 함께 사라집니다. 포인터를 조금이라도 움직이면 다시 나타납니다. 컨트롤에 키보드 포커스가 있거나 속도 메뉴가 열려 있는 동안에는 사라지지 않으며, 동작 줄이기를 요청한 사용자에게는 사라지지 않습니다. 터치 화면에서 컨트롤이 사라진 영상을 탭하면 컨트롤만 다시 나타납니다.

## 동작 \{#behavior\}

`player`는 `player` 클래스가 있는 루트 요소를 받아, 연결한 동작을 해제하고 미디어에 컨트롤을 돌려주는 함수를 반환합니다.

```js name=app.js
import { player } from '@master/ui/behaviors/player.js'

const detach = player(document.querySelector('.player'))
```

미디어가 유일한 기준입니다. 동작은 미디어를 수신하면서 미디어가 알리는 상태를 스타일시트가 읽는 속성에 반영하고, 모든 컨트롤은 스스로 바뀌는 대신 미디어에 변경을 요청합니다. 따라서 시스템의 미디어 키나 다른 스크립트처럼 다른 곳에서 녹음을 재생해도 똑같이 그려집니다.

- **토글.** 재생 버튼은 미디어가 재생되는 동안, 음소거 버튼은 음소거된 동안, 자막 버튼은 첫 번째 captions 또는 subtitles 트랙이 표시되는 동안, 화면 속 화면 버튼과 전체 화면 버튼은 동영상이 각 상태에 있는 동안 `aria-pressed="true"`가 됩니다. 토글은 Play나 Mute처럼 하나의 이름을 유지하며, 상태는 `aria-pressed`가 알립니다. `player-off`와 `player-on` 두 면이 있으면 상태에 맞는 면을 보여 주고, 면이 하나뿐이면 켜져 있는 동안 오목한 영역 안으로 들어갑니다.
- **시간.** 탐색 트랙의 `max`는 재생 시간이고 `value`는 현재 시간이며, 문구로 된 `aria-valuetext`가 함께 설정됩니다. 경과 시간과 재생 시간은 각자의 요소에 작성되며, 녹음이 한 시간 이상이면 시간 단위가 포함됩니다. 사용자가 트랙을 드래그하는 동안에는 미디어가 손가락 아래의 손잡이를 움직이지 않습니다.
- **불러온 부분.** 현재 시간 주변에서 불러온 부분은 루트의 `--player-buffered`에 0부터 1까지의 값으로 설정되며, 트랙에서 재생된 부분 아래에 그려집니다.
- **볼륨과 속도.** 볼륨 슬라이더는 볼륨 값을 담으며, 미디어가 음소거된 동안에도 그 값을 유지한 채 한 단계 흐리게 표시됩니다. 기기 자체의 버튼으로만 볼륨을 조절하는 기기에서는 숨겨집니다. 속도 버튼은 `popovertarget`이 가리키는 메뉴를 엽니다. 메뉴 안의 각 `menu-input` 라디오 버튼이 재생 속도이며, 동작은 버튼에 속도를 작성하고 해당 라디오 버튼을 선택합니다.
- **자막.** 자막을 끄면 트랙은 `disabled`가 아니라 `hidden`이 되므로, 같은 트랙을 읽는 [트랜스크립트](/components/transcript)는 큐를 그대로 유지합니다.
- **전체 화면**의 대상은 동영상이 아니라 미디어 플레이어이므로, 컨트롤 행이 영상 위에 남습니다. 동영상만 전체 화면으로 표시할 수 있는 iPhone에서는 시스템 자체의 플레이어가 사용됩니다.
- **값.** 반환된 함수에는 현재 시간을 초 단위로 나타내는 `value`가 있습니다. 이 값을 설정하면 그 위치로 이동합니다.

| 옵션 | 기본값 | |
| --- | --- | --- |
| `step` | `5` | 방향키로 이동하는 초 |
| `jump` | `10` | <kbd class="kbd">J</kbd>와 <kbd class="kbd">L</kbd> 키로 이동하는 초 |
| `volumeStep` | `0.1` | <kbd class="kbd">ArrowUp</kbd>과 <kbd class="kbd">ArrowDown</kbd> 키로 볼륨이 바뀌는 크기 |
| `idle` | `2500` | 재생 중인 동영상의 컨트롤이 사라지기 전까지 포인터가 멈춰 있어야 하는 밀리초 |
| `valueText` | 영어 | 시간과 재생 시간으로 만드는 탐색 트랙의 `aria-valuetext`로, 페이지 언어로 작성합니다 |
| `rateText` | `1.5×` | 속도 버튼이 각 재생 속도를 표시하는 문구 |

## 키보드 \{#keyboard\}

키는 미디어 플레이어 안 어디에 포커스가 있든 작동하며, 동영상 화면을 클릭한 뒤에도 작동합니다. 컨트롤에 필요한 키는 그 컨트롤이 처리합니다. 포커스가 있는 버튼에서 <kbd class="kbd">Space</kbd> 키를 누르면 버튼이 눌리고, 볼륨 슬라이더에서는 방향키가 볼륨을 조절하며, 속도 메뉴에서는 [메뉴](/components/menu)의 키를 사용합니다.

## 접근성 \{#accessibility\}

- 루트에 `role="group"`과 녹음의 이름을 지정하는 `aria-label`을 설정해, 컨트롤이 그 녹음의 컨트롤로 안내되도록 하세요.
- 모든 버튼에 하는 일을 페이지 언어로 이름 붙이고, 상태가 바뀌어도 이름을 유지하세요. 상태는 `aria-pressed`가 나타냅니다.
- 말소리가 있는 동영상에는 자막이 필요합니다. `<track kind="captions">`를 추가하세요. 영상이 없는 녹음에는 [트랜스크립트](/components/transcript)가 필요합니다.
- 소리가 있는 녹음을 자동으로 재생하지 마세요. 미디어 플레이어는 사용자가 요청할 때 재생합니다.
- 버튼은 포인터 종류와 관계없이 32px이며, 터치 화면에서는 각 버튼의 조작 영역이 위아래로 44px까지 넓어집니다. 시간은 숫자가 바뀌어도 너비를 유지하므로 재생 중에 트랙이 흔들리지 않습니다.

## React, Svelte, Vue \{#frameworks\}

`player` 컴포넌트는 `src`, `video`, `poster`, `tracks`로 미디어와 컨트롤 행을 렌더링하고 동작을 연결하며, 현재 시간과 재생 여부를 받아 외부로 전달합니다. React에서는 `time`과 `playing`을 `onTimeChange`, `onPlayingChange`와 함께 사용하고, Svelte에서는 바인딩 가능한 prop을, Vue에서는 `v-model:time`과 `v-model:playing`을 사용합니다. 외부에서 시간을 설정하면 그 위치로 이동하고, `playing`으로 재생과 일시 정지를 제어합니다. `npx master-ui add player` 명령을 실행해 프로젝트에 복사하세요. 컴포넌트의 구성과 사용 방법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
