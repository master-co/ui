媒體播放器在原生的 `<audio>` 或 `<video>` 上套用頁面自己的控制項。實際播放的仍是媒體元素本身：它保有原本的語意、在瀏覽器媒體控制中的位置，以及作為備援的 `controls` 屬性。`player` [行為](/guide/behaviors)掛上時會移除這個屬性，此後便將媒體的狀態反映到控制列上：播放期間播放按鈕呈按下狀態；進度軌道就是[滑桿](/components/slider)本身的範圍輸入元件，已播放的部分下方會繪製已載入的部分；時間則以寬度固定的小型等寬數字顯示。

## 影片 \{#video\}

`player-video` 會讓媒體播放器成為影片的畫框。畫面填滿一塊帶有表面圓角的深色區域，同樣的控制列疊在畫面底部邊緣，底下襯著從邊緣往上漸淡的陰影。由於螢幕本身是暗的，無論在哪個主題下，控制列都以深色配色繪製。影片會多出三個控制項，每個都只在能運作時顯示：影片有字幕（captions 或 subtitles）軌道時顯示字幕按鈕，瀏覽器支援時顯示子母畫面按鈕，瀏覽器允許時顯示全螢幕按鈕。點擊畫面可播放或暫停，按兩下則進入全螢幕。

影片播放中且指標靜止兩秒半，或指標已離開畫框時，控制列會從畫面淡出，指標也一併隱藏。任何移動都會讓它重新出現。只要有控制項取得鍵盤焦點或播放速度選單開啟，控制列就不會淡出；讀者要求減少動態效果時也絕不淡出。在觸控螢幕上，若控制項已淡出，點一下畫面只會讓它們重新出現。

請將 `--player-ratio` 設為影片的長寬比，讓畫框在影片載入前就保留空間。控制列會依媒體播放器分配到的空間調整：寬度小於 26rem 時，音量滑桿會移出，靜音按鈕保留；小於 24rem 時，子母畫面和已播放時間也會移出，讓手機上的每個控制項都能保有手指所需的 44px 觸控區。

## 行為 \{#behavior\}

`player` 接收根元素，也就是帶有 `player` 類別的元素，並傳回一個函式，用來解除行為並將控制項還給媒體。

```js name=app.js
import { player } from '@master/ui/behaviors/player.js'

const detach = player(document.querySelector('.player'))
```

媒體是唯一的事實來源。行為會監聽媒體，將它回報的狀態反映到樣式表讀取的屬性上；每個控制項都是要求媒體改變，而不是自行改變，因此從其他地方播放的錄音（系統的媒體鍵、其他腳本）也會以相同方式呈現。

- **切換按鈕。** 媒體播放時，播放按鈕為 `aria-pressed="true"`；靜音時為靜音按鈕；第一條 captions 或 subtitles 軌道顯示時為字幕按鈕；影片處於子母畫面或全螢幕時，則為對應的按鈕。切換按鈕保持同一個名稱，例如 Play 或 Mute，由 `aria-pressed` 表示狀態。有 `player-off` 和 `player-on` 兩種外觀時，會顯示對應狀態的那一個；只有一種外觀時，開啟狀態下按鈕會呈凹槽樣式。
- **時間。** 進度軌道的 `max` 是總長度，`value` 是目前時間，並以文字提供 `aria-valuetext`。已播放時間和總長度會寫入各自的部分，錄音長度達到一小時時會加上小時。讀者拖曳進度軌道期間，媒體不會移動手指下的滑塊。
- **已載入。** 目前時間附近已載入的範圍會寫成根元素上的 `--player-buffered`，介於 0 到 1 之間，繪製在軌道上已播放部分的下方。
- **音量與速度。** 音量滑桿顯示目前音量，媒體靜音時仍保留這個音量，只是改以淡一階的樣式顯示；在只能用裝置本身按鈕調整音量的裝置上，音量滑桿會隱藏。播放速度按鈕會開啟它的 `popovertarget` 所指的選單；選單中的每個 `menu-input` 單選按鈕都是一種速率，行為會將速率寫在按鈕上，並勾選對應的單選按鈕。
- **字幕。** 關閉時，軌道會設為 `hidden` 而不是 `disabled`，因此讀取同一條軌道的[逐字稿](/components/transcript)仍保有它的字幕片段。
- **全螢幕**作用於媒體播放器而不是影片，因此控制列仍會疊在畫面上方。在只允許影片填滿螢幕的 iPhone 上，則會使用系統本身的播放器。
- **值。** 傳回的函式有一個 `value`，即目前時間的秒數；設定它即可跳轉。

| 選項 | 預設值 | |
| --- | --- | --- |
| `step` | `5` | 方向鍵每次跳轉的秒數 |
| `jump` | `10` | <kbd class="kbd">J</kbd> 和 <kbd class="kbd">L</kbd> 每次跳轉的秒數 |
| `volumeStep` | `0.1` | <kbd class="kbd">ArrowUp</kbd> 和 <kbd class="kbd">ArrowDown</kbd> 每次調整的音量 |
| `idle` | `2500` | 影片播放中，指標靜止多少毫秒後控制項會淡出 |
| `valueText` | 英文 | 進度軌道的 `aria-valuetext`，由目前時間和總長度產生，使用頁面的語言 |
| `rateText` | `1.5×` | 播放速度按鈕針對某個速率顯示的文字 |

## 鍵盤操作 \{#keyboard\}

只要焦點在媒體播放器內，或點擊過影片畫面之後，這些按鍵就能使用。控制項本身需要的按鍵仍由該控制項處理：<kbd class="kbd">Space</kbd> 按下取得焦點的按鈕，方向鍵調整音量滑桿，播放速度選單則使用[選單](/components/menu)的按鍵操作。

## 無障礙 \{#accessibility\}

- 請為根元素加上 `role="group"` 和說明錄音名稱的 `aria-label`，讓這些控制項被讀作該錄音的控制項。
- 請以頁面的語言，依每個按鈕的作用為它命名，並在狀態改變時維持同一個名稱：狀態由 `aria-pressed` 表示。
- 含有語音的影片需要字幕：請加上 `<track kind="captions">`。沒有畫面的錄音則需要[逐字稿](/components/transcript)。
- 絕不要自動開始播放有聲音的錄音。媒體播放器只在讀者要求時才播放。
- 按鈕在任何指標下都是 32px；在觸控螢幕上，每個按鈕的觸控區會往上下延伸，達到 44px。時間在數字變動時保持寬度不變，因此播放時軌道不會位移。

## React、Svelte 和 Vue \{#frameworks\}

`player` 元件會根據 `src`、`video`、`poster` 和 `tracks` 算繪媒體與控制列，掛上行為，並支援傳入及傳出目前時間與是否正在播放：在 React 中是 `time` 和 `playing` 搭配 `onTimeChange` 和 `onPlayingChange`，在 Svelte 中是可繫結的 props，在 Vue 中是 `v-model:time` 和 `v-model:playing`。從外部設定時間會跳轉；設定 `playing` 會播放或暫停。用 `npx master-ui add player` 將元件複製到專案中。元件的建置與使用方式請參閱 [React、Svelte 和 Vue](/guide/frameworks)。
