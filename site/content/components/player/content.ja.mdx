メディアプレーヤーは、ネイティブの `<audio>` または `<video>` に、ページ独自のコントロールを重ねます。再生を担うのは引き続きメディア要素です。メディア要素はそのセマンティクス、ブラウザーのメディアコントロールにおける位置付け、そしてフォールバックとなる `controls` 属性を保持します。`player` の[ビヘイビア](/guide/behaviors)は、適用時にその属性を取り除き、以降はメディアの状態をコントロールの行に反映します。再生ボタンは再生中に押された状態になります。シークトラックは[スライダー](/components/slider)と同じ範囲入力で、再生済みの部分の下に読み込み済みの部分が描かれます。時間は、桁が変わっても幅が変わらない小さな等幅数字で表示されます。

## 動画 \{#video\}

`player-video` を指定すると、メディアプレーヤーが動画の枠になります。映像はサーフェスと同じ角丸の暗い領域を埋め、同じコントロールの行が、下端から立ち上がる影の上で映像の下端に重なります。画面は暗いものなので、コントロールの行はどちらのテーマでもダークスキームで描画されます。動画では 3 つのコントロールが加わり、それぞれ動作できる場合にのみ表示されます。字幕ボタンは動画に captions または subtitles のトラックがある場合、ピクチャーインピクチャーはブラウザーが対応している場合、全画面表示はブラウザーが許可している場合に表示されます。映像をクリックすると再生と一時停止を切り替え、ダブルクリックすると全画面表示になります。

動画の再生中にポインターが 2.5 秒間動かないか、ポインターが枠の外に出ると、コントロールの行は映像からフェードアウトし、ポインターも消えます。ポインターを少しでも動かすと元に戻ります。コントロールにキーボードフォーカスがある間や速度メニューが開いている間は、フェードアウトしません。動きを抑える設定をしている読者に対しても、フェードアウトしません。タッチスクリーンでは、コントロールがフェードアウトした映像をタップすると、コントロールが元に戻るだけです。

動画の読み込み前から枠がその形を保つように、`--player-ratio` に動画の縦横比を設定します。コントロールの行は、メディアプレーヤーに与えられた幅に応じて変わります。幅が 26rem より狭いと音量スライダーが行から外れ、ミュートボタンは残ります。24rem より狭いとピクチャーインピクチャーと経過時間も外れます。そのため、スマートフォンでもすべてのコントロールが、指での操作に必要な 44px の操作領域を保ちます。

## ビヘイビア \{#behavior\}

`player` は、`player` クラスを持つ要素であるルートを受け取り、関数を返します。この関数はビヘイビアを解除し、メディア要素にコントロールを戻します。

```js name=app.js
import { player } from '@master/ui/behaviors/player.js'

const detach = player(document.querySelector('.player'))
```

信頼できる唯一の情報源はメディア要素です。ビヘイビアはメディア要素を監視し、その状態をスタイルシートが読み取る属性に反映します。各コントロールは自身の状態を変えるのではなく、メディア要素に変更を依頼します。そのため、システムのメディアキーやほかのスクリプトなど、別の場所から再生された録音も同じように描画されます。

- **トグル**　再生ボタンはメディアの再生中、ミュートボタンはミュート中、字幕ボタンは最初の captions または subtitles のトラックが表示されている間、ピクチャーインピクチャーボタンと全画面表示ボタンは動画がそれぞれの状態にある間、`aria-pressed="true"` になります。トグルは「Play」「Mute」のように 1 つの名前を保ち、状態は `aria-pressed` が示します。`player-off` と `player-on` の 2 つの表示を持つトグルは、状態に応じた方を表示します。表示が 1 つのトグルは、オンの間くぼんだ表示になります。
- **時間**　シークトラックの `max` は再生時間の長さ、`value` は現在の再生位置で、文章による `aria-valuetext` を持ちます。経過時間と再生時間の長さはそれぞれの部分に書き込まれ、録音が 1 時間以上になると時間の桁も表示されます。読者がトラックをドラッグしている間は、メディア要素が指の下のつまみを動かすことはありません。
- **読み込み済み**　現在の再生位置の前後で読み込み済みの範囲は、0 から 1 までの値の `--player-buffered` としてルートに書き込まれ、トラック上の再生済みの部分の下に描かれます。
- **音量と速度**　音量スライダーは音量を保持し、ミュート中も値を保ったまま、一段控えめな表示になります。音量を本体のボタンでしか設定できないデバイスでは非表示になります。速度ボタンは、`popovertarget` が指定するメニューを開きます。メニュー内の各 `menu-input` ラジオボタンが再生速度を表し、ビヘイビアは選んだ速度をボタンに書き込み、対応するラジオボタンをチェックします。
- **字幕**　オフにしたトラックは `disabled` ではなく `hidden` になります。そのため、同じトラックを読み取る[トランスクリプト](/components/transcript)はキューを保持できます。
- **全画面表示**は動画ではなくメディアプレーヤー全体に適用されるため、コントロールの行は映像の上に残ります。動画しか全画面表示できない iPhone では、システム標準のプレーヤーが使われます。
- **値**　返される関数は、現在の再生位置を秒で表す `value` を持ちます。設定するとシークします。

| オプション | 既定値 | |
| --- | --- | --- |
| `step` | `5` | 矢印キーでシークする秒数 |
| `jump` | `10` | <kbd class="kbd">J</kbd> と <kbd class="kbd">L</kbd> でシークする秒数 |
| `volumeStep` | `0.1` | <kbd class="kbd">ArrowUp</kbd> と <kbd class="kbd">ArrowDown</kbd> で音量が変わる量 |
| `idle` | `2500` | 再生中の動画のコントロールがフェードアウトするまでの、ポインターが静止している時間（ミリ秒） |
| `valueText` | 英語 | 再生位置と再生時間の長さから作る、シークトラックの `aria-valuetext`。ページの言語で指定します |
| `rateText` | `1.5×` | 速度ボタンに表示する、再生速度の文言 |

## キーボード操作 \{#keyboard\}

キー操作は、メディアプレーヤー内のどこにフォーカスがあっても、また動画の映像をクリックした後でも機能します。コントロールが必要とするキーは、そのコントロールが優先して処理します。<kbd class="kbd">Space</kbd> はフォーカスのあるボタンを押し、矢印キーは音量スライダーを動かし、速度メニューでは[メニュー](/components/menu)のキー操作が使えます。

## アクセシビリティ \{#accessibility\}

- ルートに `role="group"` と録音の名前を示す `aria-label` を指定し、各コントロールがその録音のコントロールとして読み上げられるようにします。
- すべてのボタンに、その働きを表す名前をページの言語で付けます。状態が変わっても名前は変えず、状態は `aria-pressed` で示します。
- 音声を含む動画には字幕が必要です。`<track kind="captions">` を追加します。映像のない録音には[トランスクリプト](/components/transcript)が必要です。
- 音声付きの録音を自動で再生しないでください。メディアプレーヤーは読者が求めたときに再生します。
- ボタンはどのポインターでも 32px です。タッチスクリーンでは、各ボタンの上下に操作領域が広がり、高さ 44px になります。時間の表示は桁が変わっても幅が変わらないため、再生中にトラックがずれません。

## React、Svelte、Vue \{#frameworks\}

`player` コンポーネントは、`src`、`video`、`poster`、`tracks` からメディア要素とコントロールの行を描画してビヘイビアを適用し、現在の再生位置と再生中かどうかの受け渡しを行います。React では `time` と `playing` に `onTimeChange` と `onPlayingChange`、Svelte ではバインド可能なプロパティ、Vue では `v-model:time` と `v-model:playing` を使います。外部から設定した時間でシークし、`playing` で再生と一時停止を切り替えます。`npx master-ui add player` でプロジェクトにコピーできます。コンポーネントの構成と使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
