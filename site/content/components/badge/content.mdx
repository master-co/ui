## Tones \{#tones\}

Tones carry meaning. Pair each one with text that says the same thing, so the status does not depend on color alone.

## On an icon \{#on-an-icon\}

`.badge-corner` places a count on the corner of its nearest positioned parent. Give the parent `.relative` and describe the count for assistive technology.

<ComponentPreview name="corner" title="On an icon" html={`<button type="button" class="btn btn-icon relative" aria-label="Notifications, 3 unread">

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--badge-height` | `1.25rem` | Block size and minimum inline size |
| `--badge-padding-x` | `var(--spacing-2xs)` | Inline padding |
| `--badge-font-size` | `var(--font-size-xs)` | Label size |
| `--badge-bg`, `--badge-fg`, `--badge-border` | Neutral tone | Colors set by each tone |
