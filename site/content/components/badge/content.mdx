A badge is a small chip for a status, a category or a count. Neutral badges carry most labels; hue appears only when the badge states a status, and always beside words that say the same thing.

## On an icon \{#on-an-icon\}

`badge-corner` places a count on the corner of its nearest positioned parent and cuts it out of the surface below with a canvas ring. Describe the count in the parent's accessible name.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `badge` | A neutral chip |
| `badge-outline`, `badge-raised`, `badge-ink` | Contour only, a small raised sheet, solid ink |
| `badge-info`, `badge-success`, `badge-warning`, `badge-danger` | Status washes |
| `badge-dot` | A leading dot in the badge's tone |
| `badge-sm`, `badge-lg`, `badge-pill` | Sizes and fully rounded ends |
| `badge-corner` | A count on a parent's corner |
