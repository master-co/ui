署名パッドは、指、ペン、マウスで署名する欄と、代わりに名前を入力するフィールドで構成されます。パッドは[テキストフィールド](/components/input)と同じくぼんだ外観で、署名する位置を示す細い線と、名前を書き始める位置を示す小さな十字が付きます。各ストロークは、ペンの筆圧に応じた太さの塗りつぶした輪郭として、インラインの `<svg>` に書き込まれ、描いたものは SVG ドキュメントとしてフォームに渡されます。全体はネイティブの `<fieldset>` です。凡例（legend）で署名の対象を示し、`<fieldset>` に `disabled` を指定するとパッドに描画できなくなり、内部のすべてのコントロールが無効になります。

## ビヘイビア \{#behavior\}

パッドで描画するにはスクリプトが必要です。`signature` の[ビヘイビア](/guide/behaviors)は、`signature` クラスを持つ要素であるルートを受け取り、ビヘイビアを解除する関数を返します。

```js name=app.js
import { signature } from '@master/ui/behaviors/signature.js'

const pad = signature(document.querySelector('.signature'))

pad.value // [[[x, y, pressure], …], …], one list of points a stroke
pad.svg   // '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 160" …>…</svg>', or '' when nothing is drawn
```

- **ストローク**　ストロークは、ポインターが通過した点の集まりです。各点は描画の `viewBox` の単位で表され、0 から 1 までの筆圧を持ちます。ペンは自身の筆圧を伝えますが、指とマウスは筆圧を伝えません。そのため、ペンが留まった場所にインクがたまるように、ゆっくり動かした部分ほどストロークが太く描かれます。各ストロークは `signature-stroke` のパスになります。一定の筆圧で `--signature-weight` の幅を持つ塗りつぶした輪郭で、点を通る曲線でなめらかにし、端は丸めます。ブラウザーがポインターの移動イベントをまとめる場合も、まとめられたイベントまで読み取るため、素早い筆運びでも曲線が保たれます。
- **値**　`value` はストロークの集まりで、設定するとストロークを描画します。この場合、イベントは発行されません。`svg` は描画内容を SVG ドキュメントにしたものです。`signature-value` フィールドも同じドキュメントを保持するため、フォームがそれを送信します。パスは `currentColor` を使い、画像としては黒になります。
- **イベント**　フィールドは、ストロークを描いている間に `input` を、描き終えたときに `change` を発行します。Undo や Clear でストロークを取り消したときは両方を発行します。
- **Undo と Clear**　Undo は最後のストロークを、Clear はすべてのストロークを取り消します。ストロークがないうちは、どちらも表示されません。取り消すものがない間、スクリプトはボタンに `aria-disabled` を付けます。そのため、パッドを空にしたばかりのボタンはフォーカスを保ったまま、その状態を伝えます。
- **ステータス**　`signature-status` は、最初のストロークを描き終えたときに「Signature drawn」、パッドが空になったときに「Signature cleared」、Undo の後に「Last stroke removed」と読み上げます。

| オプション | 設定する内容 |
| --- | --- |
| `drawn` | 最初のストロークを描き終えたときにステータスが読み上げる文言。既定値は「Signature drawn」です |
| `cleared` | パッドが空になったときに読み上げる文言。既定値は「Signature cleared」です |
| `undone` | Undo でストロークを取り消したときに読み上げる文言。既定値は「Last stroke removed」です |

ビヘイビアは `signaturePath(stroke, weight)` と `signatureSvg(strokes, { viewBox, weight })` もエクスポートしています。これらはページがなくても、ストロークをパスやドキュメントに変換します。サーバーはこれらを使って、保存済みの署名を最初の HTML に描画できます。

## 名前の入力 \{#a-typed-name\}

描画にはキーボード操作がありません。キーボード、スイッチ、スクリーンリーダーで署名する人や、手でストロークを描けない人は、名前を入力して署名します。そのため、名前の入力はこのパターンに欠かせない署名方法です。名前の入力は `signature-name` クラスを指定したネイティブの[入力フィールド](/components/input)で、`--signature-font` の筆記体で表示されます。`--signature-font` は各システムに付属する書体（Apple のシステムでは「Snell Roundhand」、Windows では「Segoe Script」）を並べ、最後を `cursive` としたフォントスタックです。プレースホルダーはインターフェースの書体のままです。

スクリプトがない場合、パッドでは描画できないため、入力した名前が署名のすべてになります。フォームは、ほかのフィールドと同様に、入力した名前をそのフィールドの `name` で送信します。

## フォームでの使用 \{#in-a-form\}

署名が必須の場合は、名前の入力に `required` を指定します。描画も同じ必須条件を満たします。ストロークがある間、ビヘイビアは名前の入力から `required` を外し、パッドが空になると元に戻します。どちらもないまま送信すると、名前の入力にブラウザー標準のメッセージが表示されます。一度送信を試みると、`:user-invalid` によってフィールドとパッドにエラーを示す輪郭が描かれ、フィールド内の `field-error` が表示されます。

## 比率とインク \{#proportions-and-ink\}

描画の `viewBox` が、パッドの比率とストロークの単位を決めます。パッドの幅は列と同じで、高さは `viewBox` によって決まります。そのため、スマートフォンで描いた署名をデスクトップで表示しても形が保たれます。フォームの 1 行には `0 0 400 160` が適しており、余裕のあるページには `0 0 480 140` のような横長のボックスが適しています。インクの色は `--signature-ink` で、既定値は強調テキストの色です。`--signature-weight` は一定の筆圧でのストロークの幅で、`viewBox` の単位で表し、ストロークを書き込むときに読み取られます。パッドの角丸は `--signature-radius` です。

## 画像への変換 \{#a-picture-of-it\}

描画内容は SVG として出力されます。SVG は拡大縮小でき、サイズも小さく保てます。PDF ライブラリやメールなどで PNG が必要な場合は、アプリケーションが SVG を canvas に描画します。

```js name=png.js
async function png(svg, scale = 2) {
  const url = URL.createObjectURL(new Blob([svg], { type: 'image/svg+xml' }))
  const image = new Image()
  image.src = url
  await image.decode()
  const canvas = document.createElement('canvas')
  canvas.width = image.naturalWidth * scale
  canvas.height = image.naturalHeight * scale
  canvas.getContext('2d').drawImage(image, 0, 0, canvas.width, canvas.height)
  URL.revokeObjectURL(url)
  return new Promise((resolve) => canvas.toBlob(resolve, 'image/png'))
}

const blob = await png(pad.svg)
```

ドキュメントは `viewBox` から取得したサイズを `width` と `height` に持つため、`scale` で解像度を決められます。canvas の何も描かれていない部分は透明です。

## アクセシビリティ \{#accessibility\}

- パッドと名前の入力を `<fieldset>` でまとめ、その凡例で署名の対象を示します。
- 描画には `role="img"` と `aria-label` を指定して画像として名前を付け、線とプレースホルダーは `aria-hidden="true"` で隠します。描画の名前がすでに署名する場所を伝えているためです。
- キー操作では描画できないため、パッドはフォーカスを受け取りません。名前の入力には、もう 1 つの署名方法であることがわかる、目に見えるラベルを付けます。
- ステータスの読み上げ優先度は polite です。パッドに署名されたときと空になったときに読み上げ、ストロークごとの読み上げは行いません。
- パッド上では、指でページをスクロールする代わりに描画します（`touch-action: none`）。スマートフォンの読者がパッドを通り過ぎてスクロールできるように、パッドの高さは署名に必要な分にとどめます。
- 強制カラーモードでは、ストロークは `CanvasText`、線と十字は `GrayText` で描画され、パッドには輪郭線が残ります。
- 同意、署名者の本人確認、署名日時の記録など、署名の法的要件には、アプリケーションが適用される法域に従って対応します。

## React、Svelte、Vue \{#frameworks\}

`signature` コンポーネントは全体を描画してビヘイビアを適用し、ストロークの受け渡しを行います。入力した名前は 2 つ目の値 `typed` です。最初の値は初回の描画に反映されるため、サーバーは署名をパッドに描いた状態で送信できます。`npx master-ui add signature` でプロジェクトにコピーできます。コンポーネントの構成と使い方は [React、Svelte、Vue](/guide/frameworks) を参照してください。
