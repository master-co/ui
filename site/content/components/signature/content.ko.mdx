서명 패드는 손가락, 펜, 마우스로 서명하는 오목한 영역과, 서명 대신 이름을 입력하는 필드로 구성됩니다. 패드는 [입력 필드](/components/input)와 같은 오목한 영역으로, 서명할 가는 기준선과 이름이 시작되는 위치의 작은 십자 표시가 있습니다. 각 획은 펜을 누른 세기만큼의 두께를 가진 채운 윤곽선으로 인라인 `<svg>`에 작성되며, 그림은 SVG 문서로 폼에 담깁니다. 그룹은 네이티브 `<fieldset>`입니다. legend가 무엇에 서명하는지를 밝히고, `<fieldset>`에 `disabled`를 설정하면 패드가 멈추고 안의 모든 요소가 비활성화됩니다.

## 동작 \{#behavior\}

패드에 그리려면 스크립트가 필요합니다. `signature` [동작](/guide/behaviors)은 `signature` 클래스가 있는 루트 요소를 받아, 연결한 동작을 해제하는 함수를 반환합니다.

```js name=app.js
import { signature } from '@master/ui/behaviors/signature.js'

const pad = signature(document.querySelector('.signature'))

pad.value // [[[x, y, pressure], …], …], one list of points a stroke
pad.svg   // '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 160" …>…</svg>', or '' when nothing is drawn
```

- **획.** 획은 포인터가 지나간 점들로, 그림의 `viewBox` 단위로 나타내며 각 점에는 0부터 1까지의 압력 값이 있습니다. 펜은 자체 압력 값을 제공하지만 손가락과 마우스는 제공하지 않으므로, 펜이 머무른 곳에 잉크가 고이듯 천천히 움직인 부분이 더 굵게 그려집니다. 각 획은 `signature-stroke` 경로가 됩니다. 고른 압력에서 `--signature-weight` 두께를 가진 채운 윤곽선으로, 점들을 지나는 곡선으로 매끄럽게 다듬어지고 끝은 둥급니다. 브라우저가 포인터 이동을 병합하는 경우 병합된 이동도 읽으므로, 손을 빠르게 움직여도 곡선이 유지됩니다.
- **값.** `value`는 획 목록이며, 이 값을 설정하면 획을 그리고 이벤트는 발생하지 않습니다. `svg`는 그림을 SVG 문서로 나타낸 것이며, `signature-value` 필드에도 같은 문서가 담기므로 폼이 이를 제출합니다. 경로는 `currentColor`를 사용하며, 이미지에서는 검은색이 됩니다.
- **이벤트.** 필드는 획을 그리는 동안 `input`을, 획이 끝나면 `change`를 발생시키며, Undo나 Clear로 획을 지울 때는 두 이벤트를 모두 발생시킵니다.
- **Undo와 Clear.** Undo는 마지막 획을, Clear는 모든 획을 지웁니다. 첫 획이 생기기 전까지 두 버튼은 화면에 표시되지 않습니다. 지울 것이 없는 동안 스크립트가 버튼에 `aria-disabled`를 설정하므로, 방금 패드를 비운 버튼은 포커스를 유지하며 그 상태를 알립니다.
- **상태.** `signature-status`는 첫 획이 끝나면 "Signature drawn", 패드가 비워지면 "Signature cleared", Undo 뒤에는 "Last stroke removed"라고 안내합니다.

| 옵션 | 설정하는 내용 |
| --- | --- |
| `drawn` | 첫 획이 끝났을 때 상태 영역이 안내하는 문구입니다. 기본값은 "Signature drawn"입니다 |
| `cleared` | 패드가 비워졌을 때 안내하는 문구입니다. 기본값은 "Signature cleared"입니다 |
| `undone` | Undo로 획을 지웠을 때 안내하는 문구입니다. 기본값은 "Last stroke removed"입니다 |

동작은 `signaturePath(stroke, weight)`와 `signatureSvg(strokes, { viewBox, weight })`도 내보냅니다. 이 함수들은 페이지 없이 획을 경로와 문서로 바꾸므로, 서버에서 이 함수로 저장된 서명을 첫 HTML에 그려 넣을 수 있습니다.

## 이름 입력 \{#a-typed-name\}

그림에는 키보드 조작이 없습니다. 키보드, 스위치, 스크린 리더로 서명하는 사람이나 손으로 획을 긋기 어려운 사람은 이름을 입력해 서명합니다. 따라서 이름 입력은 부가 기능이 아니라 이 패턴의 일부입니다. 이름 입력은 `signature-name` 클래스가 있는 네이티브 [입력 필드](/components/input)로, `--signature-font`의 필기체로 표시됩니다. `--signature-font`는 각 시스템에 기본 탑재된 글꼴(Apple 시스템의 "Snell Roundhand", Windows의 "Segoe Script")을 나열하고 `cursive`로 끝나는 글꼴 스택입니다. 플레이스홀더는 인터페이스 글꼴을 유지합니다.

스크립트가 없으면 패드에 그릴 수 없으므로 입력한 이름이 서명 전체가 됩니다. 폼은 다른 필드와 마찬가지로 이름 입력을 그 `name`으로 제출합니다.

## 폼에서 사용하기 \{#in-a-form\}

서명이 필수라면 이름 입력에 `required`를 설정하세요. 그림도 같은 필수 조건을 충족합니다. 획이 있는 동안 동작은 이름 입력에서 `required`를 제거하고, 패드가 비워지면 다시 설정합니다. 둘 다 없이 제출하면 이름 입력에 브라우저 자체의 메시지가 표시되며, 한 번 제출을 시도한 뒤에는 `:user-invalid`가 필드와 패드에 위험 윤곽선을 그리고 필드 안의 `field-error`가 표시됩니다.

## 비율과 잉크 \{#proportions-and-ink\}

그림의 `viewBox`가 패드의 비율과 획의 단위를 정합니다. 패드의 너비는 열의 너비와 같고 높이는 `viewBox`가 정하는 만큼이므로, 휴대폰에서 그린 서명을 데스크톱에서 보여 줘도 모양이 유지됩니다. `0 0 400 160`은 폼의 한 줄에 어울리고, `0 0 480 140`처럼 더 넓은 상자는 여유 공간이 있는 페이지에 어울립니다. 잉크 색은 `--signature-ink`로, 기본값은 강한 텍스트 색입니다. `--signature-weight`는 고른 압력에서의 획 두께를 `viewBox` 단위로 나타내며, 획을 작성할 때 읽힙니다. 패드의 모서리 반경은 `--signature-radius`입니다.

## 이미지로 내보내기 \{#a-picture-of-it\}

그림은 확대·축소해도 깨지지 않고 크기도 작은 SVG로 내보내집니다. PDF 라이브러리나 이메일처럼 PNG가 필요한 경우에는 애플리케이션이 SVG를 캔버스에 그립니다.

```js name=png.js
async function png(svg, scale = 2) {
  const url = URL.createObjectURL(new Blob([svg], { type: 'image/svg+xml' }))
  const image = new Image()
  image.src = url
  await image.decode()
  const canvas = document.createElement('canvas')
  canvas.width = image.naturalWidth * scale
  canvas.height = image.naturalHeight * scale
  canvas.getContext('2d').drawImage(image, 0, 0, canvas.width, canvas.height)
  URL.revokeObjectURL(url)
  return new Promise((resolve) => canvas.toBlob(resolve, 'image/png'))
}

const blob = await png(pad.svg)
```

문서는 `viewBox`에서 가져온 크기를 `width`와 `height`에 담고 있으므로, `scale`이 해상도를 정합니다. 캔버스에서 아무것도 그려지지 않은 부분은 투명합니다.

## 접근성 \{#accessibility\}

- 패드와 이름 입력을 무엇에 서명하는지 밝히는 legend가 있는 `<fieldset>`으로 묶으세요.
- 그림에 `role="img"`로 이미지 역할을 지정하고 `aria-label`로 이름을 붙인 뒤, 기준선과 플레이스홀더는 `aria-hidden="true"`로 숨기세요. 그림의 이름이 이미 어디에 서명할지 알려 줍니다.
- 키로 그릴 수 없으므로 패드는 포커스를 받지 않습니다. 이름 입력에는 서명하는 또 다른 방법임을 알리는 보이는 레이블을 지정하세요.
- 상태 영역은 보조 기술의 현재 안내를 끊지 않고 상태를 알립니다. 획마다 안내하지 않고, 패드에 서명했거나 패드가 비워졌을 때 안내합니다.
- 패드 위에서는 손가락이 페이지를 스크롤하지 않고 그림을 그립니다(`touch-action: none`). 휴대폰 사용자가 패드를 지나 스크롤할 수 있도록 패드의 높이를 서명에 필요한 만큼만 유지하세요.
- 강제 색상 모드에서는 획을 `CanvasText`로, 기준선과 십자 표시를 `GrayText`로 그리며, 패드는 윤곽선을 유지합니다.
- 동의, 서명자의 신원, 서명 시점의 기록처럼 어떤 표시를 법적으로 서명이 되게 하는 요소는 컴포넌트가 아니라 애플리케이션과 해당 관할 지역의 몫입니다.

## React, Svelte, Vue \{#frameworks\}

`signature` 컴포넌트는 그룹을 렌더링하고 동작을 연결하며, 획을 받아 외부로 전달합니다. 입력한 이름은 두 번째 값인 `typed`입니다. 첫 값은 첫 렌더링에 그려지므로, 서버가 보내는 페이지에는 서명이 이미 패드에 그려져 있습니다. `npx master-ui add signature` 명령을 실행해 프로젝트에 복사하세요. 컴포넌트의 구성과 사용 방법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
