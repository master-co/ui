签名板是一个可以用手指、触控笔或鼠标签名的凹槽，并附带一个可改为输入姓名的输入框。签名区域与[输入框](/components/input)是同样的凹槽，上面有一条用于签名的细线，姓名起始处有一个细小的十字。每一笔都以填充轮廓的形式写入内联 `<svg>`，宽度随笔压而变，绘制结果以 SVG 文档的形式进入表单。整个组是原生 `<fieldset>`：其 legend 说明签署的内容，在它上面设置 `disabled` 会停用签名区域并禁用其中的所有控件。

## 行为脚本 \{#behavior\}

签名区域需要脚本才能绘制。`signature` [行为脚本](/guide/behaviors)接收根元素，即带有 `signature` 类的元素，并返回用于解除绑定的函数。

```js name=app.js
import { signature } from '@master/ui/behaviors/signature.js'

const pad = signature(document.querySelector('.signature'))

pad.value // [[[x, y, pressure], …], …], one list of points a stroke
pad.svg   // '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 160" …>…</svg>', or '' when nothing is drawn
```

- **笔画。** 一笔就是指针经过的各个点，以绘图 `viewBox` 的单位表示，每个点带有 0 到 1 的压力值。触控笔会提供自己的压力值；手指和鼠标不提供，因此笔画在移动较慢的地方绘制得更粗，就像笔停留处墨水会积聚一样。每一笔都成为一条 `signature-stroke` 路径：在均匀压力下宽度为 `--signature-weight` 的填充轮廓，用经过各点的曲线平滑处理，端点为圆头。在浏览器合并指针移动事件的情况下，被合并的事件也会被读取，因此手速很快时曲线依然保留。
- **值。** `value` 是所有笔画，设置它会绘制这些笔画，且不派发任何事件。`svg` 是绘制结果的 SVG 文档，`signature-value` 字段保存同一份文档，因此表单会提交它。路径使用 `currentColor`，在图片中为黑色。
- **事件。** 绘制笔画时字段派发 `input`，笔画结束时派发 `change`；Undo 或 Clear 撤销笔画时两者都会派发。
- **Undo 和 Clear。** Undo 撤销最后一笔，Clear 清除全部笔画。在有笔画之前，这两个按钮隐藏不显示；没有可撤销的内容时，脚本将它们标记为 `aria-disabled`，因此刚刚清空签名区域的那个按钮会保留焦点，并表明这一状态。
- **状态。** 第一笔结束时，`signature-status` 播报“Signature drawn”；签名区域被清空时播报“Signature cleared”；Undo 之后播报“Last stroke removed”。

| 选项 | 设置的内容 |
| --- | --- |
| `drawn` | 第一笔结束时状态区域播报的内容。默认为“Signature drawn” |
| `cleared` | 签名区域被清空时播报的内容。默认为“Signature cleared” |
| `undone` | Undo 撤销一笔时播报的内容。默认为“Last stroke removed” |

行为脚本还导出 `signaturePath(stroke, weight)` 和 `signatureSvg(strokes, { viewBox, weight })`，它们无需页面即可把笔画转换为路径和文档：服务器可以用它们把已保存的签名绘制到初始 HTML 中。

## 输入姓名 \{#a-typed-name\}

绘图无法用键盘完成。使用键盘、开关设备或屏幕阅读器签名的人，或者手无法稳定画出笔画的人，可以通过输入姓名来签名，因此输入姓名是这一模式的组成部分，而不是附加功能。它是带有 `signature-name` 类的原生[输入框](/components/input)，以 `--signature-font` 中的手写字体显示，这是一组系统自带的字体（Apple 系统上的“Snell Roundhand”，Windows 上的“Segoe Script”），最后回退到 `cursive`。其占位文字保持界面字体。

没有脚本时，签名区域无法绘制，输入的姓名就是完整的签名：表单像提交任何字段一样，以它自己的 `name` 提交它。

## 在表单中 \{#in-a-form\}

签名为必填时，请把输入姓名的输入框标记为 `required`。绘制的签名同样满足这一要求：只要有笔画，行为脚本就会移除输入框上的 `required`，签名区域被清空时再恢复。读者既未绘制也未输入就提交时，会在输入框上看到浏览器自己的提示信息；尝试提交过一次之后，`:user-invalid` 会在输入框和签名区域上绘制危险轮廓，字段中的 `field-error` 也会显示出来。

## 只读和禁用 \{#read-only-and-disabled\}

根元素上的 `signature-readonly` 按原样显示已提供的签名：无法在上面绘制，Undo 和 Clear 也会隐藏。请同样给输入姓名的输入框加上 `readonly`，或者将其省略。`<fieldset>` 上的 `disabled` 会停用签名区域，把笔迹和文字变为禁用颜色，并像 fieldset 一贯的做法那样禁用其中的所有控件。

## 比例和笔迹 \{#proportions-and-ink\}

绘图的 `viewBox` 决定签名区域的比例和笔画的单位：签名区域与所在列同宽，高度由 `viewBox` 决定，因此在手机上绘制、在桌面上显示的签名会保持原有形状。`0 0 400 160` 适合表单中的一行；`0 0 480 140` 这样更宽的框适合空间充裕的页面。笔迹颜色为 `--signature-ink`，默认是高强调文字颜色；`--signature-weight` 是笔画在均匀压力下的宽度，以 `viewBox` 的单位表示，在写入笔画时读取。签名区域的圆角为 `--signature-radius`。

## 导出为图片 \{#a-picture-of-it\}

绘制结果以 SVG 导出，可以任意缩放且体积很小。如果需要 PNG，例如供 PDF 库或电子邮件使用，应用可以在 canvas 上绘制这份 SVG：

```js name=png.js
async function png(svg, scale = 2) {
  const url = URL.createObjectURL(new Blob([svg], { type: 'image/svg+xml' }))
  const image = new Image()
  image.src = url
  await image.decode()
  const canvas = document.createElement('canvas')
  canvas.width = image.naturalWidth * scale
  canvas.height = image.naturalHeight * scale
  canvas.getContext('2d').drawImage(image, 0, 0, canvas.width, canvas.height)
  URL.revokeObjectURL(url)
  return new Promise((resolve) => canvas.toBlob(resolve, 'image/png'))
}

const blob = await png(pad.svg)
```

文档在 `width` 和 `height` 中带有取自 `viewBox` 的尺寸，因此 `scale` 决定分辨率。canvas 上未绘制的地方是透明的。

## 无障碍 \{#accessibility\}

- 用 `<fieldset>` 把签名区域和输入姓名的输入框组合在一起，其 legend 说明要签署的内容。
- 把绘图命名为图片，即 `role="img"` 加上 `aria-label`，并用 `aria-hidden="true"` 隐藏细线和占位文字：绘图的名称已经说明了在哪里签名。
- 签名区域不获取焦点，因为没有任何按键可以绘制。请给输入姓名的输入框一个可见标签，说明这是另一种签名方式。
- 状态区域是礼貌型的：在签名完成或清空时播报，而不是每一笔都播报。
- 在签名区域上，手指会绘制而不是滚动页面（`touch-action: none`）。签名区域的高度不要超过签名所需，以便手机上的读者仍能滚动越过它。
- 在强制颜色模式下，笔画使用 `CanvasText` 绘制，细线和十字使用 `GrayText`，签名区域保留轮廓线。
- 让一个标记在法律上构成签名的要素，例如同意、签署人身份和时间记录，属于应用及其所在司法管辖区的范畴，而不属于组件。

## React、Svelte 和 Vue \{#frameworks\}

`signature` 组件渲染整个组，绑定行为脚本，并接收和传出笔画；输入的姓名是第二个值 `typed`。初始值会在首次渲染时绘制，因此服务器发送的页面中签名已经在签名区域上。使用 `npx master-ui add signature` 将组件复制到项目中。有关这些组件的实现和用法，请参阅 [React、Svelte 和 Vue](/guide/frameworks)。
