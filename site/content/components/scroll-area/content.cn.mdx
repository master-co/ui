滚动区域是页面内可独立滚动的区域，可用于面板中的长列表、宽表格或日志。它保留平台原生的滚动行为，使用纤细低调的滚动条。内容延伸到哪一侧的边缘之外，哪一侧就显示渐隐效果。内容到头时，对应边缘清晰可见。在阅读过程中末尾不断增长的区域，例如聊天或构建日志，还可以[跟随新内容](#follow)。

## 渐隐效果如何随滚动变化 \{#how-the-fade-knows\}

渐隐效果由遮罩实现，遮罩的两个渐变色标由自定义属性 `--scroll-area-start` 和 `--scroll-area-end` 控制。区域自身的滚动时间轴驱动两段动画：第一段在滚动范围的前 1.5rem 内逐渐显现起始边缘的渐隐效果，第二段在最后 1.5rem 内逐渐消除末端边缘的渐隐效果。整个过程无需脚本或哨兵元素。内容没有溢出时，时间轴处于非活动状态，两侧边缘都清晰可见。

浏览器不支持滚动驱动动画时，区域仍可照常滚动，边缘始终清晰可见。

## 滚动到边界后 \{#scrolling-past-it\}

沿块轴滚动到区域边界后，可以接着滚动页面。在已无法继续滚动的区域上使用滚轮或滑动时，页面会像在其他内容上操作一样滚动。只有行内轴会限制滚动传递，因此横向滑动到一行的末端时，手势会在那里停止，避免触发浏览器的返回操作。

## 沿行内轴滚动 \{#inline\}

`scroll-area-inline` 可横向滚动，并在行内轴的起始边缘和末端边缘显示渐隐效果，适用于一排卡片或比所在列更宽的[表格](/components/table#wide-tables)。

## 跟随新内容 \{#follow\}

聊天、构建日志或流式输出的回答会在阅读过程中从末尾不断增长。为区域设置 `role="log"`，并挂载 `follow` [行为脚本](/guide/behaviors)：新内容到达时，它让末尾保持可见；读者一旦从末尾滚开，就停止跟随；读者回到末尾时，再次跟随。在内容之后放一个带有 `hidden` 的 `scroll-area-latest` 按钮：它只在区域未跟随时出现，按下后会滚动到末尾并重新跟随。

判断方式如下：

- **跟随。** 从挂载行为脚本的那一刻起，区域就开始跟随：它会滚动到末尾，此后只要内容增长，无论是新增一行、流式输出的词语落入最后一条消息，还是一张图片加载完成，都会再次滚动到末尾。
- **停止。** 向开头方向滚动会停止跟随，无论由什么引起：滚轮、手指、滚动条、<kbd>↑</kbd>、<kbd>Page Up</kbd> 或 <kbd>Home</kbd>。向开头方向转动滚轮会在区域移动之前立即停止跟随，因此恰在此刻到达的词语也不会把读者拉回去。
- **再次跟随。** 通过 <kbd>End</kbd>、滚动条或按钮重新到达末尾，就会再次跟随。距离末尾只差几个像素也算作到达末尾。
- **事件。** 每当读者使区域开始或停止跟随，区域都会派发 `change`。行为脚本的 `value` 表示是否正在跟随；将其设为 `true` 可把读者带到末尾，例如应用在读者发送消息时就会这样做。设置它不会派发事件。

```js name=app.js
import { follow } from '@master/ui/behaviors/follow.js'

const log = document.querySelector('.scroll-area[role="log"]')
const following = follow(log)

form.addEventListener('submit', () => { following.value = true })
```

没有行为脚本时，该区域就是普通的滚动区域：停留在读者离开的位置，按钮保持隐藏。按钮粘性定位在区域底部，位于内容和渐隐边缘之上，并叠放在最后一行上方，而不是排在其后，因此显示按钮不会让内容变高。

## 保持阅读位置 \{#keeping-the-place\}

在读者正在查看的内容上方插入内容，例如在顶部加载更早的消息，会把正在阅读的内容往下推。浏览器会通过滚动锚定自行避免这一点：区域内的滚动位置会随上方内容的位移相应调整，正在阅读的消息保持在原位。样式表在区域上保留 `overflow-anchor: auto`，在其按钮上设置 `none`，因此浏览器不会把按钮当作固定不动的元素。在不支持滚动锚定的浏览器中，`follow` 行为脚本会按上方内容移动的距离自行完成同样的调整。位于顶部、其下方会插入新行的一行文字，例如提示正在加载更多内容的说明，也要设置 `overflow-anchor: none`，让浏览器固定的是某一行内容，而不是这行文字。

## 无障碍 \{#accessibility\}

- 滚动区域必须能通过键盘访问。如果区域内没有可聚焦的内容，为区域设置 `tabindex="0"`、一个 `role`（如 `region`）以及无障碍名称。
- 遮罩也会让区域自身的滚动条在相同的边缘渐隐。强制颜色模式下会移除遮罩。
- 为区域设置高度或最大高度。两者都未设置时，区域会随内容撑开，始终不会滚动。
- `role="log"` 是礼貌型实时区域：添加到其中的内容会被播报，而不会移动焦点。回答以流式方式写入某条消息时，为该消息设置 `aria-busy="true"`，回答完成后再移除，使它完整地播报一次，而不是逐词播报。
- `scroll-area-latest` 按钮显示时是 Tab 键顺序中的真正按钮。按下后按钮隐藏，焦点移到区域上，之后可用按键滚动区域。
- 跟随从不移动焦点，并且读者一滚开就停止，因此不断到达的内容永远不会把页面从正在阅读的人眼前抽走。
