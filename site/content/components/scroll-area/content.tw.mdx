捲動區域是頁面內可獨立捲動的範圍，例如面板中的長清單、寬表格或記錄。它沿用平台的原生捲動行為，搭配纖細低調的捲動條。內容超出哪一側，該側邊緣就會淡出。捲到內容盡頭時，該側邊緣會恢復清晰。閱讀期間內容會在結尾持續增加的區域，例如聊天或建置記錄，也可以[跟隨新內容](#follow)。

## 淡出效果如何運作 \{#how-the-fade-knows\}

淡出效果由遮罩繪製，兩個漸層停止點分別由自訂屬性 `--scroll-area-start` 和 `--scroll-area-end` 控制。這兩個屬性各由一段動畫驅動，兩段動畫都使用區域自己的捲動時間軸。第一段在最初 1.5rem 的捲動距離內逐漸顯示起始側的淡出效果，第二段則在最後 1.5rem 逐漸移除結束側的淡出效果。整個過程無須使用腳本或偵測用元素。內容沒有溢出時，時間軸不會啟用，兩側邊緣都保持清晰。

瀏覽器若不支援捲動驅動動畫，區域仍可照常捲動，邊緣會保持清晰。

## 捲到邊界後 \{#scrolling-past-it\}

沿區塊軸捲到區域盡頭後，頁面會接著捲動。即使滑鼠滾輪操作或滑動手勢從區域內開始，只要該方向已無內容可捲動，就會像在頁面其他內容上操作一樣捲動頁面。只有行內軸的捲動會限制在區域內，因此側向滑到一列的盡頭時，手勢就此停止，不會觸發瀏覽器的返回手勢。

## 跟隨新內容 \{#follow\}

聊天、建置記錄或串流產生的回答，會在閱讀期間於結尾持續增加。為區域加上 `role="log"` 並掛載 `follow` [行為](/guide/behaviors)：內容送達時，它會讓結尾保持在視野內；讀者一捲離結尾就停止跟隨，回到結尾時再恢復跟隨。在內容之後放一個帶有 `hidden` 的 `scroll-area-latest` 按鈕：它只在區域未跟隨時出現，按下後會捲到結尾並恢復跟隨。

判斷方式：

- **跟隨。** 從掛載行為的那一刻起，區域就會跟隨：它會捲到結尾，而每當內容增加，無論是新增一列、串流的文字落在最後一則訊息中，或圖片載入完成，都會再次捲到結尾。
- **停止。** 往起點方向捲動就會停止跟隨，無論是由滑鼠滾輪、手指、捲動條、<kbd>↑</kbd>、<kbd>Page Up</kbd> 或 <kbd>Home</kbd> 造成。往起點方向轉動滾輪時，會在區域移動之前立即停止，因此在那一瞬間送達的文字不會把讀者拉回去。
- **恢復跟隨。** 用 <kbd>End</kbd>、捲動條或按鈕再次到達結尾時，就會恢復跟隨。距離結尾只差幾個像素也算是結尾。
- **事件。** 每當讀者讓區域開始或停止跟隨，區域都會派送 `change`。行為的 `value` 表示是否正在跟隨；將它設為 `true` 可讓讀者回到結尾，就像應用程式在讀者送出訊息時所做的那樣。設定它不會派送事件。

```js name=app.js
import { follow } from '@master/ui/behaviors/follow.js'

const log = document.querySelector('.scroll-area[role="log"]')
const following = follow(log)

form.addEventListener('submit', () => { following.value = true })
```

沒有行為時，區域就是一般的捲動區域：它會停在讀者離開的位置，按鈕也會保持隱藏。按鈕以 sticky 定位固定在區域底部，位於內容和淡出邊緣上方，並疊在最後一列上而不是排在它後面，因此顯示按鈕永遠不會讓內容變高。

## 保留讀者的位置 \{#keeping-the-place\}

在讀者正在看的內容上方插入內容，例如在頂端載入較早的訊息，會把正在閱讀的內容往下推。瀏覽器本身會用捲動錨定避免這種情況：區域會隨著上方的內容移動，讓正在閱讀的訊息留在原處。樣式表在區域上保留 `overflow-anchor: auto`，並在其按鈕上設定 `none`，按鈕永遠不會是瀏覽器固定不動的元素。瀏覽器不支援捲動錨定時，`follow` 行為會自行處理，移動的距離與上方內容移動的距離相同。頂端若有一行內容，新的列會插入在它下方，例如提示正在載入更多內容的說明，也請設定 `overflow-anchor: none`，讓瀏覽器固定某一列而不是這行說明。

## 無障礙 \{#accessibility\}

- 使用者必須能透過鍵盤將焦點移到可捲動區域。若區域內沒有可取得焦點的內容，請加上 `tabindex="0"`、適當的 `role`（例如 `region`）和標籤。
- 遮罩也會讓區域自己的捲動條在相同的邊緣淡出。強制色彩模式下會移除遮罩。
- 為區域設定高度或最大高度，否則它會隨內容增高，不會產生捲動。
- `role="log"` 是禮貌型即時區域：新增到其中的內容會被播報，但不會移動焦點。回答正在串流進某則訊息時，請為該訊息加上 `aria-busy="true"`，並在回答完成後移除，讓它完整地播報一次，而不是逐字播報。
- `scroll-area-latest` 按鈕顯示時，是位於 Tab 順序中的真正按鈕。按下後它會隱藏，焦點會移到區域，之後即可用按鍵捲動區域。
- 跟隨永遠不會移動焦點，而且讀者一捲離就會停止，因此持續送達的內容永遠不會讓正在閱讀的人失去所在的位置。
