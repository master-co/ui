일정표는 하루의 시간을 세로 시간축에 표시하고, 각 일정의 높이로 소요 시간을 나타냅니다. 캘린더의 일간 보기, 콘퍼런스의 회의실별 일정, 병원의 진료 예약에 사용할 수 있습니다. 일정은 순서가 있는 목록으로 작성하고, 각 항목에 제목과 시간을 텍스트로 표시합니다. 스타일시트는 시간 눈금에 맞춰 일정을 배치하고, 한 시간 간격으로 가는 눈금선을 긋고 각 눈금선에 레이블을 붙입니다. 시간이 겹치는 일정은 나란히 놓입니다. 스크립트나 별도의 측정 없이 동작합니다.

하루 종일 이어지는 일정은 시간 영역 위의 띠에 표시합니다. 월간 보기는 날짜마다 일정을 레인에 배치하고, 일정 목록은 일정을 날짜별로 나열합니다. [일정표 보기](#schedule-view)는 독자가 직접 조작하는 일정표로, `schedule` 동작을 바탕으로 일간, 주간, 월간 또는 일정 목록으로 전환할 수 있습니다.

## 일정 배치 방식 \{#how-an-event-gets-its-place\}

표시 범위는 `--schedule-from`부터 `--schedule-to`까지이며, `schedule`에 설정합니다. 한 시간의 높이는 `--schedule-hour`로 지정하며 기본값은 48px입니다. 각 `schedule-event`에서 `--start`와 `--end`에 같은 24시간제 기준의 시간 값을 지정합니다. 오전 10시 30분은 10.5, 오후 1시 45분은 13.75입니다. 일정은 지정한 시각에 시작하고 끝나며 위아래의 가는 선과 각각 1px씩 떨어져 있어, 한 일정이 끝나는 시각에 다른 일정이 시작해도 둘 사이에 선이 남습니다.

`schedule-rail`에는 `--schedule-from`부터 `--schedule-to`까지 마지막 시각까지 한 시간 간격으로 레이블이 하나씩 들어갑니다. 각 레이블의 세로 중앙은 해당 눈금선과 맞춰집니다. 독자에게 익숙한 형식으로 시각을 표기하세요. 시간축의 너비는 48px(`--schedule-rail`)입니다.

한 시간에 48px이면 하루 전체 높이가 1,100픽셀을 넘습니다. 필요한 시간대만 표시하거나 일정표를 [스크롤 영역](/components/scroll-area)에 넣으세요.

## 겹치는 일정 \{#events-that-overlap\}

시간이 겹치는 일정은 너비를 나눠 씁니다. 각 일정의 `--lanes`에는 나란히 배치할 일정의 개수를, `--lane`에는 0부터 시작하는 배치 순서를 지정하세요. 위 예시에서 디자인 검토와 인터뷰는 같은 시간대에 두 열로 나란히 배치됩니다. 목록을 렌더링하는 쪽에서 데이터를 바탕으로 각 일정의 열을 결정하고, 스타일시트는 그 값에 따라 배치합니다.

## 짧은 일정 \{#short-events\}

각 일정은 크기 컨테이너이므로 자체 높이에 따라 텍스트 배치가 달라집니다.

- 기본 크기에서 한 시간 이상인 일정은 제목을 위에, 시간을 아래에 표시합니다.
- 더 짧은 일정은 제목과 시간을 한 줄에 놓고 일정의 세로 중앙에 맞춥니다. 둘 다 들어갈 공간이 없으면 시간은 화면에서 숨깁니다.
- 기본 크기에서 15분짜리 일정처럼 한 줄도 들어갈 공간이 없으면 배경색이 있는 일정 블록만 표시합니다. 제목과 시간은 보조 기술이 읽을 수 있도록 목록에 남으며, 화면에서는 시간축의 위치로 시각을 알 수 있습니다.

## 현재 시각과 현재 일정 \{#now\}

일정표에 `schedule-now`를 적용하면 `--now`로 지정한 시각에 진한 선이 그려지고, 선이 일정 영역의 시작 가장자리와 만나는 곳에 점이 표시됩니다. 시각은 일정과 같은 시간 단위로 지정합니다. 선은 일정 블록 뒤로 지나가므로 텍스트를 가로지르지 않습니다.

`aria-current="true"`로 표시한 일정은 진한 배경색으로 강조됩니다. 진행 중인 일정이나 일정표 옆에 세부 정보가 열려 있는 일정에 사용합니다.

## 세부 정보를 여는 일정 \{#events-that-open-something\}

## 종일 일정 \{#whole-days\}

## 월간 보기 \{#month\}

`schedule-month`는 한 달을 7일 단위의 주로 나누어 표시합니다. 각 `schedule-week`에는 날짜, 그날 시작하는 일정, 더 보기 버튼을 차례로 작성하므로 스크린 리더는 날짜 순서대로 내용을 읽습니다. 스타일시트는 각 요소를 해당 열과 레인에 배치합니다. 날짜 숫자인 `schedule-date-number`는 그날을 여는 원형 버튼이며, 오늘은 진한 색으로 표시됩니다. 하루에는 `--lanes`개(기본값 3개)의 일정을 표시하고, 나머지는 `schedule-more` 버튼 뒤로 들어갑니다. 이 버튼을 누르면 나머지 일정을 나열하는 [팝오버](/components/popover)가 열립니다. 월간 보기의 짧은 일정은 `schedule-event-plain`으로 간단하게 표시합니다. 일정 블록 없이 점, 시간, 제목만 표시합니다.

너비가 36rem보다 좁은 공간에서는 레인을 사용하지 않습니다. 대신 각 날짜의 숫자 아래에 일정마다 점을 하나씩 최대 3개까지 표시하며, 숫자를 누르면 그날이 열립니다. 텍스트를 좁은 7개 열에 억지로 밀어 넣지 않습니다.

`schedule-agenda`는 같은 일정을 날짜별로 나열합니다. 각 행의 시작 부분에 날짜를 표시하고 그 옆의 `schedule-list`에 일정을 표시하며, 좁은 공간에서는 날짜를 일정 위에 표시합니다. 휴대폰, 인쇄물, 그리고 보는 것보다 읽는 것을 선호하는 독자에게 적합합니다.

월간 보기와 일정 목록은 일정 데이터로 작성하므로, 아래 예시처럼 동작이나 프레임워크 컴포넌트가 생성합니다.

## 직접 조작하는 일정표 \{#schedule-view\}

`schedule-view`는 조작 버튼이 있는 헤더를 본문 위에 배치하고, 본문은 [`schedule` 동작](/guide/behaviors)이 작성합니다. 헤더에는 오늘, 이전, 다음 버튼과 기간 이름, 그리고 일간·주간·월간·일정 목록 전환 스위치가 있습니다. 이전과 다음 버튼은 현재 보기의 기간 단위로 이동하고, 날짜 숫자를 누르면 그날이 열리며, 기간 이름이 바뀌면 이를 알립니다. 좁은 공간에서는 기간 이름이 한 줄을 따로 차지합니다.

### 일정 데이터 \{#the-events\}

각 일정에는 고정된 `id`, `title`, `start`, `end`가 있습니다. 종일 일정은 `allDay: true`를 지정하고 시작과 끝을 `YYYY-MM-DD` 형식의 날짜로 지정합니다. 그 밖의 일정은 `YYYY-MM-DDTHH:mm` 형식의 현지 시각을 사용합니다. `end`는 해당 시점을 포함하지 않습니다. 13일 하루만 진행되는 종일 일정은 14일에 끝나며, 자정에 끝나는 일정은 전날에 끝나는 것으로 처리됩니다. `category`는 팔레트 이름으로, 예를 들어 `blue`는 `category-blue`에 해당합니다. `href`를 지정하면 일정이 링크가 되고, 지정하지 않으면 일정의 id를 `value`로 갖는 버튼이 되며 페이지에서 이 버튼의 이벤트를 수신합니다.

시간은 일정표를 표시하는 시간대로 이미 변환된 값이어야 하며, 반복 일정은 각 회차를 개별 일정으로 전달해야 합니다. 시간대와 반복 규칙은 애플리케이션에서 처리합니다. 날짜는 달력 기준으로 계산하며 정오 시각으로 유지하므로, 일광 절약 시간이 바뀌어도 종일 일정이 전날로 밀리지 않습니다. 이 보기는 일정을 편집, 이동, 저장하지 않습니다. 일정을 표시하고 어떤 일정을 눌렀는지 알려 줄 뿐입니다.

### 동작 \{#behavior\}

```js name=app.js
import { schedule } from '@master/ui/behaviors/schedule.js'

const team = schedule(document.querySelector('.schedule-view'), { events, today: '2026-11-13' })
team.value // { date: '2026-11-13', view: 'month' }
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `events` | `[]` | 위에서 설명한 일정 데이터 |
| `value` | 오늘이 속한 달 | 처음 표시할 날짜와 보기를 나타내는 `{ date, view }`. 보기는 `day`, `week`, `month`, `agenda` 중 하나입니다. |
| `today` | 브라우저의 오늘 날짜 | `YYYY-MM-DD` 형식의 오늘 날짜. 서버에서 일정표를 렌더링할 때 지정하면 서버와 브라우저의 날짜가 일치합니다. |
| `locale` | 페이지의 `lang` | 요일과 월 이름에 사용할 BCP 47 태그 |
| `weekStart` | 로캘의 주 시작 요일 | 한 주의 첫날. 일요일은 0, 토요일은 6입니다. |
| `lanes` | `3` | 월간 보기의 하루에 표시할 일정 수. 나머지는 더 보기 버튼 뒤로 들어갑니다. |
| `from`, `to` | `8`, `18` | 일간·주간 보기에서 최소한으로 표시할 시간 범위. 더 이르거나 늦은 일정이 있으면 범위가 넓어집니다. |
| `messages` | 영어 | 띠의 이름, 더 보기 버튼의 텍스트와 이름, 빈 일정 목록에 표시할 문장 |
| `draw` | 없음 | 제목과 본문을 직접 작성하는 렌더러가 있을 때 작성 작업을 넘겨받는 함수 |

독자가 조작하면 루트에서 `input` 및 `change` 이벤트가 발행됩니다. 함수가 반환하는 객체의 `value`는 읽고 설정할 수 있으며, 값을 설정할 때는 이벤트가 발행되지 않습니다. `scheduleLayout(value, options)`은 보기에 표시할 내용을 데이터로 반환합니다. 각 일정의 레인이 포함된 주, 각 일정의 위치가 포함된 시간, 띠, 일정 목록의 날짜가 들어 있으므로 서버, 프레임워크, 동작이 같은 일정을 같은 방식으로 배치합니다.

## 일정표, 간트 차트, 캘린더 \{#schedule-gantt-or-calendar\}

일정표는 일정을 시간 위에 배치하는 컴포넌트로, 하루의 시간대를 위에서 아래로 읽거나 한 달의 날짜를 표시합니다. 계획의 각 항목을 한 행씩 배치하고 공통 시간축에 기간을 표시하려면 [간트 차트](/components/gantt)를 사용합니다. 한 달에서 날짜나 날짜 범위를 고를 때는 [캘린더](/components/calendar)를, 사건을 발생한 순서대로 보여 줄 때는 [타임라인](/components/timeline)을 사용합니다.

## 접근성 \{#accessibility\}

- 일정을 시간순으로 `<ol>`에 작성하고 목록에 이름을 지정하세요. 하루만 표시할 때는 `aria-label`을 사용하세요. 여러 날을 표시할 때는 각 날짜의 `schedule-day`에서 `aria-labelledby`로 해당 날짜의 제목을 참조하세요.
- 각 일정의 제목과 시간을 텍스트로 작성하고, 시각은 `<time datetime>` 요소로 표시하세요. 그러면 시각적 배치 없이도 "디자인 검토, 10:00부터 11:30까지"처럼 읽을 수 있습니다. 시간축은 같은 시간 정보를 시각적으로 반복하므로 `aria-hidden="true"`로 보조 기술에서 숨기세요.
- 현재 일정과 오늘 날짜는 `aria-current` 속성으로 표시하며, 스크린 리더가 이를 알려 줍니다. 현재 시각을 나타내는 선은 스타일시트가 그리므로, 현재 시각을 알아야 하는 곳에는 텍스트로도 표기하세요.
- 강제 색상 모드에서는 각 일정에 윤곽선이 표시되고 현재 일정은 강조색으로 채워집니다. 가는 눈금선과 현재 시각을 나타내는 선에는 시스템 색상이 적용됩니다.
- 월간 보기는 날짜 그리드가 아닙니다. 날짜는 그날을 여는 숫자이고 일정은 링크나 버튼이며, 각각 제목과 시각으로 이름이 지정됩니다. 더 보기 버튼은 몇 개의 일정을 어느 날짜에 나열하는지 알려 줍니다. 카테고리 색상만으로 일정을 구분하지 않습니다.
- 보기의 조작 버튼은 화면이 바뀌어도 포커스를 유지합니다. 날짜 숫자는 달을 이동하면 사라지므로, 날짜 숫자로 하루를 열면 포커스가 그날의 이름으로 이동합니다.

## React, Svelte 및 Vue \{#frameworks\}

`schedule` 컴포넌트는 `scheduleLayout()`으로 기간을 작성하므로 서버가 보내는 첫 HTML에 그 내용이 포함됩니다. 또한 헤더와 날짜 숫자에 반응하는 동작을 연결합니다. 값은 `{ date, view }`이며, `href`가 없는 일정을 누르면 `onEventClick`(Vue에서는 `eventClick`)으로 전달됩니다. 서버에서 렌더링할 때는 `today`와 `locale`을 지정하세요. `npx master-ui add schedule`로 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte 및 Vue](/guide/frameworks)에서 확인할 수 있습니다.
