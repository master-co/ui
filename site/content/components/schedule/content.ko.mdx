일정표는 하루의 시간을 세로 시간축에 표시하고, 각 일정의 높이로 소요 시간을 나타냅니다. 캘린더의 일간 보기, 콘퍼런스의 회의실별 일정, 병원의 진료 예약에 사용할 수 있습니다. 일정은 순서가 있는 목록으로 작성하고, 각 항목에 제목과 시간을 텍스트로 표시합니다. 스타일시트는 시간 눈금에 맞춰 일정을 배치하고, 한 시간 간격으로 가는 눈금선을 긋고 각 눈금선에 레이블을 붙입니다. 시간이 겹치는 일정은 나란히 놓입니다. 스크립트나 별도의 측정 없이 동작합니다.

## 일정 배치 방식 \{#how-an-event-gets-its-place\}

표시 범위는 `--schedule-from`부터 `--schedule-to`까지이며, `schedule`에 설정합니다. 한 시간의 높이는 `--schedule-hour`로 지정하며 기본값은 48px입니다. 각 `schedule-event`에서 `--start`와 `--end`에 같은 24시간제 기준의 시간 값을 지정합니다. 오전 10시 30분은 10.5, 오후 1시 45분은 13.75입니다. 일정은 지정한 시각에 시작하고 끝나며 위아래의 가는 선과 각각 1px씩 떨어져 있어, 한 일정이 끝나는 시각에 다른 일정이 시작해도 둘 사이에 선이 남습니다.

`schedule-rail`에는 `--schedule-from`부터 `--schedule-to`까지 마지막 시각까지 한 시간 간격으로 레이블이 하나씩 들어갑니다. 각 레이블의 세로 중앙은 해당 눈금선과 맞춰집니다. 독자에게 익숙한 형식으로 시각을 표기하세요. 시간축의 너비는 48px(`--schedule-rail`)입니다.

한 시간에 48px이면 하루 전체 높이가 1,100픽셀을 넘습니다. 필요한 시간대만 표시하거나 일정표를 [스크롤 영역](/components/scroll-area)에 넣으세요.

## 겹치는 일정 \{#events-that-overlap\}

시간이 겹치는 일정은 너비를 나눠 씁니다. 각 일정의 `--lanes`에는 나란히 배치할 일정의 개수를, `--lane`에는 0부터 시작하는 배치 순서를 지정하세요. 위 예시에서 디자인 검토와 인터뷰는 같은 시간대에 두 열로 나란히 배치됩니다. 목록을 렌더링하는 쪽에서 데이터를 바탕으로 각 일정의 열을 결정하고, 스타일시트는 그 값에 따라 배치합니다.

## 짧은 일정 \{#short-events\}

각 일정은 크기 컨테이너이므로 자체 높이에 따라 텍스트 배치가 달라집니다.

- 기본 크기에서 한 시간 이상인 일정은 제목을 위에, 시간을 아래에 표시합니다.
- 더 짧은 일정은 제목과 시간을 한 줄에 놓고 일정의 세로 중앙에 맞춥니다. 둘 다 들어갈 공간이 없으면 시간은 화면에서 숨깁니다.
- 기본 크기에서 15분짜리 일정처럼 한 줄도 들어갈 공간이 없으면 배경색이 있는 일정 블록만 표시합니다. 제목과 시간은 보조 기술이 읽을 수 있도록 목록에 남으며, 화면에서는 시간축의 위치로 시각을 알 수 있습니다.

## 현재 시각과 현재 일정 \{#now\}

일정표에 `schedule-now`를 적용하면 `--now`로 지정한 시각에 진한 선이 그려지고, 선이 일정 영역의 시작 가장자리와 만나는 곳에 점이 표시됩니다. 시각은 일정과 같은 시간 단위로 지정합니다. 선은 일정 블록 뒤로 지나가므로 텍스트를 가로지르지 않습니다.

`aria-current="true"`로 표시한 일정은 진한 배경색으로 강조됩니다. 진행 중인 일정이나 일정표 옆에 세부 정보가 열려 있는 일정에 사용합니다.

## 여러 날 보기 \{#several-days\}

여러 날을 나란히 표시하려면 각 날짜의 `schedule-events` 목록을 `schedule-day` 안에 넣고 그 위에 `schedule-heading`을 배치하세요. 각 날짜 열은 너비를 나눠 쓰고 시간축을 공유하며, 열마다 제목과 시간 눈금이 같은 높이에 정렬됩니다. 오늘 열에 `aria-current="date"`를 지정하세요. 오늘의 제목은 진한 색으로 표시되며, 현재 시각을 나타내는 선은 오늘 열에서 점과 함께 표시되고 다른 날짜 열에서는 가는 선으로 이어집니다.

## 세부 정보를 여는 일정 \{#events-that-open-something\}

일정을 눌러 세부 정보를 열 수 있게 하려면 `schedule-event`를 목록 항목 자체에서 그 안의 링크나 버튼으로 옮기세요. 배치 방식은 같으며, 호버하면 배경색이 한 단계 진해지고 키보드로 포커스하면 윤곽선이 표시됩니다.

```html
<li>
  <a class="schedule-event" href="/events/design-review" style="--start: 10; --end: 11.5">
    <span class="schedule-title">Design review</span>
    <span class="schedule-time"><time datetime="10:00">10:00</time> – <time datetime="11:30">11:30</time></span>
  </a>
</li>
```

## 일정표, 간트 차트, 캘린더 \{#schedule-gantt-or-calendar\}

일정표는 하루의 시간대를 위에서 아래로 읽는 컴포넌트입니다. 계획의 각 항목을 한 행씩 배치하고 공통 시간축에 기간을 표시하려면 [간트 차트](/components/gantt)를 사용합니다. 월간 보기에서 날짜를 고를 때는 [캘린더](/components/calendar)를, 사건을 발생한 순서대로 보여 줄 때는 [타임라인](/components/timeline)을 사용합니다.

## 접근성 \{#accessibility\}

- 일정을 시간순으로 `<ol>`에 작성하고 목록에 이름을 지정하세요. 하루만 표시할 때는 `aria-label`을 사용하세요. 여러 날을 표시할 때는 각 날짜의 `schedule-day`에서 `aria-labelledby`로 해당 날짜의 제목을 참조하세요.
- 각 일정의 제목과 시간을 텍스트로 작성하고, 시각은 `<time datetime>` 요소로 표시하세요. 그러면 시각적 배치 없이도 "디자인 검토, 10:00부터 11:30까지"처럼 읽을 수 있습니다. 시간축은 같은 시간 정보를 시각적으로 반복하므로 `aria-hidden="true"`로 보조 기술에서 숨기세요.
- 현재 일정과 오늘 날짜는 `aria-current` 속성으로 표시하며, 스크린 리더가 이를 알려 줍니다. 현재 시각을 나타내는 선은 스타일시트가 그리므로, 현재 시각을 알아야 하는 곳에는 텍스트로도 표기하세요.
- 강제 색상 모드에서는 각 일정에 윤곽선이 표시되고 현재 일정은 강조색으로 채워집니다. 가는 눈금선과 현재 시각을 나타내는 선에는 시스템 색상이 적용됩니다.
