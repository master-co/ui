A text field is a well cut into its surface. On focus it rises to the sheet and takes a single ink contour with a soft halo. Use `.input` on `<input>` and `<textarea>`, and `.field` on the `<label>` that holds it.

<ComponentPreview name="default" title="Input" bodyClass="p-lg" html={`<label class="field">
  Email
  <input class="input" type="email" placeholder="you@example.com">
</label>`} />

## Hint and error \{#hint-and-error\}

Connect a hint or an error to its field with `aria-describedby`, and mark an invalid value with `aria-invalid="true"`.

<ComponentPreview name="hint" title="Hint and error" bodyClass="grid gap-lg p-lg" html={`<label class="field">
  Project name
  <input class="input" value="atlas" aria-describedby="name-hint">
  <span class="field-hint" id="name-hint">Lowercase letters, numbers and dashes.</span>
</label>
<label class="field">
  Domain
  <input class="input" value="atlas" aria-invalid="true" aria-describedby="domain-error">
  <span class="field-error" id="domain-error">Enter a full domain, such as atlas.dev.</span>
</label>`} />

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `input` | A text input or textarea |
| `input-sm`, `input-lg` | 32px and 44px heights; the default is 40px |
| `field` | A label stacked over its control |
| `field-hint`, `field-error` | Muted guidance and the danger message under a control |
