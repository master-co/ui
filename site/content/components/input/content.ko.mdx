텍스트 입력 필드는 표면을 파낸 듯한 오목한 영역으로, 0.5px 두께의 윤곽선으로 둘러싸입니다. 포커스를 받으면 주변 표면과 같은 높이로 올라오고, 전경색 윤곽선 하나와 은은한 후광이 나타납니다. `<input>`과 `<textarea>`에는 `.input`을, 필드를 감싸는 `<label>`에는 `.field`를 사용하세요.

<ComponentPreview name="default" height={120} title="입력 필드" background="plain" bodyClass="p-lg" html={`<label class="field">
  Email
  <input class="input" type="email" placeholder="you@example.com">
</label>`} />

## 힌트와 오류 \{#hint-and-error\}

`aria-describedby`로 힌트나 오류를 해당 필드에 연결하고, 유효하지 않은 값은 `aria-invalid="true"`로 표시하세요. `field-error`는 필드가 유효하지 않을 때만 힌트 대신 표시되므로, 처음부터 둘 다 마크업에 넣어 둘 수 있습니다.

<ComponentPreview name="hint" height={264} title="힌트와 오류" background="plain" bodyClass="grid gap-lg p-lg" html={`<label class="field">
  Project name
  <input class="input" value="atlas" aria-describedby="name-hint">
  <span class="field-hint" id="name-hint">Lowercase letters, numbers and dashes.</span>
</label>
<label class="field">
  Domain
  <input class="input" value="atlas" aria-invalid="true" aria-describedby="domain-error">
  <span class="field-error" id="domain-error">Enter a full domain, such as atlas.dev.</span>
</label>`} />

## 브라우저 기본 유효성 검사 \{#native-validation\}

스크립트 없이도 브라우저 자체의 제약 조건에 따라 같은 상태가 표시됩니다. `required`, `type`, `pattern` 중 하나가 지정된 필드에는 `:user-invalid`를 통해 오류 윤곽선이 표시됩니다. 이 선택자는 사용자가 필드를 편집하거나 폼 제출을 시도한 뒤에만 유효하지 않은 필드에 적용되며, 폼을 처음 열었을 때는 적용되지 않습니다. 이때 `field-error`도 함께 표시됩니다.

<ComponentPreview name="validation" height={208} narrowHeight={224} title="브라우저 기본 유효성 검사" background="plain" bodyClass="p-lg" html={`<form class="flex flex-col gap-md">
  <label class="field">
    Work email
    <input class="input" type="email" required placeholder="you@company.com" aria-describedby="work-email-hint work-email-error">
    <span class="field-hint" id="work-email-hint">Type something that is not an email, then leave the field.</span>
    <span class="field-error" id="work-email-error">Enter an email address, such as ada@example.com.</span>
  </label>
  <button type="submit" class="btn btn-primary self-start">Continue</button>
</form>`} />

## 크기 \{#sizes\}

필드 높이는 32px, 38px, 44px입니다. [버튼](/components/button), [선택 상자](/components/select), [세그먼트 컨트롤](/components/segmented)도 같은 높이를 사용하므로 같은 크기끼리 한 줄에 놓으면 높이 차이 없이 나란히 정렬됩니다. 터치 화면에서는 모든 크기의 높이가 44px입니다.

<ComponentPreview name="sizes" height={216} title="크기" background="plain" bodyClass="grid gap-md p-lg" html={`<input class="input input-sm" placeholder="Small" aria-label="Small">
<input class="input" placeholder="Medium" aria-label="Medium">
<input class="input input-lg" placeholder="Large" aria-label="Large">`} />

## 여러 줄 입력 \{#textarea\}

`.input`을 지정한 `<textarea>`는 지정한 줄 수와 세로 크기 조절 손잡이를 유지합니다. 내용에 맞춰 높이가 늘어나게 하려면 `input-auto`를 추가하세요. `field-sizing: content`는 높이를 3줄에서 최대 12줄까지 조절하며, 그 이상은 스크롤로 볼 수 있습니다. 범위를 바꾸려면 `--input-rows`와 `--input-max-rows`를 설정하세요. `field-sizing`을 지원하지 않는 브라우저에서는 최소 높이와 손잡이가 유지됩니다.

<ComponentPreview name="textarea" height={512} title="여러 줄 입력" background="plain" bodyClass="grid gap-lg p-lg" html={`<label class="field">
  Message
  <textarea class="input" rows="3" placeholder="A fixed height with a resize handle"></textarea>
</label>
<label class="field">
  Notes
  <textarea class="input input-auto" placeholder="Keep typing: this one grows with its content"></textarea>
</label>`} />

## 입력 그룹 \{#input-group\}

`input-group`은 별도 스타일이 없는 필드와 그에 딸린 아이콘, 단위, 단축키 또는 버튼을 하나의 오목한 영역으로 감쌉니다. 그룹은 `:has()`를 통해 내부 필드의 호버, 포커스, 유효하지 않음, 비활성화 상태를 표시합니다. `input-group-field`는 입력 요소 자체의 의미론과 텍스트 커서를 유지합니다. 오목한 영역 어디를 눌러도 필드에 포커스가 가도록 그룹을 `<label>`로 만드세요.

<ComponentPreview name="group" height={216} title="입력 그룹" background="plain" bodyClass="grid gap-md p-lg" html={`<label class="input-group">
  <svg class="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="11" cy="11" r="6"/><path d="m20 20-4.35-4.35"/></svg>
  <input class="input-group-field" type="search" placeholder="Search projects" aria-label="Search projects">
  <kbd class="kbd">⌘K</kbd>
</label>
<label class="input-group">
  <span class="input-group-addon">https://</span>
  <input class="input-group-field" value="atlas" aria-label="Subdomain">
  <span class="input-group-addon">.master.co</span>
</label>
<label class="input-group">
  <input class="input-group-field" type="number" value="24" aria-label="Timeout">
  <span class="input-group-addon">seconds</span>
</label>`} />

그룹 안의 [버튼](/components/button)은 오목한 영역의 가장자리에서 4px 안쪽에 놓이고, 모서리 반경은 오목한 영역의 모서리 반경보다 4px 작습니다. 따라서 어느 크기에서든 두 모서리의 중심이 일치합니다. 그룹에 버튼이 들어갈 때는 그룹에 `<div>`를 사용하세요.

<ComponentPreview name="inline" height={152} title="버튼이 있는 입력 그룹" background="plain" bodyClass="grid gap-md p-lg" html={`<form class="input-group">
  <input class="input-group-field" type="email" placeholder="you@example.com" aria-label="Email">
  <button type="submit" class="btn btn-primary">Subscribe</button>
</form>
<div class="input-group input-group-sm">
  <input class="input-group-field" value="https://atlas.dev/p/9f2c" readonly aria-label="Share link">
  <button type="button" class="btn">Copy</button>
</div>`} />

필드와 버튼을 분리해 배치하려면 `<form class="flex gap-xs">`로 플렉스 행에 넣으세요.

## 여러 값 입력 \{#several-values\}

`input-group-wrap`을 사용하면 그룹에서 수신자, 태그, 필터처럼 여러 값을 입력받을 수 있습니다. 각 값은 오목한 영역 안에 [칩](/components/chip)으로 표시되고, 필드는 마지막 줄의 남은 공간을 차지합니다. 값이 한 줄에 다 들어가지 않으면 영역이 한 줄씩 늘어납니다. 칩은 영역의 가장자리에서 6px 안쪽에 놓이며, 칩과 영역의 둥근 모서리는 중심이 일치합니다.

값의 배치는 스타일시트가 처리합니다. <kbd class="kbd">Enter</kbd>로 값을 추가하고 <kbd class="kbd">Backspace</kbd>로 마지막 값을 제거하는 동작은 몇 줄의 스크립트로 직접 구현하거나 서버에 요청을 보내고 응답을 받아 처리할 수 있습니다.

<ComponentPreview name="wrap" height={160} narrowHeight={192} title="여러 값 입력" background="plain" bodyClass="p-lg" html={`<div class="field max-w(420) mx-auto">
  <label for="input-teams">Teams</label>
  <div class="input-group input-group-wrap">
    <span class="chip">Design<button type="button" class="chip-remove" aria-label="Remove Design"></button></span>
    <span class="chip">Research<button type="button" class="chip-remove" aria-label="Remove Research"></button></span>
    <span class="chip">Engineering<button type="button" class="chip-remove" aria-label="Remove Engineering"></button></span>
    <span class="chip">Operations<button type="button" class="chip-remove" aria-label="Remove Operations"></button></span>
    <input class="input-group-field" id="input-teams" placeholder="Add a team">
  </div>
</div>`} />

## 검색과 자동 채우기 \{#search-and-autofill\}

`type="search"` 필드는 브라우저의 지우기 버튼을 유지하며, 버튼 모양은 아이콘 전경색의 가는 ×로 바뀝니다. 브라우저가 필드를 자동으로 채우면 브라우저 엔진의 기본 노란색이나 파란색 대신 정보 색상이 오목한 영역에 옅게 적용되어 폼 전체의 모양이 일관되게 유지됩니다.

<ComponentPreview name="search" height={96} title="검색" background="plain" bodyClass="p-lg" html={`<input class="input max-w(360) mx-auto" type="search" value="moonstone" aria-label="Search">`} caption="Chromium과 Safari에서는 필드에 마우스를 올리거나 포커스를 주면 지우기 버튼이 표시됩니다." />

## 파일 \{#file\}

`<input type="file">`에서 브라우저 기본 버튼은 세그먼트 트랙의 옵션처럼 오목한 영역 안에 놓인 작은 볼록한 컨트롤로 표시됩니다.

<ComponentPreview name="file" height={120} title="파일" background="plain" bodyClass="p-lg" html={`<label class="field">
  Attachment
  <input class="input" type="file">
</label>`} />

## 날짜, 시간, 숫자, 색상 \{#date-time-and-color\}

`.input`은 브라우저 기본 날짜, 시간, 숫자, 색상 필드에도 같은 오목한 영역 스타일을 적용합니다. 선택 도구는 사용자가 기기에서 익숙하게 쓰는 플랫폼 기본 도구를 그대로 사용합니다. 색상 필드는 정사각형이며, 색상 견본은 가장자리에서 4px 안쪽에 놓이고 필드와 견본의 둥근 모서리는 중심이 일치합니다.

브라우저가 이 필드에 표시하는 작은 기호는 아이콘과 같은 선 굵기와 전경색으로 표시됩니다. 달력이나 시계 아이콘은 선택 도구를 열고, 숫자 필드의 위쪽 꺾쇠는 값을 늘리며 아래쪽 꺾쇠는 값을 줄입니다. Chromium과 Safari에서는 이 요소에 스타일을 적용할 수 있으며, Firefox에서는 기본 모양이 유지됩니다. 사용자가 값을 자주 증감해야 한다면 [스테퍼](/components/stepper)를 사용하세요.

  Starts

</label>
<label class="field">
  At
  <input class="input" type="time" value="09:30">
</label>

## 필드 그룹 \{#fieldset\}

`<fieldset>`에 `fieldset`을 적용하면 관련 컨트롤을 하나의 제목 아래 묶고 브라우저 기본 홈 모양 테두리를 없앱니다. `fieldset-legend` 클래스는 `<legend>`에 필드 레이블과 같은 스타일을 적용합니다. [체크박스](/components/checkbox), [라디오 버튼](/components/radio), [선택 옵션](/components/choice)을 이 구조로 감싸 그룹에 이름을 지정하세요.

  <label class="check"><input type="checkbox" class="checkbox" checked> Failed deployments</label>
  <label class="check"><input type="checkbox" class="checkbox" checked> Expiring certificates</label>
  <label class="check"><input type="checkbox" class="checkbox"> Product news</label>
</fieldset>`} />

## React, Svelte, Vue \{#frameworks\}

`field` 컴포넌트는 레이블, 컨트롤, 힌트, 오류를 각각의 ID로 연결합니다. 컨트롤은 페이지에서 작성한 마크업을 그대로 사용하며, 이 페이지의 나머지 구성 요소도 모두 마크업으로 구현합니다. `npx master-ui add field`로 컴포넌트를 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte, Vue](/guide/frameworks)에서 확인할 수 있습니다.
