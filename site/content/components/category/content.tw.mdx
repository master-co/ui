分類說明某份資料屬於哪一類：一個專案、一份行事曆、一個團隊或一個標籤。Master UI 以預設集 23 組具名色盤之一來標示分類，每組色盤提供四個角色：帶淡色的**底面**、在底面上清晰可讀的**文字**、裝飾用的**線條**，以及用於圓點或色條的**標記**。`category-<name>` 類別會為自身及其內容設定這四個角色，選擇使用的部位則會讀取它們。

## 介面框架、狀態、分類與內容 \{#roles-of-color\}

介面框架預設使用中性色；狀態色說明某樣東西目前的情況，分類色說明它屬於哪一類，內容色如實呈現資料本身，品牌色則保留給它唯一的關鍵時刻。

- **狀態**是元件的色調，例如 `badge-success`：已完成、失敗、有風險。它一律搭配說明同一狀態的文字。
- **分類**是包住資料的類別，例如 `category-blue`：一個專案、一份行事曆、一個標籤。這裡的紅色代表一個分類，而不是危險；一個徽章只能是其中一種，不能兩者兼具。
- **內容**是資料本身的顏色：一種塗料、一個主題的強調色、圖表中的一個資料數列。[色票](/components/swatch)會如實呈現它。

在分類內的按鈕、欄位、對話框或其他介面框架都維持中性的外觀：只有 `badge-category`、`chip-category`、`schedule-event-category` 和 `icon-frame-category` 會讀取這些角色。

## 色盤 \{#palettes\}

每組色盤在每個角色上都使用相同的明度，因此沒有哪個分類顯得比其他分類更重；每個角色在 Moonstone、Obsidian 和 Paper 中都符合對比要求：文字對比至少為 4.5:1，標記對比至少為 3:1，在各自的分類底色、基礎背景與凸起元件的背景上皆須達標。色相與彩度則是各色盤自己的；黃色的文字會像預設集較深的色階一樣偏向琥珀色，而不會變成橄欖色。

## 一個分類，只標示一次 \{#scope\}

## 也要用文字說明 \{#words\}

色彩從來不是標示分類的唯一方式。請在徽章或膠囊標籤中，或在圓點旁寫出分類的名稱；無法分辨藍綠色與綠色的讀者、灰階列印的紙本，以及螢幕閱讀器都需要這些文字。由使用者自選的分類色不是主題的角色，也沒有經過對比檢查：請將它對應到最接近的具名色盤，或在色票中把它當成內容呈現。

在強制色彩模式下，系統色彩會取代淡色：文字、邊緣和已選取的篩選條件都會保留系統色彩，只有以色彩本身為內容的色票會保留自己的顏色。

## 重新調整色盤 \{#retune\}

這些角色是主題的 token：`--color-category-<name>-surface`、`-text`、`-line` 和 `-mark`。因此主題可以像調整任何色彩一樣重新調整一組色盤：在專屬的主題中設定這四個 token，並維持它們的對比。若要讓某個作用範圍擁有自己的色盤，請在其上設定這四個公開屬性。

```css name=theme.css
@theme {
  --color-category-teal-surface: light-dark(oklch(96% .03 190), oklch(28% .04 190));
  --color-category-teal-text: light-dark(oklch(45% .08 190), oklch(87% .09 190));
}
```
