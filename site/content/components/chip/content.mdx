A chip is a small pill that is a choice or a value. Its ends are true half circles, which tells it apart from a [badge](/components/badge): a badge describes, a chip can be acted on. As a filter, a chip is a `<label>` around a native checkbox or radio, raised at rest and filled with ink when chosen, the way a [checkbox](/components/checkbox) fills.

## One of several \{#one-of-several\}

With radios that share a `name`, chips are a single choice, and the arrow keys move between them. Use this for a short set that changes a view at once; for a value in a form, a [segmented control](/components/segmented) reads as one control.

## Values \{#values\}

Without an input a chip is a value: a recipient, a tag, an applied filter. It rests in a chip tone on one contour. `chip-remove` is a round button at its end; give it a name that includes the value. Put [`icon`](/components/icon) on a leading icon.

## Accessibility \{#accessibility\}

- The input inside a filter chip covers it invisibly, so the label is the target and the input keeps the state, the keys and the form value. Group filter chips in a `<fieldset>` with a `<legend>`, or a `role="radiogroup"` with a label.
- The remove button's target reaches past its 20px glyph without moving it. On touch screens a filter chip grows to 36px.
- A chosen chip is ink on moonstone and pearl on obsidian, with no hue, so it does not depend on color vision.
