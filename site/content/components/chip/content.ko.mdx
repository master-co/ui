칩은 선택지나 값을 나타내는 작은 알약 모양의 컴포넌트입니다. 양끝이 정확한 반원이어서 [배지](/components/badge)와 구분됩니다. 배지는 정보를 표시하고, 칩은 조작할 수 있습니다. 필터 칩은 네이티브 체크박스나 라디오 버튼을 감싸는 `<label>`입니다. 기본 상태에서는 표면이 살짝 올라와 있고, 선택하면 [체크박스](/components/checkbox)처럼 잉크 색으로 채워집니다.

## 단일 선택 \{#one-of-several\}

라디오 버튼이 같은 `name` 값을 공유하면 칩을 하나만 선택할 수 있으며, 방향키로 칩 사이를 이동합니다. 선택지가 적고 선택 즉시 화면이 바뀌는 경우에 사용하세요. 폼에서 값을 고를 때는 [세그먼트 컨트롤](/components/segmented)이 하나의 컨트롤로 인식됩니다.

## 값 \{#values\}

입력 요소가 없는 칩은 수신자, 태그, 적용된 필터 같은 값을 나타냅니다. 기본 상태에서는 칩 색조와 윤곽선 하나로 표시됩니다. `chip-remove`는 칩 끝에 붙는 원형 버튼입니다. 버튼 이름에 칩의 값을 포함하세요. 칩 앞에 아이콘을 배치할 때는 아이콘에 [`icon`](/components/icon) 클래스를 지정하세요.

## 그림, 점, 개수 \{#parts\}

칩에는 순서대로 그림(`chip-media`, 칩이 크기와 둥근 모양을 맞추는 [아바타](/components/avatar)나 아이콘), 카테고리 점(`chip-dot`), 텍스트(`chip-label`), 개수(`chip-count`를 지정한 [배지](/components/badge)), 삭제 버튼을 넣을 수 있습니다. 공간이 부족하면 텍스트가 먼저 줄어들어 말줄임표로 끝나며, 그림과 개수와 버튼은 크기를 유지합니다. 시작 부분의 그림과 끝 부분의 개수는 칩의 끝에서 위아래 가장자리와 같은 거리만큼 떨어져 있으므로 곡선이 동심원을 이룹니다.

## 카테고리 색상 \{#category\}

`chip-category`는 칩 자체나 그 상위 요소에 지정된 [카테고리 색상](/components/category)을 읽습니다. 값 칩에는 카테고리의 표면색, 텍스트 색, 선 색이 적용됩니다. 필터 칩은 살짝 올라온 표면과 선택 시의 잉크 색을 유지하므로 어느 카테고리에서든 선택 상태가 같은 방식으로 표시되며, 카테고리는 `chip-dot`으로 나타냅니다.

## 크기 \{#sizes\}

`chip-sm`은 24px, `chip-lg`는 32px이며 기본값은 28px입니다. 삭제 버튼, 그림, 개수도 함께 크기가 바뀝니다. 터치 화면에서도 칩은 높이를 유지합니다. 필터 칩의 조작 영역은 칩 바깥까지 확장되어 44px에 이르고, 삭제 버튼의 조작 영역은 해당 값 칩 안에서 높이 44px에 이릅니다. [태그 입력](/components/tags)처럼 값을 담는 필드는 칩 높이를 직접 설정합니다.

## 접근성 \{#accessibility\}

- 필터 칩 안의 입력 요소가 보이지 않는 상태로 칩 전체를 덮습니다. 레이블 전체가 조작 영역이 되고, 입력 요소는 상태와 키보드 동작, 폼 값을 관리합니다. 필터 칩은 `<legend>` 요소가 있는 `<fieldset>`으로 묶거나, `role="radiogroup"`과 레이블을 지정한 요소로 묶으세요.
- 삭제 버튼은 아이콘의 위치를 그대로 유지하면서 조작 영역을 28px로 넓힙니다. 터치 화면에서는 이 조작 영역의 높이가 44px가 되며, 해당 값 칩의 끝을 넘어가지 않습니다.
- 카테고리 점은 장식 요소입니다. 카테고리는 칩의 텍스트로 전달합니다.
- 선택한 칩은 moonstone에서 잉크 색으로, obsidian에서 진주색으로 표시됩니다. 두 색 모두 무채색이므로 색상을 구별하지 않아도 선택 상태를 알아볼 수 있습니다.
