Progress shows how much of a task is done. Use `.progress` on a native `<progress>`: the browser reports the value to assistive technology, and the class draws a thin well that fills with ink. For work of unknown length inside a control, use a [spinner](/components/spinner).

<ComponentPreview name="default" title="Progress" bodyClass="p-lg" html={`<label class="field">
  Uploading 3 of 5 files
  <progress class="progress" value="62" max="100">62%</progress>
</label>`} />

## Indeterminate \{#indeterminate\}

Leave out `value` while the amount is unknown. A band of ink travels along the track; with reduced motion the track rests at an even half tone instead.

<ComponentPreview name="indeterminate" title="Indeterminate" bodyClass="p-lg" html={`<label class="field">
  Preparing the build
  <progress class="progress"></progress>
</label>`} />

## Sizes \{#sizes\}

The track is 6px thick. `progress-sm` is 4px, for a row in a list, and `progress-lg` is 8px.

<ComponentPreview name="sizes" title="Sizes" bodyClass="flex flex-col gap-md p-lg" html={`<progress class="progress progress-sm" value="30" max="100" aria-label="Small">30%</progress>
<progress class="progress" value="55" max="100" aria-label="Medium">55%</progress>
<progress class="progress progress-lg" value="80" max="100" aria-label="Large">80%</progress>`} />

## With a value \{#with-a-value\}

The bar does not print its number. Put it beside the label in tabular figures so it does not shift as it counts.

<ComponentPreview name="value" title="With a value" bodyClass="p-lg" html={`<div class="flex flex-col gap-xs">
  <div class="flex items-baseline justify-between text-sm">
    <span class="fg-text-strong" id="storage-label">Storage</span>
    <span class="fg-text-muted">7.4 of 10 GB</span>
  </div>
  <progress class="progress" value="7.4" max="10" aria-labelledby="storage-label">74%</progress>
</div>`} />

## Accessibility \{#accessibility\}

- Label the bar with a `field` label, `aria-label` or `aria-labelledby`.
- The text inside `<progress>` is a fallback for browsers that do not draw the element.
- When the bar describes a region that is loading, set `aria-busy="true"` on that region until it is done.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `progress` | A progress bar; indeterminate without `value` |
| `progress-sm`, `progress-lg` | 4px and 8px tracks; the default is 6px |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--progress-height` | `.375rem` | Track thickness |
| `--progress-color` | `var(--color-surface-inverse)` | Fill color |
