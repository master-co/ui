Progress shows how much of a task is done. Use `.progress` on a native `<progress>`: the browser reports the value to assistive technology, and the class draws a thin well that fills with ink. For work of unknown length inside a control, use a [spinner](/components/spinner).

<ComponentPreview name="default" title="Progress" bodyClass="p-lg" html={`<label class="field">
  Uploading 3 of 5 files
  <progress class="progress" value="62" max="100">62%</progress>
</label>`} />

## Indeterminate \{#indeterminate\}

Leave out `value` while the amount is unknown. A band of ink travels along the track; with reduced motion the track rests at an even half tone instead.

<ComponentPreview name="indeterminate" title="Indeterminate" bodyClass="p-lg" html={`<label class="field">
  Preparing the build
  <progress class="progress"></progress>
</label>`} />

## Sizes \{#sizes\}

The track is 6px thick. `progress-sm` is 4px, for a row in a list, and `progress-lg` is 8px.

<ComponentPreview name="sizes" title="Sizes" bodyClass="flex flex-col gap-md p-lg" html={`<progress class="progress progress-sm" value="30" max="100" aria-label="Small">30%</progress>
<progress class="progress" value="55" max="100" aria-label="Medium">55%</progress>
<progress class="progress progress-lg" value="80" max="100" aria-label="Large">80%</progress>`} />

## Segmented \{#segmented\}

`progress-segmented` cuts the track into equal pieces, for progress that is a count of things: three of five steps, four of eight uploads. Set `--progress-steps` to the same number as `max`, so a piece is a step. The cut is a mask over the well and its fill alike, which keeps the pieces in step with the value.

<ComponentPreview name="segmented" title="Segmented" bodyClass="flex flex-col gap-md p-lg" html={`<label class="field">
  Step 3 of 5
  <progress class="progress progress-segmented" max="5" value="3">Step 3 of 5</progress>
</label>
<label class="field">
  5 of 8 files uploaded
  <progress class="progress progress-segmented progress-lg" style="--progress-steps: 8" max="8" value="5">5 of 8</progress>
</label>`} />

## Ring \{#ring\}

`progress-ring` draws the same amount around a circle, for a tile, a row or the corner of a card. It is an element with `role="progressbar"`. Where the browser supports typed `attr()`, the ring reads `aria-valuenow` and `aria-valuemax` itself, so the amount is written once, for people and for the drawing, and the arc eases to each new value. Elsewhere, set `--progress-ring-value` in a `style` attribute as well.

The element's own content is the label in the middle. Both ends of the arc are round, and an empty ring is an empty track.

<ComponentPreview name="ring" title="Ring" bodyClass="flex flex-wrap items-center justify-center gap-lg p-lg" html={`<div class="progress-ring progress-ring-sm" role="progressbar" aria-label="Upload" aria-valuenow="40"></div>
<div class="progress-ring" role="progressbar" aria-label="Storage used" aria-valuenow="64">64</div>
<div class="progress-ring progress-ring-lg" role="progressbar" aria-label="Steps done" aria-valuenow="3" aria-valuemax="8" aria-valuetext="3 of 8">3/8</div>
<div class="progress-ring progress-ring-xl" role="progressbar" aria-label="Coverage" aria-valuenow="86">86%</div>`} />

Without `aria-valuenow` the amount is unknown, and a quarter arc travels the track. Set `--progress-ring-color` to a status color when the ring reports one, and say the status in words beside it.

<ComponentPreview name="ring-states" title="Ring states" bodyClass="flex flex-wrap items-center justify-center gap-lg p-lg" html={`<div class="progress-ring" role="progressbar" aria-label="Preparing"></div>
<div class="progress-ring progress-ring-lg" role="progressbar" aria-label="Checks passed" aria-valuenow="100" style="--progress-ring-color: var(--color-success)">100</div>
<div class="progress-ring progress-ring-lg" role="progressbar" aria-label="Quota used" aria-valuenow="92" style="--progress-ring-color: var(--color-danger)">92</div>`} />

## With a value \{#with-a-value\}

The bar does not print its number. Put it beside the label in tabular figures so it does not shift as it counts.

<ComponentPreview name="value" title="With a value" bodyClass="p-lg" html={`<div class="flex flex-col gap-xs">
  <div class="flex items-baseline justify-between text-sm">
    <span class="fg-text-strong" id="storage-label">Storage</span>
    <span class="fg-text-muted">7.4 of 10 GB</span>
  </div>
  <progress class="progress" value="7.4" max="10" aria-labelledby="storage-label">74%</progress>
</div>`} />

## Accessibility \{#accessibility\}

- Label the bar with a `field` label, `aria-label` or `aria-labelledby`.
- The text inside `<progress>` is a fallback for browsers that do not draw the element.
- When the bar describes a region that is loading, set `aria-busy="true"` on that region until it is done.

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `progress` | A progress bar; indeterminate without `value` |
| `progress-sm`, `progress-lg` | 4px and 8px tracks; the default is 6px |
| `progress-segmented` | The track in `--progress-steps` equal pieces, five by default |
| `progress-ring` | A ring on a `role="progressbar"` element; indeterminate without `aria-valuenow` |
| `progress-ring-sm`, `progress-ring-lg`, `progress-ring-xl` | 20px, 64px and 96px rings; the default is 40px |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--progress-height` | `.375rem` | Track thickness |
| `--progress-color` | `var(--color-surface-inverse)` | Fill color |
| `--progress-ring-value` | from `aria-valuenow` | The ring's amount, where typed `attr()` is not supported |
| `--progress-ring-size` | `2.5rem` | The ring's diameter |
| `--progress-ring-width` | a tenth of the size | The ring's thickness |
| `--progress-ring-color` | `var(--color-surface-inverse)` | The arc's color |
