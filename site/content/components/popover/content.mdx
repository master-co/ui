A popover is a floating sheet that belongs to the button that opened it. Add the `popover` attribute and `.popover` to any element, and point a button at it with `popovertarget`. The browser moves it to the top layer, closes it on an outside click or <kbd>Esc</kbd>, and keeps it next in the tab order after its button. CSS anchor positioning places it, so there is no positioning script.

<div id="share" popover class="popover">
  <div class="flex flex-col gap-sm w(260)">
    <p class="m(0) fg-text-strong">Share this project</p>

    </div>
  </div>
</div>`} />

## Placement \{#placement\}

A popover opens 6px below its button and lines up with the button's start edge. The button is its anchor without any name: the popover API connects the two. When the popover would leave the viewport it flips to the other side.

| Class | Placement |
| --- | --- |
| `popover` | Below, lined up with the start edge |
| `popover-end` | Lined up with the end edge, for a button at the end of a row |
| `popover-center` | Centered on the button |
| `popover-top` | Above the button; combine it with `popover-end` or `popover-center` |

<button type="button" class="btn" popovertarget="place-center">Center</button>
<button type="button" class="btn" popovertarget="place-end">End</button>
<button type="button" class="btn" popovertarget="place-top">Top</button>

<div id="place-start" popover class="popover">Lined up with the start edge.</div>

<div id="place-end" popover class="popover popover-end">Lined up with the end edge.</div>
<div id="place-top" popover class="popover popover-top popover-center">Above the button.</div>`} />

In a browser without anchor positioning the popover still opens and closes; it appears centered in the viewport, where the browser places any popover.

## With a form \{#with-a-form\}

A popover can hold controls. Focus stays on the button when it opens; <kbd>Tab</kbd> moves into the popover, or put `autofocus` on the first field to start there.

<form id="rename" popover class="popover">
  <div class="flex flex-col gap-sm w(240)">
    <label class="field">
      Project name
      <input class="input input-sm" value="atlas" autofocus>
    </label>
    <div class="flex justify-end gap-xs">
      <button type="button" class="btn btn-sm" popovertarget="rename" popovertargetaction="hide">Cancel</button>
      <button type="button" class="btn btn-sm btn-primary" popovertarget="rename" popovertargetaction="hide">Save</button>
    </div>
  </div>
</form>`} />

## On hover \{#on-hover\}

A popover can also open when a link or a button is hovered or focused, as a preview of where it leads. Give it `popover="hint"` and point the trigger at it with `interestfor`. A hint does not close a menu or another popover that is already open. Keep the content a preview: a reader on a touch screen reaches it only by a long press, so nothing should be available here alone.

<ComponentPreview name="hover" title="On hover" bodyClass="flex items-start justify-center p-lg min-h(240)" html={`<p class="m(0) text-sm fg-text-body">Deployed by <a class="link" href="#ada" interestfor="ada-card">Ada Lovelace</a> two hours ago.</p>

<div id="ada-card" popover="hint" class="popover">
  <div class="flex items-center gap-sm">
    <span class="avatar avatar-lg"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
    <div class="flex flex-col">
      <span class="fg-text-strong">Ada Lovelace</span>
      <span class="text-xs fg-text-muted">Owner · 412 deployments</span>
    </div>
  </div>
</div>`} caption="Hover the name, or move to it with Tab." />

Interest invokers ship in Chrome and Edge. Elsewhere the link works as a link and the preview does not appear.

## Accessibility \{#accessibility\}

- The button gets `aria-expanded` from the browser; do not set it yourself.
- A popover is not modal: the page stays interactive. For a task that must be finished or dismissed first, use a [dialog](/components/dialog).
- For a list of actions use a [menu](/components/menu), and for a label on hover a [tooltip](/components/tooltip).

## Classes \{#classes\}

| Class | Description |
| --- | --- |
| `popover` | The floating sheet, on an element with the `popover` attribute |
| `popover-end`, `popover-center` | Line up with the button's end edge, or center on it |
| `popover-top` | Open above the button |

## Custom properties \{#custom-properties\}

| Property | Default | Description |
| --- | --- | --- |
| `--popover-padding` | `1rem` | Padding inside the sheet |
| `--popover-max-width` | `22rem` | Widest the sheet grows before its text wraps |
| `--anchored-gap` | `6px` | Distance from the button |
