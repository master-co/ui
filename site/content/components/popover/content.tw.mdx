彈出面板依附於開啟它的按鈕。在任一元素加上 `popover` 屬性和 `.popover`，再用 `popovertarget` 讓按鈕指向該元素。瀏覽器會將面板移到頂層，點擊面板外部或按下 <kbd>Esc</kbd> 時關閉，並讓面板在 Tab 順序中緊接在按鈕之後。面板由 CSS 錨點定位，不需要用腳本定位。

## 放置位置 \{#placement\}

彈出面板會在按鈕下方 6px 處開啟，並與按鈕的起始邊緣對齊。Popover API 會將按鈕與面板連結，因此按鈕無須命名即可作為錨點。面板若會超出檢視區，就會翻到另一側。

| 類別 | 放置位置 |
| --- | --- |
| `popover` | 位於下方，與起始邊緣對齊 |
| `popover-end` | 與結束邊緣對齊，適合放在一列末端的按鈕 |
| `popover-center` | 相對於按鈕置中 |
| `popover-top` | 位於按鈕上方，可搭配 `popover-end` 或 `popover-center` |

瀏覽器若不支援錨點定位，彈出面板仍可正常開關，並會依照瀏覽器對彈出面板的預設定位顯示在檢視區中央。

## 搭配表單 \{#with-a-form\}

彈出面板可以容納控制項。面板開啟時，焦點會留在按鈕上。按 <kbd>Tab</kbd> 可將焦點移入面板，也可在第一個欄位加上 `autofocus`，讓焦點在開啟時直接移到該欄位。

## 指標懸停時 \{#on-hover\}

指標停在連結或按鈕上，或連結或按鈕取得焦點時，也可開啟彈出面板來預覽其指向的內容。為面板加上 `popover="hint"`，再用 `interestfor` 讓觸發元素指向面板。提示面板不會關閉已開啟的選單或其他彈出面板。請只放預覽內容，因為觸控螢幕的使用者只能透過長按查看。任何資訊都不應只在這裡提供。

<div id="ada-card" popover="hint" class="popover">
  <div class="flex items-center gap-sm">
    <span class="avatar avatar-lg"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
    <div class="flex flex-col">
      <span class="fg-text-strong">Ada Lovelace</span>

    </div>
  </div>
</div>`} caption="將指標移到名稱上，或按 Tab 將焦點移到名稱。" />

Chrome 和 Edge 已支援這類預覽觸發元素。其他瀏覽器仍可正常開啟連結，但不會顯示預覽。

## 無障礙 \{#accessibility\}

- 瀏覽器會為按鈕設定 `aria-expanded`，請勿自行設定。
- 彈出面板是非模態的，開啟時使用者仍可操作頁面。如果必須先完成或取消一項任務，請使用[對話框](/components/dialog)。
- 使用[選單](/components/menu)列出可執行的操作，使用[工具提示](/components/tooltip)顯示指標懸停時的標籤。

## React、Svelte 和 Vue \{#frameworks\}

`popover` 元件會依應用程式狀態開關彈出面板，也會在瀏覽器開關面板時發出通知。觸發元素和內容仍由頁面自己的標記定義。執行 `npx master-ui add popover` 即可將元件複製到專案中。請參閱 [React、Svelte 和 Vue](/guide/frameworks)，了解元件的建構和使用方式。
