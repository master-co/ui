팝오버는 자신을 연 버튼에 연결된 떠 있는 패널입니다. 원하는 요소에 `popover` 속성과 `.popover`를 추가하고, 버튼에서 `popovertarget`로 해당 요소를 지정하세요. 브라우저는 팝오버를 최상위 레이어로 옮기고, 바깥을 클릭하거나 <kbd>Esc</kbd> 키를 누르면 닫습니다. 탭 이동 순서에서는 팝오버가 버튼 바로 다음에 옵니다. 위치는 CSS 앵커 포지셔닝으로 정하므로 별도의 스크립트가 필요 없습니다.

## 배치 \{#placement\}

팝오버는 버튼 아래 6px 지점에 열리며 버튼의 시작 쪽 가장자리에 맞춰 정렬됩니다. Popover API가 두 요소를 연결하므로 앵커 이름을 지정하지 않아도 버튼이 앵커가 됩니다. 팝오버가 뷰포트를 벗어날 위치라면 반대쪽에 열립니다.

| 클래스 | 배치 |
| --- | --- |
| `popover` | 버튼 아래에서 시작 쪽 가장자리에 맞춰 정렬 |
| `popover-end` | 버튼이 행 끝에 있을 때 버튼의 끝 쪽 가장자리에 맞춰 정렬 |
| `popover-center` | 버튼을 기준으로 가운데 정렬 |
| `popover-top` | 버튼 위에 배치. `popover-end` 또는 `popover-center`와 함께 사용 |

<button type="button" class="btn" popovertarget="place-center">Center</button>
<button type="button" class="btn" popovertarget="place-end">End</button>
<button type="button" class="btn" popovertarget="place-top">Top</button>

<div id="place-start" popover class="popover">Lined up with the start edge.</div>

앵커 포지셔닝을 지원하지 않는 브라우저에서도 팝오버는 열리고 닫힙니다. 이 경우 브라우저의 기본 팝오버 배치에 따라 뷰포트 중앙에 표시됩니다.

## 폼이 있는 팝오버 \{#with-a-form\}

팝오버 안에 입력 컨트롤을 넣을 수 있습니다. 팝오버가 열려도 포커스는 버튼에 남으며, <kbd>Tab</kbd> 키를 누르면 팝오버 안으로 이동합니다. 열릴 때 첫 번째 필드에 포커스를 두려면 해당 필드에 `autofocus`를 추가하세요.

## 호버 시 미리보기 \{#on-hover\}

링크나 버튼에 호버하거나 포커스를 두면 이동할 곳을 미리 보여 주는 팝오버를 열 수도 있습니다. 팝오버에 `popover="hint"`를 추가하고, 팝오버를 여는 요소에서 `interestfor`로 지정하세요. 힌트 팝오버가 열려도 이미 열려 있는 메뉴나 다른 팝오버는 닫히지 않습니다. 콘텐츠는 미리보기로만 제공하세요. 터치 화면에서는 길게 눌러야 볼 수 있으므로, 여기에서만 확인할 수 있는 정보가 있어서는 안 됩니다.

<ComponentPreview name="hover" height={240} title="호버 시 열기" background="plain" bodyClass="flex items-start justify-center p-lg min-h(240)" html={`<p class="m(0) text-sm fg-text-body">Deployed by <a class="link" href="#ada" interestfor="ada-card">Ada Lovelace</a> two hours ago.</p>

<div id="ada-card" popover="hint" class="popover">
  <div class="flex items-center gap-sm">
    <span class="avatar avatar-lg"><img class="avatar-image" src="/demo/portrait-1.svg" alt=""></span>
    <div class="flex flex-col">

      <span class="text-xs fg-text-muted">Owner · 412 deployments</span>
    </div>
  </div>
</div>`} caption="이름 위에 포인터를 올리거나 Tab 키로 포커스를 옮기세요." />

Chrome과 Edge는 호버나 포커스로 팝오버를 여는 기능(interest invokers)을 지원합니다. 다른 브라우저에서는 링크가 평소처럼 동작하며 미리보기는 표시되지 않습니다.

## 접근성 \{#accessibility\}

- 브라우저가 버튼에 `aria-expanded`를 부여하므로 직접 설정하지 마세요.
- 팝오버는 비모달이므로 열려 있어도 페이지를 계속 조작할 수 있습니다. 페이지로 돌아가기 전에 작업을 완료하거나 창을 닫아야 한다면 [대화 상자](/components/dialog)를 사용하세요.
- 실행할 작업 목록에는 [메뉴](/components/menu)를, 호버할 때 표시할 레이블에는 [툴팁](/components/tooltip)을 사용하세요.

## React, Svelte 및 Vue \{#frameworks\}

`popover` 컴포넌트는 애플리케이션 상태에 따라 팝오버를 열고 닫으며, 브라우저에서 팝오버가 열리거나 닫히면 이를 알려 줍니다. 팝오버를 여는 요소와 그 안의 콘텐츠는 페이지 마크업에서 직접 작성합니다. `npx master-ui add popover`로 컴포넌트를 프로젝트에 복사하세요. 컴포넌트의 구성과 사용법은 [React, Svelte 및 Vue](/guide/frameworks)를 참고하세요.
