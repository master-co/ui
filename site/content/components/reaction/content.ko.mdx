반응은 독자가 [메시지](/components/message) 아래에 남기는 이모지로, 같은 반응을 남긴 다른 사람의 수가 함께 표시됩니다. 각 반응은 네이티브 체크박스를 감싼 칩 색상의 평평한 알약 모양입니다. 한 번 누르면 내 반응을 추가하고 다시 누르면 취소합니다. 개수는 CSS 카운터로 표시하므로 스크립트 없이도 체크 여부에 따라 늘거나 줄어듭니다.

말풍선 바로 뒤에 `reaction-group`을 배치하세요. 받은 메시지에서는 말풍선의 시작 가장자리에, 보낸 메시지에서는 끝 가장자리에 반응 행을 맞춥니다. `aria-label`로 그룹에 접근 가능한 이름을 지정하고, 화면에 메시지가 여러 개 있으면 누구의 메시지에 달린 반응인지도 이름에 포함하세요.

## 반응 수 \{#count\}

각 반응의 `--count`에 현재 독자를 제외하고 그 반응을 남긴 사람 수를 지정하세요. CSS 카운터는 이 값에서 시작하며, 체크박스가 선택되면 1을 더합니다. 따라서 독자가 남긴 반응에는 `--count`보다 1 큰 수가 표시됩니다. `reaction-count`를 비워 두면 카운터가 그 안에 숫자를 표시합니다. 수가 너무 커서 1씩 세기 어려우면 그 안에 `1.2k` 같은 텍스트를 넣으세요. 이 경우 입력한 텍스트가 표시됩니다.

## 상태 \{#states\}

기본 상태에서는 반응이 윤곽선 하나를 두른 평평한 알약 모양으로 표시되며, 반응 수는 옅게 표시됩니다. 호버하면 윤곽선이 더 뚜렷해지고, 누르면 알약 모양이 오목한 영역으로 들어가면서 이모지도 함께 눌려 들어갑니다. 반응을 남기면 라이브러리의 선택 상태가 적용되어 잉크 색의 가는 윤곽선과 옅은 잉크 색 배경이 나타나며, 반응 수는 진한 잉크 색으로 표시됩니다. 닫힌 스레드에서처럼 체크박스가 비활성화되면 평평한 모양을 유지하고 이모지는 흐리게 표시됩니다.

## 반응 추가 \{#adding\}

`reaction-add`는 반응 행 끝에 있는 둥근 버튼으로, 얼굴과 더하기 기호가 표시되며 페이지의 이모지 선택기를 엽니다. 선택기는 눈에 띄지 않는 정사각형 [버튼](/components/button)을 모은 [팝오버](/components/popover)이며, 각 버튼에는 `reaction-emoji`가 들어 있습니다. 버튼 바로 뒤의 팝오버가 열려 있는 동안에는 버튼이 눌린 모양을 유지합니다. 이모지를 고르면 해당 반응을 남깁니다. 아직 아무도 남기지 않은 반응이라면 알약 모양의 항목도 새로 추가합니다. 새 항목은 페이지에서 추가해야 하므로 선택기에 몇 줄의 스크립트가 필요합니다. 이 페이지의 다른 기능은 모두 스크립트 없이 동작합니다.

<script>
  const picker = document.getElementById('reaction-picker')
  const reactions = document.getElementById('reactions')

  picker.addEventListener('click', function (event) {
    const option = event.target.closest('button')
    if (!option) return
    let input = Array.from(reactions.querySelectorAll('.reaction-input')).find(function (each) { return each.value === option.value })
    if (!input) {

      const emoji = document.createElement('span')

      reaction.append(input, emoji, count)
      reactions.insertBefore(reaction, reactions.querySelector('.reaction-add'))

## 접근성 \{#accessibility\}

- 각 체크박스의 접근 가능한 이름에는 `aria-label="Thumbs up, 3 others"`처럼 이모지 이름과 다른 사람이 남긴 반응 수를 텍스트로 적고, 화면에 표시되는 이모지와 숫자는 `aria-hidden="true"`로 보조 기술에서 숨기세요. 독자가 반응을 남겼는지는 체크 상태로 전달되므로, 체크박스를 누를 때마다 상태가 바뀌어도 이름은 정확하게 유지됩니다.
- 화면에 표시된 반응 수를 스크린 리더가 읽어 준다고 가정하지 마세요. 브라우저 엔진은 CSS 카운터가 생성한 텍스트를 접근 가능한 이름과 설명에서 제외합니다. Chromium에서는 체크박스의 접근 가능한 이름에 레이블 텍스트만 들어가고 CSS 카운터가 생성한 숫자는 빠집니다.
- 그룹에 접근 가능한 이름을 지정하고 `reaction-add`에는 "반응 추가"라는 이름을 지정하세요. 선택기의 각 버튼에는 해당 이모지의 이름을 지정하고, 이모지 자체는 보조 기술에서 숨기세요.
- 알약 모양 전체가 입력 영역입니다. 크기는 28px이며 터치 화면에서는 44px입니다. 강제 색상 모드에서도 윤곽선을 유지하며, 내가 남긴 반응에는 강조 색상의 더 두꺼운 윤곽선을 표시합니다.

## 플랫폼 참고 사항 \{#platform\}

`text-box: trim-both cap alphabetic`로 반응 수 텍스트의 위아래 여백을 대문자 높이(cap height)에 맞춰 잘라냅니다. 그러면 알약 모양 안에서 줄 상자 대신 숫자 자체가 세로 중앙에 놓여 이모지의 가운데와 맞습니다. 이 기능이 없어도 숫자는 중앙에서 0.5px 이내에 놓입니다. Chromium과 Safari는 `text-box`를 지원합니다.
