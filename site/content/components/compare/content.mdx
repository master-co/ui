Compare lays one picture over another of the same thing and lets a reader move the line between them: before and after an edit, light and dark, a draft and its revision. The handle is a native `<input type="range">`, so it has the keys, the value and the name of a slider. Its thumb is a pearl grip on a fine line, and the picture on top is clipped at that line.

## The handle moves the picture \{#the-handle-moves-the-picture\}

Where the browser has scroll-driven animations, the grip is a view timeline inside its input and the frame reads it: `--compare-position` follows the thumb with no script, and the clip and the line follow that property.

Elsewhere the `compare` [behavior](/guide/behaviors) does the same job: it copies the input's value, as a percentage of its range, into `--compare-position` on the root, when it attaches and each time the input moves. Attach it in every browser: where the stylesheet already drives the property, the script changes nothing that is drawn.

```js name=app.js
import { compare } from '@master/ui/behaviors/compare.js'

const detach = compare(document.querySelector('.compare'))
```

It takes the root, the element with the `compare` class, has no options and dispatches no event of its own: the input sends `input` and `change` as any range input does, and its `value` is where the line stands. Without the stylesheet's timeline and without the behavior, the pictures stay parted where `--compare-position` puts them, at the middle unless you set it.

The input is one grip wider than the frame, so the middle of the grip travels from one edge to the other and the line can reach both.

## Pictures \{#pictures\}

`compare-before` lies underneath and shows from the start to the line; `compare-after` lies on top and shows from the line to the end. Both fill the frame and crop to it, so give one of them the shape with a width and a height or an `aspect-ratio`, and use two pictures of the same framing.

The frame has a surface's corner and the inward edge every [figure](/components/figure) gets. Set `--compare-radius` to nest it in a card.

## Accessibility \{#accessibility\}

- Name the input for what moving it does: "Show more of the graded picture".
- Give each picture an `alt` that says which one it is and how it differs. A reader who cannot see the two side by side needs the difference in words.
- The handle is one tab stop. The arrow keys move the line by a step, <kbd>Home</kbd> and <kbd>End</kbd> show one picture whole.
- The grip is 32px, and 44px on touch screens. The frame lets a finger scroll the page vertically across it.
