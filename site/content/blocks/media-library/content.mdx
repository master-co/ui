Open the library to add existing artwork. Select Harbor, search for Dawn, then select it too. The dialog shows both the new additions and the resulting collection size.

<PagePreview name="default" title="Choose from a media library" example="media-library" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Search** A native search field filters the `choice` tiles. Stable IDs keep the selection across queries.
- **Commit** The dialog owns the draft. Cancel removes pending additions and Add commits them together.

## Accessibility \{#accessibility\}

The checkbox label names the artwork. Already-added artwork has a visible explanation. When the search field contains text, the first Escape may clear it. Press Escape again to close the dialog and return to the library button.
