라이브러리를 열고 Harbor를 고른 뒤 Dawn을 검색해 함께 선택합니다. 대화상자에는 새로 추가할 개수와 추가 후 전체 개수가 표시됩니다.

<PagePreview name="default" title="미디어 라이브러리에서 선택" example="media-library" />

블록은 복사해 사용하는 마크업입니다. 페이지의 텍스트 색상과 크기를 따르며, 미리보기에서는 body에 `fg-text-body text-sm` 클래스를 설정합니다. 각 블록은 크기 컨테이너이므로 넓은 페이지, 사이드바 너비의 공간, 대화 상자 어디서든 자체 너비에 맞춰 배치가 바뀝니다.

## 구성 요소 \{#anatomy\}

- **검색** 검색란으로 `choice` 타일을 걸러 내고 고정 ID로 선택을 유지합니다.
- **추가 확정** 대화상자가 초안을 보관합니다. 취소하면 버리고 추가하면 한꺼번에 반영합니다.

## 접근성 \{#accessibility\}

체크박스에 작품 이름을 붙이고 이미 추가한 그림에는 설명을 표시합니다. 검색어가 있을 때는 Escape를 처음 누르면 검색어가 지워질 수 있습니다. 한 번 더 누르면 대화상자가 닫히고 라이브러리 버튼으로 초점이 돌아갑니다.
