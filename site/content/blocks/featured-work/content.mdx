Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Proportions** Each `figure-media` keeps its original aspect ratio. The grid aligns the figures at the top.
- **Reading order** The category and title stay inside the same `figcaption` as the description when the images stack.

## Accessibility \{#accessibility\}

Describe what is visible in each image. Its linked title names the work independently of the image or its category.
