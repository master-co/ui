A native table keeps each quantity beside its unit price and subtotal. Add, rename or move a line and its controls continue to identify the same item.

<PagePreview name="default" title="Edit line items" example="line-items" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Amounts** Compute in whole cents, then format each `table-numeric` value with two decimal places.
- **Row order** Move the existing row node so its quantity and description travel together.

## Accessibility \{#accessibility\}

Each quantity and row action has a name derived from the description. After deletion focus moves to an adjacent description or the add button.
