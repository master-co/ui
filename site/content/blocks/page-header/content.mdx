Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **The way back.** A [breadcrumb](/components/breadcrumb) over the title, for a page more than one level deep.
- **The title and one line.** A [heading](/components/heading) as the page's `<h1>` and a muted sentence that says what the list below holds.
- **The actions.** The one the page exists for is a primary [button](/components/button), last in the row; the rest are default buttons before it.
- **A split that wraps.** `flex flex-wrap items-end justify-between gap-md`: on a narrow screen the actions drop under the title and keep their order. `min-w(0)` on the title's column lets a long title wrap instead of pushing the actions out.

This is a region of a page, not a bar: it scrolls with the content. For the bar that stays, use a [navbar](/components/navbar).

## For one thing \{#entity\}

The page of a single project, person or file starts with the thing itself: its mark, its name, its status, and one line of facts. Secondary actions go into a [menu](/components/menu) behind one quiet button, and [tabs](/components/tabs) under the header switch between its views.

## Accessibility \{#accessibility\}

- The header is a `<header>` inside `<main>`, and its title is the page's one `<h1>`.
- Status is a word in a badge, never a color alone.
- An icon button has a name; the menu it opens is a list of buttons, closed with Escape.
- The facts are a `<dl>`: each value is announced with its label.
