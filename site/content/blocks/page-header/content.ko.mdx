블록은 복사해 쓰는 마크업입니다. 페이지의 텍스트 색상과 크기를 그대로 사용하며, 미리보기에서는 body에 `fg-text-body text-sm` 클래스를 설정합니다. 각 블록은 크기 컨테이너이므로 넓은 페이지, 사이드바만큼 좁은 공간, 대화상자 등 어디에 놓이든 자체 너비에 따라 배치가 바뀝니다.

## 구성 요소 \{#anatomy\}

- **돌아갈 경로.** 두 단계 이상 들어간 페이지에서는 제목 위에 [브레드크럼](/components/breadcrumb)을 배치합니다.
- **제목과 한 줄 설명.** 페이지의 `<h1>`로 [제목](/components/heading)을 배치하고, 아래 목록에 어떤 항목이 있는지 눈에 덜 띄는 색의 한 문장으로 설명합니다.
- **작업 버튼.** 페이지의 주된 작업을 실행하는 주요 [버튼](/components/button)은 행 맨 끝에 놓고, 나머지 작업을 실행하는 기본 버튼은 그 앞에 배치합니다.
- **줄바꿈되는 양쪽 배치.** `flex flex-wrap items-end justify-between gap-md`를 적용하면 화면이 좁을 때 작업 버튼이 순서를 유지한 채 제목 아래로 내려갑니다. 제목 열에 `min-w(0)`를 적용하면 긴 제목이 작업 버튼을 밀어내지 않고 줄바꿈됩니다.

페이지 헤더는 콘텐츠와 함께 스크롤되는 페이지 영역입니다. 스크롤해도 제자리에 머무는 바에는 [탐색 모음](/components/navbar)을 사용하세요.

## 접근성 \{#accessibility\}

- 헤더는 `<main>` 안의 `<header>`이며, 헤더 제목은 페이지에서 유일한 `<h1>`입니다.
- 색상만으로 상태를 구분하지 않도록 배지에 상태를 텍스트로 표시합니다.
- 레코드 이름 옆의 글자 표식은 이름과 같은 정보를 전달하므로 보조 기술에서 숨깁니다.
- 아이콘 버튼에는 접근 가능한 이름을 지정합니다. 이 버튼으로 여는 메뉴는 버튼 목록이며, Escape 키로 닫을 수 있습니다.
- 주요 정보는 `<dl>`로 구성하며, 스크린 리더는 각 값을 해당 레이블과 함께 읽어 줍니다.
