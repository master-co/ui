Submit an email address and role to add an invitation to the pending list. Each row has its own menu to resend or withdraw that invitation in the local example.

<PagePreview name="default" title="Invite members" example="member-invitations" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Invitation** A native email `input` validates the address. A duplicate pending address returns to the same field.
- **Pending row** Each list row owns a `menu` ID and both actions use the invitation ID.

## Accessibility \{#accessibility\}

The menu button includes the email address in its name. Withdrawing a row moves focus to a neighboring invitation or the email field.
