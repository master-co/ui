記事は一度だけ表示し、その下に一致した節を並べます。「token」を検索すると二つのガイドから該当する節を探せます。検索結果の URL は再読み込みや共有ができます。

<PagePreview name="default" title="ヘルプ記事の検索" example="help-search" />

ブロックはコピーして使えるマークアップです。文字色と文字サイズはページから引き継ぎます。プレビューでは body に `fg-text-body text-sm` を設定しています。各ブロックはサイズコンテナーで、広いページでも、サイドバーほどの幅でも、ダイアログ内でも、自身の幅に応じて配置が変わります。

## 構成 \{#anatomy\}

- **検索結果の URL** GET フォームが検索語を URL に含めます。利用時には action にこのブロックを表示するページを指定します。
- **記事と節へのリンク** 記事名はガイドの先頭に、節のリンクは固定の ID に移動します。記事名が一致した場合は、その記事の節をすべて表示します。

## アクセシビリティ \{#accessibility\}

検索欄には見えるラベルを付け、リンクは文書の順序に並べます。件数と該当なしのメッセージでも検索結果を確認できます。
