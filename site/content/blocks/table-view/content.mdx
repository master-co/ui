Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

| Band | Holds | Layout |
| --- | --- | --- |
| Header | A title, a count and the primary action | A split: `flex flex-wrap items-center justify-between` |
| Filters | A search [input group](/components/input#input-group), filter [chips](/components/chip), a raised [select](/components/select) | A wrapping row; `ml-auto` sends the sort to the end |
| Table | A [table](/components/table) with a checkbox column and a [menu](/components/menu) on each row | `overflow-x-auto`, so a narrow sheet scrolls the table and not the page |
| Footer | The selection count and a [pagination](/components/pagination) | A split |

- **One [sheet](/components/surface#sheet).** The bands are parted by hairlines, `bt(1) bt-solid b-line-hair`, not by cards inside the card.
- **The filter grows, to a point.** `grow(1) basis(200) max-w(320)`: it takes the room in the row, never less than 200px before wrapping, never more than 320px.
- **Selected rows say so.** `aria-selected="true"` on a `table-row` gives it the selected tone; the checkbox in it is checked. Your script keeps the two in step, and sets the header checkbox's `indeterminate` property when some rows are selected.
- **Row actions hide in a menu** behind a quiet button at the end, named for its row: "Actions for Atlas".

## What needs a script \{#script\}

Filtering, sorting, selecting all and paging change data, so they belong to your application or your server. The block gives each of them the right element to listen to: a search field, checkboxes, a `<select>`, links. Without a script, wrap the bands in a `<form method="get">` and the filters become a query string the server can answer.

## Accessibility \{#accessibility\}

- The sheet is a `<section>` named by its title.
- Every checkbox has a name that includes its row: "Select Atlas". The header's is "Select all projects".
- The actions column has a heading for assistive technology, visually hidden.
- The pagination is a `<nav>` with a label, and the current page carries `aria-current="page"`.
- A table that scrolls sideways needs a focusable scroller: add `tabindex="0"` and a label to the `overflow-x-auto` element when the table can overflow.
