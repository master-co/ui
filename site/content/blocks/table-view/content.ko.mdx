블록은 복사해 사용하는 마크업입니다. 페이지의 텍스트 색상과 크기를 따르며, 미리보기에서는 body에 `fg-text-body text-sm` 클래스를 설정합니다. 각 블록은 크기 컨테이너이므로 넓은 페이지, 사이드바 너비의 공간, 대화 상자 어디서든 자체 너비에 맞춰 배치가 바뀝니다.

## 구성 요소 \{#anatomy\}

- **하나의 [시트](/components/surface#sheet).** 시트 안에 카드를 겹쳐 넣는 대신 얇은 구분선 `bt(1) bt-solid b-line-hair`로 영역을 나눕니다.
- **헤더는 두 부분으로 나뉩니다.** 한쪽에는 제목과 개수를, 다른 쪽에는 기본 작업을 배치합니다. `flex flex-wrap items-center justify-between` 클래스를 적용하면 시트가 좁을 때 기본 작업이 제목 아래로 내려갑니다.
- **필터는 공간이 부족하면 줄바꿈되는 행에 배치합니다.** 검색 [입력 그룹](/components/input#input-group), 필터 [칩](/components/chip), 볼록한 [셀렉트](/components/select)가 들어갑니다. `ml-auto`로 정렬 컨트롤을 행 끝에 배치합니다. 활성화된 칩이 없으므로 모든 상태가 표시됩니다.
- **필터는 일정 너비까지만 늘어납니다.** `grow(1) basis(200) max-w(320)`를 적용하면 행의 남는 공간을 채우되, 줄바꿈 전에는 200px보다 좁아지지 않고 최대 320px까지만 늘어납니다.
- **표는 자체 영역에서 스크롤됩니다.** `scroll-area-inline` 클래스를 적용한 [스크롤 영역](/components/scroll-area)에 표를 넣습니다. 시트가 좁아지면 표만 스크롤되고, 열이 더 이어지는 가장자리는 흐려집니다.
- **행은 선택한 정렬 기준에 따라 표시됩니다.** “최근 배포”가 선택되어 있어 가장 최근에 배포한 항목이 맨 위에 표시됩니다.
- **선택한 행은 선택 상태로 표시됩니다.** `table-row`에 `aria-selected="true"`를 적용하면 선택 상태의 색상이 표시되며, 행 안의 체크박스도 체크됩니다. 스크립트에서 두 상태를 동기화하고, 일부 행만 선택되면 헤더 체크박스의 `indeterminate` 속성을 설정하세요.
- **행별 작업은 행 끝의 눈에 띄지 않는 버튼으로 여는 [메뉴](/components/menu)에 들어갑니다.** 버튼 이름에는 “Atlas 작업”처럼 해당 행의 이름을 포함합니다.
- **푸터는 두 부분으로 나뉩니다**. 한쪽에는 선택한 행의 개수를, 다른 쪽에는 [페이지네이션](/components/pagination)을 배치합니다. 링크는 비활성화할 수 없으므로 첫 페이지의 “이전” 링크에는 `aria-disabled="true"`를 지정하고 `href`는 생략합니다.

## 선택한 행에 적용할 작업 \{#selection\}

## 스크립트가 필요한 동작 \{#script\}

필터링, 정렬, 전체 선택, 페이지 이동은 데이터를 바꾸므로 애플리케이션이나 서버에서 처리합니다. 블록은 각 동작의 이벤트를 받을 요소로 검색 필드, 체크박스, `<select>`, 링크를 제공합니다. 스크립트 없이 사용하려면 모든 영역을 하나의 `<form method="get">` 요소로 감쌉니다. 그러면 필터가 쿼리 문자열로 전달되어 서버에서 처리할 수 있습니다.

## 접근성 \{#accessibility\}

- 시트는 `<section>`이며, 시트의 제목을 접근 가능한 이름으로 사용합니다.
- 각 행의 체크박스 이름에는 “Atlas 선택”처럼 해당 행의 이름을 포함합니다. 헤더 체크박스의 이름은 “모든 프로젝트 선택”입니다.
- 작업 열의 제목은 화면에서 숨기되 보조 기술에서 읽을 수 있게 합니다.
- 페이지 탐색에는 레이블이 있는 `<nav>`를 사용하고, 현재 페이지에는 `aria-current="page"`를 지정합니다.
- 각 행의 첫 번째 셀은 `<th scope="row">`입니다. 따라서 스크린 리더는 셀을 읽을 때 해당 프로젝트 이름도 함께 읽습니다.
- 표는 스크롤 영역 안에서 가로로 스크롤됩니다. 표 안의 체크박스와 버튼을 통해 키보드로 스크롤 영역에 접근할 수 있습니다. 표 안에 포커스를 받을 수 있는 요소가 없다면 스크롤 영역에 `tabindex="0"`, 역할, 접근 가능한 이름을 지정해야 합니다.
