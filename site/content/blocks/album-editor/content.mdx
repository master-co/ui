An album editor keeps the thumbnail, description and controls in one sortable row. Edit a description, move that photograph, then remove a neighboring item.

<PagePreview name="default" title="Edit an album" example="album-editor" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Identity** A stable `data-value` belongs to the whole `sortable-item`, so its text field moves with it.
- **Removal** After removal the next available handle receives focus. The heading receives focus when the album is empty.

## Accessibility \{#accessibility\}

Each move and remove button names its photo. Press Space to pick it up, an arrow key to move it, and Space to drop it.
