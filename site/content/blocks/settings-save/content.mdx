A settings form ends with one row for the draft status and its actions. Edit the archive name, try a failed save, then retry with the same text.

<PagePreview name="default" title="Save settings" example="settings-save" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Saved value** Discard restores the last successful save. A failed request leaves the field editable.
- **Action row** The status wraps within `form-actions` before the buttons leave the panel.

## Accessibility \{#accessibility\}

The archive name has a visible label. A status region announces saving, failure and completion, including after a retry.
