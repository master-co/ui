블록은 복사해서 사용하는 마크업입니다. 페이지의 텍스트 색상과 글자 크기를 따르며, 미리보기에서는 body에 `fg-text-body text-sm`을 설정합니다. 각 블록은 크기 컨테이너이므로 자체 너비에 따라 레이아웃이 바뀝니다.

## 구성 \{#anatomy\}

- **상단의 가는 구분선**에는 `bt(1) bt-solid b-line-hair`를 적용하고, 전체 텍스트에는 한 톤 낮춘 색상인 `fg-text-muted`을 적용합니다. 푸터는 페이지에서 가장 눈에 덜 띄는 영역입니다.
- 첫머리에 **브랜드와 소개 문장 하나**를 배치하고 그 아래에 상태 [배지](/components/badge)를 둡니다.
- **네 열로 배치한 링크.** `grid-cols(2) grid-cols(4)@container(--2xl)`를 적용해 휴대전화에서는 두 열, 블록 너비가 42rem 이상이면 네 열로 표시합니다. 56rem 이상에서는 브랜드 영역이 행 너비의 3분의 1을, 링크 열이 나머지 3분의 2를 차지합니다.
- **`link link-quiet`.** 차분한 링크는 주변 텍스트의 색상을 따르고 상호작용할 때만 밑줄을 표시하므로, 링크가 40개 있어도 페이지에서 지나치게 눈에 띄지 않습니다. `self-start`를 적용하면 각 링크의 너비가 링크 텍스트에 맞춰지고, 옆의 빈 공간은 링크의 상호작용 영역에서 제외됩니다.
- **작은 글씨로 된 안내 문구**는 두 번째 가는 구분선 아래에 별도 행으로 배치합니다.

각 열은 `<nav>`이며, `aria-labelledby`로 해당 열의 제목을 이름으로 지정합니다. 열 제목에는 `<h2>`를 사용하고 글자 크기는 `heading-xs`로 지정합니다. 푸터는 페이지의 모든 섹션 바깥에 있으므로 각 열은 어느 섹션에도 속하지 않습니다.

블록은 보통 페이지의 텍스트 색상을 따릅니다. 푸터만 루트 요소에 색상을 직접 지정합니다. 푸터가 페이지의 다른 영역보다 눈에 덜 띄도록 `<footer>`에 `fg-text-muted`를 적용합니다.

## 접근성 \{#accessibility\}

- 이 블록에는 `<footer>`를 사용합니다. `<main>` 및 모든 `<article>` 요소 바깥에 있으면 페이지의 콘텐츠 정보 랜드마크가 됩니다. 이 랜드마크는 페이지당 하나만 둡니다.
- `<nav>` 요소가 여러 개라면 각 요소의 레이블이 서로 달라야 합니다. 여기서는 각 열의 제목을 레이블로 사용합니다.
- 기본 표면 위에 한 톤 낮춘 텍스트 색상을 사용해도 두 색상 모드 모두에서 본문 텍스트의 대비 기준을 충족합니다. 작은 글씨로 된 안내 문구에도 이보다 옅은 색은 사용하지 않습니다.
