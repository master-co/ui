블록은 복사해서 쓰는 마크업입니다. 페이지의 텍스트 색상과 크기를 그대로 사용하며, 미리보기에서는 body에 `fg-text-body text-sm`을 설정합니다. 각 블록은 크기 컨테이너이므로 자체 너비에 따라 레이아웃이 바뀝니다.

## 구성 요소 \{#anatomy\}

- **[`sheet sheet-inverse`](/components/surface#inverse).** moonstone에서는 잉크색, obsidian에서는 진주색을 사용하며, 기본 강조 버튼과 같은 방향으로 빛이 비치는 효과를 줍니다. 페이지당 하나만 사용하세요.
- **텍스트에 반전 잉크색을 적용합니다.** 제목과 도입 문구에는 `fg-text-inverse`를 적용합니다. 유틸리티는 제목 자체의 색상 선언 뒤에 적용됩니다.
- **행동 유도에는 기본 버튼을 사용합니다.** 잉크색 표면에서는 일반적인 볼록한 버튼이 가장 밝게 보입니다. 기본 강조 버튼을 사용하면 잉크색 표면 위에 잉크색 버튼이 놓입니다.
- **문장 하나와 행동 하나**를 제시하고, 아직 준비되지 않은 방문자를 위해 덜 강조된 보조 행동을 둡니다.

## 강조를 낮춘 행동 유도 \{#quiet\}

페이지의 마무리가 이미 강하게 강조되어 있거나 모든 페이지에서 같은 행동을 요청한다면 일반적인 표면 조합을 사용하세요. [트레이](/components/surface#tray) 안에 [볼록한 표면](/components/surface#sheet)을 두고, 시작 쪽에는 문구를, 끝 쪽에는 버튼을 배치합니다. `flex flex-wrap justify-between`을 적용하면 공간이 부족할 때 버튼이 문구 아래로 내려갑니다.

## 입력 필드를 포함한 행동 유도 \{#field\}

## 접근성 \{#accessibility\}

- 반전 표면은 두 색상 모드 모두에서 텍스트 대비를 온전히 유지합니다. 배경의 잉크색과 텍스트 색상에 테마가 정의한 반전 색상 쌍을 사용하기 때문입니다.
- 입력 필드에는 접근성 이름이 필요합니다. 이 예에서는 `aria-label="Email"` 속성으로 이름을 지정하며, 공간이 충분하면 화면에 표시되는 레이블이 더 좋습니다.
- 버튼을 클릭하면 어떤 일이 일어나는지 알려 주세요. "배포 시작"은 결과를 분명히 알려 주지만 "제출"만으로는 결과를 알기 어렵습니다.
