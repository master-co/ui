Read the permission matrix by role or by action. The table stays intact in a narrow panel so you can compare who may publish and who may manage members.

<PagePreview name="default" title="Role permissions" example="role-permissions" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Two directions** A row header names the action and a column header names the role.
- **Narrow widths** The labeled `scroll-area-inline` preserves the comparison when all columns cannot fit.

## Accessibility \{#accessibility\}

Every data cell says Allowed or Not allowed. Focus the scroll region and use the arrow keys to reach the last role.
