Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Stages** A native ordered list carries the sequence. An `auto-grid` lets the same list fit the available width.
- **Deliverables** The deliverable and fee sit inside their stage, including the planning stage that carries no fee.

## Accessibility \{#accessibility\}

The sequence describes a service before it starts. Use an ordered list with a heading for each stage. No stage is marked current.
