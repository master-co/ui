Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width.

## What is in it \{#anatomy\}

- **A header at a reading measure.** An eyebrow, a [heading](/components/heading) and a lead in a `max-w(560)` column. The grid below is wider than the words above it; that difference is what makes the header read as a header.
- **A grid by container width.** `grid-cols(2)@container(--2xl) grid-cols(3)@container(--5xl)`: two columns from 42rem of block and three from 64rem. Rows are farther apart than columns, `row-gap-2xl` against `gap-xl`, so each claim reads as a unit.
- **The mark in a well.** A 36px [well](/components/surface#well) holds each icon in strong ink. A well, not a colored tile: the interface keeps hue for status.
- **A list.** The claims are `<li>` in a `<ul>`; each title is an `<h3>` under the block's `<h2>`.

Six claims is plenty. Three good ones beat nine.

## On sheets \{#sheets\}

Set each claim on a [sheet](/components/surface#sheet) in a [tray](/components/surface#tray), 4px apart, and let one claim in each row take two columns, on alternating sides. The corners nest, because the tray's corner is a sheet's corner plus the inset.

## One feature, in depth \{#depth\}

For the feature that sells the product, give it the whole width: the argument on one side and a [figure](/components/figure) on the other, from 64rem of block. ## Accessibility \{#accessibility\}

- Icons are decoration here: `aria-hidden="true"`, since each title already says the thing.
- Keep the heading order: one `<h2>` for the block, an `<h3>` for each claim.
- A check mark is not a word. The proof must read without it.
- The picture in the example is atmosphere, so its `alt` is empty. A screenshot of the feature gets a description.
