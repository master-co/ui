블록은 복사해서 사용하는 마크업입니다. 페이지의 텍스트 색상과 글자 크기를 따르며, 미리보기에서는 body에 `fg-text-body text-sm`을 설정합니다. 각 블록은 크기 컨테이너이므로 자체 너비에 따라 레이아웃이 바뀝니다.

## 구성 \{#anatomy\}

- **읽기 좋은 너비의 헤더.** `max-w(560)` 너비의 열에 짧은 상단 문구, [제목](/components/heading), 소개 문단을 배치합니다. 아래 그리드가 위쪽 텍스트보다 넓어 헤더가 본문과 구분됩니다.
- **컨테이너 너비에 맞춰 바뀌는 그리드.** `grid-cols(2)@container(--2xl) grid-cols(3)@container(--5xl)`에 따라 블록 너비가 42rem 이상이면 두 열, 64rem 이상이면 세 열로 표시합니다. 행 간격은 `row-gap-2xl`, 열 간격은 `gap-xl`로, 행 사이를 더 넓게 띄워 각 항목이 하나로 읽히게 합니다.
- **오목한 영역에 담은 아이콘.** 각 아이콘은 36px 크기의 [오목한 영역](/components/surface#well)에 배치하고 진한 전경색으로 표시합니다. 오목한 영역을 사용하며, 인터페이스에서 색조는 상태를 나타낼 때만 사용합니다.
- **목록 구조.** `<ul>` 안에서 각 기능 항목을 `<li>`로 표시합니다. 각 항목의 제목은 블록의 `<h2>` 아래에 배치하는 `<h3>`입니다.

기능은 여섯 가지면 충분합니다. 잘 고른 세 가지가 아홉 가지를 나열하는 것보다 낫습니다.

## 접근성 \{#accessibility\}

- 각 제목이 이미 기능을 설명하므로 아이콘은 장식용입니다. 아이콘에 `aria-hidden="true"`를 설정합니다.
- 제목 계층을 지키세요. 블록에는 `<h2>` 하나를, 각 항목에는 `<h3>` 하나를 사용하세요.
- 체크 표시는 텍스트를 대신할 수 없습니다. 체크 표시 없이도 근거를 이해할 수 있어야 합니다.
- 예시 이미지는 분위기를 연출하는 장식용이므로 `alt` 속성을 비워 둡니다. 기능을 보여 주는 스크린샷에는 설명을 입력하세요.
