Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Group headings** Keep recording activity and review coverage in separate sections. Each card title links to its own report.
- **Empty reports** Keep the link active when there are no reviews. Its destination explains when the first entry will appear. Replace the demo report URLs with your own.

## Accessibility \{#accessibility\}

The section headings precede the reports they describe. Each card contains one named link, so keyboard users reach each report in a single stop.
