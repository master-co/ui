A logo cloud is a quiet row of the names that already trust you. It works by being understated: the marks are in muted ink, all one weight, and none is a link. Put it under a [hero](/blocks/hero), where a visitor decides whether to keep reading.

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width.

The examples set names in type, since the library ships no one's logo. Replace each with an inline `<svg>` that uses `currentColor`, and the row keeps its one ink in light and in dark.

## What is in it \{#anatomy\}

- **A wrapping, centered row.** `flex flex-wrap items-center justify-center` with a larger gap between marks than between lines: `gap-md col-gap-2xl`.
- **One ink.** `fg-text-muted` on the list. A logo in its own colors would be the loudest thing on the page.
- **A list.** `<ul>` with a label, so the number of names is announced and the row has a name.

## In a grid \{#grid\}

When the names deserve more room, set each on a [sheet](/components/surface#sheet) in a [tray](/components/surface#tray): two columns, then three from 42rem of block. The tray's 4px inset is the gap, so the corners nest.

## Accessibility \{#accessibility\}

- Give each SVG logo a name: `role="img"` with `aria-label="Northwind"`, or visually hidden text beside a decorative mark.
- Muted ink on the base surface still meets contrast for large text; keep the marks at least 20px tall.
- Use names you have permission to show.
