Review two edits to the same recording. Each field shows your draft and the latest saved text in labeled cards. Choose a version for both fields to finish the review.

<PagePreview name="default" title="Resolve draft conflicts" example="draft-conflicts" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Versions** Each `card` keeps its version label when the pair stacks.
- **Original** Open the `accordion` to inspect the shared starting value before deciding.

## Accessibility \{#accessibility\}

Each field gets its own named radio group. The unresolved count changes once per field, even if you revise a previous choice.
