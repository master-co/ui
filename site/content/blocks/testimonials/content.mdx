Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width.

## What is in it \{#anatomy\}

- **`quote quote-lg` in a measure.** The pull quote sets its own opening mark and balances its lines; `max-w(720) mx-auto` gives it a column.
- **A source that is a person.** A face, a name in ink and a role with a company. An anonymous quotation persuades nobody.
- **Nothing else.** No stars, no logos, no carousel. One strong sentence does more than five rotating ones a visitor never waits for.

## Several \{#several\}

Three quotations on [sheets](/components/surface#sheet) in a [tray](/components/surface#tray), one column until 56rem of block and three from there. Each card is a `flex` box so the quote can grow and keep the sources on one line across the row.

Keep them the same length, within a line or two. A wall of cards with ragged feet looks unedited.

## Accessibility \{#accessibility\}

- Each is a `<blockquote>`, with the source in a `<footer>` inside it.
- The avatar repeats the name beside it, so its `alt` is empty.
- Use words people said, with their permission, and link to the source when it is public.
