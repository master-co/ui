Show the source beside the result it produces. This worked example pairs an HTML utility with its CSS declaration. Both panes can be selected or copied independently.

<PagePreview name="default" title="Source and output" example="source-and-output" />

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## What is in it \{#anatomy\}

- **Two panes** An `auto-grid` stacks the named code panels in reading order when the column narrows.
- **Clipboard** Each button reads its own `code` element, including whitespace and punctuation.

## Accessibility \{#accessibility\}

The headings and the two copy buttons name their side. If clipboard access fails, the original text stays selectable and the status explains the fallback.
