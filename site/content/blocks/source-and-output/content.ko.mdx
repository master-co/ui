소스와 그 결과를 나란히 둡니다. 이 정적 예제는 HTML 유틸리티와 해당 CSS 선언을 보여 주며 양쪽을 개별 선택하거나 복사할 수 있습니다.

<PagePreview name="default" title="소스와 출력" example="source-and-output" />

블록은 복사해 사용하는 마크업입니다. 페이지의 텍스트 색상과 크기를 따르며, 미리보기에서는 body에 `fg-text-body text-sm` 클래스를 설정합니다. 각 블록은 크기 컨테이너이므로 넓은 페이지, 사이드바 너비의 공간, 대화 상자 어디서든 자체 너비에 맞춰 배치가 바뀝니다.

## 구성 요소 \{#anatomy\}

- **두 영역** 폭이 좁으면 `auto-grid`가 이름 있는 코드 영역을 읽기 순서대로 쌓습니다.
- **클립보드** 각 버튼은 같은 영역의 `code`만 읽어 공백과 문장 부호를 보존합니다.

## 접근성 \{#accessibility\}

제목과 복사 버튼이 어느 쪽인지 밝힙니다. 클립보드 쓰기가 실패해도 원문을 선택할 수 있고 상태가 수동 복사를 안내합니다.
