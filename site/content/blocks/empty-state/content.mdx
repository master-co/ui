An empty state is what a view shows before it has anything to show. It is the smallest block: the [empty](/components/empty) component with the right words in it. The words are the work. A good empty state says what belongs here, why it is empty, and what to do next.

Blocks are markup to copy. They take the page's own text color and size; the previews set `fg-text-body text-sm` on the body. Each block is a size container, so it reflows by its own width: in a wide page, a sidebar's worth of room or a dialog.

## Four kinds of empty \{#kinds\}

A view can be empty for four different reasons, and each wants different words.

| Kind | Say | Offer |
| --- | --- | --- |
| **Nothing yet** | What goes here and what it is for | The action that creates the first one |
| **First run** | The few steps to a first result | The next step |
| **No results** | What was searched, and which filters still apply | A way to widen the search |
| **Something failed** | What happened, in plain words, and whose side it is on | A way to try again, in an [alert](/components/alert) |

The first is above. The other three follow.

## First run \{#first-run\}

For a product a person has just opened, replace the empty view with the way in: [steps](/components/steps), set vertically with a sentence each, and the next step as the primary button. The step already done shows as done; `aria-current="step"` marks where they are.

## No results \{#no-results\}

When a search or a filter leaves nothing, repeat the query back, typo and all, and say which filters are still on. A reader who cannot see why the list is empty will assume the data is gone.

The region is `aria-live="polite"`, so the change from results to none is announced after the reader stops typing.

## Something failed \{#failed\}

A failure is not an empty state, though it stands in the same place. It is an [alert](/components/alert): the status hue and an icon say that something is wrong, the words say what, and one button is the way forward. Say that the reader's work is safe when it is. The section keeps the name of the view that failed, so the landmark is still there to find.

## Accessibility \{#accessibility\}

- The title is a heading at the level of the view it replaces.
- An empty state that appears in response to an action is announced: `aria-live="polite"` for no results, `role="alert"` for a failure.
- The icon is decoration. Never rely on it, or on its color, to say which kind of empty this is.
- "Read the guide" goes somewhere, so it is a link drawn as a button; "New project" does something, so it is a button.
- Keep the primary action the same one the full view offers, so the reader learns it once.
