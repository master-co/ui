## 구성 방법 \{#how-it-is-built\}

- **프레임에 `container-inline` 적용**. 프레임이 크기 컨테이너가 됩니다. 내부의 모든 `@container(…)` 유틸리티는 화면 크기가 아닌 프레임 크기를 기준으로 동작합니다.
- **높이가 고정된 행.** `flex h(440)`로 두 영역의 높이를 같게 맞추고, 각 영역에 `overflow-y-auto`를 적용해 독립적으로 스크롤되게 합니다. 화면 높이를 모두 쓰는 앱에서는 높이를 숫자로 지정하는 대신 [고정 셸](/pages/app-shell#fixed)에서 가져오세요.
- **목록은 고정 너비, 상세 영역은 가변 너비.** 프레임 너비가 48rem 미만이면 목록에 `w-full`을 적용하고, 48rem 이상이면 `shrink(0)`와 함께 `w(300)@container(--3xl)`을 적용합니다. 상세 영역에는 `grow(1) basis(0) min-w(0)`를 적용해 남은 너비를 채우고 목록을 밀어내지 않도록 합니다.
- **48rem 미만에서는 영역 하나만 표시.** 상세 영역은 `hidden`으로 숨기고 `flex@container(--3xl)`을 적용해 다시 표시합니다. 좁은 화면에서는 목록이 표시되며, 행을 선택하면 해당 항목의 상세 페이지로 이동합니다. 이 이동은 라우터에서 처리하세요.
- **두 영역 사이의 구분선**에는 `bxe(1)@container(--3xl) bxe-solid@container(--3xl)`을 적용해 두 영역이 모두 표시될 때만 보이게 합니다.

[`list-interactive`](/components/list) 안의 `list-row`에 `aria-current="true"`를 적용해 현재 행을 표시합니다.

## 세 가지 구성 방법 \{#three-ways\}

| 사용 상황 | 구성 방법 |
| --- | --- |
| 두 영역이 페이지의 일부인 경우 | 위 예제처럼 유틸리티와 컨테이너 사용 |
| 사용자가 두 영역의 너비를 조절하는 경우 | [분할기](/components/splitter) |
| 두 영역이 앱 전체를 구성하는 경우 | 목록을 사이드바로 둔 [고정 셸](/pages/app-shell#fixed) |

## 접근성 \{#accessibility\}

- 목록은 각 항목의 상세 내용으로 연결되는 링크로 구성됩니다. 현재 표시 중인 항목의 링크에 `aria-current="true"`를 지정합니다.
- 프레임에 레이블을 지정하고, 상세 영역에는 선택한 항목의 이름을 제목으로 넣으세요. 그러면 상세 영역에 바로 도달한 사용자도 어떤 항목을 보고 있는지 알 수 있습니다.
- 스크롤할 수 있지만 내부에 포커스를 받을 요소가 없는 영역에는 키보드로 스크롤할 수 있도록 `tabindex="0"`을 지정하세요.
- 좁은 화면에서 상세 영역을 숨기면 `display: none`이 적용되어 접근성 트리에서 제외됩니다. 이 영역을 가리키는 컨트롤이 남지 않도록 하세요.
