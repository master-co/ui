## 구성 방법 \{#how-it-is-built\}

- **프레임에 `page` 적용.** 프레임은 세로로 배치되며 최소 높이는 `100dvh`입니다. 동적 뷰포트 단위는 휴대폰의 도구 모음이 나타나거나 사라질 때 화면에 보이는 높이를 따라가므로, 프레임의 최소 높이가 가시 영역을 넘거나 빈 공간을 남기지 않습니다. 이 구성에서 유틸리티로 표현할 수 없는 부분은 이 설정뿐입니다.
- **본문 영역에 `grow(1)` 적용.** 본문 영역이 남은 공간을 채우므로 짧은 페이지에서도 푸터가 맨 아래에 놓입니다.
- **영역 대신 콘텐츠에 너비 제한 적용.** 헤더와 푸터는 전체 너비를 차지합니다. 본문 영역과 푸터 내부 콘텐츠는 같은 너비 제한인 `max-w(720) mx-auto px-lg`를 사용하므로 양쪽 가장자리가 맞춰집니다. 내비게이션 바는 `--navbar-padding-x: max(1.5rem, calc(50% - 21rem))`로 같은 가장자리에 맞춥니다. 가운데에서 너비의 절반만큼 바깥쪽입니다. 색인 페이지에는 더 넓은 너비를 사용하고, 글을 읽는 페이지에는 이 너비를 사용합니다.
- **컴포넌트로 표면 구성.** 상단에는 스크롤할 때 자체적으로 상단에 붙는 [내비게이션 바](/components/navbar)를 사용합니다. 푸터 위의 가는 선은 테두리 유틸리티로 만듭니다.

## 이 프레임으로 만드는 페이지 \{#uses\}

사이트의 페이지 대부분은 이 프레임의 본문 영역에 다른 것을 넣은 것입니다.

| 페이지 | 본문 영역에 넣는 것 |
| --- | --- |
| 아티클, 블로그 게시글, 변경 이력 | [브레이크아웃](/components/breakout): 이미지나 표가 밖으로 확장될 수 있는 읽기 단 |
| 옆에 목차를 둔 긴 아티클 | 탐색 메뉴와 목차를 더한 [문서](/pages/docs) 페이지 |
| 검색, 리소스 디렉터리 | [검색 결과](/pages/results) 페이지: 조건과 그 조건으로 찾은 결과를 나란히 배치 |
| 랜딩 페이지 | 차례로 이어지는 [블록](/blocks): 히어로, 기능 소개, 요금제, 행동 유도 |
| 로그인, 오류 | 가운데에 놓인 카드 하나: [가운데 정렬](/pages/centered) 페이지 |

## 접근성 \{#accessibility\}

- 랜드마크로 `<header>`, `<main>`, `<footer>`를 각각 하나씩 사용하고 모든 `<nav>`에 레이블을 지정합니다.
- 페이지의 첫 요소는 본문 영역으로 이동하는 [건너뛰기 링크](/components/skip)입니다. 본문 영역에는 `tabindex="-1"`을 지정해 링크를 실행할 때 포커스도 함께 이동하도록 합니다. 키보드 사용자는 키를 한 번 눌러 헤더를 건너뛸 수 있습니다.
- 스크롤할 때 상단에 붙는 헤더는 페이지 위쪽을 가립니다. 링크로 이동한 제목이 헤더에 가려지지 않도록 루트의 `scroll-padding-top`을 헤더 높이로 설정하거나, 링크 대상인 각 제목에 [flash](/components/flash)를 적용해 해당 제목이 보이도록 합니다.
