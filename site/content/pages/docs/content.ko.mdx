## 레이아웃 구성 \{#how-it-is-built\}

| 영역 | 클래스 | 구성 요소 |
| --- | --- | --- |
| 헤더 | `navbar shell-header` | 브랜드, 검색 필드, 제품으로 이동하는 링크 |
| 사이드바 | `shell-sidebar` | 각 그룹 위에 `nav-label`을 둔 [nav](/components/nav) |
| 주 영역 | `shell-main` | `max-w(720) mx-auto`로 최대 너비를 제한하고 가운데 정렬한 `<article>` |
| 보조 영역 | `shell-aside` | [목차](/components/toc) |

- **본문이 읽기 너비를 정합니다.** 720px이면 본문 한 줄에 약 75자가 들어갑니다. 이는 편하게 읽을 수 있는 한 줄 길이의 상한에 해당합니다. 본문을 감싸는 열이 남은 너비를 모두 차지하므로 본문은 양옆 열 사이의 중앙에 놓입니다.
- **양옆 열은 각각 독립적으로 스크롤됩니다.** 각 열의 높이는 뷰포트에서 헤더를 제외한 높이와 같습니다. 탐색 메뉴가 길어도 메뉴를 스크롤할 때 페이지는 움직이지 않고, 페이지를 스크롤할 때도 탐색 메뉴는 제자리에 있습니다.
- **목차는 현재 섹션을 자동으로 표시합니다.** 브라우저가 `scroll-target-group`을 지원하면 [목차](/components/toc)가 페이지의 스크롤 위치를 따라갑니다. 지원하지 않는 브라우저에서는 스크립트에서 `aria-current` 속성을 설정합니다.
- **제목은 헤더에 가려지지 않습니다.** 각 제목에는 [flash](/components/flash)를 적용합니다. 링크로 이동하면 제목이 뷰포트 상단에서 5rem 아래에 놓여 고정 헤더에 가려지지 않고, 이동한 제목에는 윤곽선이 표시됩니다.
- **본문 끝에서 다른 페이지로 이동할 수 있습니다.** [페이지 탐색](/components/pager)에 이전 페이지와 다음 페이지의 제목을 표시합니다.

`hidden flex@container(--xl)`을 적용해 검색 필드를 기본적으로 숨깁니다. 크기 컨테이너인 탐색 바의 너비가 36rem 이상이면 검색 필드가 표시됩니다.

## 접근성 \{#accessibility\}

- 네 탐색 영역에는 각각 레이블이 필요합니다. 사이트 탐색에는 "문서", 페이지 목차에는 "이 페이지의 목차"를 사용하고, 브레드크럼과 이전·다음 페이지 탐색에도 각각 레이블을 지정합니다. 양옆 열은 각각 `<nav>` 요소를 일반 요소로 감싼 구조이므로 열마다 랜드마크가 하나씩 생깁니다.
- 소스 순서는 헤더, 탐색 메뉴, 본문, 목차입니다. 페이지를 순서대로 읽으면 탐색 메뉴를 지나 본문의 `<h1>`에 도달합니다. 따라서 첫 번째 요소로 [건너뛰기 링크](/components/skip)를 두어 `tabindex="-1"`이 지정된 주 영역으로 바로 이동할 수 있게 합니다.
- 좁은 화면에서는 목차를 숨깁니다. 목차로 바로 이동하는 편의는 줄어들지만, 모든 제목은 본문에 그대로 남습니다.
