Master UI is published as CSS source. Your project's Master CSS integration compiles it together with your own styles, so there is no separate build step or runtime.

## Set up Master CSS \{#set-up-master-css\}

Install Master CSS and its integration for your framework first. Follow the [Master CSS installation guide](https://css.master.co/guide/installation) for Vite, Astro, Next.js, Svelte and others.

## Install the package \{#install-the-package\}

```bash
npm install @master/ui
```

Any package manager works, such as `bun add @master/ui` or `pnpm add @master/ui`.

## Import the stylesheet \{#import-the-stylesheet\}

Import Master UI after the Master CSS preset in your app stylesheet:

```css name=app.css
@import '@master/css';
@import '@master/ui';
```

The preset declares the layer order `theme, base, defaults, components, utilities`. Master UI adds its rules to `components`, so utilities in your markup still win.

## Import only what you use \{#import-only-what-you-use\}

Each component is also exported on its own. Import the shared theme first, then the components the app needs:

```css name=app.css
@import '@master/css';
@import '@master/ui/theme.css';
@import '@master/ui/components/button.css';
@import '@master/ui/components/switch.css';
```

## Customize the theme \{#customize-the-theme\}

Override Master UI tokens after the import. Every component that reads a token follows the new value:

```css name=app.css
@import '@master/css';
@import '@master/ui';

@theme {
  --color-accent: light-dark(var(--color-violet-60), var(--color-violet-40));
  --color-focus-ring: var(--color-violet-50);
}
```

Tokens declared in `@theme` also register utilities, so `bg-accent` and `fg-on-accent` are available in markup.

| Token | Used for |
| --- | --- |
| `--color-primary`, `--color-primary-hover`, `--color-on-primary` | Primary buttons and badges |
| `--color-accent`, `--color-accent-hover`, `--color-on-accent` | Accent buttons, checked switches |
| `--color-danger`, `--color-danger-hover`, `--color-on-danger` | Destructive actions |
| `--color-focus-ring` | Keyboard focus outlines |
| `--color-control-track` | Unchecked switch tracks |

Components also expose their own custom properties, such as `--btn-height` or `--switch-height`, documented on each component page.
