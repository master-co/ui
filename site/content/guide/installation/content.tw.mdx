## 使用 AI 代理設定 \{#set-up-with-an-ai-agent\}

程式設計代理可以替你完成這項設定。在應用程式的根目錄中，將下方的提示詞貼給代理。它會先檢查專案，並在變更檔案前詢問你樣式表的途徑、匯入範圍、代理設定，以及如何處理既有的元件庫。接著它會安裝固定版本的套件、匯入樣式表，並在瀏覽器中與透過 `master-ui check` 檢查第一個元件。

## 設定 Master CSS \{#set-up-master-css\}

若要使用原始碼樣式表，請先設定 Master CSS 2.1 或更新版本，以及適用於你的框架的整合。Vite、Astro、Next.js、Svelte 等框架請依照 [Master CSS 安裝指南](https://css.master.co/guide/installation)進行。

## 安裝套件 \{#install-the-package\}

```bash
npm install @master/ui --save-exact
```

任何套件管理工具都可以，例如 `bun add @master/ui --exact` 或 `pnpm add @master/ui --save-exact`。Master UI 仍處於實驗階段，任何版本都可能破壞先前發布的內容，因此請固定版本並有意識地升級；[穩定性](/guide/stability#experimental)說明升級後該執行什麼。

## 匯入樣式表 \{#import-the-stylesheet\}

在應用程式的樣式表中，於 Master CSS 預設組之後匯入 Master UI：

```css name=app.css
@import '@master/css';
@import '@master/ui';
```

預設組宣告了串接層順序 `theme, base, defaults, components, utilities`。Master UI 將它的規則加入 `components`，因此標記中的 utility 仍會生效。

## 確認安裝 \{#verify-the-installation\}

確認應用程式有載入 `app.css`，然後在一個會渲染的頁面上加入按鈕。在 JSX 中，請寫 `className` 而不是 `class`：

```html
<button type="button" class="btn btn-primary">Save changes</button>
```

透過既有的開發指令執行應用程式。按鈕在淺色模式下應為墨色表面，在深色模式下應為淺色表面，並有可見的鍵盤焦點環。它的外觀不需要行為腳本；儲存變更仍需要應用程式自己的動作處理函式。

如果它看起來像沒有樣式的瀏覽器按鈕，請檢查頁面是否載入了 `app.css`，以及編譯後的輸出是否包含 `.btn`。使用原始碼匯入時，請確認 Master CSS 整合有處理這份樣式表。接著[檢查標記](#check-your-markup)。

## 只匯入你使用的部分 \{#import-only-what-you-use\}

每個元件也都有個別匯出。先匯入共用的主題，再匯入應用程式需要的元件：

```css name=app.css
@import '@master/css';
@import '@master/ui/theme.css';
@import '@master/ui/components/button.css';
@import '@master/ui/components/switch.css';
```

請納入標記中所有 class 對應的樣式表。例如，內含 `icon` 或 `spinner` 的按鈕，也需要該元件的樣式表。完整匯入可以省去自行管理這份清單的工夫。

## 每份樣式表一行匯入 \{#one-import-per-stylesheet\}

套件附帶一個小型命令列工具。`init` 會寫入 `ui/index.css`，以各自一行的方式匯入主題與每份樣式表，並寫入 `master-ui.json`，記錄專案擁有哪些內容：

```bash
npx master-ui init
```

```css name=app.css
@import '@master/css';
@import './ui/index.css';
```

用這個入口檔案取代完整的 `@master/ui` 匯入。這是選用的：當你想自行維護匯入清單，或[擁有部分元件的原始碼](/guide/registry)時再選擇它。只有在標記不再使用某一行的 class 時，才刪除那一行。

## 行為 \{#behaviors\}

大多數元件不需要腳本。少數模式沒有原生元素（combobox、命令面板、日曆），套件為每一種都提供參考腳本：

```js name=app.js
import { attach } from '@master/ui/behaviors'

const detach = attach()
```

在標記存在之後，於瀏覽器端程式碼中呼叫 `attach()`。它會掛上當下辨識到的模式，並回傳一個清理函式；移除該標記之前請呼叫 `detach()`。它不會觀察之後插入的內容，也不會設定右鍵選單的目標。限定範圍的掛載方式與個別函式請參閱[行為](/guide/behaviors)。在 React、Svelte 或 Vue 中，請使用[框架元件](/guide/frameworks)管理它們的生命週期。

## 不使用 Master CSS \{#without-master-css\}

套件包含已編譯為一般 CSS 的元件。支援 CSS 匯入的打包工具可以直接使用已安裝且固定版本的套件：

```css name=app.css
@import '@master/ui/base.css';
@import '@master/ui/standalone.css';
```

`base.css` 提供預設組的重設樣式，包括 `box-sizing: border-box` 與表單控制項的字型。如果你的專案已經提供同等的重設樣式，請省略這行匯入。

若是靜態頁面，請將已安裝套件中的編譯檔案複製到伺服器對外提供的資料夾。例如，當 `public/` 對應到 `/` 時：

```bash
mkdir -p public/styles
cp node_modules/@master/ui/dist/base.css public/styles/master-ui-base.css
cp node_modules/@master/ui/dist/standalone.css public/styles/master-ui.css
```

```html
<link rel="stylesheet" href="/styles/master-ui-base.css">
<link rel="stylesheet" href="/styles/master-ui.css">

<button type="button" class="btn btn-primary">Save changes</button>
```

複製的檔案來自你安裝的確切套件版本。當你有意升級該版本時，請重新複製。這個途徑不需要在應用程式中編譯 CSS。

編譯後的樣式表宣告了與原始碼建置相同的串接層與 token。它會跟隨讀者的色彩配置；`data-theme="light"` 或 `data-theme="dark"` 可以為整個頁面或某個子樹固定配置。它不含 Master CSS 的 utility：請用你自己的 CSS 處理版面，並在複製[版面](/components#layouts)、[區塊](/blocks)或[頁面](/pages)時替換其中的 utility class。

## 檢查標記 \{#check-your-markup\}

每份樣式表都有一份[契約](/guide/contracts)：它的 class、每個 class 該放在哪個元素上，以及需要的屬性。`check` 會讀取你的樣板並回報違反契約之處：

```bash
npx master-ui check
```

在已安裝套件的專案根目錄執行它。它會檢查 HTML 以及 JSX、Svelte、Vue、Astro 等樣板，但不會渲染它們。解決它回報的診斷後，請在瀏覽器中檢查可見的結果與鍵盤互動；靜態檢查沒有問題，並不代表無障礙或瀏覽器支援已經沒有問題。[搭配 AI 使用](/guide/ai#check-the-markup)說明診斷與在 CI 中的用法。

## 自訂主題 \{#customize-the-theme\}

使用[主題設定](/guide/theming#retune-tokens)變更品牌色、圓角或焦點色等共用值。[預設主題](/guide/theme)說明它們的角色與預設值。如果變更只影響單一實例或單一元件，請先從[自訂](/guide/customization)開始，選擇合適的層級。
