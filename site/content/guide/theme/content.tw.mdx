Master UI 的預設主題採用一致的材質風格。淺色模式是 **Moonstone**，呈現清透的鋅灰珍珠質感。深色模式是 **Obsidian**，呈現霧面鋅灰玻璃質感，各層表面分明，邊緣清晰可辨。兩者都由略偏左的上方光源照亮，因此每個凸起表面的頂緣都有一道亮線，下方則有一抹逐漸淡去的短陰影。

整體風格克制，以墨色取代彩色，採用半像素輪廓、層層相套的圓角，以及隨狀態變化的深度。細節靠光線呈現，無須額外裝飾，邊緣只需清楚到足以辨識。

參考下列各節，為介面選擇適合的表面、線條、文字或深度角色。這些數值來自目前套件的預設主題。[主題設定](/guide/theming) 說明如何覆寫數值或打造其他材質。

## 原則 \{#principles\}

[設計](/guide/design) 說明預設材質、層級、形狀與互動狀態背後的設計考量。做設計決策時可參考該頁，本頁則記錄 `@master/ui` 實作的 token 與樣式組合。

`packages/ui/theme.css` 是實際定義這些數值的樣式表。元件樣式會讀取這些 token，Paper 等主題可以直接替換它們，無須重寫元件。

## 表面 \{#surfaces\}

所有表面共用一套層級。每個層級代表一種用途，依表面的用途選擇層級後，主題會為該角色套用對應的淺色或深色數值。

  <div class="sheet flex flex-col gap-md p-lg">
    <p class="m(0) text-xs fg-text-muted">Raised sheet</p>

  </div>

| Token | 角色 | Moonstone | Obsidian |
| --- | --- | --- | --- |
| `--color-surface-base` | 頁面底色 | 98.6% | 19.4% |
| `--color-surface-tray` | 用來承托面板的下凹托盤 | 96% | 17.4% |
| `--color-surface-raised` | 凸起表面，如卡片和按鈕 | 100% | 24.2% |
| `--color-surface-raised-low` | 凸起表面漸層的底端 | 99.3% | 22.8% |
| `--color-surface-inset` | 凹入表面，如欄位和軌道 | 96.6% | 16.4% |
| `--color-surface-inset-hover` | 指標懸停時的凹入表面 | 95.8% | 15.4% |
| `--color-surface-floating` | 浮在內容上方的彈出視窗和選單 | 100% | 26.4% |
| `--color-surface-chip` | 中性色的標籤和徽章 | 96.5% | 白色，不透明度 7% |
| `--color-surface-inverse` | 墨色，用於主要按鈕和已勾選的控制項 | 22% | 95% |
| `--color-surface-scrim` | 強制回應對話框背後的遮罩 | 18% 亮度，不透明度 20% | 黑色，不透明度 55% |

表中百分比若未標示為不透明度，即表示 OKLCH 明度。`@apply --surface-sheet` 會為凸起表面套用從 `raised` 到 `raised-low` 的由上而下漸層。依用途選擇角色，例如用 `floating` 區分浮在面板上方的選單，用 `inset` 標示面板內的欄位。色彩 token 本身不會設定元素的位置或陰影。

## 線條 \{#lines\}

Moonstone 的線條採用不同不透明度的中性墨色，Obsidian 則採用不同不透明度的白色。其中兩種是 1px 的分隔線，其餘三種用零模糊的 `box-shadow` 繪製成半像素環狀輪廓，不佔版面配置空間。各輪廓的不透明度皆依線寬調整，讓線條纖細又清楚。

| Token | Moonstone | Obsidian | 線寬或形式 | 用途 |
| --- | --- | --- | --- | --- |
| `--color-line-hair` | 6.5% | 7.5% | 1px | 表面內部的低對比分隔線 |
| `--color-line-divider` | 12% | 13% | 1px | 區段之間及分頁標籤列的分隔線 |
| `--color-line-contour` | 12% | 14% | .5px | 各種表面的外輪廓 |
| `--color-line-strong` | 20% | 23% | .5px | 懸停時的輪廓、開關軌道、按鍵帽 |
| `--color-line-mark` | 32% | 36% | .5px | 核取方塊及欄位取得焦點時的輪廓 |
| `--color-texture` | 20% | 23% | 點與 .5px 細線 | [紋理](/components/texture)的標記，主題未另行設定時沿用 `--color-line-strong` |

需要一眼辨識的控制項會用比一般表面更鮮明的輪廓。欄位疊加兩道輪廓，核取方塊則使用標記線。

## 文字 \{#text\}

文字使用柔和的墨色，避開純黑與純白。

| Token | 用途 |
| --- | --- |
| `--color-text-strong` | 標題、標籤和值 |
| `--color-text-body` | 內文 |
| `--color-text-muted` | 提示、說明文字和未選取的選項 |
| `--color-text-disabled` | 停用的控制項 |
| `--color-text-inverse` | 墨色表面上的文字 |
| `--color-focus` | 焦點外框 |

## 高度 \{#elevation\}

高度表示從按下的凹槽到覆疊層的深度順序。凸起表面由頂緣內側的高光、一道半像素輪廓，以及三到六層向下投射的陰影組成。

<div class="p-lg r-lg bg-surface-raised shadow-flat text-xs fg-text-muted">flat</div>
<div class="p-lg r-lg bg-surface-raised shadow-raised text-xs fg-text-muted">raised</div>
<div class="p-lg r-lg bg-surface-raised shadow-raised-hover text-xs fg-text-muted">raised-hover</div>
<div class="p-lg r-lg bg-surface-raised shadow-lifted text-xs fg-text-muted">lifted</div>
<div class="p-lg r-lg bg-surface-floating shadow-floating text-xs fg-text-muted">floating</div>`} />

| Token | 用途 |
| --- | --- |
| `--shadow-pressed` | 凹槽和按下的控制項 |
| `--shadow-flat` | 只有一道輪廓、沒有抬升的表面 |
| `--shadow-raised` | 一般狀態下的按鈕、標籤和小卡片 |
| `--shadow-raised-hover` | 上述元件懸停時使用，輪廓更鮮明 |
| `--shadow-lifted` | 卡片和面板 |
| `--shadow-floating` | 選單和彈出視窗 |
| `--shadow-overlay` | 對話框 |

例如，`--shadow-raised` 在高光與輪廓下方疊加 `0 1px 2px -1px`、`0 2px 4px -2px` 和 `0 4px 8px -4px`。高度越高，各層陰影的偏移範圍越大。負的擴散半徑讓陰影貼近物件，模糊則讓陰影邊緣更柔和。這些 token 負責呈現深度，實際堆疊順序仍由元素的版面配置與平台行為決定。

## 墨色 \{#ink\}

墨色表面以反相色填滿，例如主要按鈕、已勾選的核取方塊、已傳送的訊息，以及每頁唯一的[反相面板](/components/surface)。所有墨色表面的頂緣都有同樣的亮線，四周也有同樣的細線，因此無論大小，看起來都是同一種材質。

| Token | 角色 |
| --- | --- |
| `--color-surface-inverse-high`, `--color-surface-inverse-low` | 墨色面板的明暗漸層 |
| `--color-ink-high`, `--color-ink-low` | 墨色控制項在一般狀態下較圓潤的明暗漸層 |
| `--color-ink-high-hover`, `--color-ink-low-hover`, `--color-ink-pressed` | 同一控制項在懸停與按下時的色彩 |
| `--color-ink-highlight` | 墨色表面頂緣的亮線 |
| `--color-ink-edge` | 墨色表面四周的細線 |
| `--color-surface-tip` | 工具提示的表面，Moonstone 用墨色，Obsidian 用較淺的色塊 |
| `--shadow-ink`, `--shadow-ink-hover`, `--shadow-ink-pressed` | 墨色控制項在各狀態下的深度 |
| `--shadow-ink-mark` | 小型選取填色，如核取方塊、單選按鈕和選取的日期 |
| `--shadow-ink-well`, `--shadow-thumb-on-ink` | 已填色的軌道，以及軌道上的滑塊 |
| `--shadow-tip` | 工具提示和圖表數值標籤 |

帶有色相的控制項（如品牌按鈕或破壞性操作的確認按鈕）會以自身色相調配表面、邊緣與光暈，受光處則使用 `--color-tone-highlight` 和 `--color-tone-highlight-soft`。

## 形狀 \{#shape\}

圓角半徑和表面一樣依用途區分。標籤用來做小型標記，控制項可供按壓或輸入，表面則是承載內容的面板。這些 token 定義在 `@theme` 中，因此也能用作 utility，例如 `r-control` 會套用控制項的基本半徑。元件還會套用下文所述的連續圓角形狀與縮放比例，單用圓角 utility 無法重現完整效果。

| Token | 數值 | 適用元件 |
| --- | --- | --- |
| `--radius-chip` | 6px | 徽章、按鍵帽、核取方塊、骨架畫面 |
| `--radius-control-sm` | 8px | 小型按鈕和欄位、選單列、選項、分段控制項的滑塊 |
| `--radius-control` | 10px | 按鈕、欄位、凹槽 |
| `--radius-control-lg` | 12px | 大型按鈕和欄位、警示、選擇項目、浮動通知 |
| `--radius-surface` | 16px | 面板、卡片 |

外層容器的圓角由內部元件決定，等於內層半徑加上兩者之間的內距。托盤的半徑等於面板半徑加 4px，選單等於選單列半徑加 4px，分段控制項的軌道等於滑塊半徑加上內距，欄位內的按鈕則等於欄位半徑減 4px。如此一來，轉角處的間隙也能維持等寬。只有膠囊形元件、圓點和頭像使用更圓的形狀。

### 連續圓角 \{#continuous-corners\}

`border-radius` 會畫出四分之一圓。圓弧與直線相接時，曲率會瞬間從零跳到圓弧的曲率，因此接合處看得出轉折。以 `corner-shape: squircle` 畫出的圓角方形會提早開始轉彎，曲率再逐漸增加，讓直邊平順地接入圓角。

瀏覽器支援 `corner-shape` 時，元件會使用圓角方形曲線，其餘情況則使用四分之一圓。半徑相同時，圓角方形曲線更貼近原本的直角，因此元件會將半徑乘上 `--corner-scale`，維持視覺上的圓潤程度。使用圓角方形曲線時係數為 1.6，其餘情況為 1。兩個值統一在主題中設定，供所有元件讀取。

| 屬性 | 支援 `corner-shape` | 不支援 |
| --- | --- | --- |
| `--corner-shape` | `squircle` | `round` |
| `--corner-scale` | `1.6` | `1` |

膠囊形元件、圓點、頭像和滑塊仍採用正圓弧。[主題設定](/guide/theming#retune-tokens) 說明如何讓所有圓角都使用圓弧。

## 字體排印 \{#type\}

主題本身不會下載字型。文件使用 Geist，控制項則讀取預設組態的字型家族 token。請先在應用程式中載入字型，再指定使用它。下方列出本站的字體排印設定。

```css name=app.css
@theme {
  --font-sans: 'Geist';
  --font-feature-sans: 'ss02', 'ss03', 'ss04', 'ss06', 'ss07', 'ss08';
}

body {
  font-weight: 350;
}
```

控制項標籤使用 `--font-weight-control`（460），字重比一般字重略高，清楚好讀又不顯厚重。標題維持一般字重，靠字級和墨色區分層級。

## 動態效果 \{#motion\}

互動和說明動畫共用同一組緩動曲線，讓互動反應俐落、說明動畫平穩。位移距離由 `--lift` 設定，預設讓凸起的控制項在懸停時上移半像素，按下時下移半像素。卡片的上移距離是兩倍。若希望主題沒有位移，請將它設為 `0px`。減少動態效果模式已套用此設定。

| Token | 數值 | 用途 |
| --- | --- | --- |
| `--easing-glide` | `cubic-bezier(.22, 1, .36, 1)` | 所有狀態變化 |
| `--duration-press` | 60ms | 按下控制項 |
| `--duration-quick` | 160ms | 懸停與焦點、彈出視窗、選單和工具提示，以及所有退場動畫 |
| `--duration-base` | 280ms | 滑塊和面板移動、對話框進場 |
| `--lift` | .5px | 凸起控制項上移和下沉的距離 |

覆疊層的進場與退場都由 CSS 定義。`@starting-style` 設定元素進場的起始畫面，而 `display` 和 `overlay` 透過 `allow-discrete` 參與轉場，讓退場動畫播完後，元素才離開頂層。退場比進場短。啟用減少動態效果時，會移除位移與縮放，只保留淡入淡出。

## 狀態與品牌 \{#status-and-brand\}

介面只用 `--color-info`、`--color-success`、`--color-warning` 和 `--color-danger` 這四種色相傳達狀態。每種色相都經過調整，確保作為文字顏色時，在對應主題下清晰可讀。

品牌色是唯一不表示狀態的色相，每個畫面只在一個 [`btn-brand`](/components/button#variants) 上使用。

| Token | 數值 | 用途 |
| --- | --- | --- |
| `--color-brand` | `var(--color-indigo-50)` | 品牌表面的底色 |
| `--color-brand-ink` | 近白色 | 品牌表面上的文字 |
| `--color-brand-text` | Moonstone 用 indigo-60，Obsidian 用 indigo-30 | 頁面上的品牌色文字 |

品牌表面的邊緣、高光和光暈都以 `--color-brand` 調配，因此覆寫這個 token 就能一併調整。若品牌色偏淺，請將 `--color-brand-ink` 設為深墨色。

## 配色方案 \{#color-schemes\}

隨配色方案變化的色彩使用 `light-dark()`，部分高光與疊在圖片上的色彩則在兩種方案中共用。主題會依元素的 `color-scheme` 選用配色方案。Master CSS 預設組態會在根元素上設定 `color-scheme: light dark`，也能為整個頁面或單一子樹指定配色方案。

```html
<html data-theme="dark">
  …
  <aside data-theme="light">A moonstone panel on an obsidian page</aside>
</html>
```

深色模式共用同一份樣式表，元件也無須加上深色模式專用的類別。
