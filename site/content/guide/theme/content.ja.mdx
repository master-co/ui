Master UI の既定テーマは、ライトモードとダークモードで共通の質感表現を使います。ライトモードの **moonstone** は、すっきりとした亜鉛色の真珠のような質感です。ダークモードの **obsidian** は、亜鉛色のつや消しガラスを思わせる質感で、面の段差と輪郭がはっきり見えます。どちらも、やや左寄りの上方に光源が一つある想定です。浮き上がった面の上端には細い光が入り、下には短く、次第に薄くなる影が落ちます。

色彩を抑えたインク調の配色、半ピクセルの輪郭、入れ子でも揃う角の丸み、状態に応じて変わる奥行きが特徴です。細部は光で表現し、輪郭は見分けられる程度にやわらかく仕上げています。

以下の各節を参照して、インターフェースの面、線、テキスト、奥行きに合う役割を選んでください。掲載している値は、現行パッケージの既定テーマのものです。値の上書きや別の質感を作る方法は[テーマ設定](/guide/theming)を参照してください。

## 設計原則 \{#principles\}

[デザイン](/guide/design)では、既定の質感、視覚的な階層、形状、操作時の状態をどう設計したかを説明しています。設計を検討する際はそちらを参照してください。このページでは、`@master/ui` が実装するトークンとスタイルの組み合わせを説明します。

`packages/ui/theme.css` は、これらの値を実際に定義するソースです。コンポーネントのスタイルはそのトークンを参照するため、Paper などのテーマを使えば、コンポーネントを書き換えずに値を差し替えられます。

## 面 \{#surfaces\}

面は共通の階層を成します。各段階は色そのものではなく、面の役割を表します。用途に応じて段階を選ぶと、テーマがライトモードとダークモードそれぞれの値を適用します。

| トークン | 役割 | moonstone | obsidian |
| --- | --- | --- | --- |
| `--color-surface-base` | ページ全体の背景 | 98.6% | 19.4% |
| `--color-surface-tray` | シートを収めるくぼんだ面 | 96% | 17.4% |
| `--color-surface-raised` | カードやボタンの浮き上がった面 | 100% | 24.2% |
| `--color-surface-raised-low` | 浮き上がった面のグラデーションの下端 | 99.3% | 22.8% |
| `--color-surface-inset` | 入力欄やトラックのくぼんだ面 | 96.6% | 16.4% |
| `--color-surface-inset-hover` | 同じくぼみのホバー時の面 | 95.8% | 15.4% |
| `--color-surface-floating` | コンテンツの上に重なるポップオーバーやメニュー | 100% | 26.4% |
| `--color-surface-chip` | ニュートラルなチップやバッジ | 96.5% | 白（不透明度 7%） |
| `--color-surface-inverse` | インク色。プライマリボタンやチェック済みのコントロール | 22% | 95% |
| `--color-surface-scrim` | モーダル背面のバックドロップ | 明度 18%、不透明度 20% | 黒（不透明度 55%） |

不透明度として明記したものを除き、値は OKLCH の明度です。浮き上がった面には、上端の `raised` から下端の `raised-low` へのグラデーションを使います。このグラデーションは `@apply --surface-sheet` が生成します。用途に応じて役割を選んでください。たとえば、シートに重なるメニューを見分けやすくするには `floating` を、シート内の入力欄を示すには `inset` を使います。要素の配置やシャドウは、色のトークンとは別に指定します。

## 線 \{#lines\}

線には、Moonstone では無彩色のインクを、Obsidian では白を使い、それぞれ不透明度を調整します。2 種類は 1px の罫線です。残りの 3 種類は、ぼかしなしの `box-shadow` で描く 0.5px の輪郭で、レイアウト上の領域を取りません。線幅に合わせて不透明度を調整し、細くてもはっきり見えるようにしています。

| トークン | Moonstone | Obsidian | 線幅 | 用途 |
| --- | --- | --- | --- | --- |
| `--color-line-hair` | 6.5% | 7.5% | 1px | サーフェス内の控えめな区切り線 |
| `--color-line-divider` | 12% | 13% | 1px | セクション間やタブ列の罫線 |
| `--color-line-contour` | 12% | 14% | .5px | すべてのサーフェスの輪郭 |
| `--color-line-strong` | 20% | 23% | .5px | ホバー時の輪郭、スイッチのトラック、キートップ |
| `--color-line-mark` | 32% | 36% | .5px | チェックボックス、フォーカス時の入力欄の輪郭 |
| `--color-texture` | 20% | 23% | 点と .5px の極細線 | [テクスチャ](/components/texture)の模様。テーマで値を指定するまでは `--color-line-strong` に従います |

ひと目で見つける必要があるコントロールには、サーフェスよりもはっきりした輪郭を使います。入力欄は輪郭を 2 本重ね、チェックボックスにはマーク用の線を使います。

## テキスト \{#text\}

テキストには柔らかなインク色を使い、純黒や純白は使いません。

| トークン | 用途 |
| --- | --- |
| `--color-text-strong` | 見出し、ラベル、値 |
| `--color-text-body` | 本文 |
| `--color-text-muted` | ヒント、キャプション、非アクティブな選択肢 |
| `--color-text-disabled` | 無効なコントロール |
| `--color-text-inverse` | インク面上のテキスト |
| `--color-focus` | フォーカスリング |

## エレベーション \{#elevation\}

エレベーションは、押し込まれたくぼみからオーバーレイまでの奥行きの段階です。浮き上がった面は、上端の内側のハイライト、0.5px の輪郭 1 本、下方向に落ちる影 3〜6 層で表現します。

| トークン | 用途 |
| --- | --- |
| `--shadow-pressed` | くぼみ、押下中のコントロール |
| `--shadow-flat` | 輪郭が 1 本で、浮き上がりのないサーフェス |
| `--shadow-raised` | 通常時のボタン、チップ、小型カード |

たとえば `--shadow-raised` は、ハイライトと輪郭の下に `0 1px 2px -1px`、`0 2px 4px -2px`、`0 4px 8px -4px` を重ねます。エレベーションが高いほど、オフセットの範囲が広がります。負の拡張半径で影を要素の近くに収め、ぼかしで縁を柔らかくします。これらのトークンは見た目の奥行きを表現します。重なり順は、要素のレイアウトとプラットフォームのビヘイビアで決まります。

## インク \{#ink\}

インクは、反転色で塗りつぶした面です。プライマリボタン、チェック済みのチェックボックス、送信したメッセージ、ページに 1 枚だけ置く[反転シート](/components/surface)などに使います。どのインク面も上端に同じハイライトを入れ、周囲を同じ極細線で囲むため、大きさにかかわらず質感がそろいます。

| トークン | 役割 |
| --- | --- |
| `--color-surface-inverse-high`, `--color-surface-inverse-low` | インク色のシートに当たる光のグラデーション |
| `--color-ink-high`, `--color-ink-low` | 通常時のインク色のコントロールに、より丸みを感じさせる光のグラデーション |
| `--color-ink-high-hover`, `--color-ink-low-hover`, `--color-ink-pressed` | 同じコントロールのホバー時と押下時 |
| `--color-ink-highlight` | すべてのインク面の上端に入るハイライト |
| `--color-ink-edge` | インク面を囲む極細線 |
| `--color-surface-tip` | ツールチップの背景。Moonstone ではインク色、Obsidian では明るめの面 |
| `--shadow-ink`, `--shadow-ink-hover`, `--shadow-ink-pressed` | インク色のコントロールの状態ごとの奥行き |
| `--shadow-ink-mark` | 選択状態を示す小さな塗りつぶし。チェックボックス、ラジオボタン、選択した日付 |
| `--shadow-ink-well`, `--shadow-thumb-on-ink` | トラックの塗りつぶし部分と、その上を動くつまみ |
| `--shadow-tip` | ツールチップとグラフの値 |

ブランド色のコントロールや破壊的操作の確認ボタンなど、固有の色相を持つコントロールは、その色相から面、縁、光彩の色を合成します。`--color-tone-highlight` と `--color-tone-highlight-soft` はハイライトに使います。

## 形状 \{#shape\}

角丸半径は、サーフェスと同様に役割に応じて決まります。チップは小さな目印、コントロールは押下や入力に使う要素、サーフェスはシートとして扱います。トークンは `@theme` にあるため、ユーティリティとしても使えます。たとえば `r-control` は、コントロールの基準となる角丸半径を使います。コンポーネントには、後述する連続曲線の角と半径の倍率も適用されます。同じ仕上がりにするには、角丸ユーティリティに加えてこれらの指定が必要です。

| トークン | 値 | 適用先 |
| --- | --- | --- |
| `--radius-chip` | 6px | バッジ、キートップ、チェックボックス、スケルトン |
| `--radius-control-sm` | 8px | 小サイズのボタンと入力欄、メニュー項目、選択肢、セグメントコントロールのつまみ |
| `--radius-control` | 10px | ボタン、入力欄、くぼみ |
| `--radius-control-lg` | 12px | 大サイズのボタンと入力欄、アラート、選択項目、トースト |
| `--radius-surface` | 16px | シート、カード |

外枠には固有の角丸半径がありません。内側の要素の半径に、両者の間隔を足して求めます。トレイはシートの半径に 4px、メニューは項目の半径に 4px、セグメントコントロールのトラックはつまみの半径に内側の余白を足します。入力欄内のボタンは、入力欄の半径から 4px を引きます。こうすると、曲がり角でも間隔が一定になります。ピル、ドット、アバターだけは、さらに丸みを持たせます。

### 連続曲線の角 \{#continuous-corners\}

`border-radius` は円の 4 分の 1 の弧を描きます。この弧と直線の継ぎ目では、曲率がゼロから円弧の曲率へ急に変わり、曲がり始めが目立ちます。`corner-shape: squircle` で描くスクワークルは、より手前から曲がり始め、徐々に曲率が増すため、辺から角へ滑らかにつながります。

ブラウザーが `corner-shape` に対応していれば、コンポーネントはスクワークルを描きます。非対応の場合は 4 分の 1 円弧を使います。同じ半径ではスクワークルの曲線のほうが角に近いため、見た目の丸みをそろえるよう、半径に `--corner-scale` を掛けます。倍率はスクワークルで 1.6、円弧で 1 です。どちらの値もテーマで一度設定し、すべてのコンポーネントが参照します。

| プロパティ | `corner-shape` 対応時 | 非対応時 |
| --- | --- | --- |
| `--corner-shape` | `squircle` | `round` |
| `--corner-scale` | `1.6` | `1` |

ピル、ドット、アバター、つまみの丸みには引き続き真円の曲線を使います。すべての角に円弧を使う方法は、[テーマ設定](/guide/theming#retune-tokens)を参照してください。

## タイポグラフィ \{#type\}

テーマはフォントをダウンロードしません。ドキュメントでは Geist を使い、コントロールはプリセットのフォントファミリートークンを参照します。使うフォントは、指定する前にアプリで読み込んでください。このサイトのタイポグラフィ設定は次のとおりです。

```css name=app.css
@theme {
  --font-sans: 'Geist';
  --font-feature-sans: 'ss02', 'ss03', 'ss04', 'ss06', 'ss07', 'ss08';
}

body {
  font-weight: 350;
}
```

コントロールのラベルには、太く見えすぎず読みやすい、やや軽めのミディアムウェイト `--font-weight-control`（460）を使います。見出しは標準のウェイトにそろえ、文字サイズとインク色で階層を示します。

## モーション \{#motion\}

共通のイージングで操作には素早く反応し、内容を伝える動きは穏やかにします。コントロールの移動距離は 1 つの値で指定します。`--lift` は 0.5px で、浮き上がったコントロールはホバー時にその分だけ上がり、押下時にその分だけ沈みます。カードはその 2 倍の距離を上がります。テーマ全体で移動をなくすには `0px` に設定してください。モーションを減らす設定が有効な場合は、自動的にこの値が適用されます。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--easing-glide` | `cubic-bezier(.22, 1, .36, 1)` | すべての状態変化 |
| `--duration-press` | 60ms | コントロールの押下 |
| `--duration-quick` | 160ms | ホバーとフォーカス、ポップオーバー・メニュー・ツールチップの表示、すべての終了アニメーション |
| `--duration-base` | 280ms | つまみとパネルの移動、ダイアログの表示 |
| `--lift` | .5px | 浮き上がったコントロールが上下する距離 |

オーバーレイは、表示時と非表示時の両方の遷移を CSS で定義します。`@starting-style` は表示時の開始状態を定めます。`display` と `overlay` を `allow-discrete` で遷移させることで、要素がトップレイヤーを離れる前に終了アニメーションを再生できます。非表示時の遷移は表示時より短くなります。モーションを減らす設定では、移動と拡大・縮小を省き、フェードだけを残します。

## ステータスとブランド \{#status-and-brand\}

インターフェースがステータスを伝えるために使う色相は、`--color-info`、`--color-success`、`--color-warning`、`--color-danger` の 4 つだけです。それぞれのテーマで、テキスト色としても読みやすいように調整しています。

ブランド色は、ステータスを表さない唯一の色相です。各ビューで一度だけ、[`btn-brand`](/components/button#variants)に使います。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--color-brand` | `var(--color-indigo-50)` | ブランド色のサーフェスの塗り |
| `--color-brand-ink` | 白に近い色 | ブランド色のサーフェス上のテキスト |
| `--color-brand-text` | Moonstone では indigo-60、Obsidian では indigo-30 | ページ上のブランド色のテキスト |

ブランド色のサーフェスは、縁、ハイライト、光彩の色を `--color-brand` から合成します。このトークンを上書きすれば、3 つの色がまとめて変わります。ブランド色が明るい場合は、`--color-brand-ink` に暗いインク色を指定してください。

## カラースキーム \{#color-schemes\}

スキームによって変わる色には `light-dark()` を使います。一部のハイライトや画像に重ねる色は、両方のスキームで共通です。テーマは要素の `color-scheme` に従います。Master CSS プリセットはルートに `color-scheme: light dark` を設定します。ページ全体や特定のサブツリーにスキームを固定するには、次のように指定します。

```html
<html data-theme="dark">
  …
  <aside data-theme="light">A moonstone panel on an obsidian page</aside>
</html>
```

ダークモード用の別スタイルシートはなく、コンポーネントにもダークモード専用のクラスはありません。
