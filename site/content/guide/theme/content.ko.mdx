Master UI의 기본 테마는 일관된 재질 표현을 사용합니다. 라이트 모드의 **moonstone**은 깔끔한 아연색 진주 질감이고, 다크 모드의 **obsidian**은 높이가 다른 표면과 경계가 또렷하게 구분되는 무광 아연색 유리 질감입니다. 두 모드 모두 위쪽에서 약간 왼쪽으로 치우친 한 광원의 빛을 받습니다. 높인 표면마다 위쪽 가장자리에 가느다란 빛이 맺히고, 아래에는 짧은 그림자가 드리워져 서서히 사라집니다.

절제된 느낌을 위해 색채 대신 잉크색을 쓰고 윤곽선은 0.5px로 그립니다. 모서리는 겹쳐도 자연스럽게 맞물리며, 깊이는 상태에 따라 달라집니다. 세부 표현은 장식 대신 빛으로 살리고, 가장자리는 알아볼 수 있을 정도로만 선명하게 표시합니다.

아래에서 인터페이스에 필요한 표면, 선, 텍스트, 깊이의 역할을 고르세요. 여기에 나오는 값은 현재 패키지의 기본 테마에 적용됩니다. 값을 재정의하거나 다른 재질을 만드는 방법은 [테마 설정](/guide/theming)에서 확인할 수 있습니다.

## 설계 원칙 \{#principles\}

[디자인](/guide/design)에서는 기본 재질, 시각적 위계, 형태, 상호작용 상태를 정한 근거를 설명합니다. 디자인 결정을 내릴 때는 해당 지침을 참고하세요. 이 페이지에서는 `@master/ui`에서 구현한 토큰과 스타일 조합을 설명합니다.

`packages/ui/theme.css`에서 이 값들을 실제 코드로 정의합니다. 컴포넌트 스타일은 해당 토큰을 참조하며, Paper 같은 테마는 컴포넌트를 다시 작성할 필요 없이 토큰 값을 바꿀 수 있습니다.

## 표면 \{#surfaces\}

표면은 하나의 위계를 이룹니다. 각 단계는 색상이 아닌 역할을 나타냅니다. 표면의 용도에 맞는 단계를 고르면 테마가 라이트 모드와 다크 모드에 적용할 값을 각각 결정합니다.

불투명도를 따로 명시한 경우를 제외하면 값은 OKLCH 명도입니다. 높인 표면에는 위쪽의 `raised`에서 아래쪽의 `raised-low`로 이어지는 그라데이션을 사용하며, `@apply --surface-sheet`가 이 그라데이션을 설정합니다. 용도에 맞게 역할을 고르세요. `floating`은 시트 위에 뜬 메뉴를 구분하고, `inset`은 그 시트 안의 필드를 구분합니다. 색상 토큰은 요소의 위치나 그림자를 설정하지 않습니다.

## 선 \{#lines\}

moonstone의 선에는 중립적인 잉크색에 알파값을 적용하고, obsidian의 선에는 흰색에 알파값을 적용합니다. 두 토큰은 1px 구분선을 그립니다. 나머지 세 토큰은 흐림이 없는 `box-shadow`로 0.5px 두께의 윤곽선을 그리므로 레이아웃 공간을 차지하지 않습니다. 이 두께에 맞게 알파값을 조정해 윤곽선이 가늘면서도 선명하게 보이도록 합니다.

| 토큰 | moonstone | obsidian | 표시 형태와 두께 | 용도 |
| --- | --- | --- | --- | --- |
| `--color-line-hair` | 6.5% | 7.5% | 1px | 표면 내부의 은은한 구분선 |
| `--color-line-divider` | 12% | 13% | 1px | 섹션이나 탭 행 사이의 구분선 |
| `--color-line-contour` | 12% | 14% | .5px | 모든 표면의 윤곽선 |
| `--color-line-strong` | 20% | 23% | .5px | 호버 상태의 윤곽선, 스위치 트랙, 키캡 |
| `--color-line-mark` | 32% | 36% | .5px | 체크박스와 포커스를 받은 필드의 윤곽선 |
| `--color-texture` | 20% | 23% | 점과 .5px 두께의 가는 선 | [텍스처](/components/texture)를 이루는 무늬에 사용하며, 테마에서 값을 지정하기 전까지는 `--color-line-strong`의 값을 따릅니다 |

한눈에 찾아야 하는 컨트롤에는 일반 표면보다 뚜렷한 윤곽선을 적용합니다. 필드에는 윤곽선 두 겹을 쌓고, 체크박스에는 표의 마크 윤곽선 토큰을 적용합니다.

## 텍스트 \{#text\}

텍스트에는 순수한 검은색이나 흰색을 피하고 부드러운 잉크색을 사용합니다.

| 토큰 | 용도 |
| --- | --- |
| `--color-text-strong` | 제목, 레이블, 값 |
| `--color-text-body` | 본문 |
| `--color-text-muted` | 힌트, 캡션, 비활성 상태의 옵션 |
| `--color-text-disabled` | 비활성화된 컨트롤 |
| `--color-text-inverse` | 잉크색 배경 위의 텍스트 |
| `--color-focus` | 포커스 윤곽선 |

## 높이 \{#elevation\}

높이는 눌려 들어간 오목한 영역부터 오버레이까지 표면의 깊이 단계를 나타냅니다. 높인 표면은 위쪽 가장자리 안쪽의 하이라이트, 0.5px 윤곽선 하나, 아래로 드리우는 그림자 3~6개로 이루어집니다.

<div class="p-lg r-lg bg-surface-raised shadow-flat text-xs fg-text-muted">flat</div>

| 토큰 | 용도 |
| --- | --- |
| `--shadow-pressed` | 오목한 영역과 눌린 컨트롤 |
| `--shadow-flat` | 윤곽선 하나만 있는 평평한 표면 |
| `--shadow-raised` | 기본 상태의 버튼, 칩, 작은 카드 |
| `--shadow-raised-hover` | 같은 요소의 호버 상태, 더 뚜렷한 윤곽선 |
| `--shadow-lifted` | 카드와 패널 |
| `--shadow-floating` | 메뉴와 팝오버 |
| `--shadow-overlay` | 대화 상자 |

예를 들어 `--shadow-raised`는 하이라이트와 윤곽선 아래에 `0 1px 2px -1px`, `0 2px 4px -2px`, `0 4px 8px -4px`의 그림자를 겹쳐 놓습니다. 높이가 높을수록 그림자 오프셋의 범위가 넓어집니다. 음수 확산 값은 그림자가 요소 가까이에 머물게 하고, 흐림 효과는 그림자 가장자리를 부드럽게 만듭니다. 이 토큰은 깊이감을 표현하며, 실제 쌓임 순서는 요소의 레이아웃과 플랫폼 동작에 따라 결정됩니다.

## 잉크 \{#ink\}

잉크는 반전 색상으로 채운 표면입니다. 주요 버튼, 체크된 체크박스, 보낸 메시지, 페이지에 하나 있는 [반전 표면](/components/surface)이 여기에 해당합니다. 모든 잉크 표면은 위쪽 가장자리에 같은 빛을 받고 둘레에 같은 가는 윤곽선을 두르므로, 크기에 관계없이 같은 재질로 보입니다.

| 토큰 | 역할 |
| --- | --- |
| `--color-surface-inverse-high`, `--color-surface-inverse-low` | 잉크 표면에 드리우는 빛 |
| `--color-ink-high`, `--color-ink-low` | 기본 상태의 잉크 컨트롤에 더 둥글게 드리우는 빛 |
| `--color-ink-high-hover`, `--color-ink-low-hover`, `--color-ink-pressed` | 같은 컨트롤의 호버 상태와 눌린 상태 |
| `--color-ink-highlight` | 모든 잉크 표면의 위쪽 가장자리에 맺히는 빛의 선 |
| `--color-ink-edge` | 잉크 표면 둘레의 가는 윤곽선 |
| `--color-surface-tip` | 툴팁 표면. moonstone에서는 잉크, obsidian에서는 더 밝은 표면 |
| `--shadow-ink`, `--shadow-ink-hover`, `--shadow-ink-pressed` | 상태별 잉크 컨트롤의 깊이 |
| `--shadow-ink-mark` | 선택된 체크박스, 라디오 버튼, 날짜의 작은 채움 영역 |
| `--shadow-ink-well`, `--shadow-thumb-on-ink` | 채워진 트랙과 그 위를 움직이는 손잡이 |
| `--shadow-tip` | 툴팁과 차트의 값 |

브랜드 컨트롤이나 삭제처럼 되돌리기 어려운 작업을 확인하는 컨트롤은 각각의 색조를 바탕으로 표면색, 가장자리 색, 빛 번짐을 표현합니다. 두 토큰 `--color-tone-highlight` 및 `--color-tone-highlight-soft`는 컨트롤에 닿는 빛을 표현합니다.

## 형태 \{#shape\}

표면과 마찬가지로 모서리 반경도 요소의 역할에 따라 정해집니다. 칩은 작은 표시이고, 컨트롤은 누르거나 입력하는 요소이며, 표면은 시트입니다. 토큰이 `@theme`에 정의되어 있어 유틸리티로도 사용할 수 있습니다. `r-control`은 컨트롤의 기본 반경을 사용합니다. 컴포넌트는 아래에서 설명하는 연속 곡선 모서리 형태와 배율도 적용합니다. 반경 유틸리티만으로는 같은 모서리 형태를 구현할 수 없습니다.

| 토큰 | 값 | 적용 대상 |
| --- | --- | --- |
| `--radius-chip` | 6px | 배지, 키캡, 체크박스, 스켈레톤 |
| `--radius-control-sm` | 8px | 작은 버튼과 필드, 메뉴 행, 옵션, 세그먼트 컨트롤의 손잡이 |
| `--radius-control` | 10px | 버튼, 필드, 오목한 영역 |
| `--radius-control-lg` | 12px | 큰 버튼과 필드, 알림, 선택 항목, 토스트 |
| `--radius-surface` | 16px | 시트, 카드 |

요소를 담는 컨테이너에는 고정된 모서리 반경이 없습니다. 안쪽 요소의 반경에 두 요소 사이의 여백을 더해 바깥쪽 반경을 구합니다. 트레이는 시트의 반경에 4px을 더한 값을, 메뉴는 행의 반경에 4px을 더한 값을 사용합니다. 세그먼트 컨트롤의 트랙은 손잡이의 반경에 안쪽 여백을 더한 값을 사용하고, 필드 안의 버튼은 필드의 반경보다 4px 작은 값을 사용합니다. 이렇게 하면 모서리를 따라 여백의 폭이 일정하게 유지됩니다. 알약형 요소, 점, 아바타만 더 둥글게 처리합니다.

### 연속 곡선 모서리 \{#continuous-corners\}

`border-radius`는 4분원 호를 그립니다. 4분원 호와 직선 가장자리가 만나는 지점에서는 곡률이 0에서 호의 곡률로 단번에 바뀌어 이음새가 도드라져 보입니다. `corner-shape: squircle`로 그리는 스쿼클은 더 일찍 휘기 시작해 곡률이 서서히 커지므로 가장자리가 모서리로 매끄럽게 이어집니다.

브라우저가 `corner-shape`을 지원하면 컴포넌트는 스쿼클로 모서리를 그리고, 그 외에는 4분원 호로 그립니다. 같은 반경에서 스쿼클은 원보다 모서리 꼭짓점에 더 가깝게 지나갑니다. 따라서 둥글기가 같아 보이도록 컴포넌트는 반경에 `--corner-scale`을 곱합니다. 스쿼클을 사용할 때는 1.6, 그 외에는 1을 적용합니다. 두 값은 테마에서 한 번 정의하며 모든 컴포넌트가 이 값을 읽습니다.

| 속성 | `corner-shape` 지원 시 | 미지원 시 |
| --- | --- | --- |
| `--corner-shape` | `squircle` | `round` |
| `--corner-scale` | `1.6` | `1` |

알약 모양 요소의 끝부분과 점, 아바타, 손잡이는 원형을 유지합니다. 모든 곳에서 모서리를 원형으로 유지하는 방법은 [테마 설정](/guide/theming#retune-tokens)을 참고하세요.

## 타이포그래피 \{#type\}

테마는 글꼴을 다운로드하지 않습니다. 문서에서는 Geist를 사용하고, 컨트롤은 프리셋의 font-family 토큰을 참조합니다. 글꼴을 지정하기 전에 앱에서 먼저 불러오세요. 사이트의 타이포그래피 설정은 다음과 같습니다.

```css name=app.css
@theme {
  --font-sans: 'Geist';
  --font-feature-sans: 'ss02', 'ss03', 'ss04', 'ss06', 'ss07', 'ss08';
}

body {
  font-weight: 350;
}
```

컨트롤 레이블의 글자 굵기는 `--font-weight-control`(460)로 지정합니다. 중간 굵기 중에서도 가벼운 편이라 묵직해 보이지 않으면서도 또렷하게 읽힙니다. 제목은 보통 굵기를 유지하고, 크기와 글자색으로 계층을 구분합니다.

## 모션 \{#motion\}

한 계열의 이징으로 상호작용에는 빠르게 반응하고 설명을 보여 주는 전환은 부드럽게 진행합니다. 컨트롤의 이동 거리는 하나의 값으로 정합니다. `--lift`의 기본값은 0.5px입니다. 높인 컨트롤에 포인터를 올리면 그만큼 올라가고 누르면 그만큼 내려갑니다. 카드는 두 배만큼 올라갑니다. 이동 없는 테마를 만들려면 이 값을 `0px`로 설정하세요. 동작 줄이기 설정이 켜져 있으면 이미 이동이 비활성화됩니다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--easing-glide` | `cubic-bezier(.22, 1, .36, 1)` | 모든 상태 변경 |
| `--duration-press` | 60ms | 컨트롤 누르기 |
| `--duration-quick` | 160ms | 호버와 포커스, 팝오버·메뉴·툴팁, 모든 퇴장 전환 |
| `--duration-base` | 280ms | 손잡이와 패널의 이동, 대화 상자의 등장 |
| `--lift` | .5px | 높인 컨트롤이 올라가고 내려가는 거리 |

오버레이의 등장과 퇴장 전환은 모두 CSS로 정의합니다. `@starting-style`은 요소가 등장할 때의 시작 프레임을 지정합니다. `display`와 `overlay`는 `allow-discrete`를 사용해 전환되므로 요소가 최상위 레이어를 벗어나기 전에 퇴장 전환이 재생됩니다. 퇴장 전환은 등장 전환보다 짧습니다. 동작 줄이기 설정이 켜져 있으면 위치 이동과 크기 변화는 사라지고 페이드 효과는 유지됩니다.

## 상태 및 브랜드 색상 \{#status-and-brand\}

인터페이스에서 상태를 전달하는 데 쓰는 색상은 `--color-info`, `--color-success`, `--color-warning`, `--color-danger`뿐입니다. 각 색상은 해당 테마에서 글자색으로 사용해도 또렷하게 읽히도록 조정되어 있습니다.

브랜드 색상은 상태를 나타내지 않는 유일한 색상입니다. 화면마다 [`btn-brand`](/components/button#variants)에 한 번만 사용합니다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--color-brand` | `var(--color-indigo-50)` | 브랜드 표면의 바탕색 |
| `--color-brand-ink` | 흰색에 가까운 색 | 브랜드 표면 위의 텍스트 |
| `--color-brand-text` | moonstone에서는 indigo-60, obsidian에서는 indigo-30 | 페이지에서 브랜드 색상을 적용한 텍스트 |

브랜드 표면의 가장자리, 하이라이트, 빛 번짐에 쓰이는 색은 모두 `--color-brand`의 값을 바탕으로 혼합합니다. 따라서 이 토큰 하나를 재정의하면 표면 전체의 색이 함께 조정됩니다. 브랜드 색상이 밝다면 `--color-brand-ink`에 어두운 글자색을 지정하세요.

## 색 구성표 \{#color-schemes\}

색 구성표에 따라 달라지는 색은 `light-dark()` 함수로 지정합니다. 일부 하이라이트와 이미지 위에 표시되는 색은 두 구성표에서 동일합니다. 테마는 요소의 `color-scheme`을 따릅니다. Master CSS 프리셋은 루트에 `color-scheme: light dark`를 설정하며, 페이지 전체나 특정 하위 트리에 색 구성표를 고정할 수 있습니다.

```html
<html data-theme="dark">
  …
  <aside data-theme="light">A moonstone panel on an obsidian page</aside>
</html>
```

다크 모드 전용 스타일시트나 컴포넌트 클래스는 없습니다.
