Master UI의 기본 테마는 하나의 재질 언어를 가집니다. 라이트 모드는 깔끔한 아연빛 진주인 **moonstone**입니다. 다크 모드는 무광 아연빛 유리인 **obsidian**으로, 표면들이 단계적으로 구분되고 알아볼 수 있는 가장자리를 유지합니다. 두 모드 모두 위쪽에서 약간 왼쪽에 있는 하나의 광원으로 비추므로, 모든 솟은 면은 위쪽 가장자리에 한 줄기 빛을 받고 옅어지는 짧은 그림자 위에 놓입니다.

성격은 절제되어 있습니다. 색보다 잉크, 반 픽셀 윤곽, 중첩되는 모서리, 그리고 상태에 따라 바뀌는 깊이입니다. 디테일은 장식이 아니라 빛에서 나오며, 어떤 가장자리도 알아보는 데 필요한 정도보다 더 강하지 않습니다.

아래 섹션을 참고해 인터페이스에 맞는 표면, 선, 텍스트, 깊이의 역할을 선택하세요. 값은 현재 패키지의 기본 테마를 설명합니다. 값을 재정의하거나 다른 재질을 만드는 방법은 [테마 설정](/guide/theming)에서 보여 줍니다.

**상태는 같은 컨트롤의 깊이를 바꿉니다.** 기본, 호버, 활성 상태는 각각 raised, raised-hover, pressed 그림자 토큰을 사용하며, 활성 상태에서는 안쪽으로 들어간 면도 적용됩니다. 기본 `--lift`는 호버를 지원하는 포인터에서 호버 시 버튼을 0.5px 올리고, 활성 상태에서는 0.5px 내립니다. 단면도는 깊이를 과장해서 보여 줍니다. 실제 상호작용은 라이브 미리 보기에서 두 색 구성표로 직접 시험해 보세요.

## 원칙 \{#principles\}

기본 재질, 위계, 기하 구조, 상호작용 상태에 대한 결정은 [디자인](/guide/design)에서 설명합니다. 디자인 결정에는 그 지침을 활용하세요. 이 페이지는 `@master/ui`가 구현한 토큰과 레시피를 문서화합니다.

`packages/ui/theme.css`가 이 값들의 실행 가능한 소스입니다. 컴포넌트 스타일은 이 토큰을 읽으며, Paper 같은 테마는 컴포넌트를 다시 작성하지 않고도 토큰을 대체할 수 있습니다.

## 표면 \{#surfaces\}

표면은 하나의 사다리를 이룹니다. 각 단계는 색이 아니라 역할입니다. 표면이 하는 일에 따라 단계를 고르면, 테마가 라이트와 다크에서 그 값을 결정합니다.

| `--color-surface-inset` | 웰: 필드, 트랙 | 96.6% | 16.4% |
| `--color-surface-inset-hover` | 포인터가 올라간 같은 웰 | 95.8% | 15.4% |

불투명도가 명시되지 않은 값은 OKLCH 명도입니다. 솟은 면은 `raised`에서 `raised-low`로 이어지는 위에서 아래로의 그라데이션이며, `@apply --surface-sheet`가 이를 작성해 줍니다. 역할은 목적에 따라 선택하세요. `floating`은 시트 위의 메뉴를 구분하고, `inset`은 시트 안의 필드를 나타냅니다. 색상 토큰은 요소를 배치하거나 그림자를 주지 않습니다.

## 선 \{#lines\}

선은 moonstone에서는 중립적인 잉크의 알파 값, obsidian에서는 흰색의 알파 값입니다. 그중 두 개는 1px 구분선입니다. 나머지 세 개는 윤곽으로, 레이아웃 공간을 차지하지 않는 블러 0의 `box-shadow`로 반 픽셀 고리를 그립니다. 알파 값은 그 너비에 맞게 조정되어 있어 윤곽이 흐릿하지 않고 섬세하게 읽힙니다.

| 토큰 | Moonstone | Obsidian | 그리는 두께 | 용도 |
| --- | --- | --- | --- | --- |
| `--color-line-hair` | 6.5% | 7.5% | 1px | 표면 안의 조용한 구분선 |
| `--color-line-divider` | 12% | 13% | 1px | 섹션 사이의 구분선, 탭 행 |
| `--color-line-contour` | 12% | 14% | .5px | 모든 표면의 윤곽 |
| `--color-line-strong` | 20% | 23% | .5px | 호버된 윤곽, 스위치 트랙, 키캡 |
| `--color-line-mark` | 32% | 36% | .5px | 체크박스, 포커스된 필드의 윤곽 |
| `--color-texture` | 20% | 23% | 점과 .5px 가는 선 | [텍스처](/components/texture)의 표시. 테마가 설정하기 전까지는 `--color-line-strong`을 따릅니다 |

한눈에 찾을 수 있어야 하는 컨트롤은 표면보다 더 뚜렷한 윤곽을 가집니다. 필드는 윤곽 고리 두 개를 겹치고, 체크박스는 mark를 사용합니다.

## 텍스트 \{#text\}

텍스트는 부드러운 잉크이며, 순수한 검정이나 흰색이 아닙니다.

| 토큰 | 용도 |
| --- | --- |
| `--color-text-strong` | 제목, 레이블, 값 |
| `--color-text-body` | 본문 |
| `--color-text-muted` | 힌트, 캡션, 비활성 옵션 |
| `--color-text-disabled` | 비활성화된 컨트롤 |
| `--color-text-inverse` | 잉크 위의 텍스트 |
| `--color-focus` | 포커스 윤곽선 |

## 고도 \{#elevation\}

고도는 눌린 웰에서 오버레이에 이르는 깊이의 순서입니다. 솟은 면은 위쪽 가장자리의 안쪽 하이라이트, 반 픽셀 윤곽 하나, 그리고 아래로 떨어지는 셰이드 3~6개를 결합합니다.

| 토큰 | 용도 |
| --- | --- |
| `--shadow-pressed` | 웰과 눌린 컨트롤 |
| `--shadow-flat` | 윤곽 하나만 있고 떠오르지 않는 표면 |
| `--shadow-raised` | 기본 상태의 버튼, 칩, 작은 카드 |
| `--shadow-raised-hover` | 포인터가 올라간 같은 요소로, 윤곽이 더 뚜렷함 |
| `--shadow-lifted` | 카드와 패널 |
| `--shadow-floating` | 메뉴와 팝오버 |
| `--shadow-overlay` | 대화 상자 |

예를 들어 `--shadow-raised`는 하이라이트와 윤곽 아래에 `0 1px 2px -1px`, `0 2px 4px -2px`, `0 4px 8px -4px`를 겹칩니다. 더 높은 고도는 더 넓은 범위의 오프셋을 사용합니다. 음수 확산은 그림자를 물체 가까이에 유지하고, 블러는 그 가장자리를 부드럽게 합니다. 이 토큰들은 깊이를 그릴 뿐이며, 쌓임 순서는 여전히 요소의 레이아웃과 플랫폼 동작에서 결정됩니다.

## 잉크 \{#ink\}

잉크는 반전 색으로 채운 면입니다. 기본 버튼, 선택된 체크박스, 보낸 메시지, 페이지에 하나뿐인 [반전 시트](/components/surface)가 여기에 해당합니다. 모든 잉크 면은 위쪽 가장자리에 같은 빛줄기를 받고 주위에 같은 가는 선을 가지므로, 어떤 크기에서도 하나의 재질로 읽힙니다.

| 토큰 | 역할 |
| --- | --- |
| `--color-surface-inverse-high`, `--color-surface-inverse-low` | 잉크 시트 위에 떨어지는 빛 |
| `--color-ink-high`, `--color-ink-low` | 기본 상태의 잉크 컨트롤에 떨어지는 더 둥근 빛 |
| `--color-ink-high-hover`, `--color-ink-low-hover`, `--color-ink-pressed` | 포인터가 올라가거나 눌린 같은 컨트롤 |
| `--color-ink-highlight` | 모든 잉크 면의 위쪽 가장자리에 있는 빛줄기 |
| `--color-ink-edge` | 그 주위의 가는 선 |
| `--color-surface-tip` | 툴팁: moonstone에서는 잉크, obsidian에서는 더 밝은 판 |
| `--shadow-ink`, `--shadow-ink-hover`, `--shadow-ink-pressed` | 각 상태에서 잉크 컨트롤의 깊이 |
| `--shadow-ink-mark` | 작은 선택 채움: 체크박스, 라디오, 선택된 날짜 |
| `--shadow-ink-well`, `--shadow-thumb-on-ink` | 채워진 트랙과 그 위를 움직이는 썸 |
| `--shadow-tip` | 툴팁과 차트의 값 |

색조가 있는 컨트롤(브랜드, 파괴적 동작의 확인)은 자신의 색조로부터 면, 가장자리, 광채를 혼합합니다. `--color-tone-highlight`와 `--color-tone-highlight-soft`는 그 컨트롤이 받는 빛입니다.

## 모양 \{#shape\}

모서리 반경은 표면처럼 역할입니다. 칩은 작은 표시이고, 컨트롤은 누르거나 입력하는 대상이며, 표면은 시트입니다. 토큰이 `@theme`에 있으므로 유틸리티로도 사용할 수 있습니다. `r-control`은 컨트롤의 기본 반경을 사용합니다. 컴포넌트는 여기에 아래에서 설명하는 연속 곡률 모서리 모양과 배율을 추가로 적용합니다. 반경 유틸리티만으로는 이 처리를 재현할 수 없습니다.

| 토큰 | 값 | 사용처 |
| --- | --- | --- |
| `--radius-chip` | 6px | 배지, 키캡, 체크박스, 스켈레톤 |
| `--radius-control-sm` | 8px | 작은 버튼과 필드, 메뉴 행, 옵션, 세그먼트 썸 |
| `--radius-control` | 10px | 버튼, 필드, 웰 |
| `--radius-control-lg` | 12px | 큰 버튼과 필드, 알림, 선택지, 토스트 |
| `--radius-surface` | 16px | 시트, 카드 |

홀더는 자체 반경을 갖지 않습니다. 담고 있는 것에서 모서리를 도출합니다. 즉 안쪽 반경에 그 사이의 인셋을 더한 값입니다. 트레이는 시트의 모서리에 4px을 더한 값, 메뉴는 행의 모서리에 4px을 더한 값, 세그먼트 트랙은 썸의 모서리에 인셋을 더한 값, 필드 안의 버튼은 필드의 모서리에서 4px을 뺀 값입니다. 따라서 간격은 굽은 부분 전체에서 하나의 너비를 유지합니다. 알약 모양, 점, 아바타만 더 둥급니다.

### 연속 곡률 모서리 \{#continuous-corners\}

`border-radius`는 4분의 1 원을 그립니다. 4분의 1 원이 직선 가장자리와 만나는 곳에서 곡률이 0에서 최대값으로 한 번에 뛰어오르며, 눈은 그 이음매를 어깨처럼 인식합니다. `corner-shape: squircle`로 그리는 스쿼클은 더 일찍 휘기 시작해 점차 조여들므로, 가장자리가 모서리로 자연스럽게 이어집니다.

컴포넌트는 브라우저가 `corner-shape`를 지원하는 곳에서는 스쿼클을, 그 밖에서는 4분의 1 원을 그립니다. 스쿼클은 같은 반경의 원보다 모서리에 더 바짝 붙으므로, 컴포넌트는 같은 겉보기 둥글기를 유지하기 위해 반경에 `--corner-scale`을 곱합니다. 스쿼클에서는 1.6, 그렇지 않으면 1입니다. 두 값은 테마에서 한 번 설정되며, 모든 컴포넌트가 이를 읽습니다.

| 속성 | `corner-shape` 지원 시 | 미지원 시 |
| --- | --- | --- |
| `--corner-shape` | `squircle` | `round` |
| `--corner-scale` | `1.6` | `1` |

알약 모양, 점, 아바타, 썸은 진짜 원으로 유지됩니다. 모든 곳에서 원형 모서리를 유지하는 방법은 [테마 설정](/guide/theming#retune-tokens)에서 보여 줍니다.

## 글꼴 \{#type\}

테마는 글꼴을 다운로드하지 않습니다. 문서는 Geist를 사용하며, 컨트롤은 프리셋의 font-family 토큰을 읽습니다. 글꼴을 지정하기 전에 앱에서 글꼴을 불러오세요. 이 사이트의 타이포그래피 설정은 다음과 같습니다.

```css name=app.css
@theme {
  --font-sans: 'Geist';
  --font-feature-sans: 'ss02', 'ss03', 'ss04', 'ss06', 'ss07', 'ss08';
}

body {
  font-weight: 350;
}
```

컨트롤 레이블은 `--font-weight-control`(460)을 사용합니다. 이는 무거워 보이지 않으면서 또렷하게 읽히는 가벼운 미디엄입니다. 제목은 regular를 유지하며, 크기와 잉크가 단계를 표현합니다.

## 모션 \{#motion\}

하나의 이징 계열이 상호작용은 빠르게, 설명은 차분하게 유지하고, 하나의 길이가 컨트롤의 이동 거리를 정합니다. `--lift`는 솟은 컨트롤이 포인터 아래에서 올라가고 누를 때 가라앉는 반 픽셀입니다. 카드는 두 배만큼 올라갑니다. 이동이 없는 테마를 원한다면 `0px`로 설정하세요. 동작 줄이기 설정에서는 이미 그렇게 됩니다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--easing-glide` | `cubic-bezier(.22, 1, .36, 1)` | 모든 상태 변화 |
| `--duration-press` | 60ms | 컨트롤 누르기 |
| `--duration-quick` | 160ms | 호버와 포커스, 팝오버, 메뉴, 툴팁, 모든 퇴장 |
| `--duration-base` | 280ms | 움직이는 썸과 패널, 대화 상자의 등장 |
| `--lift` | .5px | 솟은 컨트롤이 올라가고 가라앉는 거리 |

오버레이는 두 방향 모두를 CSS로 작성합니다. `@starting-style`은 요소가 등장할 때의 시작 프레임을 제공하고, `display`와 `overlay`는 `allow-discrete`로 전환되므로 요소가 최상위 레이어를 떠나기 전에 퇴장 애니메이션이 재생됩니다. 퇴장은 등장보다 짧습니다. 동작 줄이기 설정에서는 이동과 크기 변화가 제거되고 페이드만 남습니다.

## 상태 색상과 브랜드 \{#status-and-brand\}

`--color-info`, `--color-success`, `--color-warning`, `--color-danger`는 인터페이스가 무언가를 알리는 데 사용하는 유일한 색조입니다. 각각은 해당 테마에서 텍스트로 읽히도록 조정되어 있습니다.

브랜드 색상은 상태를 나타내지 않는 유일한 색조입니다. [`btn-brand`](/components/button#variants)에 뷰마다 한 번 나타납니다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--color-brand` | `var(--color-indigo-50)` | 브랜드 표면의 면 |
| `--color-brand-ink` | 흰색에 가까움 | 브랜드 표면 위의 텍스트 |
| `--color-brand-text` | moonstone에서는 indigo-60, obsidian에서는 indigo-30 | 페이지 위의 브랜드 색 텍스트 |

브랜드 표면은 `--color-brand`로부터 가장자리, 빛, 광채를 혼합하므로, 이 토큰 하나만 재정의하면 브랜드 표면이 조정됩니다. 브랜드 색상이 밝다면 `--color-brand-ink`를 어두운 잉크로 설정하세요.

## 색 구성표 \{#color-schemes\}

구성표마다 다른 색상은 `light-dark()`를 사용합니다. 일부 하이라이트와 이미지 위에 그리는 색상은 두 구성표에서 같습니다. 테마는 요소의 `color-scheme`을 따릅니다. Master CSS 프리셋은 루트에 `color-scheme: light dark`를 설정하며, 페이지 전체나 하나의 하위 트리에 대해 구성표를 고정할 수 있게 합니다.

```html
<html data-theme="dark">
  …
  <aside data-theme="light">A moonstone panel on an obsidian page</aside>
</html>
```

다크 모드를 위한 두 번째 스타일시트도, 컴포넌트에 붙이는 다크 전용 클래스도 없습니다.
