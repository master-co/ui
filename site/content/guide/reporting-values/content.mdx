## A change rounded to zero \{#rounding-zero\}

If rounding produces negative zero, normalize it to zero before choosing the sign or direction. Preserve the original reading for subsequent calculations.

```js
const observed = -0.032
const rounded = Number(observed.toFixed(1)) || 0
const direction = rounded < 0 ? 'Down' : rounded > 0 ? 'Up' : 'No change at this precision'
const label = [rounded.toFixed(1), direction].join(' · ')
```

## Sort mixed units \{#sort-units\}

Store durations in one base unit. Sort on that number before formatting the row, so 900 µs precedes 2 ms.

```js
const measurements = [{ name: 'Decode', us: 2000 }, { name: 'Read', us: 900 }]
const rows = measurements.toSorted((a, b) => a.us - b.us).map(sample => ({
  name: sample.name,
  duration: sample.us < 1000 ? sample.us + ' µs' : sample.us / 1000 + ' ms'
}))
```

## Align versions by identifier \{#align-versions\}

Take the union of the identifiers and look up both values for each row. A missing entry has its own text, and a measured zero retains its value.

```js
const previous = new Map([['Upload', 14], ['Queue', 0]])
const current = new Map([['Queue', 2], ['Export', 5]])
const ids = new Set([...previous.keys(), ...current.keys()])
const rows = Array.from(ids, id => [
  id, previous.get(id) ?? 'Unavailable in this version',
  current.get(id) ?? 'Unavailable in this version'
])
```
