## 舍入为零的变化量 \{#rounding-zero\}

若舍入后得到负零，先转为零，再决定正负号和方向。后续计算仍使用原始读数。

```js
const observed = -0.032
const rounded = Number(observed.toFixed(1)) || 0
const direction = rounded < 0 ? 'Down' : rounded > 0 ? 'Up' : 'No change at this precision'
const label = [rounded.toFixed(1), direction].join(' · ')
```

## 下降表示改善 \{#falling-error-rate\}

同时写出变化方向和影响。即使黑白打印，中性的变化标记仍然可读。

```html
<div class="stat">
  <p class="stat-label">Failed uploads</p>
  <p class="stat-value">1.2%</p>
  <p class="stat-delta">Improved, down from 1.8%</p>
</div>
```

## 估算值与实测值 \{#measurement-status\}

即使单位相同，也要在每个数值旁注明估算或实测。单独复制一个值也能看出其性质。

```html
<dl>
  <dt>East transect</dt><dd>About 18 km</dd>
  <dt>West transect</dt><dd>17.8 km measured</dd>
</dl>
```

## 低于检出限的读数 \{#detection-limit\}

同时记录比较关系、阈值和单位。导出单元格时也要保留三者。

```js
const result = { qualifier: 'below', limit: 0.1, unit: 'mg/L' }
const cell = result.qualifier === 'below'
  ? 'Below ' + result.limit + ' ' + result.unit
  : result.value + ' ' + result.unit
// Use cell for both the table text and its export.
```

## 同一时刻的两个当地日期 \{#two-time-zones\}

两地使用同一个机器可读时间点，各自显示当地日期、时间与时区。跨年时两边都写明年份。

```html
<dl>
  <dt>Taipei</dt><dd><time datetime="2026-12-31T16:30:00Z">1 Jan 2027, 00:30 UTC+08</time></dd>
  <dt>London</dt><dd><time datetime="2026-12-31T16:30:00Z">31 Dec 2026, 16:30 UTC+00</time></dd>
</dl>
```

## 报表生成时间与数据截止时间 \{#report-cutoff\}

## 混合单位排序 \{#sort-units\}

用统一的基准单位存储时长，先按数值排序，再格式化每行。这样 900 µs 会排在 2 ms 前。

```js
const measurements = [{ name: 'Decode', us: 2000 }, { name: 'Read', us: 900 }]
const rows = measurements.toSorted((a, b) => a.us - b.us).map(sample => ({
  name: sample.name,
  duration: sample.us < 1000 ? sample.us + ' µs' : sample.us / 1000 + ' ms'
}))
```

## 用标识符对齐版本 \{#align-versions\}

合并两个版本的标识符，逐行查找各自的值。缺项用文字说明，实测为零则保留 0。

```js
const previous = new Map([['Upload', 14], ['Queue', 0]])
const current = new Map([['Queue', 2], ['Export', 5]])
const ids = new Set([...previous.keys(), ...current.keys()])
const rows = Array.from(ids, id => [
  id, previous.get(id) ?? 'Unavailable in this version',
  current.get(id) ?? 'Unavailable in this version'
])
```

## 跨年的日期范围 \{#cross-year-range\}

开始日期和结束日期各用一个 `time`。即使换成两行，也能看到两边的年份。

```html
<p>Survey period
  <time datetime="2026-12-30">30 Dec 2026</time> to
  <time datetime="2027-01-02">2 Jan 2027</time>
</p>
```
