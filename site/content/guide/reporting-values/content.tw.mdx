讓觀測值、單位和比較基準一起出現。先用原始值運算及排序，再格式化給讀者看。

## 變動量捨入為零 \{#rounding-zero\}

若捨入後得到負零，先轉成零，再決定正負號及方向。後續運算仍使用原始讀數。

```js
const observed = -0.032
const rounded = Number(observed.toFixed(1)) || 0
const direction = rounded < 0 ? 'Down' : rounded > 0 ? 'Up' : 'No change at this precision'
const label = [rounded.toFixed(1), direction].join(' · ')
```

## 百分點與相對變動 \{#percentage-points\}

從 40% 升至 45%，相差 5 個百分點。以原本的 40% 為分母，則相對成長 12.5%。在 [統計數值](/components/stat) 旁寫出比較基準。

## 下降代表改善 \{#falling-error-rate\}

同時寫出變動方向和影響。即使黑白列印，中性的變動標示仍可辨讀。

```html
<div class="stat">
  <p class="stat-label">Failed uploads</p>
  <p class="stat-value">1.2%</p>
  <p class="stat-delta">Improved, down from 1.8%</p>
</div>
```

## 估計值與實測值 \{#measurement-status\}

即使單位相同，也將「約」或「實測」和對應數值放在一起。複製單一數值時仍保有其性質。

```html
<dl>
  <dt>East transect</dt><dd>About 18 km</dd>
  <dt>West transect</dt><dd>17.8 km measured</dd>
</dl>
```

## 低於偵測下限的讀數 \{#detection-limit\}

同時記錄比較關係、界線及單位。匯出儲存格也要保留三者。

```js
const result = { qualifier: 'below', limit: 0.1, unit: 'mg/L' }
const cell = result.qualifier === 'below'
  ? 'Below ' + result.limit + ' ' + result.unit
  : result.value + ' ' + result.unit
// Use cell for both the table text and its export.
```

## 同一時刻的兩個當地日期 \{#two-time-zones\}

兩地使用相同的機器可讀時間點，各自顯示當地日期、時間與時區。跨年時，兩邊都要寫明年份。

```html
<dl>
  <dt>Taipei</dt><dd><time datetime="2026-12-31T16:30:00Z">1 Jan 2027, 00:30 UTC+08</time></dd>
  <dt>London</dt><dd><time datetime="2026-12-31T16:30:00Z">31 Dec 2026, 16:30 UTC+00</time></dd>
</dl>
```

## 報表產生時間與資料截止時間 \{#report-cutoff\}

報表保留兩個時間戳記。重新呈現畫面時，仍讀取原來的時間。

```html
<dl>
  <dt>Data through</dt><dd><time datetime="2026-11-17T23:59:00Z">17 Nov, 23:59 UTC</time></dd>
  <dt>Report generated</dt><dd><time datetime="2026-11-18T08:00:00Z">18 Nov, 08:00 UTC</time></dd>
</dl>
```

## 中心估計值與區間 \{#estimate-interval\}

寫出統計量、區間類型和單位，讀者即可從文字得知兩個端點。

## 預測從哪裡開始 \{#forecast-boundary\}

用列群組標題標出實績與預測的交界，兩組共用欄頭上的單位。

```html

  <caption class="table-title">Monthly demand</caption>
  <thead><tr class="table-row"><th class="table-heading" scope="col">Period</th><th class="table-heading" scope="col">Water (L)</th></tr></thead>

</table>
```

## 混合單位的排序 \{#sort-units\}

用同一個基準單位儲存時間，先依數值排序，再格式化各列。如此 900 µs 會排在 2 ms 前。

```js
const measurements = [{ name: 'Decode', us: 2000 }, { name: 'Read', us: 900 }]
const rows = measurements.toSorted((a, b) => a.us - b.us).map(sample => ({
  name: sample.name,
  duration: sample.us < 1000 ? sample.us + ' µs' : sample.us / 1000 + ' ms'
}))
```

## 用識別值對齊版本 \{#align-versions\}

合併兩版的識別值，逐列查找各自的數值。缺項顯示專用說明，實測為零則保留 0。

```js
const previous = new Map([['Upload', 14], ['Queue', 0]])
const current = new Map([['Queue', 2], ['Export', 5]])
const ids = new Set([...previous.keys(), ...current.keys()])
const rows = Array.from(ids, id => [
  id, previous.get(id) ?? 'Unavailable in this version',
  current.get(id) ?? 'Unavailable in this version'
])
```

## 可比較的小數值 \{#decimal-precision\}

同一欄使用資料足以支持的精度，數值儲存格靠末端對齊。為實測值補零會讓人以為精度更高。

```html
<table class="table">
  <caption class="table-title">Mass measured to 0.1 g</caption>
  <thead><tr class="table-row"><th class="table-heading" scope="col">Sample</th><th class="table-heading table-numeric" scope="col">Mass (g)</th></tr></thead>
  <tbody><tr class="table-row"><th class="table-cell table-primary" scope="row">A</th><td class="table-cell table-numeric">9.8</td></tr>
    <tr class="table-row"><th class="table-cell table-primary" scope="row">B</th><td class="table-cell table-numeric">12.0</td></tr></tbody>
</table>
```

## 跨年的日期範圍 \{#cross-year-range\}

起日和迄日各用一個 `time`。即使日期範圍分成兩行，兩邊都能看到年份。

```html
<p>Survey period
  <time datetime="2026-12-30">30 Dec 2026</time> to
  <time datetime="2027-01-02">2 Jan 2027</time>
</p>
```
