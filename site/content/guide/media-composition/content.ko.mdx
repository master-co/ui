## 이미지 로드 전에 공간 확보 \{#reserve-media-space\}

<ComponentPreview name="artwork-theme" title="적용 중인 테마의 선화" height={136} narrowHeight={156} theme background="plain" bodyClass="flex flex-col justify-center p-md" html={`<img id="field-wave" src="/demo/media/field-wave-light.svg" width="128" height="85" alt="Field recording waveform">

const root = document.documentElement
const system = matchMedia('(prefers-color-scheme: dark)')
const wave = document.getElementById('field-wave')
function syncArtwork() {
  const mode = root.dataset.theme
  const dark = mode === 'dark' || (mode !== 'light' && system.matches)
  wave.src = dark ? '/demo/media/field-wave-dark.svg' : '/demo/media/field-wave-light.svg'
}
new MutationObserver(syncArtwork).observe(root, { attributes: true, attributeFilter: ['data-theme'] })
system.addEventListener('change', syncArtwork)

## 자막 원고에서 재생 위치 이동 \{#transcript-time\}

기본 컨트롤과 자막을 유지합니다. 시간 링크는 자체로 미디어 프래그먼트로 작동합니다. 페이지 안에서 일반적으로 활성화하면 재생 위치를 옮기고 키보드 포커스는 해당 줄에 그대로 두어 읽기를 이어갈 수 있게 합니다.

```html
<video id="lesson" class="w-full" controls playsinline preload="metadata" poster="/demo/moonrise.jpg" src="/demo/moonrise.mp4">
  <track kind="captions" srclang="en" label="English" src="/demo/recording.vtt">
</video>
<ol id="lesson-transcript">
  <li><a class="link" href="/demo/moonrise.mp4#t=0.3">0:00</a> This is a short recording, made to show the player and its transcript.</li>
  <li><a class="link" href="/demo/moonrise.mp4#t=4.707">0:04</a> Each line of the transcript is a cue, with the time it begins.</li>
</ol>
<script>
const lesson = document.getElementById('lesson')
for (const link of document.querySelectorAll('#lesson-transcript a')) {
  link.addEventListener('click', event => {
    if (event.ctrlKey || event.metaKey || event.shiftKey || event.altKey) return
    event.preventDefault()
    lesson.currentTime = Number(link.hash.slice(3))
  })
}
</script>
```

## 선택한 표기법으로 색상 복사 \{#color-notations\}

견본은 한 번만 표시하고 두 원본 문자열에 각각 이름을 붙입니다. 각 버튼은 옆의 코드만 복사하며 OKLCH는 함수 전체를 포함합니다.

<ComponentPreview name="color-notations" title="선택한 표기법으로 색상 복사" height={175} narrowHeight={205} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<div id="ink-values">
  <p><span class="swatch" aria-hidden="true" style="--swatch:#000"></span> Print black</p>
  <dl>
    <div><dt>HEX</dt><dd><code>#000000</code> <button class="btn btn-sm" aria-label="Copy HEX" type="button">Copy</button></dd></div>
    <div><dt>OKLCH</dt><dd><code>oklch(0% 0 none)</code> <button class="btn btn-sm" aria-label="Copy OKLCH" type="button">Copy</button></dd></div>
  </dl>
  <output></output>
</div>
<script>
const values = document.getElementById('ink-values')
for (const button of values.querySelectorAll('button')) {
  button.addEventListener('click', async () => {
    const code = button.parentElement.querySelector('code')
    try {
      await navigator.clipboard.writeText(code.textContent)
      values.querySelector('output').textContent = 'Copied ' + code.textContent
    } catch {
      values.querySelector('output').textContent = 'Select the value and use Copy.'
    }
  })
}
</script>`} />
