## 在图片加载前预留空间 \{#reserve-media-space\}

在 HTML 中写出图片的实际宽高。响应式宽度配合自动高度会在等待加载时预留比例，下方的署名链接也能保持位置。

```html
<figure class="figure max-w(320)">
  <img class="figure-media" src="/demo/media/armchair-portrait.webp" width="600" height="800" alt="Linen armchair">
  <figcaption class="figure-caption"><a class="link" href="/demo/CREDITS.md">Photo credits</a></figcaption>
</figure>
```

## 从文字稿跳到视频时间点 \{#transcript-time\}

保留原生控件和字幕。时间链接本身也是媒体片段地址。在页面内正常激活时跳至对应时间，焦点保留在该行以便继续阅读。

```html
<video id="lesson" class="w-full" controls playsinline preload="metadata" poster="/demo/moonrise.jpg" src="/demo/moonrise.mp4">
  <track kind="captions" srclang="en" label="English" src="/demo/recording.vtt">
</video>
<ol id="lesson-transcript">
  <li><a class="link" href="/demo/moonrise.mp4#t=0.3">0:00</a> This is a short recording, made to show the player and its transcript.</li>
  <li><a class="link" href="/demo/moonrise.mp4#t=4.707">0:04</a> Each line of the transcript is a cue, with the time it begins.</li>
</ol>
<script>
const lesson = document.getElementById('lesson')
for (const link of document.querySelectorAll('#lesson-transcript a')) {
  link.addEventListener('click', event => {
    if (event.ctrlKey || event.metaKey || event.shiftKey || event.altKey) return
    event.preventDefault()
    lesson.currentTime = Number(link.hash.slice(3))
  })
}
</script>
```

    <div><dt>OKLCH</dt><dd><code>oklch(0% 0 none)</code> <button class="btn btn-sm" aria-label="Copy OKLCH" type="button">Copy</button></dd></div>
  </dl>
  <output></output>
</div>
<script>
const values = document.getElementById('ink-values')
for (const button of values.querySelectorAll('button')) {
  button.addEventListener('click', async () => {
    const code = button.parentElement.querySelector('code')
    try {
      await navigator.clipboard.writeText(code.textContent)
      values.querySelector('output').textContent = 'Copied ' + code.textContent
    } catch {
      values.querySelector('output').textContent = 'Select the value and use Copy.'
    }
  })
}
</script>`} />
