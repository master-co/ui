Master UI 沒有自己的編輯器。編輯格式化文字，包括文件模型、選取範圍、復原紀錄、貼上和輸入法組字，是大型引擎的工作，而市面上已有優秀的引擎。Master UI 提供給這類引擎的是一個外框：[`editor`](/components/editor) 契約負責繪製凹槽、工具列橫帶、各種狀態和文件內容，讓富文字欄位的外觀與行為和頁面上的其他欄位一致。本指南以純 JavaScript 將 [TipTap](https://tiptap.dev/docs/editor/getting-started/install/vanilla-javascript) 放進這個外框。

## 分工 \{#who-does-what\}

| | 負責 |
| --- | --- |
| TipTap | 文件及其結構定義、選取範圍、復原與重做、按鍵與快捷鍵、貼上、輸入法，以及它設為可編輯的元素 |
| `editor` | 外框及其狀態、工具列橫帶、文件的大小，以及段落、標題、清單、引文、連結和分隔線的外觀 |
| [`toolbar`](/components/toolbar) 及其行為 | 讓所有控制項只占一個 Tab 停駐點、以方向鍵在控制項之間移動，以及按下狀態的按鈕 |
| 你的頁面 | 連接兩者：每個按鈕執行哪個指令、它的狀態為何，以及值要送往何處 |

`@master/ui` 不依賴任何編輯器，也沒有任何 React、Svelte 或 Vue 元件包裝編輯器。這個範例是網站本身的，TipTap 是網站的相依套件：你可以複製它，或參照它改用 ProseMirror、Lexical 或其他引擎。契約不會改變。

## 將引擎放進外框 \{#frame\}

TipTap 會讓一個元素變成可編輯，並將文件寫入其中。請讓它在該元素上加上 `editor-document`，並設定欄位控制項應有的角色、名稱和描述，同時在它渲染的節點上寫入編輯器的類別：`editor` 樣式表從不直接選取元素，因此標題之所以套用樣式，是因為它帶有 `editor-heading`，而不是因為它是 `h2`。行內程式碼和程式碼區塊則使用元件庫本身的[程式碼](/components/code)類別。

```js name=main.js
const editor = new Editor({
  element: root.querySelector('[data-editor]'),
  content: notes,
  extensions: [
    StarterKit.configure({
      heading: { levels: [2, 3] },
      paragraph: { HTMLAttributes: { class: 'editor-paragraph' } },
      bulletList: { HTMLAttributes: { class: 'editor-list' } },
      orderedList: { HTMLAttributes: { class: 'editor-list editor-list-numbered' } },
      listItem: { HTMLAttributes: { class: 'editor-item' } },
      blockquote: { HTMLAttributes: { class: 'editor-quote' } },
      code: { HTMLAttributes: { class: 'code' } },
      codeBlock: { HTMLAttributes: { class: 'code-block' } },
      horizontalRule: { HTMLAttributes: { class: 'editor-rule' } },
      link: { openOnClick: false, autolink: true, defaultProtocol: 'https', HTMLAttributes: { class: 'editor-link' } },
    }),
    headingClass,
  ],
  editorProps: {
    attributes: { class: 'editor-document', role: 'textbox', 'aria-multiline': 'true', 'aria-labelledby': 'rich-text-label', 'aria-describedby': 'rich-text-hint rich-text-error' },
  },
})
```

標題不會為其層級輸出任何屬性，因此需要一個小型擴充（範例中的 `headingClass`）為每個層級加上類別：第二層使用 `editor-heading`，第三層使用 `editor-subheading`。文件高度從 `--editor-rows` 行（預設六行）長到 `--editor-max-rows` 行，之後就會捲動。

## 連接工具列 \{#toolbar\}

工具列是加上 `editor-toolbar` 的[工具列](/components/toolbar)，平鋪在凹槽頂端。它的行為讓它只占一個 Tab 停駐點，可以用方向鍵在其中移動，並以 `aria-pressed` 表示按鈕的按下狀態；每個按鈕做什麼、說明什麼，則由頁面決定。

- **按下按鈕會執行指令並交回焦點。** `editor.chain().focus().toggleBold().run()`：讀者會回到文件中原本書寫的位置，並保有 TipTap 所保留的選取範圍。
- **由選取範圍決定按下狀態。** 每次發生 transaction 時，每個按鈕的 `aria-pressed` 都會設為 `editor.isActive(...)` 的結果，因此只要游標位於粗體文字中，「粗體」就會顯示為按下狀態，文字樣式下拉選單也會顯示游標所在的區塊類型。
- **無法執行的操作會停用。** `editor.can()` 會試行一個指令：沒有可復原的內容時停用「復原」；編輯器為唯讀或停用時，則停用所有控制項。
- **連結使用小型表單，而不是 prompt。** 連結按鈕會開啟一個帶有 URL 欄位的[彈出面板](/components/popover)。欄位本身的驗證會檢查網址；「套用」會將連結加到選取範圍上，若未選取任何內容，則以文字插入連結；「移除」則會拿掉連結。TipTap 會拒絕 `javascript:` 之類的網址，連結也會帶有 `rel="noopener noreferrer nofollow"`。

請為每個圖示按鈕命名，並在 `aria-keyshortcuts` 中寫出 TipTap 已處理的快捷鍵，讓螢幕閱讀器能同時讀出兩者。

## 狀態 \{#states\}

| 狀態 | 標記 | 範例的設定方式 |
| --- | --- | --- |
| 焦點 | `editor-document` 上的 `:focus` | 由瀏覽器在文件取得焦點時設定；外框會以欄位的光暈浮起 |
| 無效 | `editor-document` 上的 `aria-invalid="true"` | 內容留空時：外框顯示錯誤狀態的邊緣，並顯示欄位的 `field-error`，直到讀者再次輸入 |
| 唯讀 | `editor-document` 上的 `aria-readonly="true"` | `editor.setEditable(false)` 加上該屬性；文字仍可閱讀和複製 |
| 停用 | `editor` 上的 `aria-disabled="true"` | `editor.setEditable(false)`、該屬性，並停用所有控制項 |

這些狀態是 TipTap 維護在其元素上的屬性：請以 `editor.setOptions({ editorProps: { attributes } })` 設定，絕不要直接設定在元素上，否則下一次渲染時就會被移除。

## 值 \{#value\}

TipTap 的文件是資料。`editor.getJSON()` 是應用程式要儲存的內容，`editor.commands.setContent(json)` 則會載入已儲存的內容，就像「**Load other notes**」和「**Reset**」所做的那樣。範例以 `textContent` 寫出 JSON：讀者輸入的任何內容都不會被當成標記放進頁面。若必須在編輯器以外以 HTML 顯示內容，請在伺服器上從 JSON 渲染，並經過清理器處理。

監聽 `update` 來儲存或驗證，監聽 `transaction` 來繪製工具列；兩者都不會改變文件。頁面不會在文件上加入自己的按鍵處理程式：以輸入法組字日文、中文或韓文時會使用 Enter 和方向鍵，而 TipTap 知道何時正在組字。請在 `blur` 時驗證，而不是在按鍵時。

## 銷毀 \{#destroy\}

編輯器持有監聽器、一個檢視和它的復原紀錄。`mount()` 會傳回一個函式，用來卸除工具列行為、移除頁面的監聽器，並呼叫 `editor.destroy()`；請在欄位離開頁面時呼叫它，就像框架在元件卸載時所做的那樣。

## 未涵蓋的部分 \{#leaves-out\}

- **跟隨選取範圍的工具列。** 浮在所選文字上方的工具列需要追蹤選取範圍繪製的位置，這由 TipTap 的 `BubbleMenu` 擴充及其定位功能負責；本指南維持固定的工具列。
- **提及、表格、圖片和協同編輯。** 每一項都是一個 TipTap 擴充，並有各自的介面。
- **Markdown 的匯入與匯出。** 請在伺服器上轉換 JSON。
