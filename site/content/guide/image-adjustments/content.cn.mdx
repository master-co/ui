读者选择一张图片，进行裁剪，以 90 度为单位旋转，并设置亮度、对比度和饱和度，边调整边看到效果。浏览器中没有任何操作会修改图片本身：页面交出的是原始文件和作为数据的调整参数，由应用的图片处理流程裁切、编码并存储图片。本页用[裁剪器](/components/cropper)、原生输入控件和 CSS 滤镜实现这一流程。

## 职责划分 \{#who-does-what\}

| 部分 | 负责 |
| --- | --- |
| [裁剪器](/components/cropper)及其行为脚本 | 裁剪框：边缘、按键、指针，以及以图片自身像素表示的裁剪区域 |
| 原生输入控件 | 选择文件、色调的范围滑块、显示方式的单选按钮 |
| 你的页面 | 读取文件、用于显示文件的对象 URL、调整效果的预览，以及交出的数据 |
| 你的应用 | 对要存储的图片进行裁切、旋转、滤镜处理和编码，并上传 |

页面在自己的预览上设置 filter 和 transform；没有任何 Master UI 行为脚本会绘制图片。这是本示例中唯一由数据决定样式的地方，并且只留在页面中。

## 文件 \{#the-file\}

- **选择。** 文件输入框放在按钮的 label 中，设置 `accept="image/*"`。图片在显示前先用 `HTMLImageElement.decode()` 解码，因此不是图片的文件会被拒绝，并在[行内提示](/components/alert)中给出消息，当前显示的图片保持不变。
- **显示。** 选中的文件通过对象 URL 显示。替换或清除图片时，用 `URL.revokeObjectURL()` 释放旧的 URL；示例停止时，`mount()` 返回的函数也会这样做。
- **重新开始。** 裁剪器从 `cropper-image` 的 `width` 和 `height` 读取图片尺寸，因此换上新图片时，要按其原始尺寸设置这两个属性，并重新挂载裁剪器，裁剪框覆盖整张图片。
- **隐私。** 文件始终不会离开浏览器；请在按钮旁说明这一点。

## 调整参数 \{#the-adjustments\}

- **裁剪。** 裁剪器的 `value`，即以图片像素表示的 `{ x, y, width, height }`，在裁剪框每次触发 `input` 和 `change` 时读取。
- **旋转。** 每次向左或向右转 90 度，取值为 0、90、180 或 270 度。裁剪区域始终按图片原本的方向记录；预览以中心为轴旋转裁剪后的图片，因此在 90 度和 270 度时宽高互换。
- **色调。** 亮度、对比度和饱和度，范围为 0% 到 200%，100% 即图片原样。CSS 正好以 `brightness()`、`contrast()` 和 `saturate()` 提供这三项，因此预览效果与图片处理流程应用同样三项调整后的结果一致。
- **显示方式。** “适应”在展示区内完整显示结果，“填充”用结果铺满展示区，“平铺”则重复显示结果，就像以该图片作为背景时那样。

“重置”会还原色调和裁剪，但保留图片。

```json name=adjustments.json
{
  "file": { "name": "dawn.jpg", "type": "image/jpeg", "size": 482113 },
  "crop": { "x": 160, "y": 80, "width": 1280, "height": 800 },
  "rotate": 90,
  "brightness": 110,
  "contrast": 100,
  "saturation": 85,
  "mode": "fit"
}
```

把原始 `File` 和这个对象一起交给应用：应用可以用同样的方式裁切、旋转全分辨率图片并应用滤镜，同时保留原图，以便日后再次调整。

## 未涵盖的内容 \{#what-this-leaves-out\}

完整的图片编辑器不止这三项色调，还有色温、高光与阴影、曲线，以及导出文件。CSS 没有任何对应这些功能的滤镜，而近似效果会让读者看到存储后的图片并不具备的结果，因此本示例选择不提供，而不是加以模仿。是否在浏览器中用 canvas 或 `OffscreenCanvas` 对结果进行编码由应用决定，这里不作演示。

## 无障碍 \{#accessibility\}

- 文件输入框是放在有标签的按钮中的真正输入控件，可用 <kbd class="kbd">Tab</kbd> 聚焦；下方的提示说明图片会被送往何处。
- 裁剪框支持裁剪器的按键操作，每次变化后，其状态区域会读出裁剪区域。
- 每项色调都是带标签的范围滑块，旁边写有当前值；旋转按钮以方向命名。
- 预览以图片自身的描述加上“adjusted”命名，例如“A pier at dawn, adjusted”；对图片做了哪些调整写在页面显示的数据中，而不只体现在画面上。
