讀者選擇一張圖片、裁切它、每次旋轉四分之一圈，並設定亮度、對比和飽和度，同時即時看到結果。瀏覽器中沒有任何東西會修改圖片本身：頁面交出的是原始檔案和以資料表示的調整內容，再由應用程式的影像處理流程裁切並編碼要儲存的圖片。本頁使用[裁切器](/components/cropper)、原生輸入元件和 CSS 濾鏡實作這個流程。

## 分工 \{#who-does-what\}

| 部分 | 負責 |
| --- | --- |
| [裁切器](/components/cropper)及其行為 | 裁切框：它的邊緣、按鍵、指標操作，以及以圖片本身像素表示的裁切範圍 |
| 原生輸入元件 | 選擇檔案、色調的範圍滑桿、顯示方式的單選按鈕 |
| 你的頁面 | 讀取檔案、用來顯示檔案的物件 URL、調整內容的預覽，以及要交出的資料 |
| 你的應用程式 | 裁切、旋轉、套用濾鏡並編碼要儲存的圖片，以及上傳圖片 |

頁面在自己的預覽上設定濾鏡和變形；沒有任何 Master UI 行為會繪製圖片。這是本範例中唯一由資料決定樣式的地方，而這件事留在頁面中處理。

## 檔案 \{#the-file\}

- **選擇。** 放在按鈕標籤內的檔案輸入欄位設定 `accept="image/*"`。圖片在顯示前會以 `HTMLImageElement.decode()` 解碼，因此不是圖片的檔案會被拒絕，並在[提示訊息](/components/alert)中說明原因，目前顯示的圖片則維持不變。
- **顯示。** 所選檔案以物件 URL 顯示。替換或清除圖片時，會以 `URL.revokeObjectURL()` 釋放舊的 URL；範例停止時，`mount()` 傳回的函式也會這麼做。
- **重新開始。** 裁切器從 `cropper-image` 的 `width` 和 `height` 讀取圖片尺寸，因此換新圖片時，會依其原始尺寸設定這兩個屬性，並重新掛上裁切器，涵蓋整張圖片。
- **隱私。** 檔案從不離開瀏覽器；請在按鈕旁說明這一點。

## 調整內容 \{#the-adjustments\}

- **裁切。** 裁切器的 `value`，即以圖片像素表示的 `{ x, y, width, height }`，在裁切框每次觸發 `input` 和 `change` 時讀取。
- **旋轉。** 每次向左或向右旋轉四分之一圈，以 0、90、180 或 270 度表示。裁切範圍保持在圖片原本的方向；預覽則以中心為軸旋轉裁切後的圖片，因此在 90 和 270 度時寬高會互換。
- **色調。** 亮度、對比和飽和度，範圍從 0% 到 200%，100% 代表圖片原樣。CSS 剛好有這三種對應的 `brightness()`、`contrast()` 和 `saturate()`，因此預覽的結果，就是影像處理流程套用相同三種調整後會產生的結果。
- **顯示方式。** 「完整顯示」會在預覽區內顯示完整結果，「填滿」會讓結果覆蓋整個預覽區，「平鋪」則會像背景圖片一樣重複排列。

「重設」會還原色調和裁切範圍，但保留圖片。

```json name=adjustments.json
{
  "file": { "name": "dawn.jpg", "type": "image/jpeg", "size": 482113 },
  "crop": { "x": 160, "y": 80, "width": 1280, "height": 800 },
  "rotate": 90,
  "brightness": 110,
  "contrast": 100,
  "saturation": 85,
  "mode": "fit"
}
```

請將原始的 `File` 和這個物件一起交給應用程式：應用程式可以用相同方式以原始解析度裁切、旋轉圖片並套用濾鏡，同時保留原始檔案，以便日後再次調整。

## 未涵蓋的部分 \{#what-this-leaves-out\}

完整的相片編輯器不只有這三種色調，還有色溫、亮部與陰影、曲線，以及匯出的檔案。CSS 沒有對應這些功能的濾鏡，而近似的做法會讓讀者看到儲存的圖片實際上不會有的結果，因此本範例選擇省略，而不是模仿。在瀏覽器中以 canvas 或 `OffscreenCanvas` 編碼結果，是應用程式的選擇，這裡不予示範。

## 無障礙 \{#accessibility\}

- 檔案輸入欄位是放在有標籤的按鈕內的真正輸入元件，可以用 <kbd class="kbd">Tab</kbd> 抵達；其下方的提示說明圖片會被送往何處。
- 裁切框具備裁切器的按鍵操作，其狀態區域會在每次變更後說明裁切範圍。
- 每種色調都是一個有標籤的範圍滑桿，旁邊寫出它的數值；旋轉則是以方向命名的按鈕。
- 預覽以圖片本身的描述加上「調整後」來命名，例如「黎明時的碼頭，調整後」；對圖片所做的調整寫在頁面顯示的資料中，而不只呈現在圖像裡。
