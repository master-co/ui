## 役割分担 \{#who-does-what\}

| 部分 | 担当 |
| --- | --- |
| [クロッパー](/components/cropper)とそのビヘイビア | 切り抜き枠。枠の辺、キー操作、ポインター操作、画像本来のピクセル単位での切り抜き範囲 |
| ネイティブの入力要素 | ファイルの選択、色調の範囲スライダー、表示方法のラジオボタン |
| ページ | ファイルの読み込み、表示に使うオブジェクト URL、調整内容のプレビュー、引き渡すデータ |
| アプリケーション | 保存する画像の切り抜き、回転、フィルター適用、エンコード、アップロード |

ページは自身のプレビューにフィルターとトランスフォームを設定します。画像を描画する Master UI のビヘイビアはありません。この例でデータがスタイルを決めるのはこの 1 か所だけで、それはページの中にとどまります。

## ファイル \{#the-file\}

- **選択。** ボタンのラベルの中に置いたファイル入力は `accept="image/*"` を指定します。画像は表示する前に `HTMLImageElement.decode()` でデコードするため、画像ではないファイルは[アラート](/components/alert)のメッセージとともに拒否され、表示中の画像はそのまま残ります。
- **表示。** 選択したファイルはオブジェクト URL で表示します。画像を置き換えたり消去したりすると、古い URL は `URL.revokeObjectURL()` で解放されます。例を停止するときに `mount()` が返す関数を呼び出した場合も同様です。
- **やり直し。** クロッパーは `cropper-image` の `width` と `height` から画像の大きさを読み取ります。そのため、新しい画像では本来の大きさから両方を設定し、クロッパーを画像全体に対して適用し直します。
- **プライバシー。** ファイルがブラウザーの外に送られることはありません。そのことをボタンの横に明記します。

## 調整内容 \{#the-adjustments\}

- **切り抜き。** クロッパーの `value` で、画像のピクセル単位の `{ x, y, width, height }` です。枠から発行される `input` と `change` のたびに読み取ります。
- **回転。** 左または右に 90° ずつ回転し、0、90、180、270 度のいずれかで表します。切り抜き範囲は画像本来の向きで保持し、プレビューでは切り抜いた画像を中心で回転させるため、90 度と 270 度では幅と高さが入れ替わります。
- **色調。** 明るさ、コントラスト、彩度で、0% から 200% までの値をとり、100% が元の画像のままです。CSS にはちょうどこの 3 つが `brightness()`、`contrast()`、`saturate()` としてあるため、プレビューは、同じ 3 つを適用する画像処理パイプラインの結果と一致します。
- **表示。** 「全体を表示」は結果全体をステージ内に収め、「ステージを埋める」は結果でステージ全体を覆い、「繰り返し」は背景画像のように結果を敷き詰めます。

「リセット」は色調と切り抜き範囲を元に戻し、画像はそのまま残します。

```json name=adjustments.json
{
  "file": { "name": "dawn.jpg", "type": "image/jpeg", "size": 482113 },
  "crop": { "x": 160, "y": 80, "width": 1280, "height": 800 },
  "rotate": 90,
  "brightness": 110,
  "contrast": 100,
  "saturation": 85,
  "mode": "fit"
}
```

元の `File` とこのオブジェクトをまとめてアプリケーションに渡します。アプリケーションはフル解像度の画像に同じ切り抜き、回転、フィルターを適用でき、元の画像を保持しておけば後で調整し直すこともできます。

## この例で扱わないもの \{#what-this-leaves-out\}

本格的な写真編集ソフトには、この 3 つ以外にも、色温度、ハイライトとシャドウ、トーンカーブ、ファイルの書き出しなどがあります。CSS にはそのいずれにも当たるフィルターがなく、近似で表示すると、保存される画像とは異なる結果を読み手に見せることになります。そのため、この例ではそれらを模倣せず、扱いません。canvas や `OffscreenCanvas` を使ってブラウザー内で結果をエンコードするかどうかはアプリケーションが決めることで、ここでは扱いません。

## アクセシビリティ \{#accessibility\}

- ファイル入力は、ラベル付きのボタンの中にある本物の入力要素で、<kbd class="kbd">Tab</kbd> キーで移動できます。その下のヒントで、画像の送り先を伝えます。
- 切り抜き枠ではクロッパーのキー操作を使え、変更のたびにステータス領域が切り抜き範囲を伝えます。
- 各色調はラベル付きの範囲スライダーで、横に値を表示します。回転は、方向を名前にしたボタンです。
- プレビューの名前は、画像自体の説明に「調整済み」を加えたもので、たとえば「夜明けの桟橋（調整済み）」のようになります。何を行ったかは、図だけでなく、ページが表示するデータでも伝えます。
