독자가 사진을 고르고, 자르고, 90도씩 회전하고, 밝기, 대비, 채도를 설정하면서 결과를 바로 확인합니다. 브라우저에서는 사진 자체를 바꾸지 않습니다. 페이지가 전달하는 것은 원본 파일과 데이터로 된 조정 내용이며, 저장할 사진을 자르고 인코딩하는 일은 애플리케이션의 이미지 파이프라인이 담당합니다. 이 페이지에서는 [자르기 도구](/components/cropper), 네이티브 입력 요소, CSS 필터로 이를 구현합니다.

## 역할 분담 \{#who-does-what\}

| 부분 | 담당 |
| --- | --- |
| [자르기 도구](/components/cropper)와 그 동작 | 자르기 상자의 가장자리, 키보드, 포인터, 사진 자체의 픽셀 단위로 표시한 자르기 영역 |
| 네이티브 입력 요소 | 파일 선택, 밝기·대비·채도 범위 입력, 표시 방식 라디오 버튼 |
| 페이지 | 파일 읽기, 파일을 표시하는 객체 URL, 조정 내용 미리보기, 전달할 데이터 |
| 애플리케이션 | 저장할 사진의 자르기, 회전, 필터 적용, 인코딩, 업로드 |

페이지는 자체 미리보기에 filter와 transform을 설정합니다. 사진을 그리는 Master UI 동작은 없습니다. 이 예제에서 데이터가 스타일을 결정하는 곳은 이곳뿐이며, 이 처리는 페이지에 남겨 둡니다.

## 파일 \{#the-file\}

- **선택.** 버튼의 레이블 안에 있는 파일 입력에 `accept="image/*"`를 지정합니다. 사진은 표시하기 전에 `HTMLImageElement.decode()`로 디코딩하므로, 사진이 아닌 파일은 [알림](/components/alert)의 메시지와 함께 거부되고 현재 표시 중인 사진은 그대로 유지됩니다.
- **표시.** 선택한 파일은 객체 URL로 표시합니다. 사진을 바꾸거나 지우면 `URL.revokeObjectURL()`로 이전 URL을 해제하며, 예제가 중지될 때 `mount()`가 반환하는 함수도 같은 작업을 합니다.
- **다시 시작.** 자르기 도구는 `cropper-image`의 `width`와 `height`에서 사진 크기를 읽으므로, 새 사진은 원본 크기로 두 값을 설정하고 자르기 도구를 사진 전체에 다시 연결합니다.
- **개인 정보.** 파일은 브라우저 밖으로 나가지 않습니다. 버튼 옆에 이 사실을 알려 주세요.

## 조정 내용 \{#the-adjustments\}

- **자르기.** 자르기 도구의 `value`이며, 사진의 픽셀 단위로 표시한 `{ x, y, width, height }`입니다. 상자에서 발생하는 `input`과 `change`마다 읽습니다.
- **회전.** 왼쪽이나 오른쪽으로 90도씩 회전하며, 0, 90, 180, 270도로 표시합니다. 자르기 영역은 사진 자체의 방향을 기준으로 유지되고, 미리보기에서는 자른 사진을 중심점을 기준으로 회전하므로 90도와 270도에서는 너비와 높이가 서로 바뀝니다.
- **밝기·대비·채도.** 각 값은 0%부터 200%까지 설정할 수 있고, 100%는 원본 그대로입니다. CSS에는 정확히 이 세 가지가 `brightness()`, `contrast()`, `saturate()`로 있으므로, 미리보기는 같은 세 가지를 적용하는 이미지 파이프라인의 결과와 같습니다.
- **표시 방식.** 맞춤은 결과 전체를 미리보기 영역 안에 표시하고, 채우기는 결과로 영역 전체를 덮으며, 바둑판식은 사진을 배경으로 사용할 때처럼 결과를 반복합니다.

초기화하면 밝기·대비·채도와 자르기 영역이 원래대로 돌아가고 사진은 유지됩니다.

```json name=adjustments.json
{
  "file": { "name": "dawn.jpg", "type": "image/jpeg", "size": 482113 },
  "crop": { "x": 160, "y": 80, "width": 1280, "height": 800 },
  "rotate": 90,
  "brightness": 110,
  "contrast": 100,
  "saturation": 85,
  "mode": "fit"
}
```

원본 `File`과 이 객체를 함께 애플리케이션에 전달하세요. 애플리케이션은 원본 해상도의 사진을 같은 방식으로 자르고, 회전하고, 필터를 적용할 수 있으며, 원본을 보관해 나중에 다시 조정할 수 있습니다.

## 이 예제에서 다루지 않는 것 \{#what-this-leaves-out\}

완전한 사진 편집기에는 밝기·대비·채도 외에도 색온도, 하이라이트와 그림자, 곡선, 내보낸 파일 등이 있습니다. CSS에는 이에 해당하는 필터가 없고, 근사치로 흉내 내면 저장된 사진에는 없는 결과를 독자에게 보여 주게 되므로 이 예제에서는 흉내 내지 않고 제외합니다. 캔버스나 `OffscreenCanvas`로 브라우저에서 결과를 인코딩할지는 애플리케이션이 결정할 일이며, 여기서는 다루지 않습니다.

## 접근성 \{#accessibility\}

- 파일 입력은 레이블이 있는 버튼 안의 실제 입력 요소이며 <kbd class="kbd">Tab</kbd>으로 이동할 수 있습니다. 그 아래의 도움말은 사진이 어디로 전달되는지 알려 줍니다.
- 자르기 상자는 자르기 도구의 키보드 조작을 지원하며, 자르기 영역이 바뀔 때마다 상태 영역이 새 자르기 영역을 알려 줍니다.
- 밝기, 대비, 채도는 각각 레이블이 있는 범위 입력으로 제공되며, 각 입력 옆에 값이 표시됩니다. 회전 버튼의 이름은 회전 방향입니다.
- 미리보기 이름은 “새벽의 부두, 조정됨”처럼 사진 자체의 설명에 “조정됨”을 붙여 지정합니다. 사진에 적용한 내용은 그림뿐만 아니라 페이지가 표시하는 데이터에도 들어 있습니다.
