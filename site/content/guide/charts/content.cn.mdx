Master UI 自行绘制图表。[图表组件](/components/chart)通过单个 SVG 和主题令牌绘制二十多种图表，从折线图到旭日图一应俱全。每种图表在[图表](/charts)文档中都有单独的页面。此外，还有用于展示单个数值、趋势或占比的小型组件。本指南介绍如何选型、如何让多个图表随同一时间范围联动，以及何时更适合使用图表引擎。

## 如何选型 \{#choose\}

先考虑读者需要看到什么，再选择图形。以下组件均根据标记绘制，无需脚本即可跟随主题，并以文字提供数值。

| 读者需要看到什么 | 使用 |
| --- | --- |
| 数值随时间的变化趋势 | [折线图](/charts/line)，只有一到两个数据系列时也可用[面积图](/charts/area) |
| 两个时间点之间哪些上升、哪些下降 | [斜率图](/charts/slope)。如果列表中每项都有两个数值，用[哑铃图](/charts/dumbbell) |
| 排名如何变化 | [排名变化图](/charts/bump) |
| 各项数值的大小对比 | [柱状图](/charts/bar)。名称较长时用[条形图](/charts/bar#across) |
| 一个数值如何变成另一个数值 | [瀑布图](/charts/waterfall) |
| 两个数值之间的区间 | [区间图](/charts/range) |
| 不同时点或不同组别的总量构成 | [堆叠柱状图](/charts/bar#stacked)或[堆叠面积图](/charts/area#stacked)。各组规模不同时用[马赛克图](/charts/marimekko) |
| 一个整体由哪些部分组成 | 最多五个部分时，用[环形图](/charts/donut)或[饼图](/charts/pie)。需要精确到 1 个百分点时，用[华夫格图](/charts/waffle)。部分较多时，用[矩形树图](/charts/treemap)。有两个层级时，用[旭日图](/charts/sunburst)。在单根条中展示构成时，用[构成条](/components/breakdown) |
| 流程中有多少量到达各个阶段 | [漏斗图](/charts/funnel) |
| 少量目标各自的完成进度 | [多环进度图](/charts/rings) |
| 少量对象在同一组指标上的表现 | [雷达图](/charts/radar) |
| 测量值的分布 | [直方图](/charts/histogram)。同时比较多组分布时，用[箱线图](/charts/box) |
| 两个尺度上的分布规律 | [热力图](/charts/heatmap) |
| 两个指标之间的关系 | [散点图](/charts/scatter)。用[气泡图](/charts/scatter#bubble)呈现第三个指标 |
| 单个数值及其变化 | [指标卡](/components/stat) |
| 在一句话或一行内展示数据系列的变化趋势 | [迷你折线图](/components/sparkline) |
| 单个测量值及其离限值有多近 | [仪表图](/components/gauge)或[计量条](/components/meter) |
| 大量小数值呈现的规律，且旁边不显示刻度 | 由单元格组成的[热力图](/components/heatmap) |
| 按列比较精确数值 | [表格](/components/table) |

数值本身足以传达信息时，直接展示数值即可。带变化量的指标卡比只有两根柱的图表更容易快速读懂。

## 仪表板示例 \{#dashboard\}

三个指标和三张图表共用一个时间范围。切换时间范围时，所有指标和图表都基于同一份数据同步更新，因此指标数值始终与图表一致。

<PagePreview name="dashboard" title="图表仪表板" example="chart-dashboard" caption="选择时间范围、将指针移到某一天，或通过图例隐藏数据系列。" />

- **一个控件统一控制下方的所有内容。**时间范围选择器单独占一行，放在指标和图表上方，始终置于卡片之外。需要独立时间范围的图表应放在另一个视图中。
- **图表根据数据重新生成。**在已有图表的元素上调用 `chart(element, options)` 会替换原图表，调用其返回的函数可停止图表。时间范围变化时，使用该时间范围的数据再次调用它。
- **先看指标，再用图表解释。**每张卡片的标题都说明它展示的指标。图表的 `label` 向看不到图形的读者提供相同的说明，并附上单位。
- **每种图表各有用途。**堆叠面积图展示总量的变化及其构成，环形图展示当前整体的构成，柱状图展示排名并直接标出数值，因为读者需要根据数值解读排名。

## 主题色 \{#colors\}

单个数据系列的图表使用墨色。仅用单色就能读懂，也能融入周围的单色界面。

多个数据系列各用一种[分类色](/components/category)。图表默认按固定顺序分配颜色：蓝、橙、蓝绿、紫、琥珀、粉、绿、天蓝。在两种配色方案中，常见色觉缺陷的读者都能分辨相邻颜色。如果某个对象在整个产品中始终使用同一种颜色，请显式指定该数据系列的 `category`。例如，无论东京排在列表的哪个位置，它在图表、图例、徽标和表格行中都用蓝色。

- **隐藏一个数据系列时，其他系列的颜色保持不变。**即使其他系列移出图表，仍显示的系列也会保留各自的分类色。
- **分类色与状态色用途不同。**成功、警告和危险表示对象的状态。数据系列出现异常时，应通过图表旁的[徽标](/components/badge)或一句话说明。只有[瀑布图](/charts/waterfall#inks)使用状态色，因为它的升降台阶表示带正负号的变化量，与指标卡中的变化量相同。
- **文字始终使用文本色。**名称和数值使用文本令牌，旁边放置对应系列颜色的标记。柱或扇区用色块，折线用短线。
- **同一颜色的不同深浅只用于表示一个指标。**热力图的单元格、漏斗图的各阶段和旭日图的外环都用同一颜色的不同深浅表示数值。
- **主题应用于每个图形标记。**图形标记读取分类色的 `--color-category-<name>-mark` 令牌，墨色读取 `--chart-color`，所以配色方案、主题和限定在某一区域内的覆盖设置均可直接生效，无需重绘。

## 统一刻度 \{#scale\}

一张图表使用一套数值刻度。访客数以千人为单位，比率以百分比为单位，这类量级不同的指标应分别绘制在上下排列的两张图表中，并对齐两张图的时间刻度。不要在同一张图的两侧各设一套数值刻度，因为读者难以判断每条线对应哪侧刻度，两条线的交点也没有实际含义。

柱状图的数值刻度从零开始，因为柱长代表数值。折线图着重展示变化时，数值轴可以从更高的值开始，并在图表的 `label` 中注明。

## 无障碍 \{#accessibility\}

- **图表是一个列表。** 每个数据点都是一个列表项，以其数值命名。无需脚本，屏幕阅读器就能读出“周四：新增 1,420，回访 820”。能看到图表的读者也可以用方向键逐个浏览同一批数据点。
- **图例由控件组成。** 每个图例项都是一个包裹实际复选框的标签，可用 Tab 键聚焦，用空格键切换选中状态。
- **数值提示便于查看。** 它会在指针下方、焦点所在处或手指触摸处显示，其中的每个数值都能在其他地方找到。如果精确数值是重点，就直接写出来：柱数较少时，设置 `values: true` 以显示数值，或在图表旁放一张[表格](/components/table)。
- **始终为颜色搭配文字标识。** 图例和数值提示都会显示数据系列的名称。
- **动画遵循读者的偏好。** 启用减少动态效果时，图表会直接以绘制完成的状态显示。

## 何时使用图表引擎 \{#engine\}

图表适合绘制几百个图形标记，每个标记都是读者可通过键盘访问的元素。遇到以下情况时，请使用图表引擎：

- 有数千个数据点，或数值以流式方式每秒更新多次；
- 需要在绘图区内缩放、平移或框选；
- 需要绘制组件不支持的图形，例如地图、网络图、树形结构图、K 线图、桑基图，或需要核密度估计的小提琴图、山脊图等。

使用 SVG 绘制的引擎可以在 `fill` 和 `stroke` 中直接使用主题令牌。使用 Canvas 绘制的引擎无法读取 CSS 自定义属性，而主题令牌使用 `light-dark()` 表示，因此需要在图表所在的位置解析每种颜色：在图表的根元素内放置一个隐藏的探测元素，将主题令牌设为它的颜色，再用该颜色绘制一个像素，即可读取 `rgba()` 格式的颜色值。配色方案或主题变化时，重新解析颜色，并继续遵循前述规则：使用统一的刻度，固定类别顺序，在图例中标明每个数据系列的名称，并以文本形式显示数值。

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```
