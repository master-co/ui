Master UI 自行繪製圖表。[圖表](/components/chart)元件以單一 SVG 搭配主題的 token 繪製二十多種圖表，從折線圖到旭日圖都有。每種圖表在[圖表總覽](/charts)都有專頁。另有較小的元件，可呈現單一數值、趨勢或占比。本指南說明如何選擇元件、如何用同一個期間選擇器連動多張圖表，以及何時適合使用圖表引擎。

## 如何選擇 \{#choose\}

先想讀者需要看出什麼，再選圖表形式。下列元件都能依據標記繪製，無須腳本即可套用主題，並以文字呈現數值。

| 讀者需要看出什麼 | 使用 |
| --- | --- |
| 數值如何隨時間變化 | [折線圖](/charts/line)，只有一到兩個資料序列時也可用[面積圖](/charts/area) |
| 兩個時間點之間，哪些項目上升、哪些下降 | [斜率圖](/charts/slope)；若要比較清單中各項目的兩個數值，使用[啞鈴圖](/charts/dumbbell) |
| 名次如何變動 | [排名變化圖](/charts/bump) |
| 各項數值的大小比較 | [長條圖](/charts/bar)；名稱較長時用[橫向長條圖](/charts/bar#across) |
| 一個數值如何增減成另一個數值 | [瀑布圖](/charts/waterfall) |
| 兩個數值之間的跨度 | [區間圖](/charts/range) |
| 各時間點或群組的總量由哪些部分組成 | [堆疊長條圖](/charts/bar#stacked)或[堆疊面積圖](/charts/area#stacked)；群組大小不一時使用[馬賽克圖](/charts/marimekko) |
| 整體由哪些部分組成 | 最多五個部分時用[圓環圖](/charts/donut)或[圓餅圖](/charts/pie)；以 1% 為單位時用[華夫格圖](/charts/waffle)；部分較多時用[樹狀矩形圖](/charts/treemap)；有兩個層級時用[旭日圖](/charts/sunburst)；要沿著單一長條呈現時，用[組成分布](/components/breakdown)元件 |
| 流程中有多少量到達各階段 | [漏斗圖](/charts/funnel) |
| 幾項目標各自的達成比例 | [多環圖](/charts/rings) |
| 幾個項目在相同指標上的表現 | [雷達圖](/charts/radar) |
| 量測值如何分布 | [直方圖](/charts/histogram)；同時比較多組分布時用[盒鬚圖](/charts/box) |
| 沿兩個尺度呈現的分布型態 | [熱圖](/charts/heatmap) |
| 兩項指標之間的關係 | [散佈圖](/charts/scatter)，用[氣泡大小](/charts/scatter#bubble)呈現第三項指標 |
| 單一數值及其變化 | [統計數值](/components/stat)元件 |
| 在句中或一列內呈現資料序列的走勢 | [迷你折線圖](/components/sparkline) |
| 單一量測值有多接近上限 | [儀表圖](/components/gauge)或[量值計](/components/meter) |
| 大量小數值的分布模式，且圖旁無須顯示刻度 | 由方格組成的[熱圖](/components/heatmap) |
| 按欄比較精確數值 | [表格](/components/table) |

用數字就能說清楚時，直接呈現數值即可。把統計數值和變化量放在一起，比畫兩根長條更容易讀懂。

## 儀表板範例 \{#dashboard\}

用同一個期間選擇器控制三項數值和三張圖表。切換期間時，所有項目都依同一批資料同步更新，讓數值與圖表始終一致。

<PagePreview name="dashboard" title="圖表儀表板" example="chart-dashboard" caption="選擇期間、將指標移到某一天，或透過圖例隱藏資料序列。" />

- **用一個控制項設定下方所有內容的資料範圍。** 把期間選擇器獨立成一列，放在數值與圖表上方，且不得放在卡片內。需要獨立期間的圖表應放到另一個檢視畫面。
- **用資料重新繪製圖表。** 在已有圖表的元素上呼叫 `chart(element, options)`，會取代原有圖表，並傳回可停止新圖表的函式。期間變更時，以所選期間的數值再次呼叫。
- **先呈現數值，再用圖表解釋。** 每張卡片的標題都說明顯示的內容。圖表的 `label` 也傳達同樣的資訊，並附上單位，讓看不到圖表的讀者也能理解。
- **讓每種圖表各司其職。** 堆疊面積圖呈現總量的變化與組成，圓環圖呈現目前的整體組成，長條圖呈現排名並直接標出數值，方便讀者比較名次背後的差距。

## 主題配色 \{#colors\}

只有一個資料序列時，圖表採用單色。讀者無須靠色相區分資料，圖表也能自然融入周圍的單色介面。

有多個資料序列時，每個序列各用一個[色彩類別](/components/category)。預設依固定順序分配藍色、橘色、藍綠色、紫色、琥珀色、粉紅色、綠色和天藍色。這個順序讓有常見色覺辨識障礙的讀者，在淺色與深色配置中也能區分相鄰的顏色。若同一項目需要在整個產品中沿用同一個顏色，請明確指定資料序列的 `category`。例如，東京無論排在哪個位置，在圖表、圖例、徽章和表格列中都用藍色。

- **隱藏資料序列時，其餘序列保留原色。** 某個序列從圖表中移除後，其他序列仍沿用各自的色彩類別。
- **色彩類別不代表狀態。** 成功、警告和危險表示項目的狀態。若某個資料序列表現不佳，請在[徽章](/components/badge)或圖表旁的句子中用文字說明。只有[瀑布圖](/charts/waterfall#inks)會使用狀態色，因為每個向上或向下的階梯都像統計數值的變化量一樣，代表帶有正負號的變動。
- **文字一律套用文字 token，不使用資料序列的顏色。** 在名稱與數值旁加上代表資料序列顏色的標記。長條或扇形用色塊，折線用線段。
- **同一色相的深淺變化只用來呈現單一指標。** 熱圖的方格、漏斗圖的各階段和旭日圖的外環，都以同一種顏色的不同強度呈現。
- **每個標記都會套用主題。** 標記使用色彩類別的 `--color-category-<name>-mark` token，單色繪圖使用 `--chart-color`。色彩配置、主題和限定在單一區域的覆寫都能直接生效，無須重新繪製。

## 單一尺度 \{#scale\}

每張圖表只用一個尺度。若要呈現尺度不同的兩項指標，例如以千人為單位的訪客數與以百分比表示的比率，請分成上下兩張圖表，對齊時間刻度。若把兩個尺度放在同一張圖的左右兩側，讀者難以判斷各條線對應哪一側，兩條線的交點也沒有意義。

長條圖的尺度從零開始，因為長條的長度代表數值。若折線圖著重呈現變化幅度，可以從較高的數值起算，並在圖表的 `label` 中說明。

## 無障礙 \{#accessibility\}

- **圖表以清單呈現。** 每個資料點都是一個以其數值命名的清單項目。即使沒有腳本，螢幕閱讀器也能讀出「週四：新訪客 1,420 人，回訪者 820 人」。看得到圖表的讀者也能用方向鍵逐一瀏覽相同的資料點。
- **圖例可操作。** 每個圖例項目都是包住原生核取方塊的標籤。按 Tab 可移入焦點，按空白鍵可切換勾選狀態。
- **數值提示方便快速查看。** 將指標移到資料點上、讓資料點取得焦點，或用手指觸碰資料點時，都會顯示提示。提示中的數值在其他地方也找得到。若重點是精確數值，請直接標示，例如用 `values: true` 在少量長條上顯示數值，或在圖表旁放一個[表格](/components/table)。
- **用文字輔助辨識色彩。** 圖例和數值提示都會顯示資料序列的名稱。
- **動畫遵循讀者偏好。** 啟用減少動態效果時，圖表會直接呈現繪製完成的狀態。

## 何時使用圖表引擎 \{#engine\}

圖表元件適合繪製幾百個標記，每個標記都是可透過鍵盤操作到的元素。遇到下列需求時，請改用圖表引擎：

- 有數千個資料點，或數值以串流方式每秒更新多次；
- 需要在繪圖區縮放、平移或框選；
- 需要元件未支援的圖表形式，例如地圖、網路圖、樹狀圖、K 線圖、桑基圖，或需要核密度估計的小提琴圖、山脊圖。

使用 SVG 繪圖的引擎可在 `fill` 和 `stroke` 中直接使用主題的 token。使用 Canvas 繪圖的引擎無法直接讀取 CSS 自訂屬性，而色彩 token 又以 `light-dark()` 定義，因此要在圖表所在的位置解析各個顏色。讓圖表根元素內的隱藏測試元素以 token 作為文字顏色，再用這個顏色繪製一個像素，即可取得 `rgba()` 色值。色彩配置或主題變更時，請重新解析，並遵循前述原則：每張圖只用一個尺度、依固定順序分配色彩類別、在圖例中標示每個資料序列的名稱，並以文字提供數值。

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```
