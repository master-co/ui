Master UI 自行繪製圖表。[圖表](/components/chart)是一個 SVG，以主題的 token 繪製折線圖、面積圖、長條圖、圓餅圖、環圈圖、圓環圖、雷達圖和散佈圖；每種類型在[圖表](/charts)單元中都有自己的頁面。它旁邊還有幾個較小的元件，用來呈現單一數字、趨勢或占比。本指南說明該選用哪一個，示範多個圖表如何在同一個期間選擇下協同運作，並說明何時改用圖表引擎更合適。

## 該選哪一個 \{#choose\}

從讀者需要看到什麼出發，而不是從形狀出發。以下每一種都由標記繪製，無須腳本就會跟隨主題，並以文字說出自己的數值。

| 讀者需要看到 | 使用 |
| --- | --- |
| 數值隨時間如何變化 | [折線圖](/charts/line)；只有一兩組序列時，也可用[面積圖](/charts/area) |
| 數量彼此之間的比較 | [長條圖](/charts/bar)；名稱較長時改用[橫向](/charts/bar#across)長條 |
| 總量由哪些部分組成，隨時間變化或跨群組比較 | [堆疊長條圖](/charts/bar#stacked)或[堆疊面積圖](/charts/area#stacked) |
| 一個整體由哪些部分組成 | [環圈圖](/charts/donut)或[圓餅圖](/charts/pie)，最多五個部分；沿著一條長條呈現時，使用[占比分布](/components/breakdown) |
| 少數幾個目標，各有自己的整體 | [圓環圖](/charts/rings) |
| 少數幾個對象在相同指標上的表現 | [雷達圖](/charts/radar) |
| 兩個指標互相對照 | [散佈圖](/charts/scatter) |
| 一個數字及其變化 | [統計數值](/components/stat) |
| 一組序列在句子或一列中的走向 | [迷你趨勢線](/components/sparkline) |
| 一個讀數，以及它離上限有多近 | [儀表](/components/gauge)或[量表](/components/meter) |
| 大量較小數值之間的規律 | [熱圖](/components/heatmap) |
| 精確的數字，分欄比較 | [表格](/components/table) |

一個數字就能說清楚時，就不要畫成圖：附帶變化量的統計數值，比畫著兩根長條的圖表更快讀懂。

## 儀表板 \{#dashboard\}

三個數字和三個圖表，位於同一個期間選擇之下。選擇期間時，所有內容會依相同的數字一起改變，因此數字所說的和圖表所呈現的永遠一致。

<PagePreview name="dashboard" title="圖表儀表板" example="chart-dashboard" caption="選擇期間、將指標移到某一天，或從圖例隱藏一組序列。" />

- **一個控制項統管其下的所有內容。** 期間位於數字和圖表上方的一列，絕不放在卡片裡。需要自己期間的圖表屬於另一個檢視。
- **圖表依資料重新寫出。** 對已有圖表的元素呼叫 `chart(element, options)` 會取代原本的圖表，而它傳回的函式可將圖表停止。期間改變時，會以該期間的數字呼叫它。
- **數字帶頭，圖表解釋。** 每張卡片以標題說明它呈現的內容；圖表的 `label` 也說明同樣的內容及單位，供看不到圖形的讀者使用。
- **每種類型只做一件事。** 堆疊面積圖呈現總量如何變化及其組成，環圈圖呈現目前整體由哪些部分組成，長條圖則呈現排名並寫出數值，因為排名要靠數字來讀。

## 來自主題的顏色 \{#colors\}

只有一組序列的圖表使用墨色。它不需要顏色就能閱讀，放在周圍單色的介面旁也不會搶走注意力。

多組序列各取一個[分類色](/components/category)。未另行指定時，圖表會依固定順序給色：藍色、橘色、藍綠色、紫羅蘭色、琥珀色、粉紅色、綠色和天藍色；在兩種色彩配置下，順序相鄰的顏色對常見的色覺辨認障礙類型而言都仍可區分。顏色要在整個產品中跟著某個對象走時，請自行為序列指定 `category`：不論 Tokyo 排在清單的哪個位置，它在圖表、圖例、徽章和表格的對應列中都是藍色。

- **隱藏一組序列不會讓其他序列換色。** 另一組序列離開圖表時，每組序列仍保留自己的分類色。
- **分類色不是狀態。** 成功、警告和危險說明某件事的狀況；出現問題的序列要用文字說明，例如在圖表旁放一個[徽章](/components/badge)或一句話。
- **文字絕不使用序列的顏色。** 名稱和數值採用文字 token，旁邊再放一個該顏色的色標：長條或扇形用色塊，折線用一道短線。
- **主題會套用到每個圖形。** 圖形讀取分類色的 `--color-category-<name>-mark` token，墨色讀取 `--chart-color`，因此色彩配置、主題，以及只作用於某個區域的覆寫都會生效，無須重新繪製任何東西。

## 單一刻度 \{#scale\}

一個圖表只有一個刻度。兩個大小不同的指標，例如以千計的訪客數和以百分比計的比率，應畫成上下排列、共用相同時間格的兩個圖表，絕不畫成兩側各有一個刻度的單一圖表：讀者分不出哪條折線屬於哪一側，兩條折線交叉的位置也沒有任何意義。

長條的刻度從零開始，因為長條的長度就是它的數值。若重點是變化而非數量，折線的刻度可以從較高的值開始；此時請在圖表的 `label` 中說明。

## 無障礙 \{#accessibility\}

- **圖表是一份清單。** 每個資料點都是以其數值命名的清單項目，因此無須腳本，螢幕閱讀器就會讀出「Thu: New 1,420, Returning 820」；看得見圖表的讀者也能用方向鍵走過相同的資料點。
- **圖例是控制項。** 每個項目都是包住真正核取方塊的 label，可用 Tab 移到項目上，再按 Space 切換。
- **數值提示是一種便利功能。** 它會在指標懸停、取得焦點和手指觸碰時出現，絕不包含其他地方沒有的數值。若重點是精確的數字，請把它們寫出來：在少數幾根長條上使用 `values: true`，或在圖表旁放一個[表格](/components/table)。
- **顏色絕不單獨傳達資訊。** 序列的名稱會列在圖例中，也會出現在數值提示裡。
- **動態效果配合讀者。** 啟用減少動態效果時，圖表出現時就已畫好。

## 何時改用引擎 \{#engine\}

圖表是為數百個圖形而繪製的，每個圖形都是讀者能用按鍵到達的元素。資料超出這個範圍時，請改用圖表引擎：

- 數千個資料點，或每秒串流進來許多次的數值；
- 在繪圖區上縮放、平移或範圍刷選；
- 圖表不繪製的形狀，例如地圖、網路圖或 K 線圖。

以 SVG 繪圖的引擎可直接在 `fill` 和 `stroke` 中使用主題的 token。在 canvas 上繪圖的引擎無法讀取自訂屬性，而且 token 是以 `light-dark()` 寫成的，因此請在圖表所在的位置解析每個顏色：在圖表的根元素內放一個隱藏的探針，以該 token 作為它的顏色，再用這個顏色畫一個像素，就能以 `rgba()` 取得該顏色。色彩配置或主題改變時要重新解析，並遵守上述相同的規則：單一刻度、依固定順序給出的分類色、為每組序列命名的圖例，以及以文字呈現的數字。

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```
