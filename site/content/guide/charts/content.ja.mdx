Master UI はチャートを自前で描画します。[チャート](/components/chart)は 1 つの SVG で、折れ線、面、棒、円グラフ、ドーナツグラフ、リング、レーダーチャート、散布図をテーマのトークンで描画します。それぞれの種類には、[チャート](/charts)セクションに専用のページがあります。その横には、1 つの数値、推移、割合を示すための、より小さなコンポーネントがあります。このガイドでは、どれを使うべきかを説明し、1 つの期間選択の下で複数のチャートが連動する例を示し、チャートエンジンのほうが適している場合を説明します。

## どれを使うか \{#choose\}

形から考えるのではなく、読み手が何を見る必要があるかから考えます。以下はいずれもマークアップから描画され、スクリプトなしでテーマに従い、数値を言葉で伝えます。

| 読み手が見る必要があるもの | 使うもの |
| --- | --- |
| 時間に沿って値がどう推移するか | [折れ線グラフ](/charts/line)。系列が 1 つか 2 つなら[面グラフ](/charts/area) |
| 量どうしの比較 | [棒グラフ](/charts/bar)。名前が長い場合は[横向き](/charts/bar#across) |
| 合計が何で構成されているか（時間に沿って、またはグループごとに） | [積み上げ棒グラフ](/charts/bar#stacked)または[積み上げ面グラフ](/charts/area#stacked) |
| 1 つの全体が何で構成されているか | 部分が 5 つまでの[ドーナツグラフ](/charts/donut)または[円グラフ](/charts/pie)。1 本のバーに沿って示すなら[内訳](/components/breakdown) |
| それぞれが独自の全体を持つ、少数の目標 | [リング](/charts/rings) |
| 同じ指標で見る、少数の対象 | [レーダーチャート](/charts/radar) |
| 2 つの指標の対比 | [散布図](/charts/scatter) |
| 1 つの数値と、その変化 | [統計指標](/components/stat) |
| 文中や行の中で、系列がどちらへ向かったか | [スパークライン](/components/sparkline) |
| 1 つの測定値と、それが上限にどれだけ近いか | [ゲージ](/components/gauge)または[メーター](/components/meter) |
| 多数の小さな値にまたがるパターン | [ヒートマップ](/components/heatmap) |
| 列で比較する正確な数値 | [テーブル](/components/table) |

数値で伝わるなら、チャートは描画しません。変化量を添えた統計指標は、2 本の棒のチャートより速く読めます。

## ダッシュボード \{#dashboard\}

1 つの期間選択の下に、3 つの数値と 3 つのチャートを置きます。期間を選ぶと、同じ数値からすべてが一緒に変わるため、数値が伝える内容とチャートが示す内容は常に一致します。

<PagePreview name="dashboard" title="チャートのダッシュボード" example="chart-dashboard" caption="期間を選んだり、日にポインターを重ねたり、凡例から系列を非表示にしたりできます。" />

- **1 つのコントロールが、その下にあるすべての範囲を決めます。** 期間は数値とチャートの上の 1 行に置き、カードの中には置きません。独自の期間が必要なチャートは、別のビューに属します。
- **チャートはデータから書き直します。** すでにチャートを持つ要素に `chart(element, options)` を呼び出すとチャートが置き換わり、戻り値の関数でそのチャートを停止できます。期間が変わると、その期間の数値でこの関数を呼び出します。
- **数値が主役で、チャートが補足します。** 各カードは何を示すかをタイトルで伝え、チャートの `label` は、描画を見ない読み手に向けて同じ内容を単位とともに伝えます。
- **それぞれの種類が 1 つの役割を担います。** 積み上げ面グラフは合計の推移とその構成を、ドーナツグラフは現在の全体の構成を、棒グラフは値を書き出したランキングを示します。ランキングは数値で読まれるためです。

## テーマから取得する色 \{#colors\}

系列が 1 つのチャートはインク色で描画します。色がなくても読み取れ、周囲のモノクロのインターフェースの横に、注意を引くことなく並びます。

複数の系列には、それぞれ[カテゴリ](/components/category)を 1 つずつ割り当てます。指定しなければ、チャートは blue、orange、teal、violet、amber、pink、green、sky の固定の順序で割り当てます。この順序で隣り合う色は、どちらの配色でも、一般的な色覚特性で見分けられるように離してあります。色がプロダクト全体を通じて 1 つの対象に結び付く場合は、系列の `category` を自分で指定します。Tokyo は、一覧のどこにあっても、チャートでも、凡例でも、バッジでも、テーブルの行でも青になります。

- **系列を非表示にしても、ほかの系列の色は変わりません。** 別の系列がチャートから外れても、各系列は自分のカテゴリを保ちます。
- **カテゴリはステータスではありません。** 成功、警告、危険は物事の状態を伝えます。失敗している系列は、チャートの横の[バッジ](/components/badge)や文で、そのことを言葉で伝えます。
- **テキストを系列の色にすることはありません。** 名前と値にはテキストのトークンを使い、その横にその色のマークを置きます。棒やスライスにはブロック、折れ線には短い線です。
- **テーマはすべてのマークに届きます。** マークはカテゴリの `--color-category-<name>-mark` トークンを、インク色は `--chart-color` を読み取るため、配色、テーマ、1 つの領域に限定した上書きのすべてが反映され、何も描き直す必要はありません。

## 1 つのスケール \{#scale\}

チャートのスケールは 1 つです。規模の異なる 2 つの指標、たとえば千単位の訪問者数とパーセントで示す割合は、同じ時間の区切りで上下に並べた 2 つのチャートにします。左右にスケールを 1 つずつ持つ 1 つのチャートにはしません。読み手はどの線がどちら側のスケールに属するかを判別できず、2 本の線が交差する位置にも意味がないためです。

棒のスケールはゼロから始めます。棒の長さがその値を表すためです。量ではなく変化が要点である場合、折れ線はゼロより上から始めてもかまいません。その場合は、チャートの `label` でそのことを伝えます。

## アクセシビリティ \{#accessibility\}

- **チャートはリストです。** 各ポイントは値を含む名前を持つリスト項目なので、スクリプトなしでもスクリーンリーダーは「Thu: New 1,420, Returning 820」のように読み上げます。目で見る読み手は、矢印キーで同じポイントをたどれます。
- **凡例はコントロールです。** 各項目は本物のチェックボックスを囲むラベルで、Tab キーで移動し、Space キーで切り替えます。
- **値表示は補助的なものです。** ポインターを重ねたとき、フォーカスしたとき、指で触れたときに表示され、ほかのどこにもない値を表示することはありません。正確な数値こそが要点である場合は、数値を書き出します。少数の棒なら `values: true` を指定するか、チャートの横に[テーブル](/components/table)を置きます。
- **色だけに頼りません。** 系列の名前は凡例と値表示に示されます。
- **動きは読み手の設定に従います。** 動きを抑える設定では、チャートは描画済みの状態で表示されます。

## エンジンを使う場合 \{#engine\}

チャートは数百個のマークを想定して描画され、各マークは読み手がキー操作で到達できる要素です。データがその規模を超える場合は、チャートエンジンを使います。

- 数千個のポイントがある場合や、1 秒に何度も値が流れ込む場合
- プロット上でズーム、パン、ブラシ選択を行う場合
- 地図、ネットワーク図、ローソク足など、チャートが描画しない形の場合

SVG に描画するエンジンは、テーマのトークンを `fill` と `stroke` にそのまま使えます。canvas に描画するエンジンはカスタムプロパティを読み取れず、トークンは `light-dark()` で書かれているため、チャートを置いた場所で各色を解決します。チャートのルート内に隠したプローブ要素の色にトークンを指定し、その色で 1 ピクセルを描画すると、色を `rgba()` として取得できます。配色やテーマが変わったときは色を解決し直し、上記と同じ規則を守ります。スケールは 1 つにし、カテゴリは固定の順序で使い、凡例ですべての系列の名前を示し、数値はテキストで伝えます。

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```
