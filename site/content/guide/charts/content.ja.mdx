Master UI は、いくつかの数値ならスクリプトなしで自ら描画します。少数の棒、文中の傾向、ダイヤル、1 本のバーの中の割合などです。軸の目盛りを調整する必要があるチャート、点が多いチャート、ポインターの下にツールチップを表示するチャート、レーダーのような形のチャートは、チャートエンジンの仕事です。このガイドでは、エンジンの 1 つである [Chart.js](https://www.chartjs.org/docs/latest/getting-started/integration.html) を Master UI の色で描画し、操作できる凡例と同じ数値を示すテーブルを添えます。また、テーマとの同期を保つ方法と、不要になったときに破棄する方法を示します。

これらの例で Chart.js に依存しているのはこのサイトであり、ライブラリーではありません。`@master/ui` は Chart.js に依存しておらず、canvas や SVG に描画するエンジンであれば、どれでも同じように組み込めます。

## ライブラリーのチャートか、エンジンか \{#choose\}

まずはコンポーネントを検討します。各コンポーネントはマークアップから描画するため、数値がテキストとしてページに含まれ、スクリプトなしでテーマに従い、印刷もできます。

| 必要なもの | 使うもの |
| --- | --- |
| 1 週間の曜日のように、1 つの目盛り上の少数の数値 | [チャート](/components/chart) |
| 数値の横や行の中で、系列がどう推移したか | [スパークライン](/components/sparkline) |
| 1 つの測定値と、それが上限にどれだけ近いか | [ゲージ](/components/gauge)、または[半円の進捗リング](/components/progress#half-ring) |
| 既知の範囲の中で、ある量がどこにあるか | [メーター](/components/meter) |
| 合計が何で構成されているか（1 本のバーで表示） | [内訳](/components/breakdown) |
| 多数の小さな値に見られるパターン | [ヒートマップ](/components/heatmap) |

エンジンを読み込む価値があるのは、軸の目盛りをデータに合わせて調整する必要がある場合、ラベルより点が多い場合、読み手がポインターで値を探る場合、系列を表示したり隠したりする場合、またはコンポーネントでは描画できない形の場合です。たとえば、数か月にわたる折れ線、ドーナツ、リング、レーダーです。以下の例では、Chart.js をそれぞれのプレビューの中でだけ読み込み（1 つあたり約 160 KB）、各チャートが描画する部品だけを登録しています。

## 折れ線と棒 \{#lines-and-bars\}

時間の経過に沿った複数の系列を、折れ線または棒で表示します。切り替えると、同じデータをもう一方の形で描画します。凡例で地域を表示したり隠したりでき、チャートの下のテーブルにはすべての数値が含まれています。

<PagePreview name="series" title="折れ線と棒" example="chart-series" caption="棒に切り替えたり、凡例から地域を隠したり、数値を開いたりできます。" />

- **描画するものだけを登録します。** `chart.js/auto` ではなく `chart.js` から `Chart.register(LineController, LineElement, PointElement, BarController, BarElement, CategoryScale, LinearScale, Tooltip)` を呼び出すと、エンジンの残りの部分はバンドルに含まれません。
- **マークは細くします。** 折れ線は 2px で、点はポインターの下にだけ表示します。棒は軸から離れた側の端が丸く、隣の棒とは面の色のリングで区切られます。グリッドは横方向の極細線だけで、縦線はありません。
- **軸は 1 つです。** 目盛りの異なる 2 つの指標は 2 つのチャートにします。左右に軸を 1 つずつ持つ 1 つのチャートにはしません。

## 全体に対する割合 \{#parts-of-a-whole\}

割合をドーナツまたは円で、3 つの目標を同心円のリングで表示します。各リングは、同じ色の淡い色調のトラックの上で、その色で塗りつぶされます。

<PagePreview name="parts" title="全体に対する割合" example="chart-parts" caption="円に切り替えたり、種類や目標を隠したり、数値を開いたりできます。" />

凡例のチップで部分を隠すとその扇形が消え、ほかの扇形が詰まります。リングのトラックはカテゴリーの面の色なので、残りの部分も同じ目標として、控えめに読み取れます。全体を構成する部分は 4〜5 個にとどめ、ストレージの例のように、残りは「Other」にまとめます。

## レーダー \{#radar\}

2 つのリリースを 6 つの指標で比較します。各形状は、そのマークの色と同じ色の淡い塗りで描画されるため、2 つの形状が互いに透けて見えます。

<PagePreview name="radar" title="レーダー" example="chart-radar" caption="凡例からリリースを隠したり、数値を開いたりできます。" />

レーダーは、少数の対象を同じ指標でひと目で比較するためのものです。スコアはテーブルで伝えます。指標はすべて同じ範囲を共有します。ここでは 0 から 100 です。

## テーマから取得する色 \{#colors\}

各系列は[カテゴリー](/components/category)を名前で指定し、色はカテゴリーが決めます。Tokyo は、一覧のどこにあっても、チャートでも凡例のチップでも、その名前を示すどのバッジでも青になります。マークにはカテゴリーの `-mark` の役割を使い、面に対して 3:1 のコントラストを保ちます。レーダーの淡い塗りも同じマークの色を薄くしたものです。グリッド、目盛り、ツールチップには、テーマの線、テキスト、インクのトークンを使います。データに含めるのはカテゴリー名で、色は含めません。

canvas はカスタムプロパティを読み取れず、トークンは `light-dark()` で書かれているため、各例はチャートを置いた場所で色を解決します。チャートのルート内に隠したプローブ要素の色にトークンを指定し、その色で 1 ピクセルを描画すると、色を `rgba()` として取得できます。プローブはチャートと同じ場所にあるため、Paper も、特定の領域に限定した上書きも、カラースキームも反映されます。

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```

例では 4 つのカテゴリーを、青、オレンジ、ティール、バイオレットの固定の順序で使います。パレットとして検証すると、どちらのカラースキームでも、一般的な色覚特性で互いに見分けられます。5 つ目の系列は「Other」にまとめるか、別のチャートで表示し、4 色のいずれかに近すぎる色相を割り当てることはしません。

## アクセシビリティ \{#accessibility\}

- **凡例はコントロールです。** 各項目は本物のチェックボックスを囲む[フィルターチップ](/components/chip#category)で、何を表示するかを名前にしたグループに入れます。そのため Tab キーで移動でき、Space キーで切り替えられます。ドットがカテゴリーを示し、文言が名前を示します。
- **数値はテキストです。** 各チャートには、同じ値を示すテーブルを開閉式の領域に用意し、canvas には `role="img"` と、チャートが何を示すかを伝える 1 文を付けます。ポインターの下のツールチップは補助的なもので、値を読み取る唯一の方法にはしません。
- **色だけに頼りません。** 系列は凡例とテーブルで名前を示し、ステータスの色を系列に使うことはしません。
- **動きは読み手の設定に従います。** 動きを抑える設定では、チャートを滑らかに描画せず、すぐに表示します。

## 同期を保ち、破棄する \{#lifecycle\}

各例の `main.js` は `mount(root)` をエクスポートします。この関数はチャートを描画し、チャートを停止する関数を返します。

- **サイズ。** canvas は、スタイルシートが高さを設定したコンテナーの中に置きます。Chart.js は `responsive` と `maintainAspectRatio: false` により、そのコンテナーの幅に追従します。配置のために寸法を計測することはありません。
- **テーマ。** 読み手のカラースキームが変わったとき、またはルート要素のクラス、スタイル、`data-theme` が変わったときは、色を解決し直してチャートを再描画します。
- **終了。** アンマウントすると各チャートの `destroy()` を呼び出し、すべてのリスナーとオブザーバーを削除します。そのため、ビューが閉じても、その中のチャートが何かを残すことはありません。フレームワークでは、要素が存在するときに `mount` を呼び出し、要素がなくなるときにその戻り値を呼び出します。React ではエフェクトのクリーンアップ、Svelte ではアタッチメント、Vue では `onBeforeUnmount` です。
