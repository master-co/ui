Master UI는 차트를 직접 그립니다. [차트](/components/chart)는 테마의 토큰으로 선, 영역, 막대, 파이, 도넛, 링, 레이더, 산점도를 그리는 SVG 하나이며, 각 형식에는 [차트](/charts) 섹션에 전용 페이지가 있습니다. 그 곁에는 수치 하나, 추세, 비율을 위한 더 작은 컴포넌트가 있습니다. 이 가이드에서는 무엇을 사용할지 설명하고, 하나의 기간 선택 아래에서 여러 차트가 함께 동작하는 모습을 보여 주며, 차트 엔진이 더 나은 도구인 경우를 설명합니다.

## 무엇을 사용할지 \{#choose\}

모양이 아니라 독자가 봐야 하는 것에서 출발하세요. 아래의 모든 컴포넌트는 마크업으로 그리고, 스크립트 없이 테마를 따르며, 수치를 글로 알려 줍니다.

| 독자가 봐야 하는 것 | 사용할 것 |
| --- | --- |
| 시간에 따라 값이 어떻게 이어지는지 | [선 차트](/charts/line), 계열이 한두 개라면 [영역 차트](/charts/area) |
| 서로 비교되는 양 | [막대 차트](/charts/bar), 이름이 길면 [가로 막대](/charts/bar#across) |
| 시간에 따라 또는 그룹별로 합계가 무엇으로 이루어지는지 | [누적 막대](/charts/bar#stacked) 또는 [누적 영역](/charts/area#stacked) |
| 하나의 전체가 무엇으로 이루어지는지 | 부분이 다섯 개 이하인 [도넛 차트](/charts/donut) 또는 [파이 차트](/charts/pie). 막대 하나를 따라 나타내려면 [구성 내역](/components/breakdown) |
| 각자 고유한 전체를 가진 몇 가지 목표 | [링](/charts/rings) |
| 같은 지표로 본 몇 가지 대상 | [레이더 차트](/charts/radar) |
| 서로 대비되는 두 지표 | [산점도](/charts/scatter) |
| 수치 하나와 그 변화 | [지표](/components/stat) |
| 문장이나 행 안에서 계열이 어느 방향으로 움직였는지 | [스파크라인](/components/sparkline) |
| 측정값 하나와 그 값이 한계에 얼마나 가까운지 | [게이지](/components/gauge) 또는 [미터](/components/meter) |
| 많은 작은 값에 걸친 패턴 | [히트맵](/components/heatmap) |
| 열로 나란히 비교하는 정확한 수치 | [표](/components/table) |

수치 하나로 전달된다면 그리지 마세요. 변화량을 함께 보여 주는 지표가 막대 두 개짜리 차트보다 빨리 읽힙니다.

## 대시보드 \{#dashboard\}

하나의 기간 선택 아래에 수치 세 개와 차트 세 개가 놓입니다. 기간을 고르면 같은 숫자에서 모두가 함께 바뀌므로, 수치가 말하는 내용과 차트가 보여 주는 내용이 항상 일치합니다.

<PagePreview name="dashboard" title="차트 대시보드" example="chart-dashboard" caption="기간을 고르거나, 하루에 포인터를 올리거나, 범례에서 계열을 숨겨 보세요." />

- **컨트롤 하나가 그 아래의 모든 것에 적용됩니다.** 기간은 카드 안이 아니라 수치와 차트 위의 한 행에 놓입니다. 고유한 기간이 필요한 차트는 다른 화면에 속합니다.
- **차트는 데이터로부터 다시 작성합니다.** 이미 차트가 들어 있는 요소에 `chart(element, options)`를 호출하면 차트가 교체되고, 반환된 함수는 차트를 중지합니다. 기간이 바뀌면 그 기간의 숫자로 차트를 다시 작성합니다.
- **수치가 앞서고 차트가 설명합니다.** 각 카드는 제목에서 보여 주는 내용을 밝히고, 차트의 `label`은 그림을 보지 않는 독자를 위해 같은 내용을 단위와 함께 알려 줍니다.
- **각 형식은 한 가지 일을 합니다.** 누적 영역은 합계가 어떻게 움직였고 무엇으로 이루어졌는지를, 도넛은 지금 전체가 무엇으로 이루어지는지를, 막대는 값을 적은 순위를 보여 줍니다. 순위는 숫자로 읽기 때문입니다.

## 테마의 색상 \{#colors\}

계열이 하나인 차트는 잉크색입니다. 읽는 데 색상이 필요하지 않으며, 주변의 단색 인터페이스 옆에서 주의를 끌지 않고 자리합니다.

계열이 여러 개이면 각 계열에 [카테고리](/components/category)가 하나씩 배정됩니다. 따로 지정하지 않으면 차트는 파랑, 주황, 청록, 보라, 호박색, 분홍, 초록, 하늘색의 정해진 순서로 카테고리를 배정하며, 이 순서에서 이웃한 색은 두 색 구성표 모두에서 흔한 유형의 색각 이상에도 서로 구별됩니다. 제품 전체에서 색상이 대상을 따라다녀야 할 때는 계열의 `category`를 직접 지정하세요. Tokyo는 목록에서 어느 자리에 있든 차트에서도, 범례에서도, 배지에서도, 표의 해당 행에서도 파란색입니다.

- **계열을 숨겨도 다른 계열의 색은 바뀌지 않습니다.** 다른 계열이 차트에서 빠져도 각 계열은 자신의 카테고리를 유지합니다.
- **카테고리는 상태가 아닙니다.** 성공, 경고, 위험은 무언가의 상태를 알립니다. 실패하고 있는 계열은 차트 옆의 [배지](/components/badge)나 문장으로 그 사실을 글로 알립니다.
- **텍스트는 절대 계열의 색으로 쓰지 않습니다.** 이름과 값은 텍스트 토큰을 사용하고, 그 옆에 해당 색의 표시 요소를 둡니다. 막대나 조각에는 블록을, 선에는 획을 둡니다.
- **테마는 모든 표시 요소에 적용됩니다.** 표시 요소는 카테고리의 `--color-category-<name>-mark` 토큰을, 잉크는 `--chart-color`를 읽으므로 색 구성표, 테마, 한 영역에 한정된 재정의가 모두 적용되며 아무것도 다시 그리지 않습니다.

## 하나의 눈금 \{#scale\}

차트의 눈금은 하나입니다. 천 단위의 방문자 수와 백분율로 나타낸 비율처럼 크기가 다른 두 측정값은 양쪽에 눈금이 하나씩 있는 차트 하나가 아니라, 같은 시간 단계를 공유하며 위아래로 놓인 차트 두 개로 나타냅니다. 독자는 어느 선이 어느 쪽 눈금에 속하는지 알 수 없고, 두 선이 교차하는 지점은 아무 의미가 없기 때문입니다.

막대의 길이가 곧 값이므로 막대의 눈금은 0에서 시작합니다. 양이 아니라 변화가 요점일 때는 선의 눈금이 더 높은 값에서 시작해도 됩니다. 이때는 차트의 `label`에 그 사실을 밝히세요.

## 접근성 \{#accessibility\}

- **차트는 목록입니다.** 각 지점은 자신의 값을 이름으로 가진 목록 항목이므로, 스크린 리더는 스크립트 없이 "Thu: New 1,420, Returning 820"이라고 읽습니다. 눈으로 보는 독자는 방향키로 같은 지점을 차례로 이동합니다.
- **범례는 컨트롤입니다.** 각 항목은 실제 체크박스를 감싼 레이블이므로 Tab으로 이동하고 Space로 전환합니다.
- **값 표시창은 편의 기능입니다.** 포인터를 올리거나 포커스를 받거나 손가락을 댈 때 나타나며, 다른 곳에 없는 값을 담지 않습니다. 정확한 수치가 요점이라면 수치를 적으세요. 막대가 몇 개뿐이라면 `values: true`를 지정하고, 그렇지 않다면 차트 옆에 [표](/components/table)를 두세요.
- **색상은 절대 단독으로 쓰이지 않습니다.** 계열의 이름은 범례와 값 표시창에 표시됩니다.
- **모션은 독자의 설정을 따릅니다.** 동작 줄이기 설정에서는 차트가 이미 그려진 상태로 나타납니다.

## 차트 엔진을 사용할 때 \{#engine\}

차트는 표시 요소 수백 개를 그리도록 만들어졌으며, 각 표시 요소는 독자가 키로 접근할 수 있는 요소입니다. 데이터가 그 범위를 넘어서면 차트 엔진을 사용하세요.

- 수천 개의 지점, 또는 초당 여러 번 들어오는 값
- 그래프 영역의 확대·축소, 이동, 브러시
- 지도, 네트워크, 캔들스틱처럼 차트가 그리지 않는 모양

SVG로 그리는 엔진은 테마의 토큰을 `fill`과 `stroke`에 그대로 사용할 수 있습니다. 캔버스에 그리는 엔진은 사용자 지정 속성을 읽을 수 없고 토큰은 `light-dark()`로 작성되어 있으므로, 차트가 놓인 위치에서 각 색상의 실제 값을 구하세요. 차트 루트 안의 숨겨진 프로브 요소가 토큰을 색상으로 받고, 그 색으로 칠한 픽셀 하나에서 `rgba()` 색상을 얻습니다. 색 구성표나 테마가 바뀌면 색상을 다시 구하고, 위와 같은 규칙을 지키세요. 눈금은 하나만 쓰고, 카테고리는 정해진 순서로 배정하며, 범례에서 모든 계열의 이름을 밝히고, 수치는 텍스트로 제공합니다.

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```
