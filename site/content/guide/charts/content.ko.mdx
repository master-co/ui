Master UI는 차트를 직접 그립니다. [차트](/components/chart) 컴포넌트는 하나의 SVG에서 테마 토큰을 사용해 선 차트부터 선버스트 차트까지 20가지가 넘는 형태를 그립니다. 각 형태는 [차트 목록](/charts)에서 확인할 수 있습니다. 단일 수치, 추세, 비중을 보여 주는 데는 더 작은 컴포넌트도 있습니다. 이 가이드에서는 목적에 맞는 컴포넌트를 고르는 법, 하나의 기간 선택으로 여러 차트를 함께 제어하는 법, 차트 엔진이 더 적합한 경우를 설명합니다.

## 차트 선택 \{#choose\}

독자가 무엇을 파악해야 하는지부터 생각합니다. 아래 컴포넌트는 모두 마크업을 바탕으로 그려지고, 스크립트 없이 테마를 따르며, 수치를 텍스트로 전달합니다.

| 독자가 파악해야 할 내용 | 사용할 차트 |
| --- | --- |
| 시간에 따른 값의 변화 | [꺾은선 차트](/charts/line), 또는 계열이 한두 개일 때 [영역 차트](/charts/area) |
| 두 시점 사이에 어떤 값이 오르고 내렸는지 | [기울기 차트](/charts/slope). 목록의 각 항목에 값이 두 개씩 있으면 [덤벨 차트](/charts/dumbbell) |
| 순위의 변화 | [순위 변화 차트](/charts/bump) |
| 여러 값의 크기 비교 | [막대 차트](/charts/bar). 이름이 길면 [가로 막대 차트](/charts/bar#across) |
| 한 수치가 다른 수치로 바뀌는 과정 | [폭포 차트](/charts/waterfall) |
| 두 값 사이의 범위 | [범위 차트](/charts/range) |
| 시간이나 그룹에 따른 합계의 구성 | [누적 막대 차트](/charts/bar#stacked) 또는 [누적 영역 차트](/charts/area#stacked). 그룹마다 크기가 다르면 [마리메코 차트](/charts/marimekko) |
| 하나의 전체를 이루는 구성 | 항목이 최대 5개면 [도넛 차트](/charts/donut) 또는 [원형 차트](/charts/pie). 1% 단위로 표시하려면 [와플 차트](/charts/waffle), 항목이 많으면 [트리맵](/charts/treemap), 계층이 두 단계면 [선버스트 차트](/charts/sunburst), 막대 하나로 표시하려면 [구성 내역](/components/breakdown) |
| 각 단계까지 도달하는 양 | [퍼널 차트](/charts/funnel) |
| 각각의 목표치를 기준으로 본 몇 가지 목표의 달성 정도 | [링 차트](/charts/rings) |
| 같은 지표를 기준으로 여러 항목 비교 | [레이더 차트](/charts/radar) |
| 관측값의 분포 | [히스토그램](/charts/histogram). 여러 그룹을 한꺼번에 비교하려면 [상자 수염 그림](/charts/box) |
| 두 축에 걸친 패턴 | [히트맵](/charts/heatmap) |
| 두 지표의 관계 | [산점도](/charts/scatter). 세 번째 지표까지 표시하려면 [버블](/charts/scatter#bubble) 사용 |
| 단일 수치와 그 변화 | [통계 컴포넌트](/components/stat) |
| 문장이나 표의 행에서 보는 계열의 추세 | [스파크라인](/components/sparkline) |
| 단일 측정값과 한계값까지의 거리 | [게이지](/components/gauge) 또는 [미터](/components/meter) |
| 축 표시 없이 여러 작은 값에서 드러나는 패턴 | 셀로 구성된 [히트맵](/components/heatmap) |
| 열별로 비교하는 정확한 수치 | [표](/components/table) |

수치만으로 충분하면 그대로 표시합니다. 수치와 변화량을 함께 보여 주는 통계 컴포넌트는 막대 두 개를 비교하는 차트보다 빠르게 읽을 수 있습니다.

## 대시보드 \{#dashboard\}

하나의 기간 선택으로 수치 세 개와 차트 세 개를 제어합니다. 기간을 선택하면 모두 같은 데이터를 바탕으로 함께 갱신되므로 표시된 수치와 차트가 항상 일치합니다.

<PagePreview name="dashboard" title="차트 대시보드" example="chart-dashboard" caption="기간을 선택하거나, 날짜 위에 포인터를 올리거나, 범례에서 계열을 숨깁니다." />

- **하나의 컨트롤이 아래의 모든 항목을 제어합니다.** 기간 컨트롤은 수치와 차트 위에 별도의 행으로 배치합니다. 카드 안에는 넣지 않습니다. 별도의 기간이 필요한 차트는 다른 뷰에 배치합니다.
- **차트는 데이터로 다시 그립니다.** 이미 차트가 있는 요소에 `chart(element, options)`를 호출하면 기존 차트를 교체합니다. 반환된 함수를 호출하면 차트 동작을 중지합니다. 기간이 바뀌면 선택한 기간의 데이터로 차트를 다시 그립니다.
- **수치를 먼저 보여 주고 차트로 설명합니다.** 각 카드의 제목은 카드가 보여 주는 내용을 나타냅니다. 차트의 `label`에도 같은 내용을 단위와 함께 적어 차트를 볼 수 없는 독자에게 전달합니다.
- **차트마다 한 가지 역할을 맡깁니다.** 누적 영역 차트는 합계의 변화와 구성을, 도넛 차트는 현재 전체의 구성을 보여 줍니다. 막대 차트는 순위와 각 값을 함께 표시합니다. 순위를 읽을 때는 각 항목의 수치도 중요하기 때문입니다.

## 테마 색상 \{#colors\}

계열이 하나인 차트는 기본 전경색으로 그립니다. 색으로 구분할 필요가 없어 주변의 단색 인터페이스와 자연스럽게 어울립니다.

여러 계열에는 각각 [카테고리](/components/category)를 지정합니다. 기본적으로 차트는 파랑, 주황, 청록, 보라, 호박색, 분홍, 초록, 하늘색 순서로 카테고리를 배정합니다. 두 색상 모드 모두에서 일반적인 색각 이상이 있어도 이웃한 색을 구분할 수 있도록 정한 순서입니다. 제품 전반에서 같은 항목에 같은 색을 쓰려면 계열의 `category`를 직접 지정합니다. 예를 들어 도쿄는 목록의 순서가 바뀌어도 차트, 범례, 배지, 표의 행에서 모두 파란색으로 표시합니다.

- **계열을 숨겨도 다른 계열의 색은 유지됩니다.** 차트에서 다른 계열이 빠져도 각 계열은 기존 카테고리를 유지합니다.
- **카테고리 색상은 계열을 구분합니다.** 성공, 경고, 위험은 항목의 상태를 나타냅니다. 문제가 있는 계열은 차트 옆의 [배지](/components/badge)나 문장으로 그 상태를 표시합니다. 상태 색상을 사용하는 형태는 [폭포 차트](/charts/waterfall#inks)뿐입니다. 통계 컴포넌트의 변화량과 마찬가지로 각 단계의 증가와 감소에 부호가 있기 때문입니다.
- **텍스트에는 텍스트 색상을 사용합니다.** 이름과 값에는 텍스트 토큰을 적용하고, 옆에 계열 색상으로 표식을 둡니다. 막대나 조각에는 사각형을, 선에는 짧은 선을 사용합니다.
- **한 지표의 값 차이는 같은 색의 농도로 나타냅니다.** 히트맵의 셀, 퍼널의 단계, 선버스트의 바깥쪽 링에는 한 가지 색을 농도만 달리해 적용합니다.
- **모든 표식에 테마가 적용됩니다.** 표식은 카테고리의 `--color-category-<name>-mark` 토큰을 사용하고 기본 전경색은 `--chart-color`를 사용합니다. 따라서 차트를 다시 그리지 않아도 색상 모드, 테마, 특정 영역에만 지정한 재정의가 모두 적용됩니다.

## 단일 눈금 \{#scale\}

차트 하나에는 값의 눈금을 하나만 사용합니다. 방문자 수(천 명 단위)와 비율(%)처럼 단위와 크기가 다른 두 지표는 같은 시간 간격을 사용하는 차트 두 개로 나누어 위아래로 배치합니다. 한 차트의 양쪽에 눈금을 두면 각 선이 어느 쪽 눈금에 해당하는지 알아보기 어렵고, 두 선의 교차점에도 의미가 없습니다.

막대의 길이가 값의 크기를 나타내므로 막대 차트의 눈금은 0에서 시작합니다. 변화에 초점을 맞춘 선 차트는 눈금을 더 높은 값에서 시작할 수 있습니다. 이 경우 차트의 `label`에 시작점을 명시합니다.

## 접근성 \{#accessibility\}

- **차트는 목록으로도 제공됩니다.** 각 데이터 점은 해당 값이 이름에 포함된 목록 항목입니다. 스크린 리더는 스크립트 없이도 "목: 신규 1,420명, 재방문 820명"처럼 읽어 줍니다. 차트를 보면서 키보드를 사용하는 독자는 방향키로 같은 점을 탐색할 수 있습니다.
- **범례에서 계열을 제어합니다.** 각 범례 항목은 실제 체크박스를 감싸는 레이블입니다. Tab 키로 이동하고 Space 키로 선택 상태를 전환합니다.
- **값 표시 팝오버로 수치를 빠르게 확인합니다.** 포인터를 올리거나, 포커스를 옮기거나, 터치하면 나타납니다. 팝오버에 표시되는 값은 다른 곳에서도 확인할 수 있습니다. 정확한 수치가 중요하면 소수의 막대에 `values: true`로 값을 표시하거나 차트 옆에 [표](/components/table)를 배치합니다.
- **색상과 이름을 함께 사용합니다.** 범례와 값 표시 팝오버에 계열 이름을 표시합니다.
- **사용자의 모션 설정을 따릅니다.** 모션 줄이기가 설정되어 있으면 차트가 그려지는 애니메이션 없이 완성된 상태로 표시됩니다.

## 차트 엔진을 사용할 때 \{#engine\}

이 차트는 수백 개 정도의 표식을 표시하도록 설계되었습니다. 각 표식은 키보드로 탐색할 수 있는 요소입니다. 다음과 같은 경우에는 차트 엔진을 사용합니다.

- 데이터 점이 수천 개이거나 새 값이 초당 여러 번 들어오는 경우
- 플롯을 확대하거나 이동하거나, 영역을 끌어서 선택해야 하는 경우
- 지도, 네트워크, 트리, 캔들스틱 차트, 생키 다이어그램, 또는 바이올린 차트나 리지라인 차트처럼 커널 밀도 추정이 필요한 형태를 그리는 경우

SVG로 그리는 엔진은 `fill`과 `stroke`에 테마 토큰을 그대로 사용할 수 있습니다. 캔버스로 그리는 엔진은 사용자 지정 속성을 직접 읽을 수 없고, 토큰 값은 `light-dark()`로 정의됩니다. 따라서 차트가 배치된 위치에서 각 색상 값을 계산합니다. 차트의 루트 요소 안에 숨겨진 테스트 요소를 두고 색상으로 토큰을 적용한 다음, 그 색으로 픽셀 하나를 칠해 색상 값을 `rgba()`로 얻습니다. 색상 모드나 테마가 바뀌면 값을 다시 계산합니다. 차트에는 눈금을 하나만 사용하고, 카테고리 순서를 고정하며, 범례에 모든 계열의 이름을 표시하고, 수치는 텍스트로 제공합니다.

```js name=theme.js
const probe = document.createElement('span')
probe.style.cssText = 'position:absolute;visibility:hidden'
root.append(probe)

function resolve(token) {
  probe.style.color = `var(${token})`
  pixel.fillStyle = getComputedStyle(probe).color
  pixel.fillRect(0, 0, 1, 1)
  const [r, g, b, a] = pixel.getImageData(0, 0, 1, 1).data
  return `rgba(${r}, ${g}, ${b}, ${a / 255})`
}
```
