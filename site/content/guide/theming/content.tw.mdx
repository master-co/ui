主題為 token 設定數值，並定義元件採用的材質配方。你可以調整一個共用值、讓變更只在頁面的某個區域生效，或替換整個介面的材質，同時保留元件的標記與行為。

Moonstone 和 Obsidian 的材質設計請見[設計](/guide/design)。[預設主題](/guide/theme)列出兩者的 token 用途與數值。要判斷該從主題還是元件著手，請先看[自訂](/guide/customization)。

## 調整 token \{#retune-tokens\}

在匯入後覆寫 token，所有讀取它的元件都會套用新值。

```css name=app.css
@import '@master/css';
@import '@master/ui';

@theme {
  --color-brand: oklch(58% .19 28);
  --color-brand-ink: oklch(99% .01 28);
  --radius-control: .5rem;
}
```

這會調整品牌色表面與控制項的預設圓角半徑。小型和大型控制項各有自己的半徑 token。請檢查 `--color-brand-ink` 與新表面的對比。品牌色文字使用獨立的 `--color-brand-text` token，因此文字色相不會隨品牌色自動變更。

### 將覆寫限制在單一區域 \{#scope\}

### 保留圓弧圓角 \{#circular-corners\}

預設主題會在瀏覽器支援時使用連續曲線圓角。若要統一使用圓弧圓角，請同時設定這兩個圓角屬性：

```css name=app.css
:root {
  --corner-shape: round;
  --corner-scale: 1;
}
```

在 `@theme` 宣告的 token 也可透過 utility 使用。`bg-surface-tray` 和 `shadow-lifted` 能讓自訂元素採用與元件相同的材質。匯入 Master UI 時，預設組態中的共用語意 token 會採用預設主題的值。覆寫後，讀取這些 token 的元件與 utility 都會套用新值。

## 主題可決定的項目 \{#what-a-theme-decides\}

建立主題時，請逐項確認下列設定。[預設主題](/guide/theme)說明各 token 的用途與預設值。

| 設定項目 | Token |
| --- | --- |
| 各表面的色調 | `--color-surface-base`, `-tray`, `-raised`, `-raised-low`, `-inset`, `-inset-hover`, `-floating`, `-chip`, `-inverse`, `-scrim` |
| 各線條的對比強度 | `--color-line-hair`, `-contour`, `-divider`, `-strong`, `-mark` |
| 文字與焦點色 | `--color-text-strong`, `-body`, `-muted`, `-disabled`, `-inverse`, `--color-focus`, `--color-focus-halo` |
| 受光與陰影分布 | `--color-highlight`, `--color-lip`, `--color-shade-1` 至 `-5` |
| 深度 | `--shadow-pressed`, `-flat`, `-raised`, `-raised-hover`, `-lifted`, `-floating`, `-overlay` |
| 墨色表面 | `--color-surface-inverse-high`, `-low`, `--color-ink-high`, `-low`，以及這些 token 的 `-hover` 形式，另有 `--color-ink-pressed`, `--color-ink-highlight`, `--color-ink-edge`, `--shadow-ink`, `-ink-hover`, `-ink-pressed`, `-ink-mark`, `-ink-well`, `-ink-top`, `--color-surface-tip`, `--shadow-tip` |
| 滑塊 | `--color-thumb-high`, `-low`, `--color-thumb-on-high`, `-on-low`, `--shadow-thumb-on-ink` |
| 色相 | `--color-brand`, `-brand-ink`, `-brand-text`, `--color-info`, `-success`, `-warning`, `-danger`, `--color-tone-highlight`, `-tone-highlight-soft` |
| 圖片與外部指定的色彩 | `--color-line-image`, `-image-strong`, `--color-line-on-color`, `--color-highlight-on-color`, `--color-on-image`, `-on-image-shade`, `--color-mark`, `-mark-underline`, `--color-sheen` |
| 形狀 | `--radius-chip`, `-control-sm`, `-control`, `-control-lg`, `-surface`, `--corner-shape`, `--corner-scale` |
| 位移與時間 | `--lift`, `--duration-press`, `-quick`, `-base`, `--easing-glide` |
| 字體 | `--font-weight-control`，以及預設組態中的 `--font-sans` 和 `--font-mono` |

套件測試會在元件樣式表中出現寫死的色值時判定失敗，確保元件色彩由主題控制。請以已安裝的 `@master/ui/theme.css` 為準，查閱完整的 token 與配方。

## 第二套主題 Paper \{#paper\}

Paper 隨套件發布，檔案位於 `@master/ui/themes/paper.css`。它以平坦的表面、線條勾勒的邊緣、較小的圓弧圓角、暖中性色和綠色品牌色取代預設材質。`--lift: 0px` 會移除這個 token 控制的指標懸停與按壓位移，開關滑塊移動等元件動畫仍可正常運作。Paper 無須修改任何元件樣式表。

```css name=app.css
@import '@master/css';
@import '@master/ui';
@import '@master/ui/themes/paper.css';
```

### 建立主題檔案 \{#create-a-theme\}

若想從平坦材質開始，請從已安裝的套件複製 Paper。若想以預設材質為基礎，請複製 `theme.css`：

```bash
mkdir -p themes
cp node_modules/@master/ui/themes/paper.css themes/app.css
```

在匯入程式庫後匯入你的主題檔案，再編輯其中的 token 與配方：

```css name=app.css
@import '@master/css';
@import '@master/ui';
@import './themes/app.css';
```

使用現有的 Master CSS 整合重新建置，沿用原有的元件標記。在整個應用程式套用主題前，先在淺色與深色配置下比較按鈕、欄位、墨色表面和覆蓋層。

## 配方 \{#recipes\}

有些材質需要多個值才能呈現，例如表面及其光影，或控制項在各狀態下的表面。主題將這些配方寫成 mixin，元件依名稱套用。主題檔案可以重新定義 mixin，所有元件都會採用最後一份定義。

| Mixin | 呈現效果 | Paper |
| --- | --- | --- |
| `--surface-sheet` | 凸起的表面 | 透過 `--color-surface-raised-low` 呈現平面 |
| `--surface-ink` | 墨色表面，例如反相面板或已傳送的訊息 | 透過 `-inverse-high` 和 `-low` token 呈現平面 |
| `--control-ink`, `-hover`, `-pressed` | 主要按鈕在各狀態下的表面與陰影 | 透過墨色 token 呈現平面 |
| `--control-tone`, `-hover`, `-pressed` | 帶色彩的控制項，以控制項自身的 `--tone` 混色 | 重新定義為單一純色 |
| `--surface-thumb` | 開關與滑桿的滑塊 | 透過滑塊 token 呈現平面 |
| `--focus-ring` | 鍵盤焦點 | 維持原樣 |
| `--on-ink` | 墨色表面為內部行內標籤提供的樣式設定 | 維持原樣 |
| `--anchored`, `--pop` | 彈出面板的位置與進出場效果 | 維持原樣 |

優先調整 token。Paper 只重新定義帶色彩的控制項配方，因為這份配方使用控制項自身設定的色相來混合表面色，而根元素上的 token 無法讀取這個色相。

Token 是自訂屬性，可在執行階段用於任何元素。Mixin 則在 Master CSS 編譯樣式表時解析，因此重新定義的 mixin 會套用至整份建置產物。

## 不使用 Master CSS \{#without-master-css\}

套件也提供各主題與元件一併編譯而成的純 CSS。若使用 CSS 打包工具，可從已安裝的套件匯入 Paper，取代預設的獨立樣式表：

```css name=app.css
@import '@master/ui/dist/themes/paper.css';

:root {
  --color-brand: oklch(58% .19 28);
}
```

若頁面未使用打包工具，請將編譯好的檔案當作靜態資源提供。重設樣式與 utility 的限制請見[安裝](/guide/installation#without-master-css)。`dist/standalone.css` 包含 Moonstone 和 Obsidian。編譯好的檔案支援覆寫自訂屬性。若要重新定義 mixin，須使用 Master CSS 編譯主題。

## 主題設計規則 \{#rules\}

- **主題不得使用選擇器指定元件。** 主題負責設定 token 與定義 mixin。在主題中加入 `.btn { … }` 這類規則屬於元件覆寫，請參閱[自訂](/guide/customization)，了解應將規則放在哪裡。
- **成對調整色彩。** 表面與其上的文字色要一起選定，線條與其下方的表面也是如此。請在淺色與深色配置下檢查內文在每種表面上的對比度。
- **讓邊界清楚可見。** 主題移除光影後，就更依賴線條界定邊界。Paper 使用對比更高的線條 token，並依用途與配色分別調整。
- **要讓陰影不可見，請將陰影 token 設為 `0 0 0 0 transparent`，不要用 `none`。** 元件會將多個陰影組成清單，而 `none` 不能作為其中一項。
- **回應使用者的高對比偏好。** 在 `prefers-contrast: more` 下，主題會加強線條和兩種低對比文字色。若主題自訂了線條，請比照 Paper 加入這段規則。修改配方時，請保留元件在強制色彩與減少動態效果下的行為。

在淺色與深色模式下，檢查鍵盤焦點、指標懸停、按壓、停用的控制項與無效的欄位。在頁面上開啟選單或對話框，確認邊緣和文字在實際背景上是否清晰。啟用減少動態效果與強制色彩後再檢查一次。主題在靜止時即使看起來清楚，仍可能讓某個狀態難以辨認，或使唯一可見的邊界消失。
