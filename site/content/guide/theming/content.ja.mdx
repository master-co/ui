テーマはトークンに値を割り当て、コンポーネントが参照する質感のレシピを定義します。共有の値を 1 つ変更したり、その変更をページの一部に限定したりできます。コンポーネントのマークアップとビヘイビアを保ったまま、インターフェイス全体の質感を差し替えることもできます。

Moonstone と Obsidian の質感の設計については、[デザイン](/guide/design)を参照してください。[既定のテーマ](/guide/theme)では、両テーマのトークンの役割と値を確認できます。テーマとコンポーネントのどちらで変更するかを判断するには、[カスタマイズ](/guide/customization)を参照してください。

## トークンの上書き \{#retune-tokens\}

インポートの後でトークンを上書きします。そのトークンを参照するすべてのコンポーネントに変更が反映されます。

```css name=app.css
@import '@master/css';
@import '@master/ui';

@theme {
  --color-brand: oklch(58% .19 28);
  --color-brand-ink: oklch(99% .01 28);
  --radius-control: .5rem;
}
```

この指定で、ブランド色のサーフェスとコントロールの既定の角丸半径が変わります。小サイズと大サイズのコントロールは、それぞれ専用の半径トークンを使います。新しい背景色に対して `--color-brand-ink` が読みやすいか確認してください。ブランド色のテキストには別のトークン `--color-brand-text` が使われるため、新しい色相は自動では反映されません。

### 上書きの適用範囲を限定する \{#scope\}

トークンはカスタムプロパティなので、カスケードに従います。要素にトークンを設定すると、再ビルドせずに子孫要素に変更を反映できます。ここでは、購入手続き内の 2 つのボタンに小さな角丸半径が継承され、その外側にあるボタンには既定値が適用されます。

<GuideFigure name="theming" title="トークンのスコープと継承">

ボタンは、自身の `--btn-radius` プロパティを通じて `--radius-control` を参照します。各ボタンがそのプロパティを自身で宣言しているため、購入手続きのコンテナーだけに `--btn-radius` を設定しても同じ効果は得られません。領域全体にはテーマトークンを使うか、各ボタンに[コンポーネントプロパティ](/guide/customization#property)を直接指定してください。このインライン宣言は、同じコンテナーに適用するプロジェクト独自のクラスにも記述できます。

### 円弧の角丸を使う \{#circular-corners\}

既定のテーマは、ブラウザーが対応している場合に連続曲線の角を使います。どの環境でも円弧の角丸にするには、角丸に関する 2 つのプロパティを両方設定してください。

```css name=app.css
:root {
  --corner-shape: round;
  --corner-scale: 1;
}
```

`@theme` で宣言されたトークンは、ユーティリティとしても使えます。`bg-surface-tray` と `shadow-lifted` を使うと、独自の要素にもコンポーネントと同じ質感を適用できます。Master UI をインポートすると、プリセットで共有するセマンティックトークンに既定のテーマの値が設定されます。上書きは、それらを参照するコンポーネントとユーティリティの両方に反映されます。

## テーマで決める項目 \{#what-a-theme-decides\}

テーマを作るときは、このチェックリストを使ってください。各トークンの役割と既定値は、[既定のテーマ](/guide/theme)で確認できます。

| 設定項目 | トークン |
| --- | --- |
| 各サーフェスの色調 | `--color-surface-base`, `-tray`, `-raised`, `-raised-low`, `-inset`, `-inset-hover`, `-floating`, `-chip`, `-inverse`, `-scrim` |
| 各線の濃さ | `--color-line-hair`, `-contour`, `-divider`, `-strong`, `-mark` |
| インク色 | `--color-text-strong`, `-body`, `-muted`, `-disabled`, `-inverse`, `--color-focus`, `--color-focus-halo` |
| 光と陰影 | `--color-highlight`、`--color-lip`、`--color-shade-1`〜`-5` |
| 奥行き | `--shadow-pressed`, `-flat`, `-raised`, `-raised-hover`, `-lifted`, `-floating`, `-overlay` |
| インク面 | `--color-surface-inverse-high`、`-low`、`--color-ink-high`、`-low`、それらの `-hover` 版、`--color-ink-pressed`、`--color-ink-highlight`、`--color-ink-edge`、`--shadow-ink`、`-ink-hover`、`-ink-pressed`、`-ink-mark`、`-ink-well`、`-ink-top`、`--color-surface-tip`、`--shadow-tip` |
| つまみ | `--color-thumb-high`, `-low`, `--color-thumb-on-high`, `-on-low`, `--shadow-thumb-on-ink` |
| 色相 | `--color-brand`, `-brand-ink`, `-brand-text`, `--color-info`, `-success`, `-warning`, `-danger`, `--color-tone-highlight`, `-tone-highlight-soft` |
| 画像と指定色 | `--color-line-image`, `-image-strong`, `--color-line-on-color`, `--color-highlight-on-color`, `--color-on-image`, `-on-image-shade`, `--color-mark`, `-mark-underline`, `--color-sheen` |
| 形状 | `--radius-chip`, `-control-sm`, `-control`, `-control-lg`, `-surface`, `--corner-shape`, `--corner-scale` |
| 移動距離と所要時間 | `--lift`, `--duration-press`, `-quick`, `-base`, `--easing-glide` |
| タイポグラフィ | `--font-weight-control` と、プリセットの `--font-sans` および `--font-mono` |

コンポーネントの色をテーマで一元管理できるよう、パッケージのテストではコンポーネントのスタイルシートに色のリテラル値があると失敗します。トークンとレシピの全体を確認するには、インストール済みの `@master/ui/theme.css` を参照してください。

## 別テーマの例：Paper \{#paper\}

Paper は `@master/ui/themes/paper.css` で公開されています。既定の質感を、フラットな面、罫線で区切った縁、小さめの円弧の角丸、暖かみのある中間色、緑のブランド色に置き換えます。Paper の `--lift: 0px` は、このトークンで制御されるホバー時と押下時の移動をなくします。スイッチのつまみの移動など、コンポーネント固有のアニメーションは引き続き動作します。コンポーネントのスタイルシートは変更しません。

```css name=app.css
@import '@master/css';
@import '@master/ui';
@import '@master/ui/themes/paper.css';
```

### テーマファイルを作成する \{#create-a-theme\}

フラットな質感から始める場合は、インストール済みのパッケージから Paper をコピーします。既定の質感をベースにする場合は、`theme.css` をコピーしてください。

```bash
mkdir -p themes
cp node_modules/@master/ui/themes/paper.css themes/app.css
```

ライブラリーの後にテーマファイルをインポートし、そのファイルのトークンとレシピを編集します。

```css name=app.css
@import '@master/css';
@import '@master/ui';
@import './themes/app.css';
```

既存の Master CSS 環境で再ビルドします。コンポーネントのマークアップはそのまま使えます。アプリ全体にテーマを適用する前に、ボタン、入力欄、インク面、オーバーレイを両方のカラースキームで見比べてください。

## レシピ \{#recipes\}

光の当たり方を含めた面の表現や、状態ごとに面が変わるコントロールなど、一部の質感は複数の値で表現します。テーマはこれらをミックスインとして定義し、コンポーネントは名前で適用します。テーマファイルでミックスインを再定義すると、最後の定義がすべてのコンポーネントに適用されます。

| ミックスイン | 描画内容 | Paper |
| --- | --- | --- |
| `--surface-sheet` | 浮き上がった面 | `--color-surface-raised-low` でフラットに |
| `--surface-ink` | インク面（反転配色のシートや送信済みメッセージなど） | `-inverse-high` と `-low` のトークンでフラットに |
| `--control-ink`, `-hover`, `-pressed` | プライマリボタンの状態ごとの面と影 | インクトークンでフラットに |
| `--control-tone`, `-hover`, `-pressed` | 固有の色相を持つコントロール。自身の `--tone` から色を合成 | 単色のフラットな面に再定義 |
| `--surface-thumb` | スイッチとスライダーのつまみ | つまみ用トークンでフラットに |
| `--focus-ring` | キーボードフォーカス | 変更なし |
| `--on-ink` | インク面から、その中のインラインチップに渡す設定 | 変更なし |
| `--anchored`, `--pop` | ポップオーバーの配置と表示・非表示時の遷移 | 変更なし |

まずはトークンで調整してください。Paper が再定義するのは、固有の色相を持つコントロールのレシピだけです。このレシピは、コントロール自身が設定した色相から面の色を合成するため、ルートにあるトークンからはその色相を参照できません。

トークンはカスタムプロパティなので、実行時に任意の要素で使えます。ミックスインは Master CSS がスタイルシートをコンパイルする際に解決されるため、再定義はビルド全体に適用されます。

## Master CSS を使わない場合 \{#without-master-css\}

パッケージには、各テーマをコンポーネントと一緒に通常の CSS へコンパイルしたファイルも含まれています。CSS バンドラーを使う場合は、既定のスタンドアロン版スタイルシートの代わりに、インストール済みのパッケージから Paper をインポートできます。

```css name=app.css
@import '@master/ui/dist/themes/paper.css';

:root {
  --color-brand: oklch(58% .19 28);
}
```

バンドラーを使わないページでは、コンパイル済みのファイルを静的アセットとして配信してください。リセットとユーティリティの制限については、[インストール](/guide/installation#without-master-css)を参照してください。`dist/standalone.css` には Moonstone と Obsidian が含まれています。コンパイル済みファイルのカスタムプロパティは上書きできます。ミックスインを再定義する場合は、Master CSS でテーマをコンパイルしてください。

## テーマの作成ルール \{#rules\}

- **テーマではコンポーネントをセレクターで指定しません。** テーマではトークンを設定し、ミックスインを定義します。テーマ内に記述した `.btn { … }` のようなルールは、コンポーネントの上書きにあたります。上書きの記述場所は[カスタマイズ](/guide/customization)を参照してください。
- **色は組み合わせで決めます。** 面の色とその上の文字色、境界線の色とその下の面の色は、それぞれセットで選びます。ライトとダークの両方で、すべての面の上で本文のコントラストが十分か確認してください。
- **輪郭を見分けられるようにします。** テーマで明暗による表現を省くと、輪郭の見分けやすさは境界線により大きく依存します。Paper では、境界線がよりはっきり見えるトークンを使い、用途と配色モードごとに調整しています。
- **影を描画しないシャドウトークンには、`none` の代わりに `0 0 0 0 transparent` を使います。** コンポーネントは複数の影をリストで合成します。リスト内の値として `none` は無効です。
- **コントラストを高める設定に対応します。** テーマは `prefers-contrast: more` で、境界線と控えめな文字色 2 種類のコントラストを高めます。独自の境界線を設定するテーマでも、Paper と同様にこのブロックを記述してください。レシピを変更するときは、強制カラーや動きを減らす設定でのコンポーネントのビヘイビアを維持してください。

ライトとダークの両方で、キーボード操作によるフォーカス、ホバー、押下、無効化されたコントロール、入力値が無効なフィールドの表示を確認してください。ページ上でメニューやダイアログを開き、実際の背景に重ねたときに輪郭と文字が見分けられるか確認します。動きを減らす設定や強制カラーでも同じ確認を行ってください。通常時は見やすくても、特定の状態が見分けられなくなったり、唯一見えていた境界が消えたりすることがあります。
