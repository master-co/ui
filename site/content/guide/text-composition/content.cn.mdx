## 可省略的署名信息 \{#optional-byline\}

先滤去缺少的值，再插入分隔符。没有日期时，作者与地点之间只留一个分隔符。用户提供的值应作为文本节点插入。

```html
<p id="byline" class="fg-text-muted"></p>
<script>
const author = 'Min Chen'
const date = null
const place = 'Hualien'
document.getElementById('byline').textContent = [author, date, place]
  .filter(value => value?.trim())
  .join(' · ')
</script>
```

## 同一卡片的两种标题层级 \{#heading-rank\}

按照所在章节选择标题元素。两张卡片均可用 [标题](/components/heading) 呈现相同字号。

```html
<main>
  <h1 class="heading heading-lg">Field archive</h1>
  <article class="card"><h2 class="heading">Latest recording</h2></article>
  <section>
    <h2 class="heading heading-lg">From the coast</h2>
    <article class="card"><h3 class="heading">Rain at the harbor</h3></article>
  </section>
</main>
```

## 原名与译名 \{#translated-name\}

两种名称分别设置 `lang`。原名放在可换行的标题中，译名另起一行。

```html
<header class="max-w(240)">
  <h2 class="heading" lang="ja">海辺の町で聞いた夜明けの音</h2>
  <p class="fg-text-muted" lang="en">Coastal dawn</p>
</header>
```

## 两行文本的读音 \{#ruby-readings\}

将每段读音放入与原文配对的 `rt`。用连续两行注音检查行距。只需复制原文时，克隆节点，移除其中的 `rt`，再读取文本。

## 缩写首次出现 \{#first-abbreviation\}

首次使用时在缩写前写出全称。触摸屏上的读者也能直接从句中理解，之后即可使用简称。

```html
<p>Record at a sound pressure level (<abbr>SPL</abbr>) below the clipping limit.</p>
<p>Log the peak SPL with each recording.</p>
```

## 可完整复制的路径 \{#breakable-path\}

在原有分隔符后放置 `wbr`。选中路径得到的仍是原字符串，也可用同样的方法在较长的扩展名前提供换行点。

## 同时按键与依次按键 \{#shortcut-order\}

用文字说明按键顺序或组合，再用独立[键帽](/components/kbd)标出每个按键。

```html
<p>Hold <kbd class="kbd">Ctrl</kbd> and press <kbd class="kbd">K</kbd> to search.</p>
<p>Press <kbd class="kbd">G</kbd>, then <kbd class="kbd">I</kbd>, to open the inbox.</p>
```

## 复制不含提示符的命令 \{#copy-command\}

提示符与命令为相邻元素。按下按钮时只读取命令。无法访问剪贴板时，保留可选中的文本并说明手动复制方法。

<ComponentPreview name="copy-command" title="复制不含提示符的命令" height={108} narrowHeight={155} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<div class="snippet">

## 发言人与作品名称 \{#quotation-credit\}

引文放在 `blockquote` 中。说明中并列发言人与作品名称，用 `cite` 标出作品。

```html
<figure class="max-w(320)">
  <blockquote><p>We heard the harbor before we could see it.</p></blockquote>
  <figcaption>Min Chen, <cite>Harbor logbook</cite></figcaption>
</figure>
```
