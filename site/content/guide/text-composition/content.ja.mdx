まず読み手が必要とする本文を書きます。操作はその隣に、注釈は対象の語のそばに置きます。コピーしたりリンクしたりする箇所は、範囲を明確にします。

## 見出しの横の操作 \{#title-action\}

見出しに折り返せる幅を与えます。[ボタン](/components/button) はラベルの幅を保ち、先頭行に揃えます。狭い幅で編集画面を開き、押せる範囲を確認します。

## 省略できる署名の情報 \{#optional-byline\}

欠けている値を除いてから区切りを挿入します。日付がなければ著者と場所の間の区切りは 1 つです。読者が入力した値はテキストノードで追加します。

```html
<p id="byline" class="fg-text-muted"></p>
<script>
const author = 'Min Chen'
const date = null
const place = 'Hualien'
document.getElementById('byline').textContent = [author, date, place]
  .filter(value => value?.trim())
  .join(' · ')
</script>
```

## カードを置く階層に合わせた見出し \{#heading-rank\}

周囲の章立てに合わせて要素を選びます。どちらのカードでも [見出し](/components/heading) で同じ大きさにできます。

```html
<main>
  <h1 class="heading heading-lg">Field archive</h1>
  <article class="card"><h2 class="heading">Latest recording</h2></article>
  <section>
    <h2 class="heading heading-lg">From the coast</h2>
    <article class="card"><h3 class="heading">Rain at the harbor</h3></article>
  </section>
</main>
```

## 原題と訳題 \{#translated-name\}

各名称に `lang` を指定します。原題を折り返せる見出しにし、その下に訳題を置きます。

```html
<header class="max-w(240)">
  <h2 class="heading" lang="ja">海辺の町で聞いた夜明けの音</h2>
  <p class="fg-text-muted" lang="en">Coastal dawn</p>
</header>
```

## 2 行にわたるふりがな \{#ruby-readings\}

読みは対応する文字と組にして `rt` に入れます。ふりがなのある行を 2 行並べて行間を確認します。本文だけをコピーする場合は、複製したノードから `rt` を除いて文字を読み取ります。

## 略語の初出 \{#first-abbreviation\}

初出では略語の前に正式名称を書きます。タッチ画面でも文中で意味が伝わり、その後は略語で読み進められます。

```html
<p>Record at a sound pressure level (<abbr>SPL</abbr>) below the clipping limit.</p>
<p>Log the peak SPL with each recording.</p>
```

## そのままコピーできるパス \{#breakable-path\}

実際の区切り文字の直後に `wbr` を置きます。パスを選択しても元の文字列のままです。長い拡張子の手前にも同じ方法で改行位置を作れます。

## 同時押しと順番に押すキー \{#shortcut-order\}

押し方は言葉で説明し、どちらの操作でも個々の[キーキャップ](/components/kbd)でキーを示します。

```html
<p>Hold <kbd class="kbd">Ctrl</kbd> and press <kbd class="kbd">K</kbd> to search.</p>
<p>Press <kbd class="kbd">G</kbd>, then <kbd class="kbd">I</kbd>, to open the inbox.</p>
```

## プロンプトを除いてコピー \{#copy-command\}

プロンプトとコマンドは隣り合う要素にします。ボタンを押したらコマンドだけを読み取ります。クリップボードが使えない場合は文字を選択できるようにし、手動のコピー方法を示します。

## 話者と作品名 \{#quotation-credit\}

引用文は `blockquote` に入れます。話者と作品名はキャプションにまとめ、作品を `cite` で囲みます。

```html
<figure class="max-w(320)">
  <blockquote><p>We heard the harbor before we could see it.</p></blockquote>
  <figcaption>Min Chen, <cite>Harbor logbook</cite></figcaption>
</figure>
```
