Start with the text a reader needs to take away. Put actions beside it, let annotations follow their words, and give anything a reader can copy or link to a stable boundary.

## An action beside a title \{#title-action\}

Give the title room to shrink. Align the [button](/components/button) with the first line and let its label keep its width. Open the editor at a narrow width to check the target.

<ComponentPreview name="title-action" title="An action beside a title" height={220} narrowHeight={260} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<div class="flex items-start justify-between gap(12) max-w(360)">
  <h2 class="heading min-w(0)" id="exhibit-name">Field recordings from the eastern coast</h2>
  <button class="btn btn-sm shrink(0)" type="button" commandfor="rename-exhibit" command="show-modal">Edit</button>
</div>
<dialog class="dialog" id="rename-exhibit" aria-labelledby="rename-title">
  <form method="dialog" class="dialog-body">
    <h2 class="heading" id="rename-title">Edit exhibit title</h2>
    <label class="field">Title <input class="input" name="title" required value="Field recordings from the eastern coast"></label>
    <div class="flex justify-end gap(8)">
      <button class="btn" value="cancel" formnovalidate>Cancel</button>
      <button class="btn btn-primary" value="save">Save</button>
    </div>
  </form>
</dialog>
<script>
const dialog = document.getElementById('rename-exhibit')
const title = document.getElementById('exhibit-name')
const field = dialog.querySelector('input')
dialog.addEventListener('close', () => {
  if (dialog.returnValue === 'save') title.textContent = field.value
  field.value = title.textContent
  dialog.returnValue = ''
})
</script>`} />

## Optional byline details \{#optional-byline\}

Filter missing values before inserting separators. With no date, the author and location share exactly one separator. Use text nodes when inserting values supplied by a reader.

```html
<p id="byline" class="fg-text-muted"></p>
<script>
const author = 'Min Chen'
const date = null
const place = 'Hualien'
document.getElementById('byline').textContent = [author, date, place]
  .filter(value => value?.trim())
  .join(' · ')
</script>
```

## An abbreviation at first mention \{#first-abbreviation\}

Write out the name before its first abbreviation. A touch reader can learn it in the sentence and recognize it later.

```html
<p>Record at a sound pressure level (<abbr>SPL</abbr>) below the clipping limit.</p>
<p>Log the peak SPL with each recording.</p>
```

## Copy a command without the prompt \{#copy-command\}

The prompt and the command are siblings. Read only the command on activation. If clipboard access is unavailable, keep the command selectable and tell the reader how to copy it.

<ComponentPreview name="copy-command" title="Copy a command without the prompt" height={108} narrowHeight={155} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<div class="snippet">
  <span class="snippet-prompt" aria-hidden="true">$</span>
  <code class="snippet-command" tabindex="0">npm view @master/ui version</code>
  <button class="btn btn-sm" type="button">Copy</button>
</div>
<output id="copy-result" aria-live="polite"></output>
<script>
const snippet = document.querySelector('.snippet')
snippet.querySelector('button').addEventListener('click', async () => {
  const result = document.getElementById('copy-result')
  try {
    await navigator.clipboard.writeText(snippet.querySelector('code').textContent)
    result.textContent = 'Copied'
  } catch {
    result.textContent = 'Select the command and use Copy.'
  }
})
</script>`} />

## The speaker and the work \{#quotation-credit\}

Keep the quoted words in `blockquote`. Put the speaker and the title of the work together in the caption, with `cite` around the work.

```html
<figure class="max-w(320)">
  <blockquote><p>We heard the harbor before we could see it.</p></blockquote>
  <figcaption>Min Chen, <cite>Harbor logbook</cite></figcaption>
</figure>
```
