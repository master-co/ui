독자가 가져갈 텍스트부터 작성합니다. 동작은 글 옆에, 주석은 해당 단어 곁에 둡니다. 복사하거나 링크할 내용은 범위가 분명해야 합니다.

## 제목 옆의 동작 \{#title-action\}

제목이 줄어들고 줄바꿈될 수 있게 합니다. [버튼](/components/button)은 레이블 너비를 유지하고 첫 줄에 맞춥니다. 좁은 화면에서 편집기를 열어 누를 수 있는 영역을 확인합니다.

## 생략 가능한 작성자 정보 \{#optional-byline\}

비어 있는 값을 먼저 제외한 뒤 구분자를 넣습니다. 날짜가 없으면 작성자와 위치 사이에 구분자 하나만 남습니다. 사용자가 제공한 값은 텍스트 노드로 넣습니다.

```html
<p id="byline" class="fg-text-muted"></p>
<script>
const author = 'Min Chen'
const date = null
const place = 'Hualien'
document.getElementById('byline').textContent = [author, date, place]
  .filter(value => value?.trim())
  .join(' · ')
</script>
```

## 카드의 위치에 따른 제목 단계 \{#heading-rank\}

문서의 개요에 맞춰 제목 요소를 정합니다. 두 카드 모두 [제목](/components/heading)으로 같은 크기를 사용할 수 있습니다.

```html
<main>
  <h1 class="heading heading-lg">Field archive</h1>
  <article class="card"><h2 class="heading">Latest recording</h2></article>
  <section>
    <h2 class="heading heading-lg">From the coast</h2>
    <article class="card"><h3 class="heading">Rain at the harbor</h3></article>
  </section>
</main>
```

## 원제와 번역 제목 \{#translated-name\}

각 이름에 `lang`을 지정합니다. 원제는 줄바꿈할 수 있는 제목으로 두고 그 아래에 번역 제목을 놓습니다.

```html
<header class="max-w(240)">
  <h2 class="heading" lang="ja">海辺の町で聞いた夜明けの音</h2>
  <p class="fg-text-muted" lang="en">Coastal dawn</p>
</header>
```

## 약어가 처음 나오는 곳 \{#first-abbreviation\}

약어가 처음 나올 때 앞에 전체 이름을 적습니다. 터치 화면에서도 문장을 읽으며 뜻을 익히고 이후 약어를 알아볼 수 있습니다.

```html
<p>Record at a sound pressure level (<abbr>SPL</abbr>) below the clipping limit.</p>
<p>Log the peak SPL with each recording.</p>
```

## 프롬프트를 뺀 명령 복사 \{#copy-command\}

프롬프트와 명령을 형제 요소로 둡니다. 실행 시 명령만 읽습니다. 클립보드를 사용할 수 없으면 명령을 선택할 수 있게 하고 수동 복사 방법을 안내합니다.

## 화자와 작품명 \{#quotation-credit\}

인용한 말은 `blockquote`에 넣습니다. 캡션에 화자와 작품 제목을 함께 두고 작품 제목을 `cite`로 감쌉니다.

```html
<figure class="max-w(320)">
  <blockquote><p>We heard the harbor before we could see it.</p></blockquote>
  <figcaption>Min Chen, <cite>Harbor logbook</cite></figcaption>
</figure>
```
