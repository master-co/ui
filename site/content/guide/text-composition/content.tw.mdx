## 可省略的署名資料 \{#optional-byline\}

先去除缺少的值，再插入分隔符號。沒有日期時，作者和地點之間只留一個分隔符。讀者提供的值請以文字節點插入。

```html
<p id="byline" class="fg-text-muted"></p>
<script>
const author = 'Min Chen'
const date = null
const place = 'Hualien'
document.getElementById('byline').textContent = [author, date, place]
  .filter(value => value?.trim())
  .join(' · ')
</script>
```

## 同一卡片的兩種標題層級 \{#heading-rank\}

依所在章節選擇標題元素。兩張卡片都能以 [標題](/components/heading) 顯示相同的視覺大小。

```html
<main>
  <h1 class="heading heading-lg">Field archive</h1>
  <article class="card"><h2 class="heading">Latest recording</h2></article>
  <section>
    <h2 class="heading heading-lg">From the coast</h2>
    <article class="card"><h3 class="heading">Rain at the harbor</h3></article>
  </section>
</main>
```

## 原名與譯名 \{#translated-name\}

兩種名稱分別設定 `lang`。原名使用標題元素並可換行，譯名另起一行。

```html
<header class="max-w(240)">
  <h2 class="heading" lang="ja">海辺の町で聞いた夜明けの音</h2>
  <p class="fg-text-muted" lang="en">Coastal dawn</p>
</header>
```

## 縮寫首次出現 \{#first-abbreviation\}

首次使用時在縮寫前寫出全名。觸控裝置上的讀者也能直接在句中理解，之後即可使用簡稱。

```html
<p>Record at a sound pressure level (<abbr>SPL</abbr>) below the clipping limit.</p>
<p>Log the peak SPL with each recording.</p>
```

在既有分隔符後放 `wbr`。選取路徑時仍會得到原字串，也能用同一方式在較長的副檔名前提供換行點。

## 同時按鍵與依序按鍵 \{#shortcut-order\}

用文字說明按鍵順序或組合，再用個別 [鍵帽](/components/kbd) 標出每個按鍵。

```html
<p>Hold <kbd class="kbd">Ctrl</kbd> and press <kbd class="kbd">K</kbd> to search.</p>
<p>Press <kbd class="kbd">G</kbd>, then <kbd class="kbd">I</kbd>, to open the inbox.</p>
```

## 複製不含提示符的指令 \{#copy-command\}

提示符與指令為相鄰元素。按下按鈕時只讀取指令。無法存取剪貼簿時，保留可選取的文字並說明手動複製方式。

<ComponentPreview name="copy-command" title="複製不含提示符的指令" height={108} narrowHeight={155} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<div class="snippet">
  <span class="snippet-prompt" aria-hidden="true">$</span>
  <code class="snippet-command" tabindex="0">npm view @master/ui version</code>
  <button class="btn btn-sm" type="button">Copy</button>
</div>
<output id="copy-result" aria-live="polite"></output>
<script>
const snippet = document.querySelector('.snippet')
snippet.querySelector('button').addEventListener('click', async () => {
  const result = document.getElementById('copy-result')
  try {
    await navigator.clipboard.writeText(snippet.querySelector('code').textContent)
    result.textContent = 'Copied'
  } catch {

</script>`} />

## 發言人與作品名稱 \{#quotation-credit\}

引文放在 `blockquote`。在圖說中並列發言人與作品名稱，用 `cite` 標出作品。

```html
<figure class="max-w(320)">
  <blockquote><p>We heard the harbor before we could see it.</p></blockquote>
  <figcaption>Min Chen, <cite>Harbor logbook</cite></figcaption>
</figure>
```
