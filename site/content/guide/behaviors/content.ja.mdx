ほとんどのコンポーネントにスクリプトは不要です。スタイルを当てる要素そのものが、すでに振る舞いを備えているからです。ただし、コンボボックス、カレンダーグリッド、スプリッターのように、対応するネイティブ要素がないパターンもいくつかあります。その場合、スタイルシートは ARIA 属性とネイティブ属性から状態を描画し、ビヘイビアが入力、フォーカス、選択を調整するリファレンススクリプトになります。このガイドでは、ビヘイビアをアタッチし、その値を読み取り、要素がページから外れたときにリスナーを解放する方法を説明します。

## ビヘイビアとは \{#what-a-behavior-is\}

ビヘイビアは、パターン名を冠した 1 つの関数を持つ 1 つのファイルです。ルート要素を受け取り、そのリスナー、オブザーバー、タイマーを停止するクリーンアップ関数を返します。クリーンアップで元のマークアップが復元されるわけではありません。たとえばカレンダーは、描画した月をそのまま保持します。依存関係もフレームワークもビルド手順もない、プレーンな ES モジュールです。

| ビヘイビアが行うこと | ビヘイビアが決して行わないこと |
| --- | --- |
| ARIA 属性とネイティブ属性の設定と削除：`aria-selected`、`aria-checked`、`aria-expanded`、`aria-activedescendant`、`aria-valuenow`、`hidden`、`tabindex`、`open`、フィールドの値 | スタイル、状態を表すクラス、サイズ、位置の設定 |
| フォーカスの移動と、プラットフォームの呼び出し：`showPopover()`、`showModal()`、`stepUp()`、`scrollIntoView()` | プラットフォームの再実装：ポップオーバーやダイアログを開く処理、ライトディスミス、モーダルのフォーカストラップと Escape |
| イベントだけが知っている情報を、コントラクトが公開するカスタムプロパティで渡す：`--menu-x`、`--splitter-size` | 要素の配置や制限の適用。これらはスタイルシートがプロパティを読み取って行います |
| 月の各週のように、パターンが繰り返す行がデータである場合に、コントラクトのクラスを使ってその行を作成する | コントラクトの外にあるものの読み書き。パーツはコントラクトのクラスとロールで見つけます |

スタイルシートは、同じコントラクトを維持する別のスクリプトとも組み合わせられます。ただし、属性、値、キーボード操作は一致している必要があります。フレームワークコンポーネントも、キー操作を再実装せず、これらと同じビヘイビアをアタッチしています。

<GuideFigure name="behaviors" title="入力から見た目の状態まで">

**DOM 属性がビヘイビアと見た目をつなぎます。** アクティブなリストボックスのオプションで Enter を押すと、ビヘイビアが `aria-checked="true"` を設定します。スタイルシートはその属性を読み取り、チェックを表示します。スクリプトがオプションを選び、CSS がその選択状態を描画します。

## ビヘイビア一覧 \{#the-behaviors\}

いずれも `@master/ui/behaviors/<name>.js` からインポートします。最後の列は[コントラクト](/guide/contracts)の `script` フィールドです。`required` はスクリプトがないとパターンが機能しないことを、`optional` はすでに機能するマークアップにスクリプトが機能を追加することを意味します。

| パターン | インポート | スクリプトが行うこと | スクリプト |
| --- | --- | --- | --- |
| [Calendar](/components/calendar) | `calendar` | 表示中の月の週を書き出し、今日、選択した日または範囲、選択できない日を示し、グリッド内を移動します | 必須 |
| [Combobox](/components/combobox) | `combobox` | 入力内容に一致しないオプションを隠し、アクティブなオプションを移動し、リストを開閉し、選択したオプションをフィールドに書き込みます | 必須 |
| [Command palette](/components/command) | `command` | コマンドを絞り込み、アクティブなオプションを移動し、Enter でそれをクリックしてダイアログを閉じます。ショートカットでどこからでも開けます | 必須 |
| [Compare](/components/compare) | `compare` | ブラウザーがスクロール駆動アニメーションに対応していない場合に、range 入力の値を `--compare-position` にコピーします。対応している場合は何も変更しません | 必須 |
| [Listbox](/components/listbox) | `listbox` | 矢印キーと文字入力でアクティブなオプションを移動し、選択したオプションにチェックを付けます。複数選択可能なリストでは複数にチェックを付けます | 必須 |
| [Menu](/components/menu) | `menu`, `contextMenu` | 矢印キーと文字入力で項目間のフォーカスを移動し、サブメニューの方向を指す矢印キーでサブメニューを開きます。`contextMenu` はポインターの位置にメニューを開きます | 任意 |
| [OTP](/components/otp) | `otp` | スロットからスロットへフォーカスを移動し、貼り付けや自動入力されたコードを各スロットに振り分けます | 必須 |
| [Splitter](/components/splitter) | `splitter` | ハンドルをドラッグまたはキーで移動したときに、最初のペインのサイズを `--splitter-size` と `aria-valuenow` に書き込みます | 必須 |
| [Stepper](/components/stepper) | `stepper` | 2 つのボタンで数値フィールドの `stepDown()` と `stepUp()` を呼び出し、上限または下限に達した側のボタンを無効にします | 必須 |
| [Tabs](/components/tabs#tab-panels) | `tabs` | `role="tablist"` の中で、タブ順序に入るタブを 1 つに保ち、矢印キーで移動と選択を行い、選択したタブのパネルを表示します | 任意 |
| [Tree](/components/tree) | `tree` | ツリー全体を 1 つのタブストップにし、矢印キーで移動と折りたたみを行えるようにします | 任意 |
| [Wheel](/components/wheel) | `wheel` | マークの下で止まったオプションに `aria-selected` を移し、フォーカスされた列にリストボックスと同じキー操作を与えます | 必須 |

## 1 つをアタッチする \{#attach-one\}

まず[スタイルシートを読み込み](/guide/installation)、コントラクトのマークアップを書きます。ルート要素が存在した後にモジュールを実行し、ルートクラスを持つ要素を渡します。以下のパッケージ名だけのインポートは、アプリケーションが npm モジュールを解決できることを前提としています。ブラウザーでモジュールを直接読み込む場合は、解決可能な URL またはインポートマップが必要です。

```html
<div class="combobox">
  <div class="input-group">
    <input class="input-group-field" id="region" role="combobox" aria-expanded="false" aria-controls="region-list" aria-autocomplete="list" autocomplete="off" aria-label="Region">
    <button type="button" class="combobox-toggle" tabindex="-1" aria-label="Show regions"></button>
  </div>
  <div id="region-list" popover="manual" class="listbox" role="listbox" aria-label="Regions">
    <div class="listbox-option" role="option" id="region-hnd" data-value="hnd" aria-checked="false">Tokyo</div>
    <div class="listbox-option" role="option" id="region-sin" data-value="sin" aria-checked="false">Singapore</div>
    <div class="listbox-empty">No regions match.</div>
  </div>
</div>
```

```js name=app.js
import { combobox } from '@master/ui/behaviors/combobox.js'

const detach = combobox(document.querySelector('.combobox'))
```

「Tok」と入力し、ArrowDown と Enter を押して、フィールドに Tokyo が表示され、`detach.value` が `hnd` になることを確認します。要素がページから外れるときは `detach()` を呼び出します。同じルートに同じビヘイビアを 2 回アタッチすると、以前のインスタンスは解除されます。ただし、アプリケーションが追加したリスナーはクリーンアップされません。

## すべてをアタッチする \{#attach-all\}

`attach()` は各パターンをルートクラスで見つけ、そのビヘイビアをアタッチします。ドキュメント全体、または渡された要素とその配下を探し、アタッチしたものをすべて解除する 1 つの関数を返します。

```js name=app.js
import { attach } from '@master/ui/behaviors'

const detach = attach()
```

個別のインポートではなくこちらを選ぶ前に、知っておくべきことが 3 つあります。

- 任意のビヘイビアもアタッチされます。すべての `menu` に矢印キー操作が付き、すべての `tree` が 1 つのタブストップになり、`role="tablist"` であるすべての `tabs` がパネルを切り替えます。プラットフォームの動作のままにしておきたいものがある場合は、ビヘイビアを名前でインポートしてください。
- オプションは渡されません。範囲を選択するカレンダーや、最初と最後の日が決まっているカレンダーは、名前でアタッチします。
- コンテキストメニューはページだけが知っているターゲットに属するため、`attach()` ではアタッチされません。`contextMenu(target, menu)` を呼び出してください。

`attach()` はドキュメントを監視しません。後から追加したマークアップには、追加した部分に対して `attach(element)` を呼び出し、その呼び出しのクリーンアップ関数も保持してください。対応するルートを削除する前に、それぞれのクリーンアップを呼び出します。

## フレームワークで使う \{#in-a-framework\}

React、Svelte、Vue では、これらの各パターンに、プロジェクトにコピーして使うコンポーネントがあります。そのコンポーネントがマークアップをレンダリングし、ビヘイビアをアタッチし、値の受け渡しを行います。一覧は [React、Svelte、Vue](/guide/frameworks) にあります。このセクションの残りは、自作のコンポーネントでビヘイビアを自分でアタッチする場合の説明です。

以下のコードはアタッチとクリーンアップだけを示しています。各ルートの中には、[1 つをアタッチする](#attach-one)の完全なコンボボックスのマークアップを置いてください。設定オプションが変わったら再アタッチします。アプリケーションの値や変化するオプションを扱う場合は、コピーしたフレームワークコンポーネントか、その[アダプターヘルパー](/guide/frameworks#your-own)を使うことをおすすめします。

React では、`useEffect` が解除関数をクリーンアップとして受け取ります。

```jsx name=Combobox.jsx
import { useEffect, useRef } from 'react'
import { combobox } from '@master/ui/behaviors/combobox.js'

export function Combobox({ children }) {
  const root = useRef(null)
  useEffect(() => combobox(root.current), [])
  return <div className="combobox" ref={root}>{children}</div>
}
```

Svelte では、ビヘイビアがアタッチメントのシグネチャーを持つため、`{@attach}` にそのまま渡せます。

```svelte name=Combobox.svelte
<script>
  import { combobox } from '@master/ui/behaviors/combobox.js'
</script>

<div class="combobox" {@attach combobox}>
  <!-- the field and the listbox -->
</div>
```

アクションはオブジェクトを返すため、アタッチメントのない Svelte のバージョンではビヘイビアをラップします。`const action = (node) => ({ destroy: combobox(node) })` と書き、`use:action` を使います。

Vue では、コンポーネントのマウント時にアタッチし、アンマウント時に解除します。

```vue name=Combobox.vue
<script setup>
import { onMounted, onUnmounted, ref } from 'vue'
import { combobox } from '@master/ui/behaviors/combobox.js'

const root = ref(null)
let detach

onMounted(() => { detach = combobox(root.value) })
onUnmounted(() => detach?.())
</script>

<template>
  <div class="combobox" ref="root"><slot /></div>
</template>
```

## オプション \{#options\}

以下のビヘイビアは、`calendar(root, options)` のように、第 2 引数にオプションオブジェクトを受け取ります。

### Calendar \{#calendar-options\}

- `value`：選択した日を表す `YYYY-MM-DD`、または範囲の両端。
- `month`：最初に表示する月を表す `YYYY-MM`。
- `min`、`max`：選択できる最初の日と最後の日。
- `range`：2 つの日と、その間のすべての日を選択します。
- `weekStart`：最初の列に置く曜日。日曜日の 0 から土曜日の 6 まで。
- `locale`：表示する名前に使う BCP 47 言語タグ。
- `disabled`：その日を選択できないかどうかを返す関数。
- `draw`：[ビヘイビアの代わりにグリッドをレンダリングする](#a-grid-of-your-own)関数。

### Combobox \{#combobox-options\}

`filter` の既定値は `true` です。ビヘイビアは、テキストに入力内容を含まないオプションを隠します。[一致するオプションをアプリケーションが提供する](#options-from-a-server)場合は `false` に設定します。

### Command palette \{#command-options\}

`shortcut` は、Command または Control と組み合わせてパレットを開閉するキーです。既定値は `'k'` で、`false` に設定するとショートカットが無効になります。`filter` はコンボボックスと同じように機能します。

### OTP \{#otp-options\}

`pattern` は、各文字が一致しなければならない正規表現です。省略した場合、ビヘイビアは最初のスロットの `pattern` 属性を読み取り、それもなければ数字にフォールバックします。

### Splitter \{#splitter-options\}

`step` は、矢印キー 1 回でハンドルを動かす量をパーセントポイントで指定します。既定値は 5 です。

## イベント \{#events\}

ビヘイビアは、ネイティブコントロールと同じ方法で変化を通知します。つまり、バブリングする DOM イベントです。`addEventListener` か、フレームワーク独自のネイティブイベント用バインディングで受け取ってください。

| ビヘイビア | イベント | ディスパッチ元 | 含まれる情報 |
| --- | --- | --- | --- |
| `combobox` | オプションが選ばれたときに `input`、続いて `change` | フィールド | 値はフィールドの `value` です |
| `listbox` | `input`、続いて `change` | リストボックス | オプションの `aria-checked="true"` を読み取ります |
| `stepper` | ボタンで数値が変わったときに `input`、続いて `change` | フィールド | 値はフィールドの `value` です |
| `splitter` | サイズが変わるたびに `input`、ドラッグが終わったときやキーでハンドルを動かしたときに `change` | ハンドル | `aria-valuenow` を読み取ります |
| `otp` | スクリプトが書き込んだスロットから `input`、すべてのスロットが埋まったときに `change` | スロット、ルート | `detail.value`：コード |
| `calendar` | `change` | ルート | `detail.value`：`YYYY-MM-DD` 形式の日、または範囲の両端が選ばれた時点での `[start, end]` |
| `wheel` | 列が別のオプションで止まったときに `change` | 列 | `detail.value`：オプションの `data-value`、またはそのテキスト。`detail.option`：要素 |
| `tree` | 枝ではない `role="treeitem"` の行が選択されたときに `change` | ルート | `detail.item`：行 |
| `tabs` | 別のタブが選択されたときに `change` | タブリスト | `detail.value`：タブの `data-value`、またはそのテキスト。`detail.tab`：要素 |

OTP フィールド、カレンダー、ホイール、ツリー、タブリストの `change` は、値が 1 つのネイティブコントロール上にないため `CustomEvent` です。OTP フィールドのスロットはネイティブの input なので、スロット自身の `change` も `detail` なしでルートを通ってバブリングします。コマンドパレット、メニュー、コンペアは独自のイベントをディスパッチしません。コマンドはそのオプションの `click` で実行され、Enter でも `click` が送られます。メニューの項目はネイティブのボタン、リンク、input です。

```js name=app.js
import { calendar } from '@master/ui/behaviors/calendar.js'

const root = document.querySelector('.calendar')
const detach = calendar(root, { value: '2026-11-13', min: '2026-11-01' })

root.addEventListener('change', (event) => {
  console.log(event.detail.value)
})
```

## 値 \{#the-value\}

1 つのネイティブコントロールでは保持できない値を持つパターンでは、そのビヘイビアが返す関数に `value` があります。読み取ると、現在選択されているものがわかります。設定すると外部から選択できます。その場合パターンには選択状態が反映されますが、ネイティブ input の `value` を設定したときと同様に、イベントはディスパッチされません。

| ビヘイビア | `value` |
| --- | --- |
| `calendar` | `YYYY-MM-DD` 形式の日、または範囲では `[start, end]`。終わりの日は選ばれるまで `null` です。何も選ばれていなければ `null`。設定すると新しい値の月が表示されます |
| `combobox` | 選択したオプションが表すもの。どのオプションも選ばれていないテキストがフィールドにある間は `null`。設定するとオプションのテキストがフィールドに書き込まれます |
| `listbox` | 選択したオプションが表すもの。何も選ばれていなければ `null`。リストボックスに `aria-multiselectable="true"` がある場合はそれらのリスト |
| `otp` | スロットが保持する文字を順に並べたもの |
| `splitter` | 最初のペインのサイズ（パーセント） |
| `stepper` | フィールドの数値。空の間は `null` |
| `compare` | range 入力の数値 |
| `tabs`, `tree` | 選択したタブまたは行が表すもの。何も選ばれていなければ `null` |
| `wheel` | 各列で選択したオプションが表すもの。列の順に並びます |

オプション、タブ、行は、その `data-value` を表します。`data-value` がない場合はテキストを表します。テキストがアプリケーションの保存する値と異なる場合は、Tokyo と表示するオプションに `data-value="hnd"` を付けるように、`data-value` を指定してください。

```js name=app.js
import { combobox } from '@master/ui/behaviors/combobox.js'

const region = combobox(document.querySelector('.combobox'))
region.value = 'hnd'        // checks the option, writes "Tokyo" into the field
console.log(region.value)   // "hnd"
```

スクリプトがフィールドに書き込む値は、要素のプロトタイプのセッターを経由します。React は input の `value` をシャドウして自身の書き込みを検知し、すでに見た値に対する `input` イベントを無視します。この方法で書き込むことで、選択が入力と同じように `onChange` に届きます。

## サーバーからのオプション \{#options-from-a-server\}

既定では、コンボボックスとコマンドパレットはマークアップ内にあるオプションを絞り込みます。サーバーへの問い合わせやインデックスの検索など、何が一致するかをページが決める場合は、`filter: false` を渡します。スクリプトは何も隠さず、読み手の入力に合わせてページがオプションを書き出します。リストが開いている間に届いたオプションには改めてアクティブなオプションが設定されるため、<kbd>Enter</kbd> で引き続き最初の一致を選べます。

```js name=app.js
import { combobox } from '@master/ui/behaviors/combobox.js'

const root = document.querySelector('.combobox')
const list = root.querySelector('[role="listbox"]')
const selection = combobox(root, { filter: false })
let request = 0

root.querySelector('[role="combobox"]').addEventListener('input', async (event) => {
  const current = ++request
  if (selection.value !== null) return // Choosing an option also dispatches input.
  const regions = await search(event.target.value)
  if (current !== request || !root.isConnected) return
  list.replaceChildren(...regions.map(option))
})
```

ここで `search(text)` はアプリケーションの非同期検索関数で、`option(region)` は `listbox-option`、`role="option"`、一意な id、`data-value`、`aria-checked="false"` を持つ要素を 1 つ作ります。ラベルはテキストのままにし、サーバーからの文字列を HTML として挿入しないでください。リクエストカウンターは、古いレスポンスが新しい結果を置き換えるのを防ぎます。読み込み中、結果なし、エラーのフィードバックはアプリケーション側で用意してください。

## 独自のグリッド \{#a-grid-of-your-own\}

要素を書き出すビヘイビアはカレンダーだけです。書き出すのは、表示している月の週です。テンプレートや、サーバーでレンダリングするフレームワークなど、それを自分で書き出すべきレンダラーは `draw` を渡します。するとスクリプトは要素を書き出しません。グリッドの月が表示すべき月と異なるときはいつでも、その月を `YYYY-MM` 形式で渡して `draw` を呼び出し、日が揃った時点で、今日、選択された日、選択できない日、タブ順序に入る日を示します。

`calendarMonth()` は、スクリプトが描画に使うのと同じデータとして月を返します。タイトル、7 つの曜日名、週です。各日は `value` がその日付である `calendar-day` ボタンです。スクリプトはこれによって、自分が書き出していない日を把握します。`value` を渡し、両端がある場合は `range` も渡すと、データには各日の描画方法も含まれます。`selected`、タブ順序に入る 1 日を示す `tab`、範囲内の日のクラスを示す `range` です。これらを書き出すレンダラーなら、スクリプトが動く前の最初の HTML に、選択された日が含まれます。

```js
import { calendarMonth } from '@master/ui/behaviors/calendar.js'

const month = calendarMonth('2026-11', {
  value: '2026-11-13',
  locale: 'en-GB'
})

const chosen = month.weeks.flat().find(day => day.selected)
console.log(chosen.date) // "2026-11-13"
console.log(chosen.tab)  // true
```

レンダラーはこのデータを使ってコントラクトのマークアップを生成します。

| データ | レンダリング先 |
| --- | --- |
| `title` | `calendar-title` のテキスト |
| `weekdays` | 短い名前をテキスト、完全な名前を `aria-label` とする `calendar-weekday` 列見出し |
| `weeks` | 週ごとの `calendar-week` 行 |
| 日の `date`、`text`、`label` | ボタンの `value`、テキスト、`aria-label` |
| `selected`、`tab` | 初期選択日には `aria-selected` と `tabindex="0"`、それ以外の日には `-1` |
| `outside`、`range` | 必要に応じて `calendar-day-outside`、および返された範囲のクラス名 |

グリッドができたら、同じ初期値とロケールを使って `calendar(root, { value, locale, draw })` をアタッチします。`draw(month)` コールバックは別の月の行をレンダリングし、それらの行が揃った時点で、ビヘイビアが現在の選択とフォーカスを示します。行を置き換えるときは、タイトル、曜日見出し、グリッドのラベル付けを維持してください。

React、Svelte、Vue 用の[カレンダーコンポーネント](/guide/frameworks)はこの方法で書かれているため、月が最初の HTML に含まれます。

## キー操作 \{#the-keys\}

コントラクトの `keyboard` リストは、そのパターンに付属するビヘイビアの動作を定めています。`npx master-ui contract combobox` で確認できます。

| キー | 動作 |
| --- | --- |
| ArrowDown, ArrowUp | リストを開き、アクティブなオプションを移動します。端では反対側に戻ります |
| Home, End | リストが開いている間、最初または最後のオプションに移動します |
| Enter | アクティブなオプションを選択し、リストを閉じます |
| Escape | リストを閉じます。フィールドのテキストは保持されます |
| 文字入力 | オプションを絞り込み、最初の一致でリストを開きます |

ビヘイビアが処理するキーでは `preventDefault()` が呼ばれます。処理しないキーはそのままにされるため、アクティブなオプションがないコンボボックスで Enter を押すと、フォームは通常どおり送信されます。非表示の項目と、`disabled` または `aria-disabled="true"` を持つ項目はスキップされ、左右の矢印キーはテキストの方向に従います。

## ビヘイビアを所有する \{#own-a-behavior\}

パッケージのビヘイビアがアプリケーションの要件を満たしている間は、それをインポートし続けてください。そうすればパッケージのアップグレードで修正が取り込まれます。プロジェクトで異なるキーボード操作や選択の動作が必要になったら、ソースを取り込み、その実装を自分で保守します。

```bash
npx master-ui own combobox
```

`own` は、コンポーネントのスタイルシート、コントラクト、ビヘイビアをプロジェクトにコピーします。既定のコピー先は `ui/combobox.css`、`ui/combobox.json`、`ui/combobox.js` です。以後、そのスクリプトはプロジェクトのものになります。パッケージからではなく、そこからインポートしてください。コンポーネントの所有に関するその他の点は[カスタマイズ](/guide/customization#own-a-component)で説明しています。

combobox、command、listbox、menu の各ビヘイビアは、共有ヘルパーを `./internal.js` からインポートします。`own` はこのファイルもそれらの隣にコピーします。

編集中もコントラクトを正しく保ってください。スクリプトが変更する属性はスタイルシートが読み取る属性と一致させ、`keyboard` リストには現在のキー操作を記述します。

## スクリプトを使わない場合 \{#without-any-script\}

この表はパッケージに含まれるビヘイビアの一覧であり、JavaScript が必要になりうるアプリケーションの操作をすべて挙げたものではありません。ネイティブコントロールは、ブラウザーが対応していれば独自の操作を提供します。エンハンスメントのフォールバックについては[ブラウザーサポートのガイド](/guide/browser-support)を参照してください。表にあるパターンのいくつかには、ビヘイビアなしの形もあります。

- **タブ**はリンクやラジオコントロールで作れます。任意のビヘイビアは、関連付けたパネルを選択して表示するタブリストのためのものです。
- **ツリー**は、`<summary>` を行とする入れ子の `<details>` 要素で作れます。枝は自動的に開閉し、すべての行がタブストップになります。
- **メニュー**は、ボタンとリンクを並べたポップオーバーで作れます。ブラウザーが開閉を行い、Tab で項目間を移動し、Escape でフォーカスがボタンに戻ります。`role="menu"` はビヘイビアと一緒の場合にのみ付けてください。このロールは矢印キー操作を約束するからです。

ほかにも、スクリプトを `optional` とし、ビヘイビアを指定していないコントラクトがいくつかあります。そこでのスクリプトは、チェックボックスの `indeterminate` 状態のように HTML に属性がないものを扱う 1、2 行のコードで、コンポーネントはそれがなくても機能します。
