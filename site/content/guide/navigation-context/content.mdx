## Skip to the working area \{#skip-to-results\}

Tab to the first link in the [field notebook](/demo/navigation/field-notes.html). Activate it, then press Tab again to reach the recording index link inside the target section. Put the skip link before long navigation. In Safari on macOS, use Option-Tab if Tab skips links.

```html
<a class="skip" href="#recordings">Skip to recording notes</a>
<nav aria-label="Notebook"><a href="#mount">Microphone mount</a></nav>
<h2 id="recordings" tabindex="-1">Recordings</h2>
<a href="/demo/navigation/index.html?q=coast&amp;collection=shore">Open the recording index</a>

```

## Return to the notebook title \{#back-to-heading\}

Give the title a stable ID and allow fragment navigation to focus it. At the end of the [notebook](/demo/navigation/field-notes.html#mount), activate the return link. The next Tab visits the first link after the title.

```html
<h1 id="notebook-title" tabindex="-1">Harbor microphone notes</h1>
<!-- Notebook sections -->
<a href="#notebook-title">Back to the notebook title</a>
```

## Change sort order and keep the query \{#sort-and-filter\}

Open the [second recording batch](/demo/navigation/index.html?q=coast&collection=shore&sort=name&after=gulls) and choose Newest first. Keep the query and collection in the URL, remove the previous cursor, then update the rows and the sorted heading from the same order.

```js
function newestFirst(address) {
  const next = new URL(address)
  next.searchParams.set('sort', 'recent')
  next.searchParams.delete('after')
  return next.href
}

const link = document.createElement('a')
link.textContent = 'Newest first'
link.href = newestFirst(location.href)
document.querySelector('nav[aria-label="Sort recordings"]').append(link)
```

## Keep the first line below persistent navigation \{#header-clearance\}

In the [notebook](/demo/navigation/field-notes.html#mount), the header occupies its own grid row. The article scrolls in the space below. When larger text wraps the navigation, the row grows and the first line of a linked heading stays visible.

```css
.notebook {
  display: grid;
  grid-template-rows: auto minmax(0, 1fr);
  block-size: 100dvh;
}
.notebook-article {
  overflow: auto;
  scroll-padding-block-start: 1rem;
}
```
