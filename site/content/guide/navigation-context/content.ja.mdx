## 現在のページと現在の節 \{#current-in-two-lists\}

ナビゲーションごとに名前を付け、それぞれ一つのリンクを現在地として示します。ページとそのページ内の節は同時に現在地になります。

```html
<nav aria-label="Guides"><a href="/guide/installation" aria-current="page">Installation</a>
  <a href="/guide/customization">Customization</a></nav>
<nav aria-label="Installation sections"><a href="/guide/installation#without-master-css" aria-current="location">Without Master CSS</a>
  <a href="/guide/installation#set-the-viewport">Viewport</a></nav>
```

## 作業領域にスキップする \{#skip-to-results\}

[フィールドノート](/demo/navigation/field-notes.html)で最初のリンクに Tab で移動して実行し、もう一度 Tab を押すと対象の節にある録音索引のリンクに進みます。長いナビゲーションの前にスキップリンクを置きます。macOS の Safari で Tab がリンクを飛ばす場合は Option-Tab を使います。

```html
<a class="skip" href="#recordings">Skip to recording notes</a>
<nav aria-label="Notebook"><a href="#mount">Microphone mount</a></nav>
<h2 id="recordings" tabindex="-1">Recordings</h2>
<a href="/demo/navigation/index.html?q=coast&amp;collection=shore">Open the recording index</a>
<h2 id="mount">Microphone mount</h2>
```

## 同じ記事で言語を切り替える \{#same-translation\}

各言語の名称はその言語で表示します。ラベルの言語とリンク先の言語には別々の属性を指定します。各翻訳版が同じ節 ID を持つ場合は、その ID も引き継ぎます。

```html
<nav aria-label="Installation guide language">
  <a lang="en" hreflang="en" href="/guide/installation#set-the-viewport">English</a>
  <a lang="zh-Hant" hreflang="zh-Hant" href="/tw/guide/installation#set-the-viewport">繁體中文</a>
  <a lang="ja" hreflang="ja" href="/ja/guide/installation#set-the-viewport">日本語</a>
</nav>
```

## 検索条件を保ったまま並べ替える \{#sort-and-filter\}

[録音の 2 組目](/demo/navigation/index.html?q=coast&collection=shore&sort=name&after=gulls)で新しい順を選びます。URL には検索語とコレクションを残し、以前のカーソルを削除します。同じ並び順で行と列見出しを更新します。

```js
function newestFirst(address) {
  const next = new URL(address)
  next.searchParams.set('sort', 'recent')
  next.searchParams.delete('after')
  return next.href
}

const link = document.createElement('a')
link.textContent = 'Newest first'
link.href = newestFirst(location.href)
document.querySelector('nav[aria-label="Sort recordings"]').append(link)
```

## 折りたたんだ内容にリンクする \{#link-into-details\}

[風防のメモ](/demo/navigation/field-notes.html#wind-screen)を新しいタブで開くと、ブラウザーが外側の details を展開して対象を表示します。ID は共有したい内容に付けます。

```html
<details>
  <summary>Field setup notes</summary>
  <h3 id="wind-screen" tabindex="-1">Wind screen</h3>
  <p>Fit the outer cover before mounting the bar.</p>
</details>
```

## 固定ナビゲーションの下に見出しを収める \{#header-clearance\}

[ノート](/demo/navigation/field-notes.html#mount)ではヘッダーに専用のグリッド行を与え、記事はその下でスクロールさせます。文字を拡大してナビゲーションが折り返しても行が広がり、リンク先の見出しの先頭行が見えます。

```css
.notebook {
  display: grid;
  grid-template-rows: auto minmax(0, 1fr);
  block-size: 100dvh;
}
.notebook-article {
  overflow: auto;
  scroll-padding-block-start: 1rem;
}
```
