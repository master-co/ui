アプリが受け取る値に合わせてコントロールを選びます。例の値を入力して送信し、フィールド名、値、送信を実行したボタンを確認します。

## 識別子の先頭のゼロ \{#leading-zeros\}

識別子にはテキスト入力を使います。数字キーボードと 5 桁のパターンを指定すると入力しやすく、送信する文字列の 5 桁も保たれます。

<ComponentPreview name="leading-zeros" title="識別子の先頭のゼロ" height={130} narrowHeight={160} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<form id="member-form">
  <label class="field">Member number (5 digits)
    <input class="input" name="member" type="text" inputmode="numeric" pattern="[0-9]{5}" value="00126" required>
  </label>
  <button class="btn btn-sm" type="submit">Check number</button> <output></output>
</form>
<script>
const form = document.getElementById('member-form')
form.addEventListener('submit', event => {
  event.preventDefault()
  form.querySelector('output').textContent = new FormData(form).get('member')
})
</script>`} />

## 1 つのフォームに 2 件の住所 \{#address-sections\}

住所ごとに凡例と独立したフィールド名を付けます。`section-*` 接頭辞と住所の種別で自動入力のグループを区別します。

```html
<form>
  <fieldset class="fieldset"><legend class="fieldset-legend">Billing address</legend>
    <label class="field">Street <input class="input" name="billingStreet" autocomplete="section-bill billing street-address"></label>
    <label class="field">Postal code <input class="input" name="billingPost" autocomplete="section-bill billing postal-code"></label>
  </fieldset>
  <fieldset class="fieldset"><legend class="fieldset-legend">Shipping address</legend>
    <label class="field">Street <input class="input" name="shippingStreet" autocomplete="section-ship shipping street-address"></label>
    <label class="field">Postal code <input class="input" name="shippingPost" autocomplete="section-ship shipping postal-code"></label>
  </fieldset>
</form>
```

## コピーも送信もできる参照番号 \{#readonly-id\}

名前のある読み取り専用フィールドもフォームで送信されます。フォーカスを当てて文字を選択すれば番号全体をコピーできます。

```html
<form id="receipt">
  <label class="field">Receipt number <input class="input" name="receipt" readonly value="RC-00126"></label>
</form>
<script>
const receipt = new FormData(document.getElementById('receipt')).get('receipt')
// receipt === 'RC-00126'
</script>
```

## 凡例からグループを有効にする \{#enabled-legend\}

無効な fieldset の最初の legend に切り替えを置きます。他の入力は操作と送信の対象から外れますが、切り替えは操作できます。

<ComponentPreview name="enabled-legend" title="凡例からグループを有効にする" height={179} narrowHeight={210} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<form id="limits-form">
<fieldset class="fieldset" id="custom-limit" disabled>
  <legend class="fieldset-legend"><label class="check"><input type="checkbox" class="checkbox"> Custom limit</label></legend>
  <label class="field">Maximum entries <input class="input" type="number" name="limit" min="1" value="25"></label>
</fieldset>
<button class="btn btn-sm" type="submit">Check submitted limit</button> <output></output>
</form>
<script>
const group = document.getElementById('custom-limit')
const toggle = group.querySelector('input[type="checkbox"]')
toggle.addEventListener('change', () => { group.disabled = !toggle.checked })
const form = document.getElementById('limits-form')
form.addEventListener('submit', event => {
  event.preventDefault()
  const value = new FormData(form).get('limit')
  form.querySelector('output').textContent = value === null ? 'Limit omitted' : 'limit=' + value
})
</script>`} />

## 下書き保存と公開 \{#draft-or-publish\}

送信ボタンが操作の種類を伝えます。下書きは検証を省き、公開は同じフォームの必須タイトルを検証します。サーバーでも操作に応じて検証します。

<ComponentPreview name="draft-or-publish" title="下書き保存と公開" height={180} narrowHeight={215} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<form id="article-form">
  <label class="field">Article title <input class="input" name="title" required></label>
  <div class="flex flex-wrap gap(8)">
    <button class="btn" name="action" value="draft" formnovalidate>Save draft</button>
    <button class="btn btn-primary" name="action" value="publish">Publish</button>
  </div>
  <output></output>
</form>
<script>
const article = document.getElementById('article-form')
article.addEventListener('submit', event => {
  event.preventDefault()
  const data = new FormData(article, event.submitter)
  article.querySelector('output').textContent = 'Submitted action: ' + data.get('action')
})
</script>`} />

## ダイアログのフッターから送信 \{#dialog-footer\}

## 同意のチェックと規約へのリンク \{#terms-link\}

リンクはチェックボックスのラベルの隣に置きます。個別にフォーカスでき、規約を開いてもチェック状態を保てます。

```html
<div class="flex items-baseline flex-wrap gap(8)">
  <label class="check"><input class="checkbox" type="checkbox" name="terms" required> I agree to the terms</label>
  <a class="link" href="#license-terms">Read the terms</a>
</div>
<section id="license-terms"><h2 class="heading">License terms</h2><p>Keep the recording credits with each download.</p></section>
```

## 候補にない値も入力する \{#open-ended-options\}

入力欄に datalist を関連付けます。新しい空でない観測地点名もそのまま同じフィールド名で送信できます。

```html
<form method="get">
  <label class="field">Station
    <input class="input" name="station" list="known-stations" required>
  </label>
  <datalist id="known-stations"><option value="East Pier"></option><option value="West Pier"></option></datalist>
  <button class="btn" type="submit">Continue</button>
</form>
```

## 同じ地名を持つ選択肢 \{#duplicate-option-names\}

各項目のラベルにも地域を含めます。閉じた状態では、ブラウザーが選択した項目だけを表示することがあります。

```html
<label class="field">Collection point
  <select class="select" name="branch">
    <optgroup label="North"><option value="north-central">Central · North</option></optgroup>
    <optgroup label="South"><option value="south-central">Central · South</option></optgroup>
  </select>
</label>
```

## URL で引き継ぐ絞り込み \{#shareable-filters\}

同じ名前のチェックボックスに異なる値を付けます。初回表示と履歴からの復帰時に URL の値をすべて読み取り、何も選んでいない状態も復元します。

```html
<form method="get" id="station-filter">
  <fieldset class="fieldset"><legend class="fieldset-legend">Habitats</legend>
    <label class="check"><input class="checkbox" type="checkbox" name="habitat" value="coast"> Coast</label>
    <label class="check"><input class="checkbox" type="checkbox" name="habitat" value="forest"> Forest</label>
  </fieldset>
  <button class="btn">Apply filters</button>
</form>
<script>
const filters = document.getElementById('station-filter')
function restore() {
  const selected = new Set(new URLSearchParams(location.search).getAll('habitat'))
  for (const box of filters.querySelectorAll('[name="habitat"]')) box.checked = selected.has(box.value)
}
restore()
window.addEventListener('pageshow', restore)
</script>
```

## 未回答と未定 \{#undecided\}

任意回答にします。未選択なら FormData に項目がなく、「未定」を選べば専用の値が送信されます。

```html
<form method="get">
  <fieldset class="fieldset"><legend class="fieldset-legend">Will you attend?</legend>
    <label class="check"><input class="radio" type="radio" name="attendance" value="yes"> Yes</label>
    <label class="check"><input class="radio" type="radio" name="attendance" value="no"> No</label>
    <label class="check"><input class="radio" type="radio" name="attendance" value="undecided"> Undecided</label>
  </fieldset>
  <button class="btn" type="submit">Continue</button>
</form>
```

## 0.25 単位での入力 \{#quarter-steps\}

最初に許可する値と刻み幅を設定します。ゼロから始めれば 1.25 は有効で、1.20 は刻み幅の不一致です。

```html
<label class="field">Hours worked (quarter hours)
  <input class="input" type="number" name="hours" min="0" step="0.25" value="1.25">
</label>
```

## 空欄でも残る単位 \{#persistent-unit\}

単位を値の外に置き、正式名称を説明として関連付けます。入力を消しても単位の表示と意味が残ります。

```html
<div class="field">
  <label for="length">Cable length</label>
  <div class="flex items-baseline gap(8)">
    <input class="input" type="number" min="0" step="any" id="length" name="lengthM" aria-describedby="length-unit">
    <span id="length-unit">metres</span>
  </div>
</div>
```

## 行の名前を含めた数量操作 \{#named-quantities\}

各行の名前を数量フィールドと増減ボタンの名前に含めます。入力欄では矢印キーを使えるようにし、各グループに[ステッパー](/components/stepper)の動作を接続します。

```html
<table class="table"><caption>Subscription seats</caption><tbody>
  <tr><th id="design-seats" scope="row">Design seats</th><td>
    <div class="input-group stepper">
      <button type="button" class="btn btn-square" value="-1" tabindex="-1" aria-labelledby="design-less design-seats"><span id="design-less" class="sr-only">Decrease</span>−</button>
      <input class="input stepper-field" type="number" min="0" value="2" aria-labelledby="design-seats" name="design">
      <button type="button" class="btn btn-square" value="1" tabindex="-1" aria-labelledby="design-more design-seats"><span id="design-more" class="sr-only">Increase</span>+</button>
    </div>
  </td></tr>
  <tr><th id="review-seats" scope="row">Review seats</th><td>
    <div class="input-group stepper">
      <button type="button" class="btn btn-square" value="-1" tabindex="-1" aria-labelledby="review-less review-seats"><span id="review-less" class="sr-only">Decrease</span>−</button>
      <input class="input stepper-field" type="number" min="0" value="1" aria-labelledby="review-seats" name="review">
      <button type="button" class="btn btn-square" value="1" tabindex="-1" aria-labelledby="review-more review-seats"><span id="review-more" class="sr-only">Increase</span>+</button>
    </div>
  </td></tr>
</tbody></table>
<script type="module">
import { stepper } from '@master/ui/behaviors/stepper.js'
document.querySelectorAll('.stepper').forEach(group => stepper(group))
</script>
```

## 日数から求めた日付を表示する \{#derived-date\}

出力に名前を付け、`for` で元の入力を示します。この例は UTC の 12 月 28 日から暦日を数え、日数が無効な間は出力を空にします。

<ComponentPreview name="derived-date" title="日数から求めた日付を表示する" height={134} narrowHeight={165} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<label class="field" for="loan-days">Days after 28 Dec 2026
  <input class="input" type="number" id="loan-days" min="1" max="90" value="7" required>
</label>
<p><label for="loan-due">Due date</label> <output id="loan-due" name="due" for="loan-days">2027-01-04</output></p>
<script>
const days = document.getElementById('loan-days')
const due = document.getElementById('loan-due')
function updateDue() {
  const date = new Date(Date.UTC(2026, 11, 28))
  if (!days.validity.valid) { due.value = ''; return }
  date.setUTCDate(date.getUTCDate() + days.valueAsNumber)
  due.value = date.toISOString().slice(0, 10)
}
days.addEventListener('input', updateDue)
updateDue()
</script>`} />
