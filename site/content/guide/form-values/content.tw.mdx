## 同一表單的兩組地址 \{#address-sections\}

各組地址有自己的標題與獨立欄位名稱。以 `section-*` 前綴和地址類型區分自動填寫群組。

```html
<form>
  <fieldset class="fieldset"><legend class="fieldset-legend">Billing address</legend>
    <label class="field">Street <input class="input" name="billingStreet" autocomplete="section-bill billing street-address"></label>
    <label class="field">Postal code <input class="input" name="billingPost" autocomplete="section-bill billing postal-code"></label>
  </fieldset>
  <fieldset class="fieldset"><legend class="fieldset-legend">Shipping address</legend>
    <label class="field">Street <input class="input" name="shippingStreet" autocomplete="section-ship shipping street-address"></label>
    <label class="field">Postal code <input class="input" name="shippingPost" autocomplete="section-ship shipping postal-code"></label>
  </fieldset>
</form>
```

## 可複製及提交的編號 \{#readonly-id\}

有名稱的唯讀欄位仍會隨表單送出。將焦點移入後選取文字即可複製完整編號。

```html
<form id="receipt">
  <label class="field">Receipt number <input class="input" name="receipt" readonly value="RC-00126"></label>
</form>
<script>
const receipt = new FormData(document.getElementById('receipt')).get('receipt')
// receipt === 'RC-00126'
</script>
```

## 勾選同意與條款連結 \{#terms-link\}

連結放在核取方塊標籤旁。鍵盤可以獨立聚焦連結，開啟條款時勾選狀態維持原值。

```html
<div class="flex items-baseline flex-wrap gap(8)">
  <label class="check"><input class="checkbox" type="checkbox" name="terms" required> I agree to the terms</label>
  <a class="link" href="#license-terms">Read the terms</a>
</div>
<section id="license-terms"><h2 class="heading">License terms</h2><p>Keep the recording credits with each download.</p></section>
```

## 提供建議並接受新值 \{#open-ended-options\}

用 datalist 提供輸入建議。新的非空白測站名稱也能以同一個欄名提交。

```html
<form method="get">
  <label class="field">Station
    <input class="input" name="station" list="known-stations" required>
  </label>
  <datalist id="known-stations"><option value="East Pier"></option><option value="West Pier"></option></datalist>
  <button class="btn" type="submit">Continue</button>
</form>
```

## 不同地區的同名選項 \{#duplicate-option-names\}

選項文字保留地區名稱。收起選單後，瀏覽器可能只顯示選項本身。

```html
<label class="field">Collection point
  <select class="select" name="branch">
    <optgroup label="North"><option value="north-central">Central · North</option></optgroup>
    <optgroup label="South"><option value="south-central">Central · South</option></optgroup>
  </select>
</label>
```

## 分享網址後仍能還原的篩選 \{#shareable-filters\}

核取方塊使用同一欄名和不同值。首次載入或從歷史紀錄返回時，讀取網址中的全部值，也要還原一項都沒選的情況。

```html
<form method="get" id="station-filter">
  <fieldset class="fieldset"><legend class="fieldset-legend">Habitats</legend>
    <label class="check"><input class="checkbox" type="checkbox" name="habitat" value="coast"> Coast</label>
    <label class="check"><input class="checkbox" type="checkbox" name="habitat" value="forest"> Forest</label>
  </fieldset>
  <button class="btn">Apply filters</button>
</form>
<script>
const filters = document.getElementById('station-filter')
function restore() {
  const selected = new Set(new URLSearchParams(location.search).getAll('habitat'))
  for (const box of filters.querySelectorAll('[name="habitat"]')) box.checked = selected.has(box.value)
}
restore()
window.addEventListener('pageshow', restore)
</script>
```

## 未作答與尚未決定 \{#undecided\}

保留選填。沒有勾選時，FormData 不含這個欄位；選擇「尚未決定」時，會送出專屬的值。

```html
<form method="get">
  <fieldset class="fieldset"><legend class="fieldset-legend">Will you attend?</legend>
    <label class="check"><input class="radio" type="radio" name="attendance" value="yes"> Yes</label>
    <label class="check"><input class="radio" type="radio" name="attendance" value="no"> No</label>
    <label class="check"><input class="radio" type="radio" name="attendance" value="undecided"> Undecided</label>
  </fieldset>
  <button class="btn" type="submit">Continue</button>
</form>
```

## 每次增減四分之一單位 \{#quarter-steps\}

同時指定起始值和間距。以零為起點時，1.25 合法，1.20 則不符合間距。

```html
<label class="field">Hours worked (quarter hours)
  <input class="input" type="number" name="hours" min="0" step="0.25" value="1.25">
</label>
```

## 空欄位旁仍可見的單位 \{#persistent-unit\}

單位放在欄值外，並將全名關聯為說明。清空欄位後，仍可看到單位並讀到其意義。

```html
<div class="field">
  <label for="length">Cable length</label>
  <div class="flex items-baseline gap(8)">
    <input class="input" type="number" min="0" step="any" id="length" name="lengthM" aria-describedby="length-unit">
    <span id="length-unit">metres</span>
  </div>
</div>
```

      <input class="input stepper-field" type="number" min="0" value="2" aria-labelledby="design-seats" name="design">
      <button type="button" class="btn btn-square" value="1" tabindex="-1" aria-labelledby="design-more design-seats"><span id="design-more" class="sr-only">Increase</span>+</button>
    </div>
  </td></tr>
  <tr><th id="review-seats" scope="row">Review seats</th><td>
    <div class="input-group stepper">
      <button type="button" class="btn btn-square" value="-1" tabindex="-1" aria-labelledby="review-less review-seats"><span id="review-less" class="sr-only">Decrease</span>−</button>
      <input class="input stepper-field" type="number" min="0" value="1" aria-labelledby="review-seats" name="review">

## 顯示依天數推算的日期 \{#derived-date\}

為輸出欄位命名，用 `for` 指出來源。本例從 UTC 的 12 月 28 日起按日曆日計算，天數無效時清空輸出。

<ComponentPreview name="derived-date" title="顯示依天數推算的日期" height={134} narrowHeight={165} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<label class="field" for="loan-days">Days after 28 Dec 2026
  <input class="input" type="number" id="loan-days" min="1" max="90" value="7" required>
</label>
<p><label for="loan-due">Due date</label> <output id="loan-due" name="due" for="loan-days">2027-01-04</output></p>
<script>
const days = document.getElementById('loan-days')
const due = document.getElementById('loan-due')
function updateDue() {
  const date = new Date(Date.UTC(2026, 11, 28))
  if (!days.validity.valid) { due.value = ''; return }
  date.setUTCDate(date.getUTCDate() + days.valueAsNumber)
  due.value = date.toISOString().slice(0, 10)
}
days.addEventListener('input', updateDue)
updateDue()
</script>`} />
