## A reference to copy and submit \{#readonly-id\}

The named readonly field still participates in the form. Focus it and select its contents to copy the complete reference.

```html

  <label class="field">Receipt number <input class="input" name="receipt" readonly value="RC-00126"></label>
</form>
<script>

```

## Filters that survive a shared URL \{#shareable-filters\}

Give each checkbox the same name and a distinct value. Read all occurrences from the URL on initial load and on history restoration, including a return to no checked values.

```html
<form method="get" id="station-filter">
  <fieldset class="fieldset"><legend class="fieldset-legend">Habitats</legend>
    <label class="check"><input class="checkbox" type="checkbox" name="habitat" value="coast"> Coast</label>
    <label class="check"><input class="checkbox" type="checkbox" name="habitat" value="forest"> Forest</label>
  </fieldset>
  <button class="btn">Apply filters</button>
</form>
<script>
const filters = document.getElementById('station-filter')
function restore() {
  const selected = new Set(new URLSearchParams(location.search).getAll('habitat'))
  for (const box of filters.querySelectorAll('[name="habitat"]')) box.checked = selected.has(box.value)
}
restore()
window.addEventListener('pageshow', restore)
</script>
```

## Show the date derived from a duration \{#derived-date\}

Name the output and identify its source with `for`. This example counts calendar days from 28 December in UTC and clears the output while the duration is invalid.

<ComponentPreview name="derived-date" title="Show the date derived from a duration" height={134} narrowHeight={165} background="plain" bodyClass="flex flex-col justify-center p-md" html={`<label class="field" for="loan-days">Days after 28 Dec 2026
  <input class="input" type="number" id="loan-days" min="1" max="90" value="7" required>
</label>
<p><label for="loan-due">Due date</label> <output id="loan-due" name="due" for="loan-days">2027-01-04</output></p>
<script>
const days = document.getElementById('loan-days')
const due = document.getElementById('loan-due')
function updateDue() {
  const date = new Date(Date.UTC(2026, 11, 28))
  if (!days.validity.valid) { due.value = ''; return }
  date.setUTCDate(date.getUTCDate() + days.valueAsNumber)
  due.value = date.toISOString().slice(0, 10)
}
days.addEventListener('input', updateDue)
updateDue()
</script>`} />
