원형 차트와 도넛 차트는 전체가 어떤 항목으로 구성되는지 보여 줍니다. 각 조각은 합계에서 차지하는 비율을 나타내며, 조각 사이의 간격은 일정하고 모서리는 둥글게 처리합니다. 여섯 번째 조각까지 넣으면 작은 조각을 알아보기 어려우므로, 나머지는 "기타"로 묶어 전체 조각을 다섯 개 이하로 유지합니다.

## 옆에 배치하는 범례 \{#legend\}

차트에 `chart-split` 클래스를 적용하면 범례가 원형 차트 옆에 세로로 놓이고, 각 항목의 끝에 해당 조각의 비율이 표시됩니다. 옆 공간이 부족하면 범례가 차트 아래로 이동합니다.

`pie`는 가운데가 뚫리지 않은 형태입니다. `--chart-size`는 두 차트의 너비이며 기본값은 12rem입니다. `hole`은 도넛 차트의 바깥쪽 반지름에 대한 구멍 반지름의 비율이며 기본값은 .7입니다.

## 원형 차트와 도넛 차트 \{#pie-or-donut\}

[도넛 차트](/charts/donut)는 중앙에 수치 하나를 표시할 수 있고, 원형 차트는 원 전체를 조각으로 채웁니다. 하나의 막대에서 각 부분을 보여 주려면 [Breakdown](/components/breakdown)을 사용합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `series` | `[]` | 각 계열에 `name`과 함께 `values`, 조각이나 링의 `value`, 또는 산점도의 `points`를 지정합니다. `category`, `type`, 링의 `max`도 지정할 수 있습니다. |
| `format`, `tickFormat` | 로캘에 따름 | 값과 눈금 레이블의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `legend`, `toggle` | 계열이 두 개일 때 표시, `true` | 범례를 표시할지, 범례 항목을 체크박스로 표시할지 지정합니다. |

값 표시, 키보드 조작, 범례, 색상, 척도는 모든 차트 유형에 공통으로 적용됩니다. [차트](/components/chart)에서 공통 동작과 모든 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
