饼图和环形图都用于展示整体的构成。每个扇区的大小取决于它占总和的比例，扇区之间保持固定间距，边角采用圆角。将整体分成最多五部分，其余合并为“其他”，因为第六个狭小的扇区很难辨认。

## 侧边图例 \{#legend\}

给图表添加 `chart-split` 类后，图例会在饼图旁纵向排列，每项末尾显示对应扇区的占比。空间不足时，图例会移到饼图下方。

`pie` 与环形图的区别在于中心没有孔。`--chart-size` 设置两种图的宽度，默认为 12rem。`hole` 表示环形图的内孔半径占外圆半径的比例，默认为 .7。

## 饼图还是环形图 \{#pie-or-donut\}

[环形图](/charts/donut)的中心可用来显示一个数值，饼图则把整个圆都留给扇区。要在一根条形中展示各部分，可使用[构成条](/components/breakdown)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，也可为扇区或圆环提供 `value`，或为散点图提供 `points`；还可指定 `category`、`type` 及圆环的 `max` |
| `format`, `tickFormat` | 由区域设置决定 | 数值和刻度的显示格式；散点图的横轴使用 `xFormat` |
| `legend`, `toggle` | 有两个数据系列时显示, `true` | 分别控制是否显示图例，以及图例项是否以复选框呈现 |

所有图表类型共用相同的读数提示、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了全部选项、CSS 类和自定义属性。
