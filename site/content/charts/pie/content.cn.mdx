饼图和环形图展示整体由哪些部分构成。每个扇区的大小是它在总和中的占比，与相邻扇区保持固定的间隙，并带有圆角。一个整体最多保留五个部分，其余归入“其他”：第六个细小的扇区没有人会读。

## 图例放在旁边 \{#legend\}

在图表上添加 `chart-split`，图例会以一列排在饼图旁边，每行末尾显示该扇区的占比；空间不足时则移到饼图下方。

`pie` 与之相同，只是没有中空部分。`--chart-size` 是两者的宽度，默认为 12rem；`hole` 是中空部分占环形图半径的比例，默认为 .7。

## 饼图还是环形图 \{#pie-or-donut\}

[环形图](/charts/donut)把中央留给一个数字；饼图则让扇区占满整个圆。若要沿着一根条形阅读各部分，请用[占比分布](/components/breakdown)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 图表展示的内容及其单位，即绘图区的无障碍名称 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，扇区或圆环使用 `value`，散点图使用 `points`；还可选填 `category`、`type` 和圆环的 `max` |
| `format`, `tickFormat` | 按 locale 的格式 | 数值和刻度数字的书写方式；散点图的横向刻度使用 `xFormat` |
| `legend`, `toggle` | 有两个数据系列时生成，`true` | 是否生成图例，以及图例项是否为复选框 |

数值提示、键盘操作、图例、颜色和刻度在每种图表类型中都相同：[图表](/components/chart)页面有完整说明，并列出全部选项、类名和自定义属性。
