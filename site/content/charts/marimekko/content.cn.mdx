马赛克图同时展示两种占比。每个标签对应一根柱，柱宽由该组占总量的比例决定。每个数据系列对应柱内的一段，段高由该系列在组内的占比决定。这样就能在一张图中同时看出各组的规模和构成，而等宽的堆叠柱状图无法同时展示这两点。

纵轴显示各部分在柱内的占比，范围为 0% 到 100%。柱宽没有刻度，因此读数提示的标题会显示各柱的总量及其占整体的比例。面积比长度更难比较。总览各组的规模和构成时用马赛克图，需要跨组比较同一部分时用[堆叠柱状图](/charts/bar#stacked)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `labels` | `[]` | 沿刻度轴、环绕雷达图或位于热力图各列上方的标签 |
| `series` | `[]` | 每个系列包含 `name` 和对应图表类型所需的数据，即 `values`、`value`、`points`、`ranges` 或 `children`；还可指定 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `format`, `tickFormat` | 由区域设置决定 | 数值和刻度的显示格式；散点图的横轴使用 `xFormat` |
| `current` | 无 | 标有 `aria-current` 的数据点索引 |
| `legend`, `toggle` | 有两个数据系列时显示, `true` | 分别控制是否显示图例，以及图例项是否以复选框呈现 |

所有图表类型共用相同的读数提示、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了全部选项、CSS 类和自定义属性。
