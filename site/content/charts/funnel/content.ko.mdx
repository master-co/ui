퍼널 차트는 방문, 가입, 활성화, 결제처럼 하나의 흐름이 어떤 단계를 거치고 각 단계에 얼마나 도달하는지 보여 줍니다. 각 계열은 한 단계에 해당하며, 너비는 첫 단계의 값 대비 해당 단계의 값에 비례합니다. 각 단계의 모양은 다음 단계의 너비까지 좁아지므로 감소 폭이 가장 큰 곳에서 가장 많이 좁아집니다. 각 단계 옆에는 이름을 표시하고 그 뒤에는 값과 첫 단계 대비 남은 비율을 표시합니다.

흐름 순서대로 단계를 전달하고 각 단계에 `value`를 하나씩 지정합니다. 첫 단계는 가장 진하고 이후 단계는 한 단계씩 옅어지므로, 너비와 색의 농도 모두에서 흐름을 읽을 수 있습니다. 각 단계가 첫 단계의 부분집합인 하나의 흐름에는 퍼널 차트를 사용합니다. 지역별 매출처럼 하나의 흐름에서 첫 단계의 부분집합에 해당하지 않는 수치는 [막대 차트](/charts/bar)로 표시합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `series` | `[]` | 각 계열에 `name`과 차트 형태에 맞는 데이터인 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`는 선택 사항입니다. |
| `format`, `tickFormat` | 로캘 기본 형식 | 값과 눈금의 표시 형식. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `current` | 없음 | `aria-current`로 표시할 점의 인덱스 |

값 표시, 키보드 조작, 범례, 색상, 척도는 모든 차트 형태에 공통으로 적용됩니다. [차트](/components/chart)에서 자세한 설명과 모든 옵션, CSS 클래스, 사용자 지정 속성을 확인할 수 있습니다.
