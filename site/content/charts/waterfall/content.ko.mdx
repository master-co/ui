폭포 차트는 기초 현금 잔액이 유입과 유출을 거쳐 기말 현금 잔액으로 바뀌는 과정처럼 값이 어떻게 변하는지 보여 줍니다. 첫 막대는 기준선에서 시작하고 이후 막대는 직전 막대가 끝난 높이에서 시작합니다. 막대의 끝을 다음 막대와 가는 선으로 이어 누적값의 흐름을 따라갈 수 있게 합니다. 증가와 감소는 상태별 잉크 색과 값에 붙는 부호로 구분합니다.

`total`은 기준선에서 합계까지 이어지는 마지막 막대의 이름을 지정합니다. 이 옵션을 생략하면 차트가 마지막 증감 단계에서 끝나므로 최종값 없이 변동 내역만 보여 주기에 적합합니다. `values: true`를 설정하면 각 막대 위에 증감량을 부호와 함께 표시합니다. 값 표시에는 해당 단계 직후의 누적값도 나옵니다.

## 증감과 상태별 잉크 색 \{#inks\}

차트 유형 중 폭포 차트만 막대에 상태별 잉크 색을 적용합니다. [Stat](/components/stat) 컴포넌트의 변화량과 마찬가지로 증가 막대에는 성공 색을, 감소 막대에는 위험 색을 적용합니다. 색으로만 구분하지 않도록 값 표시와 각 데이터 포인트의 이름에도 값과 함께 부호를 표시합니다. 비용처럼 증가가 바람직하지 않은 경우에는 차트의 `label`과 제목에 그 의미를 명시합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 접근성 이름 |
| `labels` | `[]` | 축을 따라, 레이더 차트 둘레에, 또는 히트맵 열 위에 표시하는 이름 |
| `series` | `[]` | 각 계열에 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`는 선택 사항입니다. |
| `total` | 없음 | 폭포 차트의 마지막 합계 막대 이름 |
| `min`, `max`, `ticks` | 범위 자동 맞춤, `4` | 축의 양 끝값과 대략적인 눈금 수입니다. 산점도의 가로축에는 `xMin`, `xMax`, `xTicks`를 사용합니다. |
| `format`, `tickFormat` | 로캘 기본 형식 | 값과 눈금의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `dots`, `values` | `false` | 선의 모든 데이터 포인트에 점을 표시하거나 각 막대에 값을 표시합니다. |
| `current` | 없음 | `aria-current`로 표시한 데이터 포인트의 인덱스 |

값 표시, 키보드 조작, 범례, 색상, 눈금은 모든 차트 유형에 공통입니다. [차트](/components/chart)에서 전체 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
