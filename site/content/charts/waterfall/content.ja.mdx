ウォーターフォールグラフは、期首の現金残高が入出金を経て期末の残高になるまでのように、ある値がどのように変化したかを示します。最初の棒はベースラインから始まり、以降の棒は直前の棒の終点から増減します。棒の終点から次の棒へ細い線を引くため、累計値の推移を目で追えます。増加と減少は、ステータス色と値に付く符号で区別します。

`total` は、ベースラインから合計値まで伸びる最後の棒の名前を指定します。省略すると、グラフは最後の増減で終わります。最終値を示さずに変動だけを並べる場合に適しています。`values: true` を指定すると、各棒の上に増減量が符号付きで表示され、詳細表示には増減後の累計値も表示されます。

## 増減とステータス色 \{#inks\}

ウォーターフォールグラフだけは、データの描画にステータス色を使います。[Stat](/components/stat) の変化量と同様に、増加には成功色、減少には危険色を使います。詳細表示と各データ点の名前では、すべての値に符号も付けます。コストのように増加が望ましくない指標では、そのことをグラフの `label` とタイトルに明記します。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフの内容と単位を示す、プロット領域のアクセシブルな名前 |
| `labels` | `[]` | 軸に沿って、レーダーチャートの周囲に、またはヒートマップの各列の上に表示する名前 |
| `series` | `[]` | 各系列に `name` と、形式に応じて `values`、`value`、`points`、`ranges`、`children` のいずれかを指定。`category`、`type`、`low` と `high`、リングの `max` は任意 |
| `total` | なし | ウォーターフォールグラフの最後に表示する合計の棒の名前 |
| `min`, `max`, `ticks` | 自動調整, `4` | スケールの両端と目盛りの数の目安。散布図の横軸には `xMin`、`xMax`、`xTicks` を使用 |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使用 |
| `dots`, `values` | `false` | 折れ線の各データ点に印を付けるか、各棒の値を表示するか |
| `current` | なし | `aria-current` で示すデータ点のインデックス |

詳細表示、キーボード操作、凡例、色、スケールはすべてのグラフ形式で共通です。[チャート](/components/chart) では、これらの機能とすべてのオプション、CSS クラス、カスタムプロパティを説明しています。
