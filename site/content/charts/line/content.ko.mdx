## 선의 형태 \{#curve\}

`curve`는 점과 점을 잇는 방식을 지정합니다. 기본값인 `smooth`는 데이터에 없는 봉우리나 골이 생기지 않도록 값을 넘지 않는 부드러운 곡선을 그립니다. `linear`는 점을 직선으로 잇고, `step`은 다음 값이 나오기 전까지 현재 값을 유지하므로 요금제의 좌석 수나 가격처럼 한 번에 바뀌는 값에 적합합니다.

<ComponentPreview name="step" height={348} title="계단형" bodyClass="p-lg" behaviors html={`<div class="card max-w(560) mx-auto">
  <div class="card-header">
    <h3 class="card-title">Seats</h3>
    <p class="card-description">On the plan, this year</p>
  </div>
  <figure class="chart" id="seats" style="--chart-height: 11rem"></figure>
</div>
<script>
addEventListener('DOMContentLoaded', function () {
  MasterUI.chart(document.getElementById('seats'), {
    type: 'line',
    curve: 'step',
    label: 'Seats on the plan per month',
    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'],
    series: [{ name: 'Seats', values: [12, 12, 12, 20, 20, 20, 20, 32, 32, 32, 40, 40] }],
    max: 40
  })
})
</script>`} />

## 빈 구간과 점 \{#gaps\}

값이 `null`이면 해당 구간의 선이 끊기고, 해당 위치의 값 표시에는 값이 있는 계열만 나옵니다. `dots: true`를 설정하면 포인터 아래의 점을 포함해 선의 모든 점을 표시합니다. 점이 몇 개 없는 선에 사용합니다.

<ComponentPreview name="gaps" height={348} title="빈 구간과 점" bodyClass="p-lg" behaviors html={`<div class="card max-w(560) mx-auto">
  <div class="card-header">
    <h3 class="card-title">Uptime</h3>
    <p class="card-description">Percent per month; no reading in May</p>
  </div>
  <figure class="chart" id="uptime" style="--chart-height: 11rem"></figure>
</div>
<script>

  MasterUI.chart(document.getElementById('uptime'), {
    type: 'line',
    curve: 'linear',
    dots: true,

    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug'],

    format: function (value) { return value + '%' }
  })
})
</script>`} />

## 값의 범위 \{#band\}

계열에 레이블마다 `low`와 `high`를 하나씩 지정하면 예측값이 가질 수 있는 범위나 두 번의 실행 결과 사이의 폭을 나타낼 수 있습니다. 선 뒤에 선과 같은 색의 옅은 띠로 그리며, 값 표시에는 수치 뒤에 범위를 함께 표시합니다.

## 막대 위에 선 표시 \{#over-bars\}

[막대 차트](/charts/bar#many)에서 계열에 `type: 'line'`을 지정하면 막대와 같은 척도를 사용해 막대 위에 선을 그립니다. 목표값이나 이동 평균을 표시할 때 사용합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `labels` | `[]` | 축을 따라, 레이더 차트 둘레에, 또는 히트맵의 열 위에 표시하는 이름 |
| `series` | `[]` | 각 계열의 `name`과 차트 유형에 따라 사용하는 `values`, `value`, `points`, `ranges` 또는 `children`입니다. `category`, `type`, `low`와 `high`, 링의 `max`도 지정할 수 있습니다. |
| `curve` | `'smooth'` | `smooth`, `linear` 또는 `step` |
| `min`, `max`, `ticks` | 데이터에 맞춤, `4` | 축의 양 끝값과 대략적인 눈금 수입니다. 산점도의 가로축에는 `xMin`, `xMax`, `xTicks`를 사용합니다. |
| `format`, `tickFormat` | 로캘에 따름 | 값과 눈금 레이블의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `dots`, `values` | `false` | 선의 모든 점을 표시하고 각 막대에 값을 표시할지 지정합니다. |
| `legend`, `toggle` | 계열이 두 개일 때 표시, `true` | 범례를 표시할지, 범례 항목을 체크박스로 표시할지 지정합니다. |

값 표시, 키보드 조작, 범례, 색상, 척도는 모든 차트 유형에 공통으로 적용됩니다. [차트](/components/chart)에서 공통 동작과 모든 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
