## 곡선 \{#curve\}

`curve`는 선이 지점에서 지점으로 어떻게 이어지는지 정합니다. 기본값인 `smooth`는 값을 넘어서지 않는 곡선입니다. 데이터에 없는 봉우리 위로 올라가거나 데이터에 없는 골짜기 아래로 내려가지 않습니다. `linear`는 직선 구간으로 그립니다. `step`은 다음 값이 나올 때까지 각 값을 유지하며, 요금제의 좌석 수나 가격처럼 한 번에 바뀌는 수량에 사용합니다.

  <div class="card-header">
    <h3 class="card-title">Seats</h3>
    <p class="card-description">On the plan, this year</p>
  </div>
  <figure class="chart" id="seats" style="--chart-height: 11rem"></figure>
</div>

addEventListener('DOMContentLoaded', function () {
  MasterUI.chart(document.getElementById('seats'), {

## 빈 구간과 점 \{#gaps\}

값이 `null`이면 선에 빈 구간이 생기고, 해당 지점은 값이 있는 계열만 알려 줍니다. `dots: true`는 포인터 아래의 지점뿐 아니라 선의 모든 지점을 점으로 표시합니다. 지점이 몇 개뿐인 선에만 사용하세요.

  <div class="card-header">

    <p class="card-description">Percent per month; no reading in May</p>

</div>

## 막대 위의 선 \{#over-bars\}

[막대 차트](/charts/bar#many)에서 `type: 'line'`을 지정한 계열은 같은 눈금 위에서 막대 위의 선으로 그려집니다. 목표값이나 이동 평균에 사용합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 무엇을 어떤 단위로 보여 주는지 알려 주는, 그래프 영역의 접근 가능한 이름 |
| `labels` | `[]` | 눈금을 따라 놓이는 이름 또는 레이더 둘레에 놓이는 이름 |
| `series` | `[]` | 각 계열에는 `name`과 `values`를 지정합니다. 조각이나 링에는 `value`를, 산점도에는 `points`를 지정합니다. 선택적으로 `category`, `type`, 링의 `max`를 지정할 수 있습니다 |
| `curve` | `'smooth'` | `smooth`, `linear` 또는 `step` |
| `min`, `max`, `ticks` | 데이터에 맞춤, `4` | 눈금의 양 끝과 눈금을 표시하는 대략적인 단계 수. 산점도의 가로 눈금에는 `xMin`, `xMax`, `xTicks`를 사용합니다 |
| `format`, `tickFormat` | 로캘의 형식 | 값과 눈금 숫자를 적는 방식. 산점도의 가로 눈금에는 `xFormat`을 사용합니다 |
| `dots`, `values` | `false` | 선의 모든 지점을 점으로 표시합니다. 모든 막대의 값을 적습니다 |
| `legend`, `toggle` | 계열이 둘이면 작성, `true` | 범례를 작성할지 여부와 범례 항목을 체크박스로 만들지 여부 |

값 표시창, 키 조작, 범례, 색, 눈금은 모든 형식에서 같습니다. [차트](/components/chart) 페이지에 모든 옵션, 클래스, 사용자 정의 속성과 함께 정리되어 있습니다.
