## 曲线 \{#curve\}

`curve` 决定折线如何从一个数据点走到下一个数据点。默认值 `smooth` 是一条不会越过数值的曲线：它不会高出数据中不存在的峰值，也不会低于数据中不存在的谷值。`linear` 绘制直线段。`step` 让每个数值保持到下一个数值出现，适用于一次性变化的量，例如套餐的席位数或价格。

## 缺口与数据点 \{#gaps\}

值为 `null` 时，折线在该处留出缺口，对应的数据点只说明有数值的数据系列。`dots: true` 会标出折线上的每个数据点，而不只是指针所在的那一个；仅在折线只有少数几个数据点时使用。

## 叠在条形上的折线 \{#over-bars\}

在[条形图](/charts/bar#many)中，设置了 `type: 'line'` 的系列会以折线叠在条形之上，并使用同一刻度，例如目标值或移动平均。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 图表展示的内容及其单位，即绘图区的无障碍名称 |
| `labels` | `[]` | 沿刻度排列的名称，或雷达图四周的名称 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，扇区或圆环使用 `value`，散点图使用 `points`；还可选填 `category`、`type` 和圆环的 `max` |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 自动适配，`4` | 刻度的两端，以及大约分几段标出；散点图的横向刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 按 locale 的格式 | 数值和刻度数字的书写方式；散点图的横向刻度使用 `xFormat` |
| `dots`, `values` | `false` | 标出折线上的每个数据点；写出每根条形的数值 |
| `legend`, `toggle` | 有两个数据系列时生成，`true` | 是否生成图例，以及图例项是否为复选框 |

数值提示、键盘操作、图例、颜色和刻度在每种图表类型中都相同：[图表](/components/chart)页面有完整说明，并列出全部选项、类名和自定义属性。
