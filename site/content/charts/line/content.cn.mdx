## 曲线 \{#curve\}

`curve` 决定如何连接各个数据点。默认值 `smooth` 绘制平滑曲线，曲线不会越过数据的峰值或谷值。`linear` 用直线段连接各点，`step` 将每个值保持到下一点，适合套餐席位数、价格等在某一时刻突变的数值。

## 断点与圆点标记 \{#gaps\}

值为 `null` 时，折线会在该位置断开，读数提示仅显示在该位置有值的数据系列。`dots: true` 会标出折线上的所有数据点，包括指针未指向的点，适合数据点较少的折线。

## 数值区间 \{#band\}

数据系列可以通过 `low` 和 `high` 为每个标签分别指定下限和上限，用来表示预测范围或两次运行结果之间的区间。图表会在折线后方用同色的浅色带绘制这个区间，读数提示也会在数值后显示该区间。

## 在柱形上叠加折线 \{#over-bars\}

在[柱状图](/charts/bar#many)中，将数据系列设为 `type: 'line'`，即可在柱形上叠加一条与柱形共用同一标度的折线，例如目标线或移动平均线。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `labels` | `[]` | 沿刻度轴、环绕雷达图或位于热力图各列上方的标签 |
| `series` | `[]` | 每个系列包含 `name` 和对应图表类型所需的数据，即 `values`、`value`、`points`、`ranges` 或 `children`；还可指定 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 自动适配, `4` | 刻度范围的两端及大致的刻度数；散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 由区域设置决定 | 数值和刻度的显示格式；散点图的横轴使用 `xFormat` |
| `dots`, `values` | `false` | 分别用于标出折线上的每个数据点和显示每根柱形的数值 |
| `legend`, `toggle` | 有两个数据系列时显示, `true` | 分别控制是否显示图例，以及图例项是否以复选框呈现 |

所有图表类型共用相同的读数提示、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了全部选项、CSS 类和自定义属性。
