折れ線は、月ごとのレイテンシーや日ごとの価格など、連続する値の推移を表します。グラフに棒がなければ、線はプロット領域の端から端まで伸びます。ポインターを重ねると、対応するデータ位置を細い線で示し、その位置での各系列の値を点で示します。

## 曲線 \{#curve\}

`curve` は点と点の結び方を指定します。既定の `smooth` は、隣り合う点の値の範囲を超えないように滑らかな曲線を描きます。`linear` は直線で結びます。`step` は次の点まで値を一定に保つので、プランの利用枠数や価格など、ある時点で値が切り替わるデータに適しています。

## 欠損と点 \{#gaps\}

値が `null` の箇所では線が途切れ、その位置の値表示には値がある系列だけが表示されます。`dots: true` を指定すると、ポインターを重ねた点に加え、折れ線上のすべての点に印が付きます。点の少ない折れ線に使います。

## 値の範囲 \{#band\}

系列の各ラベルに `low` と `high` を1つずつ指定すると、予測の幅や2回の実行結果のばらつきなど、値が取りうる範囲を示せます。この範囲は折れ線の背後に線と同系色の淡い帯で描かれ、値表示では値に続けて表示されます。

## 棒に重ねる折れ線 \{#over-bars\}

[棒グラフ](/charts/bar#many)で `type: 'line'` を指定した系列は、棒と同じ目盛りを使って折れ線として重ねて描画されます。目標値や移動平均を示すのに使えます。

## オプション \{#options\}

| オプション | 既定値 | |
| --- | --- | --- |
| `label` | なし | グラフが何をどの単位で示すかを伝える、プロットのアクセシブルな名前 |
| `labels` | `[]` | 目盛りに沿って、レーダーチャートの周囲に、またはヒートマップの列の上に並ぶ名前 |
| `series` | `[]` | 各系列に `name` と、グラフ形式に応じて `values`、単一の `value`、`points`、`ranges`、`children` のいずれかを指定。`category`、`type`、`low` と `high`、リングの `max` は任意 |
| `curve` | `'smooth'` | `smooth`、`linear`、`step` のいずれか |
| `min`, `max`, `ticks` | データに合わせる、`4` | 目盛りの下限と上限、およその目盛り数。散布図の横軸には `xMin`、`xMax`、`xTicks` を使用 |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使用 |
| `dots`, `values` | `false` | 折れ線のすべての点に印を付けるか、各棒の値を表示するか |
| `legend`, `toggle` | 2系列の場合、`true` | 凡例を表示するか、凡例の各項目をチェックボックスにするか |

値表示、キー操作、凡例、色、目盛りはすべてのグラフ形式で共通です。[チャート](/components/chart)に、すべてのオプション、クラス、カスタムプロパティとあわせて記載しています。
