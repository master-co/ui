## 曲線 \{#curve\}

`curve` 決定折線如何從一個點連到下一個點。預設的 `smooth` 是絕不超出數值的曲線：它不會高過資料中沒有的波峰，也不會低於資料中沒有的波谷。`linear` 畫出直線段，`step` 則讓每個數值維持到下一個數值為止，適合一次變動到位的數量，例如方案的席次或價格。

## 缺口與資料點 \{#gaps\}

數值為 `null` 時，折線會在該處留下缺口，該資料點也只說出有數值的序列。`dots: true` 會標出折線上的每個點，不只是指標所在的那一點；請只用於點數不多的折線。

## 疊在長條上的折線 \{#over-bars\}

在[長條圖](/charts/bar#many)中，設定 `type: 'line'` 的序列會以折線疊在長條上，並使用同一個刻度，例如目標值或移動平均。

## 選項 \{#options\}

| 選項 | 預設值 | |
| --- | --- | --- |
| `label` | 無 | 圖表呈現的內容及單位，也就是繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿著刻度排列的名稱，或環繞雷達圖的名稱 |
| `series` | `[]` | 每組序列都有 `name` 和 `values`；扇形或圓環改用 `value`，散佈圖改用 `points`；另可選擇性提供 `category`、`type`，以及圓環的 `max` |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 自動配合、`4` | 刻度的兩端，以及大約用幾格標示；散佈圖的橫向刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 依語系 | 數值和刻度標記的寫法；散佈圖的橫向刻度使用 `xFormat` |
| `dots`, `values` | `false` | 標出折線上的每個點；寫出每根長條的數值 |
| `legend`, `toggle` | 有兩組序列時寫出、`true` | 是否寫出圖例，以及圖例項目是否為核取方塊 |

數值提示、鍵盤操作、圖例、顏色與刻度在每種圖表類型中都相同：[圖表](/components/chart)頁面有完整說明，並列出所有選項、類別與自訂屬性。
