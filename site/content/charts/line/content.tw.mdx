## 曲線 \{#curve\}

`curve` 決定如何連接各點。預設的 `smooth` 會畫出平滑曲線，且不會在各點之間產生資料中沒有的峰值或谷值。`linear` 以直線連接各點，`step` 則維持目前的數值，直到下一個點才切換，適合一次跳變的數值，例如方案的席次或價格。

## 缺值與資料點 \{#gaps\}

數值為 `null` 時，折線會在該處中斷，該點的數值提示只會列出有數值的資料序列。`dots: true` 會標示折線上的每個點，而非只標示指標所在的點，適合資料點較少的折線。

## 數值的可能範圍 \{#band\}

在資料序列中為每個標籤指定一組 `low` 和 `high`，就能呈現數值的可能範圍，例如預測區間或兩次執行結果之間的範圍。圖表會在折線後方以同色的淡色區間帶呈現，數值提示則會在數值後列出這個範圍。

## 在長條上疊加折線 \{#over-bars\}

在[長條圖](/charts/bar#many)中，設為 `type: 'line'` 的資料序列會以折線疊加在長條上，並共用同一個刻度，適合呈現目標值或移動平均。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿刻度、雷達圖周圍或熱圖各欄上方顯示的名稱 |
| `series` | `[]` | 每個資料序列都有 `name`，並依圖表類型提供 `values`、`value`、`points`、`ranges` 或 `children`。可選填 `category`、`type`、`low` 和 `high`，以及圓環的 `max` |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 依資料調整、`4` | 刻度範圍的兩端與大致的刻度數量。散佈圖的橫軸使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 依地區設定 | 數值與刻度標籤的顯示格式。散佈圖的橫軸使用 `xFormat` |
| `dots`, `values` | `false` | 標示折線上的每個點，以及顯示每根長條的數值 |
| `legend`, `toggle` | 有兩個資料序列時顯示、`true` | 是否顯示圖例，以及是否將圖例項目呈現為核取方塊 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。[圖表](/components/chart) 元件提供這些功能，並列出所有選項、CSS 類別與自訂屬性。
