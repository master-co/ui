A dumbbell compares two values of each thing: before and after, one year and another, one group and the next. Each series is a dot, and a stem joins the dots of one label, so what a reader sees first is the gap and which way it runs. It says the same as two bars side by side with a fraction of the ink, and it does not need to start at zero.

A dumbbell usually runs across, `horizontal: true`, so the names read as a list. Sort the labels by the gap or by one of the values before giving them: the order is part of what the chart says. With three series or more each label has a dot for each and the stem runs from the lowest to the highest.

## Options \{#options\}

| Option | Default | |
| --- | --- | --- |
| `label` | none | What the chart shows and in what unit: the plot's accessible name |
| `labels` | `[]` | The names along the scale, around a radar or over a heatmap's columns |
| `series` | `[]` | Each with a `name` and what its form reads: `values`, a `value`, `points`, `ranges` or `children`; optionally a `category`, a `type`, `low` and `high`, and a ring's `max` |
| `horizontal` | `false` | Bars, ranges, dumbbells and boxes run across |
| `min`, `max`, `ticks` | fit, `4` | The ends of the scale and about how many steps mark it; `xMin`, `xMax` and `xTicks` for a scatter's scale across |
| `format`, `tickFormat` | the locale's | How a value and a tick are written; `xFormat` for a scatter's scale across |
| `current` | none | The index of the point marked `aria-current` |
| `legend`, `toggle` | with two series, `true` | Whether a legend is written, and whether its entries are checkboxes |

The readout, the keys, the legend, the colors and the scale are the same in every form: [Chart](/components/chart) holds them, with every option, class and custom property.
