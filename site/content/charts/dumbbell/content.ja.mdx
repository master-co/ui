ダンベルチャートは、前後、異なる年、異なるグループなど、項目ごとに二つの値を比較します。各系列の値を点で示し、同じラベルの点を線で結ぶため、差の大きさとどちらの値が大きいかがひと目でわかります。2本の棒を並べたグラフと同じ情報を少ない描画要素で示せます。軸をゼロから始める必要もありません。

通常は `horizontal: true` で横向きにし、項目名を縦に並べて読みやすくします。差の大きさか、どちらか一方の系列の値でラベルを並べ替えてから渡します。並び順もグラフが伝える情報の一部です。3系列以上では、ラベルごとに各系列の点を表示し、最小値から最大値までを線で結びます。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフが示す内容と単位を表す、プロットのアクセシブルな名前 |
| `labels` | `[]` | 軸に沿った項目名、レーダーチャートの周囲の項目名、またはヒートマップの列名 |
| `series` | `[]` | 各系列に `name` と、形式に応じて `values`、`value`、`points`、`ranges`、`children` のいずれかを指定します。`category`、`type`、`low` と `high`、円環の `max` は任意です |
| `horizontal` | `false` | 棒、範囲、ダンベル、箱ひげを横向きに表示 |
| `min`, `max`, `ticks` | データに合わせて自動調整, `4` | 軸の両端の値と目盛りの数の目安。散布図の横軸には `xMin`、`xMax`、`xTicks` を使用 |
| `format`, `tickFormat` | ロケールに準拠 | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使用 |
| `current` | なし | `aria-current` を付けるデータ点のインデックス |
| `legend`, `toggle` | 2系列の場合に表示, `true` | 凡例を表示するかどうかと、凡例の項目をチェックボックスにするかどうか |

値の表示、キー操作、凡例、色、スケールは、すべての形式で共通です。すべてのオプション、クラス、カスタムプロパティは [チャート](/components/chart) に記載しています。
