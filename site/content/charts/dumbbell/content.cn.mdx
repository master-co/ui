哑铃图用于比较每个对象的两个数值，例如变化前后、两个年份或两个群体的数据。同一标签下，每个数据系列用一个点表示，各点由线段连接，让读者一眼看出差距有多大、哪个值更高。它用占用面积小得多的点和线传达与两根并排柱条相同的信息，数值轴也无需从零开始。

哑铃图通常采用横向布局，即 `horizontal: true`，便于逐行阅读名称。传入标签前，先按差值或其中一组数值排序，因为排列顺序也能传达信息。有三个或更多数据系列时，每个标签都为各数据系列绘制一个点，线段从最小值延伸到最大值。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 绘图区的无障碍名称，说明图表展示的内容及其单位 |
| `labels` | `[]` | 沿坐标轴、环绕雷达图或位于热力图各列上方的名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和与图表类型对应的数据字段：`values`、`value`、`points`、`ranges` 或 `children`。还可指定 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `horizontal` | `false` | 让条形、区间、哑铃和箱体横向排列 |
| `min`, `max`, `ticks` | 自动适配, `4` | 坐标轴的两端及大致的刻度数。散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 由区域设置决定 | 数值和刻度的显示格式。散点图的横轴使用 `xFormat` |
| `current` | 无 | 标记了 `aria-current` 的数据点索引 |
| `legend`, `toggle` | 有两个数据系列时显示图例, `true` | 是否显示图例，以及图例项是否为复选框 |

所有图表类型共用相同的读数显示、按键操作、图例、颜色和刻度。有关这些行为以及所有选项、类和自定义属性，请参阅 [图表](/components/chart)。
