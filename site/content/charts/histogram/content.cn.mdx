直方图展示观测值的分布，包括多数值集中在哪里、分布范围有多广，以及是否偏向一侧。图表以便于读数的整值为边界，把第一个数据系列的观测值分到各个区间。每个区间对应一根柱，柱高表示落入该区间的观测值数量。横轴连续，因此相邻的柱彼此紧贴。

将原始观测值传入数据系列的 `values`，不要传入预先统计的次数。各区间的观测值数量由图表计算。用 `bins` 指定大致的区间数。省略时，图表根据观测值数量自动划分 5 到 20 个区间。区间边界采用便于读数的整值，因此区间可读作“200 到 250”。恰好落在边界上的观测值归入以该边界为起点的区间。

直方图的每根柱对应同一指标的一个数值区间，按区间顺序排列。按类别比较数值时，请使用[柱状图](/charts/bar)。要用五个统计量概括分布，可以使用[箱线图](/charts/box)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 绘图区的无障碍名称，说明图表展示的内容及其单位 |
| `series` | `[]` | 每个数据系列包含 `name` 和与图表类型对应的数据字段：`values`、`value`、`points`、`ranges` 或 `children`。还可指定 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `bins` | 根据观测值数量确定 | 直方图将观测值划分到的大致区间数 |
| `min`, `max`, `ticks` | 自动适配, `4` | 坐标轴的两端及大致的刻度数。散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 由区域设置决定 | 数值和刻度的显示格式。散点图的横轴使用 `xFormat` |
| `current` | 无 | 标记了 `aria-current` 的数据点索引 |

所有图表类型共用相同的读数显示、键盘操作、图例、颜色和标度。有关这些行为以及所有选项、类和自定义属性，请参阅 [图表](/components/chart)。
