## 積み上げ \{#stacked\}

各系列が合計の内訳を表す場合は、`stacked` を設定します。各層を直前の層の上に重ね、最上部の輪郭で合計を示します。各層はそれぞれの色の淡い単色で塗ります。

## ストリームグラフ \{#stream\}

`stacked: 'stream'` を設定すると、基準線から上に積み上げる代わりに、中央線を中心に面を積み上げます。下の層の変動に各層の位置が左右されなくなるため、各位置で層の厚みを読み取れ、全体の膨らみや細まりも把握できます。ストリームグラフには目盛りがなく、値表示で各層の値を確認できます。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフが示す内容と単位。描画領域のアクセシブル名になります |
| `labels` | `[]` | 軸に沿って、レーダーチャートの周囲に、またはヒートマップの各列の上に表示する名前 |
| `series` | `[]` | 各系列に `name` と、グラフ形式に応じた `values`、`value`、`points`、`ranges`、`children` のいずれかを指定します。`category`、`type`、`low` と `high`、リングの `max` は任意です |
| `stacked` | `false` | 棒や面を積み上げます。`'percent'` は各積み上げの合計を 100% にし、`'stream'` は積み上げた面を中央線の周りに配置します |
| `curve` | `'smooth'` | `smooth`、`linear`、`step` のいずれか |
| `min`, `max`, `ticks` | データに合わせる、`4` | 軸の両端の値と目盛りの目安となる数。散布図の横軸には `xMin`、`xMax`、`xTicks` を使います |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使います |
| `legend`, `toggle` | 2 系列の場合に表示、`true` | 凡例を表示するか、凡例の項目をチェックボックスにするか |

値表示、キー操作、凡例、色、目盛りは、どのグラフ形式でも共通です。すべてのオプション、CSS クラス、カスタムプロパティは [チャート](/components/chart) を参照してください。
