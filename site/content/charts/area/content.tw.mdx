## 堆疊面積圖 \{#stacked\}

若各資料序列共同構成總量，請設定 `stacked`。各層依序向上堆疊，最上緣代表總量，各層以各自的淡色均勻填滿。

## 流圖 \{#stream\}

`stacked: 'stream'` 讓堆疊面積以中線為中心，不再從基準線向上堆疊。各層不會因下方各層的變化而被推移，讀者可從各位置的厚度判讀該層的變化，整體則呈現時厚時薄的形狀。流圖沒有刻度，數值提示會顯示各層的數值。

`stacked: 'percent'` 將每個位置的總量視為 100%。各層從 0% 到 100% 填滿繪圖區，呈現各層所占的比例。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿刻度排列、環繞雷達圖或位於熱圖各欄上方的名稱 |
| `series` | `[]` | 每個資料序列都有 `name`，並依圖表形式提供 `values`、單一 `value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low` 和 `high`，以及圓環的 `max` |
| `stacked` | `false` | 將長條或面積堆疊。`'percent'` 將每組堆疊的總量視為 100%，`'stream'` 則讓堆疊面積沿中線置中 |
| `curve` | `'smooth'` | `smooth`、`linear` 或 `step` |
| `min`, `max`, `ticks` | 依資料調整, `4` | 刻度的上下限與大致的刻度數量。散佈圖的水平刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 依語系 | 數值與刻度標籤的顯示格式。散佈圖的水平刻度使用 `xFormat` |
| `legend`, `toggle` | 有兩個資料序列時顯示, `true` | 是否顯示圖例，以及圖例項目是否為核取方塊 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。[圖表](/components/chart) 說明這些功能，並列出所有選項、CSS 類別與自訂屬性。
