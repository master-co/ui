와플 차트는 전체의 1%에 해당하는 칸 100개를 정사각형으로 배열하고, 아래쪽부터 한 행씩 각 계열의 비율에 맞춰 채웁니다. 원형 차트 조각의 각도를 가늠하는 것보다 칸을 세는 편이 정확하므로, 100개 중 9개처럼 전체에서 각 항목이 차지하는 비율을 1% 단위로 보여 주기에 적합합니다.

칸이 정확히 100개 채워지도록 각 항목의 비율에서 소수점 이하를 버린 뒤, 남은 칸을 버린 소수 부분이 큰 항목부터 배정합니다. 비율이 0.5% 미만인 항목은 칸을 배정받지 못할 수 있지만, 범례에는 해당 비율과 함께 표시됩니다. `--chart-size`는 정사각형의 너비를 설정하고, `chart-split`은 범례를 그 옆에 배치합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 접근성 이름 |
| `series` | `[]` | 각 계열에 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`는 선택 사항입니다. |
| `format` | 로캘 기본 형식 | 값의 표시 형식입니다. |
| `current` | 없음 | `aria-current`로 표시한 데이터 포인트의 인덱스 |
| `legend`, `toggle` | 계열이 두 개일 때 표시, `true` | 범례를 표시할지, 범례 항목을 체크박스로 표시할지 설정합니다. |

값 표시, 키보드 조작, 범례, 색상, 눈금은 모든 차트 유형에 공통입니다. [차트](/components/chart)에서 전체 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
