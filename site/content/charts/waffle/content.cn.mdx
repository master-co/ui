华夫格图是由一百个方格组成的正方形，每格代表整体的百分之一。各数据系列按占比从底部开始逐行填充。数方格比估计饼图扇区的角度更准确，因此华夫格图适合展示精确到整数百分比的占比，例如每一百个中有九个。

各部分的占比会取整，确保恰好填满一百格。先将每个占比向下取整，再按小数部分从大到小分配剩余方格。占比低于 0.5% 的部分可能分不到方格，但图例仍会列出该部分及其占比。`--chart-size` 设置正方形的宽度，`chart-split` 将图例放在图表旁边。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和对应图表类型所需的数据：`values`、`value`、`points`、`ranges` 或 `children`。可选字段包括 `category`、`type`、`low` 和 `high`，以及环形图的 `max` |
| `format`, `tickFormat` | 使用区域设置 | 数值和刻度的显示格式。散点图的横轴使用 `xFormat` |
| `current` | 无 | 标记有 `aria-current` 的数据点索引 |
| `legend`, `toggle` | 有两个数据系列时显示图例，`true` | 是否显示图例，以及图例项是否为复选框 |

所有图表类型共用读数面板、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了所有选项、CSS 类和自定义属性。
