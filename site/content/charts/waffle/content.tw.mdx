華夫格圖由一百格組成正方形，每格代表整體的 1%。圖表從底部逐列填色，按占比分配方格給各個資料序列。數格子比估算圓餅圖的扇形角度更準確，因此華夫格圖適合以整數百分比呈現各部分，例如用一百格中的九格表示 9%。

圖表會先將各部分的百分比無條件捨去至整數，再依小數部分由大到小分配剩餘方格，剛好填滿一百格。占比低於 0.5% 的部分可能分不到方格，但圖例仍會列出該部分及其占比。`--chart-size` 設定正方形的寬度，`chart-split` 將圖例放在圖表旁。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 繪圖區的無障礙名稱，說明圖表呈現的內容與單位 |
| `series` | `[]` | 每個資料序列包含 `name`，並依圖表形式提供 `values`、`value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low`、`high` 和圓環的 `max` |
| `format` | 依語系 | 數值的顯示格式 |
| `current` | 無 | 標有 `aria-current` 的資料點索引 |
| `legend`, `toggle` | 有兩個以上資料序列時顯示、`true` | 是否顯示圖例，以及圖例項目是否使用核取方塊 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。請參閱 [圖表](/components/chart) 的完整選項、CSS 類別與自訂屬性。
