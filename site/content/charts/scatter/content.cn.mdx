散点图用来对照两个指标。每个点代表一个对象，由它的 `x` 和 `y` 决定位置。两轴的范围会自动适应数据点，边界采用便于读数的整值，仅在有数据点接近零时才从零开始。要固定范围，请设置 `xMin`、`xMax`、`min` 和 `max`。指针移到数据点周围也能触发读数显示，读数面板以该点的 `label` 为标题。

## 气泡图 \{#bubble\}

带有 `size` 的点会显示为气泡，以点的面积表示第三个指标。面积与大小值成正比，所以一个气泡的大小值是另一个的四倍时，显示面积也是四倍。气泡用同一颜色描边和半透明填充，重叠时仍能看清彼此。较大的气泡先绘制，因此叠在大气泡上的小气泡仍能响应指针。

人眼判断面积的准确度低于判断位置。把最重要的指标放在坐标轴上，用气泡大小表示只需比较相对大小的指标。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和对应的数据：`values`、扇区或圆环的 `value`，或散点图的 `points`。可选字段包括 `category`、`type` 和圆环的 `max` |
| `min`, `max`, `ticks` | 自动适应数据，`4` | 刻度范围的两端和大致的刻度间隔数。散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 使用区域设置 | 数值和刻度的显示格式。散点图的横轴使用 `xFormat` |
| `legend`, `toggle` | 有两个数据系列时显示图例，`true` | 是否显示图例，以及图例项是否为复选框 |

所有图表类型共用读数面板、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了所有选项、CSS 类和自定义属性。
