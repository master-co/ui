旭日圖以兩個層級呈現整體的組成。每個資料序列在內環占一個扇形，大小代表它占整體的比例。其 `children` 則在對應的外環區段各占一個扇形。從中心往外看，就能依序看出各部分及其組成。子項目沿用所屬部分的色相，並以不同的淺色區分。中央留給數值提示。

addEventListener('DOMContentLoaded', function () {

各部分若有指定 `value`，就使用該值，否則取子項目的總和。沒有子項目的部分只在內環顯示。圖例列出各部分的名稱。子項目的名稱會顯示在數值提示中，也會納入對應資料點的名稱。請維持兩個層級，每個部分只放少量子項目。第三層圓環會讓圖表難以判讀。有更多部分時，可用[樹狀矩形圖](/charts/treemap)。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `series` | `[]` | 每個資料序列包含 `name`，並依圖表形式提供 `values`、`value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low`、`high` 和圓環的 `max` |
| `format`, `tickFormat` | 依語系 | 數值與刻度標籤的顯示格式。散佈圖的水平軸使用 `xFormat` |
| `legend`, `toggle` | 有兩個資料序列時, `true` | 是否顯示圖例，以及圖例項目是否使用核取方塊 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。請參閱 [圖表元件](/components/chart) 的完整選項、CSS 類別與自訂屬性。
