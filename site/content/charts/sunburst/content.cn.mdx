旭日图将一个整体分两层展示。每个数据系列占内环的一个扇区，表示它在整体中的占比。其 `children` 则占据该扇区外侧的外环扇区。这样就能从内向外看清整体的各个部分，以及各部分的构成。同一部分的子项沿用该部分的颜色，并以不同程度的浅色区分。圆心留给读数面板。

各部分的值默认为其子项之和，也可以通过 `value` 单独指定。没有子项的部分仅在内环占一个扇区。图例列出各部分的名称，子项名称则显示在读数面板中，也包含在相应数据点的名称中。建议只展示两层，每个部分只保留少量子项。第三圈难以辨读，如需展示更多部分，可用[矩形树图](/charts/treemap)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和对应图表类型所需的数据：`values`、`value`、`points`、`ranges` 或 `children`。可选字段包括 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `format` | 使用区域设置 | 数值的显示格式 |
| `legend`, `toggle` | 有两个数据系列时显示图例，`true` | 是否显示图例，以及图例项是否为复选框 |

所有图表类型共用读数面板、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了所有选项、CSS 类和自定义属性。
