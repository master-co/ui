サンバーストチャートは全体の構成を2階層で示します。各系列は全体に占める割合に応じて内側のリングの扇形になり、その `children` は対応する外側のリングの扇形になります。中心から外へたどると、全体の内訳と各項目の内訳が分かります。子項目には親と同じ色を段階的に明るくして使い、中央には詳細を表示します。

addEventListener('DOMContentLoaded', function () {

各項目の値は、独自の `value` を指定した場合を除き、子項目の合計になります。子項目のない項目は内側のリングだけに表示されます。凡例には各親項目の名前を、詳細表示と各データ点の名前には対応する子項目の名前を表示します。3層目のリングは表示されないため、2階層までとし、子項目は親項目ごとに数個に抑えます。項目が多い場合は[ツリーマップ](/charts/treemap)を使います。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフの内容と単位を示す、プロット領域のアクセシブルな名前 |
| `series` | `[]` | 各系列に `name` と、形式に応じて `values`、`value`、`points`、`ranges`、`children` のいずれかを指定。`category`、`type`、`low` と `high`、リングの `max` は任意 |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使用 |
| `legend`, `toggle` | 2系列の場合に表示, `true` | 凡例を表示するか、凡例の項目をチェックボックスにするか |

詳細表示、キーボード操作、凡例、色、スケールはすべてのグラフ形式で共通です。[チャート](/components/chart) では、これらの機能とすべてのオプション、CSS クラス、カスタムプロパティを説明しています。
