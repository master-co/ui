A bump chart follows ranks, not values. At each label the series are ranked by their values, and each series is a line through its ranks, so who led, who overtook whom and when is read at a glance. The ranks are written beside the plot and each series' name at its last rank.

Give the values and the chart ranks them: the highest is first, or the lowest with `ascending: true`, for times and prices. From rank to rank a line leaves and arrives level, so a change of rank is one clear turn. A bump chart hides how far apart the values are; where the distance matters, draw a [line chart](/charts/line) of the values themselves.

## Options \{#options\}

| Option | Default | |
| --- | --- | --- |
| `label` | none | What the chart shows and in what unit: the plot's accessible name |
| `labels` | `[]` | The names along the scale, around a radar or over a heatmap's columns |
| `series` | `[]` | Each with a `name` and what its form reads: `values`, a `value`, `points`, `ranges` or `children`; optionally a `category`, a `type`, `low` and `high`, and a ring's `max` |
| `ascending` | `false` | In a bump chart, the lowest value ranks first |
| `format` | the locale's | How a value is written |
| `current` | none | The index of the point marked `aria-current` |

The readout, the keys, the legend, the colors and the scale are the same in every form: [Chart](/components/chart) holds them, with every option, class and custom property.
