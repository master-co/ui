排名变化图用名次展示各系列的相对变化。图表在每个标签对应的位置按数值对各数据系列排名，再将每个系列的名次连成一条线，因此可以一眼看出谁领先、谁在何时超过了谁。名次标在绘图区旁边，各系列名称标在其最后一个名次处。

提供原始数值后，图表会自动排名，默认数值最大的排第一。对于用时、价格等数值越小越靠前的数据，可设置 `ascending: true`。连接相邻名次的线段在两端保持水平，让名次变化更清晰。排名变化图无法体现数值差距。需要比较差距时，可用原始数值绘制[折线图](/charts/line)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 绘图区的无障碍名称，说明图表展示的内容及其单位 |
| `labels` | `[]` | 沿坐标轴、雷达图四周或热力图各列上方显示的名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和图表类型所需的数据，可为 `values`、`value`、`points`、`ranges` 或 `children`，还可指定 `category`、`type`、`low` 和 `high`，以及环形图的 `max` |
| `ascending` | `false` | 在排名变化图中将数值最小的排在第一位 |
| `format`, `tickFormat` | 随区域设置 | 数值和刻度标签的显示格式。散点图的横轴使用 `xFormat` |
| `current` | 无 | 标记了 `aria-current` 的数据点索引 |

各种图表共用同样的数值提示、键盘操作、图例、颜色和刻度机制。[图表](/components/chart) 文档列出了所有选项、类和自定义属性。
