順位推移グラフは順位の推移を示します。各ラベルで値をもとに系列の順位を決め、系列ごとに順位を線で結びます。どの系列が首位だったか、いつどの系列が別の系列を追い抜いたかがひと目で分かります。描画領域の横に順位を、各系列の最終順位の位置に系列名を表示します。

値を渡すと、グラフが順位を計算します。既定では最大値が 1 位です。所要時間や価格のように小さい値を上位にする場合は、`ascending: true` を指定します。順位が変わる区間では、線が両端で水平になるため、順位の移り変わりがはっきり見えます。順位推移グラフからは値の差を読み取れないため、差が重要な場合は値そのものを[折れ線グラフ](/charts/line)で示します。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフが示す内容と単位。描画領域のアクセシブル名になります |
| `labels` | `[]` | 軸に沿って、レーダーチャートの周囲に、またはヒートマップの各列の上に表示する名前 |
| `series` | `[]` | 各系列に `name` と、グラフ形式に応じた `values`、`value`、`points`、`ranges`、`children` のいずれかを指定します。`category`、`type`、`low` と `high`、リングの `max` は任意です |
| `ascending` | `false` | 順位推移グラフで最小値を 1 位にします |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使います |
| `current` | なし | `aria-current` が付くデータ点のインデックス |

値表示、キー操作、凡例、色、目盛りは、どのグラフ形式でも共通です。すべてのオプション、CSS クラス、カスタムプロパティは [チャート](/components/chart) を参照してください。
