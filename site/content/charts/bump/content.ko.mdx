순위 변화 차트는 계열별 순위를 추적합니다. 각 레이블에서 값을 기준으로 계열의 순위를 매기고, 같은 계열의 순위를 선으로 이어 어느 계열이 선두였고 어느 계열이 언제 다른 계열을 앞질렀는지 한눈에 보여 줍니다. 순위는 차트 영역 옆에, 계열 이름은 해당 계열의 마지막 순위 위치에 표시합니다.

값을 입력하면 차트가 순위를 매깁니다. 기본적으로 값이 가장 큰 계열이 1위입니다. 시간이나 가격처럼 낮은 값이 1위여야 하면 `ascending: true`를 설정합니다. 선은 각 순위 지점에 수평으로 들어오고 수평으로 나가므로 순위가 바뀌는 구간의 굴곡이 뚜렷합니다. 순위 변화 차트에서는 계열 간 값의 격차가 드러나지 않습니다. 그 격차가 중요하면 실제 값으로 [꺾은선 차트](/charts/line)를 그립니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `labels` | `[]` | 눈금을 따라, 레이더 차트 둘레에, 또는 히트맵의 각 열 위에 표시할 이름 |
| `series` | `[]` | 각 계열에는 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. 선택적으로 `category`, `type`, `low`와 `high`, 링의 `max`를 지정할 수 있습니다. |
| `ascending` | `false` | 순위 변화 차트에서 값이 가장 작은 계열을 1위로 표시합니다. |
| `format`, `tickFormat` | 로캘에 따름 | 값과 눈금의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `current` | 없음 | `aria-current`로 표시할 데이터 지점의 인덱스 |

모든 차트 유형은 값 표시, 키보드 조작, 범례, 색상, 척도 동작을 공유합니다. [차트](/components/chart)에서 모든 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
