棒グラフは、1 週間の日ごとの値や、1 年の四半期ごとの値を比較するのに使います。各棒は割り当てられた帯の中央に立ち、基準線から離れた先端の角が丸くなります。帯にポインターを合わせると、ほかの棒はすぐに淡い色になります。帯全体が反応するため、短い棒の値も長い棒と同じように確認できます。

## 1 本の棒を強調 \{#quiet\}

グラフに CSS クラス `chart-quiet` を付けると、棒が淡い色になり、`aria-current` が付いたデータ点だけが前景色で描画されます。たとえば、1 週間のうちの今日や、閲覧者が利用中のプランを強調できます。強調する点のインデックスを `current` に指定します。`values: true` を設定すると、各棒の先端に値が表示されます。少数の棒の正確な値を示したい場合や、ホバー操作のないタッチ画面に適しています。

## 並列と積み上げ \{#stacked\}

複数の系列は各帯の中で横に並ぶため、系列同士を比較できます。`stacked` を設定すると棒が積み上がり、合計とその内訳を比較できます。積み上げの最も外側にある棒だけ角が丸くなり、棒同士は背景色の隙間で区切られます。値表示では、積み上げの見た目に合わせて上から順に値を並べます。

### 全体に占める割合 \{#percent\}

`stacked: 'percent'` を設定すると、各積み上げの合計が 100% になります。各棒の高さは積み上げ全体に占める割合に対応するため、どの積み上げも同じ高さになり、構成比の違いを比較できます。値表示には各値とその割合が表示されます。

### ゼロを境に上下へ \{#diverging\}

負の値は基準線から下へ、正の値は上へ積み上がります。賛成と反対、収入と支出のように符号が反対の 2 系列は、中央の線から上下に分かれます。表示位置が変わっても両側それぞれの色を保つには、各系列のカテゴリを明示的に指定します。

## 横向き \{#across\}

`horizontal` を設定すると、棒が横向きになり、名前ごとに 1 行を使います。名前が縦棒の列幅に収まりにくいランキングに適しています。名前は各行の横に、目盛りは行の下に表示されます。18 文字を超える名前は途中で切り詰められます。値表示では名前の全文を確認できます。

## 多数の棒と折れ線の重ね表示 \{#many\}

各帯で描画幅を分け合うため、1 週間分と同じ幅に 1 か月分を収められます。描画領域の下に表示する名前は最大 12 個で、描画領域の幅が 24rem 未満になると 1 つおきに省略します。`type: 'line'` を指定した系列は、棒と同じ目盛りで折れ線として重ねて描画されます。目標値や移動平均を示すのに使えます。目盛りの異なる 2 つの指標は、左右に軸を置く二軸グラフではなく、別々のグラフに表示します。

<ComponentPreview name="many" height={434} narrowHeight={454} title="30 日間" bodyClass="p-lg" responsive behaviors html={`<div class="card max-w(600) mx-auto">
  <div class="card-header">
    <h3 class="card-title">Requests</h3>
    <p class="card-description">Thousands per day in November, with the weekly average</p>
  </div>
  <figure class="chart" id="november"></figure>
</div>
<script>
addEventListener('DOMContentLoaded', function () {
  var requests = [49, 52, 58, 61, 44, 37, 56, 60, 64, 72, 75, 68, 45, 42, 69, 73, 81, 76, 78, 49, 48, 72, 80, 85, 83, 86, 58, 52, 82, 88]
  var days = requests.map(function (value, index) { return 'Nov ' + (index + 1) })
  var average = requests.map(function (value, index) {
    var week = requests.slice(Math.max(0, index - 6), index + 1)
    return Math.round(week.reduce(function (sum, next) { return sum + next }, 0) / week.length)
  })
  MasterUI.chart(document.getElementById('november'), {
    type: 'bar',

    series: [
      { name: 'Requests', values: requests },
      { name: 'Weekly average', type: 'line', values: average, category: 'orange' }
    ]
  })
})
</script>`} />

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフが示す内容と単位。描画領域のアクセシブル名になります |
| `labels` | `[]` | 軸に沿って、レーダーチャートの周囲に、またはヒートマップの各列の上に表示する名前 |
| `series` | `[]` | 各系列に `name` と、グラフ形式に応じた `values`、`value`、`points`、`ranges`、`children` のいずれかを指定します。`category`、`type`、`low` と `high`、リングの `max` は任意です |
| `stacked` | `false` | 棒や面を積み上げます。`'percent'` は各積み上げの合計を 100% にし、`'stream'` は積み上げた面を中央線の周りに配置します |
| `horizontal` | `false` | 棒、範囲、ダンベル、箱ひげを横向きに描画します |
| `mark` | `'bar'` | `'lollipop'` は棒を先端に点のある線で描きます |
| `min`, `max`, `ticks` | データに合わせる、`4` | 軸の両端の値と目盛りの目安となる数。散布図の横軸には `xMin`、`xMax`、`xTicks` を使います |
| `axis` | `true` | 目盛りの数値を表示するかどうか。`false` では細いグリッド線だけが残り、タイル内の小さなグラフに適しています |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使います |
| `dots`, `values` | `false` | 折れ線のすべての点に印を付けるか、すべての棒に値を表示するか |
| `current` | なし | `aria-current` が付くデータ点のインデックス |
| `legend`, `toggle` | 2 系列の場合に表示、`true` | 凡例を表示するか、凡例の項目をチェックボックスにするか |

値表示、キー操作、凡例、色、目盛りは、どのグラフ形式でも共通です。すべてのオプション、CSS クラス、カスタムプロパティは [チャート](/components/chart) を参照してください。
