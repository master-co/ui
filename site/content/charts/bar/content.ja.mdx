棒は、1週間の各曜日や1年の各四半期のように、量を比較します。各棒は基準線の上で帯の中央に立ち、基準線から遠い側の端の角が丸くなります。ポインターを重ねると、ほかの棒は即座に淡い色へ退きます。ポインターが反応する範囲は帯全体なので、短い棒も長い棒と同じように読み取れます。

## 1本の棒を強調 \{#quiet\}

チャートに`chart-quiet`を指定すると、棒は淡い色になり、インク色は`aria-current`を付けたポイントだけに残ります。週の中の今日や、読者が利用中のプランなどです。そのポイントのインデックスを`current`に指定します。`values: true`は、すべての棒の値を棒の端に書き出します。棒が少なく正確な数値こそが要点である場合や、ホバーできないタッチ画面で使います。

## 横並びと積み上げ \{#stacked\}

複数の系列は各帯の中に横並びで立ち、系列どうしを比較できます。`stacked`を指定すると系列が積み重なり、合計を比較しながら、それぞれの内訳も示せます。角が丸くなるのは積み上げの最も外側の棒だけで、棒どうしはサーフェスの色のすき間で区切られます。値表示は、見た目どおりに積み上げの上から順に並べます。

## 横向き \{#across\}

`horizontal`は棒を横向きにして、1つの名前に1行を割り当てます。名前が1列分の幅より長いランキングに使います。名前は行の横に、スケールは行の下に置かれます。18文字を超える名前は切り詰められ、値表示には名前の全体が示されます。

## 多数の棒と、その上の折れ線 \{#many\}

帯は幅を分け合うため、1週間分が収まっていた場所に1か月分も収まります。プロットの下に並ぶ名前は多くても12個で、プロットが24remより狭くなると1つおきに省かれます。`type: 'line'`を指定した系列は、目標値や移動平均のように、同じスケールで棒の上に折れ線として描画されます。スケールの異なる2つの指標は2つのチャートに分け、両側にスケールを持つ1つのチャートには決してしません。

<ComponentPreview name="many" height={434} narrowHeight={454} title="30日間" bodyClass="p-lg" responsive behaviors html={`<div class="card max-w(600) mx-auto">
  <div class="card-header">
    <h3 class="card-title">Requests</h3>
    <p class="card-description">Thousands per day in November, with the weekly average</p>
  </div>
  <figure class="chart" id="november"></figure>
</div>
<script>
addEventListener('DOMContentLoaded', function () {
  var requests = [49, 52, 58, 61, 44, 37, 56, 60, 64, 72, 75, 68, 45, 42, 69, 73, 81, 76, 78, 49, 48, 72, 80, 85, 83, 86, 58, 52, 82, 88]
  var days = requests.map(function (value, index) { return 'Nov ' + (index + 1) })
  var average = requests.map(function (value, index) {

## オプション \{#options\}

| オプション | 既定値 | |
| --- | --- | --- |
| `label` | なし | チャートが何をどの単位で示すか。プロットのアクセシブルな名前になります |
| `labels` | `[]` | スケールに沿って、またはレーダーチャートの周囲に並ぶ名前 |
| `series` | `[]` | それぞれが`name`と`values`を持ちます。スライスやリングでは`value`、散布図では`points`を指定します。任意で`category`、`type`、リングの`max`を指定できます |
| `stacked` | `false` | 棒または面を積み重ねます |
| `horizontal` | `false` | 棒を横向きにします |
| `min`、`max`、`ticks` | 自動調整、`4` | スケールの両端と、目盛りのおおよその段階数。散布図の横方向のスケールには`xMin`、`xMax`、`xTicks`を使います |
| `axis` | `true` | スケールの数値を書き出すかどうか。`false`にすると細線だけが残ります。タイル内の小さなチャートに使います |
| `format`、`tickFormat` | ロケールの書式 | 値と目盛りの書式。散布図の横方向のスケールには`xFormat`を使います |
| `dots`、`values` | `false` | 折れ線のすべてのポイントにドットを付けます。すべての棒の値を書き出します |
| `current` | なし | `aria-current`を付けるポイントのインデックス |
| `legend`、`toggle` | 系列が2つ以上あれば表示、`true` | 凡例を書き出すかどうかと、その項目をチェックボックスにするかどうか |

値表示、キー操作、凡例、色、目盛りはどの種類でも共通です。[チャート](/components/chart)のページに、すべてのオプション、クラス、カスタムプロパティとあわせてまとめています。
