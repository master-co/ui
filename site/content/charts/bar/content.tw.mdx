長條用來比較數量，例如一週的每一天、一年的各季。每根長條都立在基線上、位於所屬那一格的正中央，遠離基線的一端為圓角。指標移到某一格時，其他長條會立即退為淡色，而且指標的感應範圍是整格，因此矮的長條和高的長條一樣容易讀取。

## 凸顯單一長條 \{#quiet\}

在圖表上加上 `chart-quiet`，長條會改為淡色，墨色只留給標有 `aria-current` 的資料點，例如一週中的今天，或讀者目前使用的方案。請用 `current` 提供它的索引。`values: true` 會在每根長條的末端寫出數值，適用於長條不多且重點是精確數字的情況，或沒有懸停操作的觸控螢幕。

## 並排或堆疊 \{#stacked\}

多組序列會在每一格中並排，方便彼此比較。設定 `stacked` 後，它們會彼此堆疊，用來比較總和並呈現各總和的組成：一疊長條中只有最外側的那根有圓角，長條之間以一道表面色的間隙分開。數值提示會依畫面所見，從堆疊的頂端往下列出。

## 橫向 \{#across\}

`horizontal` 讓長條改為橫向，每個名稱占一列，適用於名稱比直欄寬度還長的排名。名稱位於各列旁，刻度位於下方；超過十八個字元的名稱會被截斷，數值提示則會顯示完整名稱。

## 長條較多時，以及疊在上方的折線 \{#many\}

各格平分寬度，因此原本放一週的位置也放得下一個月，繪圖區下方最多顯示十二個名稱；繪圖區窄於 24rem 時，名稱會每隔一個省略一個。帶有 `type: 'line'` 的序列會以折線畫在長條上方，並使用同一刻度，例如目標值或移動平均。兩個刻度不同的量值應分成兩個圖表，絕不要在同一個圖表的兩側各放一個刻度。

## 選項 \{#options\}

| 選項 | 預設值 | |
| --- | --- | --- |
| `label` | 無 | 圖表呈現的內容及單位，也就是繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿著刻度排列的名稱，或環繞雷達圖的名稱 |
| `series` | `[]` | 每組序列都有 `name` 和 `values`；扇形或圓環改用 `value`，散佈圖改用 `points`；另可選擇性提供 `category`、`type`，以及圓環的 `max` |
| `stacked` | `false` | 長條或面積彼此堆疊 |
| `horizontal` | `false` | 長條橫向延伸 |
| `min`, `max`, `ticks` | 自動配合、`4` | 刻度的兩端，以及大約用幾格標示；散佈圖的橫向刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否寫出刻度數字；`false` 只保留細線，適用於資訊小卡中的小型圖表 |
| `format`, `tickFormat` | 依語系 | 數值和刻度標記的寫法；散佈圖的橫向刻度使用 `xFormat` |
| `dots`, `values` | `false` | 標出折線上的每個點；寫出每根長條的數值 |
| `current` | 無 | 標有 `aria-current` 的資料點的索引 |
| `legend`, `toggle` | 有兩組序列時寫出、`true` | 是否寫出圖例，以及圖例項目是否為核取方塊 |

數值提示、鍵盤操作、圖例、顏色與刻度在每種圖表類型中都相同：[圖表](/components/chart)頁面有完整說明，並列出所有選項、類別與自訂屬性。
