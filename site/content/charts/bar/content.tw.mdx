長條圖用來比較數量，例如一週中每天或一年中各季的數量。每根長條從基準線起始，置於所屬區帶的中央，遠離基準線的一端採圓角。將指標移到某個區帶時，其他長條會立即淡化。整個區帶都能感應指標，因此長條再短也一樣容易查看。

## 凸顯一根長條 \{#quiet\}

在圖表上加上 `chart-quiet`，即可淡化其他長條，並用墨色凸顯以 `aria-current` 標記的資料點，例如一週中的今天，或讀者目前使用的方案。透過 `current` 指定該資料點的索引。`values: true` 會在每根長條的末端顯示數值，適合長條不多且需要查看精確數值的圖表，也適用於無法以指標停駐查看數值的觸控螢幕。

## 並排或堆疊 \{#stacked\}

多個資料序列會在各區帶內並排，方便彼此比較。設定 `stacked` 後，長條會堆疊起來，方便比較總量並看出各組的組成。每組只有最外端的長條採圓角，各長條之間留有一道露出底色的間隙。數值提示依圖上的順序，由上往下列出各層。

### 顯示各部分占比 \{#percent\}

`stacked: 'percent'` 將每組堆疊的總量視為 100%。每根長條的高度取決於它在組內的占比，因此各組等高，組成比例則隨資料而異。數值提示會列出各部分的數值與占比。

### 向零值兩側延伸 \{#diverging\}

負值從基準線向下堆疊，正值則向上堆疊，因此正負號相反的兩個資料序列會從中間的基準線向兩側延伸，例如同意與不同意、收入與支出。請自行指定各資料序列的分類，讓它們無論位於哪一側都能保有各自的顏色。

## 橫向長條 \{#across\}

`horizontal` 讓長條橫向排列，每個名稱占一列，適合名稱超出欄寬的排名圖。名稱顯示在各列旁，刻度位於下方。超過 18 個字元的名稱會截短，數值提示會顯示完整名稱。

## 棒棒糖圖與鬚線 \{#lollipop\}

`mark: 'lollipop'` 會把每根長條畫成一條細線，末端加上一個圓點。這種畫法以更少的筆墨呈現相同數值，適合長條很多或很長、實心長條容易連成一大片的情況。

## 大量長條與上方的折線 \{#many\}

各區帶共用繪圖寬度，因此一個月的資料也能放進原先一週的空間。繪圖區下方最多顯示 12 個名稱，寬度小於 24rem 時則每隔一個才顯示。設定 `type: 'line'` 的資料序列會以折線疊在長條上方，並共用同一組刻度，例如目標值或移動平均。兩項指標若需要不同刻度，請各用一張圖表，不要在同一張圖的兩側各設一組刻度。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿刻度排列、環繞雷達圖或位於熱圖各欄上方的名稱 |
| `series` | `[]` | 每個資料序列都有 `name`，並依圖表形式提供 `values`、單一 `value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low` 和 `high`，以及圓環的 `max` |
| `stacked` | `false` | 將長條或面積堆疊。`'percent'` 將每組堆疊的總量視為 100%，`'stream'` 則讓堆疊面積沿中線置中 |
| `horizontal` | `false` | 讓長條、區間、啞鈴和盒鬚圖以橫向呈現 |
| `mark` | `'bar'` | `'lollipop'` 將長條畫成末端帶有圓點的細線 |
| `min`, `max`, `ticks` | 依資料調整, `4` | 刻度的上下限與大致的刻度數量。散佈圖的水平刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否顯示刻度數字。`false` 只保留細線，適合資訊磚中的小圖表 |
| `format`, `tickFormat` | 依語系 | 數值與刻度標籤的顯示格式。散佈圖的水平刻度使用 `xFormat` |
| `dots`, `values` | `false` | 標記折線上的每個資料點，或顯示每根長條的數值 |
| `current` | 無 | 以 `aria-current` 標記的資料點索引 |
| `legend`, `toggle` | 有兩個資料序列時顯示, `true` | 是否顯示圖例，以及圖例項目是否為核取方塊 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。[圖表](/components/chart) 說明這些功能，並列出所有選項、CSS 類別與自訂屬性。
