막대는 일주일의 요일별 수량이나 1년의 분기별 수량을 비교할 때 사용합니다. 각 막대는 해당 범주의 중앙에서 기준선에 닿으며, 기준선에서 먼 쪽 모서리가 둥글게 처리됩니다. 한 범주에 포인터를 올리면 다른 막대의 색이 즉시 옅어집니다. 막대가 속한 범주 영역 전체에 포인터를 올릴 수 있어 짧은 막대의 값도 쉽게 확인할 수 있습니다.

## 한 막대 강조 \{#quiet\}

차트에 `chart-quiet`를 적용하면 막대가 옅어지고 `aria-current`로 표시된 항목만 기본 전경색을 유지합니다. 주간 차트의 오늘이나 사용 중인 요금제를 강조할 때 유용합니다. 해당 항목의 인덱스를 `current`로 지정합니다. `values: true`는 모든 막대 끝에 값을 표시합니다. 막대가 적고 정확한 수치가 중요하거나, 호버를 사용할 수 없는 터치 화면에 적합합니다.

## 나란히 배치 및 누적 \{#stacked\}

여러 계열은 각 범주 안에 나란히 배치되므로 서로 비교하기 쉽습니다. `stacked`를 사용하면 막대를 쌓아 합계와 구성을 함께 비교할 수 있습니다. 누적 막대의 가장 바깥쪽 끝만 둥글고, 막대 사이는 배경색 간격으로 구분합니다. 값 표시는 화면에서 보이는 순서대로 맨 위 막대부터 나열합니다.

### 전체 대비 비중 \{#percent\}

`stacked: 'percent'`는 각 누적 합계를 100%로 맞춥니다. 각 막대의 높이는 해당 합계에서 차지하는 비중에 비례합니다. 누적 막대의 전체 높이가 같으므로 구성 비율을 비교할 수 있습니다. 값 표시에는 각 값과 비중이 함께 나옵니다.

### 0을 기준으로 양방향 배치 \{#diverging\}

음수는 기준선 아래로, 양수는 위로 쌓입니다. 찬성과 반대, 수입과 지출처럼 부호가 반대인 두 계열은 가운데 기준선에서 양쪽으로 뻗습니다. 어느 위치에서도 양쪽의 색이 유지되도록 각 계열의 범주를 직접 지정합니다.

## 가로 막대 \{#across\}

`horizontal`은 이름마다 한 행을 할당해 막대를 가로로 배치합니다. 이름이 세로 막대의 열 너비보다 긴 순위 차트에 적합합니다. 이름은 행 옆에, 눈금은 행 아래에 표시됩니다. 이름이 18자를 넘으면 잘리며 값 표시에서 전체 이름을 확인할 수 있습니다.

## 막대가 많은 차트와 선 겹치기 \{#many\}

범주 영역이 전체 너비를 나눠 쓰므로 일주일치가 들어가던 공간에 한 달치도 표시할 수 있습니다. 플롯 아래에는 이름이 최대 12개 표시되며, 플롯 너비가 24rem보다 좁으면 이름을 하나씩 건너뛰어 표시합니다. `type: 'line'`을 지정한 계열은 막대와 같은 척도를 사용해 막대 위에 선으로 그려집니다. 목표값이나 이동 평균을 표시할 때 사용할 수 있습니다. 척도가 다른 두 지표는 별도의 차트로 표시합니다. 한 차트의 양쪽에 서로 다른 척도를 두지 않습니다.

<ComponentPreview name="many" height={434} narrowHeight={454} title="30일" bodyClass="p-lg" responsive behaviors html={`<div class="card max-w(600) mx-auto">
  <div class="card-header">
    <h3 class="card-title">Requests</h3>
    <p class="card-description">Thousands per day in November, with the weekly average</p>
  </div>
  <figure class="chart" id="november"></figure>
</div>
<script>
addEventListener('DOMContentLoaded', function () {
  var requests = [49, 52, 58, 61, 44, 37, 56, 60, 64, 72, 75, 68, 45, 42, 69, 73, 81, 76, 78, 49, 48, 72, 80, 85, 83, 86, 58, 52, 82, 88]
  var days = requests.map(function (value, index) { return 'Nov ' + (index + 1) })
  var average = requests.map(function (value, index) {
    var week = requests.slice(Math.max(0, index - 6), index + 1)
    return Math.round(week.reduce(function (sum, next) { return sum + next }, 0) / week.length)
  })
  MasterUI.chart(document.getElementById('november'), {
    type: 'bar',
    label: 'Requests per day in November, in thousands',
    labels: days,
    series: [
      { name: 'Requests', values: requests },
      { name: 'Weekly average', type: 'line', values: average, category: 'orange' }
    ]
  })
})
</script>`} />

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `labels` | `[]` | 눈금을 따라, 레이더 차트 둘레에, 또는 히트맵의 각 열 위에 표시할 이름 |
| `series` | `[]` | 각 계열에는 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. 선택적으로 `category`, `type`, `low`와 `high`, 링의 `max`를 지정할 수 있습니다. |
| `stacked` | `false` | 막대나 영역을 쌓습니다. `'percent'`는 각 누적 합계를 100%로 맞추고, `'stream'`은 누적 영역을 중앙선 중심으로 배치합니다. |
| `horizontal` | `false` | 막대, 범위, 덤벨, 상자를 가로로 표시합니다. |
| `mark` | `'bar'` | `'lollipop'`은 막대를 가는 선과 끝점으로 그립니다. |
| `min`, `max`, `ticks` | 데이터에 맞춤, `4` | 축 범위의 양 끝과 대략적인 눈금 개수입니다. 산점도의 가로축에는 `xMin`, `xMax`, `xTicks`를 사용합니다. |
| `axis` | `true` | 눈금의 숫자를 표시할지 지정합니다. 타일 안의 작은 차트에는 `false`로 설정해 가는 눈금선만 남길 수 있습니다. |
| `format`, `tickFormat` | 로캘에 따름 | 값과 눈금의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `dots`, `values` | `false` | 각각 선의 모든 데이터 지점에 점을 표시하고, 모든 막대의 값을 표시합니다. |
| `current` | 없음 | `aria-current`로 표시할 데이터 지점의 인덱스 |
| `legend`, `toggle` | 계열이 2개일 때 표시, `true` | 범례를 표시할지, 범례 항목을 체크박스로 표시할지 지정합니다. |

모든 차트 유형은 값 표시, 키보드 조작, 범례, 색상, 척도 동작을 공유합니다. [차트](/components/chart)에서 모든 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
