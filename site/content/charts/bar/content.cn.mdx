条形用于比较数量，例如一周中的每一天、一年中的各个季度。每根条形立在基线上，位于所属区间的正中，远离基线的一端为圆角。指针悬停时，其他条形立即退为浅色；指针的落点是整个区间，因此矮的条形和高的条形一样容易读取。

## 突出一根条形 \{#quiet\}

在图表上加 `chart-quiet`，条形会变为浅色，只为标有 `aria-current` 的数据点保留墨色，例如一周中的今天、读者当前使用的套餐。用 `current` 给出它的索引。`values: true` 在每根条形的末端写出数值，适用于条形不多且重在精确数字的情况，也适用于没有悬停状态的触摸屏。

## 并排或堆叠 \{#stacked\}

多个数据系列在每个区间内并排，便于相互比较。设置 `stacked` 后，它们上下堆叠，便于比较总量，并显示每个总量的构成：一组堆叠中只有最外侧的条形带圆角，条形之间以一道表面色的间隙隔开。数值提示按所见的顺序，从顶部开始列出堆叠中的各项。

## 横向条形 \{#across\}

`horizontal` 把条形改为横向，每个名称占一行，适用于名称比一列的宽度更长的榜单。名称位于各行旁边，刻度位于各行下方；超过十八个字母的名称会被截断，数值提示中显示完整名称。

## 大量条形，以及叠在其上的折线 \{#many\}

各区间平分宽度，因此原本放一周数据的空间也能放下一个月的数据，绘图区下方最多显示十二个名称；绘图区窄于 24rem 时，每隔一个名称会隐去一个。带有 `type: 'line'` 的数据系列会画成叠在条形之上的折线，使用同一刻度，例如目标值或移动平均值。刻度不同的两种度量应画成两个图表，绝不能画成两侧各有一个刻度的单个图表。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 图表展示的内容及其单位，即绘图区的无障碍名称 |
| `labels` | `[]` | 沿刻度排列的名称，或雷达图四周的名称 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，扇区或圆环使用 `value`，散点图使用 `points`；还可选填 `category`、`type` 和圆环的 `max` |
| `stacked` | `false` | 条形或面积上下堆叠 |
| `horizontal` | `false` | 条形横向排列 |
| `min`, `max`, `ticks` | 自动适配，`4` | 刻度的两端，以及大约分几段标出；散点图的横向刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否写出刻度数字；`false` 只保留细线，适用于磁贴中的小图表 |
| `format`, `tickFormat` | 按 locale 的格式 | 数值和刻度数字的书写方式；散点图的横向刻度使用 `xFormat` |
| `dots`, `values` | `false` | 标出折线上的每个数据点；写出每根条形的数值 |
| `current` | 无 | 标有 `aria-current` 的数据点的索引 |
| `legend`, `toggle` | 有两个数据系列时生成，`true` | 是否生成图例，以及图例项是否为复选框 |

数值提示、键盘操作、图例、颜色和刻度在每种图表类型中都相同：[图表](/components/chart)页面有完整说明，并列出全部选项、类名和自定义属性。
