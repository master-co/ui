柱状图适合比较一周中每天或一年中各季度的数值。每根柱都从基线起，居于对应的类别带中央，远离基线的一端采用圆角。指针移入时，其他柱会立即淡化。指针命中的是整个类别带，因此短柱和长柱一样容易查看。

## 突出一根柱 \{#quiet\}

给图表添加 `chart-quiet` 类可淡化各柱，仅为标记了 `aria-current` 的数据点保留墨色，例如一周中的今天，或读者当前使用的方案。通过 `current` 指定该数据点的索引。`values: true` 会在每根柱的末端显示数值，适合柱数较少且需要看清具体数值的图表，也适合没有悬停交互的触摸屏。

## 并排或堆叠 \{#stacked\}

多个数据系列在每个类别带内并排显示，方便比较各系列。启用 `stacked` 后，各系列依次堆叠，便于比较总量及其构成。每组堆叠只有最外侧的柱端带圆角，各柱之间留有一道露出背景的间隙。数值提示按图中从上到下的顺序列出各项。

### 按占比堆叠 \{#percent\}

`stacked: 'percent'` 将每组堆叠归一化为 100%。每根柱的高度对应它在本组中的占比，因此各组总高度相同，可以直接比较构成。数值提示会同时显示原始数值和占比。

### 向零值两侧延伸 \{#diverging\}

负值从基线向下堆叠，正值向上堆叠。这样，符号相反的两个数据系列就会从中间的零线向两侧展开，例如赞成与反对、收入与支出。为各系列显式指定类别，使两侧的数据无论出现在什么位置都保持各自的颜色。

## 横向条形图 \{#across\}

`horizontal` 将图表改为横向条形图，每个名称占一行，适合名称长于柱形类别带宽度的排名。名称显示在各行旁边，刻度在下方。超过 18 个字符的名称会被截断，数值提示中会显示全名。

## 棒棒糖图与须线 \{#lollipop\}

`mark: 'lollipop'` 将每根柱画成一条末端带圆点的细线。它用更少的填充面积表达同样的数值，适合柱条较多或较长、实心柱条容易连成一片的图表。

## 多柱布局与叠加折线 \{#many\}

各类别带平分绘图区的宽度，因此原本显示一周的空间也能放下一个月的数据。绘图区下方最多显示 12 个名称，宽度小于 24rem 时隔一个显示一个。设置了 `type: 'line'` 的数据系列会以折线叠绘在柱条上，并与柱条共用刻度，可用于显示目标值或移动平均值。两个指标需要不同的刻度时，必须分成两张图，不能使用双轴图。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 绘图区的无障碍名称，说明图表展示的内容及其单位 |
| `labels` | `[]` | 沿坐标轴、雷达图四周或热力图各列上方显示的名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和图表类型所需的数据，可为 `values`、`value`、`points`、`ranges` 或 `children`，还可指定 `category`、`type`、`low` 和 `high`，以及环形图的 `max` |
| `stacked` | `false` | 堆叠柱条或面积。`'percent'` 将每组堆叠归一化为 100%，`'stream'` 让堆叠面积围绕中线分布 |
| `horizontal` | `false` | 将柱状图、区间图、哑铃图和箱线图横向绘制 |
| `mark` | `'bar'` | `'lollipop'` 将柱条画成末端带圆点的细线 |
| `min`, `max`, `ticks` | 自适应, `4` | 坐标轴的取值范围和大致的刻度数。散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `axis` | `true` | 是否显示刻度数值。设为 `false` 时只保留细网格线，适合卡片中的小图表 |
| `format`, `tickFormat` | 随区域设置 | 数值和刻度标签的显示格式。散点图的横轴使用 `xFormat` |
| `dots`, `values` | `false` | 是否标记折线上的每个数据点，以及是否显示每根柱条的数值 |
| `current` | 无 | 标记了 `aria-current` 的数据点索引 |
| `legend`, `toggle` | 有两个数据系列时显示, `true` | 是否显示图例，以及是否将图例项显示为复选框 |

各种图表共用同样的数值提示、键盘操作、图例、颜色和刻度机制。[图表](/components/chart) 文档列出了所有选项、类和自定义属性。
