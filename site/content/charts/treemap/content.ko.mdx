트리맵은 전체를 이루는 항목을 타일로 표시하며, 각 타일의 면적은 해당 항목의 비율을 나타냅니다. 원형 차트보다 많은 항목을 표시할 수 있고, 비율이 낮은 항목도 포인터를 올릴 수 있는 타일로 표시됩니다. 타일은 큰 것부터 배치하고, 가늘고 긴 직사각형보다 정사각형의 면적을 비교하기 쉬우므로 타일 크기가 허용하는 범위에서 정사각형에 가깝게 만듭니다.

타일에 공간이 있으면 이름을 표시하고, 둘 다 들어갈 공간이 있으면 이름 아래에 값을 표시합니다. 타일 크기에 관계없이 값 표시와 각 데이터 포인트의 이름에는 항목 이름과 값이 모두 포함됩니다. 타일은 잉크 색을 옅게 깔아 채웁니다. 제품에서 이미 색으로 구분하는 항목은 계열에 `category`를 지정해 해당 카테고리의 배경색을 적용할 수 있습니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 접근성 이름 |
| `series` | `[]` | 각 계열에 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`는 선택 사항입니다. |
| `format` | 로캘 기본 형식 | 값의 표시 형식입니다. |
| `current` | 없음 | `aria-current`로 표시한 데이터 포인트의 인덱스 |

값 표시, 키보드 조작, 범례, 색상, 눈금은 모든 차트 유형에 공통입니다. [차트](/components/chart)에서 전체 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
