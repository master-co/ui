樹狀矩形圖用矩形區塊呈現整體的各個部分，區塊面積代表各部分所占的比例。它比圓餅圖容得下更多項目，占比小的部分也有可用指標指向的獨立區塊。區塊從最大者開始排列，並在各自面積允許的範圍內盡量接近正方形，因為正方形的面積比狹長矩形更容易判讀。

區塊有足夠空間時會顯示名稱，空間足夠容納兩者時，還會在名稱下方顯示數值。不論區塊大小，數值提示和對應資料點的名稱都會包含名稱與數值。區塊預設以淡色填滿。若產品已為各類別配色，可為資料序列指定 `category`，讓區塊採用該類別的底色。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 繪圖區的無障礙名稱，說明圖表呈現的內容與單位 |
| `series` | `[]` | 每個資料序列包含 `name`，並依圖表形式提供 `values`、`value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low`、`high` 和圓環的 `max` |
| `format` | 依語系 | 數值的顯示格式 |
| `current` | 無 | 標有 `aria-current` 的資料點索引 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與數值刻度。請參閱 [圖表](/components/chart) 的完整選項、CSS 類別與自訂屬性。
