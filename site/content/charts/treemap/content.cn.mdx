矩形树图用矩形块展示整体的各个部分，各块的面积与其占比成正比。它能容纳比饼图更多的部分，占比较小的部分也有自己的矩形块，读者仍可用指针指向它。布局时先放面积大的矩形块，并在面积允许的情况下让各块尽量接近正方形，因为正方形的面积比细长矩形的面积更容易估计。

矩形块有足够空间时会显示名称，空间充足时还会在名称下方显示数值。无论矩形块大小，读数面板和对应数据点的名称都会包含这两项信息。矩形块默认用淡化的前景色填充。数据系列指定 `category` 后会使用对应类别的表面样式，可沿用产品中已有的类别配色。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和对应图表类型所需的数据：`values`、`value`、`points`、`ranges` 或 `children`。可选字段包括 `category`、`type`、`low` 和 `high`，以及环形图的 `max` |
| `format` | 使用区域设置 | 数值的显示格式 |
| `current` | 无 | 标记有 `aria-current` 的数据点索引 |

所有图表类型共用读数面板、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了所有选项、CSS 类和自定义属性。
