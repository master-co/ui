多环进度图用于展示各自有上限的多个读数，例如三项目标的完成度或套餐中各项配额的使用情况。每个圆环依次向内嵌套，从顶部开始按当前值占 `max` 的比例填充。图表和该数据系列均未指定上限时，默认为 100。各环用同色的浅色轨道显示剩余部分。

只需展示一个数值及其接近上限的程度时，可使用[仪表盘](/components/gauge)。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，也可为扇区或圆环提供 `value`，或为散点图提供 `points`；还可指定 `category`、`type` 及圆环的 `max` |
| `max` | `100` | 一整圈代表的数值；数据系列自身的 `max` 优先 |
| `format` | 由区域设置决定 | 数值的显示格式 |
| `hole`, `center` | `.7`, 无 | 分别设置环形图内孔的大小和环形图或多环进度图的中心内容 |
| `legend`, `toggle` | 有两个数据系列时显示, `true` | 分别控制是否显示图例，以及图例项是否以复选框呈现 |

所有图表类型共用相同的读数提示、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了全部选项、CSS 类和自定义属性。
