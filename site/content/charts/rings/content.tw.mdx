多環圖呈現少量各有總量的數值，例如三項目標或一項計畫中的各項配額。各環由外向內依序排列，從頂端起按數值占上限的比例填色。上限 `max` 預設為 100，圖表或資料序列可另行設定。各環以自身色調的淡色呈現未填滿的部分，表示同一目標尚未達成的量。

## 選項 \{#options\}

| 選項 | 預設值 | |
| --- | --- | --- |
| `label` | 無 | 繪圖區的無障礙名稱，說明圖表呈現的內容與使用的單位 |
| `series` | `[]` | 每個資料序列都有 `name`，並依圖表類型提供 `values`、扇區或圓環用的 `value`，或散佈圖用的 `points`。也可選擇提供 `category`、`type`，以及環的 `max` |
| `min`, `max`, `ticks` | 自動配合，`4` | 刻度範圍的兩端與大致的刻度數。`xMin`、`xMax` 和 `xTicks` 用於散佈圖的水平刻度 |
| `format`, `tickFormat` | 依地區設定 | 數值與刻度標籤的顯示格式。`xFormat` 用於散佈圖的水平刻度 |
| `hole`, `center` | `.7`、無 | 圓環圖的中空區域，以及圓環圖或多環圖中央顯示的內容 |
| `legend`, `toggle` | 有兩個資料序列時顯示、`true` | 是否顯示圖例，以及圖例項目是否為核取方塊 |

所有圖表類型共用數值提示、鍵盤操作、圖例、色彩和刻度。[圖表](/components/chart)列出這些共用功能，以及所有選項、類別和自訂屬性。
