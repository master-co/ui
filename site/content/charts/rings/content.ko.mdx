링 차트는 세 가지 목표의 달성량이나 요금제의 항목별 사용량처럼 각자 기준이 되는 전체량이 있는 여러 값을 보여 줍니다. 링은 바깥쪽에서 안쪽으로 차례로 배치하고, 각 링의 맨 위에서 시작해 `max`에 대한 값의 비율만큼 채웁니다. 차트나 계열에 별도로 지정하지 않으면 최댓값은 100입니다. 링마다 같은 계열 색을 옅게 적용한 트랙을 두어 목표까지 남은 부분도 해당 링에서 확인할 수 있습니다.

값 하나가 한도에 얼마나 가까운지 표시하려면 [Gauge](/components/gauge)를 사용합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `series` | `[]` | 각 계열에 `name`과 함께 `values`, 조각이나 링의 `value`, 또는 산점도의 `points`를 지정합니다. `category`, `type`, 링의 `max`도 지정할 수 있습니다. |
| `min`, `max`, `ticks` | 데이터에 맞춤, `4` | 축의 양 끝값과 대략적인 눈금 수입니다. 산점도의 가로축에는 `xMin`, `xMax`, `xTicks`를 사용합니다. |
| `format`, `tickFormat` | 로캘에 따름 | 값과 눈금 레이블의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `hole`, `center` | `.7`, 없음 | 도넛 차트의 구멍 크기와 도넛 차트 또는 링 차트의 중앙에 표시할 내용 |
| `legend`, `toggle` | 계열이 두 개일 때 표시, `true` | 범례를 표시할지, 범례 항목을 체크박스로 표시할지 지정합니다. |

값 표시, 키보드 조작, 범례, 색상, 척도는 모든 차트 유형에 공통으로 적용됩니다. [차트](/components/chart)에서 공통 동작과 모든 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
