雷達圖讓讀者一眼看出幾個對象在相同指標上的表現，例如比較兩個版本在六項指標上的分數，或呈現一組指標的整體輪廓。每個資料序列都有輪廓與同色的半透明填色，重疊時仍能看清彼此。各指標共用同一套刻度，若已知上限，請指定 `max`。將指標移到任一放射軸，即可查看各資料序列在該項指標上的數值。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿刻度或雷達圖周圍顯示的名稱 |
| `series` | `[]` | 每個資料序列都有 `name`，並提供 `values`、扇區或圓環用的 `value`，或散佈圖用的 `points`。可選填 `category`、`type` 和圓環的 `max` |
| `min`, `max`, `ticks` | 依資料調整、`4` | 刻度範圍的兩端與大致的刻度數量。散佈圖的橫軸使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 依地區設定 | 數值與刻度標籤的顯示格式。散佈圖的橫軸使用 `xFormat` |
| `legend`, `toggle` | 有兩個資料序列時顯示、`true` | 是否顯示圖例，以及是否將圖例項目呈現為核取方塊 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。[圖表](/components/chart) 元件提供這些功能，並列出所有選項、CSS 類別與自訂屬性。
