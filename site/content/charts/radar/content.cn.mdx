雷达图便于快速比较多个对象在相同指标上的表现，例如对比两个版本在六项指标上的得分，也可展示单个对象的多维特征。每个数据系列用轮廓线和同色的半透明填充表示，因此重叠的系列仍可辨认。各项指标共用同一刻度，已知上限时请设置 `max`。将指针移到一条径向轴上，即可查看各数据系列在该指标上的数值。

雷达图使用两到三个数据系列、五到八项指标时较易阅读。可在图旁放一张[表格](/components/table)，列出准确得分。

## 单个数据系列 \{#one\}

只有一个数据系列时，图表默认使用前景色绘制。只有为该系列指定 `category` 时，才会使用类别颜色。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `labels` | `[]` | 沿刻度轴或环绕雷达图的标签 |
| `series` | `[]` | 每个系列包含 `name` 和 `values`，也可为扇区或圆环提供 `value`，或为散点图提供 `points`；还可指定 `category`、`type` 及圆环的 `max` |
| `min`, `max`, `ticks` | 自动适配, `4` | 刻度范围的两端及大致的刻度数；散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 由区域设置决定 | 数值和刻度的显示格式；散点图的横轴使用 `xFormat` |
| `legend`, `toggle` | 有两个数据系列时显示, `true` | 分别控制是否显示图例，以及图例项是否以复选框呈现 |

所有图表类型共用相同的读数提示、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了全部选项、CSS 类和自定义属性。
