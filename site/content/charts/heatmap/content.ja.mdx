ヒートマップは、曜日と時刻、年と月など、二つの軸にまたがる傾向を示します。各系列が行、各ラベルが列に対応し、交点のセルは最小値から最大値までの範囲内で値が大きいほど濃くなります。濃淡だけで値を表すため、大きい値や小さい値がどこにあるかは分かりますが、具体的な値までは読み取れません。

最小値にもごく薄い色が付くため、値があるセルと値がないセルを区別できます。値が `null` のセルは表示されません。`min` と `max` で範囲の両端を固定すると、並べた二つのヒートマップで同じ範囲を使えます。系列に `category` を指定すると、その行のセルにカテゴリの色が適用されます。指定しない場合は既定の描画色を使います。

このヒートマップには、ラベル付きの軸が二つあります。1年分の日付のように、軸を添えずに小さなセルを多数並べるには、[ヒートマップ](/components/heatmap)コンポーネントを使います。スタイルシートがリストを描画するため、スクリプトは不要です。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフが示す内容と単位を表す、プロットのアクセシブルな名前 |
| `labels` | `[]` | 軸に沿った項目名、レーダーチャートの周囲の項目名、またはヒートマップの列名 |
| `series` | `[]` | 各系列に `name` と、形式に応じて `values`、`value`、`points`、`ranges`、`children` のいずれかを指定します。`category`、`type`、`low` と `high`、円環の `max` は任意です |
| `min`, `max` | データに合わせて自動調整 | 最も淡いセルと最も濃いセルが表す値 |
| `format` | ロケールに準拠 | 値の表示形式 |

値の表示、キー操作、凡例、色、スケールは、すべての形式で共通です。すべてのオプション、クラス、カスタムプロパティは [チャート](/components/chart) に記載しています。
