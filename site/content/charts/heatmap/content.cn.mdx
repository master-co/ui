热力图同时展示数据在两个维度上的分布，例如一周内每天的各个小时，或多年中每年的各个月份。每个数据系列对应一行，每个标签对应一列。行列交叉处的单元格根据其数值在最小值和最大值之间的位置着色，数值越大，颜色越深。颜色深浅是唯一的视觉编码，适合辨认高值和低值出现的位置，难以直接读出具体数值。

数值最低的单元格也会略微着色，便于区分有数值和无数值的单元格。值为 `null` 时不绘制对应的单元格。用 `min` 和 `max` 固定数值范围的两端，就能让并排的两张热力图使用同一范围。数据系列指定 `category` 时，该行的单元格使用对应的类别颜色，否则使用默认绘图色。

这里的热力图在两个轴上都有标签。如果要展示全年每日数据这类由大量小单元格组成、四周没有坐标轴的网格，请使用[热力图](/components/heatmap)组件。它由样式表直接将列表绘制成网格，无需脚本。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 绘图区的无障碍名称，说明图表展示的内容及其单位 |
| `labels` | `[]` | 沿坐标轴、环绕雷达图或位于热力图各列上方的名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和与图表类型对应的数据字段：`values`、`value`、`points`、`ranges` 或 `children`。还可指定 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `min`, `max` | 自动适配 | 最浅和最深的单元格各自代表的数值 |
| `format` | 由区域设置决定 | 数值的显示格式 |

所有图表类型共用相同的读数显示、按键操作、图例、颜色和刻度。有关这些行为以及所有选项、类和自定义属性，请参阅 [图表](/components/chart)。
