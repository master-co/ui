히트맵은 한 주의 요일별 시간대나 여러 해의 월별 데이터처럼 두 축에 걸친 패턴을 한눈에 보여 줍니다. 각 계열은 행, 각 레이블은 열이 되며 두 축이 만나는 셀은 값이 최솟값과 최댓값 사이 어디에 놓이는지에 따라 진해집니다. 색의 농도만으로는 높은 값과 낮은 값의 위치를 파악할 수 있고, 정확한 수치까지는 알 수 없습니다.

최솟값인 셀에도 옅게 색을 입혀 값이 있는 셀과 없는 셀을 구분합니다. 값이 `null`이면 셀을 표시하지 않습니다. `min`과 `max`로 범위의 양 끝을 고정하면 나란히 놓은 두 히트맵에 같은 범위를 적용할 수 있습니다. 각 행의 셀에는 해당 계열에 `category`가 지정되어 있으면 그 색을 적용하고, 지정되어 있지 않으면 기본 전경색을 사용합니다.

이 히트맵에는 레이블이 있는 축이 두 개 있습니다. 1년치 날짜처럼 축 없이 작은 셀을 많이 나열하려면 [히트맵](/components/heatmap) 컴포넌트를 사용합니다. 이 컴포넌트는 스크립트 없이 스타일시트로 목록을 그립니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `labels` | `[]` | 축을 따라, 레이더 차트 둘레에, 또는 히트맵 열 위에 표시하는 이름 |
| `series` | `[]` | 각 계열에 `name`과 차트 형태에 맞는 데이터인 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`는 선택 사항입니다. |
| `min`, `max` | 데이터에 맞춤 | 가장 옅은 셀과 가장 진한 셀이 나타내는 값입니다. |
| `format` | 로캘 기본 형식 | 값의 표시 형식입니다. |

값 표시, 키보드 조작, 범례, 색상, 척도는 모든 차트 형태에 공통으로 적용됩니다. [차트](/components/chart)에서 자세한 설명과 모든 옵션, CSS 클래스, 사용자 지정 속성을 확인할 수 있습니다.
