範囲グラフは、月ごとの最低気温と最高気温、店の営業時間、給与の範囲などを、始点から終点まで伸びる棒で表します。系列の `ranges` の各要素は値のペアです。棒は始点の位置から描かれ、両端に丸みが付きます。棒の長さが表すのは2つの値の差なので、目盛りの範囲はゼロを起点にせず、各区間に合わせて決まります。

## 並列と横向き \{#across\}

複数の系列は、棒グラフと同様にラベルごとの区画に並べて表示されます。`horizontal` を指定すると、ラベルが縦に、目盛りが横に並びます。時間の範囲や、縦棒では収まりきらない長いラベルを表示する場合に適しています。計画上の期間を利用者が移動したり長さを変えたりできるようにするには、[ガントチャート](/components/gantt)を使います。

## オプション \{#options\}

| オプション | 既定値 | |
| --- | --- | --- |
| `label` | なし | グラフが何をどの単位で示すかを伝える、プロットのアクセシブルな名前 |
| `labels` | `[]` | 目盛りに沿って、レーダーチャートの周囲に、またはヒートマップの列の上に並ぶ名前 |
| `series` | `[]` | 各系列に `name` と、グラフ形式に応じて `values`、単一の `value`、`points`、`ranges`、`children` のいずれかを指定。`category`、`type`、`low` と `high`、リングの `max` は任意 |
| `horizontal` | `false` | 棒グラフ、範囲グラフ、ダンベルチャート、箱ひげ図を横向きに表示 |
| `min`, `max`, `ticks` | データに合わせる、`4` | 目盛りの下限と上限、およその目盛り数。散布図の横軸には `xMin`、`xMax`、`xTicks` を使用 |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使用 |
| `current` | なし | `aria-current` が付く点のインデックス |
| `legend`, `toggle` | 2系列の場合、`true` | 凡例を表示するか、凡例の各項目をチェックボックスにするか |

値表示、キー操作、凡例、色、目盛りはすべてのグラフ形式で共通です。[チャート](/components/chart)に、すべてのオプション、クラス、カスタムプロパティとあわせて記載しています。
