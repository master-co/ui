箱ひげ図は、各グループの観測値を 5 つの値に要約し、複数のグループを一度に比較できるようにします。箱は第 1 四分位数から第 3 四分位数まで伸び、中央値の位置に背景色の線が入ります。ひげは箱の両端から四分位範囲の 1.5 倍以内にある観測値の最小値と最大値まで伸びます。その範囲を外れる観測値は、個別の点として表示します。

各系列が 1 つのグループに対応します。観測値をそのまま `values` に渡すと、箱の下にグループ名が表示されます。軸の範囲は観測値に合わせて決まり、ゼロを起点にしません。値表示では 5 つの値が図の上から順に並び、`words` で各項目の名前をページの言語に合わせて設定できます。指定する項目は `{ min, q1, median, q3, max }` です。`horizontal` を設定すると、箱が横向きになります。

箱ひげ図では、5 つの値の間の分布の形が見えないため、山が 2 つある分布と、山が 1 つだけの分布が同じように見えることがあります。分布の形が重要な場合は、グループごとに[ヒストグラム](/charts/histogram)を描きます。

## 横向き \{#across\}

`horizontal` を指定すると箱が横向きになり、名前は縦に並びます。名前が長いときやグループが多いときに使います。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフが示す内容と単位。描画領域のアクセシブル名になります |
| `series` | `[]` | 各系列に `name` と、グラフ形式に応じた `values`、`value`、`points`、`ranges`、`children` のいずれかを指定します。`category`、`type`、`low` と `high`、リングの `max` は任意です |
| `horizontal` | `false` | 棒、範囲、ダンベル、箱ひげを横向きに描画します |
| `words` | 英語 | 箱ひげ図の 5 つの値の名前。`min`、`q1`、`median`、`q3`、`max` |
| `min`, `max`, `ticks` | データに合わせる、`4` | 軸の両端の値と目盛りの目安となる数。散布図の横軸には `xMin`、`xMax`、`xTicks` を使います |
| `format`, `tickFormat` | ロケールに従う | 値と目盛りの表示形式。散布図の横軸には `xFormat` を使います |
| `current` | なし | `aria-current` が付くデータ点のインデックス |

値表示、キー操作、凡例、色、目盛りは、どのグラフ形式でも共通です。すべてのオプション、CSS クラス、カスタムプロパティは [チャート](/components/chart) を参照してください。
