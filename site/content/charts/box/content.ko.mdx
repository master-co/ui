상자 수염 그림은 한 그룹의 관측값을 다섯 수치로 요약해 여러 그룹을 한눈에 비교할 수 있게 합니다. 상자의 양 끝은 제1사분위수와 제3사분위수이며, 중앙값은 배경색 선으로 표시합니다. 수염은 상자의 양 끝에서 사분위 범위의 1.5배 이내에 있는 최솟값과 최댓값까지 뻗습니다. 이 범위를 벗어난 관측값은 개별 점으로 표시합니다.

계열 하나가 그룹 하나를 나타냅니다. 원본 관측값을 `values`로 지정하면 상자 아래에 그룹 이름이 표시됩니다. 축 범위는 관측값에 맞춰 정해지며 0에서 시작하지 않습니다. 값 표시는 다섯 수치를 위에서부터 나열합니다. `words`의 항목(`{ min, q1, median, q3, max }`)에 페이지 언어에 맞는 이름을 지정합니다. `horizontal`을 사용하면 상자가 가로로 놓입니다.

상자 수염 그림은 다섯 수치 사이의 분포 모양을 보여 주지 않으므로 봉우리가 두 개인 분포도 하나인 분포와 같아 보일 수 있습니다. 분포 모양이 중요하면 각 그룹의 [히스토그램](/charts/histogram)을 그립니다.

## 가로 방향 \{#across\}

`horizontal`을 지정하면 상자가 가로로 놓이고 이름은 옆에 세로로 나열됩니다. 이름이 길거나 그룹이 많을 때 사용합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `series` | `[]` | 각 계열에는 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. 선택적으로 `category`, `type`, `low`와 `high`, 링의 `max`를 지정할 수 있습니다. |
| `horizontal` | `false` | 막대, 범위, 덤벨, 상자를 가로로 표시합니다. |
| `words` | 영어 | 상자 수염 그림의 다섯 수치에 붙일 이름(`min`, `q1`, `median`, `q3`, `max`) |
| `min`, `max`, `ticks` | 데이터에 맞춤, `4` | 축 범위의 양 끝과 대략적인 눈금 개수입니다. 산점도의 가로축에는 `xMin`, `xMax`, `xTicks`를 사용합니다. |
| `format`, `tickFormat` | 로캘에 따름 | 값과 눈금의 표시 형식입니다. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `current` | 없음 | `aria-current`로 표시할 데이터 지점의 인덱스 |

모든 차트 유형은 값 표시, 키보드 조작, 범례, 색상, 척도 동작을 공유합니다. [차트](/components/chart)에서 모든 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
