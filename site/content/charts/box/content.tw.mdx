盒鬚圖用五個統計值摘要一組觀測值，方便同時比較多組資料。盒體從第一四分位數延伸到第三四分位數，以背景色的線標出中位數。兩端的鬚線分別延伸至距盒體不超過 1.5 倍四分位距的最小與最大觀測值。超出這個範圍的觀測值會以單獨的圓點標示。

每個資料序列代表一組資料。透過 `values` 傳入原始觀測值，該組名稱就會顯示在盒體下方。刻度範圍會依觀測值調整，不以零為起點。數值提示由上往下列出五個統計值，可用 `words` 以頁面所用的語言為它們命名：`{ min, q1, median, q3, max }`。設定 `horizontal` 後，盒體會橫向排列。

盒鬚圖只呈現五個統計值，因此單峰與雙峰分布可能看起來一樣。若需要查看分布形狀，請為每組資料繪製一張[直方圖](/charts/histogram)。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `series` | `[]` | 每個資料序列都有 `name`，並依圖表形式提供 `values`、單一 `value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low` 和 `high`，以及圓環的 `max` |
| `horizontal` | `false` | 讓長條、區間、啞鈴和盒鬚圖以橫向呈現 |
| `words` | 英文 | 盒鬚圖五個統計值的名稱，分別對應 `min`、`q1`、`median`、`q3` 和 `max` |
| `min`, `max`, `ticks` | 依資料調整, `4` | 刻度的上下限與大致的刻度數量。散佈圖的水平刻度使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 依語系 | 數值與刻度標籤的顯示格式。散佈圖的水平刻度使用 `xFormat` |
| `current` | 無 | 以 `aria-current` 標記的資料點索引 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。[圖表](/components/chart) 說明這些功能，並列出所有選項、CSS 類別與自訂屬性。
