箱线图用五个统计量概括一组观测值，便于同时比较多组数据。箱体从第一四分位数延伸至第三四分位数，中位数用一条与背景同色的线标出。以箱体两端分别向外延伸 1.5 倍四分位距为界，须线延伸至界限内的最小和最大观测值。超出界限的观测值用独立的点表示。

每个数据系列对应一组数据。通过 `values` 提供原始观测值，系列名称会显示在对应箱体下方。坐标轴范围会根据观测值自动调整，不以零为起点。数值提示从上到下列出五个统计量，通过 `words` 可按页面语言为它们命名：`{ min, q1, median, q3, max }`。启用 `horizontal` 后，箱体横向绘制。

箱线图由五个统计量概括分布，因此单峰和双峰分布可能看起来一样。需要看清分布形态时，可为每组数据绘制一张[直方图](/charts/histogram)。

## 横向箱线图 \{#across\}

设置 `horizontal` 后，箱体改为横向绘制，名称沿侧边纵向排列，适合名称较长或分组较多的数据。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 绘图区的无障碍名称，说明图表展示的内容及其单位 |
| `series` | `[]` | 每个数据系列包含 `name` 和图表类型所需的数据，可为 `values`、`value`、`points`、`ranges` 或 `children`，还可指定 `category`、`type`、`low` 和 `high`，以及环形图的 `max` |
| `horizontal` | `false` | 将柱状图、区间图、哑铃图和箱线图横向绘制 |
| `words` | 英语 | 箱线图中五个统计量的名称，对应 `min`、`q1`、`median`、`q3` 和 `max` |
| `min`, `max`, `ticks` | 自适应, `4` | 坐标轴的取值范围和大致的刻度数。散点图的横轴使用 `xMin`、`xMax` 和 `xTicks` |
| `format`, `tickFormat` | 随区域设置 | 数值和刻度标签的显示格式。散点图的横轴使用 `xFormat` |
| `current` | 无 | 标记了 `aria-current` 的数据点索引 |

各种图表共用同样的数值提示、键盘操作、图例、颜色和刻度机制。[图表](/components/chart) 文档列出了所有选项、类和自定义属性。
