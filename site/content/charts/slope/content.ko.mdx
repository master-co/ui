기울기 차트는 두 시점을 나란히 놓고 각 계열의 값을 직선으로 연결합니다. 무엇이 올랐고 내렸는지, 어느 계열이 다른 계열을 앞질렀는지 선의 기울기와 교차로 파악할 수 있습니다. 눈금 없이 각 선의 시작점에는 값을, 끝점에는 값과 이름을 표시하므로 별도의 범례가 필요 없습니다.

이 차트에서 데이터 포인트 하나는 눈금 한 칸이 아니라 계열 하나를 뜻합니다. 포인터를 올리거나 방향키를 누르면 선 전체가 선택되고 나머지 선은 흐려집니다. 끝점에서 레이블이 겹치려 하면 서로 간격을 두되, 위쪽 레이블에 가리지 않는 범위에서 각 선에 최대한 가깝게 배치합니다. 계열이 여섯이나 일곱 개를 넘으면 양 끝이 빽빽해집니다. 나머지 계열을 한 선으로 묶거나 범례가 있는 [꺾은선 차트](/charts/line)를 사용합니다.

레이블을 세 개 이상 지정할 수도 있으며, 이 경우 각 선은 레이블마다 방향을 바꿉니다. 기울기 차트는 두 시점을 직선 하나로 연결할 때 변화가 잘 드러나므로, 레이블이 많다면 [꺾은선 차트](/charts/line)가 더 읽기 쉽습니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 접근성 이름 |
| `labels` | `[]` | 축을 따라, 레이더 차트 둘레에, 또는 히트맵 열 위에 표시하는 이름 |
| `series` | `[]` | 각 계열에 `name`과 차트 유형에 맞는 `values`, `value`, `points`, `ranges` 또는 `children`을 지정합니다. `category`, `type`, `low`와 `high`, 링의 `max`는 선택 사항입니다. |
| `min`, `max` | 범위 자동 맞춤 | 두 열이 함께 쓰는 축의 양 끝값입니다. |
| `format` | 로캘 기본 형식 | 값의 표시 형식입니다. |
| `current` | 없음 | `aria-current`로 표시한 데이터 포인트의 인덱스 |

값 표시, 키보드 조작, 범례, 색상, 눈금은 모든 차트 유형에 공통입니다. [차트](/components/chart)에서 전체 옵션, 클래스, 사용자 지정 속성을 확인할 수 있습니다.
