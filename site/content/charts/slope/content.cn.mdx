斜率图将两个时点并排摆放，每个数据系列用一条直线连接两端。从线条的斜率和交叉就能看出哪些值上升、哪些下降，以及哪些系列超过了其他系列。图中没有刻度。每条线的起点标注数值，终点标注数值和名称，因此也无需图例。

斜率图以整个数据系列作为一个可选数据点。用指针或方向键选中一条线时，整条线都会突出显示，其他线条则会淡化。同一端的标签如果会重叠，就会略微错开，在避开上方标签的同时尽量贴近各自的线条。超过六七个数据系列时，两端就会变得拥挤。可将其余系列合并为一条线，或改用带图例的[折线图](/charts/line)。

也可以使用两个以上的标签，此时每条线会依次连接各标签对应的值。标签较多时，[折线图](/charts/line)更易读，因为斜率图的优势在于用一条直线呈现两个时点之间的变化。

## 选项 \{#options\}

| 选项 | 默认值 | |
| --- | --- | --- |
| `label` | 无 | 说明图表展示的内容及其单位，用作绘图区的无障碍名称 |
| `labels` | `[]` | 沿坐标轴、环绕雷达图或位于热力图各列上方的名称 |
| `series` | `[]` | 每个数据系列包含 `name` 和对应图表类型所需的数据：`values`、`value`、`points`、`ranges` 或 `children`。可选字段包括 `category`、`type`、`low` 和 `high`，以及圆环的 `max` |
| `min`, `max` | 自动适应数据 | 两列共用的刻度范围两端 |
| `format` | 使用区域设置 | 数值的显示格式 |
| `current` | 无 | 标记有 `aria-current` 的数据点索引 |

所有图表类型共用读数面板、键盘操作、图例、配色和刻度机制。[图表](/components/chart) 组件文档列出了所有选项、CSS 类和自定义属性。
