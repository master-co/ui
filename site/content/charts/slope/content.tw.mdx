斜率圖將兩個時間點並排，為每個資料序列畫一條直線連接兩端。從線段的斜率與交會就能看出哪些數值上升、下降，以及哪些序列超越了其他序列。起點標示數值，終點標示數值與名稱，因此無須另外查看刻度或圖例。

在斜率圖中，每個資料序列整體算一個可選取的資料點。將指標移到線條上或使用方向鍵時，整條線會被選取，其他線條則會淡化。端點標籤若會重疊，圖表會將它們稍微錯開，並在上方標籤留出的空間內盡量靠近各自的線條。超過六、七個資料序列時，端點容易擁擠。可以將其餘序列合併成一條線，或改用附圖例的[折線圖](/charts/line)。

可以設定兩個以上的標籤，線條會依序連接各標籤對應的數值。標籤多時，[折線圖](/charts/line)較易閱讀。斜率圖最適合用一條直線呈現兩個時間點之間的變化。

## 選項 \{#options\}

| 選項 | 預設 | |
| --- | --- | --- |
| `label` | 無 | 說明圖表呈現的內容與單位，作為繪圖區的無障礙名稱 |
| `labels` | `[]` | 沿刻度排列、環繞雷達圖或位於熱圖各欄上方的標籤 |
| `series` | `[]` | 每個資料序列包含 `name`，並依圖表形式提供 `values`、`value`、`points`、`ranges` 或 `children`。也可指定 `category`、`type`、`low`、`high` 和圓環的 `max` |
| `min`, `max` | 依資料調整 | 兩欄共用的刻度範圍上下限 |
| `format` | 依語系 | 數值的顯示格式 |
| `current` | 無 | 標有 `aria-current` 的資料點索引 |

各種圖表共用數值提示、鍵盤操作、圖例、色彩與刻度。請參閱 [圖表元件](/components/chart) 的完整選項、CSS 類別與自訂屬性。
