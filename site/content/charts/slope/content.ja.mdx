スロープグラフでは2つの時点を左右に並べ、系列ごとに値を直線で結びます。線の傾きと交差を見るだけで、値の増減や系列間の順位の入れ替わりが分かります。始点には値、終点には値と系列名を表示するため、目盛りや凡例は不要です。

このグラフでは、目盛りの各段階とは別に、系列全体を1つのデータ点として扱います。ポインターを合わせるか矢印キーを使うと線全体が選択され、ほかの線が薄くなります。端で重なりそうなラベルは、上にあるラベルとの間隔を確保しながら、それぞれの線にできるだけ近い位置にずらします。系列が6〜7本を超えると端が混み合うため、残りを1本にまとめるか、凡例付きの[折れ線グラフ](/charts/line)を使います。

ラベルは3つ以上指定でき、その場合は各ラベルの位置で線が折れ曲がります。スロープグラフは2時点を1本の直線で結ぶと変化が伝わりやすいため、ラベルが多い場合は[折れ線グラフ](/charts/line)のほうが読みやすくなります。

## オプション \{#options\}

| オプション | 既定 | |
| --- | --- | --- |
| `label` | なし | グラフの内容と単位を示す、プロット領域のアクセシブルな名前 |
| `labels` | `[]` | 軸に沿って、レーダーチャートの周囲に、またはヒートマップの各列の上に表示する名前 |
| `series` | `[]` | 各系列に `name` と、形式に応じて `values`、`value`、`points`、`ranges`、`children` のいずれかを指定。`category`、`type`、`low` と `high`、リングの `max` は任意 |
| `min`, `max` | 自動調整 | 2つの列が共有するスケールの両端 |
| `format` | ロケールに従う | 値の表示形式 |
| `current` | なし | `aria-current` で示すデータ点のインデックス |

詳細表示、キーボード操作、凡例、色、スケールはすべてのグラフ形式で共通です。[チャート](/components/chart) では、これらの機能とすべてのオプション、CSS クラス、カスタムプロパティを説明しています。
