원형 차트와 도넛 차트는 전체가 어떻게 구성되는지 보여 줍니다. 각 조각의 크기는 합계에서 차지하는 비율에 따릅니다. 조각 사이의 간격은 일정하고 모서리는 둥글게 처리됩니다. 여섯 번째 조각까지 있으면 작은 조각을 알아보기 어려우므로 항목을 다섯 개 이하로 유지하고 나머지는 "기타"로 묶습니다.

도넛 차트의 가운데에는 합계나 강조할 항목의 값 하나를 표시합니다. 이 값은 `center`로 지정합니다. 조각 위에 포인터를 올리면 가운데에 해당 조각의 값과 이름이 표시되어 링을 가리지 않습니다. 차트에 `chart-split`을 적용하면 범례가 플롯 옆에 세로로 배치되고 각 항목 끝에 해당 조각의 비율이 표시됩니다. 공간이 부족하면 범례가 플롯 아래로 이동합니다.

`pie`는 가운데 구멍이 없는 형태입니다. `--chart-size`는 두 형태의 너비를 지정하며 기본값은 12rem입니다. `hole`은 도넛의 바깥 반지름에 대한 구멍 반지름의 비율이며 기본값은 .7입니다.

## 원형과 도넛 \{#pie-or-donut\}

[도넛 차트](/charts/donut)는 가운데에 숫자 하나를 표시하고, 원형 차트는 원 전체를 조각으로 채웁니다. 하나의 막대에서 전체의 구성을 보여 주려면 [구성 내역](/components/breakdown)을 사용합니다.

## 옵션 \{#options\}

| 옵션 | 기본값 | |
| --- | --- | --- |
| `label` | 없음 | 차트가 보여 주는 내용과 단위를 설명하는 플롯의 접근성 이름 |
| `series` | `[]` | 각 계열에 `name`과 형태에 맞는 데이터를 지정합니다. `values`를 사용하거나, 조각이나 링에는 `value`를, 산점도에는 `points`를 사용합니다. `category`, `type`, 링의 `max`는 선택 사항입니다. |
| `format`, `tickFormat` | 로캘 기본 형식 | 값과 눈금의 표시 형식. 산점도의 가로축에는 `xFormat`을 사용합니다. |
| `hole`, `center` | `.7`, 없음 | 도넛 구멍의 크기와 도넛이나 링의 가운데에 표시할 내용 |
| `legend`, `toggle` | 계열이 두 개일 때, `true` | 범례 표시 여부와 범례 항목의 체크박스 표시 여부 |

값 표시, 키보드 조작, 범례, 색상, 척도는 모든 차트 형태에 공통으로 적용됩니다. [차트](/components/chart)에서 자세한 설명과 모든 옵션, CSS 클래스, 사용자 지정 속성을 확인할 수 있습니다.
